# Captain Salvage

Captain Forever의 “전투 중 노획·재조립”에서 설계 영감을 얻은 오리지널 HTML Canvas 웹 프로토타입입니다. 원작의 코드, 아트, 이름, 음향이나 콘텐츠는 포함하지 않습니다.

## 실행

빌드 도구나 의존성은 없습니다. [index.html](index.html)을 현대 브라우저로 열거나, 작업 폴더에서 정적 웹 서버를 실행해 접속하세요.

## 플레이

- `W` / `S`: 전진·후진 추진
- `A` / `D`: 회전
- `Space`: 레이저 발사
- 마우스 클릭: 가까운 황금 잔해를 빈 연결점에 자동 부착
- `R`: 즉시 새 항해

지휘 코어를 잃으면 항해가 끝납니다. 적의 지휘 코어를 먼저 파괴해야 연결된 부품이 회수 가능한 잔해로 남습니다.
