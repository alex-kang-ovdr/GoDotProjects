# 서바이버 아레나 v7.0

단일 HTML5 Canvas / JavaScript 게임. `index.html`을 Chrome 또는 Edge에서 열면 바로 실행됩니다.

## v7 변경
- 난이도 선택(일반/도전), 적 체력과 공격력 배율
- 분열 몬스터: 처치 시 소형 몬스터 3마리 생성
- 저격 몬스터: 사거리 증가, 고속 탄환
- 누적 최고 처치, 승리 횟수, 도전 횟수 저장
- 로비의 장비 제작/도감 버튼 연결 수정

## 조작
WASD/방향키 이동, 스페이스 대시, P/Esc 일시정지, 모바일 터치 이동/대시.

## 참고
원작을 참고한 비공식 독립 프로토타입. 수치와 그래픽은 자체 제작 예시입니다.
