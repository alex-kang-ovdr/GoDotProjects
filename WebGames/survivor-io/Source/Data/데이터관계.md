# 데이터관계 상세 데이터 시트

> 모든 예시 수치와 가상 확률은 원작 실측값이 아닙니다. `상태` 열을 확인하세요.

| From | Field | To | Key | 규칙 | 검증 |
|---|---|---|---|---|---|
| 무기 | 진화조건 | 패시브스킬 | 이름 | 문자열 대신 PassiveID 매핑 권장 | 참조 무결성 |
| 액티브스킬 | 이펙트ID | 이펙트 | EffectID | 존재 확인 | 참조 무결성 |
| 몬스터 | 드랍테이블 | 드랍테이블 | DropID 그룹 | 그룹별 합 100 확인 | 가중치 |
| 스테이지웨이브 | 몬스터풀 | 몬스터 | MonsterID | 슬래시 구분 ID 존재 | 참조 무결성 |
| 과금상품 | 재화/보상 | 재화경제 | CurrencyID | 실제 SKU 매핑 | 가격 검증 |
| 액티브스킬 | SkillID | 스킬레벨 | SkillID | 레벨 1~5 연속 | 유일성 |

## 데이터 적용 규칙
- ID 중복 금지, 참조 ID 무결성 검사
- 수치 가정은 밸런스 플레이테스트 이후 수정
- 스킬, 무기, 몬스터, VFX는 데이터 기반 정의 및 객체 풀링 권장
