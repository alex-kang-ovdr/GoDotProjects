# EMBERWILD v18

Don't Starve의 생존 루프를 참고해 독자적으로 구현한 HTML Canvas + JavaScript 게임 프로토타입입니다. 원작의 코드와 에셋은 사용하지 않습니다.

## 실행
`index.html`을 Chrome/Edge로 열면 됩니다. `game.js`가 같은 폴더에 있어야 합니다. 서버와 인터넷 연결은 필요하지 않습니다.

## 조작
WASD 이동, 마우스 클릭 자동 이동·채집, E 상호작용, Space 공격, Shift 회피, F 모닥불 제작/배치, R 모닥불 휴식, C 보관함, M 지도, Esc 취소/일시정지. 모바일 터치 방향 버튼 지원.

## v18 변경
- 모닥불 휴식: 연료 18 이상, 허기 24 이상, 240 거리 내 적 없음. 연료 18·허기 12 소모, 기력 65·정신력 12·체력 7 회복. 무한 회복 불가.
- 젖음 65 이상에서 체온·정신력에 악영향, 정신력 15 미만일 때 체력 감소.
- 자동 식사 옵션을 세이브 파일에 보존하고 불러올 때 복원.
- v17 및 과거 세이브 로딩 호환, v18 별도 저장 슬롯.
- Node.js 자동 회귀 테스트 17개 (`node test.js`).

## 검증 범위
Node.js 자동 로직 테스트 17/17 통과, JavaScript 문법 검사 통과. Chromium 자동 실행은 시간 초과로 완전 검증하지 못했습니다. 실제 자원 수급을 통한 16일 완주 및 밸런싱은 미검증입니다.
