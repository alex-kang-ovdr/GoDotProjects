- 내부 문 8개와 에어록 2개를 개별 조작합니다. 닫힌 문은 산소 이동·화재 확산을 격리하며, 열린 연결을 따라 지역 감압이 진행됩니다.
- 아군의 자동 문 통과와 자동 닫기, 수동 개방 유지, 침입자의 문 파괴를 구현했습니다. 파손된 문은 다음 비콘에서 정비합니다.
- 승무원의 소유자와 실제 함선 위치를 분리했습니다. 적선 위 아군과 본함의 적 침입자를 실제 이동·피해·산소·대인전 규칙으로 처리합니다.
- 같은 방의 적대 승무원은 싸우고, 교전 중인 방은 수리·운용하지 못합니다. 적대 시스템을 점거한 침입자는 파괴 공작을 수행합니다.
- 텔레포터로 최대 2명 침투·귀환을 지휘합니다. 전력과 재사용 대기가 필요하며, 적선 파괴·도주 시 남은 아군은 사망합니다. 승무원 전멸 승리의 생존 침투조는 회수됩니다.
- 맨티스 종족, 인간·엔지·맨티스 고용, 생존 인원 최대 8명, 승무원 구조 사건을 추가했습니다.
- 공격·방어 드론, 관제 전력, 부품 자원, 교전당 최초 전개 비용과 무료 재가동을 추가했습니다. 방어 드론은 미사일만 요격합니다.
- 무기별 자동·수동 전환, 단발·일제사격을 추가했습니다. 정지 중 발사는 예약하고 탄약은 실제 발사 때 소비합니다.
- 빔을 시작·끝 방 사이의 최대 4격자 선분으로 조준합니다. 통과한 각 방을 한 번씩 타격하고 발동 시 실드 층수만큼 방별 피해가 감소합니다.
- 기함 1단계는 실제 승무원 강습, 2단계는 8초 드론 과충전, 3단계는 미사일 3연발을 사용합니다. 공격 전 6초 예고를 표시합니다.
- 상점에 드론 부품·관제·공격 드론, 텔레포터 개량, 고용, 최대 선체 보강을 추가했습니다. 사건과 보상에도 관련 자원이 연결됩니다.
- 승무원 다중 선택, 문 도면·목록 조작, 드론 탭, 침투·귀환 버튼, 수동 발사와 빔 경로, 침입·특수 공격 HUD를 추가했습니다.
- 저장 JSON 내보내기·가져오기, 가져올 상태 미리 보기, 가져오기 전 복구 사본을 추가했습니다.

### 호환과 동작 보존

- 저장 버전은 2이며 기존 브라우저 저장 키를 유지합니다. v1 저장을 원자적으로 변환하고 기존 선체·체력·자원·진행·충전을 보존합니다.
- 문·보조 전력·승무원 실제 위치·드론·빔 필드와 잘못된 외부 참조를 저장 검증에 포함했습니다.
- 침투 중, 전개 드론, 비행 중 빔을 저장·복원해도 중복 비용을 내지 않습니다.
- 개별 문이 생기면서 전체 환기는 모든 내부 문과 에어록을 여는 명령으로 바뀌었습니다.

- classic script와 외부 의존성 없는 HTML 실행 방식, 기존 지도·이벤트·전력·무기·도주·상점·승리/패배 흐름을 유지했습니다.
