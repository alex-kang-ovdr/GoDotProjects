# 09. 드론·강화장치 역기획

> 범위: 기본 게임 + Advanced Edition(AE). 확인일: 2026-11-13.\
> [확인]은 자료로 확인한 동작, [해석]은 기획 분석, [재구성안]은 재현용 데이터·로직 제안이다.

## 1. 서로 다른 두 장비 체계

드론은 부품과 전력을 사용해 지속적인 업무를 수행하는 장치다. 강화장치(Augmentation)는 함선의 규칙이나 효율을 바꾸는 보유 효과다. 둘 다 전투와 경제에 영향을 주지만 장착·가동·자원 소비 방식이 다르다.

| 구분 | 드론 | 강화장치 |
|---|---|---|
| 장착 단위 | 드론 설계도 | 효과 장치 |
| 주요 가동 조건 | 드론 제어·전력·배치 가능한 부품 | 장착되어 있고 효과 조건 충족 |
| 행동 | 공격·요격·수리 등 자동 업무 | 수치 변경·능력 해금·자원 변화 |
| 손실 | 드론 실체 파괴·도약에 따른 소멸 | 판매·교체 등 보유 변경 |
| 전술 입력 | 전력·배치·가동 시점 | 장착 선택·조건 활용 |

[해석] 두 체계를 하나의 패시브 슬롯 시스템으로 합치면 드론 부품의 전투별 비용과 장비 가동 시점을 잃게 된다.

## 2. 드론의 세 가지 층

[재구성안] 다음 객체를 분리한다.

1. **DroneBlueprint:** 설계도. 장착·매매 가능한 아이템.
2. **DroneInstance:** 현재 배치된 드론 실체. 체력·위치·가동 상태를 가짐.
3. **DronePartResource:** 새 실체를 배치할 때 지불하는 공용 자원.

[확인] 드론을 처음 가동해 배치할 때 부품을 소비한다. 이미 살아 있는 실체의 전력을 끄고 켜는 행위를 매번 새 드론 구매로 취급하지 않는다. 함내 드론은 정상적으로 살아 있다면 도약 후에도 남지만 외부·탑승 드론은 같은 방식으로 보존되지 않는다.[S1]

## 3. 드론군별 역할

| 유형 | 작업 공간 | 주요 기능 | 기획적 제약 |
|---|---|---|---|
| Combat Drone | 적 함선 주변 | 자동 탄도 공격 | 표적 방을 세밀하게 선택하기 어려움 |
| Beam Drone | 적 함선 주변 | 자동 빔 공격 | 적 실드 상태에 크게 의존 |
| Defense Drone | 자기 함선 주변 | 특정 발사체 요격 | 모든 위협을 보장 차단하지 않음 |
| Anti-Combat Drone [AE] | 자기 함선 주변 | 적 공격 드론 대응 | 함선 직접 공격과 다른 목표 |
| System Repair Drone | 자기 함선 내부 | 수리·진화 등 | 자동 업무 우선순위 |
| Anti-Personnel Drone | 자기 함선 내부 | 침입자 전투 | 수리 인력의 직접 대체는 아님 |
| Boarding Drone | 적 함선 내부 | 침입·전투·방해 | 배치와 회수 정책이 승무원과 다름 |
| Ion Intruder [AE] | 적 함선 내부 | 이온 교란·기절 | 일반 탑승자와 별도 상태 |
| Hull Repair Drone | 자기 함선 주변 | 선체 복구 | 부품을 수리 자원으로 전환 |
| Shield Overcharger [AE] | 자기 함선 주변 | 특수 실드 축적 | 일반 실드 재생과 별도 |

[확인] 드론은 기본적으로 자동 행동이며, 승무원처럼 방 목적지를 자유 명령하는 제어 체계가 아니다. 방어 드론 I과 II는 요격 대상 범위가 다르며, II는 레이저·이온도 대응한다.[S2]

[검증 필요] 외부 드론, 함내 드론, 수리 완료 후 사라지는 드론, 적 함선 내부로 진입하는 드론은 동일한 종료 정책을 갖지 않는다. 배치 취소·설계도 재정렬·부품 환급 규칙은 타입별로 검사해야 한다.

## 5. 방어 드론의 판정 설계

[확인] 방어 드론은 자동 표적 선택과 사격 타이밍 때문에 위협을 놓칠 수 있다. 요격 대상으로 분류된 발사체도 항상 제거되는 것은 아니다.[S2]

[해석] Defense Drone II의 추가 표적 범위는 처리 능력 증가인 동시에 주의 분산을 만들 수 있다. 위험한 미사일과 덜 위험한 탄 사이의 우선순위를 플레이어가 직접 지정하지 못하므로, 단순히 I의 완전한 상위 성능으로만 볼 수 없다.

[재구성안] 요격에는 다음 요소를 둔다.

- 현재 각도·회전·사격 가능 방향.
- 목표가 탐지 범위에 진입한 시점.
- 재사격 대기시간.
- 목표 예측 위치와 요격탄 이동.
- 발사체별 targetClass.
- 이미 파괴되거나 화면을 벗어난 목표 처리.
- 여러 위협에 대한 중복 조준 방지.

원작의 알려진 요격 사각·타깃 처리 특이점까지 정확히 복원하려면 플레이 캡처가 필요하다. 독자 재구성에서 개선한다면 “원작 호환”과 구분한 변경 사항으로 기록한다.

## 6. 함내 드론과 인력 경제

[확인] 시스템 수리 드론은 손상·균열·화재 대응을 자동 수행하고, 대인 드론은 침입자 대응을 담당한다.[S2]

[해석] 드론이 늘어도 승무원 역할이 전부 사라지지는 않는다.

- 운용 숙련도와 이벤트 종족 선택지를 제공하지 않는다.
- 사용 전력이 필요해 전투 중 다른 기능과 경쟁한다.
- 자동 업무의 순서가 플레이어의 최우선 과제와 다를 수 있다.
- 드론 제어가 손상되면 여러 자동 기능이 함께 무너질 수 있다.
- 사람이 위험한 방에 들어가는 시간을 줄여 다른 업무에 배치할 수 있다.

[재구성안] 수리 드론 AI는 원작 우선순위를 확인하기 전에는 “가장 가까운 손상 방”으로 단정하지 않는다. 버그 분석을 위해 선택한 작업과 이유를 로그에 남긴다.

## 7. 드론 부품과 회수

[확인] 드론 부품은 해킹과도 공유한다. Drone Recovery Arm은 살아남은 외부 드론의 일부를 회수하지만 해킹 드론·탑승 드론·이온 침입자를 동일하게 환급하지 않는다.[S3][S4]

[해석] 부품 부족은 “드론 빌드가 나쁘다”는 절대 결론보다 전투별 장치 사용의 가치 판단을 요구한다. 쉬운 전투에서 모든 드론·해킹을 가동하면 다음 위험 구간의 선택 폭이 줄어든다.

[재구성안] 기대 비용:

~~~text
expectedPartsCost =
    newDeployments
  + hackingLaunches
  - eligibleRecoveredInstances
~~~

이 값은 단일 전투 내부뿐 아니라 상점까지 남은 예상 전투 수와 함께 평가한다. 회수 확률이 아닌 회수 가능 여부와 생존 여부를 명시한다.

## 8. 강화장치 장착 규칙

[확인] 강화장치는 최대 3개이며 일반 화물칸에 보관하지 않는다. 중첩 가능한 효과와 중첩되지 않는 효과가 존재한다. 새 장비를 얻었을 때 초과 장착 처리는 일반 무기 화물 처리와 다르다.[S4]

[재구성안] 필요한 데이터:

~~~json
{
  "augmentId": "example_modifier",
  "stackPolicy": "additive",
  "maxCopies": 3,
  "trigger": "on_weapon_charge_rate",
  "value": 0.10,
  "eligibility": ["player_ship"],
  "excludedEffects": [],
  "eventRequirements": []
}
~~~

이 JSON은 원작 데이터 형식이 아니라 장비 효과의 혼선을 줄이기 위한 제안이다. maxCopies와 중첩 방식은 장비마다 확인해야 한다.

## 9. 강화장치의 기획상 분류

| 분류 | 대표 예 | 의사결정 변화 |
|---|---|---|
| 공격 속도 | Automated Re-loader | 반복 공격의 시간 창 변화 |
| 첫 공격 | Weapon Pre-Igniter | 장기 DPS보다 첫 무력화 중시 |
| 자원 회수 | Drone Recovery Arm | 드론 장기 유지비 감소 |
| 정보 | Long-Ranged Scanners | 위험·경로 선택의 정보 증가 |
| 접근 규칙 | Zoltan Shield Bypass | 특정 특수 실드 제한 우회 |
| 사망 보호 | Backup DNA Bank | 클론 시스템 정지의 위험 완화 |
| 전술 시너지 | Stealth Weapons | 은폐 중 사격의 대가 변화 |
| 이벤트 열쇠 | Damaged Stasis Pod | 현재 성능보다 후속 선택지 보존 |

[해석] 효과를 구매 가격 대비 수치 증가만으로 평가하면 정보·이벤트 열쇠·접근 규칙의 가치를 놓친다. “이번 런에서 이 슬롯을 비워 둘 가치”가 비교 대상이다.

## 10. 속도 증가와 시간 감소의 차이

[확인] Automated Re-loader의 10%는 발사 속도 증가로 해석되며 충전시간을 단순히 10% 빼는 것과 다르다. 여러 개의 가산 중첩과 승무원 보정도 구분한다.[S4] 무기 운용 숙련은 충전시간 감소를 제공한다.[S5]

[재구성 계산 예시]

~~~text
T = Tbase × crewTimeMultiplier / (1 + 0.10 × reloaderCount)

Burst Laser II, Tbase = 12
숙련 최대 crewTimeMultiplier = 0.8
Reloader 1개

T = 12 × 0.8 / 1.1 ≈ 8.73초
~~~

이는 확인된 개별 규칙을 조합한 산술 예시다. 해킹·전력 중단·첫 발사·충전 축적 같은 전투 상태까지 포함한 “항상 8.73초마다 명중”이라는 뜻은 아니다.

## 11. 대표 판단 시나리오

### 상황 A: 드론 부품 4개, 해킹과 방어 드론 보유

[해석] 모든 전투에서 둘 다 쓰면 최대 2회의 전투로 자원이 고갈될 수 있다. 적 무기가 일반 실드로 막히는 전투라면 방어 드론을 켤 이유가 작고, 해킹 없이도 짧게 해결된다면 부품을 아낄 수 있다. 반대로 한 번의 미사일이 클론실을 무력화할 수 있는 상황이면 부품보다 생존이 우선이다.

### 상황 B: 세 번째 강화장치 슬롯이 채워짐

[해석] 즉시 전투를 개선하는 장치와 후반 성장용 장치 사이에서 교체를 판단한다. 남은 섹터, 전투 수, 이미 충분한 화력, 다음 상점까지의 거리를 함께 고려한다. 경제 장비의 회수 기간을 평가할 때 이미 얻은 이익을 미래 이익으로 중복 계산하지 않는다.

## 12. QA와 수용 기준

| ID | 시험 | 기대 결과 |
|---|---|---|
| DRN-01 | 배치된 드론 OFF → ON | 새 실체가 아니면 부품 중복 소비 없음 |
| DRN-02 | 함내 드론 생존 상태로 도약 | 외부 드론과 동일 소멸 처리 금지 |
| DRN-03 | 해킹 드론 + 회수장치 | 해킹 부품 자동 환급 금지 |
| DRN-04 | 방어 드론 I 앞의 레이저 | II와 같은 대상 집합을 사용하지 않음 |
| DRN-05 | 수리 드론 가동 중 제어 손상 | 전력 조건에 따라 작업 상태 갱신 |
| DRN-06 | 선체 수리 드론의 가동 종료 | 일반 외부 공격 드론 종료와 구분 |
| AUG-01 | 강화장치 3개 + 보상 | 일반 화물칸으로 몰래 이동시키지 않음 |
| AUG-02 | 중첩 불가 강화장치 반복 획득 | 중첩 정책에 따른 명시적 처리 |
