# Shadow over Mystara — Web Enhanced v4

브라우저에서 `index.html`을 열어 실행하는 순수 HTML5 Canvas/JavaScript 게임입니다. 외부 의존성 없음.

## v4 추가
- F 회피: 스태미나 소모, 짧은 무적 시간, 쿨다운
- H 홀드 차지 강공격: 일정 시간 충전 후 버튼 해제
- L 퍼펙트 가드: 타이밍 성공 시 피해 무효 및 MP 회복
- 오우거/트롤/드래곤 보스별 3개 고유 패턴
- 드래곤 메테오 장판 예고 및 판정
- 적 간 겹침 완화, 콤보 통계, 스태미나 HUD
- 모바일 회피/차지 버튼

## 기본 조작
WASD/방향키 이동, J 공격, K 강공격, E 특수기, Space 점프, Shift 대시, U 주문, Q 주문 선택, O 아이템 링, I 아이템 사용, P 일시정지, R 재시작.

원작 IP의 공식 이식작이 아닌 비상업적 시스템 연구용 프로토타입입니다. 정확한 원작 프레임 데이터/패턴은 별도 검증이 필요합니다.
