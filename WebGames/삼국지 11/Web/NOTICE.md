# 출처·권리·배포 주의

본 프로그램은 사용자 요청에 따라 새로 작성한 HTML / CSS / JavaScript 전략 게임 프로토타입입니다. 원작 삼국지 11의 공식 웹 버전이나 KOEI TECMO의 승인·제휴 제품으로 표시하지 않습니다.

원작 실행파일, 지도 바이너리, 초상화, UI 이미지, 음원, 전체 원문 대사, 게임 디스크 콘텐츠는 포함하지 않습니다. 지도·도시·부대 그림은 Canvas로 생성합니다. 원작 명칭은 연구·분석 대상 식별에 사용합니다.

`reference/`에는 사용자 제공 v5 산출물과 그 안의 출처 표본을 보존했습니다. 기존 문서·2차 출처 데이터가 별도 재배포 허가를 제공한다는 보장은 없습니다. 이 파일은 해당 자료에 새 라이선스를 부여하지 않습니다. 공개·상업 배포에 앞서 명칭·자료의 사용 조건을 별도로 확인해야 합니다.

이벤트 대사와 설정, 무장 프리셋 대부분, 전투 공식은 새로 구성했으며 원작 데이터라고 주장하지 않습니다. 화면에 표시된 ‘출처 표본’의 의미는 `docs/FIDELITY.md`를 참고하세요.

외부 분석 서비스, 광고, 계정 생성, 로그인, 사용자 지표 추적, 온라인 통신은 구현하지 않았습니다. 자동 저장은 사용자의 브라우저 저장소, 파일 내보내기는 사용자 컴퓨터의 JSON 파일을 사용합니다.
