# 게임 개요와 원작 재현 범위

> **원작 일치도 표기:** `확인`=원작 UI/공식 자료로 검증, `참고`=공략 자료 기반, `가설`=재구현 제안, `미확정`=실측 필요. 이 문서는 비공식 역기획이며 코에이테크모의 내부 명세가 아닙니다.

## 게임 정체성
삼국지 11은 헥스 기반 단일 전략·전술 지도를 사용하는 턴제 군주제 전략 게임이다. 도시 경영, 인재 운용, 외교, 부대 이동, 전투가 같은 월드에서 진행된다.
## 목표와 상태
- 시나리오 시작 시 선택 세력의 군주, 소유 거점, 소속 무장, 자원 및 관계를 초기화한다.
- 플레이어는 내정, 인재, 군사, 외교, 연구, 계략 명령을 통해 중국 통일을 추진한다.
- 세력 멸망, 통일 및 이벤트 기반 종료를 별도 조건으로 처리한다.
## 범위
PC판 기본판과 파워업키트 차이를 분리한다. 다른 플랫폼 이식판의 UI/추가 기능을 혼합하지 않는다.
## 재현 우선순위
P0: 지도/턴/도시/부대/전투, P1: 내정/인재/외교/계략/기교, P2: 역사 이벤트/AI 행동 경향/연출.

## 구현 인터페이스 공통 요구
- 모든 명령은 실행 가능 여부·소모 자원·상태 변경·이벤트 로그를 반환한다.
- 시나리오와 규칙 데이터를 로직에서 분리한다.
- 재현 실험에는 버전, 난이도, 시나리오, 날짜, 입력 상태, 결과 스크린샷을 첨부한다.
