# 삼국지 11 역기획 v5 — 공개 자료 기반 실측 데이터 편입

## 구성
- [이전 버전 자료](../Archive/ReverseDesign/RTK11_Reverse_Design_v4/README_V4.md): v4 기존 76개 파일 보존 (원작 검증 완료 데이터로 간주하지 않음)
- `verified_data/cities_42.csv`: 42개 도시 이름과 특성, 공개 자료 전사
- `verified_data/officers_sourced_sample.csv`: 공개 무장 표에서 확인 가능한 12명 표본
- `verified_data/city_stats_sourced_sample.csv`: 도시 8곳 기본 수치 표본
- `SOURCE_REGISTER.md`: 출처와 한계
- `DATA_GAPS.md`: 아직 확보하지 못한 원작 데이터

## 중요
공개 웹페이지의 검색 결과에서 직접 확인한 값만 수록했습니다. 전체 원작 실행파일/시나리오/세이브 데이터를 추출하지 않았으며 이 패키지는 완전 복원본이 아닙니다. 표본은 원작 파일이 아닌 제3자 공략 데이터입니다. 원문 대사집은 확보하지 않았고 v4의 대사는 신규 창작 시연 대사입니다.
