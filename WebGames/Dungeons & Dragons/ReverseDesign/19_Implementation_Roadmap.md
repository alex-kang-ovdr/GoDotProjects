# 코어 게임플레이 구현 로드맵

| 단계 | 구현 항목 | 완료 기준 |
|---|---|---|
| P0 | 고정 틱, 이동, 카메라, 레인 | 이동 및 충돌 테스트 통과 |
| P1 | 기본 공격, 피격, 가드, 다운 | 전투 상태 전이 및 히트박스 디버깅 |
| P2 | 6개 클래스 데이터, 고유 커맨드 | 캐릭터별 공격/이동 차이 재현 |
| P3 | 주문 링, 아이템 링, 장비 | 사용·소모·전환 정상 동작 |
| P4 | 적 AI, 보스 패턴 | 전투 웨이브 1개 완주 |
| P5 | 스테이지 분기, 상점, 성장 | 2개 이상 경로 완주 |
| P6 | 4인 협동, QA, 밸런싱 | 동시 플레이 및 회귀 테스트 통과 |

## 권장 모듈
`Input / Actor / Combat / Spell / Inventory / AI / Stage / Coop / UI / Data / Test`

## 우선 확보할 실측 데이터
- 캐릭터별 기본 공격 1~3타 프레임
- 공격 X 범위 및 Z 레인 허용폭
- 가드 방향·경직·무적 시간
- 주문별 사용 횟수 및 발동 조건
- 적 5종과 보스 2종의 행동 패턴
