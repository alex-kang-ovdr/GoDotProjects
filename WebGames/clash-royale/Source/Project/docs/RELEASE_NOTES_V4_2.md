# Crownfall Arena 4.2 — 가로 전투 화면과 조작 정리

2026-11-16 · 가로 손패·엘릭서·HUD 분리 및 진영 방향 변경

## 변경 결과

가로 게임 화면의 상대는 왼쪽, 아군은 오른쪽에 표시합니다. 왼쪽은 단순 HUD, 오른쪽은 카드와 인터랙티브 버튼으로 나눴습니다. PC 바깥의 좌측 설정·전역 치트와 우측 상세·통계·선택 대상 치트 구성은 유지합니다.

| 구역 | 내용 |
|---|---|
| 왼쪽 HUD | 경기 시간·국면·점수, 세로 엘릭서·수치·배율, 다음 카드, 선택 설명, 모드별 목표와 리플레이 시간 |
| 가운데 전장 | 왼쪽 상대 진영과 오른쪽 아군 진영, 세로로 흐르는 강과 두 다리 |
| 오른쪽 손패 | 카드 4장을 한 열로 세로 배치, 네 장 전체 표시 |
| 오른쪽 보조 버튼 열 | 일시정지, 카드 취소·정보, 방향·가이드·음향·기록, 상대·난이도·덱·사거리 및 모드별 제어 |

손패와 보조 버튼은 서로 다른 열입니다. 조작이 많은 연습·리플레이에서는 보조 버튼 열만 스크롤합니다. 버튼은 최소 44×44 CSS 픽셀을 확보하고, 손패는 네 행에 높이를 균등하게 배분합니다. 시작·일시정지·결과 패널은 전장 오른쪽으로 정렬합니다.

엘릭서는 아래에서 위로 채웁니다. 현재 수치, 상한 10, 생성 배율과 눈금을 함께 표시합니다. 세로 모드로 복귀하면 원래의 가로 엘릭서 바와 가로 손패로 돌아옵니다.

## 입력과 상태 유지

- 가로 투영은 `(worldX,worldY) → (worldY,480−worldX)`, 역변환은 `(screenX,screenY) → (480−screenY,screenX)`입니다.
- 적 킹은 화면 `(65,240)`, 아군 킹은 `(575,240)`에 놓입니다. 레인 A는 아래쪽, 레인 B는 위쪽입니다. 훈련의 설명·목표·결과 안내도 표시 방향에 맞춰 읽습니다.
- 클릭·드래그·배치 미리보기·선택·주문 효과·지형이 같은 변환을 사용합니다. 방향키의 월드 이동도 `(-dy,+dx)`로 맞췄습니다.
- 동적 개체와 HP·피해 글자는 정방향입니다. 엔진 좌표, 전투 계산, 저장 형식과 리플레이 명령은 바꾸지 않습니다.
- UI는 실제 노드를 이동하고 앵커로 복원합니다. 이벤트와 상태를 유지하고, 부모에서 분리된 컨트롤의 숨김을 따로 갱신합니다.
- 전환 중이던 드래그는 취소합니다. 화면 방향은 기존 프로필에 저장합니다.

## 검증

| 검사 | 결과와 범위 |
|---|---|
| 렌더러 관련 자동 검사 | 20개 통과. 그중 화면 방향 검사 7개, 진영·입력 역변환·배치·효과·시뮬레이션 불변 포함 |
| DOM 구조 모델 | 실제 HTML의 24개 이동 노드를 8회 왕복, 원래 부모·형제 순서 복원 및 slot·ID 연결 확인 |
| 정적 연결 | JavaScript 문법, HTML ID 중복·바인딩, 필수 파일 검사 |
| CSS 소스 검토 | 단일 열 손패, 독립 버튼 스크롤, 44px 조작 영역, 반응형 우선순위, 모드별 숨김 확인 |
| 산출물 | 최신 코드·문서를 단일 오프라인 HTML과 소스 ZIP으로 다시 빌드 |

렌더러 검사는 Node 기반 Canvas 호출과 좌표 검사입니다. 브라우저 접근 정책 제한으로 이번 버전의 실제 페이지 시각·터치·포커스·세로 리플레이 슬라이더는 직접 실행 검증하지 못했습니다. DOM 구조 모델과 CSS 계산은 실제 모바일 브라우저 사용성 검증을 대체하지 않습니다. 이전 4.1의 전체 130개 전투·기능 검사는 별도 이력이며, 이번 변경에서는 관련 렌더러 검사에 집중했습니다.
