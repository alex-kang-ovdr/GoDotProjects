# Crownfall Arena 4.3 — 외부 설정, 가로 전투, 2D·3D와 밀집보병

2026-11-16 · 프로그램 버전 4.3.0 · 기존 게임 주소와 접근 범위 유지

## 1. 화면 변경

사용자의 마지막 요청에 따라 인게임 좌측 하단의 승리 조건·플레이 방법·상시 조작 설명을 제거했다. 세부 규칙은 외부 도움말에 남기고 전투 중에 계속 표시하지 않는다.

| 영역 | 현재 배치 |
|---|---|
| 외부 좌측 PC 패널 | 화면 방향·2D/3D·일시정지·음향·도움말·기록·상대·난이도·덱·모드·전역 치트 |
| 인게임 좌측 | 시간·국면·점수·세로 엘릭서와 생성 배율 |
| 중앙 전장 | 가로: 적 왼쪽 / 아군 오른쪽. 세로: 적 위 / 아군 아래 |
| 인게임 우측 상단 | 다음 카드 미리보기 |
| 인게임 우측 | 손패 4장을 한 열로 세로 배치 |
| 조건부 조작 | 카드 선택 중에만 정보·취소, 살아 있는 밀집보병 분대가 있을 때만 전장 우측 하단의 스킬 |
| 외부 우측 PC 패널 | 대상 상세·통계·대상 치트·카드 설명·로그 |

일반 설정을 나열하던 인게임 보조 열은 제거했다. 좁은 화면과 터치 중심 환경에서는 게임 바깥 제목줄의 설정 버튼으로 같은 좌측 패널을 연다. 설정 서랍 자체는 전투를 멈추지 않으며 일시정지 버튼은 서랍 안에서도 작동한다. 덱·도움말 등의 모달은 기존 일시정지·재개 규칙을 사용한다.

처음 사용하는 환경의 기본 방향은 가로다. 이전에 세로를 저장한 환경은 그 선택을 유지한다. 화면 방향 전환은 실제 노드를 이동하고 앵커로 복원하여 이벤트·값을 보존한다. 손패 4장은 최소 높이 44px의 네 행으로 구성하며, 짧은 가로 화면에서는 외부 제목줄을 제외한 높이를 사용한다. 최종 실제 모바일 브라우저 크기·포커스 검증은 아래 한계에 명시했다.

## 2. 2D와 실제 3D

외부 좌측 렌더링 옵션에서 Canvas 2D와 WebGL1 3D를 선택한다. 3D는 높이가 있는 로우폴리 지형·다리·타워·병력·방패·투사체를 삼각형 메시와 깊이 버퍼로 그리며 방향광을 적용한다. 숲·황혼·설원 테마도 같은 전투 좌표에서 표시한다. HP·숫자·문구·조준 표시 등은 투명 Canvas HUD에 정방향으로 그린다.

`ArenaView`가 렌더러를 바꾸며, 최초 HUD 컨텍스트를 `alpha:true`로 만든다. 모드 전환은 현재 Game을 새로 만들지 않는다. 전투 시간, 자원, RNG, 명령, 병력·타워 상태를 유지하며 로컬 표시 설정만 저장한다.

배치 좌표는 현재 카메라의 지면 역변환으로 구한다. 3D 대상 선택은 실제 모델 삼각형과 깊이를 검사하므로 지면 원점과 떨어져 보이는 타워 머리·공중 병력도 선택할 수 있다. 방향키 조준 역시 현재 화면을 기준으로 이동한다. WebGL 생성·셰이더·그리기 실패나 컨텍스트 손실에는 자원을 정리하고 같은 전투를 2D로 이어간다.

자세한 구현·입력 계약은 [RENDERING.md](RENDERING.md)를 참고한다.

## 3. 밀집보병과 방패 돌격

| 항목 | 값 |
|---|---|
| 카드 비용·병력 | 엘릭서 5, 6명, 3열 × 2행 |
| 병사 한 명 | HP 340, 피해 65, 공격 간격 1.15초, 사거리 32 |
| 방어 대형 | 이동 속도 24, 실제 보호 조건을 충족하면 받는 피해 35% 감소 |
| 방패 돌격 | 엘릭서 1, 5초, 이동 속도 68, 대형 해제와 개별 추적, 방어 해제 |
| 재사용 대기 | 발동 시점부터 14초, 분대마다 별도 적용 |
| 돌격 종료 | 생존 병사 재집결 후 방어 대형 복구 |

분대 앵커와 개별 병사 좌표가 실제 이동을 제어한다. 다리 중심 정렬, 후방 타워·막힌 다리 우회, 사상자 후 자리 정리, 기절과 이탈에 따른 보호 해제를 포함한다. 집결·재집결 중에는 실제 앞뒤·좌우 위치에 따라 슬롯을 결정적으로 교환하여 뒤로 밀린 병사가 다른 병사에 막혀 원래 자리만 고집하는 정체를 해결했다. 몸체를 통과시키거나 순간이동하지 않는다.

스킬은 UI와 엔진 모두에서 진영·생존·소환 출처·배치·기절·비용·쿨다운·진행 모드를 검사한다. 분대의 병사를 클릭하면 해당 분대를 즉시 선택하고, 여러 분대가 있으면 드롭다운으로 고를 수 있다. 버튼 또는 `E`로 발동한다. 전투 분석은 카드 수와 스킬 횟수·소모 비용을 분리한다.

바로 체험하려면 외부 좌측 **밀집보병 체험**을 누른다. 새 추천 덱 **방패의 진군**, 시작 엘릭서 10, 밀집보병 자동 선택으로 자유 연습을 시작한다. 개인 저장 덱은 바꾸지 않는다. 전체 카드 수는 19종, 추천 덱은 4종이며 기존 상대 3명의 기본 덱은 유지했다.

분대 상세·피해 계산·공개 API는 [PHALANX.md](PHALANX.md)를 참고한다.

## 4. 저장과 호환성

전투 규칙 3과 snapshot·replay 형식 2를 유지한다. 기존 카드만 사용하는 덱의 상태 모양과 기존 명령을 보존하며, 밀집보병 덱에만 분대 상태를 추가한다. 규칙 2에서는 새 카드를 허용하지 않는다.

밀집보병 소환에는 생성 분대를 연결하는 `groupId`, 능력에는 `type:'ability'` 명령을 추가한다. 돌격·쿨다운·재집결·생존 멤버를 저장하고 동일하게 복원한다. 리플레이에서는 검증된 기록 명령만 재생하고 관전자 스킬 입력을 차단한다. 훈련에는 별도 모드 계약으로 능력을 차단한다. 기존 일반 대전·도전·훈련·연습의 전적 반영 경계는 유지한다.

최종 소스에서 `node --test --test-reporter=tap tests/*.test.mjs`를 실행하여 **159개 통과, 실패 0, 건너뜀 0**을 확인했다.

| 검사 | 확인한 결과 |
|---|---|
| 전체 자동 회귀 | 159개 통과. 전투·AI·도전·전적·훈련·치트·저장·재생·렌더러 포함 |
| 새 분대 회귀 | 16개. 실제 대형·배치·다리·우회·보호·스킬·재집결·사상자·모드 차단·저장·리플레이·AI |
| 전체 경기 표본 | 기존 3상대 × 3난이도 × 2 seed = 18경기 완주. 기본 배치 전투의 수치·비용·진행·이동·종료·대표 리플레이 확인; AI 능력 사용은 별도 분대 검사 |
| 정체 결함 재현 | 후열에 막힌 병사의 슬롯 교환 회귀 추가. 수정 후 18경기 최대 관찰 정체 2초 |
| 3D·새 카드 표시 | 3D 검사 8개와 밀집보병 2D 검사 1개. 카메라·메시·모델 선택·상태 불변·자원 정리 |
| 렌더러 전환 | 3개. 투명 HUD 최초 생성, 방향·전투 유지, 지원 실패·draw 실패·context loss 시 2D 복구 |
| 기존 규칙 보존 | 기존 덱에 같은 입력을 적용한 1,800틱의 규칙 2·3 전체 snapshot 해시가 이전 소스와 일치 |
| 정적 UI 구조 | 실제 HTML의 7개 방향 이동 노드를 8회 왕복하여 부모·형제 복원. 설정 외부 배치·우측 NEXT·좌측 HUD·스킬 계층 확인 |
| 입력 연결 | 새 병사 선택 직후 다음 HUD 갱신을 기다리지 않고 올바른 분대 스킬 발동 |
| 문법·바인딩 | JavaScript 구문, HTML ID 중복·연결, 필수 파일 검사 통과 |

WebGL 검사는 호출 기록기와 독립적인 수학 계산을 사용한다. 실제 GPU 렌더 결과나 장치별 FPS 측정은 아니다. 밀집보병의 방진·돌격·재집결·배치 대기는 별도 Canvas 2D 이미지로 확인했다. 브라우저 접근 제한으로 이번 버전의 실제 페이지 클릭·터치·포커스·모바일 다운로드 및 GPU 시각 품질은 직접 검증하지 못했다. 정적 DOM·CSS 검사와 자동 회귀는 이 실기 검증을 대신하지 않는다.
