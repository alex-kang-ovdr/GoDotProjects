## 플레이 흐름 추가

- 전술 훈련 3개: 중앙 유인, 화살비 대공, 거인·궁수 지원.
- 목표 위치, 진행 체크리스트, 제한 시간, 성공·실패·같은 조건 재시도.
- 훈련 중 저장·복원과 훈련 완료 기록.
- 키보드 조준: 1~4 → 방향키 → Enter, Shift로 미세 조정.
- 엘릭서 부족 카드의 예상 대기 시간과 상한 안내.
- 카드별 사용·소비량, 레인 분포, 자연 생성 손실을 계산하는 전투 분석.
- 리플레이 JSON 파일 저장·불러오기. 일반 전적과 기존 최근 기록을 덮어쓰지 않고 재생.

18경기는 상대 3종 × 난이도 3종 × seed 2개로 구성했습니다. 양쪽 제어기가 상대 손패·엘릭서에 접근하면 즉시 실패하도록 막았고, 모든 배치에서 정상 비용과 성공 여부를 확인했습니다. 관찰한 경기 시간은 120.32~270.72초, 사거리 밖에서의 연속 무이동 최댓값은 3초였습니다. NaN·불법 배치·자원 범위 오류·예외는 없었습니다.

이 표본은 모든 덱 조합에 대한 밸런스 인증이 아닙니다. 작은 seed 표본에서 난이도별 승률이 순서대로 증가하지 않았으므로, 난이도의 차이는 별도 고정 상황의 반응·선택 테스트로 설명합니다.

## 호환성과 전달물

- 신규 전투 규칙 3, 기존 기록의 누락된 rulesVersion은 2.
- 저장·리플레이 형식 버전 2, AI snapshot 형식 버전 2 유지.
- 규칙 2의 수정 전 두 경기 스냅샷 SHA-256 일치.
- `dist/crownfall-offline.html`: 외부 의존성 없이 파일 하나로 실행.
- `dist/source.zip`: 모듈 소스·스크립트·테스트·문서 포함.
- 현재 온라인 주소와 공개 범위 유지.

## 확인하지 못한 부분

브라우저 접근 정책 차단이 이어져 이번 버전의 전체 UI를 클릭하며 확인하지 않았습니다. 정적 DOM 연결과 번들 문법, 순수 시뮬레이션, 독립 Canvas 렌더 출력은 확인했습니다. 실제 모바일의 터치·오디오·파일 저장과 전체 UI 흐름은 추가 검증이 필요합니다.
