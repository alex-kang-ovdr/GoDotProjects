# 07. 카드 체계와 덱 구성

> 조사 기준: 2026-11-13. 표준 개인 덱 기반 전투를 대상으로 한다. Draft·Merge Tactics·시즌 특수 모드의 덱 규칙은 별도다. **[확인]**은 공식 자료, **[분석]**은 규칙에서 도출한 설계 해석, **[재현 설계]**는 동작을 구현하기 위한 제안이다. 실제 서버 코드나 추천 알고리즘을 분석한 문서가 아니다.

## 1. 시스템의 역할

**[분석]** 덱은 전투 시작 전에 플레이어가 설정하는 전략적 제약이다. 전투 중 모든 대응을 자유롭게 선택하지 못하게 하고, 선택한 카드 집합·손패 순환·엘릭서 예산 안에서 해결하게 만든다. 따라서 카드의 단독 성능보다 **8개 선택이 만드는 대응 범위와 빈틈**이 중요하다.

**[확인]** 표준 덱은 8개 전투 카드와 별도 타워 유닛 선택으로 구성된다. 타워 유닛은 8칸을 소비하지 않는다. 덱 빌더가 있는 모드에서는 모드당 최대 10개 덱을 저장할 수 있고, 친선전·비공개 토너먼트는 트로피 진척도 덱을 사용한다. [E01](https://support.clashroyale.com/hc/en-us/articles/49484924205595-Cards-Decks), [E06](https://support.supercell.com/clash-royale/en/articles/tower-troops-4.html)

## 2. 카드 분류의 서로 다른 축

**[확인]** 희귀도는 일반·희귀·영웅·전설·챔피언의 다섯 종류다. 여기서 한국어 희귀도 **영웅(Epic)**과 **히어로 형태(Hero)**는 다른 개념이다. 진화와 히어로는 희귀도 증가가 아니라 카드에 적용하는 별도 형태다. [E01](https://support.clashroyale.com/hc/en-us/articles/49484924205595-Cards-Decks), [E04](https://support.clashroyale.com/hc/en-us/articles/49484957323163-Heroes)

**[분석]** 기획 데이터에서는 다음 축을 독립시켜야 한다.

| 분류 축 | 대표 값 | 결정하는 사항 | 혼동하면 생기는 오류 |
| --- | --- | --- | --- |
| 전장에 만드는 결과 | 유닛·건물·주문 | 생성물, 배치 방식, 생존 시간 | 주문을 체력 있는 개체와 동일하게 처리 |
| 수집 희귀도 | 일반~챔피언 | 수집·업그레이드 자원 | 고희귀도를 무조건 상위 호환으로 평가 |
| 전투 역할 | 승리 수단·탱커·대공·광역·제어 | 덱의 대응 범위 | 희귀도만 보고 덱 완성도 판단 |
| 카드 형태 | 기본·진화·히어로 | 특수 효과의 활성화 | 진화와 히어로를 한 배치에 무조건 중첩 |
| 배치 정책 | 아군 영역·지정 타깃·특수 위치 | 입력 유효성 | 모든 카드에 같은 배치 마스크 적용 |
| 비용 정책 | 고정·상태 의존 | 엘릭서 지출과 평균 표시 | 동적 비용을 고정 평균으로 오해 |
| 모드 적합성 | 보유 덱·대여 덱·선택형 덱 | 이용 가능 카드 | 컬렉션 해금과 대회 사용 자격 혼동 |

같은 카드가 여러 역할을 수행할 수 있다. 예를 들어 대공과 광역 방어를 함께 담당하는 카드가 있다면, 그 카드가 손패에 없을 때 두 취약점이 동시에 드러난다. 태그를 단순 합산할 때 이러한 **역할 집중도**도 확인해야 한다.

## 3. 덱의 구조적 완성도

**[분석]** 다음 항목은 공식 게임이 강제하는 슬롯 규칙이 아니라 덱을 설명·평가하는 분석 도구다. 반드시 각 역할에 한 장씩 넣어야 한다는 뜻은 아니다.

| 검토 항목 | 덱에서 답해야 하는 질문 | 빠졌을 때의 전형적인 문제 |
| --- | --- | --- |
| 지속 가능한 타워 피해 수단 | 어떤 상태를 만들면 타워에 피해를 줄 수 있는가? | 방어에는 성공하지만 승리로 전환하지 못함 |
| 고체력 대상 처리 | 큰 단일 대상에 충분한 피해를 줄 수 있는가? | 방어 카드 여러 장을 중복 지출 |
| 다수 대상 처리 | 저체력 다수 유닛을 적은 비용으로 정리하는가? | 큰 공격이 작은 방어에 멈춤 |
| 공중 대응 | 공격 가능한 대상과 사거리의 공백이 없는가? | 특정 공중 조합을 상대할 수 없음 |
| 즉시 개입 수단 | 상대 배치 직후나 공격 직전에 대응하는가? | 느린 유닛만 있어 피해를 방치 |
| 위치 조작·유도 | 적을 중앙 또는 타워 사거리로 끌어오는가? | 수치상 강한 방어도 위치 때문에 손해 |
| 순환용 카드 | 주력 카드로 돌아오는 비용이 감당되는가? | 주력 대응 카드가 한 번 빠지면 장기간 취약 |
| 후속 전환 | 살아남은 방어 병력을 공격에 이용하는가? | 매번 처음부터 공격 비용을 지불 |

### 3.1 승리 수단을 기준으로 한 분석형 분류

| 유형 | 주된 승리 구조 | 필요한 조력 | 구조적 위험 |
| --- | --- | --- | --- |
| 누적 공격형 | 큰 전열과 지원을 묶어 한 번의 큰 공격 형성 | 후방 누적·지원 보호·상대 반대편 대응 | 초기 투자 중 반대쪽 압박 |
| 빠른 순환형 | 상대 핵심 대응이 돌아오기 전에 주력 재사용 | 저비용 방어·엘릭서 관리 | 작은 배치 실수가 누적되기 쉬움 |
| 역공형 | 방어에 쓴 생존 병력을 공격 자산으로 전환 | 효율적인 유도·생존 관리 | 상대가 먼저 공격하지 않을 때 주도권 문제 |
| 주문 유도형 | 같은 대응 주문을 요구하는 위협을 반복 제시 | 여러 위협의 시차 배치 | 상대가 대응 수단을 여럿 보유하면 약화 |
| 공성형 | 강 건너 접근 대신 원거리 구조물을 활용 | 설치 공간 확보·주변 수비 | 핵심 설치를 막히면 공격 계획 지연 |
| 분산 압박형 | 두 경로에 동시에 비용 지출을 강요 | 분할 배치·상대 잔여 자원 추정 | 양쪽 모두 애매하게 투자할 위험 |

이는 현재 최상위 메타 덱 순위가 아니다. 같은 카드도 조합과 플레이 방식에 따라 여러 분류에 속한다.

## 4. 평균 엘릭서와 실질 회전 비용

**[재현 설계]** 고정 비용 카드만 포함한 덱의 표시용 평균은 다음처럼 계산할 수 있다.

```text
AverageElixir = Sum(BaseCost(card[i]), i=0..7) / 8
ReturnCost(keyCard, handState) = 핵심 카드가 다시 손패에 올 때까지 실제 선택한 카드 비용 합
```

평균은 덱을 빠르게 비교하는 요약값이다. 실제 회전 비용은 현재 손패·카드 순서·방어에 반드시 써야 하는 카드에 따라 변한다. 히어로·챔피언 능력 비용은 추가 행동 예산이므로, 카드 배치 비용의 단순 평균만으로 전투 지출을 예측하면 안 된다.

**가상 계산 예시:** 카드 비용이 `[4, 4, 3, 3, 2, 2, 1, 1]`인 덱의 평균은 `20 / 8 = 2.5`다. 핵심 카드 이후 실제로 `1→1→2→2`를 사용하면 재순환 비용은 6이지만, 방어 때문에 `4→3→2→1`을 사용했다면 10이다. 평균은 같아도 의사결정에 따른 회전 속도는 달라진다.

**[분석]** 저비용 카드를 추가하면 순환이 빨라지지만, 저비용 카드가 수행할 수 없는 방어를 다른 카드에 집중시키게 된다. 따라서 최적화 목표는 “평균 최소화”가 아니라 “취약한 순간을 버틸 수 있는 회전 구조”다.

## 5. 특별 슬롯을 포함한 덱 검증

**[확인]** 2026-03-16 개편에서 특수 슬롯은 진화 1칸, 히어로 1칸, 와일드 1칸으로 정리됐다. 와일드 슬롯은 진화·히어로·챔피언 중 적합한 항목을 사용하며, 한 카드의 진화와 히어로 형태를 전환할 수 있다. 상세 허용 조합은 [08 문서](08_evolutions_champions_heroes_towers.md)에 수록한다. [E08](https://supercell.com/en/games/clashroyale/blog/news/mid-march-update/)

**[재현 설계]** 덱 저장과 출전 가능성을 분리하면 불완전한 덱을 편집 중 저장할 수 있으면서도 잘못된 덱의 매칭을 막을 수 있다.

```text
ValidateDeck(deck, profile, modeRules):
  카드 개수와 중복 정책 검사
  모드의 보유/대여/밴 목록 검사
  각 카드의 선택 형태와 해금 상태 검사
  슬롯별 허용 형태 및 슬롯 해금 검사
  타워 유닛 선택과 모드 허용 목록 검사
  유효 레벨 계산
  오류 목록과 수정 가능한 경고 반환
```

| 실패 상황 | 저장 시 처리 제안 | 출전 시 처리 제안 |
| --- | --- | --- |
| 카드가 7장뿐임 | 편집 상태 보존 | 남은 한 칸 강조 |
| 보유하지 않은 카드의 공유 덱 붙여넣기 | 후보 덱으로 보존 | 대체 후보 제시 |
| 진화를 일반 슬롯에 배치 | 기본형으로 표시 | 특수 효과 비활성 경고 |
| 해금 전 히어로 보상은 소유함 | 소유와 사용 자격 분리 표시 | 해금 조건 설명 |
| 시즌 밴 카드 포함 | 덱 기록 유지 | 해당 모드 출전 차단 |
| 모드 변경으로 레벨 제한 발생 | 원래 레벨 보존 | 유효 레벨을 별도 표시 |

## 6. 덱 편집 UX의 역기획

**[분석]** 덱 편집 화면의 핵심 과제는 수집량이 커져도 “넣을 카드 찾기 → 현재 전략과 비교 → 교체 결과 확인”을 짧게 유지하는 것이다. 전투 성능 수치만 보이는 카드 목록보다 역할·타깃·비용을 함께 비교할 수 있는 구조가 유용하다.

**[재현 설계]** 추천 화면 흐름:

1. 모드와 현재 덱을 먼저 표시한다. 다른 모드의 덱을 수정하는 실수를 방지한다.
2. 선택한 칸의 허용 형태를 강조한다. 특수 슬롯 효과가 적용되는지 즉시 보인다.
3. 컬렉션에서 비용·타입·레벨·역할·해금 상태로 좁힌다.
4. 교체 전후 평균 비용과 핵심 대응 범위의 변화를 보여 준다.
5. 카드 상세에서 기본형/선택형태/모드 유효 레벨을 명확히 구분한다.
6. 연습·친선전 진입을 연결해 덱을 저장한 뒤 바로 검증할 수 있게 한다.

### 6.1 2026년 11월 Deck Wizard

**[확인]** 2026-10-27 공지는 Deck Wizard가 빈 덱 또는 좋아하는 카드를 중심으로 덱을 추천하고, 듀얼 덱에서는 다른 덱이 사용 중인 카드를 피하도록 설명한다. 11월 시즌 2주차부터 테스트 방식으로 배포되어 모든 계정에서 동시에 보인다고 단정할 수 없다. 내부 추천 모델·학습 데이터·평가 목적함수는 공개되지 않았다. [E24](https://supercell.com/en/games/clashroyale/blog/release-notes/new-season-king-vs-king/)

**[재현 설계]** 유사 기능을 만들 때는 “고승률 덱 추천”과 “현재 컬렉션에서 즉시 사용 가능한 덱 추천”을 다른 목표로 취급한다. 높은 레벨·특수 형태 보유·조작 난도·모드 금지 조건을 함께 입력하고, 추천 이유를 “대공 대응 보완”, “고비용 카드 수 감소”처럼 검토 가능한 설명으로 제공한다. 실제 Deck Wizard가 이러한 방식이라는 의미는 아니다.

## 7. 데이터 모델 제안

| 데이터 | 핵심 필드 | 저장 원칙 |
| --- | --- | --- |
| `CardDefinition` | `cardId`, 타입, 희귀도, 기본 비용, 역할 태그 | 밸런스 버전으로 관리 |
| `CardFormDefinition` | `formId`, 원본 카드, 발동 규칙, 필요 슬롯 | 기본 카드와 형태의 소유를 분리 |
| `PlayerCard` | 해금 여부, 레벨, 복제 카드 수, 소유 형태 | 계정 영속 데이터 |
| `DeckPreset` | 모드, 이름, 8개 카드·선택 형태, 타워 유닛 | 모드별 네임스페이스 |
| `ModeDeckRule` | 허용 풀, 밴, 레벨 정책, 슬롯 정책 | 이벤트 단위로 교체 가능 |
| `RecommendationRequest` | 고정 카드, 제외 카드, 보유 조건 | 민감정보 없이 규칙 입력 중심 |
| `DeckSnapshot` | 확정 카드·레벨·형태·규칙 버전 | 매치 시작 시 고정 |

**[재현 설계]** 덱 링크에는 레벨이나 계정 소유권을 직접 복제하지 않는다. 구성 의도만 전달한 뒤 수신자의 컬렉션과 모드 조건으로 다시 해석한다. `cardId`가 존재해도 해당 시즌에 사용 가능한지는 별도 검사한다.

## 8. 밸런스 분석 관점

**[분석]** 카드 사용률만으로 덱 다양성을 판단하면 같은 핵심 조합에서 한두 카드만 바뀌는 상황을 놓친다. 카드 쌍의 공동 사용률, 승리 수단 분포, 타워 유닛 조합, 선택 형태의 편중을 함께 보아야 한다.

덱 성능은 실력·레벨·모드·상대 조합의 영향을 받는다. 특정 카드의 전체 승률이 높다는 사실만으로 그 카드 자체가 강하다고 결론 내리지 않는다. 숙련자가 주로 사용하는 카드인지, 동일 레벨 전투에서도 우위가 유지되는지 분리해서 확인해야 한다.

## 9. 검증 시나리오
