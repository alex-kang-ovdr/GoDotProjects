# 장비 지급과 실제 능력 변화

## 목적과 소유권

물품으로 제작·거래한 장비를 주민에게 지급해 실제 전투와 생산에 반영한다. 장착은 버튼을 누르는 즉시 능력치를 올리는 방식이 아니라, 주민이 창고에 가서 제품 한 개를 받고 착용하는 작업이다.

각 주민은 다음 슬롯을 가진다.

```js
colonist.equipment = {
  weapon: null, // 또는 'rifle'
  armor: null,  // 또는 'armor'
  tool: null    // 또는 'tool'
};
```

기본 권총과 맨손 작업은 시작 능력이다. 판매하거나 바닥에 떨어뜨리는 기본 장비 물품은 없다. 새 제품만 창고·바닥·운반·장착 사이에서 소유권이 이동한다.

## 지급과 해제

```js
game.command('equip', { id: colonist.id, item: 'rifle' });
game.command('unequip', { id: colonist.id, slot: 'weapon' });
```

살아 있고, 일어선 상태이며, 다른 주민에게 운반되지 않고, 징집이 해제된 주민에게 명령할 수 있다. 창고에 실제 재고가 있고 접근할 수 있어야 한다. 바닥에 남은 제품은 먼저 창고로 운반해야 한다.

장착 명령은 창고로 이동하는 작업을 배정한다. 수령할 때 재고를 다시 확인해 한 개만 차감한다. 이후 1.5초 동안 장착하면 운반물에서 해당 슬롯으로 옮긴다. 두 주민이 마지막 제품을 요청해도 복제되지 않는다. 도중에 중단하면 수령한 제품을 현 위치에 내려놓는다.

해제는 장비를 슬롯에서 빼서 주민의 발밑에 놓는다. 운반 담당이 다시 창고로 입고할 수 있다. 사망한 주민의 장비도 한 번만 바닥에 떨어지고 슬롯은 비워진다. 쓰러졌지만 살아 있는 주민은 장비를 계속 소유한다.

같은 장비를 반복해서 지급하거나 저장을 반복 복원해도 효과가 누적되지 않는다. 계산 때 슬롯을 조회해 배율을 한 번 적용한다.

## 효과

| 장비 | 실제 적용 | 적용하지 않는 영역 |
| --- | --- | --- |
| 개량 소총 | 징집 사거리 7.5→9칸, 피해 ×1.35, 명중률 +4%p, 징집 사격 간격 1.35→1.2초 | 민간인 자동 방어의 탐지 반경은 기존 값 유지 |
| 방탄 조끼 | 총탄 피해 ×0.65, 총상으로 추가되는 출혈량 ×0.65 | 화재, 굶주림, 온도, 이미 발생한 출혈 |
| 작업 도구 | 건설·수리·농사·채집·채광·제작 진행량 ×1.25 | 이동, 운반 속도, 조리, 연구, 치료, 휴식·여가 |

소총을 들고 있는 비징집 주민이 자동 방어할 때도 소총의 피해와 명중 보정은 사용한다. 민간인 방어의 기존 피해 감소 계수와 탐지 반경은 유지한다. 벽에 가려진 적에게 사격하려면 기존 경로·시야 규칙에 따라 접근해야 한다.

조끼는 엄폐와 별개다. 엄폐는 공격이 맞을 가능성에, 조끼는 맞은 뒤 피해와 출혈 증가량에 영향을 준다. 이미 쓰러진 주민에게도 소유 중인 조끼는 총탄 피해에 적용된다.

## 화면과 운영

주민을 선택하면 **장비와 도구** 목록이 나타난다. 현재 장착품, 창고 재고, 장착·해제 버튼과 진행 상태를 표시한다. 징집 중이면 먼저 해제해야 지급할 수 있다. 제작 탭 아래의 주민 목록에서도 해당 주민 선택 화면으로 이동한다.

방어 인원에게 소총·조끼를 먼저 줄지, 제작·건설 담당에게 도구를 먼저 줄지는 물자와 노동 시간의 선택이다. 물품을 팔면 은화를 얻지만 정착지의 장비 보유량은 줄어든다. 보유량 유지 주문이 켜져 있으면 부족분을 다시 제작한다.

## 범위와 검증 경계

품질, 개인별 내구도, 탄약, 여러 무기 종류, 의복 슬롯은 구현하지 않는다. 같은 종류의 장비 한 개는 같은 성능이다. 사거리·명중·피해·작업 시간 효과, 마지막 재고 경합, 장착 중단, 해제·사망 반환과 중간 저장의 소유권 보존을 테스트한다.
