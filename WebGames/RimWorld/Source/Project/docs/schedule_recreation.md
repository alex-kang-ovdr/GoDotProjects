# 일정·여가·기분 — v3 구현 명세

## 플레이 목적

정착민의 시간을 생산, 수면, 여가에 나누고 생활 부족이 기분에 미치는 영향을 보여 준다. 일정은 매일 반복되며 기존 작업 우선순위와 함께 사용한다.

## 24시간 일정

게임의 하루는 120 시뮬레이션 초다. 따라서 일정의 한 시간칸은 5 시뮬레이션 초에 해당한다. 처음 시작 시각은 08:00이다.

| 모드 | 기본 행동 |
| --- | --- |
| `anything` · 자율 | 필요와 작업 우선순위에 따라 선택. 기존 야간 수면 판단도 유지한다. |
| `work` · 작업 | 업무를 우선 수행하되 긴급한 식사·휴식과 위기 대응은 허용한다. |
| `sleep` · 수면 | 휴식이 필요하면 침대로 간다. 충분히 쉰 뒤에는 여유 시간을 사용한다. |
| `recreation` · 여가 | 여가가 부족하면 시설이나 조용한 휴식으로 채운다. |

| 프리셋 | 수면 | 작업 | 여가 | 나머지 |
| --- | --- | --- | --- | --- |
| 균형 생활 `balanced` | 22:00–06:00 | 08:00–18:00 | 18:00–20:00 | 자율 |
| 야간 작업 `night` | 10:00–18:00 | 20:00–06:00 | 06:00–08:00 | 자율 |
| 자율 생활 `free` | 별도 고정 없음 | 별도 고정 없음 | 별도 고정 없음 | 모든 시간 자율 |

새 게임은 균형 생활로 시작한다. v1·v2 저장을 불러온 주민은 자율 생활을 적용해 기존 생활 패턴의 급격한 변경을 피한다.

```js
game.command('schedule', {id:pawnId, hour:18, mode:'recreation'});
game.command('schedulePreset', {id:pawnId, preset:'night'});
```

`hour`는 0–23의 정수, `mode`는 정해진 네 모드 중 하나다. 잘못된 요청은 거절한다. 완료한 연구나 물자에 영향을 주지 않는다.

## 일정보다 먼저 처리하는 것

즉각적인 위협과 쓰러짐, 심각한 허기·피로, 구조·응급 치료·급식·소방은 일정을 따르기 전에 처리한다. 징집은 플레이어의 전투 지휘를 따른다.

이미 식사하거나 수면 중이더라도 포만감 25 이상·에너지 12 이상이면 긴급한 구조·소방을 위해 중단할 수 있다. 그보다 심각한 욕구는 먼저 회복하며, 도중에 내려놓은 음식은 신선도와 수량을 보존한다.

시간대가 바뀌면 일반 작업을 다시 판단한다. 중단한 운반 물자는 내려놓고 예약을 정리한다. 응급 작업이나 직접 지시한 우선 작업을 단순히 시간이 바뀌었다는 이유로 끊지 않는다.

작업 시간 설정은 해당 작업의 우선순위를 켜 주지 않는다. 예를 들어 연구 작업이 비활성이라면 작업 시간에도 연구하지 않는다. **작업 탭은 어떤 일을 할지, 일정 탭은 언제 일하고 쉴지를 정한다.**

## 여가 시설

| 건물 | 재료 | 기준 건설 작업량 | 내구도 |
| --- | --- | ---: | ---: |
| 고리 던지기 `horseshoes` | 목재 12 · 강철 4 | 6 | 80 |

주민은 접근 가능한 완성 시설로 이동한 뒤 실제 시간을 보내야 한다. 한 시설은 작업 예약을 사용한다. 불타는 시설이나 접근할 수 없는 시설에서는 여가를 채우지 못한다. 시설이 없으면 주변에서 산책·조용한 휴식을 하며 더 느리게 회복한다.

여가는 평소 초당 0.12 감소한다. 시설에서 여가를 채우는 기본 속도는 초당 3, 조용한 휴식은 초당 0.8이다. 온도 스트레스에 따른 쾌적도 영향을 받는다. 여가 행동 중 휴식 에너지도 조금 회복한다. 만족한 뒤에는 다른 일로 돌아간다.

## 기분과 근거 표시

`game.getMoodFactors(pawnOrId)`는 실제 기분 계산에 사용하는 항목들을 `[{id,label,value}]` 형식으로 반환한다. 화면이 별도의 추정식을 사용하지 않는다.

| 요인 | 기분 목표에 적용하는 값 |
| --- | --- |
| 기본 안정감 | +76 |
| 부상·통증 | 건강 부족분 × −0.28 |
| 허기 | 포만감 35 미만 부족분 × −0.8 |
| 피로 | 에너지 30 미만 부족분 × −0.55 |
| 휴식 중 / 환자 침상 | +5 |
| 실내 | +4 |
| 불편한 온도 | 온도 스트레스 × −0.18 |
| 여가 부족 | 여가 30 미만 부족분 × −0.35 |

합산 기분 목표는 5–92 범위로 제한한다. 실제 기분은 목표로 점진적으로 변한다. 일정과 여가를 정하는 것은 허기·통증·온도 문제를 해결하는 것과 함께 사용해야 한다.

## UI와 저장

- 일정 탭에서 주민 → 활동 → 시간칸 순서로 편집한다.
- 현재 시간은 밝은 테두리로 표시하고 각 모드는 색상과 텍스트로 구분한다.
- 프리셋은 선택 주민의 하루 전체를 바꾼다.
- `L`로 일정, `C`로 의료·소방, `J`로 연구를 연다.
- 주민별 24개 모드, 여가 수치, 마지막 일정 판단 시간은 저장한다.
- 모드가 잘못되었거나 24칸이 아닌 v3 저장은 거절한다.

인물 관계, 개별 성격, 종교·이념, 다양한 오락 만족도와 사회적 기억은 현재 구현하지 않는다.
