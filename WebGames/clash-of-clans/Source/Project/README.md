# Clan Haven v14 — 오프라인 싱글플레이 전략 게임

`index.html`을 Chrome/Edge에서 열면 서버나 외부 라이브러리 없이 실행됩니다.

## 게임 진행
마을 건설 → 자원 생산 → 병력 편성·연구 → 12개 AI 캠페인 → 전리품·별 → 성장. 전투 중 동·서·남·북 분산 투입, 마법·영웅 능력, 1~4배속, 일시정지, 경로 시각화, 리플레이를 사용할 수 있습니다. 브라우저 로컬 저장과 JSON 가져오기/내보내기를 지원합니다.

## v14 변경
- **AI 이동 최적화:** 타깃이 바뀌지 않은 유닛은 기존 경로를 보존하여 불필요한 A* 재탐색 감소
- **막힌 경로 재시도 제한:** 유효 경로가 없을 때 탐색 간격을 두어 계산량 폭주 방지
- **후반 캠페인 밸런스:** 적 건물 HP 및 방어시설 피해 증가율 조정
- **정찰 정보:** 적 방어시설·성벽·함정 수를 원정 전에 표시
- **결과 화면:** 종료 후 같은 기지 즉시 재도전

## 검증
- `node test_core.js`: 기본 전투 및 리플레이 동일성 검사 10개
- `node test_campaign.js`: 최대 회관 및 충분한 훈련소를 가정한 편성으로 12개 캠페인 자동 전투. 전투가 종료되는지, 별·파괴율·소요시간 기록
- 자동화 Chromium의 로컬 파일/localhost 접근은 실행 환경에서 차단되어 실제 브라우저 UI 테스트는 미완료

## 주의
클래시 오브 클랜의 실제 수치·내부 AI·아트를 복제한 게임이 아니라 역기획을 바탕으로 한 독립 프로토타입입니다. 테스트 편성은 후반 성장 상태를 가정하므로 초반 기지로 모든 스테이지를 클리어할 수 있다는 의미는 아닙니다.
