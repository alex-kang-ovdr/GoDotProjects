# 원작 재현 구현 계획

## 단계 1: 결정론적 시뮬레이션 코어
- `GameState`, `Ruleset`, `Scenario`, `Command`, `Event`, `RandomSource` 분리
- 턴 진행, 헥스 맵, 도시 자원, 부대 생성·이동
- 명령 실행 전 검증과 이벤트 로그

## 단계 2: 전투/전법/계략
- 병과·전법·특기 데이터 기반 실행
- 원작 피해/성공 공식은 실측 전까지 교체 가능한 인터페이스로 보존
- 1000회 반복 Monte Carlo 검증과 고정 시드 회귀 테스트

## 단계 3: 내정/인사/외교/기교
- 시설 건설 및 PK 합병
- 인재·외교·연구 상태 머신

## 단계 4: AI와 시나리오
- 관찰 로그 기반 우선순위 조정
- 시나리오 초기 데이터 입력 및 무결성 검사

## 단계 5: 웹 UI
- Canvas/WebGL 헥스 렌더링, 카메라, 부대 명령, 상태 패널
- 게임 규칙은 UI에 종속되지 않는 순수 TypeScript 모듈 권장

## 완료 정의
- 동일 초기 상태·입력·시드에 대해 결과 재현 가능
- 검증 완료 항목의 원작 결과와 일치
- 미확정 공식은 추정 구현으로 명시
