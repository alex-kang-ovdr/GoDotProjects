# 부대 편성·출진·보급

> **원작 일치도 표기:** `확인`=원작 UI/공식 자료로 검증, `참고`=공략 자료 기반, `가설`=재구현 제안, `미확정`=실측 필요. 이 문서는 비공식 역기획이며 코에이테크모의 내부 명세가 아닙니다.

## 편성
주장 1명, 부장 최대 2명, 병종·병력·병장·군량·기력을 설정한다. 각 병과는 해당 장비 보유량과 연동된다.
## 상태
`Unit {id,forceId,leaderId,deputyIds,type,troops,food,energy,position,actionDone,statuses}`.
## 출진
출진 시 도시 병력·병장·군량을 차감하고 부대를 생성한다. 출진 가능 최소·최대 수치와 초기 기력은 원작 실측 대상.
## 보급
군량 소모, 부대 합류·귀환·괴멸 및 도시에 들어갈 때 자원 이전 규칙을 분리한다.

## 구현 인터페이스 공통 요구
- 모든 명령은 실행 가능 여부·소모 자원·상태 변경·이벤트 로그를 반환한다.
- 시나리오와 규칙 데이터를 로직에서 분리한다.
- 재현 실험에는 버전, 난이도, 시나리오, 날짜, 입력 상태, 결과 스크린샷을 첨부한다.
