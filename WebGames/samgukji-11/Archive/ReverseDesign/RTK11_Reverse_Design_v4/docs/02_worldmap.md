# 월드맵과 헥스 좌표

> **원작 일치도 표기:** `확인`=원작 UI/공식 자료로 검증, `참고`=공략 자료 기반, `가설`=재구현 제안, `미확정`=실측 필요. 이 문서는 비공식 역기획이며 코에이테크모의 내부 명세가 아닙니다.

## 지도 구성
전략과 전투는 하나의 헥스 맵에서 진행한다. 각 칸은 지형, 고도, 개발 가능 여부, 건물, 부대, 소유 영향권, 화재 등의 상태를 갖는다.
## 데이터 구조
`Hex {q,r,terrain,height,regionId,developmentCityId,structureId,unitId,fireState}`. axial 좌표는 **구현 제안**이며 원작 내부 좌표 방식이라고 단정하지 않는다.
## 인접 좌표
axial 이웃: `(1,0),(1,-1),(0,-1),(-1,0),(-1,1),(0,1)`.
거리: `(abs(dq)+abs(dr)+abs(dq+dr))/2`.
## 길찾기
지형·병과·연구·시설 통과 가능 여부로 간선 비용을 구성하고, 적 부대 점유 및 이동 제한을 별도로 평가한다. 헥스 거리 기반 A*는 재현 구현 제안이다.
## 검증
지형별 이동 가능 범위, 숲·습지·잔도에서의 병종별 제한, 강 도하, 도시 및 관문 주변 이동, 적 부대 주변 통과.

## 구현 인터페이스 공통 요구
- 모든 명령은 실행 가능 여부·소모 자원·상태 변경·이벤트 로그를 반환한다.
- 시나리오와 규칙 데이터를 로직에서 분리한다.
- 재현 실험에는 버전, 난이도, 시나리오, 날짜, 입력 상태, 결과 스크린샷을 첨부한다.
