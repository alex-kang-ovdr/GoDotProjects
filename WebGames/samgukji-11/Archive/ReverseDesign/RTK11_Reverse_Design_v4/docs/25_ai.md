# AI 계층·평가·행동

> **원작 일치도 표기:** `확인`=원작 UI/공식 자료로 검증, `참고`=공략 자료 기반, `가설`=재구현 제안, `미확정`=실측 필요. 이 문서는 비공식 역기획이며 코에이테크모의 내부 명세가 아닙니다.

## 계층
전략 AI(목표 거점/전선) → 도시 AI(내정/병력/수송) → 전술 AI(이동/공격/전법/계략).
## 후보 평가(재구현 제안)
`score = objectiveValue + threatReduction + expectedDamage - resourceCost - exposureRisk`.
**이 식은 원작 AI 수식이 아니다.** 실제 AI 행동을 관찰해 가중치와 규칙을 역추정한다.
## 관찰 로그
시나리오, 난이도, 세력, 턴, AP, 도시 자원, 후보 명령, 실제 선택, 목표 위치, 결과를 기록한다.
## 회귀 테스트
빈 도시 공격, 수송 우선순위, 약한 부대 추격, 불리한 공성, 기력 부족 시 계략, 방어 시설 건설.

## 구현 인터페이스 공통 요구
- 모든 명령은 실행 가능 여부·소모 자원·상태 변경·이벤트 로그를 반환한다.
- 시나리오와 규칙 데이터를 로직에서 분리한다.
- 재현 실험에는 버전, 난이도, 시나리오, 날짜, 입력 상태, 결과 스크린샷을 첨부한다.
