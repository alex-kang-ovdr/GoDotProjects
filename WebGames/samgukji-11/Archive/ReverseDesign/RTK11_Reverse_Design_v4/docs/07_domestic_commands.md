# 내정 명령

> **원작 일치도 표기:** `확인`=원작 UI/공식 자료로 검증, `참고`=공략 자료 기반, `가설`=재구현 제안, `미확정`=실측 필요. 이 문서는 비공식 역기획이며 코에이테크모의 내부 명세가 아닙니다.

## 명령 종류
순찰, 징병, 훈련, 병장 생산, 거래, 수송, 개발 등은 실행 가능 거점과 담당 무장, AP/금 등의 비용이 다르다.
## 명령 인터페이스
`canExecute(state,force,city,officers,parameters) -> {ok,reasons,cost}`
`execute(...) -> events[]`.
## 결과
치안, 병력, 사기/기력, 병장, 금·군량 등의 변화는 명령별로 분리한다.
## 테스트
무장 중복 배정, 금 부족, 생산 시설 미건설, 병력 상한, 치안 하락, 최적 담당 무장 변경.

## 구현 인터페이스 공통 요구
- 모든 명령은 실행 가능 여부·소모 자원·상태 변경·이벤트 로그를 반환한다.
- 시나리오와 규칙 데이터를 로직에서 분리한다.
- 재현 실험에는 버전, 난이도, 시나리오, 날짜, 입력 상태, 결과 스크린샷을 첨부한다.
