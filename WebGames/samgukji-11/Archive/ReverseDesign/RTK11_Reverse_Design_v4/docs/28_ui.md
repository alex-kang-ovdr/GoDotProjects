# UI·UX·카메라

> **원작 일치도 표기:** `확인`=원작 UI/공식 자료로 검증, `참고`=공략 자료 기반, `가설`=재구현 제안, `미확정`=실측 필요. 이 문서는 비공식 역기획이며 코에이테크모의 내부 명세가 아닙니다.

## 지도 조작
줌·회전·이동·헥스 선택·도시 선택·부대 선택·명령 컨텍스트를 구분한다.
## 주요 화면
시나리오/세력 선택, 도시 정보, 무장 목록, 내정 건설, 부대 편성, 전법 선택, 외교, 기교, 일기토, 설전.
## 표시 규칙
가능 명령 활성화, 비용/실패 사유, 이동 가능 헥스 강조, 전법 대상 범위, 경로 프리뷰, 상태이상 아이콘.
## 테스트
같은 헥스에서 부대/시설 선택 우선순위, 화면 회전 후 좌표 선택, 명령 취소, 키보드/마우스 입력.

## 구현 인터페이스 공통 요구
- 모든 명령은 실행 가능 여부·소모 자원·상태 변경·이벤트 로그를 반환한다.
- 시나리오와 규칙 데이터를 로직에서 분리한다.
- 재현 실험에는 버전, 난이도, 시나리오, 날짜, 입력 상태, 결과 스크린샷을 첨부한다.
