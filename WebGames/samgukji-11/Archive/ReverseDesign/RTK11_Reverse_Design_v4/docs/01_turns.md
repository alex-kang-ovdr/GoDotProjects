# 턴과 날짜·행동력

> **원작 일치도 표기:** `확인`=원작 UI/공식 자료로 검증, `참고`=공략 자료 기반, `가설`=재구현 제안, `미확정`=실측 필요. 이 문서는 비공식 역기획이며 코에이테크모의 내부 명세가 아닙니다.

## 시간 모델
1개월을 상순·중순·하순의 세 구간으로 나누며 각 구간을 1턴(10일)로 표시한다. 달력은 단순 10일 가산이 아니라 월 내 세 구간을 순환시킨다.
## 세력 행동
세력별 명령을 순서대로 실행한다. 도시 내정 명령과 지도 위 부대 명령은 실행 주체, 행동 가능 여부, 행동력(AP) 소모를 각각 기록한다.
## 처리 파이프라인(재현용 가설)
1. 활성 세력 결정 → 2. 명령 수락 및 비용 검사 → 3. 명령별 즉시 결과 → 4. 세력 턴 종료 → 5. 다른 세력 턴 → 6. 날짜 갱신 및 정기 처리.
**주의:** 원작 내부의 정확한 정기 처리 시점과 AP 회복 수치는 버전별 실측 전까지 미확정이다.
## 불변식
AP 음수 불가, 행동 완료 부대의 재행동 불가(특수 효과 예외 별도), 달력은 상→중→하→다음 달 상 순서.
## 테스트
연말 12월 하순→1월 상순, 도시 건설 완료 시점, 병력/군량 수입 지급 시점, 턴 종료 전후 부대 기력 변동.

## 구현 인터페이스 공통 요구
- 모든 명령은 실행 가능 여부·소모 자원·상태 변경·이벤트 로그를 반환한다.
- 시나리오와 규칙 데이터를 로직에서 분리한다.
- 재현 실험에는 버전, 난이도, 시나리오, 날짜, 입력 상태, 결과 스크린샷을 첨부한다.
