# 역사 이벤트·조건 분기

> **원작 일치도 표기:** `확인`=원작 UI/공식 자료로 검증, `참고`=공략 자료 기반, `가설`=재구현 제안, `미확정`=실측 필요. 이 문서는 비공식 역기획이며 코에이테크모의 내부 명세가 아닙니다.

## 이벤트 모델
`Event {id,dateWindow,preconditions,priority,choices,effects,onceFlag}`.
## 조건
시나리오·연월, 세력 존속, 군주/무장 생존·소속, 도시 소유, 관계, 다른 이벤트 발생 여부.
## 효과
무장 이동, 세력 변경, 동맹, 도시 소유 변경, 보상, 대사/연출.
## 테스트
조건 하나씩 변경, 다중 이벤트 충돌, 거절 분기, 같은 이벤트 재발동 방지, 역사/가상 설정.

## 구현 인터페이스 공통 요구
- 모든 명령은 실행 가능 여부·소모 자원·상태 변경·이벤트 로그를 반환한다.
- 시나리오와 규칙 데이터를 로직에서 분리한다.
- 재현 실험에는 버전, 난이도, 시나리오, 날짜, 입력 상태, 결과 스크린샷을 첨부한다.
