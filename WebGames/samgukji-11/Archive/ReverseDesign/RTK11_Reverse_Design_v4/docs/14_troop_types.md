# 병과·상성·지형 제한

> **원작 일치도 표기:** `확인`=원작 UI/공식 자료로 검증, `참고`=공략 자료 기반, `가설`=재구현 제안, `미확정`=실측 필요. 이 문서는 비공식 역기획이며 코에이테크모의 내부 명세가 아닙니다.

## 기본 병과
검병, 창병, 극병, 노병, 기병. 별도로 공성병기와 함선을 취급한다.
## 전술 성격
창병은 밀치기·혼란, 극병은 다수 대상·끌어오기, 노병은 원거리·화공, 기병은 돌격·이동 강제 효과가 중심이다.
## 데이터 주의
병과 상성·기본 공격·방어·이동력·지형 비용의 **정확한 원작 값은 이 문서에 아직 수록하지 않는다**. 근거 없는 상수값으로 채우지 않는다.
## 테스트
각 병과 조합 전체 교차 비교, 숲·습지·잔도·수역, 연구 전후 전법·이동 변화.

## 구현 인터페이스 공통 요구
- 모든 명령은 실행 가능 여부·소모 자원·상태 변경·이벤트 로그를 반환한다.
- 시나리오와 규칙 데이터를 로직에서 분리한다.
- 재현 실험에는 버전, 난이도, 시나리오, 날짜, 입력 상태, 결과 스크린샷을 첨부한다.
