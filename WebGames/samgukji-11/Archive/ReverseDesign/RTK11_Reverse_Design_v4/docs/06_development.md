# 개발지·내정 시설·PK 합병

> **원작 일치도 표기:** `확인`=원작 UI/공식 자료로 검증, `참고`=공략 자료 기반, `가설`=재구현 제안, `미확정`=실측 필요. 이 문서는 비공식 역기획이며 코에이테크모의 내부 명세가 아닙니다.

## 시설
시장, 농장, 조폐, 곡창, 병영, 대장간, 마구간, 공방, 조선 등. 시설마다 설치 가능 영역, 금 비용, 건설 진행, 내구, 기능, 인접 보너스를 데이터로 정의한다.
## 인접 보너스
조폐는 인접 시장, 곡창은 인접 농장의 생산을 강화한다. 널리 알려진 1.5배 보정은 실제 버전과 레벨·중복·반올림을 실측해 확정한다.
## PK 합병
동종 시설을 합병하여 Lv.1→Lv.2→Lv.3으로 올리는 기능을 일반판과 구분한다. 합병 대상 시설의 레벨·인접 조건·잔여 개발지 처리·비용은 테스트 표로 검증한다.
## 알고리즘(제안)
`income = sum(baseIncome(facilityLevel) * adjacencyModifier * otherModifiers)`; **원작 확정 수식 아님**.
## 테스트
같은 시설 배치 변경, 조폐 2개 영향, 건설 중 턴 경과, 합병 후 인접 효과, 철거 후 재개발.

## 구현 인터페이스 공통 요구
- 모든 명령은 실행 가능 여부·소모 자원·상태 변경·이벤트 로그를 반환한다.
- 시나리오와 규칙 데이터를 로직에서 분리한다.
- 재현 실험에는 버전, 난이도, 시나리오, 날짜, 입력 상태, 결과 스크린샷을 첨부한다.
