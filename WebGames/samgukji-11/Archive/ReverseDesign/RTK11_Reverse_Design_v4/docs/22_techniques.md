# 기교 연구

> **원작 일치도 표기:** `확인`=원작 UI/공식 자료로 검증, `참고`=공략 자료 기반, `가설`=재구현 제안, `미확정`=실측 필요. 이 문서는 비공식 역기획이며 코에이테크모의 내부 명세가 아닙니다.

## 연구 계열
창병·극병·노병·기병, 연병, 발명, 방위, 화공 등 계열의 단계별 기술을 관리한다. PK 추가 연구 계열은 별도 플래그로 구분한다.
## 연구 조건
선행 단계, 금, 기교 포인트, 연구 수행 무장 및 시간 조건을 독립 필드로 둔다.
## 효과
전법, 이동, 시설, 사거리, 방어, 생산 등에 효과를 연결한다. UI에서 확인 가능한 연구 비용과 시간은 데이터 추출 후 확정한다.
## 테스트
연구 전후 동일 전투, 중간 단계 누락 방지, 세력 소멸 시 기술 상태, PK 추가 계열 표시.

## 구현 인터페이스 공통 요구
- 모든 명령은 실행 가능 여부·소모 자원·상태 변경·이벤트 로그를 반환한다.
- 시나리오와 규칙 데이터를 로직에서 분리한다.
- 재현 실험에는 버전, 난이도, 시나리오, 날짜, 입력 상태, 결과 스크린샷을 첨부한다.
