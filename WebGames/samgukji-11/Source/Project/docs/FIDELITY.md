# 원작 일치도와 v2 확장 범위

이 구현은 기존 v1의 재구성 규칙을 유지하며 3D 표현과 확장 지도를 추가한 프로토타입입니다.

- 42개 도시명과 공개 자료 기반 무장 표본은 기존 데이터에서 이어받았습니다. 출처는 `reference/`입니다.
- 현재 카탈로그 무장은 99개, 실제 캠페인에는 산적 두목을 포함하여 100개 무장 레코드가 있습니다.
- 공개 자료 표본 12명 외 수치는 재구성·임시 데이터가 포함되어 있습니다.
- 86×70 지도 좌표, 높이, 도로, 지형 생성, 훈련 배치, 전투 공식, AI는 원작 데이터 추출물이 아닙니다.
- 모든 모델·재질·애니메이션·효과음은 이 프로토타입용 절차적 재구성입니다.
- UI의 전법은 기존 v1 12종, 병과는 검병을 포함해 7종입니다.

## 3D가 의미하지 않는 것

3D 전장은 원작 PC판의 그래픽 리소스나 정확한 지형의 복원이 아닙니다.
실사 사진 같은 그래픽, 개별 병사 물리 시뮬레이션, 수천 명의 독립 AI, 래그돌, 실시간 액션 전투는 없습니다.
게임은 턴제이며 대표 병사 모델이 부대의 명령 결과를 시각화합니다.

## 여전히 없는 기능

수군·관문·항구, 일기토·설전, 원작 전체 역사 이벤트, 전체 특기 조합, 포로·혈연,
군단 위임, 온라인 멀티플레이, PK 원본 데이터 전체 복원은 미구현입니다.

기존 역기획 v5 자료는 `reference/RTK11_Reverse_Design_v5_original.zip`에 보존했습니다.
그 자료의 후보·추정·재구성 항목이 v2에서 새롭게 원작 검증 완료로 바뀐 것은 아닙니다.
