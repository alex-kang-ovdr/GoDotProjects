# 빠른 시작 — 2D / 3D 공통

ZIP을 전부 풀고 `PLAY.html`을 여십시오. Windows에서는 `START_GAME.bat`으로도 엽니다.
단일 `RTK11_2D3D_Play.html`은 같은 내용입니다.

시작 화면에서 **2D 지도** 또는 **3D 전장**을 선택하고 **전투 훈련**을 시작하세요.
지도 위 **2D 지도 / 3D 전장** 버튼이나 **B 키**로 게임을 재시작하지 않고 전환합니다.
게임 날짜·부대·자원·공격 결과는 유지됩니다.

공격 버튼을 누르고 선택 부대 오른쪽 적을 클릭하면 전투를 확인할 수 있습니다.
왼쪽 드래그는 이동, 휠은 확대입니다. 3D에서만 오른쪽/Shift+드래그와 Q/E 회전이 적용됩니다.
전략 시점/전투 시점은 2D에서도 넓은 지도/가까운 지도로 이용할 수 있습니다.
V 키는 패널 접기/복원입니다. 전체 버튼으로 전역 지도를 확인합니다.

v2에서 이어하려면 이전 실행본에서 JSON을 내보낸 후 새 실행본에서 불러오세요.
선호 모드는 저장소가 허용된 브라우저에 기억되며 JSON 캠페인 데이터와 분리되어 있습니다.
WebGL을 사용할 수 없거나 실행 중 연결이 끊기면 2D로 계속 진행합니다.

직접 로컬 HTML 실행을 금지하는 환경에서는 정책을 바꾸지 말고 허용된 로컬 서버나 IIS에서 여세요.
`node server.cjs`는 선택적 개발 서버입니다. IIS/Windows 실행 자체는 이 작업 환경에서 검사하지 않았습니다.
검증 범위는 `TEST_REPORT.md`, 전체 설명은 루트 `README.md`에 기록되어 있습니다.
