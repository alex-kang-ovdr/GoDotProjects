# 빠른 시작

1. ZIP을 빈 폴더에 전부 압축 해제합니다.
2. `PLAY.html`을 Chrome 또는 Edge에서 엽니다. Windows의 `START_GAME.bat`도 같은 파일을 엽니다.
3. 조조 → 보통 → 8도시 목표를 선택하고 게임을 시작합니다.

## 바로 전투하기

시작 도시 진류 북서쪽에 하후돈 부대가 있습니다. 왼쪽 ‘부대’에서 선택할 수도 있습니다. 밝은 헥스로 이동한 뒤 적 산적 부대와 인접하면 ‘전법 → 나선첨’을 선택하고 산적을 클릭합니다. 실패할 수도 있습니다. 기력이 소모되며 해당 턴의 행동은 종료됩니다.

다음 턴에 다시 행동합니다. 혼란이 성공한 적은 한 차례의 행동을 건너뜁니다. 산적을 격파하면 첫 전과 목표를 달성합니다.

## 내정과 추가 출진

진류를 선택해 시설 개발 → 빈 개발지 → 시장 또는 농장을 건설합니다. 징병은 치안을 떨어뜨리므로 순찰과 병행합니다. 출진 창에서는 주장과 병과, 병력, 군량을 지정합니다. 병장 수량이 병력보다 부족하면 생산하거나 병과·병력을 바꾸세요.

무장은 한 턴에 도시 명령 한 번을 처리합니다. 모든 무장이 행동했다면 다음 턴을 진행합니다. 출진한 무장은 도시 명령을 수행하지 않습니다.

## 도시 점령

성벽 내구도를 0으로 만들면 점령합니다. 창·극·기병의 전법은 야전 부대 대상이며 성에는 통상 공격을 사용합니다. 충차와 정란은 공성 보너스가 큽니다. 다만 성에 인접하면 턴 진행 때 수비대의 피해를 받으므로 병력과 군량을 충분히 준비합니다.

## 저장

매 명령 후 브라우저 자동 저장을 시도합니다. 확실한 백업은 상단 `내보내기`의 JSON 저장 파일입니다. 새 폴더·새 브라우저에서는 JSON을 `불러오기`로 복구합니다. 작은 화면에서는 상단 `메뉴`에서 내보내기에 접근합니다.

## 실행 문제가 있을 때

ZIP 미리보기 안이 아니라 해제된 폴더에서 실행했는지 확인합니다. 분리형 `index.html`의 폴더가 누락되었다면 단일 파일 `PLAY.html`을 사용합니다.

조직 정책이 로컬 HTML 실행을 차단한 경우, 허용된 개발 환경에서 `node server.cjs`로 로컬 서버를 실행하고 표시된 주소를 엽니다. 인터넷은 필요 없으며 서버 실행에만 Node.js 18 이상이 필요합니다. 포트가 사용 중이면 `PORT` 환경변수를 바꿀 수 있습니다.

```powershell
$env:PORT=8090
node server.cjs
```

원작과 다른 지도·배치·공식·이벤트를 사용하는 재구성 프로토타입입니다. 이 문서의 공략은 원작 삼국지 11 공략이 아닙니다.
