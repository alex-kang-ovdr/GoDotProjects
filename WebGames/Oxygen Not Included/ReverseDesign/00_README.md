## 1. 문서의 목적

게임의 기능을 시스템별로 분해하고, 그 기능들이 어떤 자원 흐름과 플레이어 선택을 만들어 내는지 설명한다. 각 문서는 기능 소개에서 끝나지 않고 **입력과 출력, 상태, 작동 조건, 예외, 실패 연쇄, 다른 시스템과의 연계, 분석용 계산, 재현 가능한 검증 질문**을 포함한다.

핵심 관점은 다음과 같다.

**Oxygen Not Included의 기지는 개별 건물의 합계보다, 물질·에너지·노동이 서로 의존하는 생산망으로 이해해야 한다.** 산소 공급을 늘리면 물·전력·열 처리가 따라오고, 인구를 늘리면 노동과 생존 수요가 함께 늘며, 우주로 확장하면 기존 운영 체계를 고립된 환경에서 다시 성립시켜야 한다. 이는 본 문서의 기획적 해석이다.

## 6. 조사 범위와 사용상의 맥락

- 사용자가 제공한 [나무위키 문서](https://namu.wiki/w/Oxygen%20Not%20Included)는 조사 시 직접 본문을 열 수 없었다. 읽은 것으로 취급하지 않고 Klei 공식 자료·개발자 공지로 주요 근거를 구성했다.
- 기본 게임의 공통 구조를 상세히 분석하고, Spaced Out!은 우주·방사선·다중 거점 차이를 별도 문서화했다.
- 추가 콘텐츠 팩은 기본 시스템을 바꾸는 축과 연계 중심으로 다뤘다. 모든 개별 건물·생물·레시피의 최신 수치를 전수 추출한 도감은 아니다.
- 2026년 11월 QoL 공개테스트의 변경은 안정판의 확정 규칙으로 섞지 않았다. 자세한 기준은 [27번](27_sources_version_notes.md)을 따른다.
- 실제 게임 실행·세이브 분석·소스 코드 추출은 수행하지 않았다. 문서와 계산 검토, 공개 자료 확인, 향후 게임 시험을 구분했다.
