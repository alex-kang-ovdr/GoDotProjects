## 7. 단위 사전

| 값 | 단위 예 | 비교할 때 지켜야 할 것 |
|---|---|---|
| 질량 | g, kg, t | 1kg = 1,000g, 1t = 1,000kg |
| 유량 | g/s, kg/s | 단위 시간의 생산·운송·소비 |
| 전력 | W, kW | 1W = 1J/s, 1kW = 1,000W |
| 저장 에너지 | J, kJ | 1kJ = 1,000J. 시간과 함께 비교 |
| 식량 열량 | kcal | 음식 질량과 열량은 별도 값 |
| 온도 | °C, K | 온도 차이의 1K와 1°C 크기는 같음. 절대값은 오프셋 주의 |
| 열·열유량 | DTU, kDTU/s 등의 게임 표기 | 현실 열역학 근사와 게임 고유 산출 규칙을 구분 |
| 게임 시간 | s, cycle | cycle을 실시간 플레이 속도와 혼동하지 않음 |
| 방사선 | rads/cycle 등 게임 표기 | 게임 내 위험과 산업 규칙을 위한 단위로 취급 |

## 8. 가장 자주 혼동되는 다섯 쌍

1. **재고와 생산량:** 많이 저장되어 있어도 순소비 상태면 언젠가 고갈된다.
2. **능력치와 작업 자격:** 빨리 할 수 있는 능력과 해당 행동을 할 수 있는 권한·기술은 별도다.
3. **물질 오염과 병원균:** 물질 종류가 정상으로 바뀌어도 병원균 처리까지 끝났다고 가정할 수 없다.
4. **사기와 스트레스:** 생활 수준의 수지와 시간에 따라 변하는 상태를 하나의 게이지로 합치지 않는다.
5. **냉각과 열 제거:** 한 구역의 온도를 낮추는 것과 전체 시스템의 열을 처리하는 것은 별도 문제다.

이 장은 관련 시스템 문서에서 사용한 용어를 설명한다. 특정 빌드의 효과·수치를 판단할 때는 연결 문서의 해당 출처와 검증 조건을 우선한다.
