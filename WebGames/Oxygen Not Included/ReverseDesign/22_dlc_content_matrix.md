# 22. 기본 게임·Spaced Out!·콘텐츠 팩 차이

> **조사 기준일:** 2026-11-13  
> **범위:** 공개 자료로 확인한 출시 콘텐츠의 시스템 영향. 2026년 11월 공개테스트는 별도 취급  
> **주의:** 이 문서는 모든 DLC의 개별 건물·생물 수치를 열거한 도감이 아니라, 역기획 시 함께 묶거나 분리해야 할 규칙을 정의한다.  
> [전체 목차](00_README.md)

## 1. 콘텐츠를 구분하는 기준

**[해석]** ONI의 확장을 모두 “건물과 자원이 늘어나는 DLC”로 처리하면 규칙이 섞인다. 분석에서는 다음 세 층을 분리한다.

| 층 | 역할 | 문서에서의 처리 |
|---|---|---|
| 규칙 모드 | 우주 지도·로켓·다중 거점 등 플레이 구조 변경 | 기본 게임과 Spaced Out! 별도 문서 |
| 콘텐츠 팩 | 특정 환경·생물·복제체·생산 체인 추가 | 공통 시스템에 대한 변화로 기술 |
| 공통 무료 업데이트 | 기존 규칙·수치·UI·버그 동작 변경 | 출시 시점과 적용 브랜치를 기록 |

**[확인]** Klei 공식 제품 페이지는 Spaced Out!, Frosty Planet, Bionic Booster, Prehistoric Planet, Aquatic Planet을 구분해 소개한다.[^official] 장식·사운드트랙 상품은 본 역기획서의 생존·생산 시스템 분석 범위에서 제외한다.

## 3. Spaced Out!: 공간 규모가 달라지는 확장

**[확인]** 공식 설명은 여러 월드의 동시 관리, 자원 운송, 모듈식 로켓, 개편된 성도와 연구 진행을 핵심으로 제시한다.[^spaced]

**[해석]** 이 변화가 만드는 기획 차이는 다음과 같다.

- 생산망의 끝이 다른 방이 아니라 다른 천체가 된다. 배송 실패가 현지 생존 문제로 연결된다.
- 새 기지를 만들 때 현지 시설뿐 아니라 출발지의 노동·보급 손실을 계산해야 한다.
- 중앙집중형 생산은 효율적일 수 있지만 운송 단절에 취약하다. 필수품의 현지 생산은 중복 투자와 독립성의 교환이다.
- 조작 초점이 한 월드에 있어도 다른 거점의 안전을 검토해야 하므로, 자동화와 경보의 가치가 커진다.

### 분리해야 할 규칙

| 항목 | 잘못 섞기 쉬운 설명 | 이 문서 세트의 원칙 |
|---|---|---|
| 로켓 | 기본 게임의 목적지·연료 설명을 SO 성도에 그대로 적용 | [기본 로켓](19_space_rocketry_base.md)과 [SO 거점](21_multicolony_spaced_out.md) 구분 |
| 연구 | 모든 모드의 데이터뱅크 획득 경로가 같다고 가정 | 연구 포인트의 출처와 빌드를 기록 |
| 방사선 | 기본판에도 동일한 핵 발전 체계가 있다고 가정 | [방사선 문서](20_radiation_nuclear_spaced_out.md)는 SO 기준 |
| 천체 환경 | 모든 천체가 같은 자원·위험을 가진다고 가정 | 월드 프리셋과 콘텐츠 조합별 검토 |

## 4. Frosty Planet: 열을 비용이자 자원으로

**[확인]** 2024-07-18 출시한 Frosty Planet Pack은 추운 시작 행성, 저온 적응 생물·식물, 관련 자원과 기술을 제공한다.[^frosty]

**[해석]** 기본적인 열 관리의 질문을 변형한다. 고온 산업에서 버려야 했던 열이 다른 구역에서는 유용한 투입이 될 수 있다. 그러나 “저온 맵이면 냉각을 고민하지 않아도 된다”는 결론은 성립하지 않는다. 장소별 목표 온도가 다르고, 열을 잘못 전달하면 작물·설비·고체 지형의 상태가 바뀔 수 있기 때문이다.

| 재분석할 항목 | 확인할 입력 | 필요한 설계 선택 |
|---|---|---|
| 생활 구역 | 복제체 활동 환경, 의복·보호 조건 | 국소 난방, 단열, 이동 경로 |
| 농업 | 작물별 허용 온도와 투입 자원 | 저온 작물 선택과 가열 농장 분리 |
| 물 공급 | 얼음·액체의 사용 가능한 상태 | 해동 속도, 운반, 열 공급 |
| 산업 | 냉각 가능한 환경과 필요한 공정 온도 | 열원과 열수요를 맞추는 배치 |

정확한 식물별 생육 범위와 수율은 본문에서 검증한 범위를 넘어 일괄 단정하지 않는다.

## 5. Bionic Booster: 노동력의 유지비 구조 변경

**[확인]** 2024-12-12 출시한 Bionic Booster Pack은 바이오닉 복제체, 능력 부스터, 휴대형 전력, 원격 작업을 포함한다. 공식 설명은 내부 산소 저장과 별도 서비스 시설도 명시한다.[^bionic]

**[해석]** 바이오닉은 기존 인력을 단순히 성능만 높여 대체하는 유닛으로 분석하면 안 된다. 생존 투입·정비·행동 주기·전문화 수단을 다른 조합으로 바꾸는 시스템으로 읽어야 한다.

| 항목 | 유기체 복제체의 일반 분석 | 바이오닉에서 다시 확인할 것 |
|---|---|---|
| 생존 투입 | 식사·호흡·생활시설 | 전력 보급, 산소 저장·보충, 정비 자원 |
| 능력 구성 | 특성·스킬·경험에 따른 전문화 | 부스터 장착 조건과 교체 비용 |
| 외곽 작업 | 이동 중 호흡·안전·귀환 | 내부 저장 자원의 잔량과 서비스 접근성 |
| 전력 | 주로 기지 설비의 가동 비용 | 인력 자체와 고립 설비의 보급망 |
| 건강 | 질병·환경 피해·회복 | 유기체의 면역·치료 규칙을 그대로 대입하지 않음 |

**[검증 필요]** “산소가 필요 없다”, “모든 질병에 면역”, “일정과 생활 관리가 완전히 불필요하다”는 일반화는 하지 않는다. 실제 적용 규칙은 [복제체](03_duplicants_attributes_skills.md)와 [건강](13_health_germs_suits.md)의 분기 항목을 따른다.

## 6. Prehistoric Planet: 생태와 공간 배치의 확장

**[확인]** 2025-06-12 출시한 Prehistoric Planet Pack의 공식 소개는 공룡 계열 생물, 벽·천장에 자라는 식물, 신규 물질과 충돌 천체 방어 요소를 포함한다.[^prehistoric]

**[해석]** 바닥 한 줄에 농장을 배치한다는 전제가 약해지면 건축 공간의 효율 기준도 바뀐다. 식물의 설치 면, 성장 공간, 접근 가능한 작업 면, 수확물 회수 경로를 따로 분석해야 한다. 포식 생물은 산출물을 만드는 생산 설비인 동시에 다른 생물 재고를 소비하는 주체가 되어 생태계 전체의 유지 조건을 바꾼다.

역기획 검토 항목은 다음과 같다.

- 종별 먹이망과 생존·번식 조건을 작성하고, 단순히 사육 가능한 개체 수만으로 안정성을 판단하지 않는다.
- 농장과 목장의 평면 배치뿐 아니라 벽·천장·높이·작업 접근을 기록한다.
- 방어 과제는 위험 감지, 준비 기간, 필요한 자원·설비, 실패 결과를 구분해 기술한다.
- 새로운 연료·요리·재료의 가치가 기존 생산 체인의 어느 병목을 우회하는지 평가한다.

## 7. Aquatic Planet: 액체 속 공간을 생활권으로

**[확인]** 2026-06-11 출시한 Aquatic Planet Pack은 수중 바이옴, 수영 기술, 수중 생태와 건물을 추가한다.[^aquatic] 출시와 함께 배포된 공통 무료 업데이트도 별도로 존재하므로 상품 소유 여부와 무료 패치 적용 여부를 같은 값으로 취급하면 안 된다.[^aquaticrelease]

**[해석]** 수중 행동은 단순히 이동 애니메이션을 바꾸는 기능으로 끝나지 않는다. 이동 가능 공간, 산소 접근, 작업 발판, 생물의 생활 공간, 건물의 침수 조건이 다시 결합한다.

| 시스템 | 다시 분석해야 할 관계 | 예외 질문 |
|---|---|---|
| 이동 | 육상 경로와 수중 경로의 연결 | 기술이 다른 복제체가 같은 지시를 수행할 수 있는가? |
| 호흡 | 체류 시간과 산소 보충 지점 | 귀환이 막혔을 때 비상 행동은 무엇인가? |
| 건설 | 설치 조건과 수중 작업 | 수중 전용·허용·불가 건물을 어떻게 표시하는가? |
| 생태 | 방 경계와 수영장 경계 | 수위 변화로 생활 공간이 바뀌는가? |
| 물류 | 부력·위치·접근·설비 포트 | 수확물과 재료를 회수하는 경로는 무엇인가? |

## 8. 2026년 11월 공개테스트의 취급

**[확인]** 2026-10-29 개발자 공지는 11월 QoL의 **공개테스트 시작**을 알렸다. 수영과 수중 그루밍의 공통화, 배관 흐름 표시 등의 변경이 여기에 포함된다.[^test]

이 문서의 원칙은 다음과 같다.

1. 테스트 공지를 정식 출시 완료의 근거로 쓰지 않는다.
2. 안정판 범위의 시스템 설명에 테스트 규칙을 기본값으로 끼워 넣지 않는다.
3. 향후 정식 반영 시 영향을 받는 문서와 검증 항목을 표시한다.
4. 실제 빌드 번호가 없는 수치 비교에는 브랜치 불확실성을 남긴다.

## 9. 콘텐츠 조합을 지원하는 데이터 설계

**[설계 제안]** DLC 이름 하나를 전역 분기로 사용하는 대신 기능별 이용 가능 조건을 둔다.

```yaml
# 원작 데이터가 아닌 재구현 예시
feature:
  id: example_underwater_action
  ruleset_support: [Base, SpacedOut]
  content_requirement: configurable
  release_channel: stable_or_test
  enabled_since_build: requires_verification
  actor_requirements: [required_capability]
  environment_requirements: [valid_medium]
```

이 구조는 유료 팩에 먼저 들어간 기능이 나중에 무료 공통 기능으로 바뀌는 경우에도 데이터의 의미를 유지하기 위한 제안이다. 원작이 실제로 이러한 YAML을 쓴다는 뜻은 아니다.

## 10. 조합 검증 매트릭스

| 시험 축 | 최소 비교 | 기대하는 확인 결과 |
|---|---|---|
| 규칙 모드 | Base / Spaced Out! | 연구·로켓·월드 규칙이 모드에 맞게 선택됨 |
| 인력 유형 | Organic / Bionic | 소비·정비·능력 요구가 혼합되지 않음 |
| 생태 환경 | 육상 / 수중 / 저온 | 종별 요구 환경이 올바르게 적용됨 |
| 콘텐츠 | 팩 없음 / 단독 / 여러 팩 조합 | 추가 콘텐츠가 허용된 생성·레시피에 반영됨 |
| 브랜치 | Stable / Public testing | 향후 규칙을 안정판 결과로 오인하지 않음 |
| 저장 상태 | 신규 생성 / 기존 세이브 | 생성 시점만 바뀌는 내용과 소급되는 변경을 분리 |
