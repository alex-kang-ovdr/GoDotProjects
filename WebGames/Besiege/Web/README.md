# IRONWOOD 4.0 · 공성 공방

공성차·선박·비행기·피스톤 기계를 3D 부품으로 조립하고 실제 물리로 운용하는 JavaScript 웹 게임입니다. **제작 → 출격 → 주행·항해·비행 → 목표 파괴 또는 관문 통과 → 결과·기록·점검 보고서·재도전·재설계** 흐름을 구현합니다. Besiege의 제작·실험 구조에서 영감을 받은 독립 작품이며 원작 에셋·실행 코드·내부 수치를 사용하지 않습니다.

## 실행

### 다운로드한 단일 HTML

`dist/ironwood-play.html`을 최신 WebGL 지원 브라우저에서 엽니다. HTML 안에 스타일, 게임 코드, Three.js와 cannon-es를 묶었으므로 실행 중 외부 CDN·HTTP 서버·패키지 설치가 필요하지 않습니다. 브라우저가 로컬 파일의 저장 공간을 제한하면 설계 JSON 내보내기를 사용하세요.

### 모듈 소스를 수정하며 실행

```bash
python3 -m http.server 8000 --directory dist
```

브라우저에서 `http://localhost:8000`을 엽니다. 모듈판 `dist/index.html`은 HTTP 서버로 제공해야 합니다. 수정한 소스로 단일 HTML을 다시 만들 때만 개발 의존성이 필요합니다.

```bash
npm ci
npm run build:offline
npm run pack:source
```

## 첫 작전

1. 기본 **척후 공성차**를 확인합니다. 중심 코어, 4륜 구동, 회전 관절과 대포를 갖춘 15개 부품 설계입니다.
2. 자재 한도와 코어 연결을 확인하고 **Space** 또는 출격 버튼을 누릅니다.
3. **F**로 정면 표적을 사격합니다. **Q/E**로 포탑을 돌리고 **I/K**로 고각을 조절하면 예상 탄도와 착탄 지점을 확인할 수 있습니다.
4. **W/S**로 전후진, **A/D**로 차동 선회합니다. **B**로 제동합니다.
5. 모든 표적을 파괴하면 기록과 별을 받습니다. 실패하면 같은 설계로 바로 재도전하거나 조립으로 돌아가 구조를 바꿉니다.

F는 누를 때마다 한 번 작동합니다. 재장전 후 키를 놓았다가 다시 누르세요. 대포가 여러 개면 발사한 포탄 수만큼 탄약을 사용합니다. 탄약을 다 써도 충각 공격은 가능하므로 즉시 실패하지 않습니다.

돌초소에는 1개, 성문에는 2개, 요새에는 3개의 방어 포탑이 있습니다. 붉은 공격 예고가 나타나면 이동하거나 엄폐물을 이용하세요. 공격 예고 때 정해진 조준점을 향해 실제 포탄이 발사됩니다. 포탑을 지지하는 표적을 파괴하면 추가 발사가 중단됩니다. 첫 작전에서는 중앙 포탑을 먼저 노려 보세요.

코어 파괴, 제한 시간 초과, 시험장 이탈은 실패입니다. 같은 물리 스텝에 코어 손실과 마지막 표적 파괴가 겹치면 실패를 우선합니다. 한 번 결정된 결과는 바뀌지 않습니다. 종료 후 전장은 살펴볼 수 있고, 재도전하면 새 물리 세계로 시작합니다.

## 선박과 비행기 시작하기

**선박:** 설계 메뉴의 **쌍동 항해선**을 선택하면 해협 항로도 함께 열립니다. 또는 작전만 바꾼 뒤 **추천 설계 불러오기**를 누릅니다. Space로 출격하고 W로 추진, A/D로 조타합니다. 빛나는 관문을 순서대로 통과하세요. 코어가 수면 아래 깊게 잠긴 상태가 지속되면 침수 실패입니다. 부유체를 한쪽에 모으거나 무게를 높이 올리면 안정성이 나빠질 수 있습니다.

**비행기:** 설계 메뉴의 **개척 비행기**를 선택합니다. Space로 출격한 뒤 W를 눌러 활주·가속합니다. 속도와 받음각에 따라 날개에서 양력이 발생합니다. **↑/↓는 기수, ←/→는 좌우 기울기, A/D는 방향**을 조절합니다. 빛나는 공중 관문을 순서대로 통과하세요. 기본 자세 보조를 켜고 익힌 뒤 끌 수 있습니다. 자세 보조도 힘·토크를 사용하며 위치나 회전값을 강제로 맞추지 않습니다.

임무 변경만으로 현재 설계를 교체하지 않습니다. 추천 설계를 직접 불러오면 이전 설계·작전은 백업되며 **설계 → 이전 작업 복원**으로 되돌릴 수 있습니다. 수상·비행 임무에도 다른 기체를 가져갈 수 있지만 환경에 맞지 않는 구성에는 권고가 표시됩니다.

## 조립과 파손 규칙

| 부품 | 질량 | 자재 | HP | 연결 및 역할 |
| --- | ---: | ---: | ---: | --- |
| 중심 코어 | 3.0 | 5 | 100 | 기체에 하나. 제어와 생존의 기준이며 이동·복사·삭제 불가 |
| 목재 블록 | 1.0 | 1 | 55 | 면이 맞닿는 구조물끼리 고정 연결 |
| 강철 보강 | 1.3 | 2 | 110 | 목재보다 강한 고정 연결, 높은 내구도 |
| 구동 바퀴 | 1.4 | 3 | 50 | 차축 방향의 이웃 하나에 장착, 좌우 구동 그룹 |
| 회전 관절 | 1.5 | 3 | 65 | 아래 지지부와 Y축 회전, 위 탑재물을 함께 회전 |
| 대포 | 3.0 | 5 | 75 | 고각 -10~45도, 포신 방향 발사, 차체 반동 |
| 부유체 | 0.7 | 3 | 65 | 침수율에 따른 부력·항력. 좌우·앞뒤 배치가 선체 안정성에 영향 |
| 추진 프로펠러 | 1.5 | 5 | 55 | 부품의 앞 방향으로 추력. 코어 연결이 끊기면 엔진 정지 |
| 양력 날개 | 0.6 | 3 | 45 | 속도와 받음각에 따른 양력·항력. 기본 설치각 6도 |
| 선형 피스톤 | 1.8 | 4 | 70 | 아래 지지의 로컬 Y축으로 상부 탑재물 이동. 유한 힘과 0.25~2m 행정 |

- 부품마다 별도의 물리 강체가 존재합니다. 고정 연결과 힌지 연결을 구분합니다.
- 구조 연결 파단과 부품 HP 손실은 별개의 상태입니다. 연결이 떨어진 부품은 파편으로 계속 시뮬레이션됩니다.
- **코어와 연결이 끊긴 바퀴·관절·대포는 제어를 받지 않습니다.** HP가 남은 포도 떨어지면 발사할 수 없습니다.
- 일반 구조물은 여섯 면의 인접 관계만 연결하며, 모서리 접촉은 연결하지 않습니다.
- 관절을 우회하는 고정 구조를 만들면 회전이 막힐 수 있습니다.
- 제작 범위는 X/Z -12~12, Y 0~10의 정수 격자이고 최대 100부품입니다. 출력은 0.3~2.0입니다.
- 대칭 배치는 양쪽 모두 유효할 때만 한 번에 반영됩니다. 한쪽만 배치되는 부분 성공은 없습니다. 중앙선에는 한 개만 놓습니다.
- 이동은 확인 전까지 원본을 바꾸지 않습니다. Esc로 취소하거나 불가능한 위치를 클릭해도 기존 부품이 사라지지 않습니다.
- 자재를 초과한 설계도 편집·저장은 가능하지만 캠페인 출격 전에 한도를 맞춰야 합니다. 자유 제작에는 자재 제한이 없습니다.
- 부유체와 날개는 수동 부품입니다. 살아 있는 부품은 떨어져도 부력·공기력을 받지만, 연결이 끊긴 부품을 조종할 수는 없습니다. 파괴된 부유체·날개는 해당 힘을 잃습니다.
- 날개·프로펠러를 추가했다고 자동으로 안정적인 기체가 되는 것은 아닙니다. 무게중심, 날개 위치, 추력 방향과 받음각을 함께 조정하세요.
- 날개의 면적 배율은 양력과 항력을 함께 바꿉니다. 값을 높이면 같은 속도에서 더 큰 힘을 받으며 저항도 증가합니다.

## 피스톤과 굴곡 주행

**승강 시험대:** 설계 메뉴에서 승강 시험대를 불러오면 자유 제작이 함께 열립니다. Space로 시작하고 Z를 누르면 상부가 올라가며, X로 내립니다. 입력을 놓으면 마지막 목표를 유지합니다. 아래 지지와 위 탑재물을 조립해야 하며, 옆면은 자동 고정되지 않습니다. 출력은 힘과 목표 이동 속도에, 최대 이동 설정은 행정에 영향을 줍니다. 과적 상태에서는 목표가 올라가도 실제 피스톤은 멈출 수 있습니다.

**굴곡 주행:** 작전 메뉴에서 선택한 뒤 추천 철갑 충각차를 불러옵니다. 좌우로 번갈아 놓인 네 관문을 순서대로 통과합니다. 관문을 지난 뒤 B로 감속하고 A/D로 다음 관문을 향해 조향하세요. 평평한 지면의 조향 코스이며 W만 유지해서는 통과할 수 없습니다.

## 묶음 조립

Shift 클릭 또는 **여러 부품 선택**으로 묶음을 만듭니다. 금색 부품이 회전 기준이며 나머지는 청록색입니다. 6방향 이동, 묶음 폭만큼 떨어진 복사, 90도 회전, X=0 반사, 묶음 삭제를 제공합니다. 전체가 유효할 때만 반영하고 실행 취소 한 단계로 되돌립니다. 코어가 포함된 묶음은 변형할 수 없습니다. 새 배치 도구를 선택하면 묶음 선택 모드를 해제합니다.

## 시험 보고서와 점검

시험 중 부품을 클릭하면 물리가 멈추고 HP·코어 연결·연결별 하중비·누적 손상을 볼 수 있습니다. 피스톤에는 실제 이동량과 목표값을 함께 표시합니다. 한 스텝 버튼으로 입력 없이 1/60초씩 진행하거나 0.5배속으로 관찰할 수 있습니다.

**시험 보고서**는 실제 사건의 시점·피해·최초 파손·파손 원인과 관련 부품을 기록합니다. 순간 하중과 누적 연결 손상은 별도 색상 모드입니다. 보고서에서 부품을 선택하거나 조립으로 돌아가 원본 위치를 주황색으로 확인하세요. 설계나 작전이 바뀌면 과거 위치 강조를 해제합니다. 최고 하중·속도는 시뮬레이션 시간 기준 최대 12Hz의 정기 표본과 추가 관측을 사용하며, 전체 물리 스텝의 연속 최대값은 아닙니다. 최근 시험 한 회를 현재 탭에서 보관하고 JSON으로 내보낼 수 있습니다.

## 저장과 재설계

형식 1 설계 JSON과 기존 브라우저 저장을 유지합니다. 과거 설계에 고각 필드가 없으면 0도로 읽습니다. 자동 저장, 이름 있는 설계 8칸, 설계 교체 전 백업, JSON 가져오기·내보내기를 제공합니다. 같은 이름으로 저장해도 자동으로 덮어쓰지 않으며 기존 칸을 바꾸려면 명시적인 덮어쓰기 버튼을 사용합니다. 이전 빠른 저장은 빈 보관함에 한 번 이관하고 원본 불러오기도 유지합니다. 아직 연결하지 않은 부품이 있는 설계도 보관할 수 있습니다.

시험에는 설계 복사본을 사용합니다. 물리 파손이 편집 원본을 바꾸지 않으며 조립으로 돌아가면 복원됩니다. 설계·도움말·작전·보고서 창을 열면 진행 중인 시험이 일시정지되고, 선택 없이 닫으면 이어집니다. 실제로 다른 설계나 미션을 적용하면 시험을 종료하고 조립으로 돌아갑니다. 설계 불러오기를 실행 취소하면 부품과 작전이 함께 복구됩니다. 잘못된 JSON은 현재 설계나 시험을 변경하지 않습니다.

## 현재 범위

10종 부품, 6개 프리셋, 6개 캠페인과 자유 제작을 제공합니다. 지상 공성, 선박 항해, 프로펠러 비행기, 피스톤 기계의 제작·운용·점검·재설계 흐름을 구현했습니다. 부력·양력은 게임용 근사 모델이며 CFD나 실제 항공기 인증 수준의 계산은 아닙니다. 유압 유량·압축성·파도·유체 연성·궤도 벨트·멀티플레이·원작 전체 블록은 포함하지 않습니다. 보강은 두 끝점을 찍는 원작의 도구와 달리 한 격자를 차지하는 구조 블록입니다. 탄도선은 중력·초기 속도·환경 충돌을 이용한 예상이며 움직이는 물체, 자기 기체, 이후 충돌을 모두 예측하는 보증선은 아닙니다.
