# Besiege 상세 역기획서

**조립 UX · 블록 연결 · 부품별 물리 규칙 · 제어 · 파손 · 환경 확장**

- 작성 언어: 한국어
- 조사일: **2026-11-13**
- 대상: **Steam PC판**. 기본 게임, The Splintered Sea, The Broken Beyond를 구분한다.
- 공개 변경 기록의 기준점: **V1.91-25490, 2026-09-21**까지 확인한 기능을 포함한다. 실제 설치본의 빌드를 검사한 결과는 아니다.
- 구성: **Markdown 22개**. 상대 링크·표·Mermaid 다이어그램·분석용 수식·미실행 시험 계획 포함.

## 1. 작성 목적

게임 소개나 공략 목록을 넘어 **사용자가 어떤 편집 조작으로 어떤 연결과 기구를 만들고, 그 기구가 입력·외력·손상에 어떻게 반응하는지**를 시스템 단위로 설명한다. 특히 배치와 연결의 구별, 가동부의 자유도, 힘의 작용점, 구조 파단, 입력의 시간 의미를 중심으로 분석했다.

기획자에게는 규칙과 사용자 흐름, 프로그래머에게는 상태·연결·데이터 계약, 테스트 담당자에게는 미확정 규칙을 확인할 실험 구성을 제공한다.

## 2. 증거 수준

| 표기 | 의미 | 읽는 방법 |
|---|---|---|
| **[공식 확인]** | 개발사 소개·공식 공지에서 명시 | 발표 버전과 후속 변경을 함께 확인 |
| **[공식 확인·역사 자료]** | 과거 공식 버전의 동작 설명 | 현행 세부를 자동으로 확정하지 않음 |
| **[설계 해석]** | 기능의 목적·인과관계·트레이드오프 분석 | 원작 개발자의 의도를 인용한 것이 아님 |
| **[재구성 제안]** | 유사 경험을 구현하는 독립 설계 | 원작 코드·내부 수식·자료구조가 아님 |
| **[검증 필요]** | 문헌만으로 확정하기 어려운 동작 | 제시한 시험으로 실행판 확인 필요 |
| **도구 제작자 관측** | 진단 도구 제작자가 공개한 직접 관측 | 공식 확정 사양과 분리하여 사용 |

**게임 실행·계측·비공개 코드 분석은 수행하지 않았다.** 질량·토크·파단력·마찰 계수·현재 물리 스텝·네트워크 패킷 값 등을 임의로 채우지 않았다. 실험표는 계획이며 실행 결과가 아니다.

## 5. 문서 전반의 주요 해석

### 5.1 조립은 형태와 관계를 함께 편집한다

같은 위치에 놓인 부품도 접점·가동측·배치 순서·설정에 따라 다른 기구가 될 수 있다. 외형, 충돌체, 접합, 입력 연결을 분리해서 분석해야 한다.

### 5.2 물리 실패를 읽는 UX가 제작 깊이를 만든다

차량이 움직이지 않으면 구동 방향·접지·간섭·가동부 구속 중 원인을 구분할 수 있어야 한다. 마지막 파편 위치보다 최초 파단과 그때의 입력·하중이 중요하다.

### 5.3 동력원과 운동을 허용하는 부품은 다르다

힌지·슬라이더·수동 바퀴·공력면은 자체 구동과 구분한다. 힘을 만드는 장치뿐 아니라 힘이 구조를 거쳐 어디로 돌아오는지 설명한다.

### 5.4 환경 확장은 새로운 관계를 더한다

수중에서는 부력·저항·젖음, 우주에서는 대기·중력·연료망이 추가된다. 개별 부품을 설명할 때 환경 조건과 DLC 범위를 함께 적었다.

### 5.5 최신 기능과 과거 규칙을 섞지 않는다

2025~2026년의 추가 로드·다중 매개변수 편집·물리 부품·화염 연료화·연료 펌프 변경을 반영했다. 발표 시점 수치, 구형 저장본 호환성, 새 배치 기본값은 별도로 취급한다.

## 6. 자료 범위와 제한

사용자가 지정한 [나무위키 비시즈 문서](https://namu.wiki/w/%EB%B9%84%EC%8B%9C%EC%A6%88)는 이번 조사에서 본문을 열지 못했다. 따라서 해당 내용을 읽거나 검증한 것으로 인용하지 않았다. **개발사의 Steam 공식 소개·변경 기록·기술 설명을 중심으로 작성**했으며, 연결의 일부 미공개 세부에 한해 진단 도구 제작자의 직접 관측을 명시적으로 분리했다.

공식 공지 중 일부 개별 페이지는 본문이 표시되지 않아 동일한 공식 뉴스 피드에서 내용을 확인했다. [99 출처](99_sources.md)에 개별 기사 링크와 본문 확인 경로를 함께 남겼다.

이 문서 묶음은 설명과 분석을 새로 작성했으며 원문을 길게 전재하지 않았다. 실제 게임의 전 부품 수치표, 실행 테스트 결과, 원본 코드 재현물로 사용하지 않는다.
