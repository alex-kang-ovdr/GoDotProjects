# PROJECT IDOL — Virtual Star Maker (Web v1)

## 실행
`index.html`을 Chrome, Edge, Firefox 등의 브라우저로 열면 됩니다. 서버나 설치 과정이 필요하지 않습니다.

## 기능
- 8명 연습생 훈련과 자유 그룹 편성
- 월별 경제/피로/성장 및 평가
- 데뷔, 음악 제작, 가사/MV 스토리보드 초안, 음원 발매
- 팬덤 활동과 역주행
- 기존 스토리 데이터 120개 이벤트, 엔딩 24종 데이터
- localStorage 자동 저장 및 JSON 저장 파일 가져오기/내보내기

## 주의
- 실제 AI 음악/영상 생성 API 미연결. 가사와 스토리보드는 브라우저 내 템플릿 기반 초안입니다.
- 데이터팩은 초안이므로 일부 이벤트가 반복적인 구조입니다.
- 게임 수치와 팬덤/음원 지표는 실제 연예계 자료가 아닌 가상 게임 밸런스입니다.
