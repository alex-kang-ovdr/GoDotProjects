# PROJECT IDOL Data Studio v3

## 실행
압축 해제 후 `index.html` 실행. `seed.js`와 `studio3.js`는 같은 폴더에 둡니다.

## 신규 기능
- 자유 그룹 편성, 멤버별 포지션 및 평균 능력치
- 캐릭터별 표정/의상 이미지 업로드 (파일당 450KB 제한)
- 이벤트 연결 그래프 및 후속 이벤트 관리
- 월/능력치/플래그 기반 이벤트 조건 및 선택 결과 시뮬레이터
- 기존 v2 편집 기능 유지, 통합 JSON 가져오기/내보내기

## 제한
- 그래프는 연결 관계를 카드로 표시하는 경량 시각화이며 자유 드래그 노드 에디터는 아님
- 조건 검사: 월, min_stat, required_flags. 그 외 조건은 미지원으로 표시
- 이미지 저장은 브라우저 localStorage 한도에 영향을 받음
- 실제 게임 연동은 내보낸 groups/assets/event_links 처리 코드를 게임 측에 추가해야 함
- AI 음원/영상 생성 API는 포함하지 않음
