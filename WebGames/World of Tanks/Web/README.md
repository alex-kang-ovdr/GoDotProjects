# IRON FRONT · 철의 전선 3.0

장갑 각도, 정찰, 엄폐와 측면 기동을 중심으로 만든 **JavaScript 싱글플레이 2D 전차 전술 게임**입니다. 월드 오브 탱크 역기획에서 출발해 독자적인 전차 수치와 수작업 전장으로 구성한 웹 프로토타입이며, Canvas 2D 그래픽과 Web Audio 효과음을 코드로 생성합니다.

차고에서 전차와 작전을 선택하고, 5 대 5 전투를 마친 뒤 보조 목표·훈장·전적을 확인하는 플레이 흐름을 제공합니다. 기초 사격장과 세 작전은 처음부터 모두 선택할 수 있습니다.

3.0에서는 **표적 고정, 분대 집중 사격, 전술 지도 이동 명령, 지형에 따른 기동 차이**를 추가했습니다. 근접한 차체를 포탄이 건너뛰는 문제와 미발견 잔해가 계속 보이지 않던 문제를 고쳤고, 아군에 막힌 AI가 사격 위치를 옮기도록 보완했습니다.

## 실행

[웹에서 플레이](https://iron-front-tank-ops.taru00.chatgpt.site)

**`dist/iron-front-offline.html`은 내려받아 브라우저로 열면 실행되는 단일 파일 버전**입니다. CSS·아이콘·JavaScript가 포함되어 인터넷 연결이나 Node.js가 필요하지 않습니다. 사이트 차고의 **HTML 내려받기**로도 받을 수 있습니다.

여러 파일로 나뉜 소스를 개발하려면 Node.js 환경에서 프로젝트 폴더를 열고 실행합니다. 외부 패키지 설치는 필요하지 않습니다.

```sh
npm start
```

브라우저에서 `http://localhost:3000`에 접속합니다. 다른 포트는 `PORT=8080 npm start`로 지정합니다. `dist/index.html`은 ES 모듈을 사용하므로 로컬 HTTP 서버에서 실행하고, 정적 호스팅에는 `dist/` 내용을 올립니다.

소스를 수정한 뒤 단일 파일을 다시 생성하려면 다음 명령을 실행합니다. 생성된 HTML은 직접 수정하지 않습니다.

```sh
npm run build:offline
```

## 전투와 전장

플레이어 1명과 아군 AI 4대가 적 AI 5대와 싸웁니다. 선택한 차종에 맞춰 양 팀의 차종 구성과 초기 총 내구도를 맞춥니다. 적 전멸 또는 적 기지 점령으로 승리하며, 최대 6분이 지나면 생존 전차 수를 먼저 비교하고 동수일 때 차량별 잔존 내구도 비율의 합으로 판정합니다. 전황이 같으면 무승부입니다.

| 작전 | 전장 특징 | 보조 목표 2개 |
| --- | --- | --- |
| 메마른 계곡 | 농가·낮은 담장·세 갈래 우회로를 활용하는 기동전 | 피해와 정찰 지원 합계 600 / 생존 귀환 또는 2대 격파 |
| 강철 보급소 | 창고와 적재 구역의 모서리를 이용하는 근접 교전 | 장갑으로 300 방어 또는 900 피해 / 2대 격파 또는 점령 25 기여 |
| 안개 능선 | 바위와 수풀 사이의 정찰·사선 확보·우회 | 정찰 지원 250 또는 직접 피해 900 / 2대 발견 또는 2대 격파 |

**기초 사격장**에는 이동하거나 사격하지 않는 표적 3대가 있습니다. 10m 이동, 표적 명중, 3대 격파를 화면에서 확인하며 연습합니다. 세 표적을 모두 격파하면 수료하고, 제한 시간 내 표적이 남으면 훈련 종료로 처리합니다. 훈련은 작전 전적에 포함하지 않습니다.

R-41 정찰형은 기동과 시야, M-47 기동형은 균형, H-90 중장갑은 정면 방호와 단발 화력에 중점을 둡니다. 차고에는 선택한 전차의 실제 내구도·속도·관통력·정면 장갑 수치가 표시됩니다. 난이도는 적 AI의 반응과 사격 오차에 영향을 줍니다.

### 사격과 장갑

차체와 포탑을 따로 조작합니다. 포탑은 회전 속도 제한이 있으며 이동·포탑 회전 중에는 탄착 분산이 커집니다. 조준점에는 포탑 정렬, 재장전, 사선 차단, 맞게 될 장갑 면과 AP 예상 관통률 또는 HE 예상 폭발 피해를 표시합니다. 1.55배 확대 조준은 화면과 장갑 방향을 더 자세히 확인하는 기능입니다.

AP는 전면·측면·후면 장갑, 입사각, 거리와 관통 편차에 따라 관통·비관통·도탄을 판정합니다. HE는 직격과 주변 폭발 피해를 적용하고 단단한 엄폐물은 폭발을 차폐합니다. **AP와 HE를 바꿀 때마다 새 탄종의 전체 재장전을 시작**합니다. 같은 탄종을 계속 선택해도 장전이 다시 시작되지는 않습니다.

**R 또는 목표 고정 버튼**을 누르면 조준 방향의 발견된 적을 고정합니다. 최대 고정 거리는 127m이며 포탑은 기존 회전 속도로 표적 중심을 따라갑니다. 고정만으로 발사하지는 않습니다. 발사를 누르고 있을 때 포탑 정렬과 엄폐물·아군 사선을 확인한 뒤 사격하며, 표적을 놓치거나 사거리 밖으로 나가거나 격파하면 고정을 해제합니다. 다시 R을 누르거나 터치 조준 스틱을 움직여 자유 조준으로 돌아갑니다. 고정은 이동 표적의 앞을 미리 조준하지 않으며 명중률·관통력·재장전 보너스도 주지 않습니다.

### 지형과 기동

차량 중심이 밟고 있는 지형에 따라 주행 성능이 바뀝니다. 도로는 이동에 유리하고 진흙과 험지는 가속·선회가 둔해집니다. HUD에서 현재 지형과 속도 배율을 확인할 수 있습니다. 아래 값은 평지의 기본 성능을 1로 둔 배율이며 전진·후진 모두 적용됩니다.

| 지형 | 최고 속도 | 가속 | 차체 선회 |
| --- | ---: | ---: | ---: |
| 평지 | 1.00배 | 1.00배 | 1.00배 |
| 도로 | 1.08배 | 1.15배 | 1.00배 |
| 진흙 | 0.64배 | 0.58배 | 0.78배 |
| 험지 | 0.82배 | 0.75배 | 0.88배 |

엔진 손상 배율과 지형 배율은 함께 적용됩니다. 지형은 포탑 회전 속도에 영향을 주지 않으며, 지형을 벗어나면 해당 주행 제한도 해제됩니다. 사격장에는 진흙 구간을 지나며 차이를 익힐 수 있는 표본 지형이 있습니다.

### 시야, 연막과 분대

아군이 발견한 적의 현재 위치를 공유하며, 놓친 적은 마지막 발견 위치와 구분합니다. 수풀은 발견 거리를 줄이고 건물·바위는 관측과 포탄을 막습니다. 플레이어의 정찰 정보로 아군이 가한 피해는 직접 피해와 별도로 **정찰 지원**에 기록됩니다.

연막은 전투당 2회 사용하며 재사용 대기시간은 25초입니다. 7초 동안 관측선을 가리지만 포탄은 통과합니다. 가까운 거리나 다른 아군의 시야에서는 적이 계속 보일 수 있습니다. 연막을 살포한 뒤 엄폐물로 이동해 재장전하거나 이탈할 수 있습니다.

공격·방어·지원·지점 이동 명령은 25초 동안 아군의 이동 목표를 바꿉니다. 지원은 플레이어 주변으로 합류하는 명령입니다. **F 또는 집중 사격 버튼**은 발견한 적을 15초 동안 아군의 우선 표적으로 지정하며 이동 명령을 유지합니다. AI는 시야·사거리·아군과 엄폐물의 사선을 확인하므로 명령 즉시 모든 차량이 발사하는 것은 아닙니다.

AI는 차종에 따라 교전 거리·측면 기동·재장전 중 엄폐를 선택하고, 손상 시 수리하거나 위급할 때 연막을 사용합니다. 아군이 사선을 막으면 좌우의 사격 위치를 찾고 다른 아군이 차지한 엄폐점은 피합니다. 아군 기지가 점령당하는 긴급 상황에서는 기지 방어가 이동 명령보다 우선할 수 있습니다.

격파된 차량의 잔해는 이동·관측·포탄을 막는 엄폐물로 남으며 AI 경로 탐색에 반영됩니다. 보이지 않는 적을 사격해 격파해도 잔해 위치를 즉시 공개하지 않습니다. 아군이 관측해 발견한 잔해는 고정된 전장 정보로 지도에 남습니다.

### 전술 지도

**T, 지도 버튼 또는 미니맵**으로 전장 전체를 엽니다. 지도에서는 전투를 일시 정지하며 아군, 현재 발견한 적, 마지막 발견 위치, 알려진 잔해, 기지와 이동 지점을 구분합니다. 마지막 발견 표시는 현재 위치를 뜻하지 않습니다.

빈 지점을 클릭하거나 터치하면 분대가 해당 위치 주변으로 흩어져 이동합니다. 건물 내부를 선택하면 가까운 안전한 위치로 보정하며, 안전한 위치가 없으면 명령을 거부합니다. 발견된 적을 선택하면 집중 사격을 지시합니다. 명령을 확정하면 전투를 재개합니다. 방향키로 커서를 8m씩, Shift와 함께 16m씩 이동하고 지도에 초점이 있는 상태에서 Enter로 확정할 수도 있습니다. T·Esc 또는 돌아가기 버튼은 명령 없이 지도를 닫습니다.

훈련·출격 대기·플레이어 격파 상태에서는 지형과 전황을 확인할 수 있으며 분대 명령은 사용할 수 없습니다.

### 부품 손상과 수리

| 부품 | 손상 효과 |
| --- | --- |
| 궤도 | 일시적으로 기동 불가 |
| 엔진 | 최고 속도와 가속 성능이 정상의 60%로 감소 |
| 탄약고 | 재장전 시간이 정상의 1.6배로 증가 |

HUD에서 손상 부품과 남은 시간을 확인합니다. **수리 도구는 손상된 모든 부품을 즉시 복구**하며 30초 뒤 다시 사용할 수 있습니다. 내구도는 회복하지 않습니다. 탄약고 복구는 이미 진행한 장전 비율을 유지합니다. 차량이 격파되면 살아 있는 아군을 관전하거나 새 전투를 시작할 수 있습니다.

### 키보드와 마우스

| 입력 | 동작 |
| --- | --- |
| W / S 또는 ↑ / ↓ | 전진 / 후진 |
| A / D 또는 ← / → | 차체 좌 / 우 회전 |
| 마우스 이동 | 포탑 조준 |
| 마우스 왼쪽 버튼 / Space | 주포 발사; 누르고 있으면 재장전 후 계속 발사 |
| 1 / 2 | AP / HE 선택; 변경 시 다시 장전 |
| Shift / 마우스 오른쪽 버튼 | 확대 조준 켜기 / 끄기 |
| R | 발견한 적 목표 고정 / 고정 해제 |
| F | 선택한 적에 15초 집중 사격 지시 |
| T / 미니맵 클릭 | 전술 지도 열기 / 닫기 |
| Q | 연막 살포 |
| E | 손상 부품 수리 |
| Z / X / C | 분대 공격 / 방어 / 지원 명령 |
| Tab | 전투 현황 열기; 전투는 일시 정지 |
| Esc / P | 전투 일시 정지 / 계속; 현황 창에서는 돌아가기 |
| H | 조작 및 전술 지침 열기 / 닫기 |
| M | 음소거 전환 |

열린 모달에서 Tab / Shift+Tab은 버튼 사이의 초점을 이동합니다. 전투 현황 창은 Esc 또는 돌아가기 버튼으로 닫습니다. 다른 탭이나 창으로 이동하면 전투를 일시 정지합니다.

전술 지도에서는 방향키가 지도 커서를 움직이고, Shift가 이동 간격을 두 배로 늘리며, Enter가 선택 지점을 확정합니다. 출격 카운트다운 중 미리 누른 이동·발사 키는 전투가 시작되면 이어서 적용됩니다.

### 터치

왼쪽 스틱은 이동 방향을 지정하고 차체를 회전시킵니다. 오른쪽 스틱은 포탑을 조준하며 충분히 밀면 자동으로 사격합니다. `◎` 버튼으로도 사격할 수 있습니다. 화면의 탄종·수리·연막·확대·고정·집중 사격·지도 버튼과 공격·방어·지원 명령을 사용합니다. 화면 조준점보다 멀리 있는 적도 조준 방향 전체에서 장갑·표적 정보를 확인합니다. 고정한 적은 별도 조준 스틱 입력 없이 추적하고, 오른쪽 스틱을 다시 움직이면 고정을 해제합니다. 가로·세로 방향에 맞춘 HUD와 스크롤 가능한 모달을 제공합니다.

## 작전 기록과 훈장

전투 결과에는 직접 피해·정찰 지원·방어 피해·격파·명중률·작전 점수·보조 목표와 훈장이 표시됩니다. 분대 전적에서 각 차량의 기여를 확인할 수 있으며 전투 중 발견하지 못한 적의 현재 내구도는 숨깁니다. 승리 후 다음 작전으로 이어가거나 같은 전장에서 재도전할 수 있습니다.

금성 훈장은 승리와 보조 목표 2개, 은성 훈장은 승리와 보조 목표 1개로 획득합니다. 패배·무승부라도 보조 목표 2개와 1,500점 이상이면 은성 훈장을 받습니다. 그 외 승리 또는 기여가 있는 전투에는 동성 훈장을 부여합니다. 작전 점수는 피해·지원·방어·격파·발견·점령 기여와 승리·생존 보너스를 반영합니다. 기록과 훈장은 전차의 전투 능력치를 변경하지 않습니다.

전투 수·승률·최고 피해·총 격파, 작전별 최고 점수·훈장, 최근 10개 전투를 현재 브라우저에 저장합니다. 완료된 일반 전투만 한 번 집계하며 훈련과 중도 종료는 제외합니다. 전차·작전·난이도·음소거 선택도 저장합니다. 이전 버전의 전투 수와 최고 피해는 새 기록으로 옮깁니다. **승률은 승패를 확인할 수 있는 작전 기록만으로 계산**하며, 승패가 남아 있지 않은 이전 전투는 총 전투 수에만 포함합니다. 웹 주소와 로컬 파일은 브라우저 저장 영역이 달라 기록이 자동으로 공유되지 않습니다.

## 구현 범위와 소스

이 프로젝트는 직접 실행하고 수정할 수 있는 독립 전술 프로토타입입니다. 전투 판정은 브라우저 안에서 처리하며 원작의 그래픽·모델·실제 전차 데이터에 의존하지 않습니다. 15 대 15 네트워크 대전, 서버 권위 판정, 계정·연구·경제·승무원·매칭 시스템은 구현 범위에 포함하지 않습니다.

| 파일 | 역할 |
| --- | --- |
| `dist/index.html` | 차고·전투 HUD·훈련·결과·전적 모달 |
| `dist/styles.css` | 반응형 레이아웃, 터치 조작, 상태 표시 |
| `dist/v2.css` | v2 작전 선택·추가 HUD·훈련·전적 화면과 모바일 배치 |
| `dist/v3.css` | 목표 카드·고정·집중 사격·지형 표시·전술 지도와 모바일 배치 |
| `dist/js/app.js` | 입력, 고정 간격 게임 루프, UI 상태, 전적 저장 |
| `dist/js/maps.js` | 수작업 전장 3개와 사격장, 도로·진흙·험지 배치와 성능 배율 |
| `dist/js/geometry.js` | 선분·전차·장애물 충돌과 사선 판정 |
| `dist/js/engine.js` | DOM 없는 전투 규칙, 고정·집중·이동 명령, AI, 부품, 연막, 시야·점령 |
| `dist/js/career.js` | 보조 목표·점수·훈장, 전적 정규화와 중복 집계 방지 |
| `dist/js/renderer.js` | Canvas 2D 지형·전차·효과·카메라·미니맵·전술 지도 |
| `dist/js/audio.js` | Web Audio 효과음·엔진 소리 |
| `dist/iron-front-offline.html` | 생성된 단일 HTML 실행 파일 |
| `tests/` | 전투·전적 행동 검증과 3개 전장 완주 시뮬레이션 |
| `tools/serve.mjs` | 의존성 없는 로컬 정적 서버 |
| `tools/build-offline.mjs` | 단일 HTML 생성 및 합친 스크립트 구문 검증 |
| `docs/CORE_GAMEPLAY.md` | 전차 수치, 전투 판정·시야·AI 규칙과 엔진 API의 구현 명세 |
| `docs/VALIDATION.md` | 검증 범위·재현 명령·확인된 결과 |

시뮬레이션은 1/60초 간격으로 진행하고 렌더링은 `requestAnimationFrame`을 사용합니다. 전투·전적 모듈을 입력·렌더링·저장과 분리해 DOM 없이 검증합니다. 저장 접근이 차단되어도 플레이는 계속할 수 있습니다.

수치와 판정 과정, 상태·이벤트 계약을 수정하려면 [코어 게임플레이 구현 명세](docs/CORE_GAMEPLAY.md)를 참고하세요.

## 검증 명령

```sh
npm test
npm run check
npm run build:offline
```

`npm test`는 행동 테스트 48개와 별도 시뮬레이션 파일의 3개 전장 완주를 실행합니다. Node.js 집계에서는 총 49개 테스트입니다. 단일 파일에는 원본 모듈의 최신 변경이 자동으로 반영되지 않으므로 배포·배포용 압축 전에 오프라인 파일을 다시 생성합니다. 실제 검증 결과와 브라우저 확인 상태는 [실행 검증 기록](docs/VALIDATION.md)을 참고하세요.
