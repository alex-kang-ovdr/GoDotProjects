# 원작 검증 매트릭스

| 항목 | 현재 상태 | 검증 방법 |
|---|---|---|
| 10~18세 육성 구조 | 널리 알려진 원작 구조 | 버전별 달력 확인 |
| 월 3슬롯 일정 | 구조 분석 가정 | 원작 UI와 턴 진행 기록 |
| 교육 과목/비용/성장 | 미검증 | 과목별 20회 전후 수치 캡처 |
| 아르바이트 종류/일급 | 미검증 | 직업별 급여·능력치 로그 |
| 능력치·상한 | 일부 구조만 확인 | 화면 및 저장 데이터 대조 |
| 이벤트 조건/우선순위 | 미검증 | 세이브 상태 분기 실험 |
| 무사수행 지역/전투 공식 | 미검증 | 반복 전투 로그·역추정 |
| 엔딩 조건·우선순위 | 미검증 | 임계값 이분 탐색·교차 테스트 |
| 판본 간 차이 | 미검증 | DOS/Refine/Regeneration 구분 |

## 관찰 기록 형식
```json
{"version":"DOS","feature":"education.magic","date":"YYYY-MM-DD","seed":null,"before":{"money":100,"magicSkill":50},"after":{"money":80,"magicSkill":54},"repetitions":1,"confidence":"observed"}
```

- `observed`: 실제 UI·로그에서 관찰됨; `inferred`: 반복 관찰로 추론됨; `proposed`: 독립 구현 제안.
- 관찰 1회만으로 확률적 규칙이나 임계값을 확정하지 않는다.
