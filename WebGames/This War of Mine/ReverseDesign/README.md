이 문서 세트는 개별 게임 규칙을 정리하고, 규칙이 어떤 선택과 결과를 만드는지 분석한다. 인물·자원·시간·공간·위험·심리가 서로 연결되는 지점을 중심으로 작성했다. 각 시스템에는 실제 기능, 설계 해석, 상태와 데이터의 재구성, 사례, 검증 항목과 출처가 들어 있다.

사용자가 제공한 [나무위키 문서](https://namu.wiki/w/This%20War%20of%20Mine)는 직접 접근이 되지 않아 원문 전체를 읽거나 요약했다고 간주하지 않았다. 개발사 공식 자료와 다른 공개 자료로 보완했으며 접근 범위는 [출처 원장](22_Reference_and_Verification_Ledger.md)에 기록했다.

## 먼저 읽을 핵심

**[분석]** 이 게임의 중심 문제는 부족한 물건을 모으는 것과 함께, 그 부족을 해결하는 비용을 누구에게 지울지 결정하는 데 있다.

- **낮과 밤의 연결:** 낮의 회복·생산이 밤의 인력 배분을 바꾸고, 밤의 성과·피해가 다음 날의 선택을 제한한다.
- **인물의 다중 가치:** 운반·제작·거래·전투·경계 특성뿐 아니라 신체와 심리 상태가 역할의 가치를 바꾼다.
- **공유 자원의 경쟁:** 물·연료·재료가 여러 제작 사슬에 쓰여 한 생산을 늘리면 다른 생활 유지가 어려워질 수 있다.
- **두 곳의 위험:** 수색자를 따라가는 직접 조작과 집에 남은 사람들의 방어가 같은 밤에 발생하므로 인물과 장비를 나누어야 한다.
- **상황의 의미:** 같은 물건을 가져와도 버려진 물건의 수집, 거래, 민간인의 물품 절도는 다른 사건이다.
- **장기적인 결과:** 오늘 얻은 이득이 부상·회복·정서 반응을 통해 여러 날의 비용으로 이어질 수 있다.
- **확장별 목표 변화:** 돌봄, 단서, 보도, 문화유산, 기록 회수는 공통 생존 구조 위에 다른 판단 기준을 얹는다.

이 항목들은 여러 문서의 분석을 연결한 요약이다. 개별 규칙의 근거와 예외는 해당 장에서 확인한다.

## 형식과 사용

모든 문서는 UTF-8 Markdown으로 작성했고 같은 폴더의 상대 링크로 연결했다. ZIP을 풀면 이 README에서 각 시스템 문서로 이동할 수 있다. 표는 일반 Markdown 표이며, 다이어그램은 Mermaid 코드 블록이다. Mermaid를 지원하는 Markdown 뷰어에서는 그림으로 보이고, 지원하지 않는 뷰어에서는 코드로 표시된다.

실제 게임 이미지나 대사·레시피 데이터의 전수 복제는 포함하지 않았다. 필요한 규칙을 출처와 함께 요약하고, 의사결정과 시스템 연결은 별도로 분석했다. 문서 속 테스트 표는 검증 계획이며 실제 플레이 테스트 통과 결과가 아니다.
