# 대원의 성장과 휴대 산소

이 문서는 숨 4.0의 실제 구현 규칙을 설명합니다. `dist/frontier.js`가 성장·장비 규칙을 정의하고, `engine.js`와 `community.js`의 실제 작업·생활 처리에 연결합니다. 산소 수치는 이 게임의 내부 단위이며 실제 질량·압력·의료용 산소 용량을 뜻하지 않습니다.

## 1. 설계 목적과 플레이 흐름

기지를 넓히려면 자원이 필요하고, 자원을 얻으려면 대원이 기존의 안전한 생활권을 벗어나야 합니다. 작업 경험은 노동의 효율을 높이고, 휴대 산소는 짧은 저산소 작업을 가능하게 합니다. 두 시스템 모두 실제 생산과 이동을 거쳐 준비됩니다.

1. 기존 기지에서 숨·식사·물·위생·교대 수면을 확보합니다.
2. 대원은 채굴·건설·운반·발전·연구·조리·수확 등 생산적인 작업으로 경험을 쌓습니다.
3. 플레이어가 기술 포인트를 직접 배분합니다.
4. 연구 45를 달성하고 산소 충전소를 설치합니다.
5. 충전소가 주변 산소를 압축하고 대원이 방문해 휴대통으로 옮깁니다.
6. 저산소 지역에서 실제 산소를 소비하며 탐사·작업합니다.
7. 안전한 기지로 돌아와 식사·수면·재충전을 하고 다음 작업을 준비합니다.

휴대 산소만으로 길이 생기거나 건설 재료가 배달되지는 않습니다. 사다리, 돌아오는 통로, 운반 거점과 생활 설비가 여전히 필요합니다.

## 2. 경험과 기술

### 2.1 성장 데이터

| 필드 | 초기값 | 의미 |
|---|---:|---|
| `experience` | 0 | 누적 생산적 작업 경험, 최대 360 |
| `level` | 0 | 경험 60마다 1 상승, 최대 6 |
| `skillPoints` | 0 | 아직 배분하지 않은 포인트 |
| `skills.dig` | 0 | 굴착 기술, 0~3 |
| `skills.engineering` | 0 | 공학 기술, 0~3 |
| `skills.life` | 0 | 생활 기술, 0~3 |

`level = min(6, floor(experience / 60))`이며, **배분한 세 기술의 합 + 남은 포인트 = 숙련 단계**를 유지합니다. 숙련 6에서는 총 6점을 가지므로 모든 기술을 동시에 3단계까지 올릴 수 없습니다. 역할에 맞춰 배분하는 선택이 남습니다.

### 2.2 어떤 행동이 경험을 주는가

경험은 실제로 작업한 시간을 바탕으로 누적됩니다. 이동·대기·생활 필요를 처리하는 모든 시간이 자동으로 경험이 되지는 않습니다.

| 행동 | 경험이 증가하는 시점 |
|---|---|
| 채굴·건설·철거 | 작업 진도가 실제 증가한 구간 |
| 수동 발전 | 대원이 실제 발전기를 가동한 시간 |
| 연구 | 전력과 자원이 공급되어 연구 포인트가 실제 증가한 구간 |
| 조리 | 재료·전력·물이 갖춰져 조리 진도가 증가한 구간 |
| 수확 | 익은 농작물을 실제 수확 작업 중인 구간 |
| 고체 운반 | 실제 물건을 줍거나 입고하는 작업, 각각 기본 작업 시간 0.6에 대응 |
| 휴대 산소 충전 | 실제 전달한 산소량을 전달 속도로 나눈 작업 시간 |

실제 작업 1초에 대응하는 경험을 기본으로 합니다. 완료 직전의 남은 진도만 처리한 경우 그만큼만 계산합니다. 빠른 기술로 작업을 일찍 마치면 노동 시간도 줄어들기 때문에, 같은 한 작업에서 경험까지 중복 증폭하지 않습니다.

전력이 끊긴 연구·조리, 막힌 이동, 빈 충전소, 유휴 상태는 작업 경험을 만들지 않습니다. 자동 발전 시설은 대원의 노동이 아니므로 대원에게 경험을 주지 않습니다.

### 2.3 기술의 실제 효과

| 기술 | 1단계 | 2단계 | 3단계 | 적용 대상 |
|---|---:|---:|---:|---|
| 굴착 | 1.20배 | 1.40배 | 1.60배 | 채굴 작업 속도 |
| 공학: 건설·철거 | 1.15배 | 1.30배 | 1.45배 | 건설·해체 작업 속도 |
| 공학: 연구 | 1.10배 | 1.20배 | 1.30배 | 실제 연구 진도 |
| 생활 | 1.15배 | 1.30배 | 1.45배 | 조리·수확 작업 속도 |

기술은 자원 수확량·조리 산출량을 늘리지 않습니다. 생활 기술이 농장의 생장 시간을 직접 줄이는 것도 아닙니다. 생장 보너스는 별도의 유효한 온실에서 적용합니다.

역할 성향과 기존 스트레스의 작업 효율 효과는 계속 적용됩니다. 수확은 기존 3초 작업에 생활 기술 배율을 적용하며, 별도 스트레스 속도 배율은 적용하지 않습니다. 기술을 높여도 식사·휴식·위생을 생략할 수 없습니다. 역할이나 교대를 바꿔도 배분한 기술은 유지되며, 현재는 기술 초기화나 환불 기능이 없습니다.

### 2.4 조작

대원 탭 → 해당 대원의 **기술**을 누릅니다. 기술 창이 열리면 시간이 멈추고, 현재 숙련·누적 경험·남은 포인트를 확인할 수 있습니다. 배분할 기술의 버튼을 누르면 즉시 1점을 사용합니다. 포인트가 없거나 해당 기술이 3단계이면 버튼이 비활성화됩니다.

창을 닫으면 열기 전의 진행 속도로 돌아갑니다. 기술 배분 성공 시 저장도 수행합니다.

## 3. 산소 충전소

### 3.1 시설 규칙

| 항목 | 값 |
|---|---|
| 연구 해금 | 45 포인트 |
| 건설 비용 | 광석 20, 금속 12 |
| 압축 전력 | 8W |
| 저장 용량 | 산소 18 |
| 최대 압축 속도 | 산소 0.08/게임 초 |
| 공급 범위 | 연결된 인접 공기 경로를 따라 최대 2칸 |
| 공급 셀의 잔량 하한 | 산소 0.35 |
| 대원에게 전달하는 최대 속도 | 산소 1.5/게임 초 |

충전소는 산소를 생성하지 않습니다. 실제 주변 셀에서 산소를 빼고 그 양만큼 시설 안에 저장합니다. 벽과 닫힌 기밀문 너머에서 산소를 끌어오지 않으며 미탐사 셀도 공급원으로 쓰지 않습니다. 공급 셀에 산소가 충분해야 하고, 완공·활성·전력 공급·비침수·허용 온도 조건을 만족해야 압축합니다.

전원이 꺼진 경우 새 압축은 멈추지만, 시설이 활성 상태이고 침수되지 않았다면 이미 저장된 산소를 방문한 대원에게 전달할 수 있습니다. 시설 자체를 수동 정지하면 방문 충전도 중단됩니다. 저장통이 가득 찼을 때 압축을 쉬는 것은 정상 대기 상태입니다.

### 3.2 생산량으로 보는 설치 판단

휴대통 하나의 용량 6을 빈 충전소에서 만드는 데는 이상적인 공급 조건에서도 **75게임 초**가 필요합니다. 저장통 18을 채우는 데는 **225게임 초**가 필요합니다. 실제 대원에게 6을 전달하는 시간은 최대 속도 기준 4초이므로, 압축이 준비되어 있으면 방문은 짧고 준비에는 시간이 걸립니다.

대원 한 명이 휴대 산소를 계속 사용하면 초당 0.055를 소비합니다. 세 명이 계속 사용하면 0.165/초이므로, 충전소 한 대의 최대 0.08/초보다 많습니다. 모든 대원을 계속 저산소 지역에 두기보다 안전한 생활권과 짧은 탐사를 연결하는 편이 공급을 유지하기 쉽습니다. 실제 압축 속도는 주변 산소와 전력 부족으로 더 낮아질 수 있습니다.

### 3.3 대원의 자동 방문

대원의 휴대 산소가 1.5보다 적고, 자동 사용 상태이며, 급한 생활 필요가 없을 때 가까운 사용 가능한 충전소를 찾습니다. 현재 구현은 호흡 70 이상, 포만 48 이상, 기력 24 이상, 용변 70 미만, 위생 65 이상을 요구하고, 정해진 교대를 쓰면 작업 시간에 방문합니다.

자동 방문 대상으로 선택하려면 시설에 실제 저장 산소가 0.55 이상 있어야 합니다. 대원이 충전소 칸까지 이동한 뒤 전달이 시작됩니다. 기지 반대편의 충전소에서 순간적으로 산소를 가져오지 않습니다. 충전소가 비거나 휴대통이 가득 차면 작업을 끝내며, 급한 생활 필요나 경로 단절은 행동을 바꿀 수 있습니다.

## 4. 휴대 산소의 소비

| 항목 | 규칙 |
|---|---|
| 초기 산소 | 0 |
| 휴대 용량 | 대원당 6 |
| 자동 사용 모드 | 호흡하기 어려운 셀에서만 사용 |
| 사용 안 함 모드 | 잔량 보존, 자동 방문 충전·자동 소비 모두 중지 |
| 실제 소비율 | 산소 0.055/게임 초 |
| 가득 찬 휴대통 | 이상적인 연속 소비 기준 약 109초 |
| 일반 공기 | 산소가 0.16보다 많고 물이 0.7보다 적으면 주변 공기로 호흡 |

일반 공기에서 휴대 산소를 소모하지 않습니다. 저산소이거나 물 때문에 주변 공기로 호흡할 수 없으면 자동 모드의 휴대 산소를 사용해 호흡 게이지를 회복합니다. 산소가 떨어지면 기존 호흡 감소와 안전 지역으로의 이동 규칙으로 돌아갑니다.

휴대 산소는 방열복이나 이동 장비가 아닙니다. 고온 피해, 물속 이동 속도, 사다리 필요, 막힌 통로는 그대로 적용됩니다. 화면의 마스크와 휴대통 잔량은 실제 사용 상태에 연결되어 있습니다.

사망한 대원의 남은 산소는 대원 데이터에 보존합니다. 삭제하거나 공용 비축에 자동 추가하지 않습니다. 현재 시체에서 휴대통을 회수하는 플레이 동작은 구현하지 않았습니다. 따라서 전체 장비 보유량과 생존 대원의 예상 호흡 시간은 다를 수 있으며, UI는 예상 시간을 생존 대원 기준으로 계산합니다.

## 5. 수지와 철거

산소는 다음 순서로 이동합니다.

**주변 공기 → 충전소 저장 → 대원 휴대통 → 실제 호흡 소비**

`oxygenCompressed`, `oxygenRefilled`, `portableOxygenUsed`, `protectedSeconds`를 별도로 기록합니다. 정상적인 신규 게임의 이력에는 아래 관계가 성립합니다.

- 휴대통으로 옮긴 산소 = 모든 대원의 잔량 + 휴대 산소 소비량
- 휴대 산소 소비량 = 실제 보호 호흡 시간 × 0.055
- 압축한 산소 ≥ 현재 충전소 잔량 + 지금까지 휴대통으로 옮긴 산소

마지막 관계가 등식이 아닐 수 있는 이유는 충전소 철거입니다. 남은 산소를 주변의 사용 가능한 공기 공간에 실제로 방출한 뒤 철거합니다. 방출 공간이 부족하면 철거를 거부하거나 작업을 대기시켜 저장 산소가 사라지는 것을 막습니다. 범위를 넓히거나 대원이 산소를 가져간 뒤 다시 진행할 수 있습니다.

일반 지형의 모든 변화가 정밀 물질 보존 모델인 것은 아닙니다. 특히 기존 바닥 타일 건설·채굴과 기체 확산은 게임용 근사 규칙입니다. 위 수지 검증은 새 충전·휴대 시스템의 보존을 대상으로 합니다.

## 6. 문제를 찾는 순서

| 관찰 | 확인할 내용 |
|---|---|
| 충전소가 압축하지 않음 | 완공, 활성 상태, 전선, 실제 전력, 주변 산소, 침수, 과열, 저장통 가득 참 |
| 산소는 저장됐는데 대원이 안 옴 | 휴대 잔량, 자동 사용 모드, 급한 식사·용변·위생·휴식, 교대 시간, 실제 도달 경로, 다른 대원의 이용 |
| 휴대통이 줄지 않음 | 현재 주변 공기가 호흡 가능하면 정상. 사용 안 함 모드도 확인 |
| 휴대통이 있어도 건강이 줄어듦 | 고온·굶주림 등 다른 피해는 별도 처리. 휴대 산소는 모든 위험을 막지 않음 |
| 경험이 오르지 않음 | 이동·대기인지 실제 생산인지, 작업 자원·전력, 최대 경험 360 도달 여부 |
| 포인트가 있는데 버튼이 꺼짐 | 해당 기술의 3단계 도달 여부, 대원의 생존 상태 |
| 확장 점수가 오르지 않음 | 기술 포인트 획득 후 실제 배분 여부, 휴대통 보유가 아닌 실제 저산소 호흡 30초 달성 여부 |

## 7. 저장과 이행

v4는 휴대 산소·경험·기술·충전 중 작업과 실제 생산 누계를 저장합니다. 불러올 때 범위·열거형·대원과 설비 ID·기술 포인트 합계·산소 수지·방 구조·목표와 승리 상태를 검증합니다. 실패하면 현재 기지와 입력 객체를 변경하지 않습니다.

v1·v2·v3 저장에서 이어오면 기존 기지의 자원·시설·진행은 보존하고, 새 경험·기술·휴대 산소는 0에서 시작합니다. 과거 노동 시간을 추정해 경험을 소급 지급하거나 빈 충전소에 산소를 만들지 않습니다. 이미 끝낸 기존 목표는 달성 이력으로 유지하며, 새 목표까지 완료해야 4.0 최종 승리가 됩니다.
