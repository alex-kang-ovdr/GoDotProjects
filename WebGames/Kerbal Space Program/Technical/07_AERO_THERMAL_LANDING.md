# 공기역학·열·재진입·착륙

> KSP 1 (1.12.x) 관찰 기반 역설계 + 독립 재구현 기술 제안. 아래 코드/내부 자료구조는 원작 소스의 복원이 아니다. SI 단위 사용(별도 표기 제외).

## 1. 대기 모델
천체별 `ρ(h)`, `p(h)`, `T(h)`, 음속 `a(h)`을 데이터 곡선으로 정의. 단순 지수 모델 `ρ=ρ0 exp(-h/H)`는 MVP용이며 원작의 대기 곡선과 동일하다고 보지 않는다.

## 2. 공력
상대풍 `v_air = v_ship - (ω_body×r) - v_wind` (천체 중심 기준). 동압 `q=0.5ρ|v_air|²`.
- 항력 `F_D=-q C_D A normalize(v_air)`.
- 양력 `F_L=q C_L A liftDirection`.
- 부품별 공력 중심에서 힘을 적용해 `τ=(p-COM)×F`를 계산.
- Mach, AoA, 전개된 조종면, 차폐/페어링 상태를 반영.

## 3. 열
부품 온도 상태를 내부/표면 2노드로 단순화 가능:
`C_s dT_s/dt=Q_aero+Q_solar-Q_radiation-Q_conduction`,
`C_i dT_i/dt=Q_conduction-Q_internal`.
복사 `Q_rad=εσA(T⁴-T_env⁴)`. 공력 가열은 속도·대기밀도·형상에 따라 별도 경험식을 조정하며, `q`(동압)만으로 가열을 결정하지 않는다.

## 4. 낙하산과 착륙
낙하산: `Packed -> Armed -> SemiDeployed -> FullyDeployed -> Cut`; 압력/고도/속도/안전 조건을 검증. 전개 중 CdA를 시간에 따라 증가시키고 부품에 작용점을 갖는 힘으로 적용.
착륙다리: 지면 접촉, 서스펜션, 마찰, 충격 손상, 안정적인 landed 판정. 착륙 상태 판정은 수직속도만이 아니라 접촉 지속시간, 기체 선속도·각속도, 지면 근접을 함께 사용.

## 5. 테스트
- 진공에서 공력/공력 가열 0
- 해수면과 고도 변화에 따른 q 곡선
- AoA 부호 반전 시 양력 방향 반전
- 열복사 냉각 시 온도 발산 없음
- 지면 착륙 후 휴면 상태에서 침투/튐 없음
