# Dark Descent VIII — Web ARPG

단일 HTML5 Canvas + JavaScript 게임. `index.html`을 Chrome/Edge에서 열면 실행됩니다.

## v8 변경사항
- 패시브 스킬 트리: 전투 숙련 / 강인함 / 행운, 각각 5단계
- 행운 패시브에 따른 마법·레어 장비 출현 확률 증가
- 정예 몬스터 신규 속성: 폭발형(사망 후 범위 폭발), 빙결형(이동 감속)
- 보스 광역 공격 경고 표시와 지연 폭발 판정
- 층 이동 시 현상금 진행도 초기화 오류 수정
- v7 저장 데이터 불러오기 마이그레이션 (v8 저장 슬롯으로 저장)

## 조작
WASD 이동, 마우스 조준/이동, 1~5 스킬, Space 돌진, Q/R 물약, E 줍기, F 계단, G 성소, P 일시정지.
