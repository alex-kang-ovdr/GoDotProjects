# First Queen IV · Field Command v14

다중 군단 전략 맵 + 실시간 부대 전투 + 선택 병사 직접 조작을 연결한 독립 프로토타입입니다.
퍼스트 퀸 4에서 영감을 받았지만 원작의 코드·아트·음원·전체 시나리오를 사용하거나 복원한 완성 게임은 아닙니다. 능력치·기술·경제·이벤트 규칙은 자체 설계입니다.

## 실행

`index.html`을 다운로드한 뒤 Chrome 또는 Edge에서 엽니다. 전체 게임 코드가 한 HTML 안에 포함되어 있습니다. npm, 서버, 외부 라이브러리, CDN, 계정, 인터넷 연결이 필요하지 않습니다.

채팅의 HTML 링크는 공개 웹 호스팅 주소가 아닙니다. 파일을 받은 후 브라우저로 여세요. ZIP에는 단일 실행 HTML 외에 편집 가능한 소스, 빌드 스크립트, 테스트와 결과가 포함되어 있습니다.

WebGL 컨텍스트를 생성할 수 있으면 GPU 3D 렌더러를 사용합니다. 사용할 수 없는 경우 같은 장면과 카메라를 Canvas로 투영하는 **CPU 3D 호환 모드**로 전환합니다. 화면 상단에 실제 렌더링 모드가 표시됩니다. 2D 전술 화면도 선택할 수 있습니다.

## 먼저 해볼 것

1. **공성 연습**을 누릅니다. 연습에서는 사망·성장·성문 파괴가 캠페인에 반영되지 않습니다.
2. 오른쪽에서 **카리온 주력군 → G 공성**, **예비 지원대 → 3 방어**를 각각 선택합니다. 서로 다른 명령이 유지됩니다. 지원대는 3초 후 도착합니다.
3. 병사를 클릭하고 WASD로 직접 움직입니다. 카메라를 회전해도 W는 화면 위쪽입니다. Space는 공격, F는 병종별 스킬입니다.
4. 우클릭으로 선택 부대의 이동 지점을 정합니다. `명령을 전군에 적용`을 켜면 모든 아군 부대에 적용합니다.
5. 캠페인에서는 군단 분할·편성·독립 이동과 인접 군단 지원을 사용합니다. 전투 후 결과표에서 각 부대의 생존·전사·철수를 확인합니다.

## v14 변경점

### 독립 부대 지휘
- 공격 / 방어 / 집결 / 후퇴 / 이동 / 공성 / 돌격 명령을 부대별로 보관합니다.
- 횡대 / 종대 / 쐐기 / 산개 목표 배치가 선택 부대에 적용됩니다.
- 우클릭은 선택 부대에 이동 명령을 내립니다. 전체 명령은 별도 체크박스입니다.
- 예비군과 지원 군단은 지연 도착하며, 중복 투입할 수 없습니다.

### 직접 조작 및 3D
- 클릭 / Q·E 병사 선택, Tab 부대 선택.
- WASD는 카메라 회전 방향을 고려합니다. 움직임 또는 Space 입력 시 직접 조작으로 전환합니다. 자동 전투 버튼으로 AI에 돌려줄 수 있습니다.
- 병종별 무기·방패·지팡이와 보행·공격·피격·쓰러짐의 절차적 애니메이션.
- 화면과 HUD 크기를 하나의 전장 컨테이너에 맞췄습니다. 회전·줌·클릭 좌표가 동일한 카메라 수학을 사용합니다.
- WebGL은 지원 시 ANGLE instancing으로 박스 메시를 묶어 그립니다. 미지원 환경은 일반 드로우, WebGL 자체가 없으면 CPU 투영으로 대체합니다.
- CPU 호환 3D는 대규모 전투에서 느릴 수 있습니다. 필요하면 2D로 전환하세요.

### 병종별 스킬 — F
| 병종 | 기술 | 효과 |
|---|---|---|
| 보병 | 방패 결속 | 소속 부대에 8초간 받는 피해 35% 감소 |
| 기사 | 회전 베기 | 반경 65 안의 적에게 범위 피해. 벽 너머는 제외 |
| 궁수 | 일제사격 | 사선 안의 최대 5명에게 투사체 발사 |
| 치료사 | 치유 파동 | 반경 145 안의 부상 아군 회복 |

고유 스킬 대기시간은 병사별 14초입니다. 별도의 H 전술 회복은 전투 공용 16초 대기시간입니다. 해당 수치는 원작 고증 값이 아닙니다.

### 공성 / AI / 전투 결과
- 닫힌 성문은 통과할 수 없으며, 병사 자신의 공격 준비와 타격 시점에 내구도가 감소합니다. 버튼 클릭만으로 성문에 피해를 주는 일반 기능은 제거했습니다.
- 성문 파괴 즉시 충돌과 A* 경로를 갱신합니다. 개발자 옵션에만 성문 개폐가 있습니다. 파괴된 문을 닫거나 병사가 통로에 있을 때 닫을 수 없습니다.
- 모든 참가 병사에 원래 군단·예비군·적 군단·수비대 소속을 기록합니다. 전투 중 원본 캠페인 병력 배열을 잘라 옮기지 않습니다.
- 전투 결과는 복사된 상태에 적용한 뒤 무결성 검사에 성공하면 한 번만 반영합니다.
- 사망자는 제거·기록되고 생존자와 철수자는 원래 소속으로 돌아갑니다. 아직 도착하지 않은 지원군은 그대로 보존합니다.
- 방어전은 진입만으로 소유권을 변경하지 않습니다. 패배하면 함락되며 생존자는 인접 아군 거점으로 이동합니다. 안전 거점이 없으면 포로 손실로 기록합니다.

### 전략 및 경제
- 최대 5개 군단, 군단당 40명, 예비군 최대 120명.
- 적 군단은 전략 턴에 이동·후퇴·보충합니다. 무주둔 아군 거점을 점령할 수 있고, 병력이 주둔한 곳에서는 방어전이 필요합니다.
- 수동 턴 또는 자동 18초 / 턴. 자동 진행은 전략 맵에서만 동작하며 대화창이 열려 있을 때 멈춥니다.
- 고용 6명은 금화 60, 휴식은 1턴을 소비합니다. 아군 거점은 턴마다 수입을 제공하고 실제 전투 승리 시 보상이 지급됩니다.
- 훈련에서는 경제와 캠페인 손실이 발생하지 않습니다.

## 조작

| 입력 | 기능 |
|---|---|
| WASD | 선택 병사 직접 이동, 3D에서는 카메라 기준 |
| Space | 사거리 내 기본 공격 / 근접 성문 공격 |
| 클릭, Q / E | 병사 선택 / 이전·다음 선택 |
| Tab | 지휘 부대 변경 |
| 우클릭 | 선택 부대 이동 지점 |
| 1 / 2 / 3 / 4 | 공격 / 집결 / 방어 / 후퇴 |
| F / H / G | 병종 스킬 / 전술 회복 / 공성 |
| P | 일시정지 / 재개 |
| 드래그 / 휠 | 카메라 회전 / 줌 |

일시정지 중에는 시간·투사체·회복·스킬 재사용 대기가 멈춥니다. 부대 명령은 미리 바꿀 수 있습니다. 브라우저 포커스를 잃으면 전투를 자동 일시정지하고 눌린 키를 해제합니다. 입력창과 대화창에서는 게임 단축키를 가로채지 않습니다.

## 저장과 v13 호환

전략 맵에서만 저장할 수 있습니다. 로컬 저장 키는 `fq4_proto_v14`입니다. 브라우저 설정이나 파일 실행 환경에서 localStorage가 제한되면 JSON 내보내기 / 가져오기를 사용하세요.

v14 JSON 왕복 복원을 검증했습니다. v13 JSON 및 구형 `{world, uid}` 형식을 읽는 마이그레이션도 포함되어 있습니다. 기존 아군의 ID·레벨·경험치·HP·피로·군단 위치를 보존하고, `world.armies`를 기준으로 활성 군단을 복구합니다. 중복 미러 필드 `world.roster`를 다시 합치지 않습니다.

v13에 없던 상주 수비대의 개별 병사 데이터, 경제 및 전투 이력은 새로 초기화합니다. 기존 적 군단의 병력 수와 위치는 새 병사 목록으로 변환합니다. 손상되거나 실제 중복 ID가 있는 이전 저장은 거절하며, 현재 캠페인을 변경하지 않습니다. v14 파일을 v13으로 역변환하는 기능은 없습니다.

## 검증

`TEST_REPORT.md`와 `tests/*-results.json`에 수행 범위와 제한을 기록했습니다.

- 엔진 테스트 **34개 통과**.
- 실제 Chromium에서 UI·조작 통합 테스트 **19개 통과**.
- 브라우저 실행 중 수집한 pageerror / console error **0건**.
- JSON 파일 다운로드·업로드 복원, 카메라 4방향 W 입력, 3D 클릭·우클릭, 2D/3D 전환, 모바일 가로 넘침을 확인했습니다.

**환경 제한:** 테스트용 Chromium에서 WebGL 컨텍스트를 만들 수 없어 시각/조작 테스트는 CPU 3D 호환 모드와 2D로 수행했습니다. WebGL 셰이더·GPU 실행을 실제 하드웨어에서 검증한 것은 아닙니다. 또한 테스트 환경에서 file/localhost 탐색이 차단되어 HTML을 `set_content`로 주입했습니다. 실제 file://에서의 브라우저별 로컬 저장 영속성은 확인하지 못했으며, JSON 내보내기·가져오기는 실제 파일 입력과 다운로드로 검증했습니다. `preview-v14.png`는 CPU 3D 호환 모드의 실제 실행 화면입니다.

## 소스와 테스트 실행

```
index.html                단일 파일 실행본
src/engine.js             전투·전략·저장 상태와 규칙
src/renderer.js           WebGL / CPU 3D / 2D / HUD
src/ui.js                 UI, 입력, 저장 파일 입출력
src/style.css             반응형 화면
src/layout.html           HTML 템플릿
build.py                  소스를 단일 HTML로 묶기
preview-v14.png            실제 실행 미리보기
TEST_REPORT.md             검증 범위와 결과
CHANGELOG.md               버전 변경 요약
```

게임 실행에는 개발 도구가 필요 없습니다. 소스를 수정하는 개발자는 아래 명령을 사용할 수 있습니다.

```
python build.py
node tests/engine.test.cjs --report
python tests/browser.test.py
```

브라우저 테스트에는 Playwright Python 패키지와 Chromium이 별도로 필요합니다. 기본 실행 경로는 `/usr/bin/chromium`이며 `CHROMIUM_PATH` 환경변수로 변경할 수 있습니다.

## 남아 있는 범위

완전한 원작 캠페인, 고증된 인물·장비·대사, 스켈레탈 애니메이션, 높이 있는 전투 공간·성벽 위 병사, 3D 강체 물리, 네트워크 멀티플레이, 전투 중 저장은 미구현입니다. 진형은 목표 위치와 충돌 회피를 조합한 방식이며, 복잡한 전선에서 항상 대형을 완벽하게 유지하는 것은 아닙니다. 자동 테스트 통과가 모든 플레이 상황과 하드웨어의 무결함을 보장하지는 않습니다.
