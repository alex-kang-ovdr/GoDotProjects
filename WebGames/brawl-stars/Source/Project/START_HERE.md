## 구성

- **PLAY.html**: 최신 독립 실행 게임. 필요한 코드가 한 파일에 포함되어 있습니다.
- **game/**: 게임 소스, 실행 문서, 테스트. 소스 형태로 실행하려면 **game/dist/index.html**을 여세요.
- **reverse_design/**: 시스템·모드별 원본 역기획 Markdown 문서 **80개**. 먼저 **reverse_design/README.md**를 확인하세요.

게임은 **젬 그랩·쇼다운·브롤 볼·핫 존·하이스트·녹아웃·바운티의 경쟁 모드 7개와 연습장**, 그리고 **핀·브릭·코멧의 영웅 3명**을 제공합니다. 상대와 팀원은 로컬 봇이며 온라인 멀티플레이는 포함하지 않습니다.

역기획 문서 80개는 원작의 폭넓은 시스템과 모드를 분석한 자료입니다. 실행 게임은 그중 선택한 핵심 상호작용을 독자 캐릭터와 자체 수치로 구현한 프로토타입이며, 문서에 분석된 모든 기능을 구현했다는 뜻은 아닙니다. 각 모드의 실제 구현 규칙은 **game/CONTRACT.md**와 **game/docs/**를 참조하세요.

## 소스와 테스트

Node.js가 설치되어 있다면 터미널에서 **game** 디렉터리로 이동한 뒤 다음 명령으로 테스트를 실행할 수 있습니다.

```sh
node --test tests/*.cjs
```

조작 방법과 상세 실행 안내는 **game/README.md**에 있습니다. 이번 ZIP 작업에서는 게임을 변경하거나 테스트를 재실행하지 않았습니다.
