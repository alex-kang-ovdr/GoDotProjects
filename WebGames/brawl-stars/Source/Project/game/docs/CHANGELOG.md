# 변경 기록

## 4.0.0

녹아웃과 바운티를 추가해 **일곱 가지 경기 모드와 연습장**을 제공합니다. 녹아웃은 개인 탈락부터 아군 관전·라운드 재시작·최종 경기 결과까지, 바운티는 누적 별·개인 현상금·블루 스타의 소유권과 동점 판정까지 구현합니다. 세 영웅, 가젯, 추적 카메라와 기존 모드의 규칙은 유지합니다.

### 녹아웃과 관전

녹아웃은 한 라운드에서 부활하지 않는 3 대 3 경기이며 두 라운드를 먼저 이기면 승리합니다. 플레이어가 먼저 쓰러져도 경기를 계속하고 살아 있는 아군을 관전합니다. Tab 또는 다음 아군 버튼으로 대상을 바꾸며, 대상이 쓰러지면 다른 생존 아군으로 자동 전환합니다. 다음 라운드에 플레이어가 부활하면 직접 조작으로 복귀합니다.

라운드 결과는 경기 전체 결과와 분리합니다. 승리·패배·동시 전멸·시간 초과를 설명하고 2.4초의 다음 라운드 카운트다운을 표시합니다. 라운드만 끝났을 때는 완료 경기 수를 늘리지 않습니다. 최종 경기 종료에서만 결과 창과 전적을 한 번 처리합니다.

상단에는 라운드 승수, 현재 라운드 번호·남은 시간과 양 팀의 생존 인원을 표시합니다. 전체 경기 제한이 라운드 제한보다 먼저 오면 시계와 목표 문구를 전체 한도에 맞춥니다. 사망과 라운드 경계에서는 유지 중인 키·터치와 대기 중인 스킬 입력을 해제해 다음 생명에 공격이 남지 않게 합니다.

관전 시야는 살아 있는 아군의 합집합이며 플레이어 시체는 관찰자로 사용하지 않습니다. 렌더러는 `focusId`로 유효한 생존 아군을 추적하고, 잘못된 대상은 다른 생존 아군으로 대체합니다. 아군이 없으면 전체 전장으로 돌아갑니다. 초점을 바꾸어도 플레이어 팀과 적의 숨김 규칙은 그대로입니다. 사망한 플레이어의 조준선은 그리지 않습니다.

### 바운티의 점수와 소유권

팀 점수는 유효한 처치로 얻은 별의 누계입니다. 개인 현상금은 다음에 자신을 처치한 상대가 받을 값이며 팀 점수와 별개입니다. 처치 알림에 획득한 별을 표시하고, 전황표에는 개인 획득 별과 자신의 사망으로 상대에게 허용한 별을 따로 기록합니다.

같은 내부 스텝의 처치는 피해 처리 전 현상금으로 함께 정산합니다. 상호 처치의 배열 순서를 뒤집어도 지급액이 바뀌지 않습니다. 처치자도 사망했으면 팀 점수와 획득 별은 얻지만 개인 현상금은 초기값으로 남습니다. 유효한 적 처치자가 없는 사망에는 별을 지급하지 않습니다.

블루 스타는 화면에서 ‘파란 별’로 표시합니다. 최초 수집만 일반 점수 1점을 주고 이후 소유권은 동률 판정에 사용합니다. 소유자 사망 시 유효한 적 처치자에게 한 번 양도하거나 사망 지점에 떨어뜨립니다. 같은 스텝에 새 소유자도 사망한 경우 그 액터의 부활까지 소유권을 유지하며, 그 스텝 안에서 다시 연쇄 양도하지 않습니다.

상단에는 소유 팀을 공개하지만 숨은 운반자의 위치를 별도 아이콘으로 보여 주지 않습니다. 전장과 미니맵에는 땅에 놓인 별만 공개 목표로 표시하고, 운반 중인 별은 보이는 생존 캐릭터의 소유 배지로 표현합니다.

모드별 실제 런타임 명세는 [KNOCKOUT.md](KNOCKOUT.md), [BOUNTY.md](BOUNTY.md)에 제공합니다. 전체 API·데이터·카메라 규약은 [CONTRACT.md](../CONTRACT.md), 실행과 조작은 [README.md](../README.md)를 참조하세요.

### 검증 결과와 한계

고정된 코드로 `node --test tests/*.cjs`를 실행해 **106개 통과, 실패·취소·스킵 0개**를 확인했습니다. 엔진 82개와 앱 24개이며 기존 80개 사례를 모두 보존했습니다. v4 추가분은 엔진 20개와 앱 6개입니다.

엔진 검증은 라운드 중 부활 금지·플레이어 사망 후 지속, 휴식과 재시작의 복원·보존, 생존 기여, 탄환 순서·독에 의한 동시 전멸, 75초·240초 시간 판정, 살아 있는 아군 시야를 포함합니다. 바운티는 현상금 상한·사망 리셋·상호 처치·환경 사망, 최초 보너스·재수집·낙하·단일 양도·죽은 소유자, 동시 20점·120초의 점수와 블루 소유권을 검사합니다. 두 모드와 세 영웅의 실제 봇 경기를 끝까지 진행하고 같은 시드·입력의 전체 상태 재현과 유한 숫자를 확인합니다.

앱 검증은 두 모드 선택·시작, 관전 대상 순환·사망 시 대체·전멸과 부활 복귀, 라운드 HUD와 전체 제한 우선 시계, 최종 경기만 한 번 기록하는 흐름, 사망·라운드 경계의 터치/키 초기화, 바운티 목표·전황·처치 별 표시를 확인합니다. 실제 `app.js`와 `engine.js`를 Node VM에서 실행하고 작은 DOM·Renderer·Audio 대체 구현을 사용합니다. 공개 투사체 fixture로 라운드 전환을 만들며, 이 사례와 자연 봇 경기 전체 시뮬레이션을 구분합니다.

렌더러는 녹아웃·바운티 × 세 영웅 × 전체/추적 카메라의 **12조합을 네이티브 Canvas에서 별도 확인**했습니다. 관전 `focusId`의 유효 대상·대체·복귀, 로컬 팀 유지, 사망 조준 제외, 화면/월드 좌표 왕복과 CSS 크기 변경, 상태 비변경, 모바일 DPR 2, 효과 축소를 검사했습니다. 숨었거나 죽은 블루 스타 소유자의 위치·현상금과 별 좌표를 바꾸어도 전체 이미지 픽셀이 달라지지 않는 검증과 지상 별의 표시도 포함합니다. 실제 관전·별 소유·모바일 PNG를 열어 가독성을 확인했습니다.

## 3.0.0

핫 존과 하이스트를 추가해 **다섯 가지 경기 모드와 연습장**을 제공합니다. 세 영웅과 기존 가젯·연장전·전황·터치 입력은 유지합니다. 단일 HTML과 소스 ZIP의 파일명, 외부 의존성 없는 실행 방식도 유지합니다.

### 새 모드와 목표 정보

- **핫 존:** A·B 두 구역을 채우는 3 대 3 경기입니다. 양 팀이 같은 구역에서 독립적으로 진척하며 같은 팀 인원이 늘어도 점령 속도는 늘지 않습니다. 완료한 구역에서는 자신의 추가 기여를 멈추고 다음 목표로 이동합니다.
- **하이스트:** 각 팀의 금고를 지키며 상대 금고를 파괴합니다. 금고 체력의 세 경계에서 한 번씩 보호막을 발동하고, 단일 공격의 초과 피해로 여러 단계를 건너뛰지 않게 처리합니다.
- **목표 HUD와 전황:** 핫 존의 구역별 진척·동시 점유, 금고의 체력·보호막을 표시합니다. 점유 시간과 실제 금고 피해를 전투 피해와 별도로 기록합니다. 금고 파괴를 캐릭터 처치로 세지 않습니다.
- **종료 원인:** 양 팀의 동시 완료·동시 금고 파괴와 정밀 시간 종료 판정을 구분합니다. 우리 금고 파괴 패배를 상대 금고 파괴 승리처럼 설명하던 결과 문구를 바로잡았습니다.

모드별 실제 런타임 명세는 [HOT_ZONE.md](HOT_ZONE.md), [HEIST.md](HEIST.md)에 나누어 제공합니다. API와 데이터 규약은 [CONTRACT.md](../CONTRACT.md)에 통합했습니다.

### 카메라와 입력

전체 보기와 1.5배 캐릭터 추적 보기를 C·상단 버튼·도움말에서 전환합니다. 데스크톱은 전체 보기, 터치 기기는 추적 보기가 기본이며 저장한 선택을 우선합니다. 로비는 항상 전체 전장을 보여 줍니다.

추적 카메라는 월드 경계 안으로 제한하고 지형·고정 목표·자신·아군을 보여 주는 미니맵을 제공합니다. 적이나 공 위치를 미니맵 마커로 노출하지 않습니다. 화면 포인터를 매 프레임·입력 시점에 다시 월드 좌표로 변환해, 마우스가 멈춘 상태에서 카메라가 이동해도 예전 월드 조준점에 고정되지 않게 했습니다. 터치 조준은 플레이어 기준 상대 방향을 유지합니다.

렌더러에 `camera: 'overview' | 'follow'`, 선택적 `minimap: false`, 클라이언트 CSS 좌표를 반환하는 `worldToScreen`을 추가했습니다. `screenToWorld`는 마지막 실제 렌더 변환을 사용합니다. CSS 크기·위치 변경과 DPR 제한을 함께 처리합니다. 세로 모바일의 목표 표시와 경고 배치도 미니맵과 구분되도록 조정했습니다.

`node --test tests/*.cjs` 전체 실행에서 **80개 통과, 0개 실패**를 확인했습니다. 엔진 62개와 앱 18개이며 기존 54개 사례를 유지했습니다. 추가된 20개 엔진 사례는 동시 점유·속도 비중첩·무적과 사망·완료 구역·부분 프레임·보호막 초과 피해·아군 금고 피해 제외·동시 파괴·정밀 종료·안전한 시작 위치와 두 모드의 정상 진행을 검증합니다. 추가된 앱 6개 사례는 두 모드 시작, HUD와 목표 기여, 카메라 선택·저장 및 좌표 재조회 연결을 확인합니다.

핫 존·하이스트 × 세 영웅 × 두 카메라의 **12조합을 네이티브 Canvas에서 별도 확인**했습니다. 상태 비변경, 월드/화면 좌표 왕복, 경계 제한, CSS만 크기·위치를 바꾼 경우의 변환, DPR 2 제한을 검사했습니다. 숨은 적과 그 적이 소유한 공의 위치를 바꿔도 이미지 픽셀이 변하지 않는 검증도 포함합니다.

앱 테스트는 실제 `app.js`·`engine.js`와 작은 DOM·Renderer·Audio 대체 구현을 사용합니다. 카메라 앱 사례는 변환을 다시 조회하는 연결을 검증하며 실제 카메라 수학과 화면 출력은 별도 Canvas 검증에 속합니다. 실제 브라우저의 전체 배치·네이티브 포인터 캡처와 이벤트 전파·실음원·터치 실기기 사용감은 미확인입니다. 이 한계를 자동 테스트 통과와 구분합니다.

## 2.0.0

기존 세 가지 봇 대전 위에 영웅별 가젯, 자유 연습장, 브롤 볼 연장전과 전황 정보를 추가했습니다. 실행 방식은 그대로입니다. `dist/index.html` 또는 단일 배포본 `dist/Brawl_Lab_Offline.html`을 열면 되며, 패키지 설치나 게임 서버가 필요하지 않습니다.

### 추가한 기능

- **가젯 세 종류:** 핀의 퀵 스텝은 짧은 이동과 탄약 보충, 브릭의 아이언 가드는 일시 피해 감소, 코멧의 중력장은 범위 피해와 감속을 제공합니다. Q·Shift 또는 터치 버튼으로 사용합니다.
- **연습장:** 공격하지 않는 표적 세 개, 빠른 재생성, 슈퍼와 가젯의 빠른 준비를 제공합니다. 시간 제한과 승패 기록이 없으며 R 또는 초기화 버튼으로 다시 시작합니다.
- **브롤 볼 연장전:** 정규 시간 동점에서 남은 엄폐물·수풀을 제거하고, 다음 골로 승부를 정하는 45초 연장전에 들어갑니다.
- **전황표와 최근 처치:** 경기 중 T를 누르면 전투를 멈추고 K/D/A·피해·목표 기여를 확인합니다. 결과에도 전황표를 표시하고 전장에는 최근 처치 세 개를 보여 줍니다.
- **터치 조작:** 기존 스틱 외에 전장의 빈 왼쪽·오른쪽에서 이동·조준을 시작할 수 있습니다. 두 포인터를 독립적으로 추적하고, 조준 스틱의 짧은 탭은 자동 조준 공격으로 처리합니다.
- **저장되는 설정:** 조준 가이드, 효과 줄이기, 지원 기기의 진동, 팁 표시와 소리 설정을 보관합니다. 팁을 닫거나 도움말에서 다시 켤 수 있습니다.

### 전투 판정과 표현

자동 조준은 보이는 적 중 사거리와 사선 조건을 만족하는 대상을 찾습니다. 공 소유자는 골문을, 쇼다운에서는 적을 찾을 수 없을 때 접근 가능한 파워 상자를 대상으로 삼습니다. 상대의 숨겨진 위치를 자동 조준 결과로 노출하지 않습니다.

발사 시 캐릭터 중심에서 총구까지도 충돌을 검사해, 벽에 붙었을 때 탄환이 엄폐물 너머에서 시작하는 문제를 막습니다. 관통 슈퍼와 폭발탄의 성격은 유지합니다. 공의 골 판정은 이동 경로가 골라인을 실제로 통과하는 위치를 확인합니다.

중력장·방어막·감속을 별도로 표현하고, 조준 가이드는 첫 엄폐물에서 끝납니다. 연장전의 경기장 표현과 연습장 표적을 추가했습니다. 가이드는 첫 이동 구간을 설명하며 공의 이후 반사 경로 전체를 예측하지는 않습니다. 장치 픽셀 비율은 최대 2로 제한하고, 효과 줄이기 설정에서도 전투 판단에 필요한 상태 표시는 유지합니다.

### 검증과 유지 사항

기존 21개 엔진 회귀 사례를 유지하고 `tests/engine-v2.test.cjs`에 새 기능 검증을 추가했습니다. 기존 골 테스트는 골라인 밖에 공을 놓는 대신 경기장 안에서 라인을 실제로 통과하도록 시작 좌표와 속도를 바꿨습니다. 득점·초기화·승리 조건의 단언은 유지했습니다.

**엔진 42개·앱 12개, 총 54개 검증 사례가 각각 통과했습니다.** 엔진 테스트는 가젯, 차폐, 자동 조준, 연습장, 연장전, 통계 귀속과 여러 모드·영웅의 결정성·유한 숫자를 검사합니다.

앱 테스트는 실제 `app.js`와 `engine.js`를 Node VM에 불러오고 DOM·Renderer·Audio에 작은 대체 구현을 사용합니다. 네 모드의 선택·시작, 일시정지 입력 해제, 전황창 정지·복귀, R 초기화와 반복 억제, Q 입력 경계, 두 터치의 독립적인 취소, 저장된 설정 우선 적용, 훈련 전적 제외와 일반전의 1회 기록을 확인합니다. 전적 검증은 공개 종료 상태를 구성하는 사례이며 자연 경기 종료 재현으로 계산하지 않습니다.

렌더러는 네이티브 Canvas에서 네 모드·세 영웅, 입력 상태의 비변경, 숨은 적 생략, 조준 끝점과 픽셀 비율 제한을 별도로 확인했습니다. 실제 브라우저 배치·포인터 캡처와 이벤트 전파·실음원·터치 실기기 사용감은 미확인입니다. 자동 검증과 네이티브 Canvas 확인을 브라우저 플레이 검증으로 합산하지 않습니다.

외부 의존성 없는 스크립트 구성과 고정 시드 엔진을 유지합니다. 네트워크 대전, 계정·클럽, 구매, 장기 성장 경제는 이번 버전에 추가하지 않았습니다.
