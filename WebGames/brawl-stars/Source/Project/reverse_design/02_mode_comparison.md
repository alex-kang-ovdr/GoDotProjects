# 모드별 비교 매트릭스

> 아래 표의 자산·사망 비용·의사결정은 [해석]이다. 인원·점수·타이머의 정확한 규칙은 연결 문서의 근거 표를 따른다.
> 분류는 읽기 편한 분석용 그룹이며 공식 메뉴 구조가 아니다.

## 1. 모드를 구분하는 질문

같은 전투가 다른 모드로 느껴지는 이유는 목표뿐 아니라 손실의 지속 범위와 회복 기회가 다르기 때문이다.
다음 표는 어떤 자원을 둘러싸고 싸우는지, 사망이 무엇을 잃게 하는지, 플레이어의 핵심 선택이 무엇인지를 비교한다.
현재 운영 여부는 제목만으로 추정하지 않고 각 문서의 상태·자료 버전을 확인한다.

## 3. 비슷해 보이지만 다른 규칙

| 비교 | 결정적인 차이 | 설계상 영향 |

| 젬 그랩 / 핫 존 | 보유 자산을 들고 이동하는가, 장소에서 누적하는가 | 운반자 집중과 지역 분담 |

## 4. 서로 다른 경기 단위

Match, Round, Set, Run을 같은 단계로 부르지 않는다.
녹아웃의 라운드, 경쟁전의 다판제, 타워의 연속 경기, Upside의 강화 런은 정산과 상태 보존 범위가 다르다.
[코어 루프](systems/01_core_loop.md)와 [규칙 데이터](systems/08_data_rules_qa.md)가 이 차이를 구현 계약으로 정리한다.

## 5. 공통으로 관찰할 지표

단순 승률 외에 목표 접촉 시간, 교전 승리 뒤 목표 전환, 첫 실수의 복구 가능성,
선두 유지와 역전, 역할별 참여 편차, 시간 종료 비중을 본다.
모드마다 점수 단위가 다르므로 원시 점수나 피해량을 그대로 서로 비교하지 않는다.

실제 이용률·승률·매출·통계 값을 수집한 보고서는 아니다.
위 비교는 연결된 공개 규칙에 기반한 독립적 설계 해석이다.

## 6. 자료가 적은 변형의 사용법

근거 열에 제한이 있는 모드는 공개 규칙과 보조 자료, 재구현 제안을 나누어 읽는다.
공식에 없는 수치는 구현 기본값으로 간주하지 않는다.
원작과 동일한 복원이 필요하면 문서의 미확인 실험부터 수행한다.
