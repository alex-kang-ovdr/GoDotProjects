# Dark Descent VII — Browser ARPG

`index.html`을 Chrome 또는 Edge에서 열면 됩니다. 서버, 설치, 빌드가 필요하지 않습니다.

## v7 변경 사항
- v6의 치명적 몬스터 처치 버그 수정 (boss/elite 변수 선언 전 접근)
- 소켓 장비 생성 및 룬 삽입(6/7/8), 2가지 조합 룬워드
- 엘리트 몬스터 속성: 신속, 방어, 흡혈
- 사망 후 마을 부활(골드/현재 경험치 페널티)
- 독립 v7 저장 슬롯

## 조작
WASD/방향키 이동, 클릭 이동/공격, 1~5 스킬, Space 돌진, E 줍기, F 다음 층, G 성소, Q/R 물약, B 분해, V 강화, N 각인, M 도박, 6/7/8 소켓 룬, P 일시정지.

## 룬워드
- 일반 등급 2소켓 장비에 화염 → 생명: 불사조의 맹세 (+공격/흡혈)
- 일반 등급 2소켓 장비에 수호 → 수호: 철벽의 서약 (+방어/저항)
- 소켓 장비를 장착한 뒤 시작 방에서 룬 버튼 사용

원작 디아블로 2와 다른 독립 게임 프로토타입입니다. 전체 캠페인 브라우저 플레이 테스트는 별도로 필요합니다.
