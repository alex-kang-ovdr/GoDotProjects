# Dark Descent XXIV — Tactical Depth

XXIII 단일 HTML 소스를 기반으로 실행 오류를 정리하고, 이동·전투·3D 표시·저장·테스트를 재구성한 독립 웹 ARPG 프로토타입입니다. 디아블로 2의 원본 코드, 모델, 음원, 수치 테이블은 포함하지 않습니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 엽니다. 설치, npm, 빌드, 인터넷 연결, 별도 서버가 필요하지 않습니다. 이 파일에는 CSS와 JavaScript가 모두 들어 있습니다. 채팅 서비스의 HTML 미리보기에서 JavaScript가 제한되는 경우 파일을 저장한 뒤 브라우저에서 여세요.

WebGL을 사용할 수 없으면 같은 게임 규칙을 사용하는 Canvas 2D 모드로 시작합니다. 우측 상단의 `3D / 2D` 버튼으로 전환할 수 있습니다. 공개 서버에 배포한 버전은 아닙니다.

## 진행

분기방에서 봉인 열쇠를 찾고 H로 획득합니다. 열쇠가 보스방의 모든 관문을 개방합니다. 수호자를 처치한 뒤 황금 계단에서 F를 눌러 다음 층으로 이동합니다. 5층을 완료하면 승리합니다. 전투, 드롭, 장비, 레벨, 스킬 포인트, 성소, 함정, 상자, 상점, 강화, 룬 조합이 이 흐름에 연결되어 있습니다.

새 탐험에서 기사·사냥꾼·마법사와 Seed를 선택할 수 있습니다. Seed를 비우면 무작위로 시작합니다. 동일 Seed·동일 버전에서는 같은 층 구조와 콘텐츠를 생성합니다. 업데이트 사이의 맵 동일성이나 모든 입력의 완전한 리플레이 호환성을 보장하지는 않습니다.

## 조작

| 조작 | 기능 |
|---|---|
| WASD / 방향키 | 이동 |
| 바닥 클릭 | 장애물을 고려한 경로 이동 |
| 적 클릭 | 접근 후 연속 기본 공격 |
| Shift + 클릭 | 2번 스킬 |
| 1 / 2 / 3 / 4 / 5 | 직업별 기본 공격 / 액티브 / 광역 / 보조 / 궁극기 |
| Space | 마나 8 소모 회피, 쿨다운 2.7초, 짧은 무적 |
| Q / R | 체력 / 마나 물약 |
| H | 열쇠·상자·성소·함정 해체 |
| E / F | 줍기 / 다음 층 |
| Tab / T / P | 지도 확대 / 전술 디버그 / 일시정지 |
| 마우스 휠 | 화면 확대·축소 |
| B / V / N / M | 시작 방에서 분해 / 강화 / 각인 / 도박 |
| 6 / 7 / 8 | 화염 / 생명 / 수호 룬 삽입 |

휴대 화면에는 이동 버튼이 나타납니다. 실제 모바일 기기에서의 입력·성능 검증은 별도입니다. 소리는 기본 OFF이며 버튼으로 켜면 브라우저에서 합성한 효과음을 사용합니다.

## XXIV 변경점

### 실행 및 충돌

- 콘텐츠 적용 시 맵 데이터가 누락되어 시작이 중단되던 경로를 제거했습니다.
- 던전 검증 함수의 범위를 정리했습니다. 공개 API는 `window.DarkDescent`입니다.
- 2D 렌더러에서 3D 내부 함수를 호출하던 코드를 제거했습니다.
- 화면 전용 컨테이너에 렌더러와 HUD를 겹쳐 배치합니다. 조작 버튼 영역까지 WebGL 캔버스가 늘어나지 않습니다.
- 이동, 길 찾기, 돌진, 투사체, 상호작용에 벽·관문 규칙을 적용합니다.
- 이동·투사체를 작은 구간으로 나누어 검사합니다. 캐릭터 반경을 포함해 충돌합니다.

### 전술 AI

- 경계 / 교전 / 후퇴 / 재집결을 분리합니다. 한 번의 AI 업데이트에서 후퇴 이동 뒤 추격 이동을 다시 적용하지 않습니다.
- 사기 계산에 처음 생성한 분대 인원수를 사용합니다. 지휘관 사망은 사기를 낮춥니다.
- 이동 목표를 접근 가능한 타일에서 선택하고 관문을 고려한 경로를 사용합니다.
- 호위는 멀어진 지휘관 근처로 복귀하고, 측면 병사는 옆쪽 위치를 목표로 합니다. 원거리 병사는 사거리와 시야를 고려해 거리를 조절합니다.
- 후퇴와 재집결에는 시간 제한과 재후퇴 대기시간이 있습니다.
- T 디버그는 2D·3D 양쪽에서 역할, 명령, 사기, 현재 경로를 표시합니다.
- 완전한 다중 에이전트 충돌 회피나 엄격한 대형 유지 알고리즘은 아닙니다.

### 전투와 보스

- 기사 기본 공격은 근접, 사냥꾼은 화살, 마법사는 마력탄입니다. 기본 공격은 마나를 소모하지 않습니다.
- 적 근접·원거리 공격에 예고 시간이 있습니다. 시전 시점과 피해 적용 시점을 분리했습니다.
- 사거리 밖으로 이동하거나 벽 뒤로 피하면 근접 피해를 피할 수 있습니다.
- 보스는 체력 66% / 33% 구간에서 페이즈를 바꾸고 최대 4명의 생존 소환병을 관리합니다.
- 원형 위험 영역과 실제 원형 피해 판정을 일치시켰습니다. 광역 피해에는 벽 검사도 적용합니다.
- 보스별 이름·층 테마는 다르지만 기본 패턴 구조를 공유합니다. 다섯 보스의 완전히 다른 패턴 세트가 구현된 것은 아닙니다.

### 화면

- WebGL 입체 바닥·벽·문·캐릭터·오브젝트를 사용합니다.
- 몸체 방향, 다리 보행, 팔·무기 공격, 피격 색상 등 단순 절차 애니메이션을 적용했습니다. 스켈레탈 애니메이션이나 PBR 렌더링은 아닙니다.
- 3D에서도 적 체력, 피해 숫자, 상호작용 안내, 미니맵을 표시합니다.
- 플레이어 앞쪽의 가까운 벽은 낮춰 표시합니다. 시야가 가려지는 모든 상황을 완벽히 제거하는 방식은 아닙니다.
- 탐험 기억과 현재 시야를 구분하고, 화면 흔들림 해제와 확대·축소를 제공합니다.
- 클래스별 스킬명과 실제 동작을 일치시키고 패시브 버튼의 이벤트 연결을 수정했습니다.

## 저장 및 호환

새 저장 키는 `dark-descent-xxiv`, 스키마 버전은 24입니다. 이전 `dark-descent-v10`, v8, v7 키를 읽는 경로가 있지만 브라우저 파일별 저장소 격리 때문에 다른 이름의 HTML에서 이전 슬롯이 보이지 않을 수 있습니다. **이동·백업에는 JSON 내보내기 / 가져오기를 사용하세요.**

구버전 저장은 기본 구조를 검사하고 관문·콘텐츠·분대 필드를 보완합니다. 모든 과거 버전의 실사용 저장 파일을 수집해 검증한 것은 아닙니다. 테스트에는 합성 v10 저장 사례가 포함됩니다. 손상된 맵처럼 검증에 실패한 파일은 불러오지 않습니다.

처치한 적·획득한 열쇠·소모한 오브젝트는 저장 복원 시 유지합니다. 경로 캐시는 다시 계산합니다. 영구적인 디스크 백업, 클라우드 동기화, 계정 시스템은 없습니다. 브라우저 데이터 삭제 시 저장 슬롯도 사라질 수 있습니다.

## 제작 규칙

기존 간소화 규칙을 유지합니다. 일반 2소켓 장비에 화염→생명은 `불사조의 맹세`, 수호→수호는 `철벽의 서약`입니다. 원작 디아블로 2의 룬워드와 다른 독립 규칙입니다.

분해/판매는 가방의 첫 장비, 강화는 첫 장착 장비, 각인은 첫 미각인 장착 장비, 소켓은 빈 소켓이 있는 첫 장착 장비를 대상으로 합니다. 대상 선택형 제작 UI는 아직 없습니다.

## 개발 파일

```text
index.html                     완성된 오프라인 실행 파일
build.py                       표준 Python만 사용하는 HTML 재생성
src/
  core.js                      상태·공통 규칙·Seed
  generator.js                 BSP/MST 지형 생성
  gear.js                      장비·제작·성장
  navigation.js                관문·연결 검사·경로·콘텐츠 컴파일
  simulation.js                고정 스텝 전투·분대 AI·진행
  persistence.js               저장 검사·복원·마이그레이션
  render.js                    WebGL / 2D / HUD
  ui.js                        UI·입력·효과음
  boot.js                      초기화와 테스트 인터페이스
  shell.html / style.css       화면 구성
tests/                         자동 검사·실제 실행 결과
CHANGELOG.md / QA_REPORT.md     변경 내역과 검증 범위
```

게임 실행에는 Python이 필요하지 않습니다. 소스를 수정한 후 실행 HTML을 재생성할 때만 `python build.py`를 사용합니다. 외부 JavaScript 라이브러리는 없습니다.

자동 테스트에는 Python Playwright와 Chromium이 필요합니다. Linux에서 가상 디스플레이가 필요한 경우:

```bash
xvfb-run -a python tests/browser_regression.py
```

## 검증과 남은 범위

실행한 결과는 `QA_REPORT.md`, `tests/results.json`, `tests/input_combat_smoke.json`에 기록했습니다. 단순한 구문 검사만 수행한 버전이 아닙니다. 단, 자동 캠페인 진행 검사에서는 진단용 피해량을 사용했으므로 **일반 난이도 완주·장시간 파밍 밸런스를 검증했다고 해석하면 안 됩니다.**

원작 전체 스킬 트리, 액트/퀘스트, 원본 TC 드롭, 다중 열쇠 퍼즐, 온라인 멀티플레이, 실기기 성능 최적화, 고급 물리 기반 렌더링은 이번 범위에 포함하지 않습니다.
