# 03. 엘릭서·손패·카드 회전

> 조사 기준일: 2026-11-13 · 주 대상: 일반 1대1의 8장 덱  
> **[확인]** 공식 자료 확인, **[분석]** 설계 해석, **[재현 설계]** 구현 제안, **[검증 필요]** 클라이언트 실측 대상. 이 문서의 수식과 의사코드는 Supercell 내부 구현을 의미하지 않는다.

## 1. 핵심 구조

**[분석]** 엘릭서는 지금 행동할 수 있는 양을 제한하고, 손패는 지금 고를 수 있는 행동의 종류를 제한한다. 두 제한이 겹치므로 강한 카드를 보유한 것만으로 즉시 대응할 수 없다. 플레이어는 자원과 카드 순서를 동시에 관리한다.

| 계층 | 플레이어가 관리하는 것 | 상대가 추정하는 것 |
| --- | --- | --- |
| 엘릭서 | 현재 사용 가능량, 회복 속도, 넘침 | 배치 비용을 통한 잔여 자원 범위 |
| 손패 | 당장 사용 가능한 4장의 역할 | 상대가 최근 사용한 카드와 가능한 대응 |
| 대기 카드 | 다음 카드와 이후 회전 순서 | 핵심 카운터가 돌아오기까지 남은 사용 횟수 |
| 특수 형태 | 진화 진행, 히어로·챔피언 능력 | 다음 진화와 능력 사용 가능성 |

**[확인]** 공식 지원 문서는 사용한 카드가 손패에 돌아오려면 다른 카드 4장을 더 사용해야 한다고 안내한다. 일반 회전을 설명할 때는 이 규칙을 기준으로 하고, 특수 모드의 덱 크기나 별도 회전 규칙은 분리한다. [C04](https://support.clashroyale.com/hc/en-us/articles/49484904683803-1v1-Battle)

## 2. 엘릭서 규칙과 수치의 신뢰 범위

### 2.1 생성 일정

**[확인]** 일반 전투의 생성 배수는 정규 시간 첫 2분 1배, 정규 마지막 1분과 연장 첫 1분 2배, 연장 마지막 1분 3배다. 2대2는 기본 생성 속도가 더 느리며, 이벤트는 자체 배수를 사용할 수 있다. [C03](https://support.clashroyale.com/hc/en-us/articles/49484936933403-Elixir)

| 항목 | 문서상 취급 | 검증 시 주의 |
| --- | --- | --- |
| 비용 | 카드별 엘릭서 값, 능력 비용과 별도 | 형태 변경·가변 비용 카드 예외 |
| 시작량 | 통상 표준전에서 사용하는 기준 5 | 실제 시작 카운트다운과 생성 시작 시점 확인 |
| 상한 | 통상 표준전 기준 10 | 정수 UI와 내부 잔량 차이 확인 |
| 기본 생성 간격 | 재현 예시에서는 1당 2.8초 사용 | 현행 공식 지원 문서는 배수만 명시하므로 빌드별 실측 필요 |
| 2배·3배 | 기본 생성률에 해당 배수 적용 | 3배를 정확히 0.9초라고 반올림해 누적하지 않음 |
| 상대 잔량 | 일반 전투에서 직접 보이지 않는 정보로 분석 | 관전·리플레이·팀 모드의 공개 범위 별도 |

**[검증 필요]** 위 표의 시작량·상한·2.8초는 널리 알려진 표준전 기준을 명시한 것이며, 이번 작업에서 실제 클라이언트의 프레임을 계측한 값은 아니다. 1배 생성 속도를 `g1`로 두고 운용 설정에서 분리하면 소수 시간 오차와 특수 모드 혼입을 줄일 수 있다.

### 2.2 재현용 자원 식

**[재현 설계]** 카드 배치가 없는 짧은 구간에서 다음처럼 표현할 수 있다.

```text
E_next = min(E_max, E_now + g1 × phase_multiplier × delta_time)

카드 승인 시:
  E_next >= resolved_cost 이어야 한다.
  승인된 명령에 한해서 비용을 한 번 차감한다.
```

생성·차감·상한 처리가 같은 시각에 겹치면 순서가 결과를 바꿀 수 있다. 예를 들어 9.9 엘릭서에서 1 엘릭서 카드를 낼 때, 먼저 생성 상한을 적용하느냐 먼저 비용을 빼느냐에 따라 넘침이 달라진다. 원작의 순서는 실측 대상이며, 재현 구현은 명시적 이벤트 순서를 고정해야 한다.

### 2.3 엘릭서 넘침

**[분석]** 자원 상한에 머문 동안 발생한 생성 기회를 `leak`으로 정의하면 다음과 같이 계산할 수 있다.

```text
lost_elixir = integral(generation_rate while E == E_max)
```

예시로 `g1=1/2.8`, 상한 유지 2.8초를 가정하면 1배에서 약 1, 2배에서 약 2 엘릭서의 기회를 잃는다. 다만 자원을 일부러 보존해 상대의 선공을 기다리는 선택이 더 유리할 수 있으므로, 넘침을 곧바로 플레이 실수로 판정하면 안 된다.

## 3. 손패와 대기열 모델

### 3.1 8장·4장 구조의 표현

**[재현 설계]** 카드 A~H를 가진 일반 덱에서 손패와 대기열을 아래처럼 모델링한다. 실제 서버가 같은 자료구조를 쓴다는 뜻은 아니다.

```text
Hand = [A, B, C, D]
Queue = [E, F, G, H]

A 사용 → Hand=[E,B,C,D], Queue=[F,G,H,A]
B 사용 → Hand=[E,F,C,D], Queue=[G,H,A,B]
C 사용 → Hand=[E,F,G,D], Queue=[H,A,B,C]
D 사용 → Hand=[E,F,G,H], Queue=[A,B,C,D]
E 사용 → Hand=[A,F,G,H], Queue=[B,C,D,E]
```

A를 사용한 뒤 B·C·D·E, 네 번의 추가 카드 사용으로 A가 돌아온다. 같은 손패 슬롯을 계속 누르는 경우에도 실제 카드 ID를 기준으로 순서를 갱신해야 한다. UI 슬롯 번호는 카드의 영구 식별자가 아니다.

### 3.2 초기 손패

**[검증 필요]** 초기 덱 섞기, 첫 손패 제외 카드, 미러의 첫 배치 가능 여부, 모드별 고정 손패는 이번 조사에서 현재 빌드의 전체 규칙을 확정하지 않았다. 초기 카드의 무작위 순서와 이후 순환이 모두 무작위라고 혼동하면 안 된다.

**[확인]** 공식 Mirror Challenge 설명은 해당 모드가 같은 덱·같은 시작 손패를 주는 조건이라고 설명한다. 이는 시작 손패 정책을 모드별로 분리해야 하는 명확한 사례다. [C09](https://supercell.com/en/games/clashroyale/blog/fun/3-tips-for-the-mirror-challenge/)

## 4. 회전 비용과 평균 엘릭서

**[분석]** 평균 비용은 덱 전체의 무게를 보여 주지만 특정 카드의 재등장 속도를 직접 설명하지 않는다.

```text
average_cost = sum(deck_base_costs) / 8
cycle_cost(target) = target 사용 후, target이 복귀할 때까지 사용한 4장의 비용 합
replay_cost(target) = cycle_cost(target) + target의 다음 사용 비용
```

예를 들어 핵심 카드 비용이 4, 회전을 위해 사용 가능한 네 카드 비용이 `1+1+2+2=6`이면 핵심 카드 재사용까지 최소 10 엘릭서가 필요하다. 그러나 네 카드를 실제로 사용할 수 있는지, 방어 카드를 낭비해도 되는지, 시작 잔량이 얼마인지에 따라 공격 간격은 달라진다. 이 계산은 가상 카드 구성 예시다.

`cycle_cost / generation_rate`만으로 다음 사용 시간을 정하면 현재 잔량, 유닛이 만들어 주는 엘릭서, 능력 지출, 배치 승인 지연을 놓친다. 실전에서는 상대에게 대응하기 위해 낸 카드도 회전에 기여하므로, 효율적인 방어와 빠른 회전이 결합된다.

## 5. 챔피언 회전의 역사와 현재

**[확인]** 2025년 10월 업데이트에서 챔피언은 일반 카드처럼 회전하도록 바뀌었다. 같은 종류의 챔피언을 여러 개체 유지할 수 있고, 가장 최근에 배치한 개체만 능력을 쓸 수 있다. 따라서 과거의 `챔피언이 살아 있으면 덱에서 빠져 3카드 회전이 된다`는 설명을 현재 기본 규칙으로 사용하면 안 된다. [C06](https://supercell.com/en/games/clashroyale/blog/release-notes/october-update-2025/)

| 구분 | 과거 설명 | 2026년 문서 적용 |
| --- | --- | --- |
| 생존 챔피언의 카드 | 회전에서 빠짐 | 일반 카드와 같은 회전 |
| 같은 챔피언 복수 개체 | 제한된다고 설명 | 가능, 능력 권한 별도 |
| 3카드 회전 | 중요한 숙련 전략 | 과거 버전 분석용 |
| 능력 담당 | 생존 단일 개체 | 같은 종류 중 최근 배치 개체 |

**[확인]** 현행 지원 문서는 Hero 슬롯과 Wild 슬롯에 챔피언을 넣어 한 덱에서 두 챔피언을 사용할 수 있다고 안내한다. 2025년 개편 공지에 남아 있는 `덱당 1챔피언` 문장은 이후 슬롯 변경 전의 조건이다. 능력 권한은 서로 다른 종류의 챔피언까지 무조건 하나로 합치는 규칙으로 해석하지 않는다. [C07](https://support.supercell.com/clash-royale/en/articles/champions-10.html)

## 6. 능력과 회전의 분리

**[확인]** 2026년 8월 공식 밸런스 공지는 Boss Bandit를 제외한 히어로·챔피언 능력을 반복 쿨다운에서 해당 개체의 배치당 1회 사용 구조로 변경했다. 능력의 지속 시간과 재사용 가능 횟수는 다른 속성이다. [C08](https://supercell.com/en/games/clashroyale/blog/news/final-august-balance-changes-826/)

**[재현 설계]** 카드 배치와 능력 발동은 아래처럼 다른 명령이어야 한다.

| 명령 | 손패 소비·회전 | 엘릭서 지출 | 생성/대상 |
| --- | --- | --- | --- |
| `PlayCard` | 해당 카드 회전 | 현재 카드 비용 | 유닛·건물·주문 |
| `ActivateAbility` | 원칙적으로 카드 회전 없음 | 능력별 비용 | 능력 권한 개체 |
| `MirrorCard` | 미러 카드 자체를 회전 | 복제 규칙으로 계산 | 별도 생성 개체 |
| `EvolutionPlay` | 해당 카드 회전 | 카드 규칙 적용 | 그 배치의 진화 형태 |

능력 버튼을 여러 번 누르거나, 발동 직전에 대상 개체가 죽거나, 새 복제 개체가 배치되는 경우를 처리해야 한다. 실패 시 엘릭서를 돌려주는지까지 카드별 정책으로 검증해야 하며, 모든 능력의 환불 규칙을 하나로 단정하지 않는다.

## 7. 진화와 미러의 회전 상태

**[확인]** 진화는 일반 손패 회전과 별개로 해당 카드의 사용 횟수를 누적해 강화 형태를 사용하게 하는 시스템이다. 현재 지원 문서는 진화 카드의 순환과 활성 슬롯의 관계를 설명한다. [C10](https://support.clashroyale.com/hc/en-us/articles/49484923993883-Card-Evolution)

**[재현 설계]** 두 종류의 카운터를 분리한다.

```text
deck_cycle_position: 다음 손패 진입을 결정
evolution_progress[card_id]: 다음 진화 배치를 결정
```

다른 카드 4장을 내는 행위는 손패를 돌리지만, 진화 카드 자체를 4회 사용한 것이 아니다. 진화 충전 완료 상태에서 능력만 사용한다고 카드가 회전하거나 진화 진행이 바뀌면 안 된다.

**[확인]** 2026년 11월 진화 미러는 마지막 카드에 진화가 있으면 해당 진화 형태를 소환하며, 그 진화를 보유하지 않아도 된다. 진화 없는 카드에는 일반 미러처럼 작동한다. 이와 같은 예외는 `일반 복제`와 `진화 진척`을 분리해야 함을 보여 준다. [C11](https://support.clashroyale.com/hc/en-us/articles/57579150651419-What-s-New-November-2026)

**[확인]** 같은 시즌 공식 공지는 진화 미러의 추가 1레벨 효과도 명시한다. 미러 카드 레벨·모드 보정과의 세부 결합은 따로 검증한다. [C23](https://supercell.com/en/games/clashroyale/blog/release-notes/new-season-king-vs-king/)

**[검증 필요]** 미러로 소환한 진화가 원본 카드의 진화 카운터에 영향을 주는지, 가변 비용·히어로·챔피언과의 조합, 마지막 카드 기록에서 능력 버튼을 제외하는 방법은 현재 클라이언트에서 개별 조합을 확인해야 한다.

## 8. 상대 자원·손패 추적

**[분석]** 상대 엘릭서를 정확한 단일 수치로 기억하기보다 가능한 범위로 모델링하는 편이 실전에 가깝다.

1. 전투 시작량과 시간 경과로 가능한 자원 상한을 추정한다.
2. 상대가 사용한 카드·능력 비용을 차감한다.
3. 상한에서 낭비했을 가능성과 생성형 카드의 효과를 반영한다.
4. 상대 핵심 카운터 사용 뒤 다른 카드 사용 횟수를 센다.
5. 카운터가 돌아오기 전에 공격할 수 있는지, 돌아와도 자원이 부족한지 구분한다.

상대의 핵심 방어 카드가 손패에 없다는 판단과 엘릭서가 부족하다는 판단은 다르다. 전자는 회전 수로, 후자는 비용과 시간으로 검증한다. 관전 UI가 상대 자원을 보여 준다면 경기 중 사용자가 가진 정보와 관전자가 가진 정보를 섞어 플레이 품질을 평가하지 않아야 한다.

## 9. 데이터 모델과 QA

| EC-02 | 같은 손패 슬롯 연속 사용 | 카드 ID 기준으로 순환 |
