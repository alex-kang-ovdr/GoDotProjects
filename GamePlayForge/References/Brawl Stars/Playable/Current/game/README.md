# Brawl Lab v4 — 오프라인 아레나 프로토타입

이 프로젝트는 짧은 아레나 전투의 핵심 순환을 직접 플레이하며 확인할 수 있는 **싱글 플레이 브라우저 게임**입니다. 플레이어 한 명과 로컬 봇이 싸우는 일곱 가지 경기 모드와 자유 연습장을 제공합니다. v4에는 한 라운드에 한 번의 생명으로 싸우는 **녹아웃**, 처치와 현상금으로 별을 모으는 **바운티**를 추가했습니다. 녹아웃의 라운드 전환·아군 관전, 바운티의 블루 스타 소유권과 전황 정보까지 연결되어 있습니다. 영웅별 가젯, 추적 카메라, 브롤 볼 연장전도 계속 사용할 수 있습니다.

브롤스타즈 역기획에서 살펴본 구조를 실행 가능한 작은 게임으로 재구성했습니다. 캐릭터와 그래픽은 이 프로젝트의 자체 표현을 사용하며, 실제 브롤스타즈의 전체 콘텐츠·정확한 밸런스·네트워크 대전을 재현하는 범위는 아닙니다. 아래 규칙은 **이 프로토타입의 구현 규칙**입니다.

## 1. 바로 실행하기

**단일 파일로 플레이:** 프로젝트의 `dist/Brawl_Lab_Offline.html` 또는 다운로드한 `Brawl_Lab_Offline.html`을 브라우저에서 열고, 모드·영웅·봇 난도를 선택한 뒤 경기를 시작합니다. 스타일과 게임 코드가 한 HTML 안에 포함되어 있습니다.

**소스 폴더에서 플레이:** `Brawl_Lab_Source.zip`을 받았다면 폴더 전체를 압축 해제한 다음 `dist/index.html`을 브라우저에서 엽니다.

별도 설치, 빌드, 패키지 다운로드, 계정, 서버가 필요하지 않습니다. HTML과 같은 폴더의 JavaScript·CSS 파일을 함께 유지하면 `file://` 경로에서도 실행됩니다. 게임 화면의 텍스트는 한국어이며, 그래픽은 Canvas로 그립니다.

원한다면 프로젝트 폴더에서 다음과 같이 로컬 서버를 실행한 뒤 `http://localhost:8000/dist/`를 열어도 됩니다. 로컬 서버는 선택 사항입니다.

```sh
python3 -m http.server 8000
```

## 2. 조작

### 키보드와 마우스

| 행동 | 입력 | 사용 방법 |
|---|---|---|
| 이동 | W·A·S·D 또는 방향키 | 두 방향을 함께 눌러 대각선으로 이동합니다. |
| 조준 | 마우스 이동 | 화면의 목표 위치를 가리킵니다. |
| 일반 공격 | 마우스 왼쪽 버튼 유지 | 조준한 방향으로 탄약과 공격 간격에 맞춰 발사합니다. |
| 자동 조준 공격 | Space | 시야·사거리·사선을 만족하는 적을 향해 공격합니다. |
| 슈퍼 | E 또는 마우스 오른쪽 버튼 | 게이지가 가득 찼을 때 사용합니다. |
| 가젯 | Q 또는 Shift | 가젯의 재사용 대기시간이 끝났을 때 한 번 사용합니다. |
| 카메라 | 경기 중 C 또는 상단 보기 버튼 | 전체 전장 보기와 캐릭터 추적 보기를 전환합니다. |
| 관전 대상 | 녹아웃 탈락 후 Tab 또는 다음 아군 버튼 | 현재 살아 있는 다른 아군을 관전합니다. |
| 전황표 | T | K/D/A·피해·목표 기여를 확인합니다. 보는 동안 경기가 멈추고, 닫으면 이전 상태로 돌아갑니다. |
| 연습장 초기화 | R | 연습장에서 표적·스킬·누적 연습 기록을 초기화합니다. |
| 일시정지·계속하기 | Esc 또는 P | 전투를 멈추거나 다시 진행합니다. |

공을 들고 있을 때의 공격 입력은 공을 차는 입력이 됩니다. 일반 슛은 탄약 한 칸을 사용하며, 공을 소지한 상태에서 슈퍼를 사용하면 강한 슛을 시도합니다.

자동 조준은 벽이나 수풀 뒤의 적을 무조건 추적하지 않습니다. 쇼다운에서 적을 고를 수 없으면 사선이 열린 파워 상자를 찾고, 하이스트에서는 사거리·사선 조건을 만족하며 보호막이 없는 상대 금고를 찾습니다. 공 소유자는 상대 골문을 향합니다. 가젯은 버튼을 계속 누르고 있어도 대기시간 종료 후 자동으로 재발동하지 않으므로 다시 눌러 사용하세요.

### 전체 보기와 추적 보기

데스크톱의 기본값은 전체 전장을 한눈에 보는 방식입니다. 터치 기기에서는 플레이어를 약 1.5배 확대해 따라가는 추적 보기가 기본입니다. 상단 버튼, 경기 중 C, 도움말의 추적 보기 설정으로 바꿀 수 있으며 저장한 선택이 기본값보다 우선합니다. 로비 미리보기는 항상 전체 전장을 보여 줍니다.

추적 보기의 미니맵은 지형·고정 목표와 자신·아군 위치를 보여 줍니다. 적이나 공의 위치를 따로 표시하지 않아 숨겨진 상대 또는 공 운반자의 위치가 드러나지 않습니다. 바운티의 블루 스타는 땅에 놓여 있을 때만 공개 목표로 표시하고, 숨은 운반자의 위치를 별도 마커로 알리지 않습니다. 맵 가장자리에서는 카메라가 경기장 밖으로 나가지 않도록 제한됩니다. 마우스 조준은 카메라가 움직인 뒤에도 화면상의 포인터 위치를 다시 월드 좌표로 변환하고, 터치 조준은 플레이어 기준 방향을 유지합니다.

녹아웃에서 탈락하면 살아 있는 아군을 관전합니다. 추적 카메라는 선택한 아군을 따라가며, Tab 또는 다음 아군 버튼으로 대상을 바꿉니다. 대상이 쓰러지면 다른 생존 아군으로 자동 전환합니다. 생존 아군이 없으면 라운드 전환을 기다리고, 다음 라운드에 플레이어가 돌아오면 관전을 해제합니다. 관전 중 적의 수풀 시야는 **살아 있는 모든 아군이 볼 수 있는 범위의 합집합**이며, 쓰러진 플레이어의 위치로 적을 계속 드러내지 않습니다.

### 첫 경기에서 확인할 것

- 탄약은 최대 세 칸입니다. 공격을 계속 누르고 있더라도 빈 탄약으로 즉시 발사할 수는 없습니다.
- 엄폐물은 이동과 직선 사격을 막습니다. 엄폐물 뒤로 이동해 재장전 시간을 확보하세요.
- 슈퍼 게이지는 천천히 쌓이며, 상대 캐릭터에게 일반 공격 피해를 주면 더 빠르게 준비할 수 있습니다. 금고 피해는 슈퍼를 충전하지 않습니다.
- 가젯은 별도의 대기시간을 사용합니다. 슈퍼를 아끼면서 이동·방어·지역 견제에 활용할 수 있습니다.
- 수풀 속 적은 플레이어가 볼 수 있는 조건을 만족할 때만 표시됩니다.
- 목표를 달성해야 승리합니다. 처치 수만으로 젬 그랩이나 브롤 볼의 승패가 정해지지는 않습니다.

### 젬 그랩

중앙에서 생기는 크리스털, 즉 이 게임의 젬을 수집합니다. 팀 점수는 살아 있는 팀원들의 소지 젬을 합산합니다. **10개 이상이면서 상대보다 엄격하게 앞설 때** 15초 카운트다운이 시작됩니다.

카운트다운 도중 소지량이 10개 미만으로 줄거나 동점·열세가 되면 카운트다운이 취소됩니다. 다시 조건을 만족하면 15초부터 새로 시작합니다. 사망한 캐릭터는 젬을 바닥에 떨어뜨리고 잠시 뒤 부활합니다. 떨어진 젬은 다시 획득할 수 있습니다.

제한 시간은 180초입니다. 제한 시간에 도달하면 더 많은 젬을 보유한 팀이 승리하고, 보유량이 같으면 무승부입니다.

### 쇼다운

각 캐릭터가 독립적으로 싸웁니다. 상자와 처치로 얻는 파워를 수집하면서, 시간이 지날수록 좁아지는 안전 구역 안에 머물러야 합니다. 독구름 밖에 오래 머무르면 피해를 받습니다.

이 모드에서는 사망 후 부활하지 않습니다. 플레이어가 사망하면 그 시점의 생존자 수를 기준으로 순위를 표시하며 경기를 끝냅니다. 플레이어가 마지막 생존자가 되면 승리합니다.

제한 시간은 150초입니다. 드물게 여러 생존자가 시간 종료까지 남으면 생존 체력 비율과 파워를 반영한 이 프로토타입의 판정으로 마무리합니다.

### 브롤 볼

공에 접근하면 소유할 수 있습니다. 공을 소지한 상태의 일반 공격으로 패스하거나 슛하며, 아군이 공을 받으면 이어서 공격할 수 있습니다. 플레이어 팀은 오른쪽 골대를 향해 공격합니다.

골대의 입구를 통과한 공만 득점으로 처리합니다. 한 골이 들어가면 공을 중앙으로 돌리고 잠깐 경기를 멈춥니다. 재개할 때 선수 위치·체력·탄약을 초기화하고, 슈퍼 게이지는 유지합니다.

두 골을 먼저 넣은 팀이 승리합니다. 정규 시간 180초가 끝날 때 점수 차가 있으면 골이 많은 팀이 승리합니다. **동점이면 45초 연장전**으로 넘어가며, 남은 엄폐물과 수풀이 사라지고 공과 선수를 초기 위치로 돌립니다. 연장전은 다음 한 골로 승부가 결정됩니다. 총 225초까지 동점이면 무승부입니다.

### 핫 존

A와 B 두 구역을 각각 100%로 채우면 승리합니다. 살아 있고 부활 무적이 끝난 캐릭터의 **중심이 구역 안**에 있으면 점유에 기여합니다. 한 명 이상이 유효하게 점유할 때 해당 팀의 구역 진척은 초당 2.5%p씩 늘어나므로, 빈 구역을 채우는 데 40초가 필요합니다.

같은 팀이 여러 명 들어가도 진척 속도는 빨라지지 않습니다. **양 팀이 같은 구역에 있어도 각자 진척**하며, 상대가 있다는 이유로 점유가 정지하지 않습니다. 누적 진척은 이탈하거나 사망해도 감소하지 않습니다. 이미 완료한 팀은 해당 구역에서 추가 진척이나 점유 기여 시간을 얻지 않지만, 상대 팀은 계속 채울 수 있습니다.

상단 팀 점수는 두 구역 진척의 평균이고, A·B 표시에서 각각의 진척을 확인할 수 있습니다. 화면은 소수점을 내려 표시하므로 99.999%를 100% 완료로 오인하지 않습니다. 제한 시간 180초에는 표시 전의 정밀 진척을 비교합니다. 같은 스텝에 양 팀이 모두 완료하거나 제한 시간의 진척이 같으면 무승부입니다. 자세한 규칙은 [핫 존 구현 명세](docs/HOT_ZONE.md)에 정리되어 있습니다.

### 하이스트

양 팀은 각각 체력 24,000인 금고를 지킵니다. 상대 금고를 먼저 파괴하면 승리합니다. 금고는 캐릭터 이동을 막는 고체 목표이며 아군의 공격으로 피해를 받지 않습니다. 체력이 자연 회복되거나 감속·밀치기의 대상이 되지도 않습니다.

금고 체력이 **75%·50%·25%에 도달할 때마다 한 번씩 1.8초 보호막**이 켜집니다. 큰 피해가 다음 경계를 넘겨도 체력은 그 경계에서 멈추고 초과 피해는 버립니다. 예를 들어 체력 24,000인 금고에 한 번에 10,000 피해를 가하면 18,000까지만 감소하고 보호막이 켜집니다. 보호막 중의 공격은 피해나 명중 통계를 추가하지 않습니다.

상단에는 우리·상대 금고의 남은 체력 비율과 보호막 상태를 표시합니다. 양쪽 금고가 같은 전투 스텝에 파괴되면 무승부입니다. 180초가 지나면 남은 체력의 정밀 비율을 비교하고 같으면 무승부입니다. 금고 체력 비율은 화면에서 0.1% 단위로 올려 표시하지만, 승패에는 표시값을 사용하지 않습니다. 자세한 판정과 데이터는 [하이스트 구현 명세](docs/HEIST.md)를 참고하세요.

### 녹아웃

상대 팀을 전멸시키면 한 라운드를 이기고, **두 라운드를 먼저 이긴 팀이 경기에서 승리**합니다. 활성 라운드에서는 누구도 부활하지 않습니다. 플레이어가 먼저 쓰러져도 경기는 계속되고 생존 아군을 관전합니다. 상단에는 경기의 라운드 승수, 현재 라운드 번호·남은 시간, 양 팀의 생존 인원수를 표시합니다.

라운드가 끝나면 승리·패배·무승부와 이유를 표시하고 2.4초 뒤 다음 라운드를 시작합니다. 체력·탄약·위치와 지형을 복원하고, 투사체·장판·일시 효과를 정리합니다. **슈퍼 게이지, 가젯 대기시간과 경기 전체 통계는 이어집니다.** 휴식 중 가젯의 대기시간은 줄지만 자연 회복과 슈퍼 충전은 진행하지 않습니다. 새 라운드에는 1.4초의 시작 보호를 적용합니다. 사망과 라운드 경계를 넘을 때 눌린 공격·이동 입력을 지우므로 다시 조작을 시작하세요.

독구름은 매 라운드 25초부터 좁아져 65초에 최소 반경에 도달합니다. 밖에서는 초당 `300 + 라운드 경과 초 × 9`의 피해를 받으며 임시 보호막으로 독 피해를 줄일 수 없습니다. 양 팀이 같은 전투 스텝에 전멸하거나 75초까지 양 팀이 살아 있으면 해당 라운드는 무승부이며 승수가 늘지 않습니다. 체력이나 누적 피해로 라운드 승자를 정하지 않습니다.

휴식까지 포함한 전체 경기 한도는 240초입니다. 이때는 라운드 승수가 많은 팀이 이기고 같으면 경기 무승부입니다. 상단 시계는 현재 라운드와 전체 경기 중 먼저 닥치는 제한을 보여 줍니다. 라운드 결과는 완료 경기 수에 더하지 않고, 최종 경기 종료만 한 번 기록합니다. 자세한 상태 전환은 [녹아웃 구현 명세](docs/KNOCKOUT.md)를 참고하세요.

### 바운티

적을 처치하면 그 적의 현상금만큼 팀의 누적 별이 늘어납니다. 개인 현상금은 2에서 시작하고 유효한 처치마다 1씩, 최대 7까지 올라갑니다. 사망하면 현상금은 다시 2가 되며 약 2.5초 뒤 부활합니다. **팀 점수는 지금 살아 있는 캐릭터의 현상금 합계가 아니라 이미 획득한 별의 누계**입니다. 현상금이 높아졌다면 다음 처치의 이익과 자신이 쓰러질 때 상대에게 줄 별을 함께 판단해야 합니다.

중앙의 **블루 스타, 화면의 ‘파란 별’**을 처음 수집하면 일반 팀 점수 1점과 개인 획득 별 1개를 얻습니다. 이후의 재수집·양도에는 추가 점수가 없습니다. 블루 스타의 소유권은 일반 점수와 별도로 유지됩니다. 소유자가 적에게 처치되면 처치자에게 넘어가고, 유효한 적 처치자가 없는 사망이면 그 자리에 떨어집니다. 살아 있고 부활 무적이 끝난 캐릭터만 땅의 별을 수집할 수 있습니다.

같은 스텝의 처치는 피해 처리 전 현상금으로 함께 계산합니다. 서로를 처치해도 양쪽 팀은 각자의 점수를 얻고, 두 처치자 모두 사망했다면 개인 현상금은 2로 남습니다. 블루 스타는 **스텝 시작 시 소유자에게서 한 번만 양도**하며, 새 소유자가 같은 스텝에 사망했더라도 그 캐릭터의 부활까지 소유권을 유지합니다. 처리 순서 때문에 여러 사람을 연쇄로 거쳐 돌아가지 않습니다.

팀이 별 20개에 도달하면 해당 스텝의 모든 처치·양도·수집을 마친 뒤 승패를 정합니다. 양 팀이 함께 기준에 도달하면 최종 별 합계가 많은 팀, 동점이면 블루 스타 소유 팀이 승리합니다. 120초 제한에서도 같은 순서를 사용하며, 점수가 같고 소유 팀도 없으면 무승부입니다. 결과에는 파란 별에 의한 동점 판정 이유를 표시합니다. 상세 예외와 데이터는 [바운티 구현 명세](docs/BOUNTY.md)에 정리되어 있습니다.

### 연습장

공격하지 않는 표적 세 개를 상대로 자유롭게 연습합니다. 표적은 처치 후 약 1.5초 뒤 다시 나타나며, 경기 시간이나 승패 종료가 없습니다. 화면에는 남은 시간 대신 무한대 기호와 누적 피해·표적 처치 수를 표시합니다.

처음부터 슈퍼와 가젯을 사용할 수 있습니다. 슈퍼는 약 3초에 걸쳐 다시 충전되며, 모든 영웅의 가젯 재사용 시간도 연습장에서는 3초입니다. R 또는 초기화 버튼으로 연습장을 새로 시작할 수 있습니다. 연습장은 승리 수와 완료 경기 수에 합산하지 않습니다.

## 4. 세 가지 영웅

영웅은 공격 사거리와 공격 방식, 체력과 기동성, 슈퍼가 서로 다릅니다. 선택 화면에서 영웅별 설명을 확인할 수 있습니다.

| 영웅 | 공격과 슈퍼 | 연습할 판단 |
|---|---|---|
| 핀 — 정밀 사수 | 빠른 직사탄. 슈퍼는 적과 목재를 관통하는 탄환을 펼쳐 발사합니다. | 거리 유지, 엄폐물 사이의 사격 각도, 탄약을 남긴 추격 |
| 브릭 — 돌격 수호자 | 근거리 산탄. 슈퍼는 체력을 회복하며 돌진한 뒤 충격파를 만듭니다. | 접근 경로, 체력 교환, 목표 앞의 위치 확보 |
| 코멧 — 폭발 전문가 | 범위 폭발탄. 슈퍼는 넓은 폭발로 적을 밀어내고 목재를 부숩니다. | 적의 다음 위치 예측, 밀집 구간과 목표 주변 견제 |

같은 영웅이라도 모드에 따라 좋은 행동이 달라집니다. 젬 운반자는 무리한 추격을 줄이고, 공 소유자는 슛 경로를 살피며, 쇼다운에서는 교전 뒤 안전 구역으로 돌아올 경로를 확보하는 편이 유리합니다.

### 영웅별 가젯

아래 수치는 이 프로토타입의 자체 밸런스입니다. 일반 경기의 대기시간을 적었으며, 연습장에서는 모두 3초로 줄어듭니다.

| 영웅·가젯 | 효과 | 재사용 시간 |
|---|---|---|
| 핀 · 퀵 스텝 | 이동 또는 조준 방향으로 짧게 이동하고 탄약 한 칸을 보충합니다. 벽을 통과할 수 없습니다. | 12초 |
| 브릭 · 아이언 가드 | 3초 동안 독구름을 제외한 받는 공격 피해를 45% 줄입니다. | 16초 |
| 코멧 · 중력장 | 조준 방향에 4초 동안 유지되는 장판을 만듭니다. 사선이 열린 범위 안의 적에게 초당 100 피해와 35% 이동 감속을 적용합니다. | 15초 |

가젯 대기시간은 사망하거나 골 이후 재개한다고 즉시 준비 상태로 돌아가지 않습니다. 방어막과 감속 같은 일시 효과는 사망·라운드 초기화에서 제거됩니다. 중력장은 시전자 사망 또는 라운드 초기화 시 사라집니다.

## 5. 전황·설정·로컬 기록

T 또는 전황 버튼으로 각 캐릭터의 처치·사망·어시스트(K/D/A), 가한 피해와 모드별 목표 기여를 확인합니다. 젬 회수량은 바닥에서 실제로 주운 누적 수량이고, 골은 득점 팀의 마지막 터치 선수에게 기록합니다. 자책골은 개인 득점 수에 더하지 않습니다. 어시스트는 처치 직전 8초 안에 유효 피해를 준 같은 팀 선수에게 주며 처치자는 제외합니다.

핫 존의 목표 기여는 유효하게 점유한 누적 시간입니다. 같은 구역의 여러 아군이 각각 시간을 얻어도 팀 점령 속도가 늘어나는 것은 아닙니다. 하이스트의 목표 기여는 보호막·초과 피해 제한을 적용한 뒤 금고가 실제로 잃은 체력만 합산합니다. 캐릭터에게 가한 **전투 피해와 금고의 목표 피해는 별도 열**에 표시하며, 금고 파괴를 캐릭터 처치로 세지 않습니다. 유효한 금고 적중은 해당 발사 동작의 명중 1회에 포함하지만 슈퍼를 충전하지 않습니다.

최근 처치 표시는 가장 최근 항목 세 개를 잠시 보여 줍니다. 경기 결과에는 전체 전황표가 포함됩니다. 브라우저 안에 완료한 경기 수·승리 수와 선택한 모드·영웅·난도를 저장합니다. 저장소를 사용할 수 없어도 경기 자체는 계속할 수 있습니다.

녹아웃의 목표 기여는 승리한 라운드가 끝날 때 살아 있던 횟수입니다. 승리 팀이어도 먼저 탈락한 라운드는 이 수치에 더하지 않습니다. 바운티는 획득한 별과 자신의 사망으로 상대에게 허용한 별을 따로 표시하고, 처치 알림에는 그 처치로 얻은 별을 붙입니다. 최초 블루 스타의 1점도 획득 별에 포함하지만 환경 사망에는 허용 별을 부과하지 않습니다.

소리는 상단 버튼으로 켜고 끌 수 있습니다. 도움말에는 추적 카메라, 조준 가이드, 화면 효과 줄이기, 지원 기기의 터치 진동, 플레이 팁 표시 설정이 있습니다. 팁은 닫기 버튼으로 숨길 수 있고 도움말에서 다시 켤 수 있습니다. 이 선택도 브라우저에 저장합니다.

## 7. 자동 검증

테스트에는 Node.js 18 이상이 필요합니다. 브라우저 게임 실행에는 Node.js가 필요하지 않습니다. 프로젝트 폴더에서 다음 명령을 실행합니다.

```sh
node --test tests/*.cjs
```

패키지 설치나 브라우저 자동화 설치 없이 Node의 기본 테스트 도구만 사용합니다. **엔진 82개와 앱 24개, 총 106개 사례**가 전체 실행에서 통과했습니다. 실패·취소·스킵은 0개입니다. 기존 80개를 유지하면서 v4 엔진 20개·앱 6개 사례를 추가했습니다.

- 발사 시 탄약 소모, 빈 탄약 처리와 재장전.
- 벽에 대한 이동 충돌, 투사체 차단, 실제 적중 피해.
- 쇼다운의 초기 스폰과 벽 사이의 비겹침.
- 젬의 엄격한 우세 조건, 카운트다운 취소·재시작·종료.
- 사망 시 젬 총량 보존과 드롭 ID의 중복 방지.
- 공 소유자의 슛, 골 입구 판정, 득점 후 초기화와 두 골 승리.
- 쇼다운 안전 구역 축소, 독구름 피해, 플레이어 탈락과 마지막 생존자 판정.
- 같은 시드의 재현성과 여러 모드·영웅 조합의 시뮬레이션 중 비정상 숫자 방지.
- 가젯의 효과·재사용 시간·입력 유지 중 재발동 방지, 방어막의 독구름 예외와 중력장 수명.
- 총구가 엄폐물 너머에서 생성되는 문제, 고속 공의 골라인 통과, 자동 조준의 사선·은신 조건.
- 연습장 표적 재생성과 무제한 진행, 연장전 전환·첫 골 승리·시간 종료 무승부.
- 일반 공격과 핀·코멧의 투사체형 슈퍼를 행동 단위로 세는 명중 통계, 어시스트 유효 기간, 젬 회수·개인 골 귀속. 돌진·가젯·공 패스와 슛은 발사·명중 횟수에서 제외합니다.
- 핫 존의 동시 점유, 팀원 수에 따른 속도 비중첩, 무적·사망·완료 구역의 기여 제외, 부분 프레임과 동시 완료.
- 금고의 아군 피해 제외, 보호막 경계의 초과 피해 제한, 타이머 1회 감소, 무적 중 통계 제외, 동시 파괴·정밀 체력 비율 판정.
- 핫 존·하이스트와 녹아웃·바운티에서 세 영웅·봇의 실제 고정 스텝 진행, 정상 종료와 고정 시드 재현.
- 녹아웃의 라운드 중 부활 금지, 플레이어 사망 후 경기 지속, 휴식 중 자원 처리와 다음 라운드의 복원·누계 보존.
- 탄환 순서를 뒤집은 동시 전멸·독 전멸, 라운드 시간에 따른 독구름, 75초·240초 경계, 생존 아군의 합집합 시야.
- 바운티의 누적 점수·현상금 상한과 리셋, 상호 처치의 스텝 시작 값, 환경 사망의 보상 제외.

셸에서 `*.cjs`를 확장하지 않는 환경에서는 `node --test tests/engine.test.cjs tests/engine-v2.test.cjs tests/engine-v3.test.cjs tests/engine-v4.test.cjs tests/app.test.cjs`로 다섯 파일을 직접 지정할 수 있습니다.

규칙 검증에서는 봇 행동만 끄고 물리·피해·목표 판정은 그대로 진행합니다. 별도의 시뮬레이션 검증에서는 봇을 켠 상태로 이동·공격·슈퍼 입력을 반복합니다.

앱 테스트는 실제 `app.js`와 `engine.js`를 Node VM에 불러옵니다. 여덟 모드의 선택·시작, 일시정지 시 입력 해제, 전황창 상태 복구, R 초기화, Q 입력 유지 중 재발동 방지, 두 터치의 독립적인 취소, 설정 저장과 전적 갱신을 확인합니다. 점유율·금고 HUD와 목표 기여, 카메라 선택·저장·입력 좌표 재계산도 검사합니다. v4에서는 관전 대상 순환·자동 전환·부활 복귀, 라운드 HUD·전체 경기 제한 시계, 라운드 경계의 터치·키 초기화, 바운티 HUD·처치 별·목표 통계를 추가했습니다.

기존 전적 사례는 공개 종료 상태로 앱의 기록 방어를 검사합니다. 새 녹아웃 사례는 공개 투사체 fixture를 실제 엔진에서 처리해 첫 라운드 종료에 전적이 늘지 않고 두 번째 승리 후 한 번만 기록되는지 확인합니다. 자연스러운 봇 경기 전체의 종료와 결정성은 별도의 엔진 시뮬레이션에서 확인합니다.

앱 테스트의 DOM·Renderer·Audio는 작은 대체 구현을 사용합니다. 카메라 입력 검사는 변환을 다시 조회하는 앱 연결을 확인하며, 실제 카메라 수학은 별도의 네이티브 Canvas 좌표 왕복 검증으로 확인했습니다. 자동 테스트 통과가 실제 브라우저 조작이나 오디오 재생까지 검증했다는 뜻은 아닙니다.

v4 Canvas 검증에서는 생존 아군 초점, 죽은·적·누락 대상의 아군 대체, 아군 전멸 시 전체 보기, 로비·부활 복귀와 휴식 중 배경을 확인했습니다. 숨었거나 죽은 블루 스타 소유자의 위치·현상금과 소유 별의 좌표를 바꿔도 전체 이미지가 달라지지 않는 검증, 지상 별이 실제로 보이는 양성 사례, 모바일 DPR 2와 효과 축소 상태도 포함합니다. 실제 관전·별 소유·모바일 이미지의 가독성을 별도로 확인했습니다. 이 12조합은 Node의 106개 테스트 수에 합산하지 않습니다.

## 8. 구현 범위

이 버전의 목적은 이동 → 조준 → 공격·가젯 → 자원 회복 → 목표 수행 → 결과라는 전투 순환을 플레이 가능한 상태로 제공하는 것입니다. 일곱 가지 경기 모드, 세 가지 영웅과 이들을 시험하는 연습장에 집중했습니다. 녹아웃의 라운드·전체 시간 한도와 동시 전멸, 바운티의 동시 처치·사망한 새 블루 스타 소유자 처리, 핫 존의 구역별 40초, 금고의 체력·보호막·초과 피해, 브롤 볼의 45초 연장전, 가젯과 연습장 수치는 이 구현의 자체 규칙입니다.
