Godot 에디터에 PlayForge 연결

공식 Godot 4.7.2 웹 에디터와 PlayForge 서비스 플러그인을 조합한 세 번째 PoC입니다. 같은 서버에서 에디터를 열고, 공유 프로젝트의 코드를 불러오거나 저장하고 Web 빌드를 요청합니다.

저장된 프로젝트 상태 확인 중…

1. 현재 프로젝트 ZIP 다운로드2. 서비스 연결 에디터 열기 ↗
  1. Studio에서 편집한 내용의 동기화·저장을 마친 뒤 ZIP을 다운로드합니다.
  2. 공식 에디터의 Preload project ZIP에 내려받은 ZIP을 선택합니다.
  3. Start Godot editor → 프로젝트 폴더 생성 → Install & Edit 순서로 엽니다.
  4. PlayForge 독에서 Load from PlayForge로 최신 코드를 확인합니다. 수정 후 Ctrl+S로 파일을 저장하고 Upload saved script로 공유 서버에 반영합니다.
  5. Build web preview로 서버 빌드를 요청하고 완료 후 미리보기·다운로드를 엽니다. 전체 프로젝트 백업은 Project → Tools → Download Project Source를 사용합니다.

공식 에디터에서는 GDScript 파일을 명시적으로 불러오고 저장합니다. 서버 리비전이 달라졌으면 업로드를 거절해 다른 편집을 덮어쓰지 않습니다. 씬 공동 편집과 설정·에셋 자동 동기화는 후속 과제입니다. 실시간 텍스트 협업은 Classic과 Godot Layout에서 비교할 수 있습니다.

← 세 방안 비교 · 기본 공식 에디터도 열기 ↗

외부의 기본 공식 에디터에서는 프로젝트 편집만 비교합니다. PlayForge 저장·빌드 연결은 위의 서비스 연결 에디터를 사용하세요.

현재 PoC에서는 프로젝트 import와 PlayForge 플러그인 활성화를 확인했습니다. 공식 에디터의 스레드·디버그 연결 오류가 남아 있으며, 브라우저 플러그인의 전체 저장·빌드 흐름은 추가 검증이 필요합니다.
