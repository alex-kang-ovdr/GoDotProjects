Underworld Escape 웹 플레이어블 v2

index.html 파일을 Chrome/Edge에서 열면 됩니다.
화면 설정 버튼에서 2D/3D(2.5D 원근 연출), 자동/가로/세로 뷰를 선택할 수 있습니다.
설정은 localStorage에 저장됩니다. 세로 모드에서는 플레이어 추적 카메라를 사용합니다.
PC: WASD 이동, 마우스 조준, 클릭/J 공격, K 특수, Space 대시. 모바일: 가상 스틱 및 액션 버튼.
참고: 3D 모드는 WebGL 메시 렌더링이 아닌 Canvas 2.5D 시각화입니다. 가로/세로 설정은 게임 뷰 레이아웃 변경이며 기기 화면 자체를 강제 회전하지 않습니다.
