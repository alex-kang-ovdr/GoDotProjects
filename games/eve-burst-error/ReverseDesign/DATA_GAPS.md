# 데이터 공백 및 검증 필요 항목 (DATA_GAPS)

본 문서는 공개된 웹 자료만으로는 원작 바이너리/전수 대사 스크립트 수준의 100% 확정이 불가능한 영역, 판본 간 차이로 인해 추후 기준 확정(Spec Freeze)이 필요한 항목, 그리고 조사 과정에서 발견된 인명 보정 내역을 투명하게 기록합니다.

## 1. `[검증 필요]` 원작 세부 미확인 항목

| Gap ID | 분류 | 내용 | 현재 처리 방식 (`verified_data/` 반영) | 해소 방법 |
| --- | --- | --- | --- | --- |
| `GAP-01` | 인물 명칭 | 요청 체크리스트에 포함된 `シバ(시바)`라는 독립 요원/캐릭터가 본편 정규 캐스트에 별도 존재하는지 여부. 교차 검증 결과 본편 정규 인물은 르포라이터 **`柴田茜`(시바타 아카네)**로 확인됨. | `akane_shibata`로 정규 수록. 별도 단역 코드네임 'シバ'가 특정 판본·단역 대사에 존재하는지는 `[검증 필요]`로 보류. | PC-98 / SS / R 대사 스크립트 전수 검색 |
| `GAP-02` | 인물 명칭 | 요청 체크리스트의 `御堂銀三郎(미도 긴자부로)`는 원작 정식 명칭이 아닌 **`ロス＝御堂`(로스=미도)**와 **`桂木源三郎`(카츠라기 겐자부로)**의 혼동으로 판명됨. | 두 인물을 각각 `ross_mido`, `genzaburo_katsuragi`로 정확히 분리 수록. | 완료(원작 정본 확정) |
| `GAP-03` | 커맨드 반복 횟수 | 원작 특정 씬에서 `LOOK` 또는 `TALK`를 정확히 몇 회(2회/3회/4회) 반복해야 숨김 플래그가 점등되는지에 대한 씬별 전수 테이블. | `01_core_loop_and_state_machine.md` 및 `06_ui_ux_and_save_architecture.md`에 반복 소진(Exhaustion) 모델(`commandExhaustion`)을 `[재구성안]`으로 설계. | 원작 완전 공략 차트(커맨드 단위) 대조 |
| `GAP-04` | 즉사 게임오버 전수 목록 | 조사 중 선택지/커맨드 오선택으로 발생하는 모든 마이너 게임오버 분기의 정확한 위치와 대사. | `items_and_endings.json`에 대표 카테고리와 핵심 위기 구간(디브 습격, 사문 탈출, 트리스탄호 침몰, 범인 오답)을 구조화하고 세부 분기 전수는 `[검증 필요]` 표기. | 실기 플레이 또는 스크립트 분기 추출 |
| `GAP-05` | 마리나 권총 명칭 및 판본별 소품 차이 | 마리나의 애총 애칭 `'イクイク'(이쿠이쿠)` 및 일부 소품·표현이 PC-98 / SS / PLUS / R 판본마다 미묘하게 다르게 처리됨. | `items_and_endings.json`에 `item_ikuiku_handgun`으로 수록하되 판본별 명칭 차이 비고를 명시. | SS vs R 텍스트 비교 |
| `GAP-06` | 마이너 동기화 장벽 세분화 | 본 패키지는 12월 2일~8일 전체 흐름을 16개 핵심 매크로 씬과 8개 핵심 동기화 장벽(`SB_01`~`SB_08`)으로 모델링했다. 실제 원작의 커맨드 단위 마이크로 플래그(예: 특정 NPC 방문 후 이동지 추가 등 20~30여 개의 소규모 교차 플래그)는 추후 스크립트 제작 단계에서 하위 씬으로 세분화해야 한다. | 매크로 레벨 8개 핵심 동기화 장벽을 `sync_barriers.json`에 확정하고, `validate_data.mjs`로 무교착 DAG 검증 기반 구축. | 풀 스크립트 작성 시 마이크로 씬 확장 |
| `GAP-07` | 종반 범인 입력 UI 사양 | PC-98/SS/R의 범인 입력 파트에서 정확히 몇 명의 사건(스트르만, 니카이도, 디브, 아쿠아 등)에 대해 개별 입력을 받는지, 그리고 허용 오탈자/히라가나 처리 규칙 세부 사양. | `items_and_endings.json`에 진범(`mayako_mido`)과 다국어 정규화 허용 문자열 목록을 `[확인]`+`[재구성안]`으로 정의. | SS/R 종반 씬 직접 확인 |

## 2. 성인 콘텐츠 제외 및 전연령 기준선 명시

- PC-98 원작(1995)에 존재했던 성인용 이벤트 CG 및 관련 대사는 본 역기획서와 `verified_data/`에서 의도적으로 제외했으며, **세가 새턴(1997) 및 `EVE burst error R`(2016~)**의 전연령 추리·서스펜스 구성만을 기준으로 삼았다.
- 향후 PlayHub 버전 구현 시에도 추리 서스펜스·멀티 사이트·정보 비대칭 본연의 재미에 집중하며 성인용 콘텐츠는 복원 대상에서 제외한다.
