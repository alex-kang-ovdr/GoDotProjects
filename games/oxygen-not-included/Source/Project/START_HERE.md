## HTML 한 파일로 실행

소스 ZIP의 **`dist/standalone.html`**을 브라우저에서 여세요. 별도 제공되는 `Breath_Colony_v4_Standalone.html`도 같은 파일입니다. JavaScript와 CSS를 모두 포함해 외부 패키지 설치나 서버 없이 사용할 수 있습니다. 인터넷에서 불러오는 글꼴·이미지·스크립트도 없습니다.

브라우저나 기기 정책이 로컬 파일 저장을 제한하면 자동 저장 대신 **조작법 → 세이브 내보내기**로 JSON을 보관하세요. 파일을 이동하거나 브라우저를 바꿀 때도 JSON으로 기지를 옮기는 것이 확실합니다.

## 소스를 수정하며 실행

`dist/index.html`은 여러 ES 모듈로 나뉜 개발용 진입점입니다. 이 파일은 HTTP로 여세요. Python 3가 설치되어 있다면 ZIP을 풀고 `package.json`이 있는 폴더에서 실행합니다.

```sh
python3 -m http.server 8080 --directory dist
```

브라우저에서 `http://localhost:8080`을 여세요. Windows에서 `python3` 대신 `python` 또는 `py -3`을 사용하는 환경에서는 해당 명령으로 바꿉니다. 종료는 터미널의 `Ctrl+C`입니다. 다른 정적 서버를 사용해도 `dist/`를 웹 루트로 지정하면 됩니다.

코드를 수정한 뒤 단일 HTML 실행판을 다시 만들려면 Node.js가 있는 환경에서 실행하세요.

```sh
npm run build:standalone
```

외부 빌드 의존성이나 `npm install`은 필요하지 않습니다.

## 첫 플레이 순서

1. `Space`로 시간을 멈추고 산소 확산기·축전지·연구 작업대와 농장을 예약합니다.
2. 채굴한 고체는 현장에 남습니다. 대원이 코어나 보관함까지 운반하면 사용할 수 있는 비축에 들어갑니다. **물류** 탭에서 더미·화물·공간·막힌 이유를 확인하세요.
3. 농장·연구·생활 시설에 청수관을, 화장실·세면대·탱크에 오수관을 연결합니다. 파란 관과 갈색 관은 같은 칸에 설치할 수 있습니다.
4. 오른쪽 웅덩이의 취수 → 오수 정화 → 전해 → 수소 발전을 연결합니다. 취수기 건설자가 기지로 돌아온 뒤 통로를 방수 타일로 막아 물이 농장으로 넘치지 않게 합니다.
5. 조리대·식탁·냉장고를 준비합니다. 조리대는 **수확 식량 2 + 청수 0.3L + 전력 10W + 대원 작업**으로 조리식 3을 만듭니다. 조리대 선택 후 목표 비축량을 조절하세요.
6. 세 대원의 교대를 **주간·엇교대·야간**으로 나누고 침상에 접근할 수 있게 합니다. 급한 호흡·식사·용변은 교대보다 우선합니다. 계획 수면은 침상에서 실제로 쉬어야 기록됩니다.
7. 생산과 생활을 연결해 기존 **정착 유지 240초**를 달성합니다. **구역** 탭에서 침실과 식당을 만들고 각 방의 판정 이유를 확인하세요. 두 공간에는 기밀문과 주변 벽·바닥·천장이 필요합니다. 밀폐하면 공기 교환이 줄어드므로 구역 카드의 평균 산소를 확인하고, 필요한 방에는 확산기를 추가하세요.
8. 생산적인 작업으로 경험을 쌓은 대원의 **기술** 버튼을 눌러 굴착·공학·생활에 포인트를 배분합니다. 경험 60마다 포인트 1개이며 최대 숙련 6까지 성장합니다. 기술은 자동으로 배분되지 않습니다.
9. 연구 45를 달성하면 **산소 충전소**를 짓고 전선을 연결합니다. 충전소는 실제 주변 산소를 압축하고, 대원은 방문해 휴대통을 채웁니다. 저산소 작업에서 휴대 산소가 소비되는지 대원 카드와 구역 탭에서 확인하세요.
10. **목표** 탭의 5단계, 20개 목표를 완료합니다. 최종 단계는 침실·식당, 기술 3점 이상 배분, 실제 휴대 산소 호흡 30초, 사용 가능한 충전소와 기존 정착 조건을 함께 180초 연속 유지합니다. 실패한 조건은 점검 목록에 표시됩니다.

좌표별 추천 배치, 설비 수지, 추가 금속 채굴과 장기 운영 경로는 [README.md](README.md)에 있습니다. 게임 안 **조작법 → 첫 정착 추천 순서**도 참고하세요.

## 완성 기지 관찰

`examples/self-sustaining-colony.json`은 자원·연구·대원 상태를 강제로 변경하지 않고 공개 게임 명령만으로 **20개 목표를 달성한 예제**입니다. **조작법 → 세이브 가져오기**에서 이 JSON을 선택하세요. 현재 기지를 남기려면 먼저 내보내기로 보관합니다.

가져온 뒤 `Space`로 멈추고, `R` 구역 화면과 `H` 운반 화면, `V` 배관 화면을 살펴보세요. 구역 탭에서 방의 효과와 산소 충전 상태를, 대원 카드의 기술 버튼에서 실제 배분을 확인할 수 있습니다. 문을 선택하면 자동 출입·열어 두기·잠금으로 바꿀 수 있습니다. 예제는 직접 가져올 때만 적용됩니다. 기본 시작 상태는 새 기지입니다.

## 조작

| 입력 | 동작 |
|---|---|
| `Space`, `1`·`2`·`4` | 일시정지, 진행 속도 |
| `D`, `X`, `Esc` | 채굴, 작업 취소, 선택 도구 |
| `O`·`T`·`P` | 산소·온도·전력 보기 |
| `V`, `H`, `R` | 배관·운반·구역 보기 |
| `L`, `Q` | 청수관·오수관 도구 |
| 드래그 | 채굴 영역·건설·배선·배관 지정 |
| 마우스 휠 / 우클릭 드래그 | 확대·축소 / 화면 이동 |
| 대원 초상화 | 해당 대원의 위치로 이동 |

작은 화면에서는 상단 정보 버튼으로 대원·운영·물류·구역 패널을 엽니다. 건설 목록은 세로 화면 아래, 가로 화면 왼쪽에 있습니다. 터치는 도구 선택 후 타일을 누르며, 두 손가락으로 화면을 이동하고 확대합니다.

## 저장과 이전 버전

15초마다 현재 브라우저에 자동 저장하고, 수동 저장과 JSON 내보내기·가져오기를 지원합니다. v1·v2·v3 저장은 기존 진행을 보존하며 v4로 변환됩니다. 이전 버전에서 승리했더라도 새 확장 목표가 추가되므로 4.0의 최종 승리는 총 20개 목표를 완료한 뒤 달성합니다. 이전 작업을 소급해 경험이나 휴대 산소를 지급하지 않으며, 새로운 작업과 충전부터 쌓입니다. 변환 직후에는 일시정지 상태에서 안내를 확인할 수 있습니다.

배포 주소, 로컬 HTTP 주소, 단일 HTML 파일, 다른 브라우저는 저장 공간이 서로 다를 수 있습니다. 기지를 옮길 때는 JSON을 사용하세요.
