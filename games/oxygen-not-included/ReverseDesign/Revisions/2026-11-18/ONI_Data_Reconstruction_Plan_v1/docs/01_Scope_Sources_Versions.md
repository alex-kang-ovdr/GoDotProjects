# 01. 복원 범위·출처·버전 관리

검토일: 2026-11-18 (한국 기준). 산출물 버전: **데이터·기획 팩 r1**. 비교 대상: **숨 4.0.0**, 커밋 `bb78805aef453cae4a79bed91daf88dfdf3535b3`.

## 1. 무엇을 복원했는가

공개된 게임 설명, 개발사 변경 기록, 커뮤니티 수치표에서 확인한 설비·물질·대원·작물·식품·방·연구의 사실을 독립적인 JSON/CSV로 재구성했다. 원작 실행 파일, 설치 폴더, 개발사 내부 테이블, 월드 생성 설정 원본을 확보한 결과가 아니다. 데이터 이름은 대상을 식별하기 위해 사용했고, 게임의 그림·음악·대사·소스 코드를 옮기지 않았다.

이 묶음의 목적은 숨 4.0을 원작 구조에 더 가깝게 개선하는 **검증 가능한 입력 자료와 구현 명세**를 제공하는 것이다. 브라우저 게임의 새 버전을 구현했다는 의미가 아니다. 이미 배포된 4.0의 코드·진행 밸런스는 이번 문서 작업의 비교 기준이다.

## 2. 우선 복원 범위

| 영역 | 이번 범위 | 후속 검증 또는 확장 |
|---|---|---|
| 물질 | 주요 기체·물·암석·금속 16종의 비열·전도도와 일부 표시 전이점 | 전체 원소, 정확한 상변화 경계, 생성·변환 조건 |
| 설비 | 초중반 산소·전력·급수·정화·열관리·재료 생산 | 모든 장식·우주·방사선·DLC 전용 설비 |
| 대원 | 일반 유기 대원의 기본 소비, 일정, 사기·기술 구조 | 모든 특성, 질병·행동 확률, 바이오닉 대원 |
| 식량 | 초중반 식품·작물과 일부 조리 레시피 | 전체 DLC 작물, 변이, 모든 조미료 |
| 방 | 침실·식당·위생·연구·휴양 등 주요 공간 조건 | 전체 장식 태그·가구 판정의 실행 파일 대조 |
| 연구 | 초급/고급 연구 자원과 초반 노드의 구조 | 원작 전체 기술 DAG의 빌드 고정 추출 |
| 세계·생물 | 확장 설계와 복원 절차 | 바이옴/간헐천/크리터 확률 원본은 미확보 |

## 3. 신뢰도는 값마다 기록한다

| 분류 | 뜻 | 사용할 수 있는 판단 |
|---|---|---|
| `official_patch` / `developer_official` | Klei가 해당 변경을 공식 기록 | 변경 존재·대상 버전·콘텐츠 범위 |
| `community_reference` / `documented_community` | 공개 커뮤니티 위키나 DB에 명시 | 레퍼런스 수치 후보; 원본 빌드 검증을 대신하지 않음 |
| `community_display_rounded` | 웹 화면에서 반올림해 표시한 값 | 비교·계획용. 정확한 전이 임계값으로 직접 삽입하지 않음 |
| `derived` | 확인한 입력을 식에 넣어 계산 | 입력 출처와 계산식이 함께 있을 때만 재현 가능 |
| `code_observed` | 숨 4.0 코드에서 직접 확인 | 현재 구현의 동작과 제약 |
| `proposed` | 이번 고도화의 설계 선택 | 구현·측정 전 제안. 원작 수치로 표시하지 않음 |
| `unresolved` / `not_verified` | 미확인 또는 충분한 문맥 없음 | `null`로 유지하고 수집 작업을 등록 |

전체 데이터셋의 `source_game_build`를 비워 두는 이유는 일부 페이지가 정식판과 테스트판, DLC의 공통 변경을 함께 다루기 때문이다. 공식 패치가 새 기능을 확인해도 그 페이지가 제공하지 않는 개별 숫자까지 공식으로 승격하지 않는다.

## 4. 정식판과 테스트판을 구별한다

공식 업데이트 인덱스를 열람했을 때 최근 정식 Release 항목은 **744825 / 2026-07-28**, 최근 테스트 항목에는 **763612 / 2026-11-17**이 표시되어 있었다. U60 761015 공지는 공개 테스트 시작이라고 명시한다. 이는 **열람 당시 공식 목록**이며 이후 최신 버전을 예측하지 않는다. [R01](https://kleiforums.com/game-updates/oni-alpha/) · [R05](https://kleiforums.com/game-updates/oni-alpha/761015-r2830/)

기획의 목표는 기본 게임 공통 시스템이다. 확장팩이 설치되어야만 쓰는 생물·건물과, 확장팩 출시와 동시에 모든 버전에 적용된 시스템 변경을 별도 표시한다. 최신 DLC 목록이나 신규 콘텐츠가 존재한다는 이유로 기본 게임에 모두 노출시키지 않는다. [R02](https://www.klei.com/games/oxygen-not-included)

## 5. 이번 조사에서 걸러낸 오류 유형

1. **페이지 제목과 숫자 대상이 다른 검색 결과.** 물질 페이지는 여러 다른 물질의 툴팁을 포함한다. 수소 페이지에 나타난 액체의 열전도도, 오염 산소 페이지에 나타난 액체 산소 수치를 기체 값으로 가져오면 잘못된 테이블이 된다.
2. **표시 반올림을 정밀 상수로 오인.** 물의 `99.4°C` 표시는 내부 상변화 경계가 정확히 그 값이라는 증거가 아니다.
3. **유량과 포트 능력 혼동.** 기체 펌프의 흡입률과 연결 기체 배관의 최대 유량은 다르다. 설비 페이지의 Transport 항목만으로 생산률을 정하지 않는다.
4. **옛 공략과 현 문서 혼합.** 방 사기나 물풀의 요구 자원은 패치로 달라졌다. legacy 행을 현재 행과 합산하지 않는다.
5. **단위만 붙인 가짜 물리량.** 숨 4.0의 산소 공간값이나 공용 수소 단위에 `kg`라는 표지만 붙여서는 원작 데이터가 되지 않는다.

## 6. 공식 변경 사례의 적용

736649의 공통 변경에는 질식 대원의 무력화·CPR, 물풀의 표백석 요구 제거 및 급수 요구 증가가 있다. 따라서 구조 작업과 최신 작물 분기를 개선 후보에 포함했다. 다만 CPR 시간·회복량, 물풀의 정확한 급수량은 해당 패치 문장만으로 정할 수 없어 다른 근거 또는 추가 검증이 필요하다. [R04](https://kleiforums.com/game-updates/oni-alpha/736649-r2750/)

## 7. 원본 대조가 가능한 후속 수집 절차

정당하게 접근 가능한 게임 설치 자료가 제공되면, 먼저 버전·브랜치·DLC·모드 목록과 관련 파일 해시를 기록한다. 그 뒤 허용된 게임 내 데이터 화면, 제공된 설정/데이터 파일, 사용자가 직접 내보낸 기록에서 필요한 사실만 추출한다. 출처 파일 전체나 실행 코드의 무단 재배포를 복원 완료 조건으로 삼지 않는다.

동일 엔티티에 대해 `entity_id + field + branch + build + content_scope`를 키로 비교하고, 값이 다르면 새 레코드와 변경 이유를 남긴다. 검증된 버전 하나를 고정한 다음 새 게임 규칙 세트에 반영한다. 미검증 값에 0을 자동 삽입하거나 최근 검색 결과로 오래된 검증값을 무조건 덮어쓰지 않는다.

사용자 지정 [나무위키](https://namu.wiki/w/Oxygen%20Not%20Included)는 이번 직접 열람이 실패해 수치 근거로 사용하지 않았다. 대신 개별 데이터에는 실제로 회수한 출처를 기록했다.
