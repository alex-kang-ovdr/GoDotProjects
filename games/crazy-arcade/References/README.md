# Bubble Arena — Crazy Arcade BnB-inspired web prototype

Open `index.html` directly in Chrome, Edge, Firefox or mobile browser. No server, dependencies, or internet required.

- Arrow keys / WASD: move
- Space: place water balloon
- R: restart
- Touch: direction pad and bomb button

Includes destructible blocks, powerups, chain explosions, 3 AI opponents, trapping and match result. This is an original prototype inspired by the game mechanics, not an extraction of official assets or verified original game parameters.

`reference_data_v5.zip` is the previous reconstructed reference dataset, preserved unchanged.
