# Princess Maker 2 역기획서 — 확장 통합판

시스템별 21개 기본 문서(00~20)와 실행 규칙·정량 테이블·이벤트·엔딩·전투·테스트·검증 매트릭스(21~26), JSON 예시 데이터 포함.

**주의:** 21~25 문서의 수치·공식·임계값은 원작을 역컴파일하거나 실측한 결과가 아니라 **웹 재구현용 제안 규칙**이다. 원작과 1:1 일치한다고 주장하지 않는다. 26번 문서에서 검증 공백을 관리한다.

읽기 순서: 00 → 01 → 02 → 21 → 22 → 23 → 24 → 25 → 26. 다른 기본 시스템 문서는 필요할 때 참조.
