# Crypt of the Fallen v15 — PC·모바일 조작 / 원작 시스템 반영

다크앤다커의 기본 조작과 일부 클래스·전투·탈출 규칙을 반영한 오프라인 1인칭 WebGL 프로토타입입니다. **원작 시점 조작은 마우스이며, 방향키 회전은 이 웹 버전의 선택 보조 기능입니다.**

## 바로 실행

1. 단일 HTML 파일을 새로 받아 브라우저에서 여세요. ZIP은 압축을 풀고 `index.html`을 열면 됩니다.
2. 첫 화면에 **V15 / ORIGINAL CONTROLS**가 표시되는지 확인하세요. 이전 HTML을 열어 둔 탭은 자동 갱신되지 않습니다.
3. Fighter / Ranger / Wizard를 고른 뒤 `전투 연습장`에서 조작을 확인하거나 `던전 입장`을 누르세요. 연습장은 보관 장비를 소비하거나 보상을 저장하지 않습니다.
4. 휴대폰은 왼쪽 원형 패드로 이동하고 오른쪽 빈 공간을 드래그해 시점을 돌립니다. 버튼이 나타나지 않으면 메뉴의 `터치 조작 → 항상 표시`를 사용하세요.

재질·셰이더·코드가 HTML에 포함됩니다. 실행 시 외부 CDN이나 서버 설치는 필요하지 않습니다. Windows에서는 `Start_Game.bat`도 사용할 수 있습니다. 브라우저의 WebGL 지원이 필요합니다. 모바일에서는 가로 화면이 시야 확보에 편리하며 세로 배치도 포함합니다.

| 동작 | PC | 모바일 |

| 클래스 스킬 1 / 2 | Q / E | 클래스별 스킬 버튼 2개 |
| 상자·시체 수색 / 포탈 탈출 | F 유지 | 수색 유지 |
| 걷기 / 웅크리기 | Shift 유지 / Ctrl 유지 | 걷기 유지 / 웅크리기 유지 |

방향키 시점은 설정의 `방향키 시점 보조 (웹 편의)`를 켜면 사용할 수 있습니다. PC에서 Pointer Lock이 실패할 때도 보조 시점이 활성화됩니다. A/D는 좌우 이동이며 몸의 회전은 마우스·드래그로 처리합니다.

### 모바일 동시 입력과 취소

이동·시점·행동은 서로 다른 포인터로 동시에 조작할 수 있습니다. 패드나 버튼 밖으로 손가락을 옮겨도 최초로 잡은 역할을 유지합니다. 손을 떼면 해당 손가락의 입력만 해제합니다.

활과 주문은 준비가 끝난 뒤 손을 떼어야 발사됩니다. 준비 중에 놓으면 자원을 소비하지 않습니다. `pointercancel`, 캡처 상실, 화면 회전, 앱 전환, 배낭·일시정지·주문 선택에서는 충전 입력을 취소하며 발사하지 않습니다. 터치에는 마우스 잠금이 필요하지 않습니다.

## 클래스별 플레이

| 클래스 | 무기 세트 | Q / 모바일 첫 스킬 | E / 모바일 둘째 스킬 |
|---|---|---|---|
| Fighter | 아밍 소드·방패 / 쇠뇌 | 질주 | 두 번째 바람 |
| Ranger | 롱보우 / 아밍 소드 | 백스텝 | 야전 식량 |
| Wizard | 지팡이 / 단검 | 주문 기억 | 명상 |

- **Fighter:** Shift는 천천히 걷기입니다. 빠르게 이동하려면 Q 질주를 사용합니다. 회복은 사용 횟수가 제한된 E와 물약·휴식으로 관리합니다.
- **Ranger:** 공격을 유지해 활을 당기고, 준비 완료 후 놓아 발사합니다. 장전된 화살이 떨어지면 R 또는 특수 / 장전 버튼을 누릅니다. 백스텝에는 공통 무적 회피 판정이 없습니다.
- **Wizard:** Q로 주문을 고르세요. PC는 Q를 유지하며 주문 위에 포인터를 놓고 Q를 놓거나, 주문을 클릭하거나, 1~3으로 선택할 수 있습니다. 모바일은 주문 기억을 누른 뒤 원하는 주문을 누릅니다. 지팡이의 주 공격은 근접 타격이며, 보조 행동을 유지해 화염구·얼음 화살·전격을 시전합니다. 횟수가 부족하면 E 명상을 사용합니다. R로 선택 주문을 해제하면 지팡이 방어를 사용할 수 있습니다.

공통 스태미나·마나 게이지와 공통 회피 버튼은 제거했습니다. HUD는 클래스 스킬의 남은 횟수·재사용 시간, 장전 수량, 선택 주문의 남은 횟수를 표시합니다.

## 탐험 → 탈출 → 보관 → 다음 출전

상자나 시체를 F / 수색 버튼으로 조사하고 6×4 배낭에 전리품을 넣으세요. 아이템을 드래그해 배치하거나 회전할 수 있습니다. 클래스가 사용할 수 있는 장비만 장착할 수 있으며, 교체한 장비를 넣을 공간이 없으면 교체하지 않습니다. **배낭과 주문 선택 화면을 열어도 던전 시간과 적은 계속 움직입니다.**

푸른 포탈로 탈출하면 전리품과 장착 장비를 아이템으로 보관합니다. 아이템을 자동으로 골드로 바꾸지 않으며, 느슨한 골드만 바로 적립합니다. 홈의 `보관함`에서 직접 판매하거나, 현재 선택한 클래스의 다음 출전 장비를 지정하세요. 기본 지급 장비는 보관할 수 있지만 가치가 0이고 판매할 수 없습니다.

출전 시작 시 선택 장비가 보관함에서 빠집니다. 사망·출전 포기·진행 중 페이지 재열기는 해당 출전에 가져간 장비를 잃는 결과로 처리됩니다. 남은 보관함과 이전 골드는 유지됩니다. 중복 정산과 출전 중 새로고침에 의한 장비 복제를 방지합니다.

## 분석 근거와 구현 범위

- `docs/ORIGINAL_ALIGNMENT_V15.md`: 원작 근거, 기본 조작, 구현·근사·미구현 구분, 출처 URL.
- `reference/R1/data/`, `reference/R1/docs/`: 사용자가 제공한 원작 분석 R1 자료를 원래 표시와 함께 복원.
- `src/rules.js`: 실제 게임이 사용하는 클래스·스킬·주문·일부 무기 타이밍과 근사값 설명.

완전한 원작 복제는 아닙니다. 오프라인 싱글플레이이며 세 클래스와 제한된 무기·주문만 구현합니다. 원작 맵·몬스터 패턴·PvP·서버 판정·시장·퀘스트·전체 특성·정확한 애니메이션/충돌체는 포함하지 않습니다. 명상 회복 계산, 이동 단위 환산, 방어 회복, 일부 공격·장전 수치, 임시 방어도 공식은 근사입니다. 사용 준비한 소모품은 카운터로 관리하며 원작의 모든 스택·도구 슬롯 모델을 재현하지 않습니다.

횃불 뷰모델은 제공하지만 조명은 기존 웹 렌더러의 상시 랜턴을 사용합니다. 원작의 횃불 장비·광원·소음·은신 시스템 전체를 구현한 것은 아닙니다. 웹의 일시정지, 시드 입력, 지도 토글, 방향키 보조도 원작과 구분됩니다.

## 저장과 이전 버전

새 저장 키는 `crypt_v15_profile`입니다. 같은 브라우저 저장 영역에서 `crypt_v13_save`의 골드·출전·탈출 통계를 가져옵니다. 이전 골드 저장본에는 아이템이 없으므로 과거 아이템을 임의로 만들어 복구하지 않습니다.

파일명·경로·브라우저가 바뀌면 저장 영역이 달라질 수 있습니다. 특히 Android의 `content://` 열기에서 기기별 저장 공유를 보장하지 않습니다. 저장이 제한된 환경은 홈에 안내하며 현재 탭의 상태만 유지합니다.

## 개발·검사

```sh
python3 build.py
python3 tests/run_all.py
```

게임 실행에는 위 개발 도구가 필요하지 않습니다. 소스를 수정한 경우 빌드해야 `index.html`에 반영됩니다. 검사는 Python 표준 라이브러리와 Node를 사용합니다.

검증 결과는 `tests/TEST_REPORT.md`에 기록합니다. 실제 앱·입력·시뮬레이션·보관함 코드를 Node에서 실행한 검사이며 DOM 이벤트 fixture와 렌더러 인터페이스 대체를 사용합니다. 실제 Android·Chrome의 화면·멀티터치·`content://` 실행과 GPU 성능 검증은 아직 완료하지 못했습니다. 브라우저 실행은 이 환경의 권한 제한으로 차단되었습니다.

`tests/baseline_v14/`, `tests/baseline_v14_1/`, `docs/baseline_v14/`는 이전 버전 기록이며 v15의 검사 결과나 화면 캡처가 아닙니다.
