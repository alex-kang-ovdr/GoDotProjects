# 작성 및 재현 방법

R1의 정규 데이터는 자동 전체 스크래퍼 결과가 아니라 55개 출처를 확인하여 선별한 사실·수치의 수동 정규화 결과다. 출처 제목·URL·부분 위치·선언 패치·확인일을 함께 저장했다. 인터넷 없이 데이터 정합성을 재검사할 수 있지만, 변경된 웹페이지에서 같은 숫자를 다시 재현하는 보장은 없다.

공식 자료는 선별된 시즌/핫픽스 내용만 정규화했다. 해당 페이지의 모든 변경사항을 전사한 패치 DB가 아니다. 커뮤니티의 자동 수치와 수동 해설을 섞어 내부 엔진 구현으로 단정하지 않았다. 일부 페이지가 최신 헤더를 표시해도 수동 문구는 오래됐을 수 있다.

v13은 업로드 ZIP의 src/core.js와 src/game.js에서 Node export를 조회하고 실제 상수를 추출했다. prototype/v13_extracted.json에 원본 해시가 있다. 원본 파일을 수정하거나 새 플레이 버전을 생성하지 않았다.

JSON이 기준이다. CSV는 동일 ID/행을 동일 순서로 저장하며 nested object/array는 JSON문자열이다. Excel은 검토 편의를 위한 열 구성으로 원본 필드가 모두 보이지 않을 수 있으므로 완전한 원본 레코드는 JSON 또는 viewer 상세 창을 사용한다. Excel의 파생 시간 열은 수식이며 원본 시간값을 변형하지 않는다.

schemas는 R1의 자료형/필수필드/관계를 설명한다. 새로운 자료를 추가할 때 evidence와 source를 먼저 만들고, 실제로 확인한 필드만 채우며, 패치가 다른 값은 새 스냅샷 파일로 보관한다. 이전 데이터 파일을 덮어쓸 때는 원본 출처·수치 diff를 남긴다.

승인 전 문의하거나 원작 파일이 없다는 이유로 데이터를 발명하지 않았다. 이번에 확보하지 못한 부분은 unknowns의 수집 계획으로 남겼다.
