# 미복원 데이터 실측 및 재현 프로토콜

## 증거 캡처 공통 필드

각 측정에 game_patch, mode, class, level, all_equipment, perks, skills, buff_list, target_variant, map_floor, fps, capture_clock, repetition_count, measured_by, source_location를 기록한다. UI 표기값과 실제 동작 측정값을 서로 다른 컬럼에 둔다. 기본값이 변한 패치의 전후 데이터를 한 평균으로 합치지 않는다.

## 공격 시간과 궤적

행동속도 0% 세트부터 측정한다. 버튼 입력, 준비 모션 시작, 실제 유효 첫 접촉, 마지막 접촉, 다음 공격 시작, 대기 복귀를 프레임별로 기록한다. 단발·연계·다른 공격 입력·벽 충돌·방패 충돌을 각각 수행한다. 60fps의 1프레임은 약16.7ms로 관측 정밀도 한계이며, 비디오 프레임보다 정밀한 수치를 사실처럼 적지 않는다.

다중 표본에는 평균뿐 아니라 최소/최대/중앙값, 입력 지연, 프레임 드롭을 보관한다. 타격을 반복할 때 장비 롤·적 등급·거리·시선 pitch를 고정한다. 원본 애니메이션을 확보하지 못한 상태에서 세계 좌표 궤적을 추정하면 reconstructed_motion으로 표시한다.

## 피해·방어

기본 피해 / 추가 무기 / 추가 물리 / true / Power Bonus를 한 요소씩 바꾼다. 동일 대상의 head/body/limb 위치를 바꿔 2×N 행렬을 작성한다. HF132 50% 비율은 계수 적용 대상별로 비교하며 전체 피해를 나눠 맞추지 않는다. 방어는 방패 크기·자세·impact 차이·공격자 연계 유지 여부를 별도 기록한다.

## AI

시야 내/벽 뒤/문 뒤/다른 층, 소음만, 원거리 피해, 추적 후 LOS 상실, 제3자 피해를 각각 실험한다. 관찰된 타깃 전환으로 내부 위협도 수식을 단정하지 않는다. 재현 가능한 입력/출력 규칙을 먼저 작성한다. 보스 단계는 HP구간만이 아니라 시간·누적피해·패턴횟수·거리 변화와 함께 기록한다.

## 루팅 확률

현재 기준 패치·컨테이너 타입·맵·난이도·Luck·파티·원시 드롭 수를 기록한다. 아이템 단위와 상자 단위 확률의 분모를 혼동하지 않는다. N회 중 0회 관측했다고 확률0%로 저장하지 않는다. 양의 정수 드롭 수, 보장 슬롯, 독립 슬롯, 조건부 가중치 중 어느 모델인지 먼저 확인한다. 적은 표본은 measured_estimate로만 공개하며 official_drop_rate로 승격하지 않는다.

## 지도 및 인벤토리

맵 모듈 크기와 타일 크기를 분리한다. 문/연결점/탈출구/시작점은 좌표계·축·고저차를 포함한다. 가방은 셀 수, 아이템 실제 footprint, 회전 가능 여부, 장비 슬롯, 겹침·버리기·시체 교체·가득 찬 보관함을 직접 확인한다.

## 자동 승인 금지 조건

출처 버전 미상, 원시 탭/희귀도 매핑 미완료, 단위 불명, 순환 참조, 서로 다른 출처 간 충돌, 원본 없이 추정한 AI 선택확률, prototype fallback이 하나라도 있으면 해당 기능을 원작 완성으로 표시하지 않는다. 일부 검증된 수치만 사용한 경우 검증 범위를 명시한다.
