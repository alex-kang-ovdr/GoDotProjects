# Crypt of the Fallen v14.1 — 모바일 이동 조작 수정

v14 그래픽 버전에 터치 입력을 연결한 수정본입니다. 기존 버전은 WASD와 마우스 입력만 처리해, 휴대폰에서 던전 화면은 보이지만 이동할 수 없었습니다.

## 실행

- **휴대폰:** 새로 받은 단일 HTML 파일을 브라우저에서 열고 `던전 입장` 또는 `전투 연습장`을 누르세요. 첫 화면의 `V14.1 / TOUCH CONTROL FIX`를 확인하세요. 이전에 열어 둔 v14 탭에는 수정이 자동 반영되지 않습니다.
- **ZIP:** 압축을 해제한 뒤 `index.html`을 여세요. Windows에서는 `Start_Game.bat`도 사용할 수 있습니다.
- 모든 코드와 재질은 HTML에 포함됩니다. 게임 실행에 서버나 외부 CDN 다운로드가 필요하지 않습니다.

세로·가로 화면용 배치를 포함하며, 가로 화면에서 주변을 더 넓게 볼 수 있습니다. 실제 Android 기기의 `content://` 파일 열기와 기종별 GPU 성능은 이번 환경에서 검증하지 못했습니다.

## 휴대폰 조작

| 화면 조작 | 동작 |
|---|---|
| 왼쪽 원형 패드를 밀기 | 전후좌우 이동. 조금 밀면 천천히 이동 |
| 오른쪽 빈 화면을 드래그 | 위아래·좌우 시점 회전 |
| 공격 | 선택 중인 근접 무기 / 활 / 화염구 사용 |
| 방어를 누르고 유지 | 방패 방어. 양손 도끼는 방패 사용 불가 |
| 수색을 누르고 유지 | 상자·시체 수색 또는 포탈 탈출. 손을 떼면 취소 |
| 달리기를 누르고 유지 | 이동 중 달리기 |
| 점프 / 회피 | 점프 / 이동 방향으로 회피 |
| 하단 근접 / 활 / 마법 | 무기 방식 전환 |
| 하단 물약 / 장전 | 회복 물약 사용 / 예비 화살 장전 |
| 상단 배낭 / 지도 / 메뉴 | 인벤토리 / 미니맵 표시 / 일시정지·설정 |

이동, 시점 회전, 버튼 입력은 서로 다른 손가락으로 동시에 사용할 수 있습니다. 손가락이 패드나 버튼 밖으로 나가도 해당 입력을 유지하다가, 손을 떼면 해제합니다. 배낭과 메뉴를 열거나 앱을 전환하거나 화면을 회전하면 이동·방어·수색 입력을 초기화합니다.

`메뉴 → 터치 조작`에서 자동 감지 / 항상 표시 / 키보드·마우스 전용을 선택할 수 있습니다. `터치 시점 감도`는 마우스 감도와 별개입니다. 휴대폰에서는 자동 감지 또는 항상 표시를 사용하세요.

가방을 열어도 적과 시간은 계속 진행됩니다. 인벤토리에서 아이템을 선택한 뒤 장착·회전 버튼을 사용하고, 위아래 스크롤로 주변 전리품을 확인할 수 있습니다.

## PC 조작

| 입력 | 기능 |
|---|---|
| WASD / 마우스 | 이동 / 시점 |
| 좌클릭 / 우클릭 | 공격 / 방패 방어 |
| 1 / 2 / 3 | 근접 / 활 / 화염구 |
| Shift / Space / Q | 달리기 / 점프 / 회피 |
| E 길게 / H / R | 수색·탈출 / 회복 / 장전 |
| I / M | 배낭 / 지도 |
| F1 또는 Esc | 일시정지·설정 |
| F2 | HUD 숨기기 / 표시 |

마우스 잠금이 지원되지 않을 때는 방향키로 시점을 조절할 수 있습니다.

## 변경 범위

- 독립 포인터 ID로 이동 패드·시점·행동 버튼을 처리하는 `src/touch.js` 추가.
- 터치 감지, 수동 표시 설정, 별도 시점 감도, 터치용 안내·수량 표시.
- `pointerup`, `pointercancel`, `lostpointercapture`, 일시정지·배낭·재시작·창 전환·화면 회전에서 입력 정리.
- 터치 조작은 Pointer Lock을 요청하지 않으며, 호환 마우스 이벤트에 의한 중복 공격을 차단.
- 이동 입력 정규화를 길이 1 초과일 때만 적용해 아날로그 속도를 보존. 기존 WASD 속도와 대각선 최고속은 유지.
- 휴대폰용 HUD, 세로·가로 조작부, 배낭·설정창 스크롤.

`src/core.js`, `src/renderer.js`, `src/scene.js`, `src/assets.js`는 v14와 동일합니다. 재질·조명·그림자·모델은 기존 v14 구성을 사용합니다. `src/game.js`는 이동 입력 정규화 한 줄만 변경했습니다. 원작 분석 R1 데이터나 새로운 게임 규칙을 이 수정에 추가하지 않았습니다.

## 저장

기존 `crypt_v13_save` 키와 스키마를 사용합니다. 브라우저가 동일한 저장 영역을 제공하면 기존 보관 골드와 호환됩니다. 다운로드 파일명·경로·브라우저 변경 시 저장 영역 공유는 보장되지 않습니다. 저장이 제한되면 메뉴에서 안내하며 현재 탭에서만 결과를 유지합니다.

## 빌드 / 검사

```sh
python3 build.py
node tests/test_core.cjs
node tests/test_touch_unit.cjs
# Playwright와 Chromium을 실행할 수 있는 개발 환경:
python3 tests/test_touch.py
```

게임 실행에는 위 개발 도구가 필요하지 않습니다. `src/`를 수정한 경우에는 `build.py`를 실행해야 단일 HTML에 반영됩니다.

검사 결과와 정확한 한계는 `tests/TEST_REPORT.md`에 있습니다. 이번 환경에서는 Chromium 실행이 제한되어 모바일 브라우저 자동 검사를 완료하지 못했습니다. Node 기반 입력 검사에서는 실제 앱·입력·게임 코드를 실행하고 화면·렌더러 인터페이스만 대체했습니다. 이 검사를 실기기 터치 검사나 WebGL 화면 검증으로 해석하면 안 됩니다.

`tests/baseline_v14/`의 결과와 `docs/*.png`는 수정 전 v14의 기록입니다. v14.1의 신규 실행 결과나 모바일 화면 캡처가 아닙니다.
