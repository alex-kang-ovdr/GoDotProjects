- 해제·취소·캡처 상실·메뉴·배낭·재시작·회전·앱 전환에서 입력 초기화.
- 터치에서는 Pointer Lock 요청 생략, 터치 호환 마우스 공격 중복 차단.
- 터치 감지/표시 설정 및 독립 감도, 모바일 HUD와 스크롤 가능한 메뉴.
- game.tick의 이동 정규화만 수정해 작은 조이스틱 입력을 느린 이동으로 반영.
- 기존 그래픽 소스 3개와 공통 core.js는 v14와 바이트 단위 동일.
- v14 검사 결과는 tests/baseline_v14로 보관. 신규 결과는 tests/TEST_REPORT.md 참조.
- 실제 Android 기기 및 content:// 실행은 미검증. 현재 브라우저 실행 환경 제한을 별도 기록.
