# Crypt of the Fallen v14 — Light & Stone

Dark and Darker형 오프라인 1인칭 던전 프로토타입의 그래픽 개선 버전입니다.
이번 버전은 **원작 에셋을 복제한 리마스터가 아니라, 자체 제작 재질·메시·셰이더를 적용한 저폴리 그래픽 구현물**입니다.
v13의 전투 / 몬스터 / 아이템 / 탈출 규칙은 유지했습니다. `src/core.js`, `src/game.js`는 v13과 바이트 단위로 같습니다.
별도로 제작한 원작 분석 R1 데이터의 수치를 자동으로 게임에 덮어쓰지 않았습니다.

## 실행

1. ZIP을 모두 압축 해제합니다.
2. `index.html`을 데스크톱 Chrome 또는 Edge에서 엽니다. Windows에서는 `Start_Game.bat`도 사용할 수 있습니다.
3. `던전 입장` 또는 `전투 연습장`을 누릅니다.

단일 `index.html`에도 필요한 코드와 재질 데이터가 전부 포함됩니다. 런타임 CDN, 외부 이미지, 설치형 라이브러리, 서버 다운로드가 없습니다.
직접 열기를 제한하는 회사·학교 브라우저에서는 해당 관리 정책을 따라야 합니다. 이 패키지는 보안 정책을 우회하지 않습니다.
일반적인 개발 환경에서 HTTP 제공이 필요한 경우 이 폴더에서 `python -m http.server 8080`을 실행해 테스트할 수 있습니다. 게임 실행 자체에 Python이 필요한 것은 아닙니다.

**데스크톱 키보드·마우스용입니다. 터치 조작은 구현하지 않았습니다.**

표면 요철은 노멀 매핑입니다. 돌출된 모든 돌을 실제 물리 메시로 만드는 변위 매핑은 아닙니다.
금속·거칠기 표현은 단순화한 실시간 재질 모델입니다. 완전한 물리 기반 조명, 실시간 전역 조명이나 레이트레이싱을 구현했다고 주장하지 않습니다.

저사양 환경에서는 F1 → 그래픽 품질 `성능`, 렌더링 해상도 `75%`부터 확인하세요.

## 품질 프리셋

- **성능:** 랜턴 그림자와 발광 블러를 끄고 부수 입자를 줄입니다. 장면 2회 + 최종 합성 1회의 드로우 호출을 사용합니다.
- **균형:** 기본값. 1024 그림자 맵, 노멀 매핑, 발광·후처리를 적용합니다.
- **고품질:** 2048 그림자 맵과 강화된 표면 요철을 적용합니다. 더 많은 GPU 메모리와 연산이 필요합니다.

렌더링 해상도는 프리셋과 별도로 조절합니다. 특정 GPU의 60 FPS를 보장하는 설정은 아닙니다.
디버그의 `renderCpuMs`는 CPU의 렌더 제출 시간으로, GPU 프레임 시간이나 실제 FPS가 아닙니다.

## 원작 / 프로토타입 구분

이 게임은 싱글플레이 독립 프로토타입입니다. 원작의 스킬·장비·지도·드롭 확률을 완전하게 복원한 게임이 아닙니다.
원작 분석 데이터는 별도 패키지로 유지합니다. 이번 작업은 시각 시스템에 한정했습니다.
캐릭터는 외부 FBX/GLTF 스켈레탈 에셋이 아니라 코드로 생성한 관절 메시입니다.
방패와 무기 충돌은 기존 v13의 단순 충돌체·샘플링 판정을 유지합니다. 장식 메시의 모든 삼각형이 충돌체는 아닙니다.
던전 장식은 통행을 크게 막지 않는 벽·천장 중심 배치이며, 새로운 물리 장애물로 등록하지 않았습니다.

## 저장

v13과 같은 `crypt_v13_save` 키와 스키마를 사용합니다. 같은 브라우저 저장 영역에서는 기존 골드 데이터와 호환됩니다.
단, `file://`에서의 저장 범위와 다른 폴더·파일 간 공유 여부는 브라우저 정책에 따릅니다. 다른 경로로 옮겼을 때의 자동 승계는 보장하지 않습니다.
영구 저장이 불가능하면 메뉴에 안내하며 현재 탭에서만 결과를 유지합니다.
기존 규칙에 따라 탈출 아이템의 가치를 골드로 환산합니다. 실제 원작의 보관함·거래 경제와는 다릅니다.

재질 생성 시드는 14013입니다. 빌드할 때마다 외부 네트워크에 접속하지 않습니다.

## 검증 범위

- 공통 로직 55 / 브라우저 UI 통합 21 / 실제 입력 10 / 그래픽 파이프라인 26: **112개 검사 통과**.
- 300개 생성 시드 연결성 및 100개 스폰 유효성은 공통 로직 검사 안에 포함됩니다.
- 정상 픽셀 출력, 그림자·노멀·발광 on/off 이미지 차이, 옵션 변경, 해상도 변경, F2 키 충돌 등을 검사했습니다.
- Chromium 144.0.7559.96 / Xvfb / SwiftShader 환경입니다. 실제 하드웨어 GPU 성능 검증이 아닙니다.
- 환경 정책이 파일 URL을 차단하므로 완성된 HTML을 `about:blank`에 주입해 검사했습니다. 파일 탐색 제한을 우회하지 않았습니다.
- `file://` 직접 실행, 사용자 PC의 영구 저장, 모든 브라우저·GPU, 장시간 플레이 품질은 별도 검증 대상입니다.

자세한 결과는 `tests/TEST_REPORT.md`를 확인하세요. `docs/*.png`는 실제 브라우저 캡처입니다.
