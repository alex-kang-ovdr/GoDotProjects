# 변경 기록

## v15 · 2026-11-18 (KST)

### PC·모바일 입력

- WASD·마우스 기본 이동/시점 유지. 방향키는 선택형 웹 보조로 분리.
- Shift 걷기, Ctrl 웅크리기, Q/E 클래스 스킬, F 수색, Tab 배낭, X 무기 넣기, G 휴식, R 특수 행동 반영.
- 터치 조이스틱·시점 드래그·18개 행동 버튼을 같은 Game API로 연결.
- 활·주문 유지/해제와 취소를 구분하고 화면 전환·포인터 취소 시 오발 방지.

### 게임 시스템

- Fighter / Ranger / Wizard, 클래스 장비 제한, 두 무기 세트와 유틸리티 선택.
- 공통 스태미나·마나·무적 회피를 클래스 스킬/사용 횟수 모델로 교체.
- 무기 공격 타이밍 일부 복원, 충전 사격·주문, 방향 방어, 물약의 사용·지속 회복, 회복 가능 체력·휴식.
- 탈출 아이템을 실제 보관하고 직접 판매/출전 장비 선택. 재정산·재접속 중복 지급 방지.
- 실제 장비에 맞춘 지팡이·롱보우·쇠뇌·물약·횃불 뷰모델, 양손 방어·웅크리기·무기 넣기 상태 반영.

### 자료·검증

- 제공된 원작 분석 R1 data/docs 복원, 출처/버전/미확인 표시 유지.
- 원작 수치와 웹 근사값/미구현 항목 문서화.
- 신규 게임 규칙, 실제 앱 입력, 보관함, 실제 scene geometry 생성 검사.
- 이전 버전 보고서·스크린샷을 baseline 폴더로 이동. 실제 모바일 브라우저 화면 검사 미완료.
