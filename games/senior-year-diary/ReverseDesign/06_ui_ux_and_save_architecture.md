## 2. 화면 구성 및 HUD 레이아웃 `[재구성안]`

1. **상단 시간·캘린더 바 (Clock & Calendar HUD)**:
   - 날짜(`12월 28일 · D-10`), 디지털 시계(`14:30`, 5분 양자), 현재 존/장소명(`八十八町 · 市民病院`), 영업 마감 경고 표시.
2. **중앙 메인 뷰포트 (Scene / Interactive Town Map)**:
   - **탐색 모드**: 4존 탭(`야소하치 마을`, `야소하치 학원`, `키사라기 마을`, 12/29~30 한정 `동지온천`)과 클릭 가능한 41개 장소 노드.
   - **장면/대화 모드**: 장소 배경, 캐릭터 스탠딩 레이어, 텍스트 창, 분기 선택지 버튼.
3. **우측 보조 패널 (Phone / Notebook / Quick Save)**:
   - 자실(`loc_home_room`) 체류 시 **전화 대기/수신 버튼** 활성화.
   - 퀵 세이브/로드 슬롯 및 자동 체크포인트 접근(특히 12/27·12/28·12/31·1/5 권장 시점 자동 북마크).

## 3. 세이브 스냅샷 및 직렬화 아키텍처 `[확인]` `[재구성안]`

《동급생 2》는 단 하나의 시간 창 실수나 12/28 파트너 선택이 며칠 뒤 루트를 봉쇄하므로, **세이브·로드가 코어 메커니즘의 일부**로 기능한다. `[확인]`

### 3.1 SaveSnapshot JSON 구조 (`schema_version: "1.0.0"`)
```json
{
  "schema_version": "1.0.0",
  "slot_id": "slot_04",
  "saved_at_iso": "2026-11-22T14:30:00Z",
  "ui_mode": "easy",
  "day_index": 7,
  "current_minute": 600,
```

### 3.2 세이브 전략 `[재구성안]`
- **수동 슬롯 30개 + 일자별 자동 체크포인트(`auto_day_01` ~ `auto_day_16`)**: 원작에서 12/27~28 직전 세이브를 놓쳐 처음부터 재시작하던 좌절을 완화하면서도, 클래식 모드에서는 수동 슬롯만 강제하는 하드코어 옵션을 제공한다.
- **전역 갤러리/엔딩 도감(`global_meta.json`)**: 개별 세이브 슬롯과 분리하여 15인 히로인 엔딩(19종) 달성 기록과 해금된 이벤트 회상을 영구 보존한다.
- **무결성 검증**: 로드 시 `active_flags`가 `mutually_exclusive_groups` 규칙을 위반하지 않는지, `current_location_id`가 `locations.json`에 존재하는지 자동 검증한다.
