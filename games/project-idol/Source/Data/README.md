# PROJECT IDOL — Story Data Pack v1

PM2_Web_Playable_v8의 `characters.json`, `events.json`, `story_arcs.json` 구성에서 출발한 **별도 신규 게임 기획 데이터**입니다. 기존 PM2 웹 엔진에 바로 덮어써 실행되는 호환 패치가 아닙니다.

- 주연 8명 / 조연 12명
- 선택형 이벤트 120개 (대사 360줄, 선택지 360개)
- 스토리 아크 12개 / 엔딩 24개
- 캐릭터 대사 76개 / 엔딩 대사 48줄
- 조건·효과·플래그 JSON

## 설계 원칙
- PM2: 시간표, 능력치, 이벤트, 엔딩 우선순위
- 최애의 아이: 공적 이미지/내면, 방송 편집, 캐스팅, 관계 갈등
- VTuber/이세계아이돌: 개인 방송, 합방, 커뮤니티, 음악 팬덤
- 리센느: 긴 잠복기, 카탈로그 자산, 숏폼 밈, 역주행, 다음 컴백 전이

## 주의
실제 아티스트의 사생활·성격·대사 등은 재현하지 않았습니다. 등장인물과 대사는 모두 창작입니다. 이벤트 120개는 반복 가능한 시스템별 초안이며, 개별 연출의 다양화와 전용 분기 대사는 후속 제작 대상입니다.
