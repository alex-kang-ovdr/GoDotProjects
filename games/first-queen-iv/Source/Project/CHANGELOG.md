# v14 · Field Command

## 누적 패치 대신 통합 코어
v1~v13의 함수 덧씌우기, 활성 군단 roster 미러, 공유 전군 명령, 중복 클릭 이벤트 등록 방식 대신 Game / Renderer / UI의 책임을 분리했습니다. 별도 소스는 편집용이며 실행본은 여전히 하나의 HTML입니다.

## 사용자가 느끼는 변경
- 부대별 독립 명령과 선택/전군 명령 구분.
- 3D 병사 선택, 카메라 방향에 맞는 WASD, 우클릭 부대 이동.
- 진형 4종과 병종별 고유 스킬 4종.
- 무기·방패·지팡이, 공격·피격·쓰러짐 애니메이션.
- 단계별 UI, 전투 결과표, 연습 모드, 반응형 화면.
- 실제 성문 타격, 파괴 후 경로 갱신, 지연 증원.
- 전투 후 사망/철수/지원군을 원래 소속에 정확히 정산.
- JSON v13 마이그레이션과 검증 후 적용.
- WebGL 불가 시 CPU 3D 호환 모드, 실제 모드 표시.

## 규칙 변경
- F의 공용 광역 마법을 병종별 스킬로 교체. H 전술 회복은 유지.
- 고용은 6명 / 금화 60. 휴식은 전략 턴을 소비.
- 통로를 실제로 차단하는 공성 성벽·성문 배치로 교체.
- 미도착 지원군은 결과에서 제외하여 손실/복제 방지.
- 원작의 시스템과 수치를 확정 복원한 버전은 아님.

검증 결과와 환경 제약은 TEST_REPORT.md를 참조하세요.
