# v20 전술·편성 개선 계약

## 범위와 데이터 경계

v19의 플레이 가능한 엔진을 수정했다. 신규 원작 데이터를 추출하거나 의미를 승격한 버전이 아니다. data/* 및 src/source-data.js를 v19 원본과 비교해 바이트 동일성을 확인한다. 전술 명령·자동 철수·조건값·그래픽 간소화는 CUSTOM이다. 관측 원본과 실제 전장 런타임은 계속 분리한다.

## 명령 데이터

전투 부대에 `waypoints: {x,y}[]`, `autoRetreat: boolean`, 런타임 병사에 `individualRetreat: boolean`을 추가한다.

- 현재 목적지는 `g.anchor`이며 예약은 포함하지 않는다. 후속 목적지는 최대 8개다.
- 기본 이동은 예약을 교체한다. append 이동은 현재 이동이 있으면 후속 예약 끝에 붙이고, 없으면 새 이동을 시작한다.
- 전군 append 중 어느 부대가 상한에 도달했으면 모든 부대의 예약을 그대로 둔다.
- 무한대·NaN·목적지 없는 move는 거절한다. 유효한 좌표는 전장 안쪽으로 제한한다.
- 일반 명령은 선택 부대의 후속 예약을 지운다. 예약 지우기 전용 명령은 현재 목적지를 유지한다.

## 이동 완료 조건

기존 유닛별 AI에서 `g.order='hold'`를 직접 변경하던 경로를 제거했다. 이동·충돌 처리 후 한 번 부대 단위로 판정한다.

살아 있고, 전장을 떠나지 않았으며, 개별 철수하지 않는 각 병사가 자신의 진형 목표 칸에서 24단위 이내에 있어야 한다. 미도착 지원군은 완료 판정하지 않는다. 조건 충족 시 예약의 첫 목적지를 꺼내거나, 예약이 비었으면 hold로 전환한다. 막힌 길의 시간 초과를 이유로 목표를 건너뛰거나 병사를 순간이동시키지 않는다.

목표 칸이 고정 장애물 안이면 가까운 탐색 셀로 목표 칸만 보정한다. 병사는 그 위치로 실제 이동한다. 통로 혼잡·도달 불가능한 목적지의 무조건적 완주 보장은 아니다.

## 병력 보호

C는 HP 비율 0.45 미만 아군 중 최소 비율을 선택하며 동률이면 런타임 ID를 사용한다. 개별 철수는 공격 준비를 취소하고 길 찾기를 갱신하지만 쿨다운을 리셋하지 않는다. 기존 부대 철수와 같은 전장 가장자리 이동으로 처리한다.

자동 철수 정책은 부대별 OFF가 기본이다. ON이면 AI 병사가 HP 비율 0.25 이하에서 개별 철수를 시작한다. 직접 조작 병사는 AI 분기를 실행하지 않으므로 자동 보호가 조작권을 빼앗지 않는다. OFF 변경은 이미 내려진 철수 명령을 취소하지 않는다.

철수한 유닛은 `alive=true, evacuated=true`로 남아 결과에 원래 소속·장비·출처가 반영된다. 직접 조작·치유·강제 승리로 사망을 자동 되돌리지 않는다. 전투 결과의 기존 포로·퇴로 규칙을 유지한다.

## 회복 사선과 치료 명령

일반 치료는 시전할 때 유효한 대상을 선택하고 실제 타격 틱에도 사거리·사선을 재검사한다. 치료사 F, 전술 H도 사선을 검사한다. 물 지형은 기존 투사체 사선과 마찬가지로 차단하지 않는다. 벽·닫힌 성문·나무는 차단한다. 지원 명령이 이동·방어 위치를 무시하지 않도록 순서를 조정했다.

## 일괄 편성과 장비 비교

`transferMany(ids,toMain)`은 입력 목록·중복·존재·전체 정원을 검사한 뒤에만 배열을 수정한다. 대상 하나가 잘못됐다고 다른 병사만 먼저 옮기지 않는다. 병사 객체의 출처·장비·HP·성장 필드를 그대로 이동한다.

장비 미리보기는 현재 유닛의 얕은 복사본에 후보 장비 ID만 교체하여 `stats`를 호출한다. 차이는 교체 후-현재이며, 기존 장비 보정을 다시 더하지 않는다. 구매나 실제 장착을 수행하지 않는다.

## 저장 스키마 20

19에서 가져올 때 전투 그룹·병사에 새 필드의 안전 기본값을 추가한다. 20 저장에서는 필드 타입·좌표 범위·예약 8개 상한·이동 중 상태를 엄격히 검사한다. 잘못된 저장은 live world/battle을 교체하기 전에 거절한다. 세 가지 새 상태가 실제 전투 스냅샷에 들어가므로 저장/복원 후 이어지는 명령도 보존된다.

데이터 프로필 ID `hybrid-repoN-v19`와 전투 계산 `hybrid-combat-1`은 숫자 자료·기본 계산을 그대로 쓰기 때문에 유지한다. AI 수정으로 다른 버전 엔진 사이 미래 결과 동일성을 보장하지 않는다. 같은 v20 엔진의 같은 입력과 저장 재개 비교는 테스트한다.

## 렌더링 경계

예약 표식·병사 경고·미니맵 입력은 기존 project/ground와 같은 좌표계를 사용한다. 집중 화면에서도 8:5 종횡비를 유지한다. 간소화 모드는 렌더러가 만드는 박스·장식만 줄인다. 게임 tick, PRNG, 개체 수, 충돌, 통계는 변하지 않는다. 한 검증 장면에서 662→468 박스였으며 이 수치는 FPS나 GPU 실기기 벤치마크가 아니다.
