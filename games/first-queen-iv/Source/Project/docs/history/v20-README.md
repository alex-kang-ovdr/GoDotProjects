# First Queen IV · Field Command v20

v19 게임을 기반으로 전술 명령·병사 보호·병력 편성·장비 비교와 화면 사용성을 개선한 오프라인 웹 빌드입니다.
원작 완전 복원판이 아닙니다. v18의 관측 기록 309개와 장비 숫자 보정 14종을 유지하며, 전투 공식·역할·지도·경제·새 전술 규칙은 자체 설계입니다. 원작 이름·초기 상태·추가 수치를 새로 인증한 릴리스가 아닙니다.

## 실행

`index.html` 또는 별도 배포한 `FirstQueen4_v20.html`을 다운로드해 Chrome/Edge에서 엽니다. 둘은 같은 파일입니다. 게임 실행에는 서버·npm·CDN·외부 계정·인터넷 연결이 필요하지 않습니다. 채팅의 파일 링크는 공개 호스팅 주소가 아닙니다.

WebGL을 먼저 시도하며 컨텍스트를 만들 수 없으면 CPU 3D 호환 모드로 전환합니다. 2D 전술 화면도 사용할 수 있습니다. 사용 중인 렌더링 방식은 화면에 표시합니다.

## v20에서 바로 해볼 것

1. **강변 연습**을 선택하고 전장 연습을 시작합니다. **P**로 전술 일시정지합니다. 화면을 어둡게 가리지 않아 전장을 보며 명령할 수 있습니다.
2. 주력군을 선택하고 우클릭으로 다리 앞 목적지를 지정합니다. **Shift+우클릭**으로 다리 뒤와 다음 목적지를 차례로 예약합니다. 현재 목적지 외에 최대 8개를 예약할 수 있습니다.
3. 예비 지원대를 선택해 방어 명령을 내립니다. 지원대가 아직 도착하지 않았으면 주력군 병사를 잘못 조작하지 않도록 병사 선택이 해제됩니다.
4. 위험 병사가 생기면 **C**로 가장 낮은 체력 비율의 병사를 찾습니다. **V**는 그 병사만 실제로 전장 가장자리까지 이동해 철수시키는 명령입니다. 순간이동이나 무적이 아니므로 도중에 사망할 수 있습니다.
5. **F5 저장 / F9 복원**으로 예약 경로·부대 자동 철수 정책·개별 철수 상태를 복구합니다. 로드 후 P로 재개합니다.

예제 `examples/tactical-river-planning-v20.json`은 이 과정을 즉시 확인할 수 있는 연습 저장입니다. 부상자는 기능 검사용으로 지정한 상태이며 원작 세이브가 아닙니다.

## 변경 사항

### 부대 이동과 지휘

- 부대별 후속 목적지 예약. Shift+우클릭 또는 `후속 이동 예약` 체크박스를 사용합니다.
- 화면에 현재 목적지와 예약 지점 번호, 연결선, 목표 진형 칸을 표시합니다.
- 한 병사가 도착했다고 부대 전체가 방어로 바뀌던 동작을 수정했습니다. 살아 있고 전장에 남아 있는 비철수 병사들이 목표 칸 주변에 도착해야 다음 지점으로 진행합니다.
- 일반 이동·공격·방어 등의 새 명령은 선택 부대의 기존 후속 예약을 교체합니다. `후속 이동 예약 지우기`는 현재 목적지를 유지합니다.
- 막힌 성문 너머를 이동 목표로 잡았다고 성문을 통과하거나 목표를 건너뛰지 않습니다. 필요한 경우 공성 명령으로 전환하세요.
- 미니맵 클릭은 카메라 이동, 미니맵 우클릭은 실제 전장 좌표로 부대 이동을 명령합니다.
- 터치에서도 `이동 지정` 모드를 켜고 전장이나 미니맵을 눌러 목적지를 정할 수 있습니다. 모드를 끄면 병사 클릭 선택으로 돌아갑니다.

### 병력 보호

- C: HP 45% 미만의 생존·미철수 아군 중 체력 비율이 가장 낮은 병사를 선택하고 카메라를 추적합니다.
- V: 선택 병사의 개별 철수를 명령하거나 취소합니다. 공격 준비를 중단하지만 기존 공격 대기시간을 초기화하지 않습니다.
- `부상병 자동 철수`: 선택 부대에서 HP 25% 이하인 AI 병사에게 개별 철수를 적용합니다. 기본 OFF이며, 직접 조작 중인 병사는 제외합니다.
- 정책을 나중에 OFF로 바꾸어도 이미 철수 중인 병사가 자동 재돌격하지 않습니다. 선택 후 V로 별도 취소할 수 있습니다.
- 철수 병사는 생존 상태로 원래 소속에 반영됩니다. 방어전 패배 시 퇴로가 없으면 기존 포로 손실 정책이 적용되므로 생존을 보장하지는 않습니다.
- 위험 병사와 철수 중 병사를 전장에 표시합니다. 체력바 옵션을 꺼도 선택·위험 병사의 체력은 표시합니다.

### 치료 AI 수정

- 치료사는 명시적인 부대 이동을 먼저 따릅니다. 이동 중 멀리 있는 부상자를 계속 쫓아 진형에서 이탈하던 동작을 줄였습니다.
- 방어 중에는 지정된 범위 밖의 환자를 추격하지 않습니다.
- 일반 치료 타격, 치료사 기술, 전술 회복에 사선을 검사합니다. 닫힌 성문·벽·나무 너머를 치료할 수 없고, 강물은 기존 사선 규칙처럼 회복을 차단하지 않습니다.

### 편성과 장비

- 편성 창에서 여러 병사를 선택해 한 번에 이동합니다. Ctrl/Shift 선택 또는 표시된 병력 전체 선택 버튼을 사용합니다.
- 역할 필터와 번호/낮은 체력 비율/높은 공격력/높은 피로 정렬을 추가했습니다.
- 정원 부족, 중복 ID, 존재하지 않는 병사가 섞이면 전체 이동을 취소합니다. 일부만 옮겨지는 동작이 아닙니다.
- 장비 카드마다 현재 장비를 교체한 뒤의 AT·AR·DF·DR과 변화량을 표시합니다. 미리보기는 금화·병사·재고를 변경하지 않습니다.
- 관측 원본, 역할 매핑, 장비 보정 수치는 v19와 바이트 동일하게 보존했습니다.

### 화면과 조작

- `전장 집중`은 연구·저장 상단 패널을 접어 전장을 넓게 보여 줍니다. `기본 화면`으로 복귀합니다. 브라우저 전체화면 API를 호출하는 기능은 아닙니다. 집중 모드에서도 F5/F9는 사용 가능합니다.
- 전술 일시정지는 작은 배너만 표시하고 경로·병사·미니맵을 그대로 보여 줍니다.
- 그래픽 세부 설정: 자동/상세/간소화. 자동은 GPU 렌더링이 불가하면 간소화 모델을 사용합니다. 간소화는 렌더링 부품·장식만 줄이며 충돌·공격·병사 수·데이터는 바꾸지 않습니다.
- 891px 가로 화면에서도 터치 조작 버튼이 보이게 했습니다. 실제 휴대전화의 성능·다중 터치 검증은 별도입니다.
- 체크박스에 포커스가 남아 있어도 F5/F9, C/V 등 단축키가 작동합니다. 텍스트 입력·선택 목록·대화창은 여전히 보호합니다. 체크박스에서 Space는 해당 체크박스의 키보드 조작을 유지합니다.

## 저장 호환

출력 스키마는 **20**, 새 로컬 키는 `fq4_proto_v20`과 `fq4_checkpoint_v20`입니다. v19 슬롯은 덮어쓰지 않습니다. 빠른 저장 조회 시 기존 v19 저장을 대체 입력으로 읽을 수 있으며 JSON 파일 가져오기도 지원합니다.

v19 전투의 관측 참조·위치·장비·체력·공격 상태는 유지하고, 이전 버전에 없던 후속 이동은 빈 배열, 자동·개별 철수는 OFF로 초기화합니다. 이후 시뮬레이션은 수정된 v20 AI로 실행하므로 v19 엔진과 미래 전투 결과가 완전히 같다는 뜻은 아닙니다. v13·v14·v15 저장의 커스텀 프로필 이행 경로도 유지했습니다.

새 저장을 v19 프로그램으로 다시 여는 역호환은 지원하지 않습니다. 데이터셋 ID와 `hybrid-repoN-v19` 프로필 이름은 관측 어댑터를 식별하므로 그대로 유지합니다. UI/저장 버전과 데이터셋 버전은 다릅니다.

브라우저가 localStorage를 제한하면 탭 메모리로 보관하고 안내합니다. 중요한 진행은 **JSON 내보내기**로 파일을 남기세요. 복원 직후에는 일시정지됩니다.

## 검증 및 한계

`TEST_REPORT.md`에 실제 재실행 결과를 기록했습니다. **엔진 174개, 브라우저 94개, 총 268개 통과**입니다. 이전 버전의 보고서 수치를 더한 것이 아니라 v20 소스에서 다시 실행한 결과입니다.

테스트 환경에서는 WebGL 컨텍스트가 생성되지 않아 화면 검사는 CPU 3D와 2D입니다. 실제 GPU·Android/iOS 기기 성능은 검증하지 않았습니다. file:// 탐색은 관리 정책으로 차단되어 동일한 독립 HTML을 Chromium `set_content`로 주입했습니다. 파일 입력과 JSON 다운로드는 실제 브라우저 기능으로 검증했습니다.

시나리오 일부 자동 검사가 모든 대형·통로·명령 조합이나 장시간 플레이를 보장하지 않습니다. 복잡한 병목에서는 부대가 목표 집결을 기다릴 수 있으므로 산개·다른 경유점·새 명령을 사용하세요. 원작 전체 지도, 고증된 전투 공식·성장·한국어 인물명·대사는 여전히 미복원입니다.

## 개발 재실행

```text
python build.py
node tests/engine.test.cjs --report
node tests/integration.test.cjs
node tests/tactics.test.cjs
python tests/browser.test.py
python tests/browser.integration.py
python tests/browser.tactics.py
node tools/make_examples.cjs
```

브라우저 테스트에는 Playwright Python과 Chromium이 필요합니다. `CHROMIUM_PATH` 환경변수로 실행 경로를 지정할 수 있습니다. 게임 실행 자체에는 필요하지 않습니다. `src/engine.js`, `src/ui.js`, `src/renderer.js`, `src/style.css`, `src/layout.html`을 수정한 뒤 빌드합니다.
