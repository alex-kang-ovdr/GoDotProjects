# v21 전술 명령·누적 통계 명세

## 데이터 보존과 범위

v20의 소스·관측 데이터·장비 정의에서 데이터를 변경하지 않고 런타임 명령과 결과만 확장한다. 모든 새 거리/시간/탐지/추격 규칙은 CUSTOM. 원작 고증 복원 결과가 아니다.

## 상태

`group.order`에 `attackmove` 추가. 다른 명령과 마찬가지로 `anchor`, 동종 후속 `waypoints` 최대8개를 사용한다. 집중 표적은 `focusTargetId`, `focusOrigin`으로 별도 보관한다. `engagement`는 교전 이동이 적을 발견한 시점의 생존 비철수 전투병 중심이며 `engageAfter`는 교전 종료 후 재탐색 제한 틱이다.

탐지거리185, 접촉점 기준 후보범위210, 이탈 후 재탐색 대기120틱. 선택 표적은 지정 당시 표적 위치에서240보다 멀어지면 해제한다. 후보 중 현재 표적이 최단 거리×1.2+8 이내이면 유지한다. 시야는 현행 사선 검사이며 정찰/전장의 안개 시스템은 아니다.

`focusEnemy`는 모든 대상 부대를 먼저 검증한다. 전체 적용에 후퇴 부대가 하나라도 있으면 아무 부대도 수정하지 않는다. 선택 부대의 원래 명령/예약을 보존한다. 새 부대 명령은 집중·접촉·후속 경로를 교체한다. 일반 목적지 예약을 교전 이동 경로에 추가하는 식의 혼합 큐는 제공하지 않는다.

직접 조작 > 개별 철수/부대후퇴/자동부상철수 > 진행 중 행동/구출 보호 > 전술 명령. 집중 시 치료병은 적 근접 공격보다 아군 치료와 지원 위치 유지를 수행한다. 준비 취소는 공격 대기시간을 줄이지 않는다. 타격/치유 시점에 사선과 거리를 다시 검사한다.

## 집계

각 runtime unit에 performance={damage,received,healing,kills,hits,misses,gateDamage}. 실제 적용된 HP/성문 감소와 유효 회복량만 더한다. 대상이 죽은 뒤 날아오는 기존 투사체는 현행 규칙대로 판정되며, 발사자가 사망했어도 발사자 런타임 기록이 남으므로 피해 기여를 기록할 수 있다. 처치 경험 부여는 기존 생존 공격자 정책을 유지한다.

자동 자연 회복/구출 보호 회복은 healer=null이라 특정 치료병 기여를 올리지 않는다. 치료 타격, 치료사 기술, 전술 회복은 실제 시전자에 기록한다. 표의 시도=hits+misses이며 성문·회복은 여기에 포함되지 않는다.

최근120개 combatLog와 독립된 집계이며 종료 시 순수 행 배열로 report.units에 복사한다. 미도착 부대는 기존 결과표에서 구분하며 병사별 실제 전과에 아직 생성되지 않은 기록을 꾸며 넣지 않는다. 결과 JSON은 게임 세이브로 가져오는 파일이 아니다.

## 저장21

표적 참조·접촉점·재탐색 시각·기여도는 내보내기 전에 검사한다. 없는 표적/아군 표적/후퇴+집중 동시상태, 존재하지 않는 기여도 필드, 음수/비유한 수치, 분수 처치수, 미래 집계 시작은 거절한다. 입력은 복사본 검증 성공 후 반영한다.

v20 이하 전투에서 신규 fields는 무표적·접촉없음·집계0으로 추가하고 metricsSinceTick를 복원시각으로 지정한다. v20의 이미 존재하는 waypoints/autoRetreat/individualRetreat를 초기화하지 않는다. v19 이하에서만 이 이전 기능들도 기본값을 채운다.

같은 빌드에서 전투 내보내기→가져오기→같은 입력480틱의 전체 전투 상태를 비교했다. 교차기기 비트 단위 결정성 또는 네트워크 동기화 보장이 아니다.

## UI

T=교전이동 목적지 모드, X=표적 모드, Esc=입력모드 취소. 땅 우클릭은 이동, 적 우클릭은 집중. 명시적인 이동/교전이동 모드와 Shift 예약은 적 클릭보다 우선한다. 렌더러 pick은 team 매개변수로 아군 선택과 적 표적을 분리한다. 전술 오버레이는 시뮬레이션 상태를 변경하지 않는다.

미니맵은 좌표 입력을 지원하며 그 안에서 적 아이콘을 구분해 표적 선택하지 않는다. 표적 지정은 본 전장의 병사를 클릭한다. 터치 전장 드래그는 목적지·표적 모드에서 카메라를 돌리지 않는다.
