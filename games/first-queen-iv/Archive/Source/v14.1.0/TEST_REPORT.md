## 검증 범위의 제한

WebGL 컨텍스트 생성이 테스트 환경에서 실패했습니다. 따라서 GPU 렌더러/셰이더의 실제 실행과 GPU 성능을 검증했다고 주장하지 않습니다. 호환 3D와 2D에서 UI, 클릭, 키보드 입력, 회전, 줌, 전투 진행과 결과를 검증했습니다. `preview-v14.png`와 `tests/desktop.png`는 CPU 3D 실행 화면입니다.

환경의 관리 정책으로 file:// 및 localhost 탐색이 허용되지 않아 Playwright `set_content`로 동일한 독립 HTML을 Chromium에 주입했습니다. 불투명 출처의 localStorage 영속성을 검증한 것이 아니며, 브라우저 저장 제한 시 안내를 제공합니다. JSON 내보내기는 실제 다운로드로, 가져오기는 실제 파일 선택 입력으로 검증했습니다.

테스트는 재현 가능한 시나리오의 정상 동작을 확인한 것이며, 장시간 플레이·모든 기기·모든 전술 조합의 무결함을 보장하지 않습니다. FPS 수치는 목표 하드웨어의 GPU 벤치마크로 사용하지 않습니다.

## 재실행

```text
node tests/engine.test.cjs --report
python tests/browser.test.py
```

브라우저 테스트에는 Playwright와 Chromium이 필요합니다. 테스트 결과 JSON에는 각 단계의 통과 여부와 측정 시간이 기록되어 있습니다. 소스를 수정하면 먼저 `python build.py`로 실행 HTML을 재생성하세요.
