# Duck Extraction — Playable Web Prototype

Duckov의 익스트랙션 슈터 장르에서 영감을 받은 **독립적인 오리지널 게임플레이 프로토타입**입니다. 원작 리소스·코드·정확한 내부 데이터는 사용하지 않았습니다.

## 실행

`index.html`을 Chrome/Edge/Firefox에서 열면 됩니다. 인터넷, npm, 서버 설치가 필요 없습니다.

## 조작

- WASD 이동, Shift 달리기
- 마우스 조준, 왼쪽 클릭 연사
- R 재장전, E 전리품 획득/탈출, F 치료
- Tab 탐험 가방, B 기지 메뉴, Esc 닫기

## 구현 기능

- Canvas 2D 탑다운 렌더링, 2600×2600 맵, 장애물 충돌
- 적 추적·사격·거리 유지·측면 이동, 탄환과 벽 충돌
- 루팅 5종, 적 처치 드롭, 탄약·치료·재장전
- 탈출 성공 시 전리품 영구 보관, 사망 시 손실
- 기지 출격, 판매, 공격력·체력·보관함 업그레이드
- localStorage 자동 저장, 탐험 HUD 및 미니맵

## 범위 및 한계

- 단일 HTML 파일로 실행하는 **2D 프로토타입**입니다. 3D 그래픽, 원작 맵·무기·퀘스트·제작·고급 보스는 미구현입니다.
- 게임 수치 및 콘텐츠는 테스트용 자체 설계값입니다.
- 테스트는 정적 구조 확인에 한정되며 실제 브라우저 플레이 테스트는 별도로 권장합니다.
