## 무결성 확인 기준

기존 게임 ZIP과 분석 ZIP은 각각 전체 CRC 검사를 통과했습니다. 게임 매니페스트 135개 파일과 분석 매니페스트 300개 파일의 크기/SHA-256을 확인했습니다. 게임 ZIP 파일은 현재 소스 및 기준 Git 커밋과 같고, 분석 ZIP 파일은 기존 분석 폴더와 같습니다. 새 ZIP의 모든 원본 항목은 원본 바이트와 직접 비교하며 CRC32/SHA-256도 비교합니다.
