# League of Legends PC 역기획서

**소환사의 협곡 5대5를 중심으로 분석한 시스템별 상세 문서 모음**

- 작성·조사 기준일: **2026-11-13, 한국 시간 기준 날짜**.
- 구성: **총 25개 Markdown 파일 — 본문 22개, 안내 1개, 출처·버전 장부 1개, 용어집 1개**.
- 확인한 최신 공식 본편 패치 노트: **26.22, 2026-11-03 게시**.[S01]
- 문서 성격: 공개 자료를 근거로 게임 규칙·플레이어 선택·시스템 연결을 분석하고, 재현에 필요한 데이터·절차·검증 관점을 제안한 역기획서.
- 대상 제품: PC판 League of Legends. 모드별 변형은 19번 문서에서 구분한다.

## 1. 문서 전체를 관통하는 설계 해석

LoL의 핵심은 제한된 정보 아래에서 **전투력·시간·공간·성장 자원**을 교환하고, 얻은 우위를 구조물과 최종 목표로 연결하는 데 있다. 다음은 이 문서군의 [분석]이다.

1. **전투가 경제를 바꾸고 경제가 다음 전투를 바꾼다.** 처치와 압박은 자원 확보 기회를 만들지만, 구매·복귀·합류를 거쳐야 그 이득을 다시 사용할 수 있다.
2. **미니언과 시야가 전투의 조건을 만든다.** 같은 챔피언 조합이라도 웨이브와 관측 정보가 다르면 먼저 움직일 팀과 안전한 진입로가 달라진다.
3. **역할은 자원과 책임을 나누는 구조다.** 포지션, 전투 클래스, 드래프트, 성장 보상을 구분해야 팀 구성이 어떻게 작동하는지 설명할 수 있다.
4. **같은 강함에도 대응 가능한 빈틈이 필요하다.** 사거리·자원·대기시간·예고·위치 위험이 상대가 대응하는 창을 만든다.
5. **경기 안의 성장과 경기 밖의 성장은 서로 다른 수명을 가진다.** 매치의 능력치는 경기의 선택을, 계정·랭크·수집은 반복 플레이의 동기를 다룬다.

## 4. 각 본문에서 다루는 관점

- 시스템의 목적과 플레이어가 풀어야 하는 문제.
- 확인된 공개 규칙과 그 규칙이 만드는 선택.
- 상태·입력·출력·흐름과 기능 간 상호작용.
- 구체적인 가상 플레이 사례와 설계상 기회비용.
- 재현을 위한 데이터 모델과 책임 분리.
- 실패·취소·동시 사건·재접속 등 경계 조건.
- 의미 있는 검증 시나리오와 관련 시스템 링크.
- 개별 출처와 적용 시점, 추가로 확인할 항목.

수식은 근거와 가정을 붙였다. 예를 들어 피해 계산의 제한된 검산 모델과 스킬 가속 정의에서 환산한 수식을 같은 검증 수준으로 제시하지 않는다.

## 5. 사실·분석·제안을 읽는 법

| 표기 | 의미 | 활용 방법 |
| --- | --- | --- |
| [공식] | 공개 공식 자료에서 확인한 내용 | 인용한 버전·지역·모드를 함께 읽음 |
| [공식·도입 시점]·[공식·당시] | 특정 과거 시점에 확인된 내용 | 이후 변경 여부를 추가 확인 |
| [보조 확인] | 별도 표기한 커뮤니티 자료 | 공식·실측 검증 수준과 구별 |
| [분석] | 게임 구조에서 도출한 설계 해석 | 다른 게임에 적용할 때 전제 비교 |
| [제안] | 저자가 재구성한 구현·데이터·절차 | 프로젝트 요구에 맞춰 채택·수정 |
| [예시]·가상 | 설명용 상황·숫자·로그 | 원작의 측정값으로 사용하지 않음 |
| [미확인]·패치 의존 | 현재 값 또는 내부 규칙을 확정하지 못함 | 다음 조사·실측 과제로 사용 |

자료구조·이벤트명·YAML은 별도 표시가 없는 한 재구성 제안이다. 표에 등장하는 수치도 도입값, 공식 현행 안내, 설명용 가정 중 어느 것인지 확인해야 한다.

## 6. 기준 버전의 의미

확인한 최신 공식 패치 노트가 26.22라는 것은 **모든 파일의 모든 수치를 26.22 실행 파일에서 실측했다는 뜻이 아니다**. 공통 구조에는 입문·지원 문서를, 변경 사항에는 패치 노트를, 기술 배경에는 공개 당시의 개발 문서를 사용했다.

2026 포지션 퀘스트, 입력 방식, 특정 모드의 선택 구조처럼 변화가 큰 항목은 별도 시점을 기록했다. 일부 항목은 도입 이후의 관련 변경까지 확인했으며, 전수 확인하지 않은 상수는 현재값으로 확정하지 않았다.

공식 패치 일정에서 26.23은 조사일 이후 예정 항목이었다. 예정 패치나 콘텐츠 공개 예고를 현재 적용 규칙과 섞지 않았다.[S02]

## 7. 조사 방법과 한계

사용자가 제공한 [나무위키 리그 오브 레전드 문서](https://namu.wiki/w/%EB%A6%AC%EA%B7%B8%20%EC%98%A4%EB%B8%8C%20%EB%A0%88%EC%A0%84%EB%93%9C)는 이번 조사에서 본문을 열지 못했다. 해당 내용을 확인하거나 인용했다고 주장하지 않는다.

Riot의 게임 안내·공식 패치·지원 문서·개발 블로그를 주 근거로 사용했다. 별도 표시한 보조 자료와 저자의 분석을 구분했다. 공식 문서끼리 시점·지역·본문 구간이 다른 경우 [출처 장부](90_sources_version_ledger.md)에 기록했다.

이번 작업은 공개 문헌 기반 조사이며 실제 클라이언트에 접속한 플레이 테스트, 패킷 분석, 비공개 코드 열람을 수행하지 않았다. 수용 기준·검증표는 후속 검증을 위한 설계 자료다.

콘텐츠 상세 수준은 챔피언·아이템·룬의 공통 시스템과 대표 상호작용에 맞췄다. 개별 챔피언 전체 스킬 수치, 모든 아이템 가격, 모든 상점 확률을 빠짐없이 담은 데이터베이스는 별도 작업 범위다.
