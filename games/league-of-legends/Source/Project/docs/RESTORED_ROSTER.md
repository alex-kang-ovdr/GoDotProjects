# 복원 챔피언·스킬·아이템 사용 및 설계 안내

이 문서는 Nexus Front에 연결한 **플레이 가능한 챔피언 6명, QWER 24개, 구매 가능한 아이템 25개**와 전체 원작 데이터 도감의 범위를 설명한다. 공식 정적 데이터는 **Data Dragon 16.22.1 / 공개 패치 26.22**에 고정했다. 원작의 공개 능력치·쿨다운·비용·가격을 사용하고, 전투 동작은 기존 JavaScript 게임 엔진에 맞춰 구현했다.

문서의 “구현”은 이 저장소에서 작동하는 동작을 뜻한다. 피해 공식·충돌 폭·충전 재생 시간·패시브의 세부 판정을 원작 내부 코드와 동일하게 복원했다는 뜻은 아니다. 파일별 데이터 계약은 [restored-data-contract.md](restored-data-contract.md), 전체 게임의 실행·조작은 [README.md](../README.md)를 함께 참조한다.

**v9 갱신:** 정적 빌드와 콘텐츠 수는 유지한다. 기본 공격 피해 예측·막타 표시에 복원 효과를 반영하고, 리 신 Q/E를 시전자별로 분리하며, 지연 공격의 원점과 새 상태를 저장한다. 상세 변경은 [v9-combat.md](v9-combat.md)에 있다.

## 1. 이번에 사용할 수 있는 콘텐츠

| 구분 | 전체 데이터 도감 | 이 버전의 전투·상점 연결 |
|---|---:|---|
| 챔피언 | 173명 | 아리, 애쉬, 가렌, 럭스, 리 신, 진 |
| 최상위 QWER | 692개 | 위 6명의 QWER 24개와 재시전·충전 상태 |
| 아이템 | 863개 | 지원 효과를 구현한 협곡 후보 25개 |
| 로컬 원작 이미지 | 31개 | 챔피언 초상화 6개, 지원 아이템 아이콘 25개 |

**도감 수록과 플레이 가능 여부는 별도다.** 도감은 이름·식별자·기본 능력치·스킬 랭크 배열·아이템 가격·조합·출처를 조회하는 기능이다. 나머지 167명의 전투 동작은 아직 연결하지 않았고, 나머지 838개 아이템도 구매 목록에 포함하지 않는다. 863개에는 다른 모드와 특수 용도 항목이 섞여 있으므로 모두 현대 소환사의 협곡에서 구매할 수 있는 장비로 해석하지 않는다.

692개는 챔피언마다 최상위 Q/W/E/R 네 개를 합한 수다. 변신 후 스킬, 재시전 단계, 숨겨진 파생 스킬까지 각각 독립 항목으로 복원한 개수가 아니다. 패시브 이름은 도감에 보존하지만, 원본 설명의 존재만으로 실행 구현이 완성되는 것은 아니다.

기존 독자 영웅 3명과 기존 장비도 유지한다. 준비 화면에서 **복원 챔피언 6 / 기존 영웅 3**을 전환한다. 복원 챔피언은 `lol16.22` 프로필과 복원 장비 목록을 사용하며, 기존 영웅은 기존 장비 목록을 사용한다. 출전 영웅을 기준으로 해당 경기의 장비·성장 계산을 선택한다. 구현 근거는 [game.js](../dist/game.js)의 `getShopItems()`와 `_recalculateRestored()`다.

## 2. 실행과 첫 경기

### 실행 방법

배포본의 [단일 HTML](../dist/nexus-front-offline.html)을 브라우저로 열거나, 소스 폴더의 [index.html](../dist/index.html)을 연다. 소스 실행 시에는 `dist/` 아래 JavaScript·CSS·`assets/` 폴더를 함께 유지한다. 게임 실행 자체에는 Node.js 설치나 원격 게임 API 키가 필요 없다.

로컬 HTTP 환경으로 확인하려면 저장소 루트에서 실행한다.

```sh
python3 -m http.server 8080 --directory dist
```

이후 `http://localhost:8080`을 연다. 소스를 수정했다면 단일 HTML은 다음 명령으로 다시 만든다.

```sh
npm run build:offline
```

### 출전 순서

1. **복원 챔피언 6**에서 영웅을 선택한다. 준비 화면의 설명과 QWER 정보를 읽고, 더 자세한 수치는 **챔피언 · 아이템 도감**에서 확인한다.
2. 난이도, **1배·1.5배·2배 맵**, 시작 속도, 출전 장비를 선택한다. 맵 크기는 경기 시작 전에만 고른다.
3. 시작 골드는 600G다. 출전 장비 가격을 실제로 차감하며, 장비 없이 시작하면 600G를 그대로 보유한다.
4. 처음에는 Q를 배운 상태다. 레벨 상승으로 얻은 포인트를 `Shift + Q/W/E/R` 또는 성장 버튼으로 투자한다. R은 6·11·16레벨에 각 랭크를 배울 수 있다.
5. 재시전 스킬은 같은 키를 다시 누른다. 스킬 버튼의 재시전·남은 충전 표시와 챔피언 상태 표시를 확인한다. 진 R은 첫 입력이 채널 시작이고, 이후 R 입력이 실제 발사다.
6. 기지 또는 부활 대기 중 `P`로 장비를 구매·조합·판매한다. 전투 중 `B`로 귀환할 수 있다. 목표는 상대 넥서스 파괴다.

속도는 **0.5배·0.75배·1배·1.5배**이며, 전투 중에도 변경할 수 있다. 경기 시계·이동·스킬 대기·효과 지속 시간이 함께 진행된다. 아래 스킬 설명의 초는 게임 시간이다. 맵 배율은 배치와 공간 크기를 바꾸며, 챔피언 능력치와 공격·스킬 사거리에는 다시 곱하지 않는다.

### 필요한 조작

| 입력 | 용도 |
|---|---|
| 방향키 / 전장 클릭·우클릭 | 이동, 보이는 적을 지정하면 추적·기본 공격 |
| Q / W / E / R | 커서 방향·위치로 스킬 사용, 같은 키로 재시전 |
| Shift + Q / W / E / R | 스킬 포인트 투자 |
| A → 위치 선택 / S | 공격 이동 / 현재 명령 정지, 진 궁극기 채널 취소 |
| Z / V | 적 영웅 타깃 전환 / 기본 공격 범위 표시 |
| 4 | 와드 설치. 리 신 W의 이동 대상으로도 사용 |
| D / F | 점멸 / 회복 |
| B / P | 귀환 / 상점 |
| Esc | 조준 취소 또는 일시정지 |
| 터치 스킬 짧게 탭 / 끌어 놓기 | 자동 조준 / 방향·지점 직접 조준 |

W는 이동 키가 아니라 스킬 키다. PC에서 스킬 버튼을 클릭하면 방향·지점 스킬은 조준 모드로 들어가므로 전장을 클릭해 확정한다. 자기 자신 대상 스킬은 즉시 사용한다. 사거리 안의 유효한 대상이 필요한 스킬은 대상을 지정해야 하며, 사용할 수 없는 이유를 HUD에 표시한다.

## 3. 기본 능력치와 거리 기준

다음은 동봉한 공식 정적 데이터의 1레벨 기본값이다. 이동 속도와 사거리는 **원본 단위**로 표기했다. 실제 Canvas 월드에서는 둘 모두 0.5배로 변환한다. 예를 들어 애쉬의 기본 공격 사거리 600은 월드 300, 리 신의 이동 속도 345는 월드 172.5다. 체력·공격력·방어력·마법 저항력·자원·기본 공격 속도는 이 공간 변환을 적용하지 않는다. [공식 챔피언 정적 데이터](https://ddragon.leagueoflegends.com/cdn/16.22.1/data/ko_KR/champion.json)

| 챔피언 | 체력 | 공격력 | 방어력 / 마법 저항력 | 이동 속도 / 기본 공격 사거리 | 자원 | 기본 공격 속도 |
|---|---:|---:|---|---|---|---:|
| 아리 | 590 | 53 | 21 / 30 | 330 / 550 | 마나 418 | 0.668 |
| 애쉬 | 610 | 59 | 26 / 33 | 325 / 600 | 마나 280 | 0.658 |
| 가렌 | 690 | 69 | 38 / 32 | 340 / 175 | 없음 | 0.625 |
| 럭스 | 580 | 54 | 21 / 30 | 330 / 550 | 마나 440 | 0.669 |
| 리 신 | 645 | 66 | 36 / 32 | 345 / 125 | 기력 200 | 0.651 |
| 진 | 655 | 61 | 24 / 33 | 330 / 550 | 마나 300 | 0.625 |

`originalStats`에는 성장 필드도 그대로 보존한다. 다만 이 빌드의 선택한 여섯 챔피언 모두 공개 파일에 `attackdamageperlevel=0`으로 들어 있다. 이를 기억에 의존한 과거 수치로 교체하지 않았다. 따라서 이 프로젝트의 기본 공격력 성장도 해당 입력을 따른다. **공개 필드의 관측값 0이 원작 실제 최종 AD의 무성장을 증명하는 것은 아니다.** 레벨 곡선·상한·회복 적용은 웹 시뮬레이션 정책이며, 원작 밸런스를 보장하지 않는다.

## 4. 챔피언별 24개 스킬

아래 표의 쿨다운·첫 시전 비용·원본 사거리 배열은 공식 상세 데이터에서 읽은 값이다. `/`는 스킬 랭크 순서이며, 모든 랭크가 같으면 하나의 값만 적었다. 비용 0과 쿨다운 0도 유효한 원본 값이다. 실행 동작 열의 피해 종류·충돌·반복·지속 시간은 현재 웹 구현 설명이며, 원작 공식 피해식의 검증 결과와 구분한다.

충전 스킬의 **일반 시전 간격**과 **충전 재생 시간**, 재시전의 비용·유효 시간은 서로 다르다. 예를 들어 애쉬 E의 원본 쿨다운 5초만으로 충전 재생 시간을 결정하지 않는다. 이 문서의 구현 근거는 [restored-gameplay.js](../dist/restored-gameplay.js), 수치 출처는 각 챔피언의 공식 상세 JSON이다.

### 아리 — 왕복 구슬과 연속 질주

아리는 E로 상대 이동을 제한하고 Q가 나갈 때와 돌아올 때의 경로를 모두 맞추는 기동형 마법사다. R을 한 번에 소모하기보다 공격 각도 조정과 이탈에 나누어 사용한다.

| 스킬 | 쿨다운(초) / 첫 비용 | 원본 사거리 | 현재 실행 동작 |
|---|---|---:|---|
| Q 현혹의 구슬 | 7 / 마나 55·65·75·85·95 | 970 | 관통 구슬이 앞으로 이동한 뒤 시전자 쪽으로 돌아온다. 나갈 때 마법 피해, 돌아올 때 고정 피해를 적용하며 왕복 적중을 별도로 판정한다. |
| W 여우불 | 9·8·7·6·5 / 마나 30 | 700 | 주변 적을 추적하는 불꽃 세 개를 만들고 잠시 이동 속도를 높인다. 적 영웅을 우선하고, 같은 대상에 대한 후속 불꽃 피해를 줄인다. |
| E 매혹 | 12 / 마나 60 | 975 | 첫 적에게 마법 피해와 매혹을 준다. 매혹 중 이동·행동을 제한한다. |
| R 혼령 질주 | 140·120·100 / 마나 100 | 450 | 첫 질주 후 두 번 더 재시전할 수 있다. 각 질주에서 주변의 보이는 적을 공격한다. 재시전에는 추가 마나를 쓰지 않는다. |

정기 흡수는 미니언·몬스터 9마리 처치마다 회복하고, 적 챔피언 처치에 관여하면 별도의 회복을 제공한다. 현재 웹 회복량은 각각 `50 + 5 × 레벨 + 0.15 × AP`, `80 + 8 × 레벨 + 0.30 × AP`로 정했으며, 원작의 확정 피해·회복 공식으로 제시하지 않는다. W 이동 가속도 웹 공통 가속 25%를 1.5초 적용한 재구성값이다.

R은 웹 구현에서 15초의 재시전 구간과 짧은 재시전 간격을 사용한다. 처치에 따른 추가 질주 충전은 현재 지원 범위에 포함하지 않는다. [공식 아리 상세 데이터](https://ddragon.leagueoflegends.com/cdn/16.22.1/data/ko_KR/champion/Ahri.json)

### 애쉬 — 집중·둔화·정찰

기본 공격으로 집중을 쌓은 뒤 Q를 사용하고, 서리 둔화와 W로 상대의 접근을 제어한다. E는 교전 전에 정찰에 사용하며 R은 보이는 위치에만 클릭해야 하는 대상 지정기가 아닌 방향 투사체다.

| 스킬 | 쿨다운(초) / 첫 비용 | 원본 사거리 | 현재 실행 동작 |
|---|---|---:|---|
| Q 궁사의 집중 | 0 / 마나 30 | 400 | 기본 공격으로 집중 4중첩을 쌓아야 사용할 수 있다. 사용하면 중첩을 소비하고 일정 시간 공격 속도와 기본 공격을 강화한다. |
| W 일제 사격 | 18·14.5·11·7.5·4 / 마나 75·70·65·60·55 | 1200 | 부채꼴 아홉 화살을 발사해 물리 피해와 둔화를 적용한다. 같은 발사 묶음으로 한 대상을 여러 번 맞히지 않는다. |
| E 매 날리기 | 5 / 0 | 25000 | 최대 두 충전으로 정찰체를 보낸다. 이동 경로와 도착 지역에 임시 시야를 제공한다. |
| R 마법의 수정화살 | 100·80·60 / 마나 100 | 25000 | 적 챔피언과 충돌하는 장거리 화살이다. 이동 거리에 따라 기절 시간을 조절하고 주변에도 피해·둔화를 적용한다. |

서리 화살은 기본 공격에 둔화를 적용하고 서리가 있는 대상에 대한 피해 계산을 별도로 처리한다. 치명타 확률과 피해 보너스도 웹 전용 계산에 반영하지만 원작의 모든 치명타 변환 규칙을 구현하지는 않는다. Q의 쿨다운 0은 무제한 사용을 뜻하지 않으며 집중과 강화 상태가 사용 조건이다.

E는 일반 쿨다운과 별도로 충전을 재생한다. 원본의 `chargecooldown` 미해결 토큰을 공식 숫자로 오인하지 않고, 재생 시간을 별도 튜닝 배열로 관리한다. E/R의 25000은 정적 표시 값으로 보존하며, 웹 스킬 메타데이터는 4800 월드 단위, 실제 투사체·정찰 이동은 맵 크기를 고려한 범위로 처리한다. [공식 애쉬 상세 데이터](https://ddragon.leagueoflegends.com/cdn/16.22.1/data/ko_KR/champion/Ashe.json)

### 가렌 — 무자원 근접 교전

Q로 접근해 강화 기본 공격을 맞히고 E로 근접 범위를 유지한다. W는 피해를 받기 직전에 사용하고, R은 체력이 많이 줄어든 적 영웅을 마무리하는 데 사용한다. 자원 게이지가 0이어도 마나 부족으로 막히지 않는다.

| 스킬 | 쿨다운(초) / 첫 비용 | 원본 사거리 | 현재 실행 동작 |
|---|---|---:|---|

### 조합·판매와 효과 처리

재료는 **개수까지** 소비한다. 광전사의 군화에 필요한 단검은 두 개이므로, 장화 한 개와 단검 한 개만 보유했다면 남은 구매 비용은 550G다. 라바돈은 큰 지팡이 두 개를 각각 소비한다. 레시피를 중복 없는 집합으로 바꾸거나 한 재료를 여러 슬롯에서 재사용하지 않는다.

판매가는 공식 개별 값이다. 곡괭이 875G의 판매가는 613G이며, 일괄 `floor(가격 × 0.7)`로 계산한 612G를 사용하지 않는다. 장화와 광전사의 군화는 같은 신발 고유 그룹을 공유한다. 조합할 때 장화를 소모하는 업그레이드는 가능하지만 신발을 중복 보유할 수는 없다. 무한의 대검과 라바돈도 각각 중복 구매를 제한한다.

스킬 가속은 `최종 쿨다운 = 랭크별 기본 쿨다운 / (1 + 가속 / 100)`으로 반영한다. 예를 들어 기본 10초에 가속 10이면 약 9.09초다. 충전형 스킬의 재생에도 현재 엔진의 가속 정책을 사용한다. 이미 진행 중인 쿨다운의 남은 시간을 장비 구입 순간에 원작과 완전히 동일하게 재계산하는 체계를 검증했다는 뜻은 아니다.

라바돈은 합산 주문력에 1.30을 곱한다. 무한의 대검의 30%p는 엔진의 치명타 피해 배수에 0.30을 더하며, 애쉬·진의 기본 공격에는 각 챔피언용 재구성 계산을 적용한다. 생명력 흡수는 유효한 기본 공격으로 실제 감소한 대상 체력을 기준으로 회복하고, 구조물·와드에 대한 흡혈은 적용하지 않는다. 사파이어 수정은 마나 사용자에게만 최대 자원을 늘린다. 이 계산들은 [game.js](../dist/game.js)와 [restored-gameplay.js](../dist/restored-gameplay.js)의 실제 지원 범위다.

## 6. 도감에서 읽는 원본과 실행 값

준비 화면 또는 일시정지 메뉴의 **챔피언 · 아이템 도감**을 연다. 한글 이름·영문 이름·식별자로 검색하고, **전체 데이터 / 플레이 가능 / 게임 상점 지원 / 협곡 상점 후보** 범위를 선택한다. 필터는 서로 다른 의미를 갖는다. 특히 협곡 후보 여부만으로 모든 아이템이 현재 엔진에서 구매 가능해지지 않는다.

챔피언 상세의 랭크별 재사용 시간·비용·사거리는 원본 배열이다. 게임 HUD는 선택한 랭크, 스킬 가속, 재시전 상태, 충전·집중·자원 조건을 반영한 현재 상태를 표시한다. 따라서 도감의 정적 수치와 경기 HUD의 현재 사용 상태는 서로 다를 수 있다.

| 사례 | 원본 보존 값 | 웹에서 사용하는 값·조건 |
|---|---|---|
| 아리 Q 사거리 | `rangeByRank=[970,970,970,970,970]` | 기본 월드 사거리 485 |
| 가렌 W 사거리 | 0 | 자기 자신에게 사용 |
| 애쉬 Q 쿨다운 | 0 | 집중 4중첩과 비활성 상태가 필요 |
| 애쉬 E/R 사거리 | 25000 | 메타데이터 4800, 실제 이동은 맵 대각선 등으로 제한 |
| 진 R 사거리 | 25000 | 재구성 월드 사거리 1750 |
| 리 신 Q 첫 비용 | 기력 50 | 재시전 비용 30은 별도 재구성 정책 |
| 원본 미해결 피해 토큰 | `totaldamage` 등의 문자열 | 공식 수식으로 확정하지 않고 `TUNING`의 재구성 계산 사용 |

도감에 있는 플레이 가능한 챔피언은 준비 화면으로 선택할 수 있다. 진행 중인 경기에서 영웅을 바꾸는 기능은 제공하지 않는다. 도감을 열면 경기를 일시정지하며, 닫으면 이전 일시정지 상태를 유지·복원한다. 도감 UI 구현은 [catalog.js](../dist/catalog.js)에 있다.

### 기본 공격 예상 피해와 막타 표시

v9는 가렌 Q 강화, 럭스 광채, 진 네 번째 탄환과 잃은 체력 성분, 애쉬 서리·Q 강화까지 현재 기본 공격 예상 피해에 반영한다. 럭스의 물리 기본 공격과 마법 표식 피해에는 각기 방어력과 마법 저항력을 적용하고 보호막 감소와 HP 감소를 구분한다.

확률 치명타는 난수를 미리 소비하지 않고 최소·최대 범위로 표시한다. 막타 표시에는 **현재 상태의 확정 최소 피해**만 사용한다. 도착 전 회복·보호막·표식 변화나 다른 유닛의 타격은 예측하지 않으며, 사거리·공격 준비 상태는 별도 조건이다. 보이지 않는 적의 현재 상태를 읽어 이 정보를 표시하지 않는다.

## 7. 공식 확정 데이터와 재구성의 경계

| 영역 | 확정·보존한 내용 | 이 프로젝트에서 정한 내용 |
|---|---|---|
| 챔피언 | ID, 이름, 자원 종류, 기본·성장 정적 필드 | 레벨 곡선 적용, 이동·공격 상한과 게임 내 성장 흐름 |
| 스킬 | 이름, 최대 랭크, 쿨다운·비용·정적 사거리 배열 | 피해 공식, AP/AD 계수, 충돌 폭·속도, 대상 정책, 지속·틱·취소·재시전 조건 |
| 패시브 | 공식 이름 | 지원하는 동작과 수치, 생략한 원작 세부 효과 |
| 아이템 | 가격·판매가·재료·정적 능력치, 별도로 확인한 설명 전용 숫자 | 현재 엔진의 적용 순서·상한·고유 그룹 정책 |
| 지도와 시야 | 기존 웹 프로젝트의 지도·전투 맥락 | 원작 맵 자체를 재현하지 않은 1/1.5/2배 전장, 시야·지형·이동 충돌 규칙 |

데이터에는 `statsEvidence`, `evidence`, `behaviorEvidence`, `geometryEvidence`를 남겼다. 확정하지 못한 원본 툴팁 토큰은 `unresolvedTokens`에 보존한다. 수치가 빈 부분을 임의로 채운 뒤 공식 복원값처럼 표시하지 않는다. 런타임의 `TUNING.evidence`도 `authored_reconstruction_not_original_formula`로 구분한다.

| 애쉬 | 둔화 기본 공격, 집중 Q, 부채꼴 W, 충전 정찰, 장거리 기절 | 원작의 모든 치명타·서리 피해 변환, 원작과 동일한 정찰 시야·충전 재생 수식 |

| 진 | 네 발과 재장전, 네 번째 강화, 튕김, 표식 속박, 충전 함정, 네 발 채널 | 원작의 공격 속도·치명타 → AD 전환 전체, 처치에 따른 함정 생성, 모든 원작 함정 예외 |

이 경계 때문에 같은 챔피언·아이템 이름을 사용해도 원작과 동일한 교전 결과가 나오지 않을 수 있다. 확장 시에는 새 이름을 구매·선택 목록에 넣기 전에 필요한 효과와 상태 전이를 먼저 구현하고, 도감의 `playable` 표시와 실제 실행 지원 범위를 함께 변경한다.

## 8. 저장과 재개 시 확인할 내용

기존 자동 저장·이어하기 흐름을 유지하며, 복원 챔피언의 프로필·자원 종류·장비·고유 상태도 저장 계약에 포함한다. 재개는 일시정지 상태에서 시작한다. 맵과 속도는 저장 당시 설정으로 복원한다.

신규 저장은 두 프로필 모두 `engineVersion=9`를 사용하고, 복원 데이터 버전은 `16.22.1`을 유지한다. v4~v8 읽기를 지원하며 기존 영웅의 저장을 복원 챔피언으로 자동 변경하지 않는다. v8의 리 신 E 목록은 당시 남아 있는 표식 소유 정보로만 복구한다. v8에서 이미 다른 시전자에게 덮어써져 사라진 정보는 추정 복구하지 않는다.

기존 검증은 여섯 챔피언의 초기 상태 왕복, 아리 R을 사용한 뒤의 남은 재시전, 가렌 E 회전 중의 주기 효과를 저장·복원한 후 30틱 동안 원 경기와 비교한다. 과거 v4·v5·v6 실제 fixture와 기존 v7 입력 경로도 검사한다. v9는 원본 v8 소스로 생성한 [실제 이전 저장](../tests/fixtures/v8-combat-checkpoint.json)의 Q/E 재시전·럭스 구역·진 함정을 추가로 복원한다. 이 결과를 모든 챔피언의 모든 중간 상태·모든 브라우저 조합을 실측한 것으로 확대하지 않는다. 구체적인 테스트는 [restored-persistence.test.cjs](../tests/restored-persistence.test.cjs)와 [v9-combat.test.cjs](../tests/v9-combat.test.cjs)에 있다.

게임 데이터를 수정할 때는 충전 수·남은 시전 시간·표식 대상·탄환과 재장전·지속 효과·지연 공격의 직렬화도 함께 검토해야 한다. 시각 효과가 남아 있는 것과 전투 판정이 정확하게 재개되는 것은 별도 검증 항목이다.

## 9. 데이터 갱신과 재현 절차

### 포함된 파일

| 파일 | 역할 |
|---|---|
| [data/restored-input.json](../data/restored-input.json) | 도감·실행 정의를 만들기 위한 고정 사실 입력, 출처와 해시 |
| [data/restored-assets.json](../data/restored-assets.json) | 31개 로컬 PNG의 원본 URL·바이트 수·SHA-256 |
| [scripts/import-restored-data.py](../scripts/import-restored-data.py) | 입력을 검증하고 UMD 데이터 모듈을 생성 |
| [dist/restored-data.js](../dist/restored-data.js) | 브라우저 전역 `NexusRestoredData`와 Node `require()` 공용 데이터 |
| [dist/restored-gameplay.js](../dist/restored-gameplay.js) | 6명 스킬·패시브·투사체·재시전 상태의 실행 구현 |
| [tests/restored-data.test.cjs](../tests/restored-data.test.cjs) | 데이터 개수·단위·레시피·출처·로컬 자산 의미 검증 |

### 동봉 입력으로 재생성

Python 3.9 이상에서 아래 명령을 실행한다. 재생성은 네트워크나 API 키 없이 동봉 입력으로 가능하다. `restored-data.js`를 수동으로 편집하면 다음 생성 때 덮어써지므로, 실행 설명·지원 목록의 변경은 생성 스크립트에 반영한다.

```sh
python3 scripts/import-restored-data.py
node --test tests/restored-data.test.cjs
```

이 테스트는 173명·692개 QWER·863개 아이템과 실행 6명·25개를 구분하고, 원본 배열과 월드 0.5배의 관계, 25000 사거리 예외, 비용 0, 중복 재료, 공식 판매가, 설명 전용 효과의 출처, PNG 31개의 해시를 검사한다. 엔진 변경을 포함한 작업은 이어서 전체 테스트와 오프라인 빌드를 실행한다.

실제 적중·상태·시전 비용·아이템 적용·AI 전투는 별도의 [restored-combat.test.cjs](../tests/restored-combat.test.cjs)에서 검사한다. 데이터 테스트만 통과한 사실을 전투 동작 검증으로 대신하지 않는다.

```sh
npm test
npm run build:offline
```

### 이전 원작 분석 패키지에서 다시 가져오기

앞서 작성한 원작 분석 패키지의 정규화 `data` 폴더를 사용할 수 있다. 두 저장소가 나란히 있을 때의 예시는 다음과 같다.

```sh
python3 scripts/import-restored-data.py --source ../lol_original_reconstruction/data
```

이 옵션은 기존 정규화 데이터의 필수 식별자·수치·출처를 다시 투영한다. 인터넷에서 최신 패치를 자동 검색·병합하는 명령은 아니다. 현재 프로필은 16.22.1을 검사하고 다른 빌드 입력을 거절한다. 공식 JSON의 전체 긴 툴팁 본문 대신 필요한 사실·수치·미해결 토큰·증거 포인터를 보관한다.

### 새 패치 또는 지원 콘텐츠를 추가할 때

1. 공식 빌드 번호와 공개 패치 표기를 고정하고 원본 응답의 해시를 기록한다. 최신 버전을 매 실행마다 암묵적으로 받아 기존 저장 데이터와 섞지 않는다.
2. 챔피언 식별자·전체 수·랭크 배열 길이·자원 종류와 아이템 맵 플래그·구매 가능 여부·가격·판매가·재료를 비교한다.
3. 정적 `stats`에 없는 효과는 공식 설명 필드에서 별도로 확인하고 숫자와 출처 포인터를 남긴다. 확인되지 않은 공식은 미해결로 유지한다.
4. 새 장비의 모든 중요한 효과를 엔진이 지원하는지 확인한다. 단순 능력치만 반영한 아이템을 완전 지원으로 표시하지 않는다.
5. 새 스킬은 투사체·대상 선택·자원·재시전·충전·취소·사망·시야·저장 상태를 함께 연결한다. 원본 거리와 월드 거리를 혼용하지 않는다.
6. 필요한 PNG를 고정된 공식 이미지 경로에서 받고 매니페스트를 갱신한다. 이미지가 없어도 플레이를 막지 않는 UI 대체 표시를 유지한다.
7. 데이터 테스트의 기대값, 엔진 동작 테스트, 과거 저장 호환, 사용자 설명을 같은 변경에서 갱신한다. 이후 단일 HTML을 다시 빌드하고 실제 브라우저에서 확인한다.

## 10. 출처와 해석
