# 변경 기록 · Nexus Front

이 문서는 저장소에서 실제 구현한 변경 사항을 기록합니다. 공식 정적 데이터의 확정값과 이 게임의 재구성 규칙을 구분합니다. 실행은 [README.md](README.md), 상세 규칙은 [GAMEPLAY.md](GAMEPLAY.md), 최종 검증 결과는 [QA.md](QA.md)를 참고합니다.

## 9.0.0 — 분석 데이터에 근거한 전투 판단과 전장 관측

### 벽·고지대와 팀별 관측

- 기존 정글 벽 12곳을 실제 시야 차폐물로 연결하고, 걸어서 이동 가능한 고지대 4곳을 추가했습니다. 저지대에서 고지대와 그 너머를 볼 수 없고, 고지대에서는 낮은 지형을 내려다볼 수 있습니다. 벽은 양쪽에서 시야를 막습니다. 맵 1/1.5/2배에 맞춰 지형을 배치합니다.
- 시야 거리·차폐·수풀 발견 조건을 동일한 관측자가 모두 만족해야 적을 볼 수 있습니다. 서로 다른 아군의 조건을 합쳐 벽 너머 수풀을 드러내는 문제를 방지했습니다. 애쉬의 정찰은 명시적인 공중 시야 예외입니다.
- 숨은 곳에서 유효한 공격을 받으면 공격이 시작된 고정 위치에 1.5게임초 동안 금색 단서를 표시합니다. 날아온 투사체는 발사 시점의 위치, 설치된 구역과 함정은 설치 위치를 사용합니다. 단서는 이동 중인 공격자를 추적하거나 자동 공격 권한을 부여하지 않습니다.
- 팀별로 한 번 본 건물의 위치·체력·생존·보호 상태와 관측 시간을 저장합니다. 시야 밖에서는 마지막 관측 상태를 희미하게 표시하며, 숨은 피해·파괴·Actor 제거는 재탐색 전까지 갱신하지 않습니다. 좌클릭으로 기록을 살펴볼 수 있습니다.
- 중립 목표의 안내·전술 지시·길잡이는 팀이 관측한 정보로 판단합니다. 빈 캠프를 본 사실만으로 벽 뒤 몬스터의 처치 시각을 알아내지 않습니다. 정확한 재생성 대기는 처치를 본 팀 또는 확보한 팀만 기록하며, 대기 종료 뒤에는 정찰 후보로 돌아갑니다.
- 시야 밖 적의 현재 체력·레벨을 전적 화면에서 숨기고, 숨은 구조물 파괴·중립 목표 재생성 알림도 공개하지 않습니다. 이름·역할·KDA는 경기의 공개 정보입니다.

### 복원 전투 데이터의 실제 판단 반영

- 기본 공격 예상 피해가 실제 공격과 동일한 계산 함수를 사용합니다. 방어력·마법 저항·보호막, 치명타 범위, 가렌 Q·럭스 광채·진의 네 번째 탄환·애쉬 강화 상태를 계산합니다. 선택한 보이는 대상의 체력 피해 범위를 HUD에 표시합니다.
- 막타 표시는 무작위 치명타가 필요한 경우를 확정 처치로 표시하지 않고 최소 보장 피해를 사용합니다. 예측 조회는 탄약·표식·자원·체력·난수 상태를 소비하지 않습니다. 이후 회복이나 다른 공격의 도착은 예측에 포함하지 않습니다.
- 리 신 Q 재시전과 E 재시전의 대상 소유권을 시전자별로 분리했습니다. 여러 리 신의 표식 덮어쓰기와 E2에서 첫 E에 맞지 않은 새 대상이 포함되는 문제를 수정했습니다.
- AI가 안전한 비전투 상황에서 낮은 마나나 구매 가능한 다음 장비를 판단하여 귀환하고 실제 상점 규칙으로 구매한 뒤 전선으로 복귀합니다. 최근 피해·주변의 보이는 위협·공격 준비·행동 제한을 고려하며, 무자원·기력 챔피언은 낮은 마나 규칙의 대상이 아닙니다.
- 조합 차액·중복 재료·고유 그룹·6칸 제한을 AI와 추천 구매에 반영합니다. 상위 장화 보유 후 기본 장화를 다시 추천하는 순환도 해소했습니다.

### 저장·렌더링·검증

- 새 경기는 두 프로필 모두 `engineVersion: 9`로 저장합니다. 탐색 셀·건물 기억·중립 관측·공격 위치 단서를 보관하며, 실제 v4~v8 파일의 읽기를 유지합니다. 관측 기록이 없는 이전 저장은 복원 시 현재 보이는 영역부터 새 기록을 만듭니다.
- 20월드단위 격자를 0.1게임초 간격으로 갱신하고 관측자 주변 사각형만 순회합니다. 렌더러는 같은 revision의 시야 마스크를 다시 계산하거나 업로드하지 않습니다. 2배 맵도 160×160셀을 사용합니다.
- 분석→구현 대응표, 전투 계산 계약, 시야 규칙·성능 측정과 재현 가능한 검사를 별도 Markdown으로 포함합니다. 실행 모듈 13개와 로컬 PNG 31개를 단일 HTML에 포함하며, 소스 ZIP에 파일별 SHA-256 매니페스트를 보관합니다.
- 현재 구현은 여전히 복원 6명/24QWER/25아이템과 기존 3명/8장비입니다. 전체 도감 173명/692QWER/863아이템은 조회 데이터이며 전체 전투 구현을 뜻하지 않습니다. Data Dragon 16.22.1의 정적 입력은 변경하지 않았습니다.

고지대·건물 기억·공격 단서와 AI 판단은 사용자 요구를 반영한 프로젝트 규칙입니다. 원작의 정밀한 피해 공식·모든 스킬 예외 또는 온라인 서버의 정보 보안을 재현했다는 뜻이 아닙니다. 이번 변경은 웹 구현이며 언리얼 엔진 실행 프로젝트는 포함하지 않습니다.

## 8.0.0 — 복원 챔피언·스킬·아이템의 전투 연결

### 복원 데이터와 실제 플레이

- Data Dragon 16.22.1의 챔피언 173명·QWER 692개·아이템 863개를 로컬 도감으로 연결했습니다. 이름·영문 이름·ID 검색, 지원 항목 필터, 가격·재료·랭크별 스킬 배열·공식 출처를 조회합니다. 한 번에 24개 항목을 렌더링합니다.
- 아리·애쉬·가렌·럭스·리 신·진을 실제 플레이 가능한 명단에 추가했습니다. QWER 24개는 이름만 바꾸지 않고 왕복·다중 충돌·충전·재시전·표식·속박·매혹·넉백·채널링 동작을 별도로 구현했습니다. 같은 프로필의 AI 9명이 상대·아군으로 참가합니다.
- 원본 능력치·재사용 대기·첫 시전 비용·아이템 가격·판매가·조합을 가져옵니다. 거리·이동 속도는 월드 0.5배로 변환하며 일부 전역 거리의 대체값을 명시했습니다. 피해식·충돌 폭·충전 재생·상태 지속은 재구성 튜닝으로 표시합니다.
- 기존 영웅 3명·장비 8종은 별도 선택으로 유지합니다. 경기 프로필이 다른 장비를 구매하거나 저장에 혼입할 수 없습니다.

### 자원·성장·장비

- 리 신의 기력, 가렌의 무자원 스킬, 진의 4발·재장전, 애쉬 집중, 아리 정수, 럭스 광채를 연결했습니다. HUD는 자원 종류, 충전, 재시전 이름과 대기 시간, 챔피언별 상태를 표시합니다.
- 지원 아이템 25종에 물리/마법 저항, 공격 속도, 치명타, 흡혈, 스킬 가속, 주문력 배율, 이동 속도 비율 및 고유 그룹을 적용했습니다. 중복 재료의 수량, 조합 차액, 재료 소모 후 6칸 제한, 공식 판매 가격을 처리합니다.
- 출전 장비·추천 구매 경로·상점 검색·분류가 현재 프로필을 사용합니다. 큰 맵의 상점 위치 표시는 해당 경기 기지 좌표로 판단합니다.

### 화면과 지속 효과

- 여섯 초상화와 25개 아이템 아이콘을 로컬 파일로 포함했습니다. 전장 캐릭터는 꼬리·활·갑옷·지팡이·붕대·총으로 구분되는 Canvas 도형을 사용합니다.
- 진 함정은 설치 애니메이션 종료 뒤에도 아군에게 표시합니다. 숨은 적 함정과 적 정찰 효과는 공개하지 않습니다. 애쉬 이동 정찰, 럭스 구역과 궁극기 예고, 아리 여우불을 지속 효과 상태로 그립니다.
- 긴 빔은 원점의 화면·시야 여부만으로 제거하지 않고 선분 범위를 판정하며, 현재 시야 영역으로 잘라 그립니다. 렌더러는 시뮬레이션 상태를 변경하지 않습니다.

### 저장·배포

- 복원 경기는 engineVersion 8, ruleset `lol16.22`, dataVersion `16.22.1`과 재시전·충전·탄약·지속 효과를 보관합니다. 기존 영웅은 기존 v7 형식으로 저장하며 실제 v4~v7 자료의 읽기를 유지합니다. 복원 완료 경기 기록은 version 4로 실제 이름·ID·프로필을 보관합니다.
- 원본 입력 스냅샷·이미지 해시·결정적 데이터 생성기를 포함했습니다. 단일 HTML은 11개 게임 스크립트와 로컬 PNG 31개를 인라인으로 포함합니다. 소스 ZIP은 파일별 SHA-256 매니페스트를 포함하며 임시 검증 페이지·호스팅 자격 증명·ZIP 자신을 제외합니다.
- 맵 1/1.5/2배의 출전 전 선택과 속도 0.5/0.75/1/1.5배를 보존했습니다. 자동 검사와 실제 화면 확인 결과는 [QA.md](QA.md), 콘텐츠별 수치·구현 범위는 [RESTORED_ROSTER.md](docs/RESTORED_ROSTER.md)에 기록합니다.

### 원작 정밀 복원의 남은 범위

전체 도감이 전체 전투 구현을 뜻하지는 않습니다. 추가 167명·838아이템, 모든 원작 피해 공식·스킬 예외, 아리 R 처치 추가 충전, 진의 원작 AD 전환, 애쉬의 원작 치명타 변환, 가렌 W 누적 저항·강인함은 이 버전의 범위 밖입니다. 기존 맵·웨이브·목표물·소환사 주문·시야 체계도 프로젝트 규칙을 사용합니다. 앞서 별도로 설계한 언리얼의 고지대·벽 차폐 및 마지막 관측 건물 상태 동기화는 이번 데이터 연결 작업에서 추가하지 않았습니다.

## 7.0.0 — 맵 크기와 진행 속도 선택

### 세 가지 전장 크기

- 출전 준비에 1배·1.5배·2배 맵을 추가했습니다. 실제 월드는 1600×1600·2400×2400·3200×3200이며 가로·세로 길이의 배율입니다. 면적은 기본의 1배·2.25배·4배입니다. 경기 시작 후 맵 크기는 변경하지 않습니다.
- 경기마다 `game.mapScale`, `game.map`, 공격로 경로를 만들고 기본 `MAP`을 공유 변경하지 않습니다. 기지·공격로·캠프·구조물 배치와 벽·수풀의 위치·반경을 확장합니다.
- 영웅·미니언·구조물 몸체 크기, 능력치, 이동 속도, 전투·시야 사거리와 게임 시간 규칙은 공통입니다. 큰 맵에서는 공격로 이동과 합류 거리가 늘어납니다.
- 이동·AI·카메라·미니맵·조준 경계가 해당 경기 크기를 사용합니다. 길잡이의 출발 위치, 상점 접근과 기지 위협 조언도 현재 맵으로 판정합니다.

### 네 가지 진행 속도

- 준비 화면·경기 HUD·일시정지 창에서 0.5배·0.75배·1배·1.5배를 선택하고 같은 값으로 동기화합니다. 예전 2배 선택은 제거했으며 기존 환경설정·체크포인트의 2는 1.5로 변환합니다.
- 속도는 누적 게임 시간에 적용하고 엔진은 계속 1/60초 고정 스텝으로 진행합니다. 이동·전투·쿨다운·웨이브·귀환·부활·경기 시계를 함께 조절합니다. 일시정지 중 바꿔도 정지 상태를 유지합니다.
- 맵·속도 선택을 브라우저 환경설정에 보관합니다. 진행 중 속도를 바꾸면 현재 경기 저장도 시도합니다. 이어하기는 저장된 경기의 맵·속도를 복원합니다.

### 큰 맵의 처리량과 표시

- 길찾기 셀 간격을 `40×mapScale`로 설정하여 맵 확대에 따른 기본 탐색 격자 수 증가를 막습니다. 벽·구조물 충돌과 개체의 실제 반경은 계속 검사합니다.
- 정적 지형 캐시의 긴 변을 최대 2048픽셀로 제한하고 월드 크기에 맞춰 그립니다. 안개는 월드 20단위당 한 셀로 80×80·120×120·160×160을 사용합니다. 카메라·미니맵과 맵 교체의 자원도 현재 경기 기준으로 갱신합니다.
- 미니맵·일시정지·이어하기 카드에 맵 크기를 표시하고, 최근 완료 경기와 전투 보고서에도 맵 배율을 기록·표시합니다. 기존 기록에 배율이 없으면 1배로 표시합니다. `NexusFront.snapshot()`에는 맵 크기, `NexusFront.settings()`에는 현재 맵·속도를 제공합니다.

### 저장 호환과 검증

- 새 엔진 체크포인트는 v7이며 숫자형 `state.mapScale`에 1·1.5·2만 허용합니다. v4·v5·v6·v7을 읽고 이전 세 버전은 1배 맵으로 복원합니다. 저장 래퍼와 엔진 데이터의 형식 버전 1, 저장 키는 유지합니다.
- 선택한 월드 크기로 개체·경로·명령·예약 영역·예고 좌표를 검증합니다. UI 메타데이터로 월드 경계를 임의 확대하지 않으며, 큰 맵의 길잡이 원점은 정상 보관합니다. 실제 복원 검증 뒤 쓰기와 실패 시 이전 슬롯 보존을 유지합니다.

## 6.0.0 — 공격 준비, 이동 전투와 안전한 이어하기

### 영웅 기본 공격의 세 단계

- 기본 공격을 준비와 실제 발사로 분리했습니다. 준비 시간은 `clamp(0.25 / 유효 공격 속도, 0.10, 0.32)`초이며 전체 주기는 준비 시작부터 계산합니다. 시작한 공격의 주기는 도중의 공격 속도 변화로 바뀌지 않습니다.
- 이동·정지·귀환·성공한 QWER/점멸, 기절·사망·유효하지 않은 대상은 준비를 취소합니다. 같은 적 반복 클릭, F 회복·와드와 실패한 스킬 사용은 준비를 유지합니다.
- 준비 취소는 키라의 강화 공격을 소모하지 않습니다. 실제 발사 시 한 번 소모합니다. 발사 후 이동은 투사체를 지우거나 공격 대기를 초기화하지 않습니다.
- 방향 이동과 일반 클릭 이동 중 자동 기본 공격을 시작하지 않습니다. 공격 이동은 대상에게 접근해 멈춘 뒤 준비하며, AI도 준비 중에는 발을 멈춥니다. 포탑 위험·예고 광역 공격·위험한 체력은 준비보다 회피를 우선합니다.
- 미니언·포탑·몬스터의 기본 공격 간격은 기존 규칙을 유지합니다.

### 전투 상태의 시각 피드백

- 체력·마나 아래에 발사 준비·재공격 대기·공격 가능 상태와 진행 게이지를 추가했습니다.
- 플레이어의 준비 진행과 공격 가능 상태를 원호로 표시하고, 발사 직후 짧은 방향 섬광을 표시합니다. 다른 영웅은 준비 중에만 작은 표시를 사용합니다.
- V / 공격 범위 버튼을 추가했습니다. A 공격 이동 위치를 선택할 때도 사거리를 확인할 수 있습니다. 스킬 조준 시에는 스킬 미리보기가 우선합니다.
- 준비 대상 연결선은 실제로 보이는 적에게만 표시합니다. 기존 금빛 영웅 고정 표시를 유지했습니다.
- 모바일의 조이스틱·명령·성장·조준 취소 배치를 새로운 상태 게이지에 맞추어 조정했습니다.

### 저장 검증과 호환

- 엔진 저장은 v6으로 기록하며 v4·v5·v6을 읽습니다. 이전 저장의 발사된 투사체와 남은 대기 시간은 유지하고 새 준비 공격을 만들지 않습니다.
- 준비 대상·남은 시간·기간과 `attackCooldown = period - duration + remaining` 관계를 검증합니다. 준비 중 저장해도 재개 후 한 번만 발사합니다.
- 쓰기 전에 실제 복원 검증을 수행합니다. JSON 변환에 성공했더라도 유효하지 않은 엔진 상태라면 기존 저장 슬롯을 덮어쓰지 않습니다.
- 이전 v5 커밋을 직접 실행한 호환 fixture와 회귀 검사를 추가했습니다. 자동 검증 총 **197개**가 통과했습니다. 세부 조건과 실제 브라우저 범위는 [QA.md](QA.md)를 참고합니다.

## 5.0.0 — 직접 조준, 영웅 타깃 고정과 AI 교전 개선

### 끌어서 조준하고 놓아 시전

- 터치·펜·거친 포인터 또는 폭 700px 이하에서 방향·지점·돌진 스킬 버튼을 드래그해 조준하고 놓을 때 시전하도록 변경했습니다. 짧게 탭하면 자동 조준하며 자기 자신 대상 스킬은 탭 시전을 유지합니다.
- 드래그 전환 기준은 12 화면 픽셀입니다. 직선 탄환은 방향을 지정하고, 지점·돌진은 72px에서 최대 사거리에 도달하도록 시전 거리를 조절합니다. 점멸 최대 300·와드 최대 450 거리도 직접 조준할 수 있습니다.
- 취소 영역으로 끌어 놓기, Esc, 창 열기, 초점 이탈, 크기 변경, 사망, 포인터 취소·캡처 상실은 시전 없이 조준을 해제합니다. 조준 중에는 비용을 소비하지 않고 실제 놓기 시점에 엔진이 사용 조건을 검사합니다.
- 스킬 사거리·방향·목적지와 사용 불가 상태를 전장에 표시합니다. 지점·돌진의 목적지는 지도 경계까지 제한하고, 직선 탄환의 방향 좌표는 지도 밖도 허용하여 지도 끝에서도 입력한 각도를 유지합니다.
- `controls.js`에 포인터 소유권과 드래그 계산을 분리했습니다. 이동 조이스틱과 조준을 다른 손가락으로 함께 사용할 수 있으며, 손을 놓은 최종 좌표와 이동 중 영웅의 현재 위치를 반영합니다. 다른 손가락이 진행 중 스킬을 확정하지 않습니다.

### 이동과 분리된 영웅 타깃 고정

- **Z** 또는 **타깃 전환** 버튼으로 현재 보이는 살아 있는 적 영웅 중 플레이어 중심 900 거리 안의 대상을 순환합니다. 전장에서 적 영웅을 클릭해 공격할 때도 유효한 대상이면 고정합니다.
- 고정 영웅을 금빛 이중 고리·모서리 표식·**고정** 이름표와 대상 패널로 표시합니다. 패널에서 직접 해제할 수 있습니다.
- 방향키·조이스틱·클릭 이동 중에도 고정을 유지합니다. 자동 조준은 해당 스킬 사거리 안의 고정 영웅을 우선하고, 기본 공격도 실제 공격 사거리 안에 있을 때만 우선합니다. 고정 자체는 사거리 밖 추격을 만들지 않으며 직접 지정한 조준 좌표는 유지합니다.
- 클릭한 A 영웅을 추격하다 다른 B 영웅으로 고정을 바꾸면 이전 A 추격만 해제합니다. 이동 입력과 클릭·공격 이동은 유지하며 B로 새 추격을 만들지 않습니다. 같은 영웅 재고정은 기존 직접 추격을 유지합니다.
- S 정지·귀환·영웅이 아닌 대상 공격, 대상 사망·시야 상실·거리 이탈·플레이어 사망 시 해제합니다. 숨겨진 영웅의 위치를 알려 주거나 시야를 추가하지 않습니다.

### 포탑과 시야를 고려한 AI

- 적의 현재 위치에서 가까운 포탑만 검사하던 방식에서, 기본 공격을 하기 위해 실제로 접근할 예상 위치를 검사하도록 바꿨습니다. 포탑 범위 밖에서 가능한 원거리 견제는 유지합니다.
- 미니언 동행은 살아 있는 아군 미니언이 실제 포탑 공격 범위 안에 있는지 확인합니다. 체력이 높다는 이유로 동행 없는 위험 진입을 허용하지 않습니다.
- 포탑이 자신을 조준하거나 미니언 동행이 사라지면 근처 위험 범위를 벗어나도록 공격을 끊고 후퇴합니다. 일반 공격로 대상 선택과 매 프레임 추적에도 동일한 판단을 적용하고 위험한 집결 도착점을 보정합니다.
- 영웅을 선택한 다음 시야를 잃었을 때도 타깃과 경로를 해제합니다. 매 프레임 숨겨진 적의 새 위치를 따라가는 경로를 차단했습니다.

### 기존 경기 호환과 검증

- 새 진행 저장은 엔진 버전 5로 기록하며 고정 대상 ID를 포함합니다. 실제 v4 저장도 복원하고 당시에 없던 고정 상태는 비어 있는 값으로 마이그레이션합니다. 형식 버전 1과 저장 키는 유지합니다.
- 일시정지 복원과 입력 해제, 마나·쿨다운·예약 타격·RNG·장비·길잡이 보존을 유지합니다. 화면에서 누르던 조준 상태는 저장하지 않아 이어하기만으로 시전되지 않습니다.
- 드래그 임계값·거리·포인터 간섭·최종 놓기 좌표·취소·지도 경계, 타깃 우선순위·시야·거리·사망, 포탑 안전과 원거리 견제, v4 저장 호환을 자동 검증에 추가했습니다. 최종 테스트 수와 브라우저 실제 확인 범위는 [QA.md](QA.md)에 기록합니다.
- 기존 영웅·아이템·구조물 능력치, 가격과 기본 스킬 피해는 유지했습니다. 변경된 AI 판단에 따른 자연 경기 관측은 v5 조건으로 별도 기록합니다.

## 4.0.0 — 출전 준비, 전장 길잡이와 경기 이어하기

### 시작 장비와 구매 흐름

- 진행 경기 하나를 8게임초 간격과 탭 숨김·페이지 이탈 이벤트에서 저장합니다. 일시정지 창의 저장 후 나가기와 준비 화면의 이어하기를 연결했습니다.

## 3.0.0 — 협동 공략과 전투 분석

### 목표물 공략과 공격 예고

- T 전술 패널과 상단 목표물 버튼에 **드래곤 공략 / 거인 공략**을 추가했습니다. 등장 중인 목표물을 지정하면 아군 AI가 25초 동안 합류하며 목표 처치 시 지시를 정리합니다. 플레이어는 직접 이동해 참여합니다.
- AI가 목표 주변의 실제 합류 인원·체력·보이는 적 수를 확인한 뒤 공격합니다. 지원이 부족하면 둥지 바깥에서 기다리고 저체력에서는 후퇴합니다. 단순히 지나가는 공격로 AI를 협동 인원으로 세지 않습니다.
- 자율 정글 계획은 드래곤 4레벨·심연 거인 9레벨부터 검토합니다. 플레이어의 공략 지시는 이 레벨 조건을 요구하지 않으며 협동 인원과 체력 조건은 유지합니다.
- 드래곤의 **폭풍 강타**는 반경 125·1.05초 예고·마법 피해, 거인의 **심연 붕괴**는 반경 160·1.2초 예고·물리 피해입니다. 시전 당시 대상 위치를 고정하고 타격 시 영역 안의 영웅·미니언을 판정합니다. 상세 피해식·주기는 [GAMEPLAY.md](GAMEPLAY.md)에 있습니다.
- 몬스터 사망·전투 이탈·유효 공격 대상 상실 시 예고를 취소합니다. AI는 예고 영역에서 회피하고 플레이어는 직접 회피합니다.
- 현재 시야와 플레이어 위협 조건에 따라 지상 경고를 제공하며 충전·공격명·타격 파동을 표시합니다. 드래곤은 금빛, 거인은 보라색으로 전장·미니맵의 공략 핑을 구분합니다.

### 포탑 위험과 막타 보조

- 같은 영웅을 연속 공격하는 포탑의 피해를 첫 발 기본값, 이후 +22%·+44%·최대 +66%로 증가시킵니다. 4초 발사 공백·대상 변경·영웅 이외 대상 공격 시 초기화하며 피해는 발사 시 확정합니다.
- 근처 포탑 사거리, 플레이어 조준 연결선, 최근 발사의 연속 공격 단계를 표시합니다. 보호 중인 포탑은 위험 표시에서 제외합니다.
- 현재 보이고 사거리 안에 있는 적 미니언을 기본 공격 한 번의 피해로 처치할 수 있으면 체력바에 금색 테두리·다이아몬드를 표시합니다. 방어력·보호막·강화 공격·드래곤 중첩을 계산합니다.
- 막타 표식은 입력 보조이며 자동 공격을 실행하지 않습니다. 기본 공격 대기시간과 이후 다른 공격에 따른 변동까지 처치 성공으로 보장하지 않습니다.

### 사망 분석과 경기 종료

- **C** 또는 사망 배너·점수판 버튼으로 최근 사망 전 10초의 공격원·타격 수·피해 유형을 확인합니다. 실제 체력 피해와 보호막 흡수를 분리합니다.
- 피해 사건은 최대 256개, 공격원은 최대 12행으로 제한합니다. 공격원이 많으면 상위 11개와 기타 피해로 묶습니다. 부활 후에도 마지막 사망 기록을 유지하며 창을 보는 동안 경기는 계속 진행합니다.
- 일시정지 창의 접힌 **경기 종료** 안에 **항복하고 결과 보기**를 추가했습니다. 항복은 정상 패배 결과와 기록을 만들고 넥서스 파괴와 다른 종료 사유를 보존합니다. 영웅 선택 복귀·중도 새로고침은 완료 경기로 저장하지 않습니다.

### 전투 보고서와 최근 기록

- 완료 경기의 **전투 보고서**에서 양 팀 10명의 영웅·최종 레벨·KDA·CS·실제 체력 피해·장비를 비교합니다. 피해는 모든 전투 대상 유형을 합산하며 영웅 대상만의 통계가 아닙니다. 팀 피해·처치와 드래곤 중첩도 표시합니다.
- 최근 5개 v3 기록에서 상세 보고서를 다시 열 수 있습니다. 플레이어의 최종 레벨과 팀 구조물 파괴 수, 양 팀 통계·장비·목표물 상태를 기록에 포함합니다.
- DOM 독립 UMD 모듈 **history.js**로 기록 생성·정규화·읽기·추가를 분리했습니다. 기존 v2 기록은 공통 항목을 보존하며 당시 저장하지 않은 상세 데이터는 새로 만들어 채우지 않습니다.
- 완료 경기별 안정적인 ID로 중복 저장을 방지하고 최초 저장 결과를 유지합니다. 손상된 값·JSON 오류·저장 접근 제한·용량 초과를 처리합니다.
- 저장이 실패해도 현재 세션에서는 결과와 보고서를 확인할 수 있고 저장 불가를 안내합니다. 저장 실패 상태의 재로드 보존이나 계정·기기 간 동기화는 제공하지 않습니다.

### 이동과 화면 표시 수정

- 부활 후 드래곤으로 이동할 때 중앙 억제기·기지 포탑 사이에서 멈추는 문제를 수정했습니다. 살아 있는 구조물을 정글 벽과 함께 이동용 경로·충돌·슬라이드에 반영하고 파괴 시 갱신합니다. 공개 Navigation API는 유지합니다.

- 종료 통계 카드에 누락된 스타일 클래스를 적용하여 시간·KDA·CS·레벨·피해·구조물 통계가 정해진 카드 배치로 표시되도록 수정했습니다.

- 시작 상태를 Q 1랭크, W·E·R 미습득으로 변경했습니다. 레벨이 오를 때마다 스킬 포인트 1개를 지급합니다.

- 기본 경기 회귀 검증에 스킬 투자, 조합·판매, 공격 이동·정지, 팀 지시, 막힌 경로·우회·벽 슬라이드 검증을 추가했습니다. 실행 시점의 테스트 수와 브라우저 확인 결과는 [QA.md](QA.md)에 기록합니다.

## 1.0.0 — 첫 플레이 가능한 코어

- 독립 영웅 3종, QWER·점멸·회복·와드, 기본 공격과 상태 효과를 구현했습니다.
- 플레이어 1명과 아군 AI 4명 대 적 AI 5명, 세 공격로 웨이브, 정글 목표물, 성장·아이템 구매, 귀환·사망·부활을 연결했습니다.

- Canvas 자체 도형과 Web Audio 합성으로 자산 의존성을 없애고, 단일 HTML 오프라인 배포와 Node 엔진 테스트를 제공했습니다.

## 변경 근거

- [navigation.js](dist/navigation.js): 벽 배치·통행·경로·충돌.
- [controls.js](dist/controls.js): 스킬 드래그·포인터 소유권·취소·거리와 지도 경계 계산.
- [game.js](dist/game.js): 이동·성장·거래·전술 및 경기 규칙.
- [renderer.js](dist/renderer.js): 지형·우회 경로·팀 지시 표시.
- [history.js](dist/history.js): v2·v3 기록 호환, 완료 기록 생성, 최근 5개·중복·저장 오류 처리.
- [checkpoint.js](dist/checkpoint.js): 진행 경기 검증·보관·복원·저장 실패 처리.
- [coach.js](dist/coach.js): 준비 장비·핵심 빌드·길잡이 관측과 상황 조언.
- [app.js](dist/app.js): 입력·준비·길잡이·성장·전술·상점·사망 분석·전투 보고서·기록·이어하기 UI.
- [tests/](tests/): 전투·성장·분석·항복·기록·저장 복원·길잡이 검증 조건.
- [package.json](package.json), [build-offline.cjs](scripts/build-offline.cjs): 실행 명령과 게임 스크립트·다운로드 보조의 패키징.
