공통 실행 경로는 Web/index.html입니다. 플랫폼 노출 상태는 사용자 요청으로 제외이며 전체 목록은 상위 catalog.json에서 관리합니다.

실행 파일은 최신 확보 버전 18.0.0을 기준으로 구성했습니다. 게임 진행 데이터와 플랫폼 데이터는 산출물 폴더 이동과 별개로 브라우저 및 플랫폼 저장소에서 관리됩니다.
