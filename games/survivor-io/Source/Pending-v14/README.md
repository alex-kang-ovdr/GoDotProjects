# Survivor Arena v14 — R3 Reference Playable

R3 원작 역기획 자료의 **선별된 공개 참조 규칙**을 실제 브라우저 전투에 연결한 독립 게임입니다. 로블록스풍 블록 3D와 화면 기준 W/S 조작을 유지합니다. 원작 클라이언트 추출본이나 공식 게임이 아닙니다.

## 실행

압축을 풀고 **`index.html`을 Chrome 또는 Edge에서 여세요.** 서버·npm·CDN·인터넷·별도 에셋 설치 없이 실행하도록 구성했습니다. 채팅의 HTML 미리보기는 실행 환경이 아니므로 파일을 내려받아 브라우저에서 여세요. 정적 서버에도 폴더 그대로 올릴 수 있습니다.

기존 v13 게임은 **`custom/index.html`**입니다. v14 로비에서도 커스텀 링크로 이동합니다. 두 모드의 저장은 분리되어 있습니다. 단일 v14 HTML만 내려받았다면 커스텀 링크는 연결되지 않으므로 전체 ZIP을 사용하세요.

## 플레이

1. 로비에서 주무기 5종 중 하나를 장착합니다. 첫 플레이는 쿠나이가 자동 조준이라 편합니다.
2. 도시·사막·빙결 시험장, 5분 테스트 또는 15분 생존, 일반/도전을 선택합니다.
3. 이동하며 자동 공격으로 적을 처치하고 경험치를 모읍니다.
4. 레벨업마다 액티브/보조/조건을 만족한 진화 후보 중 하나를 선택합니다.
5. 보급 상자, 중간 보스, 최종 보스를 거쳐 승리·패배 기록을 정산합니다. 시간만 채우면 이기는 것이 아니라 최종 보스를 처치해야 합니다.

**5분:** 2분 30초 중간 보스, 5분 최종 보스. **15분:** 5분·10분 중간 보스, 15분 최종 보스입니다. 전장/웨이브/보스는 자체 재구성이지 원작 특정 챕터의 복구본이 아닙니다.

## 콘텐츠

| 영역 | 구현 |
|---|---|
| 주무기 5종 | 쿠나이·야구 방망이·카타나·샷건·리볼버 |
| 전투 액티브 11종 | 수호자·로켓·번개·화염병·드릴·A/B 드론·축구공·벽돌·부메랑·방어막 |
| 보조 12종 | 공격·이동·쿨다운·체력·자석·5초 회복·범위·지속시간·탄속·경험치·골드·피해 감소 |
| 진화/합체 | 14개 무기+보조 조합, A/B 드론 합체 1개 |
| 빌드 제한 | 장착 주무기 포함 액티브 6칸, 보조 6칸. 드론 합체 시 1칸 반환 |
| 부품 효과 시험 | 드론 유도·낙뢰 +2·로켓 기본 간격 −0.5초 토글. 실제 장비 획득/등급 성장은 아님 |
| 저장 | 별도 v14 프로필·전투 체크포인트, 선택 후보와 전투 설정 복원 |
| 시각/조작 | WebGL 3D·2D 대체, 화질 설정, 터치 조이스틱, 레이더, 피해 통계 |

샷건·카타나·방망이는 이동 방향을 사용합니다. 샷건으로 계속 적에게 등을 보이며 달리면 적을 맞히기 어려우므로 적을 향해 돌아서 사격하세요. 자동 조준은 쿠나이·리볼버입니다.

## 조작

| 입력 | 기능 |
|---|---|
| WASD / 방향키 / 터치 드래그 | 이동. W 위, S 아래 |
| 1 / 2 / 3 | 레벨업 카드 선택 |
| R | 레벨업 후보 다시 뽑기, 전투당 3회 |
| B | 빌드·보조 스탯·무기별 피해량 확인 |
| P / Esc | 일시정지·계속하기 |
| V / N / M | 2D/3D · 레이더 · 효과음 |
| F2 | 렌더링 진단 |

참조 모드에서는 v13의 Space 대시·E 특수기·거점·특성을 사용하지 않습니다. 해당 자체 시스템은 커스텀 v13에서 유지합니다.

## 중요한 구분

**공개 참조:** 12종 보조의 60개 레벨 값, 15개 진화/합체 조건, 3개 부품 효과 연결.

**구현용 설계값:** 기본 피해·쿨다운·몬스터 HP·공격력·카드 확률·드랍·레벨 경험치·모든 웨이브·보스 패턴·보상. R3에서 미확인이었던 원작 값을 복구한 것으로 취급하지 않습니다. R3 액티브 ATK 계수는 타격 기준 미확인이라 그대로 실행 피해에 넣지 않았습니다.

**미구현:** 원작 전체 콘텐츠, SS/신련/컬렉션/탈것/펫/장비 6부위 성장·경제·유료 결제·서버·멀티플레이. 보상 크레딧은 현재 기록용이며 전투 능력에 자동 투자되지 않습니다. 배경 건물/차량/나무는 장식으로 충돌이나 엄폐가 없습니다.

자세한 내용: [구현 범위](docs/IMPLEMENTATION_SCOPE.md), [저장 이전](docs/SAVE_AND_MIGRATION.md), [아키텍처](docs/ARCHITECTURE.md), [테스트 보고서](docs/TEST_REPORT.md).

## 기존 저장 보존

v14는 기존 `survivor_profile_v2`, `survivor_run_v12`를 변경하지 않습니다. 그러나 다른 파일 경로의 v13을 열면 브라우저의 저장 영역이 달라질 수 있습니다. 이전 v13에서 설정 → 저장 백업으로 영구 기록을 보관한 후 `custom/index.html`에서 가져오세요. v14에 v13 백업을 가져오지 않습니다. 진행 중인 v13 전투를 자동으로 새 경로에 복사하지 않습니다.

## 수정

`data/runtime_balance.json` 또는 `src`를 수정한 뒤 `python build.py`를 실행합니다. 실행 자체에는 Python이 필요하지 않습니다. 전체 소스·자동 검사 코드·실제 브라우저 캡처를 함께 제공합니다.
