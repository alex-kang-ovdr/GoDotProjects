# 저장·호환·이전

## 분리된 저장

| 영역 | v14 참조 모드 | v13 커스텀 |
|---|---|---|
| 영구 기록 | survivor_reference_profile_v14 | survivor_profile_v2 |
| 전투 | survivor_reference_run_v14 | survivor_run_v12 |
| 화면 설정 | survivor_reference_graphics_v14 | survivor_graphics_v10 |
| 출전 시험 설정 | survivor_reference_options_v14 | 없음 |
| 전투 포맷 | SurvivorReferenceRun / 14 | SurvivorArenaRun / 13 |
| 영구 백업 | SurvivorReference / 14 | SurvivorArena / 12 |

v14는 v13 저장을 읽거나 덮어쓰지 않습니다. 커스텀 코드와 실행 파일은 v13 제공본 그대로입니다. 다른 경로로 복사한 HTML은 브라우저에 따라 다른 저장 영역을 사용할 수 있습니다. **커스텀 링크를 열었다고 기존 file:// 경로의 전투가 자동으로 이전되지는 않습니다.**

기존 영구 기록을 옮기려면 원래 v13에서 설정 → 저장 백업으로 JSON을 내보내고 `custom/index.html`의 설정에서 가져옵니다. 진행 중 전투는 영구 JSON에 포함되지 않습니다. 기존 전투까지 유지하려면 원래 파일을 백업하고 동일한 경로의 v13 실행본을 계속 사용해야 합니다.

## v14 이어하기

실행 중 5초 간격, 선택 화면, 일시정지와 주요 상태 변경에서 저장을 시도합니다. 일시정지 → 저장 후 로비 → 이어하기를 사용할 수 있습니다. 레벨업/진화 선택 중의 후보, 5초 회복 주기, 수호자의 가동/대기 시간, 탄창/재장전, 드론 부품 설정, 5/15분 시간축도 저장합니다.

복원된 일반 전투는 정지 상태로 열립니다. 레벨업은 저장 당시 동일 후보를 다시 표시합니다. 저장한 전투의 부품·시간축은 로비에서 나중에 바꾼 설정으로 바뀌지 않습니다.

정산된 전투 ID는 영구 기록과 함께 기록한 뒤 체크포인트를 삭제합니다. 반복 정산을 방지하며 최근 64개 ID를 보관합니다. 단일 브라우저 원점의 한 활성 창을 전제합니다. 여러 탭 동시 플레이, 클라우드 동기화, 변조 방지 또는 서버 원장은 없습니다.

## 실패와 검증 한계

저장 실패 시 경고합니다. 저장 후 로비가 실패하면 전투를 종료하지 않습니다. 강제 종료 시에는 마지막 성공한 체크포인트까지만 복원할 수 있습니다.

자동 검사에서는 메모리 localStorage 어댑터로 직렬화·새 문서 복원을 확인했습니다. 실제 파일 경로 브라우저 재시작 검사는 환경 정책 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되어 확인하지 못했습니다. 사용자 환경의 저장 차단·용량 부족·시크릿 모드에서는 영구 기록 JSON을 별도로 보관해야 합니다.
