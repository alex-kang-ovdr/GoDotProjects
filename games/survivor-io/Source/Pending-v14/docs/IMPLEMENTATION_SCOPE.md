# v14 적용 범위와 근거 경계

## R3에서 가져와 실행에 연결한 것

- `data/reference_subset.json`에 R3의 패시브 12종, 레벨 60행, 구현 가능한 진화·합체 15조합, 3개 과학 부품 효과와 해당 출처 레코드를 원문 필드 그대로 보관합니다.
- `maps`는 원작 내부 ID가 아니라 이 게임의 ID와 R3의 재구축 ID를 잇는 로컬 매핑입니다.
- 보조 수치, 필요 레벨/대응 보조, 드론 합체의 두 입력과 슬롯 반환을 실행 코드가 참조합니다.
- 레벨업과 상자가 같은 `evolutionEligible()` 판정기를 사용합니다. 조건 만족은 후보 자격이며 다음 카드 출현을 보장하지 않습니다.
- 모든 출처가 현재 원작 클라이언트를 직접 검증한 데이터인 것은 아닙니다. 이번에 사용하는 전투 참조 항목은 COMMUNITY 공개 기록입니다.

## 구현용 값을 유지한 것

`data/runtime_balance.json`의 모든 수치는 DESIGN입니다. 피해, 쿨다운, HP, 이동/탄속, 재장전, 범위, 투사체 수, 관통, 진화 공격 강화, 경험치 요구량, 드랍률, 카드 가중치, 보스 패턴, 웨이브와 정산은 실제 원작 수치라고 주장하지 않습니다. 일부 기본 규칙을 참고하더라도 원작 전체 계산식의 복원은 아닙니다.

R3의 액티브 ATK 계수 표는 타격 기준이 미확인이라 자동 피해 공식에 넣지 않았습니다. `null` 수치에 원작인 것처럼 가정값을 덮어쓰지 않고 실행용 밸런스를 별도 파일로 격리했습니다.

## 주무기와 전투 스킬

출전 주무기는 쿠나이, 야구 방망이, 카타나, 샷건, 리볼버 중 1개입니다. 주무기는 6개 액티브 슬롯에 포함되며, 다른 주무기가 전투 레벨업 후보로 나오지 않습니다.

전투 스킬은 수호자, 로켓 발사기, 번개 발사기, 화염병, 드릴샷, A형 드론, B형 드론, 축구공, 벽돌, 부메랑, 방어막입니다. 11개 중 남는 슬롯에 배치합니다. 파괴자는 A/B 합체 결과이므로 별도 시작 스킬이 아닙니다.

원작 모든 무기·스킬을 구현한 것은 아닙니다. Lightchaser, Void Power, Sword of Disorder, 레이저, 지뢰 조합, 두리안, 캐릭터 고유 스킬, SS 장비 계열은 이 버전에 추가하지 않았습니다.

## 공격 구현의 구체적인 경계

| 항목 | 동작 | 수치/패턴의 상태 |
|---|---|---|
| 쿠나이 | 자동 조준·추적, 진화 후 고속 연사 | 구현용 탄수·속도·쿨다운 |
| 방망이 | 이동 방향 부채꼴 타격·일반 적 밀치기 | 부채꼴 각도·범위·넉백은 설계값 |
| 카타나 | 전후 양방향 관통 검기 | 투사체 크기·수명·피해는 설계값 |
| 샷건 | 마지막 이동 방향 산탄, 진화 후 연사 | 방향성 조준을 직접 운영해야 함 |
| 리볼버 | 자동 조준·6발 후 재장전, 진화 쌍발 | 탄창과 재장전 시간은 구현용 |
| 수호자 | 진화 전도 일반 탄환 차단, 가동/대기 주기 | 지속시간·회전반경·다운타임은 설계값 |
| 드릴 진화 | 복귀 궤도가 아닌 자동 추적 관통 화살 | 추적 속도·수명은 설계값 |
| 드론 | 기본은 방사 패턴, 정밀 부품 시험 시 추적 | 방사각·탄수·간격은 설계값 |
| 축구공 | 적과 발사 지점 중심의 비행 경계에서 반사 | 경계는 화면이 아닌 구현용 월드 범위 |
| 부메랑 | 투척 후 복귀, 진화 후 회전 다트 | 궤도·반복타격 간격은 설계값 |
| 방어막 | 주변 지속 피해, 진화 후 둔화 | 둔화율·타격 간격은 설계값 |

시각용 메시·탄흔·폭발·바닥 그림자는 절차적 블록 3D입니다. 배경 나무·차량·건물에는 충돌·엄폐가 없습니다. 원작/Roblox 에셋을 사용하지 않았습니다.

## 미적용 성장 및 경제

SS 신련·컬렉션·탈것·펫·장비 6부위 성장·S/SS 장비 합성·확률형 상자·과금·계정/서버 기능은 실행하지 않습니다. R3 후기 성장 데이터를 무리하게 게임에 끼워 넣지 않았습니다. 과학 부품 3개는 무료 시험 토글로만 제공하며 실제 장비 등급/획득 흐름이 아닙니다.

v14 크레딧은 전투 기록용입니다. v13의 영구 강화 능력치는 참조 모드로 가져오지 않습니다. 같은 패키지의 `custom/index.html`은 기존 자체 설계를 보존한 별도 게임입니다.
