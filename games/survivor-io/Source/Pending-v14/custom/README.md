# Survivor Arena v13 — Specialization Update

로블록스풍 블록 3D의 독립 JavaScript 서바이버라이크입니다. v12의 화면 기준 W/S 조작, 자동 전투, 드론 합체, 캐릭터 특수기, 챕터 보스, 장비 합성, 거점 수비, 이어하기를 유지하고 **전투 특성 9종·속성 정예 3종·피격 원인 기록**을 추가했습니다. 공식 탕탕특공대 또는 Roblox 제품이 아니며 공식 이미지·모델·음원·로고나 실제 결제를 포함하지 않습니다. 규칙과 수치는 이 프로토타입의 자체 설계입니다.

## 실행

ZIP을 풀고 `index.html`을 Chrome 또는 Edge에서 여세요. JavaScript·CSS·절차적 3D 모델이 단일 HTML에 포함되어 있어 게임 실행에 서버, npm, CDN, 외부 에셋 다운로드가 필요하지 않습니다. 정적 웹 서버에도 이 파일 하나만 게시할 수 있습니다. 채팅의 파일 미리보기와 실제 게임 실행은 다릅니다.

소스를 수정한 뒤에는 `python build.py`로 단일 HTML을 다시 만듭니다. Python과 Playwright는 개발·테스트용이며 게임 실행에는 필요하지 않습니다.

## 전투 특성

경험치 레벨이 **5, 10, 15**가 되면 특성을 하나씩 고릅니다. 일반 레벨업의 무기·보조 선택은 그대로 받습니다. 여러 레벨을 한꺼번에 올려도 일반 강화 횟수가 사라지지 않습니다. 선택한 특성은 다음 후보에서 제외되며 해당 전투에만 적용됩니다.

| 특성 | 효과 | 세부 규칙 |
|---|---|---|
| 냉각 탄두 | 무기 적중 시 1.5초 둔화 | 일반 적 이동 −30%, 보스 −10%. 화염 지속 피해·특수기·포탑은 제외. 공격 예고·돌진 거리는 유지 |
| 거물 사냥꾼 | 보스·엘리트 대상 모든 피해 +25% | 방호 정예 보호막에도 적용. 일반 적 피해는 그대로 |
| 오버클럭 | 무기 공격 간격 −18%, 무기 피해 −8% | 수호자의 재타격 간격에도 적용. 캐릭터 특수기·포탑에는 미적용 |
| 전장 수집가 | 획득 경험치 +20%, 흡수 반경 +45 | 기존 자석 보조와 중첩. 선택 전에 얻은 경험치를 소급 지급하지 않음 |
| 적응형 방벽 | 8초 동안 피격되지 않으면 다음 피해 1회 차단 | 최대 1회 충전. 막은 직후 0.25초 보호. 충전 중 피격되면 타이머 초기화 |
| 충격 기동 | 대시 재사용 −25%, 대시 출발점 폭발 | 반경 110, 기본 피해 60 × 현재 공격 배율. 대시 쿨다운 4.5 → 3.375초 |
| 전술 축전지 | 특수기 재사용 −20%, 사용할 때 최대 HP의 8% 회복 | 선택 시 이미 남아 있는 쿨다운도 한 번 20% 단축. 초과 회복 없음 |
| 연쇄 폭파 | 해당 특성 폭발을 제외한 처치 12회마다 폭발 | 반경 105, 기본 피해 80 × 공격 배율. 마지막 처치 위치에서 발생. 자기 폭발 처치는 재충전하지 않음 |
| 전투 응급처치 | 선택 후 20처치마다 최대 HP의 6% 회복 | 모든 처치 인정. 최대 HP를 넘지 않음 |

반경·사거리는 화면 픽셀이 아닌 게임 월드 단위입니다. 특성 선택 화면에서도 전투를 저장하고 로비로 돌아갈 수 있습니다. 이어할 때 같은 후보가 복원되며 재접속으로 무료 재추첨하지 않습니다. 특성 카드에서 숫자키 1/2/3을 사용할 수 있습니다.

### 효과 중첩과 집계

`거물 사냥꾼`은 대상 보정이고 `오버클럭`은 무기 피해 보정이므로 함께 적용됩니다. 방호 정예는 보호막을 먼저 소모하고 남는 피해만 HP에 전달합니다. `무기별 피해`는 기존과 같이 실제 감소 HP를 집계하며 과잉 피해를 포함하지 않습니다. 보호막 피해는 별도 특성 통계에 기록합니다.

연쇄 폭발은 즉시 재귀 호출하지 않고 대기열에서 처리합니다. 한 번에 최대 32개를 보관하고 폭발 자체의 처치는 다시 폭발 횟수를 충전하지 않습니다. 회복은 실제 증가한 HP만, 방벽은 완화 후 차단한 피해를 집계합니다.

## 속성 정예

| 속성 | 동작 | 회피·대응 |
|---|---|---|
| 방호 | 최대 HP의 30% 추가 보호막, 재생 없음 | 파란 보호막을 소모한 뒤 본체 HP에 피해. 보호막 파괴 표시 |
| 광폭 | 이동 +22%, 공격 +18% | 주황색 회전 장식. 접근을 허용하지 않도록 이동·둔화 활용 |
| 파동 | 첫 공격 3초 뒤, 이후 5.5초마다 파동 예고 | 1.1초 예고 후 1.1초간 반경 190까지 확장. 소유 정예를 처치하면 미해결 파동 취소 |

정기 엘리트는 60초와 240초에 등장합니다. 기본 일정에서는 도시가 방호/파동, 사막이 광폭/방호, 연구소가 파동/광폭입니다. 속성 정예는 기본 엘리트 대비 경험치가 1.5배이고 처치 시 추가 15G를 얻습니다. 동일한 적을 다시 피해 처리해도 처치·보상을 중복 지급하지 않습니다. 보스에는 이 속성이 붙지 않습니다.

## 피격 기록

접촉, 원거리 탄환, 저격, 돌진, 보스 충격파·포격·레이저·빙결 탄막, 위험 지역, 정예 파동을 구분합니다. 무적·대시·방벽으로 막은 피해는 체력 손실 기록에 넣지 않습니다. 체력이 5일 때 50 피해를 받아 쓰러지면 기록에는 실제 감소한 5HP가 남습니다. 승리·패배 결과 모두 최근 기록과 특성 통계를 확인할 수 있습니다.

## 유지한 기존 게임 루프

3명 중 캐릭터 선택 → 8종 중 시작 무기 선택 → 자동 전투·경험치 → 무기/보조 6칸씩 성장 → 무기 진화·A/B 드론 합체 → 중간 보스(150초) → 최종 보스(300초 출현) → 정산·장비 강화/3개 합성 → 다음 챕터입니다. 최종 보스를 실제로 처치해야 승리합니다.

선택형 보급 거점은 45초와 190초에 등장하고, 원 안에 적이 없는 상태로 누적 8초를 확보하면 상자·70G·정산 부품 2개 등을 지급합니다. 기존 선봉대원 충격파, 공병 고정 포탑, 구조대원 회복장을 유지합니다. 장비 3부위·4등급, 3개 합성, 부품 제작, 최고 등급 자동 장착도 그대로입니다.

## 저장과 이전 버전

영구 저장 키 `survivor_profile_v2`와 영구 스키마 12는 호환성을 위해 유지합니다. 전투 키도 `survivor_run_v12`를 유지하되 기록 내용의 버전을 **13**으로 씁니다. v12 전투는 읽어서 새 특성 상태를 채웁니다. v13 체크포인트를 v12로 다시 읽는 하위 호환은 지원하지 않습니다.

전투는 5초 간격과 주요 선택·일시정지 시점에 저장합니다. 레벨업·진화·특성 화면의 후보를 보존하고, 복원된 일반 전투는 사용자 확인 전까지 정지합니다. 저장 전투의 장비 보너스도 보존하여 로비에서 강화해도 진행 중인 전투 능력치가 소급 변경되지 않습니다. 이미 정산한 전투 ID는 중복 정산하지 않습니다.

**교체 전 백업:** v12의 설정 → 저장 백업에서 영구 기록 JSON을 보관하세요. 파일 이름·경로·브라우저·사이트 주소가 바뀌면 저장 영역이 달라질 수 있습니다. 진행 중인 전투를 이어가려면 원본을 백업한 뒤 기존과 같은 경로의 `index.html`을 교체해야 하며, 해당 브라우저가 그 파일 원점에 저장을 제공해야 합니다. 영구 기록 JSON에는 진행 중인 전투가 포함되지 않습니다.

v12에서 이미 Lv.5 이상인 전투를 이어하면 재개 시 도달한 특성 단계가 제공됩니다. 기존 무기·보조·체력·정산은 유지됩니다. 저장 공간 부족이나 접근 실패 시 경고하고, 저장 후 로비가 실패하면 전투를 종료하지 않습니다. 다중 탭 동시 플레이, 클라우드 저장, 서버 검증, 변조 방지, 결정론적 리플레이는 지원하지 않습니다.

## 검증 결과와 한계

최종 배포 HTML을 대상으로 **자동 기능 검사 272/272**을 통과했습니다.

| 검사 묶음 | 통과 |
|---|---:|
| 기존 전투·입력·성장·렌더링 회귀 | 110 / 110 |
| v12 특수기·거점·이어하기 회귀 | 71 / 71 |
| v13 특성·정예·저장 호환·피격 기록·모바일 UI | 91 / 91 |

기존 테스트의 다중 레벨업·장시간 시뮬레이션 조작부는 새 특성 화면도 선택하도록 보완했습니다. 기존의 검증 조건을 삭제하거나 완화하지 않았습니다. 260개 적과 속성·둔화 이펙트가 있는 장면도 렌더링 오류 및 드로우콜 상한 검사에 포함합니다. 이는 실제 기기의 프레임률 보장이 아닙니다.

별도의 기본 프로필 자동 플레이 3회는 모두 최종 보스 처치로 종료됐습니다. 무적이나 무료 강화 레벨은 주지 않았고, 실제로 얻은 강화와 특성을 봇이 선택했습니다. 하나의 챕터·일반 난이도의 세 시드만 확인했으며 모든 조합·난이도의 균형이나 사람의 플레이를 대표하지 않습니다. 자세한 결과는 `tests/balance_probe.json`에 있습니다.

기능 검사는 Linux Chromium + Xvfb + SwiftShader에서 **최종 HTML을 set_content로 주입**하고, 메모리 저장 어댑터를 새 문서에 복사해 수행했습니다. 별도의 실제 `file://` 탐색 및 브라우저 재시작 저장 검사를 시도했지만 `ERR_BLOCKED_BY_ADMINISTRATOR` 정책 오류로 실행하지 못했습니다. 따라서 실제 파일 원점의 저장 지속성·재시작 복원은 미검증입니다. `tests/file_origin_probe.json`에 제한을 기록했고, 이 시도는 272개 통과 검사에 포함하지 않았습니다.

물리 Android/iOS GPU 성능·발열·장시간 플레이, Safari는 확인하지 않았습니다. 배경 차량·나무·건물은 장식이며 충돌·엄폐·길찾기가 없습니다. 모델은 절차적 메시이고 그림자는 바닥 투영입니다. 원작 전체 콘텐츠나 상용 서비스 수준의 QA를 완료한 제품은 아닙니다.

`previews/combat_v13.png`는 신규 효과를 함께 보여주도록 **스크립트로 배치한 테스트 장면의 실제 브라우저 캡처**입니다. 생성 이미지나 자연 플레이 사진이 아닙니다.
