## 4. 판본별 차이점 (PC-98 원작 vs Windows 리뉴얼)

| 구분 | PC-9801 오리지널 (1995) `[확인]` | Windows 리뉴얼판 (1999) `[확인]` | 현대 재구현 엔진 시사점 `[재구성안]` |

| 해상도 / 색수 | 640×480, 8bit (256색) | 640×480, High Color | 4:3 기본 뷰포트 + 반응형 패널 레이아웃 |

| 조작·UI | MS-DOS 커맨드 선택 + 마우스/키보드 | Windows 창 모드·개선 UI | 커맨드 바 + 직접 핫스팟 클릭 하이브리드 지원 |
| 부가 수록 | 본편 단독 | 팬디스크 『盗作(도작)』 동봉 패키지 등 | 본편 데이터셋과 별도 DLC/시나리오 팩 확장 가능 구조 |

## 5. 핵심 용어집

- **폐쇄 서클(Closed Circle)**: 5층 구교사의 모든 창문이 판자로 막히고 층간 계단이 잠겨 외부와 단절된 탐색 무대.
- **핫스팟(Hotspot)**: 특정 방 내부에 존재하는 상호작용 대상(금고, 석고상, 타임 레코더, 난로, 천장 손잡이, NPC 등).
- **윤활 선행 규칙(Lubrication Prerequisite)**: 녹슨 자물쇠에 `item_machine_oil`(기계유)을 먼저 적용한 뒤 열쇠를 사용해야 파손되지 않는 원작 기믹.
- **백트래킹 루프(Backtracking Loop)**: 4층에서 얻은 `item_screwdriver`(드라이버)를 가지고 5층으로 되돌아가 금고 뒷면의 `item_d_battery`를 회수하는 등 상·하층을 왕복하는 퍼즐 설계.
- **사건 윈도우(Incident Window)**: 특정 페이즈/방에서 캐릭터가 `at_risk` 상태에 들어간 뒤 구출하지 않으면 `compromised`로 전이되는 행동 허용 구간.
- **증거 비디오테이프(`item_evidence_tape`)**: 동료 구출에 실패했을 때 화장실 등지에 출현하는 실패 지표 아이템. 전원 생환(해피 엔딩) 루트에서는 발생하지 않는 것이 정상.
- **소프트락(Softlock) / 하드락(Hardlock)**: 필수 열쇠 파손 또는 누락으로 인해 탈출 경로에 영구 도달할 수 없게 되는 상태.
