# 06. UI/UX 및 세이브·로드 아키텍처

## 1. 화면 레이아웃 설계 (4:3 원작 감성 + 현대 탐색 보조)

PC-98(640×480, 256색) 및 Windows 리뉴얼(640×480 High Color)의 전통적 커맨드 선택형 ADV 구성을 계승하되, 탐색 피로도와 실수 부담을 줄이는 **3-패널 구조**로 재설계한다. `[확인]` `[재구성안]`

```text
+--------------------------------------------------+------------------------+
|                                                  | [층별 미니맵 & 동선]   |
|            메인 씬 뷰포트 (방 배경 +             |  6F 시계탑 [잠김]      |
|            NPC 스탠딩 + 클릭 가능 핫스팟)        |  5F ■■■■□ (현재)      |
|                                                  |  4F □□□□□             |

|                                                  |  위기 경보: 0건        |
+--------------------------------------------------+------------------------+

+---------------------------------------------------------------------------+
```

## 2. 조작 UX 핵심 규칙

1. **이중 입력 지원 (커맨드 메뉴 + 직접 핫스팟 클릭)**:
   - 키보드/패드 사용자는 `[이동] / [조사] / [대화] / [아이템]` 커맨드 메뉴로 원작처럼 정확히 조작한다.
   - 마우스/터치 사용자는 씬 뷰포트의 핫스팟(`rooms.json`의 `hotspots[]`)을 직접 클릭해 컨텍스트 액션(조사 / 아이템 사용)을 즉시 실행한다. `[재구성안]`
2. **인벤토리 사용 및 조합 UX**:
   - 아이템 선택 시 `자세히 보기(Inspect)`(메모·난수표 등 단서 재열람)와 `현장 사용(Use on Hotspot)`을 분리한다.
   - 다중 재료 퍼즐(예: 2F 난로의 `갈색 표지 책` + `알코올 병` + `라이터`)은 난로 핫스팟 내부에 3슬롯 투입 상태를 시각적으로 표시하여 순서를 헷갈리지 않게 한다.
3. **긴장감을 해치지 않는 위기 피드백(Diegetic Alert)**:
   - 원작의 초견살(예고 없는 동료 실종)을 완화하기 위해, 누군가 `at_risk`에 진입하면 동료 상태 HUD에 "소재 불명 / 긴급 확인 필요 (추정 층)" 경고를 띄워 플레이어가 탐색 우선순위를 전략적으로 재배치할 수 있게 한다. `[재구성안]`

## 3. 세이브 / 로드 아키텍처 (분기 복구 중심 설계)

원작 공략의 제1 철칙은 **"층 이동·중요 선택 직전마다 세이브 슬롯을 분리 보관하는 것"**이다. `[확인]` 엔진은 이를 시스템 수준에서 지원한다. `[재구성안]`

- **다중 수동 슬롯(최소 20슬롯) + 자동 체크포인트(Auto-Save 5링 버퍼)**:
  - 층 해정(`flg_4f_unlocked`~`flg_1f_unlocked`), 사건 윈도우 발동 직전, 시계탑 진입 직전 시점에 자동 스냅샷을 남긴다.
- **결정론적 스냅샷 포맷 (`SaveSnapshotV1`)**:
  - `schemaVersion`, `savedAtIso`, `slotLabel`, `currentRoomId`, `currentPhase`, `clockTicks`, `compromisedCount` (슬롯 미리보기 메타데이터)
  - `state: GameState` (전체 직렬화 상태)
  - `actionLogHash` (재현성 및 무결성 검증용 해시)
- **엔딩/사건 아카이브(Global Meta Store)**:
  - 개별 세이브 파일과 분리된 영구 메타 저장소에 해금된 엔딩 목록(`5/5`), 확인한 단서 문서, 플레이 통계를 기록하여 회차 플레이 및 전 엔딩 수집을 지원한다.
