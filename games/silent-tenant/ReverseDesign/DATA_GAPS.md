# 데이터 공백 및 검증 필요 목록 (DATA GAPS)

Phase 1 기본 복원에 이어 Phase 2 심층 공략 교차 검증(`SRC-04`, `SRC-05`, `SRC-08`)을 통해 `GAP-02`·`GAP-03`·`GAP-04`·`GAP-05`의 4개 핵심 공백을 플레이 가능한 정합 데이터로 해소하였다. 원작 바이너리 직접 역공학이 필요한 2개 항목(`GAP-01`, `GAP-06`)만 잔여 참고 항목으로 유지한다.
