# Orbital Workshop v11 — Mission Engineering

브라우저에서 `play.html`을 직접 열어 실행합니다. 별도 설치가 필요 없습니다.

## v11 추가 기능
- 프리셋 7종 및 사용자 설계 저장 유지
- 단계별 부품 수, 질량, 추력, 추진제 분석
- 발사 초기 추중비(TWR) 진단
- 미션 체크리스트 실시간 갱신
- 우주선 설계 JSON 내보내기/가져오기/파일 저장
- 가져오기 시 포맷, 부품 종류, 단계 번호, 개수 검증

## 제한
기존 v10의 2D 물리 및 Mun SOI 근사 모델을 유지합니다. 단계별 수치는 설계 분석용이며 연료 연결이나 분리 후 실제 Δv를 정밀 계산하지 않습니다. 원작 자산은 사용하지 않습니다.
