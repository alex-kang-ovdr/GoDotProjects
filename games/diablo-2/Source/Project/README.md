# Dark Descent XXVIII — Offline Edition 28.1

JavaScript + Native WebGL / Canvas 2D로 실행하는 오프라인 싱글플레이 ARPG입니다. **HTML 파일 하나를 브라우저로 열어 플레이**합니다. XXVIII의 실제 전투·성장·지역 진행에 시작 화면, 저장 복구 안내, 한국어 키보드 입력과 그래픽 복구 처리를 보강한 28.1 실행판입니다. 저장 데이터 형식은 **v28**을 유지합니다.

## 다운로드 후 바로 실행

### HTML 파일 하나로 플레이

1. **`dark_descent_offline.html`을 다운로드**합니다.
2. 내려받은 파일을 Chrome 또는 Edge로 엽니다. 파일의 기본 연결 앱이 다른 프로그램이면 브라우저 창으로 파일을 끌어 놓거나, 브라우저의 파일 열기 기능을 사용하세요.
3. 시작 화면에서 정상 저장 기록을 **이어하기**하거나, **7직업 중 하나와 Seed를 선택해 새 탐험**을 시작합니다. Seed를 비우면 새 맵을 생성합니다. 기존 JSON 기록은 **JSON 파일 가져오기** 또는 **JSON 붙여넣기**로 불러오며, 검증 후 **P**를 눌러 재개합니다.

다운로드한 HTML에는 게임 코드·데이터·화면 스타일이 포함되어 있습니다. 플레이에 인터넷 연결, npm, Python, 외부 CDN, 별도 서버, 로그인은 필요하지 않습니다.

### 소스 패키지로 플레이

**`dark_descent_offline_web.zip`의 압축을 모두 푼 뒤 `dark_descent_offline/index.html`을 여세요.** 다음 파일은 같은 HTML을 운영체제의 기본 연결 앱으로 여는 보조 실행기입니다.

| 운영체제 | 실행 파일 | 직접 여는 방법 |
|---|---|---|
| Windows | `START_GAME.cmd` | `index.html`을 브라우저로 열기 |
| macOS | `START_GAME.command` | `index.html`을 브라우저로 열기 |
| Linux 데스크톱 | `START_GAME.sh` | `index.html`을 브라우저로 열기 |

보조 실행기는 서버를 시작하거나 프로그램을 설치하지 않습니다. 명령 파일 실행이 제한되거나 연결 앱이 지정되지 않은 환경에서는 `index.html`을 직접 여세요. macOS/Linux에서 실행 권한이 보존되지 않더라도 HTML 직접 실행에는 영향이 없습니다.

파일 링크는 다운로드용이며 공개 호스팅 주소가 아닙니다. 채팅의 HTML 미리보기에서 스크립트가 실행되지 않으면 내려받은 파일을 브라우저로 여세요. 각 운영체제의 기본 앱 연결·더블클릭 동작을 모두 실기기에서 검증한 것은 아닙니다.

## 28.1에서 보강한 실행 흐름

- 시작 화면에서 이어하기·직업·Seed·JSON 가져오기를 선택합니다. 시작 전 대기 화면의 상태는 기존 저장 슬롯에 자동 기록하지 않습니다.
- 정상 로컬 기록을 갱신하기 전에 이전 기록을 백업하며, 손상된 주 저장 기록은 자동 덮어쓰기에서 보호합니다.
- 저장 허용 여부와 마지막 저장 결과를 화면에 표시합니다. 로컬 저장이 차단되어도 현재 세션의 게임과 JSON 백업 기능을 사용할 수 있습니다.
- 화면 상단의 **JSON 백업 / 가져오기 / 시작 메뉴**에서 기록을 관리합니다. 백업 시 JSON 텍스트도 표시하며, **전체 선택 → Ctrl+C 또는 ⌘C**로 직접 복사할 수 있습니다.
- 탭 숨김·페이지 종료 시 저장을 시도합니다. 브라우저 강제 종료까지 저장을 보장하는 기능은 아니므로 중요한 진행은 JSON으로 백업하세요.
- 한국어 입력 상태에서도 WASD 등 물리 키 위치로 게임을 조작합니다. 입력칸을 작성하는 동안에는 게임 단축키가 동작하지 않습니다.
- WebGL 컨텍스트가 중단되면 2D 화면으로 전환해 진행을 이어갈 수 있습니다.

실행·저장 흐름의 자세한 계약은 `docs/08_Offline_Runtime.md`에 있습니다.

강타/출혈 규칙과 일부 스킬 예외는 공식 공개 가이드를 참고했습니다. 몬스터 저항·원소 공격 패턴, 출혈 갱신·표시 틱은 웹 구현 규칙입니다. 전체 원본 전투 엔진 복원으로 표현하지 않습니다.

## 먼저 해볼 플레이

1. 시작 화면의 **새 탐험**에서 직업과 Seed를 고릅니다. 출입구 근처에서 H/F로 필드에 진입합니다.
2. **다음 목표 경로**로 악의 소굴을 찾아 기본 공격과 배정 스킬로 사냥합니다.
3. 드롭한 룬을 모아 마을 **룬 제작**을 엽니다. 일반 장비·정확한 소켓 수·룬 순서·타입이 맞아야 합니다.
4. `Tir → El`을 2소켓 검/도끼/메이스에 넣으면 Steel, `Amn → Tir`을 2소켓 근접 무기에 넣으면 Strength입니다. 룬은 가방의 실제 아이템을 소비합니다.
5. 필드에서 적을 공격하면 화면 아래 **전투 정보**에서 출혈과 장비 효과를 볼 수 있습니다. **전투 효과** 버튼은 적용되는 공격과 예외를 설명합니다.
6. 보스의 원소와 범위 공격 예고를 보고 저항 장비를 바꾸거나 범위를 벗어납니다.

진행 보상·지역 관문·실제 룬 획득 조건을 우회하는 무료 장비 지급 기능은 추가하지 않았습니다.

## 유지된 콘텐츠

- 5액트, 131개 지역 노드, 39개 순간이동진.
- 7직업, 21개 트리, 210개 스킬 노드 중 **71개 실행**. 나머지 139개는 참조 전용입니다.
- 58개 장비 베이스, 36개 접사, 일반/마법/희귀 생성.
- 33개 룬 데이터, 78개 룬워드 레시피 중 8종 총옵션 연결. 일부 부가 효과는 여전히 미지원으로 표시합니다.
- 40칸 가방, 80칸 개인 창고, 능력치 배분, 악의 소굴 1회 초기화, 귀환과 복귀.
- 각 지역 **85×50 = 4,250타일**. 예전 25×17 대비 면적 10배, 통로 폭 4타일, 광장 템플릿의 가로·세로 각각 4배를 유지합니다.

## 저장 호환

v28 로컬 슬롯을 사용하며 **XXVIII와 28.1의 저장 형식은 동일**합니다. v28 기록과 **v26/v27 JSON 가져오기**를 지원합니다. 이전 데이터의 소켓 계산을 먼저 확인한 다음 새 전투 효과를 계산하므로 보유 Steel/Strength도 새 효과를 얻습니다. 기존 아이템 ID·맵·방문 상태·퀘스트·RNG를 유지합니다.

저장 중인 출혈은 남은 시간과 미처리 피해를 보존합니다. 다른 지역에 있는 적의 지속 피해 시간은 해당 지역을 다시 방문할 때까지 멈춥니다. 잘못된 버프/재사용 시간/중독/출혈 값은 현재 게임을 바꾸기 전에 거부합니다. 사망하거나 만료된 소환수는 내보낼 복사본에서 정리합니다.

브라우저 저장 제한에 대비해 화면 상단 **JSON 백업** 또는 **기록 / 도구 → JSON 내보내기**를 사용하세요. 다운로드를 요청해도 브라우저가 파일 생성을 막을 수 있으므로 실제 저장된 파일을 확인하세요. 표시된 JSON을 **전체 선택**해 직접 복사하는 방법도 있습니다.

손상된 주 저장이 있어도 새 탐험은 가능합니다. 이때 자동 저장은 차단되며, 상단 **원문 보관 후 저장**을 선택하면 손상 원문을 별도 로컬 슬롯에 보관한 뒤 현재 탐험 저장을 시도합니다. 정상 백업이 있다면 **시작 메뉴 → 이전 저장 복구**로 되돌릴 수 있습니다. 별도 로컬 슬롯도 같은 브라우저의 저장 공간이므로, 보존할 원문은 시작 메뉴의 **기존 저장 원문 백업**으로 파일을 따로 받아 두세요.

파일 위치나 브라우저를 바꾸기 전에는 JSON을 따로 내보내는 것이 확실한 이동 방법입니다. 저장이 차단되면 현재 세션에서 플레이를 계속할 수 있지만 다음 실행의 자동 이어하기를 보장하지 않습니다. v25 이하 직접 이관과 온라인 계정 저장은 지원하지 않습니다.

## 검증 범위

검사 환경과 실제 결과는 `QA_REPORT.md` 및 `tests/`의 결과 파일을 확인하세요. 이전 XXVIII 검사는 생성된 HTML 안의 게임 스크립트를 Node VM에서 실행했으며 DOM/Canvas는 대역을 사용했습니다. 엔진 검사 통과를 운영체제별 더블클릭 실행, 실제 브라우저 입력·WebGL 픽셀·오디오·장시간 캠페인 완주의 성공으로 해석하지 않습니다.

## 편집 및 문서

`src/`는 런타임과 UI, `data/`는 공개 참조 및 게임 데이터, `docs/`는 시스템별 MD, `tests/`는 재현용 검사입니다. Python 3으로 `python build.py`를 실행하면 외부 의존성이 없는 단일 `index.html`을 만듭니다. 플레이에는 Python이 필요하지 않습니다.

- `docs/01_Coverage.md`: 복원·실행·미지원 범위
- `docs/02_Item_Pipeline.md`: 생성·접사·소켓·룬워드
- `docs/03_World_Progression.md`: 액트·지역·퀘스트·경로
- `docs/04_Skills_Stats_Save.md`: 스킬·스탯 계약

- `docs/08_Offline_Runtime.md`: 단일 HTML 실행·시작 화면·로컬 저장 보호·JSON 백업·입력/그래픽 복구

원본 게임의 아트·음원·소스 코드는 동봉하지 않았습니다. 원본 DS1/DT1 맵, 전체 TC/ItemRatio, 모든 210개 스킬, 전체 룬워드 효과, 악몽/지옥, 온라인 멀티플레이는 구현 완료 범위가 아닙니다.
