# 아이템 생성·룬 조합 런타임

## 생성 순서

1. 자체 TC형 가중치에서 NoDrop/소모품/룬/장비를 선택한다. MF는 장비 품질 판정에만 투입한다.
2. 장비 아이템 레벨을 기준으로 선택 베이스 후보를 만든다. ilvl/qlvl/alvl을 인스턴스에 기록한다.
3. 일반·마법·희귀 품질을 웹용 확률로 선택한다. 세트/유니크/크래프트는 생성하지 않는다.
4. 타입/레벨에 맞는 접사만 뽑는다. 마법은 접두1·접미1 한도, 희귀는 총2–6개/각3개 한도, 같은 측의 동일 그룹 배제. 작은 후보풀로2개를 못 뽑는 희귀는 마법/일반으로 낮춘다.
5. 선택 무형 보정·기본 피해/방어·요구 능력치·개별 스킬·소켓을 산출한다. 실제 원작의 전체 접사/스태프모드 생성 확률 복원은 아니다.
6. 장착 시 레벨/힘/민첩/직업/양손/보조손 규칙을 검사한다. 장비가 자기 자신의 능력치 보너스로 요구 조건을 최초 만족시키는 것을 금지하는 반복 활성화 검사를 사용한다.

## 실제 소켓 삽입

`socketPreview(itemId, runeId)`는 인스턴스를 복제하고 결과만 계산한다. RNG와 다음 ID를 바꾸지 않고 룬도 소모하지 않는다. `insertRune`은 마을/활성 상태와 보유 룬을 다시 확인한 후 룬1개를 제거하고 결과를 원본 인스턴스에 반영한다.

최초 삽입에 `socketOrigin`을 남긴다. 기본 능력치, 원래 접사, 스태프모드, 요구 레벨과 능력치를 저장하며, 이후 항상 이 원본에서 순서대로 재계산한다. 이미 계산된 옵션에 다시 보너스를 더하는 방식은 사용하지 않는다.

공식 가이드의 **완성 룬워드 수치에는 개별 룬 효과가 포함**되어 있다. 지원 레시피 완성 시 이 총옵션으로 교체하며 개별 룬 효과를 재차 더하지 않는다. 예: Stealth 독저항30/마나재생15, Ancient's Pledge 화염48/냉기43, Leaf 화염5–30을 중복 계산하지 않는다.

## 판정 조건

`rarity=normal`인 비마법 베이스, 레시피와 정확히 같은 전체 소켓 수, 허용되는 장비 타입, 같은 룬 ID와 순서가 모두 필요하다. 장비 등급의 normal/exceptional/elite와 마법 품질의 normal은 서로 다른 개념이다. 이 빌드의 베이스 데이터는 선택된 일부 장비만 포함한다.

룬 순서를 틀리면 개별 룬 효과는 남지만 룬워드는 아니다. 빈 소켓이 남아 있으면 완성되지 않는다. staff와wand/orb, body_armor와helm, mace와hammer 등 레시피 타입을 구분한다. 현재 베이스에서 표현되는 타입 범위 안에서 검사한다.

## 8종의 효과 범위

| 레시피 | 연결한 주요 효과 | 보존만 하고 실행하지 않는 효과 |
|---|---|---|
| Ancient's Pledge | 방어 증가,4속성 저항,피해-마나 | 현재 매핑한 공개 속성 기준 없음 |
| Leaf | 화염 추가 피해,화염/특정 스킬,처치 마나,레벨 방어,냉저 | 해당 스킬이 미지원이면 보너스 데이터만 유지 |
| Lore | 전체 스킬,마력,처치 마나,번개저항,물리감소 | 시야 반경 |
| Rhyme | 막기 수치,저항,마나재생,웹 느려짐 방지,골드/MF | 빠른 막기 회복 프레임 |
| Smoke | 방어,저항,마력 | 원거리 방어 별도 판정,FHR,시야,충전 약화 |
| Stealth | MDR,민첩,독저항,마나재생,이속,FCR | 지구력,FHR |
| Steel | 피해/최소·최대 피해,AR,IAS,처치 마나,상처 악화50% | 시야 |
| Strength | 피해,흡혈,처치 마나,힘,활력,강타25% | 현재 매핑한 공개 속성 기준 없음 |

`deferredEffects`를 툴팁/공방에 표시한다. 따라서 ‘8종 룬워드 총옵션 연결’은 **모든 부가 효과 완전 복원**이라는 의미가 아니다. 받는 피해 처리·스킬 프레임·독 합산 등은 웹용 계산 어댑터이며 원본 엔진의 정확한 연산 순서 보증이 아니다.

33룬 모두 데이터와 삽입 매핑을 갖지만 고레벨 룬까지 모두 일반 파밍으로 나오지는 않는다. 일반 선택 가중치는 레벨에 따라 상한을 두며, 백작은 별도 저급 룬1–3개 보너스 추첨을 한다. 원본 백작 TC/확률을 복원했다는 뜻은 아니다. 고정 소켓 상점은 골드로 베이스만 팔며 룬을 만들어주지 않는다.

## 데이터 수정 시

`runewords.json`, `runes.json`은 공개 정보 레코드다. `RUNTIME_WORDS`, `PROPERTY_MAP`, `propertyEffects`, `recomputeSockets`, 전투 함수에서 지원되는 효과를 추가하고 회귀 테스트를 함께 추가해야 새 기능이 활성화된다. 레시피 목록에 행만 추가해도 원작 효과가 자동 구현되는 것은 아니다.
