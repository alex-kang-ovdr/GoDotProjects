## 원작 규칙에 근거한 부분

직업 시작 능력치/성장, 스킬 투자 제한, 장비 부여 스킬과 선행 투자 구분, 공개 시너지 목록, 선택 장비 기본 수치, 접두·접미 개수/동일 그룹 제한, 룬 레시피 판정 조건과 공개 총옵션을 데이터로 분리했다. 출처 필드 `source_refs`와 `data/sources_v27.json`과 `data/sources_v28.json`을 유지한다.

## 자체 설계·근사 부분

131지역의 절차적 지형, 광장/통로, 몬스터 수치·AI·행동 간격, 게임 프레임 처리, 미확보 스킬 수치, 드롭 TC 가중치와 품질 확률, 룬 가중치, 상점 재고/가격,40칸 가방/80칸 창고, 회피/질주/귀환 편의는 웹용 어댑터다. 기존 무조건 강화·각인은 원작 규칙과 혼동하지 않도록 비활성 상태로 유지했다.

## 데이터 소유권/출처

공개된 게임 규칙을 독립적으로 모델링한 프로토타입이다. Diablo II 및 해당 명칭은 Blizzard의 작품을 식별하기 위한 참조이며 공식 배포/제휴 제품이 아니다. 게임 이미지·음원·원본 소스는 포함하지 않았다. 원본 문서의 전체 본문 대신 출처 주소와 정규화한 선택 사실을 보존한다.

## XXVIII에서 추가로 연결한 전투 규칙

강타·8초 상처 악화, 실제 물리 피해에 대한 생명/마나 흡수, 원거리 무기·주문·차지드 스트라이크 보조 번개 구분, 멀티샷 중복 명중 방지, 파워 스트라이크 번개 시너지, 독/냉기 면역 처리를 적용했다. 실행 스킬 수는 71개로 동일하며 기존 스킬 동작을 개선한 것이다.

다섯 액트 보스의 원소 공격과 저항 수치는 자체 전투 프로필이다. 공식 원본 몬스터 수치나 독 프레임 복원으로 표현하지 않는다. 이번 검증은 Node VM 로직 검사이며 브라우저 화면·입력은 환경 제약으로 재검증하지 못했다.
