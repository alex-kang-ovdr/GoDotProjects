# 스킬·스탯·저장 계약

## 스킬 포인트

캐릭터마다3탭·30노드를 표시한다. runtime이 없는 노드는 이름/요구 레벨 등의 참조만 있고 투자·단축키 실행을 막는다. 공개 선행 목록이 확보된 지원 노드만 `requires`를 사용한다. 일부 데이터는 직접 간선 대신 공개된 누적 선행 목록이므로 UI 연결선은 원작 화살표 아트를 정확히 복원한 배치가 아니다.

직접 투자 hard rank는 스킬당20, 캐릭터 레벨의 요구조건을 지킨다. 장비의 특정 스킬 부여는 hard=0에서도 해당 스킬을 쓸 수 있게 하지만 선행 투자나 시너지 점수가 아니다. +전체/직업/화염 스킬은 기본 투자 또는 특정 스킬 부여가 존재할 때만 더한다.

공개된33스킬의1–20레벨 표시 표를 사용하며 초과 등급은 표시해도 수치 표는20에 제한한다. 그 외 지원 스킬은 명시적인 웹 근사 동작이다. 원본 서버 프레임, 애니메이션 이벤트, 모든 상태효과를 복원한 것이 아니다.

## 능력치

직업별 초기 힘/민첩/활력/마력, 초기 생명/마나, 레벨당 자원 성장, 포인트당 자원 성장은 클래스 표에서 읽는다. 레벨 상승 시 능력치5/스킬1을 지급한다. `previewAttribute`는 일시적으로 계산한 후 원래 값을 반드시 복원하며 RNG를 사용하지 않는다. 실제 배분은 보유 포인트 범위로 제한한다.

장착은 능력치 요구 조건을 통과해야 한다. 보너스로 요구 조건을 맞추는 관계는 반복 활성 검사로 계산하며 자기 자신의 보너스로 최초 요구 조건을 만족시키지 않는다. 룬 요구 레벨이 올라가거나 초기화로 스탯이 내려가면 장착되어 있더라도 비활성화할 수 있다.

## 악의 소굴 초기화

퀘스트 완료 후 마을에서 보통 난이도1회. 실제 투자한 스킬과 능력치만 반환한다. 장비 보너스·경험치·장비 자체는 보존한다. 활성 오라/버프/소환수/단축키를 초기화해 이전 빌드의 임시 효과가 남지 않도록 한다. 원작의 지옥 정수/면죄의 징표와 다른 난이도 초기화는 미구현이다.

## 저장과 이관

이전 v27 JSON은 v26 상태 모델에 `stash`, `trackedGoal`, 소켓 원본/파생 속성을 추가한다. 지역 Seed 생성 접미사는 v26을 유지하지만 새 야외 생성의 고립 바닥 정리는 적용한다. 이미 방문한 지역의 저장된 맵은 그대로 가져온다.

검증이 성공하기 전 live S를 교체하지 않는다. 버전, 포인트 예산, 스킬 선행/등급, 지역 크기/객체, 중복 아이템 ID, 다음 생성 ID, 룬 ID, 소켓 파생값, 가방/창고 용량을 검사한다. 원본 스냅샷 자체가 임의 수정되지 않았음을 암호학적으로 증명하는 기능은 아니며 안티치트가 아니다.

v26 실제 엔진이 내보낸 원소술사 Lv.12 샘플(투자/희귀 장비/방문 지역 포함)을 이관 테스트했다. 모든 사용자 저장과 역사 버전 호환을 보증하지 않는다. v25 이하 파일을 조용히 새 게임으로 덮어쓰지 않고 거부한다. 다른 기기로 옮길 때 JSON을 보관한다.

## XXVIII 상태 검증

v28은 v26/v27 소켓 기록을 기존 버전 규칙으로 검증한 뒤 강타·상처 악화를 새로 계산한다. 새 저장은 효과 불일치를 그대로 거부한다. 버프·쿨다운·중독·출혈·소환수 값을 추가 검증해 잘못된 값으로 자원이 NaN이 되거나 다음 업데이트가 중단되는 것을 막는다. 자세한 원자적 이관 순서와 소환수 정리는 `07_Save_Migration.md`를 참고한다.
