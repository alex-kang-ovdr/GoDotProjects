# 저장·전투 상태 이관 — v28

## 지원 범위

읽기: v26, v27, v28. 쓰기: v28. 로컬 슬롯: `dark-descent-xxviii`. 이전 브라우저 슬롯을 자동 덮어쓰지 않으며 JSON으로 가져온다. 원작 Diablo II 저장 파일을 읽는 기능은 아니다.

## 원자적 가져오기

1. JSON을 별도의 후보 상태로 파싱한다. 현재 라이브 상태는 아직 바꾸지 않는다.
2. 버전·직업·지역·포인트 예산·아이템 ID·소켓·전투 상태를 검증한다.
3. 소켓 계산은 **그 저장의 버전**으로 다시 계산해 비교한다. v27에서 표시만 되던 강타·상처 악화가 아직 mods에 없어도 정상이다. 기존 저장을 무조건 재계산하여 변조를 덮어주지는 않는다.
4. v26/v27의 이미 검증된 소켓 아이템을 새 효과로 이관한다. 장착·가방·창고·현재 지역 드롭·저장 지역 드롭을 포함한다. 아이템 ID·맵·방문·퀘스트·RNG·다음 ID를 유지한다.
5. 이전 소환수의 음수 대기 재사용 시간은 이미 준비 완료인 0으로 바꾼다. 사망·만료된 소환수는 정리한다.
6. v28 상태를 다시 검증한 뒤 성공한 경우에만 라이브 상태를 교체한다. 거부하면 기존 캐릭터·RNG·진행을 그대로 둔다.

소켓 원본 스냅샷 전체가 외부에서 바뀌지 않았음을 서명으로 증명하는 기능은 아니다. 이 검증을 온라인 안티치트로 사용할 수 없다.

## 지속 피해

출혈 상태: `dps`, `left`, `pending`, `timer`, `sourceLevel`. 중독도 남은 시간·미처리 피해·틱 시간을 유지한다. 저장 시 진행 중 피해를 바로 지급하거나 버리지 않는다. 재개하면 남은 시간만 처리한다.

비활성 지역은 시뮬레이션하지 않는다. 따라서 다른 지역에 머무는 동안 저장된 적의 출혈·중독도 멈춘다. 재입장 시 해당 지역의 상태를 이어간다. 이 정책을 실시간 전체 월드 시뮬레이션으로 표현하지 않는다.

## 정상 저장을 망가뜨리던 경계 조건

- 이전 소환수는 마을 대기 중 재사용 시간이 음수로 계속 내려갔다. v28은 0에서 멈추고 실제 v27 샘플의 음수 값은 이관한다.
- 적 공격으로 소환수가 죽은 직후 플레이어도 죽으면 소환수 정리가 생략될 수 있었다. 자동 저장도 정리 이전에 발생할 수 있다. `exportState`는 복사본에서 죽거나 만료된 소환수만 제거한다. 라이브 상태를 변경하지 않는다.

## 새 검증

버프 목록과 값, 알려진 버프 ID·직업·레벨·남은 시간, 변신 스킬/형태, 스킬 재사용 시간, 플레이어 행동 시간, 소환수, 적 저항, 중독·냉기·출혈 값을 검사한다. 문자열·null·음수 시간·비정상 범위를 거부한다. 현재 지역과 캐시된 모든 지역에 같은 검증을 한다.

검증 전의 NaN/잘못된 타입이 자원 재계산이나 다음 업데이트까지 도달하지 못하게 하는 것이 목적이다. 테스트는 실제 버프/변신 시전과 소환·사망 경로에서 만든 정상 저장도 포함한다.
