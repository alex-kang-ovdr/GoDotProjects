# 전투 실행 계약 — XXVIII

## 공격 패킷과 처리 순서

`src/combat_rules.js`의 `applyPacket`이 플레이어 공격과 명중 후 효과를 처리한다.

1. 사망·봉인·부재 대상, 언데드 전용 조건, 같은 멀티샷 묶음의 이미 명중한 대상을 거른다.
2. 명중률이 필요한 공격만 공격등급·방어·레벨로 판정한다. 빗나가면 아이템 명중 효과도 적용하지 않는다.
3. 무기 직접 명중에만 장비 화염/냉기/번개/독을 더한다. 주문·소환수·보조 번개와 스마이트는 제외한다.
4. 강타를 별도로 처리한다.
5. 일반 피해를 속성별 저항과 물리 치명타로 계산한다.
6. 실제 일반 피해의 물리 비율로 생명·마나 흡수를 동일하게 계산한다.
7. 남아 있는 대상에게 중독·냉각·출혈·밀치기를 적용한다.

`applyPacket` 반환값은 실제 일반 직접 피해량이다. 강타·출혈은 포함하지 않는다. 기존 희생 스킬의 반동과 흡수 계산에 강타를 섞지 않기 위한 계약이다. 최종 사망은 기존 `kill`을 통해 경험치·드롭·퀘스트를 한 번 처리한다.

## 강타·상처 악화

공식 공개 자료: [Arreat Summit — 특수 아이템 효과](https://classic.battle.net/diablo2exp/items/magic.shtml).

| 강타 대상 | 근접 | 원거리 |
|---|---:|---:|
| 일반 적 | 현재 생명 1/4 | 1/8 |
| 정예·보스 | 현재 생명 1/8 | 1/16 |

양수 물리 저항으로 감소시키고, 음수 저항으로 강타를 증폭하지 않는다. 장비 확률은 합산 후 100%로 제한하여 한 명중에 한 번 검사한다. 일반 피해보다 먼저 처리한다. 현재 단일 플레이 기준이며 다인 생명 보정은 미구현이다.

상처 악화는 8초 지속하며 공개된 레벨 구간의 초당 피해식을 사용한다. 이 게임은 정예·보스에 절반 피해를 적용한다. 공식 가이드 자체가 보스/챔피언의 정확한 적용 범위를 확정적으로 기술하지 않아, 현재 `elite`/`boss` 분류 대응은 별도 어댑터 정책이다.

하나의 출혈 기록을 유지한다. 재발동은 남은 시간을 8초로 갱신하며 더 높은 초당 피해만 교체한다. 미처리 피해는 지우지 않는다. 0.25초 또는 종료 시점마다 누적 피해를 지급한다. 이 시간 누산과 표시 주기는 원본 25fps 상태 처리의 복제가 아니다.

## 무기·스킬 예외

- 활/투창의 직접 공격은 무기 명중 효과를 받는다. 기본 투사체에도 원거리 표식을 전달한다.
- 차지드 스트라이크의 보조 번개는 근접 패킷의 무기 효과를 복사하지 않는다.
- 파워 스트라이크의 공개 일반 damage 시너지 키를 번개 피해에 연결하고 물리 피해에서 제거한다.
- 멀티샷은 무기 피해 75%와 발사 묶음당 동일 대상 한 번의 성공 명중을 적용한다. 발사 수·일부 활 스킬 원소 전환 수치는 이전 근사 구현을 유지한다. [공식 활 스킬 설명](https://classic.battle.net/diablo2exp/skills/amazon-bow.shtml)
- 스마이트는 강타·출혈을 적용하고, 장비 원소·독 피해와 일반 흡수·치명타를 제외한다. [공식 성기사 전투 스킬 설명](https://classic.battle.net/diablo2exp/skills/paladin-combat.shtml)

쌍수의 개별 손 옵션 분리, Double Swing의 보조 손별 피해 산출, 투창의 별도 기본 투척 피해표는 이번 변경에 포함하지 않는다.

## 흡수·면역·자원

생명·마나 흡수는 저항 적용 후 실제로 감소한 일반 물리 생명력을 사용한다. 초과 피해를 실제 감소량에 비례해 제한한다. 물리 면역에 원소 피해만 들어간 경우 일반 흡수는 0이다. 개별 몬스터 `drainEffectiveness`는 사용할 수 있지만 원작 전체 몬스터별 효율 표는 없다.

냉기 피해가 저항에 전부 차단되면 냉각하지 않는다. 독 초당 피해가 0이면 중독을 생성하지 않으며, 피해 0을 최소 0.01로 올리던 기존 처리를 제거했다.

최종 최대 마나와 Warmth/장비 재생률을 사용하고, [공식 캐릭터 가이드](https://classic.battle.net/diablo2exp/basics/characters.shtml)의 두 단계 내림을 거친 초당 마나 재생을 계산한다. 60Hz 시뮬레이션에 누적하므로 원본 모든 고정소수점 프레임 결과의 동등성 검증은 아니다.

## 실제 적 공격에 연결한 원소 — 자체 전투 수치

`src/encounters_v28.js`는 기존 공격 간격·피해 예산·페이즈·소환 구조를 유지하며 투사체와 범위 공격에 속성을 붙인다.

| 보스 | 투사체 / 범위 공격 | 신규 적 저항 |
|---|---|---|
| 안다리엘 | 독 / 독 | 독 50 |
| 두리엘 | 냉기 / 냉기 | 냉기 40, 물리 10 |
| 메피스토 | 번개 / 냉기 | 번개 40, 냉기 25 |
| 디아블로 | 번개 / 화염 | 화염 50, 번개 25 |
| 바알 | 냉기 / 화염 | 냉기 40, 화염 25 |

이 표는 원본 MonStats 값이 아니다. 독성 공격도 현재는 저항이 적용되는 즉시 피해이다. 기존에 저장한 적의 저항은 다시 생성하지 않는다. 필드 시전자 원소는 액트별로 고정하며 RNG를 추가로 소비하지 않는다.

정예 중갑/냉기/폭발형에 각각 물리20/냉기40/화염40 저항을 적용한다. 냉기 정예는 실제 타격 후 둔화, 흡혈 정예는 실제 피해에 비례한 회복을 한다. 빗나감·막기·무적에는 발동하지 않는다. 압력판과 폭발형 정예의 지연 폭발은 화염이다.

## 가시성

원소 색과 예고 시간은 실제 위험 영역에 표시한다. 화면 아래 대상 정보는 시야에 보이는 적만 보여주며 현재 생명·실제 저항·상태 남은 시간을 읽는다. 장비 효과는 요구 조건을 충족한 활성 장비만 합산한다. UI 읽기는 RNG나 전투 상태를 바꾸지 않는다. 이번 환경에서 화면 픽셀은 재검증하지 못했다.
