# 실제 브라우저 인수 체크리스트 — 미실행

아래 체크박스는 실기기 확인 목표이며 통과 기록이 아니다. Node 대역의 로직 검사로 체크하지 않는다.

## 오프라인 시작과 저장

- [ ] 인터넷을 끈 상태에서 Chrome/Edge로 `index.html` 또는 단일 HTML을 직접 연다.
- [ ] 시작 메뉴에서 7직업·Seed를 선택해 새 탐험을 시작한다.
- [ ] 저장 후 페이지를 다시 열면 기존 캐릭터 정보와 이어하기가 표시된다.
- [ ] 시작 메뉴에서 45초 이상 기다려도 저장이 새 캐릭터로 바뀌지 않는다.
- [ ] 정상 저장·직전 저장 복구·손상 원문 보관의 실제 브라우저 저장 유지가 맞다.
- [ ] 저장소 차단/용량 초과 상태에서 JSON 안내가 보이고 플레이를 계속할 수 있다.
- [ ] JSON 백업의 실제 다운로드 파일을 확인하고, 그 파일을 다시 가져온다.
- [ ] JSON 전체 선택·수동 복사·붙여넣기를 실제 키보드와 OS 파일에서 확인한다.
- [ ] 네이티브 파일 선택을 취소한 경우와 비동기 읽기 중 입력 처리를 확인한다.
- [ ] Windows/macOS/Linux 보조 실행기를 각각 실제 데스크톱에서 실행한다.

## 게임플레이와 화면

- [ ] 3D 화면·2D 전환·카메라 확대·컨텍스트 중단 후 2D 표시가 정상이다.
- [ ] WASD/클릭/터치 이동과 한글 IME 상태의 물리 키 조작이 동작한다.
- [ ] 시작/JSON/스킬 대화상자 포커스, Tab·Escape·버튼·화면 복귀가 자연스럽다.
- [ ] 화면 아래 전투 정보가 게임 화면과 모바일 메뉴를 가리지 않는다.
- [ ] 기본 공격·스킬·물약·줍기·H 지역 이동·Z 귀환을 실제 입력으로 확인한다.
- [ ] Steel/Strength 발동, 멀티샷/차지드 스트라이크, 보스 범위 경고를 화면에서 확인한다.
- [ ] v26/v27 JSON 이관 뒤 지역·장비·스킬·성장 표시가 정상이다.
- [ ] 390px 모바일 화면과 1440px 데스크톱 화면의 넘침과 터치 목표를 확인한다.
- [ ] 오디오·실제 GPU 성능·장시간 정상 피해 캠페인·군집전 밸런스를 확인한다.

실제 파일 열기·다운로드·영속 저장·프레임 성능 검증은 Node 로직 결과와 별도로 기록한다.
