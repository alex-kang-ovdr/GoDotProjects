# 변경 기록

## 4.0.0 — 조립·점검·재설계의 완성

- 유한한 힘으로 실제 탑재물을 올리는 수직 피스톤, 가이드·끝단·전원 단절과 과적 정지.
- 승강 시험대 프리셋과 4관문의 굴곡 주행 작전. 10종 부품, 6프리셋, 6캠페인.
- Shift/터치 다중 선택, 묶음 이동·복사·회전·반사·삭제와 전체 원자성.
- 이름 있는 설계 8칸, 명시 덮어쓰기·이름 변경·삭제, 이전 빠른 저장 1회 이관.
- 시험 중 부품 클릭으로 일시정지 점검, 한 스텝, 모바일 점검 도구.
- 순간 하중비와 누적 연결 손상 표시 분리.
- 최초 파손·피해 누계·원인·관련 부품·12Hz 관측 표본을 갖춘 시험 보고서와 JSON 내보내기.
- 원본 설계와 다르면 과거 손상 위치를 새 설계에 표시하지 않는 서명 검사.
- 설계 불러오기를 실행 취소할 때 작전까지 함께 복원.
- 기존 물리·설계·진행 기록 호환, 시스템 문서와 단일 HTML·전체 소스 갱신.
- 정량 검증과 GPU 화면 검증 한계는 `VALIDATION.md`에 기록.

## 3.0.0 — 육해공 기계 제작

### 새 부품과 실제 물리

- 부유체, 추진 프로펠러, 양력 날개로 카탈로그를 9종으로 확장.
- 침수량에 따른 부력·항력, 실제 부품 위치에 따른 선체 균형.
- 프로펠러 방향과 출력에 따른 추력, 연결 단절 시 엔진 제어 중단.
- 날개 속도·받음각에 따른 양력·항력과 실제 활주·이륙.
- 기수·기울기·방향 입력, 선택 가능한 힘·토크 기반 자세 보조.
- 쌍동 항해선과 개척 비행기 프리셋 추가.

### 항해·비행 작전

- 해협 항로·하늘 회랑 추가. 공성 3개와 함께 캠페인 5개.
- 실제 코어 경로를 이용하는 순차 관문 통과와 완료 판정.
- 수면·해저·수상 관문·공중 고리, 다음 관문 거리·고도·속도 계기.
- 침수 실패와 임무별 권고, 환경에 맞는 추천 설계 불러오기.
- 기존 캠페인 기록을 유지하면서 새 작전 기록 추가.

### 조작과 호환

- 기존 지상 방향키 조작 유지, 비행 시 추진과 자세 입력 분리.
- 모바일 가로 스크롤 팔레트와 비행/포격 터치 조작 전환.
- 새 날개 기본 설치각 6도, 명시한 0도 설정과 기존 설계 보존.
- 기존 자동 저장·JSON·대칭·이동·복사·실행 취소 흐름 유지.
- 단일 HTML·전체 소스 ZIP과 시스템별 문서 갱신.
- 검증 결과와 브라우저 환경 제약은 `VALIDATION.md`에 별도 기록.

## 2.0.0 — 제작부터 작전 결과까지

### 전투와 캠페인

- 3단계 캠페인과 자유 제작, 작전별 자재·탄약·시간 제한.
- 실제 포탄으로 반격하는 적 방어 포탑과 이동으로 피할 수 있는 공격 예고.
- 코어·부품 HP, 연결 파손 후 제어 중단, 잔해 시뮬레이션.
- 포 고각, 예상 탄도·착탄점, 재장전·탄약 표시, 브레이크.
- 코어 손실·시간 초과·경계 이탈에 따른 실패와 단일 종료 판정.
- 별 평가, 최고 기록, 같은 설계 재도전, 설계 수정, 다음 작전.

### 조립과 피드백

- 부품 이동·설정 포함 복사·좌우 대칭과 취소 시 원본 보존.
- 대칭의 양쪽 배치 검증, 중앙선 중복 방지, 실행 취소 연계.
- 코어 연결 진단, 무게중심, 자재 예산과 출격 가능 상태.
- 부품별 손상 재질, 목표 HP, 실제 연결 응력, 끊어진 부품 표시.
- 터치 고각·제동·일시정지와 HD/LOW 품질 설정.

### 안정성과 배포

- 기존 형식 1 설계 JSON·브라우저 저장 호환.
- 잘못된 JSON 검증이 현재 설계·시험을 변경하지 않도록 처리.
- 메뉴를 열고 취소하면 현재 실행을 이어가도록 처리.
- 결과 중복 기록, 이전 세션의 지연 결과 창, 편집 슬라이더 이력 문제 보강.
- 인터넷·HTTP 서버 없이 여는 단일 HTML 및 재생성 스크립트.
- 물리·편집·캠페인·데이터 테스트 40개 통과. 자세한 범위는 `VALIDATION.md`.
