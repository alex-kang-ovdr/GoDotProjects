# 90. 부품군별 동작 규칙 색인

> 조사일 2026-11-13 · Steam PC. 본 표는 **상세 분석 문서를 찾기 위한 부품군 색인**이다. 크기·재질 변형을 묶었으므로 게임의 전체 블록 수와 행 수는 일치하지 않는다. 전체 콘텐츠의 내부 ID 목록도 아니다.
> ‘역할’은 기능의 분석적 요약이고, 정확한 설정 범위·기본키·힘·파단값은 연결된 문서에서 확인/미확정 여부를 구분한다. 표의 예상 실패를 실제 측정 결과로 읽지 않는다.

## 1. 규칙 카드를 읽는 순서

각 부품은 다음 여덟 질문으로 읽는다.

1. **에너지·원인:** 자체 구동인가, 외력·상대 운동에 반응하는가?
2. **입력:** 눌림 유지·순간 입력·센서·초기 설정 중 무엇을 받는가?
3. **부착:** 고정측·가동측·끝점·연료 연결 중 무엇을 제공하는가?
4. **자유도:** 병진·회전 중 무엇을 허용하거나 막는가?
5. **출력:** 힘·토크·부력·탄체·열·신호 중 무엇을 만드는가?
6. **부담:** 반력·질량·소모·연결 하중이 어디로 돌아오는가?
7. **종료:** 입력 해제·소모·파손·분리 후 어떻게 되는가?
8. **환경:** 공기·물·진공·중력·다른 부품이 결과를 어떻게 바꾸는가?

## 10. 공통 검토 체크

블록을 ‘좋다/약하다’로 평가하기 전에 배치·연결·입력·환경을 동일하게 맞춘다. 공식을 모르는 매개변수는 UI 단위로 기록한다. 부품 본체가 부서졌는지, 연결이 떨어졌는지, 입력만 끊겼는지 분리한다. 구형 저장본·모드·DLC를 표시한 뒤에 성능을 비교한다.
