# Fortress BLUE 플레이 변경 이력

## 1.2.0 · 2026-11-18 — 판본별 발사각과 파워 입력 정리

- CLASSIC 13종의 일본 2003 문헌 각도를 원문 표와 다시 대조했다. 기본 카탈로그는 유지하고, 한국 커뮤니티의 빌드 미확정 각도를 별도 선택 프로필로 추가했다. 캐논·캐롯·미사일·멀티미사일·레이저 5종이 다르다.
- 한국 캐논의 원문 각폭 25와 최소·최대 25–45의 모순을 보존했다. 실행 제한은 최소·최대를 적용하고 산술 각폭은 20으로 표시한다.
- `FortData.aiming`에 판본별 각도 경계, 출처 상태, 공통 파워 입력 정의를 추가했다. 원본 1,208행과 기존 61개 출처 스냅샷을 수정하지 않았다.
- 각도 30행(JP 13·KR 13·3BLUE 4), 파워 17행을 담은 JSON과 복원 보고서를 추가했다. 원작 파워 곡선·충전 시간·중력·풍력·탄중량의 미확인 필드는 `null`이다. 3BLUE의 원작 각도도 `null`이며 실행 가정은 별도 필드다.
- 슬라이더의 10% 하한, AI의 5% 하한을 제거하고 충전·AI·가이드·실제 발사가 같은 0–100 정규화 범위를 사용하도록 연결했다. 0–100, 72%p/초 왕복 충전, 탄속 90–1050 선형 변환은 모두 프로토타입 값이다.
- 원작 자료의 POWER 1·2(무기 공격력)와 발사 게이지·탄속을 다른 항목으로 명시했다. 탱크별 원작 탄속 계수를 새로 추정해 넣지 않았다.
- 차체 경사로 포신이 수직을 넘어갈 때 클릭 조준의 좌우 방향이 바뀌던 오류를 수정했다. 포인터 좌표를 차체 기준으로 역회전하고 실제 발사와 같은 각도 경계를 적용한다.
- 조준 패널에 차체 기준 범위, 발사 방향별 지형 보정, 실제 고각을 표시한다. 파워 패널에는 목표와 캐릭터별 직전 실제 발사 표식을 추가했다.
- 출격 준비·설정에 각도 자료 선택을, 데이터 근거에 13종 비교표와 JSON 다운로드를 추가했다. 변경한 자료는 다음 새 전투에 적용된다.
- 미복구 `null`이 숫자 0으로 변환되지 않도록 엔진의 수치 해석을 수정했다. 미래의 측정값을 연결할 수 있도록 탱크·무기별 `aimingRuntime` 재정의 지점을 마련했으나 현재 제공하는 원작 계수는 없다.

검증 결과와 실제 브라우저 확인 범위는 [검증 기록](VALIDATION_KO.md)에 정리했다. 원작과의 물리적 일치 검증은 아니다.

## 1.1.0 · 2026-11-18 — 고유 스킬과 전투 흐름 보강

### 데이터

- 42개 무기에 `role`, `delivery`, `behavior`, `behaviorStatus`를 추가했다. 공격·지원 역할, 탄 발사·자기 적용, 곡선·직선 궤도, 반복 가능 여부가 각각 명시된다.
- 원문 공격 입력의 상태를 나타내는 `attackStatus`와 실행 계수의 상태인 `behaviorStatus`를 분리했다. 새 행동 계수는 모두 `simulation_assumption`이다.
- 세크윈드의 저HP 공격 보정, 레이저탱크·포세이돈의 지뢰 접근 기폭 제외를 `passives`에 명시했다. 기존 엔진에서 사용하던 모델을 데이터로 옮긴 것이다.
- 무기 `description`을 실제 플레이 설명으로 다듬었다. 공식 패치의 날짜·성급·레벨·공격 입력과 모델의 한계는 `sourceSnapshot`, `sourceRefs`, `attackStatus`, `assumptions`에 유지했다.

### 고유 행동

| 스킬 | 동작 | 구현 계수 |
|---|---|---|
| 이블벨라 · 흡혈박쥐떼 | 적의 실제 HP 감소량을 기준으로 자신을 회복 | 25%, 최대 HP 제한. 방어막 흡수·아군 피해·지속 피해 제외 |
| 야구소년 · 퉁퉁안타 | 지형 반사와 명중 시 밀쳐내기 | 반사 1회, 반사 속도 계수 0.72 |
| 야구소년 · 통통유도볼 | 적 추적과 지형 반사 | 반사 2회, 반사 속도 계수 0.72 |
| 메카펀치 · 펄스레이저 | 중력·바람 없는 직선 비행 | 스킬별 조준 −35~75도 |
| 이블벨라 · 유틸해제 | 반복하지 않는 지원탄 | `role=support`, `delivery=projectile`, `repeatable=false` |

위 계수는 원작의 확정 밸런스나 물리식이 아니다. 공개 공격값을 실행에 연결하기 위해 정한 동작이며 상세 구분은 [데이터 출처 문서](DATA_PROVENANCE_KO.md)에 있다.

### 아이템과 종료 판정

- 더블 준비 효과가 지원기·이동탄·턴 넘기기·시간초과 후에도 유지되고 다음 반복 가능한 공격에 사용된다. 재고와 딜레이 비용은 도구를 준비할 때 적용한다.
- BLUE3 서든데스 중 새 더블 사용을 막고, 이미 준비된 더블과 서든 반복은 최대 3회로 처리한다.
- 유틸해제를 지원탄으로 분류해 더블·서든 반복에서 제외한다. 적의 버프만 제거하며 일반 피해에는 아군도 포함될 수 있다.
- 양 팀 전멸 또는 라운드 제한의 같은 점수는 `winner=-1` 무승부로 처리한다.
- AI의 무기별 평가와 지원 스킬 선택을 확장했다. 이번 범위에는 안전 이동·이동탄 위치 계획을 포함하지 않는다.

### 조작과 피드백

- 선택한 무기의 플레이 설명, 지원 방식, 실제 발사체 수와 반복 수를 표시한다. 스킬별 사격각을 엔진의 현재 행동 안내와 맞춘다.
- 공격·지원 시작/종료를 `actionStart`·`actionEnd`로 구분하고 행동 단위의 피해·회복·발사 수를 요약한다.
- 직전 조준 복원, Q/E 무기 순환, 상대 선봉 선택과 조준 시간 선택을 추가했다.
- 같은 기기 대전의 결과 수치는 승리 팀을 기준으로 표시하고 무승부에는 팀 이름이 붙은 BLUE 수치를 표시한다.
- 각도·파워 슬라이더의 기본 키보드 조작을 복구하고 발사 버튼의 짧은 클릭, 길게 누르기, 키보드·보조기술 입력 경로를 정리했다.
- 현재 아이템 사용 여부와 체력 조건을 반영하여 사용할 수 없는 아이템 버튼을 비활성화한다.
- 같은 목표에 연속으로 들어간 피해를 합산하고, 발사자별 직전 착탄 위치를 표시한다. 착탄 뒤 카메라를 잠시 유지하고 HP·피해 표시가 결과 요약을 가리지 않도록 배치한다.

### 탄도와 전투 판정

- 조준 가이드와 실제 탄환이 동일한 1/120초 계산 간격을 사용한다. 렌더러의 중복 궤적 캐시를 제거하여 이동탄 전환도 현재 행동에 맞게 갱신한다.
- 포구까지의 구간을 검사하여 바로 앞의 얇은 벽을 통과해 발사되던 경우를 수정했다.
- 이동탄은 선택 무기의 직선·반사·흡혈 효과와 분리된 곡선 탄도로 처리한다.
- 지형이 무너진 뒤 지뢰와 화염 지대를 다시 지면에 정착시키며, 아래에 지면이 없으면 제거한다.
- 라운드 제한 판정은 캐릭터별 잔여 HP 비율의 팀 합계를 비교한다. 별도 생존자 보너스를 더하지 않으며 같은 비율이면 무승부로 처리한다.

이번 UI 변경은 코드 연결을 정적으로 대조했다. 브라우저 연결 제한으로 실제 화면·터치·반응형 렌더링의 재검증은 수행하지 못했다.

### 보존한 값

캐릭터 17종의 HP·기본 딜레이·이동·카탈로그 사격각과 무기 42개의 공격 입력·기본 탄수·추가 딜레이·해금 라운드는 유지했다. 공식 조건이 확인된 공격 입력 580·73·304도 그대로다. 스킬별 사격각은 별도 `behavior` 값으로 저장한다.

`provenance.sourceSnapshots`의 원문 61개는 내용과 `null`을 유지하고 재귀적 동결을 유지한다. 기존 복원 정본 v1.2.0, 1,208행은 수정하지 않았다. 원문 스냅샷을 튜닝용 저장 공간으로 사용하지 않는다.

### 개발 검증

프로젝트 루트에서 다음 명령으로 현재 데이터와 엔진을 함께 검사한다.

```bash
node tests/engine.test.cjs
```

검사는 이 프로토타입의 동작을 확인한다. 원작의 실제 플레이 수치와 일치함을 입증하는 검사는 아니다. 사용자 조작과 오프라인 실행 방법은 [README](../README_KO.md)에 있다.
