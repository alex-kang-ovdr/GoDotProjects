## AI 작업 제한

AI는 1/120초 고정 스텝마다 최대 6개의 예측을 처리합니다. 60fps의 일반적인 `tick(1/60)` 호출에서는 최대 12개입니다. 이번 회귀 검사에서 이 제한과 15fps·60fps 조건의 결정성을 확인했습니다. 파워 후보에 0·100을 포함하도록 탐색을 변경했으므로 이전 1.1 실행판의 후보 수·측정 시간을 현재 버전 수치로 재사용하지 않습니다.

## 렌더러와 UI 연결

렌더러는 이번 1.2에서 수정하지 않았습니다. 다음은 **이전 1.1에서 합성 Canvas 환경으로 확인한 기록**이며 이번에 실제 브라우저로 다시 확인했다는 뜻은 아닙니다.

- 엔진의 궤적 캐시 사용과 지형 이미지 캐시 재사용
- impact·explosion 이벤트의 중복 착탄 표식 제거
- 허공 이탈·반사 지점·뒤늦게 발동한 지뢰의 표식 제외
- 같은 대상의 연속 피해 합산
- 밀집한 8기 HP 표시와 포격 요약 영역의 겹침 회피
- 여러 탄환·고각 탄환 카메라, 음수 포신 각, 상태 불변성, 리셋·해제
- 실제 엔진의 발사 → 착탄 → actionEnd 연결에서 1발에 표식 1개

이번 1.2의 HTML 고정 ID 121개를 앱 참조와 대조하여 누락·중복을 발견하지 않았습니다. 로컬 스크립트·스타일 파일 경로와 JavaScript 문법 검사도 통과했습니다. 새 UI의 `getAimingState`·`getChargePower`·`setAimAtWorld` 연결, 자료 프로필의 다음 경기 적용, 파워 목표·직전 표식의 이벤트 연결을 정적으로 대조했습니다. 이 검사는 DOM 레이아웃·터치 상호작용의 실제 실행 검증을 대체하지 않습니다.

## 브라우저 검증 범위

**이번 1.2 변경분의 실제 화면·터치·반응형 렌더링 검증은 완료하지 못했습니다.** 이전 1.1 작업에서 미리보기 서버와 검증 브라우저의 연결 경로가 거부되었고 오류 페이지 접근에도 정책 제한이 있었습니다. 해당 제한의 해소가 확인되지 않았으므로 같은 경로를 반복하거나 다른 브라우저·서버로 우회하지 않았습니다. 엔진·정적 연결 검증과 배포 성공 여부를 각각 별도로 확인합니다.

이전 1.0 실행판에서는 로비, 캐릭터·프로필 선택, 전투 시작, 더블샷, 일시 정지·재개와 390×844·844×390 CSS 뷰포트의 iframe 배치를 확인했습니다. 이 기록을 1.1·1.2 변경분이나 실제 휴대전화 검증 결과로 확장해서 해석하지 않습니다.
