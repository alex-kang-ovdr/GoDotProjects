# 포트리스 BLUE · 포격 전술

실행판 **1.2.0** · 2026-11-18

브라우저에서 바로 즐기는 턴제 포격 게임입니다. 각도와 파워를 조절하고, 바람과 파괴되는 지형을 이용해 상대 팀을 쓰러뜨립니다. AI 대전과 같은 기기에서 번갈아 조작하는 2인 대전을 제공합니다.

공개 자료로 복구한 일부 스탯을 연결한 **독립 프로토타입**입니다. 포트리스2·포트리스3 BLUE의 원작 서버나 실행 파일을 완전히 복원한 버전은 아닙니다. 원문 수치와 구현을 위해 정한 값은 게임의 **데이터 · 설정 → 데이터 근거** 및 [데이터 출처 문서](docs/DATA_PROVENANCE_KO.md)에서 확인할 수 있습니다.

## 바로 실행하기

### 오프라인 다운로드판

1. `Fortress_BLUE_Playable.zip`을 다운로드합니다.
2. ZIP 안의 파일을 **모두 같은 폴더 구조로 압축 해제**합니다.
3. 압축을 푼 폴더의 `index.html`을 브라우저로 엽니다. 소스 프로젝트 형태로 받은 경우에는 `dist/index.html`을 엽니다.
4. 프로필·전장·대전 방식을 고르고 **전투 시작**을 누릅니다. 상대 선봉을 지정하거나 자동 편성을 선택하고 조준 시간을 조절할 수도 있습니다.

게임 실행에는 계정, 외부 패키지 설치, 빌드 과정이 필요하지 않습니다. JavaScript와 Canvas를 사용하는 정적 페이지이며 게임 파일은 오프라인에서도 동작합니다. 출처 링크를 열 때는 인터넷 연결이 필요합니다. HTML 파일만 따로 옮기지 말고 JavaScript·CSS·이미지 파일을 함께 유지하세요.

효과음은 처음에 꺼져 있습니다. 상단 스피커 버튼으로 켤 수 있습니다. 전체 화면 버튼은 해당 브라우저가 전체 화면 API를 지원할 때 사용할 수 있습니다.

### 소스 폴더에서 실행하기

프로젝트의 `dist/index.html`을 직접 열면 됩니다. 개발 중 HTTP 주소가 필요하고 Python이 설치되어 있다면 프로젝트 루트에서 다음 명령을 실행할 수도 있습니다.

```bash
python -m http.server 8000 --directory dist
```

그런 다음 브라우저에서 `http://localhost:8000`을 엽니다. 이 주소는 자신의 컴퓨터에서 실행하는 개발 서버 주소입니다.

## 두 가지 프로필

| 항목 | CLASSIC | 3BLUE |
|---|---|---|
| 선택 가능한 캐릭터 | 13종 | 공식 HP가 확인된 4종 |
| 캐릭터별 선택지 | 무기 2개 | 스킬 4개 |
| 팀 구성 | 1 대 1, 2 대 2, 4 대 4 | 4 대 4 |
| 스탯 기준 | 일본 서비스 2003년 문헌 | 날짜가 구분된 F3 공식 소개·패치 |
| 기본 행동 시간 | 25초 | 25초 |
| 기본 라운드 구성 | 14라운드 제한, 9라운드부터 서든데스 | 일반 7 + 서든데스 3, 총 10라운드 |

CLASSIC에는 캐터펄트, 크로스보우, 캐논, 캐롯탱크, 듀크탱크, 마인랜더, 미사일, 멀티미사일, 슈퍼탱크, 레이저탱크, 이온어태커, 세크윈드, 포세이돈이 있습니다.

3BLUE에는 캐터펄트, 메카펀치, 이블벨라, 야구소년이 있습니다. 일반·특수 공격은 처음부터 사용할 수 있고 지원 스킬은 2라운드, 궁극기는 3라운드에 열립니다. 이 해금 시점은 프로토타입의 규칙입니다.

출격 준비에서는 BLUE 팀의 **선봉 캐릭터**를 선택합니다. 상대 선봉은 직접 고르거나 자동으로 정할 수 있고, 나머지 팀원은 자동으로 구성됩니다. 조준 시간은 15·25·40·60초 중에서 고를 수 있습니다. 화면 아래 `NEXT`에서 이후 행동 순서를 확인할 수 있습니다. 선봉으로 선택한 캐릭터가 항상 첫 번째로 행동하는 것은 아닙니다.

### 탱크별 발사각 자료 선택

출격 준비의 **발사각 자료**에서 CLASSIC의 각도 기준을 선택할 수 있습니다. 기본값은 **일본 2003 문헌**입니다. **한국판 참고 · 빌드 미확정**은 한국 커뮤니티에 보고된 최소·최대 각도를 별도로 적용합니다. HP·공격·딜레이는 기존 데이터 프로필을 유지하며 발사각만 선택 자료를 사용합니다. 두 자료가 다른 캐릭터는 캐논·캐롯탱크·미사일·멀티미사일·레이저탱크 5종입니다.

전투 중 설정에서 자료를 바꾼 경우 다음 **새 전투**부터 적용합니다. 일시 정지 메뉴의 **같은 설정으로 재시작**은 현재 경기의 자료 프로필과 시드를 유지합니다. 한국 참고표의 정확한 패치는 미확인 상태이므로 한국 BLUE의 확정 원본 데이터로 취급하지 않습니다.

조준 패널의 **범위**는 차체를 기준으로 한 무기 고각입니다. **지형**은 발사 방향을 반영한 경사 보정이며 **실제 고각**은 두 값의 합입니다. 실제 고각은 경사면에서 0도보다 작거나 90도보다 커질 수 있습니다. 전장 클릭·드래그는 엔진의 차체 회전 좌표계를 역으로 계산하여 조준합니다.

3BLUE 네 캐릭터의 원작 최소·최대 발사각은 미복구입니다. 해당 프로필의 카탈로그 각도와 펄스레이저 전용 각도는 계속 **구현값**으로 구분합니다. 전체 비교표·출처·모순·미복구 필드는 [각도·파워 복원 보고서](docs/ANGLE_POWER_RECOVERY_KO.md)와 [복원 데이터 JSON](dist/datasets/Fortress_AnglePower_Recovery.json)에 있습니다.

### 3BLUE 고유 스킬

캐릭터별로 다음과 같은 고유 행동을 사용할 수 있습니다.

| 캐릭터·스킬 | 플레이할 때의 동작 |
|---|---|
| 메카펀치 · 펄스레이저 | 중력·바람을 받지 않는 직선 공격. 이 스킬의 각도 범위는 −35~75도입니다. |
| 이블벨라 · 맹독박쥐 | 독을 남기는 박쥐 6발을 발사합니다. |
| 이블벨라 · 흡혈박쥐떼 | 적을 추적하며 실제로 준 피해의 25%만큼 자신의 HP를 회복합니다. 방어막 흡수량과 아군 피해는 흡혈에 포함하지 않습니다. |
| 이블벨라 · 유틸해제 | 적의 방어막·공격 강화를 지우는 지원탄 1발입니다. 더블이나 서든데스로 반복하지 않습니다. |
| 야구소년 · 퉁퉁안타 | 지형에서 한 번 반사되며 명중한 상대를 밀어냅니다. |
| 야구소년 · 통통유도볼 | 적을 추적하고 지형에서 최대 두 번 반사됩니다. |
| 캐터펄트 · 대형 물리방패 | 자신에게 피해 320을 흡수하는 방어막을 더합니다. |
| 메카펀치 · 플라즈마실드 | 자신에게 피해 360을 흡수하는 방어막을 더합니다. |
| 야구소년 · 증폭기어 | 자신의 다음 두 차례 동안 공격을 20% 강화합니다. |

흡혈 비율·반사 횟수·직선 비행·스킬별 사격각·지원 효과는 이 플레이의 **구현 모델**입니다. 각 공식 공격 입력과는 분리해 기록했습니다. 원문 자료와 대응 관계는 [데이터 출처 문서](docs/DATA_PROVENANCE_KO.md)에 있습니다.

바운스는 지형에 닿을 때 적용하며 탱크에 직접 닿으면 공격을 마칩니다. 포탄의 폭발은 아군에게도 피해를 줄 수 있으므로 가까운 팀원의 위치를 함께 확인하세요. 유틸해제의 강화 제거는 적에게만 적용하지만 일반 피해에는 아군도 포함될 수 있습니다.

## AI와 대전 / 같은 기기 2인

- **AI와 대전:** 사용자가 BLUE 팀의 모든 캐릭터를 조작하고 상대 팀은 AI가 조작합니다. 난이도는 입문·보통·도전 중에서 고릅니다.
- **같은 기기 2인:** 두 사람이 BLUE와 RED 팀을 맡아 같은 화면·키보드 또는 터치를 번갈아 사용합니다. 자기 팀의 차례가 되면 조작권을 넘겨주세요.

같은 기기 대전은 로컬 교대 방식입니다. 별도 기기 사이의 온라인 접속이나 매칭 서버는 제공하지 않습니다.

AI는 현재 위치에서 사용할 수 있는 무기별 결과를 비교하고, 상황에 따라 방어·강화·해제 같은 지원 스킬도 선택합니다. 이번 AI의 전술 범위는 무기·조준·지원 선택이며, 안전한 이동 경로나 이동탄을 이용한 위치 변경 계획은 포함하지 않습니다.

## 기본 플레이 흐름

1. 현재 차례인 캐릭터와 상대 위치, 남은 이동량을 확인합니다.
2. 이동 버튼이나 방향키로 위치를 잡습니다. 지형이 무너지면 탱크도 내려앉고, 전장 밖으로 떨어지면 탈락합니다.
3. 사용할 무기·스킬을 고릅니다. 필요하면 발사 전에 아이템 하나를 사용합니다.
4. 사격 방향, 각도, 파워를 정합니다. 바람 화살표와 예상 궤적을 참고하세요.
5. **발사**를 누르거나 Space를 충전한 뒤 놓습니다. 발사체와 지형 변화가 처리되면 다음 행동으로 넘어갑니다.

지원 스킬도 선택한 뒤 행동 버튼을 눌러 사용합니다. 방어·증폭처럼 직접 탄을 쏘지 않는 행동에서는 버튼이 **사용**으로 바뀌며, Space를 누르면 충전 없이 즉시 적용하고 자기 차례를 마칩니다. 유틸해제처럼 탄을 보내는 지원기는 각도·파워를 정한 뒤 발사합니다. 아무 행동 없이 넘기려면 **턴 넘기기**를 누릅니다.

탱크와 일부 스킬마다 사격각 범위가 다릅니다. 각도 슬라이더의 최소·최대는 현재 선택한 스킬에 맞춰 바뀝니다. 조준 점선은 모델의 예상 경로이며 실제 명중이나 모든 추가 탄의 결과를 보장하지 않습니다. 무기 설명과 현재 행동의 반복 수·발사체 수를 함께 확인하세요. 방어·증폭처럼 직접 적용하는 지원기는 포탄을 쏘지 않습니다.

## 키보드·마우스 조작

키보드로 플레이할 때는 먼저 전장 영역을 한 번 클릭하세요. 입력창이나 선택 메뉴에 초점이 있으면 해당 UI의 기본 키 동작이 우선할 수 있습니다.

| 조작 | 동작 |
|---|---|
| `←` / `→` 또는 `A` / `D` | 현재 캐릭터 이동 |
| `↑` / `↓` 또는 `W` / `S` | 사격각 조절 |
| `1`–`4` | 해당 번호의 무기·스킬 선택. CLASSIC은 1–2 사용 |
| `Q` / `E` | 사용 가능한 이전 / 다음 무기·스킬로 이동 |
| `Tab` | 전장에 초점이 있을 때 다음 무기·스킬. 일반 UI에서는 초점 이동 |
| `Space` 누르고 있기 → 놓기 | 파워 충전 → 발사 |
| 발사 버튼 클릭 | 현재 슬라이더 파워로 발사 |
| 발사 버튼 길게 누르기 → 놓기 | 파워 충전 → 발사 |
| 전장 클릭·드래그 | 방향·각도 조준. 드래그 위치에 따라 파워도 변할 수 있음 |
| `⇄` 방향 버튼 | 좌우 발사 방향 전환 |
| `P` | 일시 정지 화면 열기 |
| `Esc` | 열린 설정·도움말·일시 정지 화면 닫기, 또는 전투 중 일시 정지 |

파워는 UI·AI·엔진이 공통으로 사용하는 **0–100% 정규화 조작 값**입니다. 슬라이더를 조절하면 위쪽 **▼ 목표** 표식이 이동하고, 아래쪽 **▲ 직전** 표식은 해당 캐릭터가 실제로 마지막에 발사한 파워를 표시합니다. 충전을 시작하면 게이지는 0부터 증가하고 최대치에서 다시 내려오므로 목표 위치에서 놓으면 됩니다. 목표 표식은 충전 도중에도 유지합니다. 현재 충전 속도 72%p/초와 왕복 방식은 구현 가정이며 원작 실측값이 아닙니다. 아이템은 화면의 아이콘을 눌러 사용합니다. 카메라는 `−`, `전체`, `+`로 조절합니다.

**직전 조준 복원**은 해당 캐릭터가 마지막에 발사한 각도·파워·방향과 선택 가능한 무기를 다시 불러옵니다. 바람과 지형은 현재 상태를 유지하므로 같은 입력으로 같은 결과가 보장되지는 않습니다. 포격이 끝나면 적 피해·아군 피해·격파·회복·지형 변화가 행동 요약으로 표시됩니다.

## 터치 조작

화면의 이동 버튼을 누르고 있으면 이동하고, 각도·파워 슬라이더로 포격을 준비할 수 있습니다. 전장 위를 드래그해 조준하는 방법도 지원합니다. 발사 버튼은 짧게 누르면 현재 파워로 발사하고 길게 누르면 충전합니다.

캐릭터와 조작부가 좁게 보이면 기기를 가로로 돌리거나 `전체` 보기로 전장 범위를 확인하세요. AI가 행동 중이거나 포탄이 날아가는 동안에는 사람의 공격·이동 입력을 받지 않습니다.

## 아이템 네 가지

각 캐릭터는 회복·방어막·더블·이동탄을 하나씩 가지고 시작합니다. **한 턴에 하나만** 사용할 수 있습니다.

| 아이템 | 이 구현의 동작 |
|---|---|
| 회복 | 최대 HP를 기준으로 CLASSIC 20%, 3BLUE 5% 회복. HP가 가득 차면 사용하지 않음 |
| 방어막 | 공격 1회 차단. 다탄 공격은 발사체별 판정 |
| 더블 | 다음 반복 가능한 공격을 같은 각도·힘으로 2회 반복하도록 준비 |
| 이동탄 | 다음 발사를 이동탄으로 바꾸고 착탄 지점으로 이동 |

아이템을 사용한 뒤에도 무기를 발사할 수 있습니다. 이동탄을 쓴 경우에는 원래 공격 대신 이동탄이 발사됩니다. 회복과 아이템의 출처·원문 조건·단순화 내용은 [데이터 출처 문서](docs/DATA_PROVENANCE_KO.md)에 정리했습니다.

더블은 도구를 누를 때 재고 1개와 그 차례의 아이템 기회를 사용하고 추가 딜레이가 붙습니다. 준비된 효과는 지원기·이동탄 사용, 턴 넘기기, 시간초과 후에도 남아 있다가 다음 반복 가능한 공격을 발사할 때 사용됩니다. 3BLUE 서든데스는 이미 3회 반복하므로 새 더블을 사용할 수 없습니다. 이전 라운드에 준비한 더블이 있다면 공격 시 사용되지만 반복은 최대 3회입니다.

## 세 개의 창작 전장

| 전장 | 특징 |
|---|---|
| 바람의 능선 | 서로 다른 높이의 능선. 탄도와 지형 파괴를 익히기 좋은 지형 |
| 부유 군도 | 섬 사이의 낙하 공간. 이동탄과 지면 확보가 중요한 지형 |
| 황혼의 주조소 | 단차와 가로 구조물이 있는 산업 테마 지형 |

맵, 지형 마스크, 배치, 탱크 외형은 이 프로젝트에서 새로 만든 것입니다. 원작 맵의 원본 에셋이나 충돌 데이터를 추출한 결과물이 아닙니다. 새 전투는 새로운 시드를 사용하며, 일시 정지 메뉴의 **같은 설정으로 재시작**은 같은 시드를 다시 사용합니다.

## 라운드와 승리 판정

상대 팀을 모두 탈락시키면 승리합니다. 행동 순서는 딜레이에 따라 정해집니다. 여기서 한 라운드는 **각 생존 캐릭터가 최소 한 번 행동한 구간**입니다. 딜레이가 짧은 캐릭터는 그 경계 전에 추가로 행동할 수 있습니다.

3BLUE는 8–10라운드가 서든데스입니다. 공격 무기는 3회 반복하고, 더블과는 곱해서 중첩하지 않습니다. 기본 6발인 맹독박쥐는 3회 반복으로 총 18발을 발사합니다. 이동탄과 네 가지 지원 스킬은 한 번만 처리하며, 유틸해제도 지원기에 포함됩니다. 전투를 마무리하기 위한 별도 모델로 8·9·10라운드 시작에 최대 HP의 8%·16%·24% 환경 피해가 적용됩니다. CLASSIC의 서든데스에는 라운드당 최대 HP의 5.5% 환경 피해를 적용하고 공격 반복 수는 늘리지 않습니다.

제한 라운드에도 양 팀이 남으면 캐릭터별 남은 HP 비율의 합을 비교합니다. 점수가 같거나 양 팀이 모두 전멸하면 무승부입니다. 이러한 종료 판정과 환경 피해는 **프로토타입의 규칙**입니다.

## 설정과 전투 기록

화면 아래 **데이터 · 설정**에서 다음 기능을 사용할 수 있습니다.

- **플레이 설정:** 조준 가이드, 화면 흔들림 줄이기, 효과 품질, 다음 전투의 클래식 발사각 자료를 조절합니다.
- **전투 튜닝:** 중력, 바람 가속 계수, 최대 발사속도, 피해 배율, 지형 파괴 배율, 턴 시간을 조절합니다. 변경값은 다음 새 전투부터 적용됩니다. 출격 준비에서 새로 시작하면 됩니다.
- **데이터 근거:** 전투 중 현재 캐릭터의 원문 스탯, 무기 입력값, 출처와 구현 가정을 확인합니다. 전투 전에는 선택한 선봉을 표시합니다.
- **전투 기록:** 이 브라우저에 저장된 최근 12경기를 확인하거나 지웁니다.

설정과 기록은 브라우저의 로컬 저장소에 보관됩니다. 브라우저나 기기가 달라지면 공유되지 않습니다. 결과 화면의 피해·발사 탄 수는 AI 대전에서 BLUE 팀 기준이며, 같은 기기 대전에서는 승리 팀을 표시합니다. 무승부는 BLUE 팀 수치를 표시하고 각 항목에 팀 이름을 붙입니다. 진행 턴은 전체 전투 기준이며, 발사 탄 수는 실제로 나온 발사체 수입니다. 저장소를 사용할 수 없는 환경에서도 게임은 실행되지만 기록 유지가 제한될 수 있습니다.

도움말·설정·일시 정지 화면을 열면 전투도 멈춥니다. 다른 탭으로 이동해 페이지가 숨겨졌을 때에도 일시 정지 화면을 표시합니다.

## 데이터 복구 범위와 모델의 한계

입력은 **복원 데이터 v1.2.0, 총 1,208행**입니다. 기존 복원 DB는 그대로 유지하며, 이 플레이에서 필요한 값만 연결했습니다. 전체 1,208행이 모두 게임 로직에 구현된 것은 아닙니다.

클래식의 기본 카탈로그는 JP2003의 13종 HP·기본 딜레이·이동력·사격각을 유지했습니다. 선택한 각도 자료는 별도 `aiming.angleProfiles`에서 실행 시 적용합니다. 공격 수치는 실제 HP 감소량으로 검증되지 않았습니다. 특히 원문 다탄 공격의 발당·총합 의미가 불명하므로 구현에서 균등 분배한 값을 사용합니다.

3BLUE는 네 캐릭터의 공식 HP·딜레이와 조건이 확인된 일부 공격 입력을 사용합니다. 공식 소개표의 성급·레벨이 미상인 값과 0성·1레벨 공격표를 같은 실제 빌드 상태라고 단정하지 않습니다. 복구되지 않은 공격값과 이동 예산은 조정값이며 다른 포트리스 게임의 수치로 채우지 않았습니다.

중력, 발사속도, 바람, 충돌 반경, 거리별 피해, 상태효과, 스킬 간소화, 라운드 해석, AI는 프로토타입 모델입니다. 원작의 물리·밸런스 정확성을 입증하려면 해당 빌드의 실행 자료와 별도의 실측이 필요합니다. 상세한 필드별 구분은 [DATA_PROVENANCE_KO.md](docs/DATA_PROVENANCE_KO.md)를 참고하세요.

## 코드 구성

외부 런타임 의존성이 없는 HTML·CSS·JavaScript 프로젝트입니다.

| 경로 | 역할 |
|---|---|
| `dist/index.html` | 로비, 전투 HUD, 도움말·설정·결과 화면 |

| `dist/engine.js` | `FortEngine`: 턴, 비행, 충돌, 지형 파괴, 피해·상태, AI와 승리 판정 |
| `dist/render.js` | `FortRenderer`: Canvas 전장·캐릭터·이펙트·카메라 표시 |
| `dist/app.js` | UI 입력, 설정·기록 저장, 효과음, 엔진·렌더러 연결 |

| `dist/datasets/Fortress_AnglePower_Recovery.json` | 각도 30행·파워 17행과 출처·구현값 분리 데이터 |

스크립트는 `data.js → engine.js → render.js → app.js` 순서로 로드합니다. 런타임 파일을 옮길 때 이 순서와 상대 경로를 유지하세요. 데이터의 `provenance.sourceSnapshots`는 원문 보존 영역이므로 튜닝 용도로 수정하지 않습니다.

무기의 원문 공격 상태는 `attackStatus`·`sourceSnapshot`에, 실행 동작은 `role`·`delivery`·`behavior`·`behaviorStatus`에 나눠 기록합니다. 화면의 탄수·해금·스킬별 각도는 엔진의 현재 행동 안내를 기준으로 합니다. 튜닝할 때는 원문 61개 스냅샷을 그대로 유지하고 실행 필드만 조정하세요.

## Node 엔진 테스트

Node.js가 설치된 개발 환경에서 **프로젝트 루트**를 현재 폴더로 지정한 다음 실행합니다.

```bash
node tests/engine.test.cjs
```

별도의 `npm install`이나 빌드 과정은 필요하지 않습니다. 검사는 실제 `dist/data.js`와 `dist/engine.js`를 불러와 실행합니다. 정상 통과한 항목은 `PASS`로 출력하고, 검사 실패 시 오류와 함께 종료합니다.

테스트는 동일 시드의 재현성, 잘못된 조작 차단, 비행 충돌·지형 파괴, 아이템과 지원 효과, 턴 진행 및 전투 종료 같은 **이 프로토타입의 동작**을 확인합니다. 브라우저의 레이아웃·터치·사운드나 원작의 미공개 물리식까지 검증하는 테스트는 아닙니다.

브라우저에서 문제를 추적할 때 개발자 콘솔의 `FortApp.getState()`로 현재 전투 진단 정보를 확인할 수 있습니다. `FortApp.getGame().getAimingState()`는 유효 각도 범위·실제 고각·파워 범위·충전 속도·출처 상태를 함께 반환합니다. 프로필, 맵, 시드, 라운드와 재현한 조작을 함께 기록하면 원인을 좁히기 쉽습니다.
