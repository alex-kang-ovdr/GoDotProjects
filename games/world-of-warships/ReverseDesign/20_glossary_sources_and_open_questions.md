## 1. 버전과 자료 상태

- 정식 15.10 배포 공지를 현재 기준으로 사용한다.
- 15.11 Work in Progress는 예정·테스트 자료이며 현행 규칙에 합치지 않는다.
- 공식 위키도 문단별 갱신 시차가 있으므로 변경된 항목은 정식 패치와 대조한다.
- 공식 영상은 실제 재생·프레임 분석을 하지 않은 경우 제목·설명·챕터 등 확인 가능한 범위만 사용한다.
- 사용자 제공 [나무위키 원문](https://namu.wiki/w/%EC%9B%94%EB%93%9C%20%EC%98%A4%EB%B8%8C%20%EC%9B%8C%EC%89%BD)은 접근되지 않았다. 그 내용을 읽거나 검증했다고 주장하지 않는다.
- 특정 문서의 정확한 수치를 원작 전체의 보편 상수로 만들지 않는다.

## 4. 출처 원장 사용법

본문의 `[Axx]`, `[Bxx]`, `[Cxx]`, `[Rxx]`는 아래 ID에 연결된다. 같은 URL을 여러 문서에서 사용한 경우 ID를 한 행으로 묶었다. ID의 문자 접두사는 우선순위나 신뢰도를 뜻하지 않는다.

**모든 원문 열람일은 2026-11-13**이다. 자료의 게시일과 열람일은 다르며, 게시일을 확인하지 않은 자료에 날짜를 만들어 넣지 않았다.

자료 유형은 다음처럼 읽는다.

- **공식 공지·가이드**: 배포 사실·설명·특정 행사 조건.
- **공식 지원**: 지원 정책·제한·조작·운영 설명.
- **공식 운영 위키**: Wargaming 또는 승인 기여자의 정리. 구문 혼재 주의.
- **개발사 Steam 공지**: 개발사가 Steam에 게시한 배포 설명.
- **공식 영상 안내**: 확인한 제목·설명 등의 범위. 재생 실측과 구분.

## 7. 확인 결과를 기록하는 양식

```yaml
VerificationRecord:
  question_id: OPEN_XX
  product: wows_pc_global
  live_patch: actual_version
  region: actual_region
  ship_and_loadout: full_snapshot
  mode_and_map_variant: ids
  source_type: live_notice_or_client_or_controlled_observation
  observed_result: measured_value_or_outcome
  repeated_trials: actual_count
  confounders: known_differences
  conclusion: confirmed_or_version_dependent_or_unresolved
  affected_documents: list
```

자료끼리 다를 때 숫자 하나를 선택해 빈칸을 메우기보다, 적용 대상·시기·모드를 먼저 분리한다. 확인하지 못한 서버 내부 구현을 가정 모델과 섞지 않는 것이 이 문서 집합의 기본 원칙이다.
