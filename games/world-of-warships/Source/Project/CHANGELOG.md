# IRON TIDE 변경 기록

## V3.0 · 2026-11-14

수상함 전투의 조작·AI·저장 결함을 보완하고 **5단계 기초 훈련 → 자유 작전 또는 승리 기반 3연전 원정 → 결과·경력 → 이어 하기**를 연결했습니다.

### 실제 전투 개선

- 좌초한 AI가 탈출 지점을 만들고 후진·선회를 조합해 해안을 벗어난 뒤 원래 목표로 복귀합니다. 장애물 여유 영역 안에서 출발해도 바깥으로 나가는 경로를 허용합니다.
- 경계와 접촉할 때 바깥 방향 속도를 제거하고 해안·경계에 평행한 이동과 조타를 유지합니다. 추진 상태와 충돌 후 실제 속도를 분리해 화면·예측·물리 값이 어긋나지 않게 했습니다.
- AI는 사거리·사선이 유효한 표적을 우선하며 작은 거리 변화만으로 표적을 계속 바꾸지 않습니다.
- 거점 명령을 받은 아군은 즉각적인 위협이 없으면 감속해 실제 점령을 유지합니다. 적을 보지 못하는 동안에도 복구·수리합니다.
- 주포 정렬 허용 오차를 0.025라디안, 약 1.43도로 제한하고 정렬 예상 시간을 표시합니다.

### 조준과 피드백

- 카메라 변환을 먼저 확정한 뒤 그 프레임의 마우스 좌표를 조준점으로 변환합니다.
- 적 함체·이름표를 클릭하거나 터치해 표적을 선택합니다. 단순 커서 이동으로 바뀌지 않으며, 작은 함체에도 최소 48px 터치 영역을 제공합니다.
- 접촉 상실 시 마지막 관측 위치와 선택을 유지합니다. 공개 격침 이벤트를 받으면 선택을 정리합니다.
- L 또는 선행 조준 버튼으로 현재 관측 속도에 따른 예상 지점을 한 번 조준합니다. 어뢰는 어뢰 속도를 사용하며 자동 발사하지 않습니다.
- 새 플레이어 명중 이벤트로 직접 피해·도탄·비관통을 표시하고, 화재·침수·부포 누적 피해는 별도로 표시합니다.
- 짧은 클릭의 발사 대기 시간이 남은 재장전과 포탑 정렬 중 더 긴 시간을 반영합니다. 긴 재장전까지 자동 발사를 예약하지 않습니다.
- 함대 생존 아이콘·피격 화면 효과·터치 누름 상태를 실제로 표시하고 동작 줄이기 설정을 반영합니다.

### 훈련·원정·기록

- 조함, HE, AP, 측면 어뢰, 거점 점령의 독립적인 다섯 훈련 장면을 추가했습니다. 실제 이동·발사체 피해·점령만 통과로 인정합니다.
- 통과·실패 뒤에는 장면을 멈추며 다음 단계·다시 도전·항구 복귀를 선택합니다. 훈련 반복으로 이전 완료 진도가 내려가지 않습니다.
- 훈련 저장은 일반 활성 전투를 보존하고 경력·XP·원정에 포함되지 않습니다.
- 북쪽 군도 → 해협의 보루 → 외해 교전을 승리해야 진행하는 군도 원정을 추가했습니다. 패배·무승부는 같은 단계에 머뭅니다.
- 원정 난이도·진행·시도 횟수·누적 피해·XP·완주 횟수를 기록합니다. 원정 진행과 경력은 한 저장 객체로 갱신합니다.
- 난이도별 작전 최고 평가, 함종별 전적, 기록의 장비·난이도를 추가했습니다.

### 호환성

- 엔진 저장은 V3로 작성하고, 실제 수정 전 V2 엔진에서 캡처한 자료로 V2 → V3 이행을 검증했습니다. 발사체·난수·자원·전투 ID를 유지합니다.
- 활성 전투·경력 저장 키는 V2와 같습니다. 경력 V2 총계·전투 ID를 보존하고, 근거 없는 난이도별 기록을 추정하지 않습니다.
- V3 UI 저장에 탄종·어뢰 확산·조준점·조준경·선택 표적·원정 맥락을 추가했습니다. 구형 UI 저장이 없으면 함선에 저장된 조준점을 사용합니다.

시뮬레이션 검증에서 이전의 60초 좌초 반복 장면이 실제 탈출·우회·거점 점령으로 끝나는 것을 확인했습니다. 훈련 다섯 단계는 일반 입력과 실제 발사체·점령을 사용해 순서대로 완료했습니다. V3 탈출 상태의 저장 후 동일 입력 재개는 동일 결과를 생성했습니다.

자동 검사 통과가 실제 브라우저·모바일 기기 전체의 검증이나 수동 원정 완주를 뜻하지는 않습니다. V2의 과거 브라우저 검증 결과는 아래 별도 이력이며 V3 화면 검증으로 간주하지 않습니다. 배포 완료 여부는 Sites의 네이티브 배포 결과로 확인합니다.

### 문서와 배포물

`README.md`에 실행·조작·제약을 갱신했으며 `docs/`에 훈련, 원정·경력, 조준·피드백, AI·항법을 각각 별도 MD로 정리했습니다. 실행 소스 ZIP에는 런타임, 문서, 테스트와 실제 V2 회귀 자료가 포함됩니다.

## V2.0 · 2026-11-14

수상함 싱글플레이의 준비 → 교전 → 종료 보고서 → 함장 경력 → 다음 출격 흐름을 확장했습니다.

### 작전과 준비

- 북쪽 군도: 세 거점과 800점 선취, 8분.
- 해협의 보루: 중앙 거점과 640점 선취, 7분.
- 외해 교전: 적 함대 격파, 5분. 시간 종료 시 팀 잔존 HP 비율을 비교하며 HUD와 결과에도 비율을 표시합니다.
- 표준·포술·생존·기동 장비의 이점과 비용을 함선 제원과 실제 시뮬레이션에 함께 반영했습니다.

### 전투

- 사거리·사선·포탑 정렬·발사각·재장전·모듈 상태를 한 발사 판정 함수에서 계산합니다.
- 어뢰 측면 발사각, 좁은/넓은 확산, 예상 비행 시간과 선행 조준을 표시합니다.
- 선수·중앙·선미 구획 피해와 소진 구획의 피해 감소를 적용합니다.
- 회복 가능 피해를 별도로 기록하며 수리반이 실제 회복 가능량만 복구합니다.
- 기관·조타·주포의 손상과 치명적 손상, 자동 복구, 주포 장전 정지·재개를 적용합니다.
- 순양함·전함의 근거리 자동 부포, 실제 탄도의 섬 충돌, 피해 종류별 집계를 추가했습니다.
- 탐지된 위협에 대한 어뢰 경고와 AI 회피를 적용합니다.
- 조준경, 아군 집중 공격·거점 점령·집결 명령을 추가했습니다.

### 저장과 경력

- 약 3초 간격, 일시정지, 항구 복귀, 페이지 종료 시 진행 중 전투를 저장합니다.
- 난수 상태, 함선·구획·모듈, 발사체·효과·소모품·타이머·점수·명령을 복원합니다.
- 잘못된 저장 데이터는 검증 후 거부합니다. 완료한 전투는 진행 중 전투로 재개하지 않습니다.
- 결과 화면에 별 평가, 실제 XP 증가량, 명중률, 무장·지속·충돌 피해, 달성 항목을 표시합니다.
- 함장 계급, 작전별 최고 기록, 최근 전투 20개와 별도 전투 ID 장부를 기록합니다.
- 동일 전투를 다시 처리해도 보상을 중복 지급하지 않습니다.

브라우저 실전 검증은 외해 교전 중심으로 수행했습니다. 세 작전의 배치·경로와 종료 조건은 자동 검증에 포함됩니다. 실제 모바일 기기 전체나 모든 브라우저 조합의 검증을 의미하지 않습니다. 배포 주소의 로그인 뒤 화면은 내부 미리보기와 별개의 확인 범위입니다.

### 실행과 범위

`dist/index.html`을 브라우저로 열어 실행합니다. 의존성 설치와 빌드가 필요하지 않습니다. 각 시스템과 조작은 `README.md`에 설명했습니다.

V2의 완성 범위는 수상함 3종, AI 3 대 3 전투, 세 작전, 로컬 경력과 저장·재개입니다. 항공모함·잠수함·온라인 대전·실제 함선 데이터 전체·서버 경제는 포함하지 않습니다.
