KNOX · LAST SIGNAL — 오프라인 플레이

1. ZIP을 먼저 압축 해제합니다.
2. index.html을 브라우저로 엽니다. 모든 게임 코드가 이 파일에 들어 있습니다.
3. 처음이면 '여유롭게'를 선택하고 '새 생존 시작'을 누릅니다.

WASD/방향키 이동 · 마우스 조준/왼쪽 버튼 공격 · Space 밀치기
Shift 달리기 · C 은신 · E 상호작용 · I 가방 · B 제작 · M 지도 · Esc 메뉴
터치: 왼쪽 스틱 이동 / 오른쪽 공격·밀치기·탐색 버튼

목표: 배터리 2 + 전자 부품 2 + 덕트 테이프 1을 모아 대피소 무전기 수리.
대피소 주변을 확보한 상태에서 신호를 90초 송출하면 성공입니다.

자동 저장은 현재 주소·브라우저의 한 슬롯입니다. 새 생존은 기존 슬롯을 대체합니다.
온라인/오프라인·다른 브라우저 간 이전은 메뉴의 JSON 내보내기/불러오기를 사용하세요.
로컬 파일 저장이 제한되면 JSON으로 백업하거나 이 폴더에서 다음 명령을 실행하세요.
  python3 -m http.server 8000
그다음 http://localhost:8000 을 여세요. Python 설치는 선택 사항입니다.
