# KNOX · LAST SIGNAL — 플레이 안내

브라우저에서 마을을 탐색하고 살아남아 대피소의 무전기를 복구하는 싱글플레이 생존 게임입니다. 다운로드 HTML은 파일을 그대로 열면 실행됩니다. ZIP은 먼저 압축을 풀고 `index.html`을 여세요.

## 첫 5분의 계획

1. **여유롭게 시작하세요.** 처음이면 시작 화면의 생존 강도를 `여유롭게`로 선택합니다. `WASD`로 움직이며 청록색 대피소와 그 안의 무전기 위치를 기억합니다. `M`을 누르면 게임이 멈추고 마을 지도를 볼 수 있습니다.
2. **대피소를 먼저 조사하세요.** 선반 가까이에서 `E`를 누르고 1.2초 동안 기다립니다. 조사 후 주변 패널에서 물품을 가져옵니다. 선반의 망치와 못을 챙기면 `B` 제작 패널에서 시작 무기를 **못 박은 방망이**로 바꿀 수 있습니다.
3. **문을 열고 퇴로를 확인하세요.** 문 가까이에서 `E`로 엽니다. 달리기는 빠르지만 지구력과 소음을 소모합니다. 좀비와 거리를 벌리고, 여럿이 붙으면 `Space`로 밀친 뒤 빠져나옵니다. PC에서는 공격할 방향에 마우스를 놓고 왼쪽 버튼을 누릅니다.
4. **마켓과 철물점을 수색하세요.** 지도에서 마켓과 철물점 위치를 찾습니다. 마켓의 **계산대 · 건전지**에 배터리, 철물점의 **전기 부품 상자**에 전자 부품과 테이프가 있습니다. 조사하는 동안 움직이면 작업이 취소됩니다. 식량·물·붕대도 필요한 만큼 가져갑니다.
5. **다치면 안전한 곳에서 치료하세요.** 가방의 붕대나 천 조각을 선택하고 치료합니다. 치료가 끝나기 전에 움직이거나 직접 공격받으면 중단됩니다. 배고픔과 갈증이 낮아지면 가방의 음식·물을 사용합니다. 가방을 열어 두어도 시간은 계속 흐릅니다.

위 순서는 길잡이입니다. 5분 내 완료를 요구하는 제한 시간은 없습니다. 한 번의 무리한 전투보다 무사히 대피소로 돌아오는 것이 목표 달성에 도움이 됩니다.

## 구조 목표

| 준비물 | 수량 | 확정 공급 위치 |
|---|---:|---|
| 배터리 | 2 | 리버사이드 마켓 계산대 |
| 전자 부품 | 2 | 녹스 철물점 전기 부품 상자 |
| 덕트 테이프 | 1 | 녹스 철물점 전기 부품 상자 |

재료를 가방에 넣고 출발 대피소의 무전기 가까이에서 `E`를 누르세요. 5초의 수리가 끝나면 재료를 소비하고 신호 송출을 시작합니다.

무전기에서 **8타일 이내**에 머물고 **주변 7타일 이내에 좀비가 없는 상태**를 유지하면 신호가 쌓입니다. 총 **90초**를 채우면 구조 성공입니다. 대피소를 떠나거나 좀비가 접근하면 진행만 멈추고 기존 진행도는 유지됩니다. 성공 후에는 계속 탐험할 수 있습니다.

## 조작표

| 조작 | 동작 |
|---|---|
| `WASD` / 방향키 | 화면 방향으로 이동 |
| 마우스 이동 + 왼쪽 버튼 | 조준 + 공격 |
| `Shift` | 달리기 |
| `C` | 은신 전환 |
| `Space` | 밀치기 |
| `E` | 문·상자·침대·무전기 상호작용 |
| `I` / `B` / `M` | 가방 / 제작 / 지도 |
| `1`–`5` | 하단 빠른 슬롯 사용 |
| `Esc` | 일시정지 메뉴 / 열린 창 닫기 |
| 휠 / `+`·`−` | 확대·축소 |

**터치:** 왼쪽 스틱으로 이동하고 오른쪽 공격·밀치기·탐색 버튼을 사용합니다. 공격은 가까운 좀비를 향합니다. 달리기 버튼은 켜기/끄기 방식입니다. 가방 버튼으로 물품과 제작 패널을 펼칩니다.

## 기억할 규칙

- 가방·주변·제작 패널은 실시간입니다. 메뉴·지도·도움말을 열면 일시정지됩니다.
- 제작 재료는 완료할 때 소모됩니다. 이동이나 피격으로 중단하면 재료가 남습니다. 망치·톱 등 보존 도구는 제작 후에도 남습니다.
- 하중 20을 넘으면 느려지고 32를 초과하는 물품은 집을 수 없습니다. 통나무 등 무거운 재료는 용도를 확인하고 챙기세요.
- 음식과 물은 가방이나 빠른 슬롯에서 사용합니다. 붕대와 천은 출혈을 멈추고 체력을 회복합니다.
- 문은 열고 닫을 수 있습니다. 주변 패널의 문 보강에는 나무판 2개·못 4개와 망치가 필요합니다.
- 침대 휴식은 가까운 좀비가 없고, 출혈이 없으며, 음식·수분이 충분할 때 가능합니다. 압축 휴식은 피로와 지구력을 회복하고 음식·수분을 소모합니다.
- 사운드는 상단 버튼으로 켤 수 있습니다. 기본은 꺼짐입니다. 메뉴에서 날씨 효과 표시를 끌 수 있습니다.

## 저장과 다른 기기로 옮기기

현재 주소의 브라우저에 한 개의 생존 슬롯을 저장합니다. 플레이 진행 시간 약 20초마다 자동 저장하고, **저장** 버튼으로 즉시 기록할 수 있습니다.

**새 생존 시작은 현재 슬롯을 대체합니다.** 다른 생존 기록을 남기려면 메뉴의 **저장 파일 내려받기**로 JSON 백업을 먼저 만드세요. **저장 파일 불러오기**로 백업을 읽으면 그 기록이 현재 슬롯을 대체합니다. 사망 기록은 불러와도 사망 상태입니다.

온라인 사이트·로컬 HTML·`localhost`·다른 브라우저는 저장 영역이 다를 수 있습니다. 온라인과 오프라인 사이, 또는 다른 기기로 이전하려면 JSON을 내보낸 뒤 옮길 곳에서 불러오세요. 자동 클라우드 동기화는 없습니다. 로컬 저장을 사용할 수 없는 환경에서는 JSON 파일로 진행을 보관하세요.

## 이 버전의 범위

64×64 타일 마을, 건물 10개, 초기 보관함 20개, 아이템 33종, 제작 9종을 제공합니다. 생존은 좀비 56마리, 여유롭게는 30마리로 시작합니다. 원작 v11 선언을 참조한 아이템 21종과 웹 보완 정의 12종을 구분했습니다.

Project Zomboid 역기획 기반의 독립 웹 프로토타입이며 원작 전체를 실행하는 제품은 아닙니다. 멀티플레이·차량 운전·전체 3D·다층 건물·원작 감염 시스템은 포함하지 않습니다. 차량은 장애물이고 날씨·기온 표시는 연출입니다. 데이터 적용 상세는 함께 제공한 `DATA_ADAPTATION.md`에서 확인할 수 있습니다.
