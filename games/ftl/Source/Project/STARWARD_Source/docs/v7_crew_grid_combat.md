# STARWARD v7 — 사각 타일 이동과 승조원 근접전

## 1. 목적

승조원을 방의 중심점에 겹쳐 놓고 같은 방이라는 이유만으로 피해를 주던 단순 모델을 확장한다. 사용자는 방 안의 사각 타일을 지정하고, 승조원은 실제 문을 통과해 상하좌우로 이동한다. 적을 지목하면 공격 가능한 인접 칸까지 접근한 뒤 근접 공격한다.

2D와 3D는 동일한 위치·경로·표적·체력·공격 시간 데이터를 표시한다. 화면 전환이나 카메라 이동은 이동 명령 또는 전투 시간 진행이 아니다.

## 2. 좌표 계약

방 정의의 `x/y/w/h`는 정수 타일 공간을 기준으로 한다. 타일은 정수 `tileX/tileY`로 식별하고, 시각적인 중심은 `x=tileX+0.5`, `y=tileY+0.5`이다. 승조원의 `x/y`는 이동 도중 보간된 실제 위치이다.

- 정지한 승조원은 타일 중심에 위치한다.
- 새 이동 경로는 상하좌우 이웃으로 이루어진다.
- 대각선 이동, 벽 관통, 서로 연결되지 않은 방 사이의 순간 이동을 허용하지 않는다.
- 문이 있는 방 경계만 건널 수 있다. 문의 파손·열림·해킹 봉쇄·진영별 통행 규칙은 기존 전술 상태를 사용한다.
- 점유와 목적지 예약은 승조원의 원래 소속이 아니라 현재 물리적 `shipId`를 기준으로 계산한다.

`getShipTiles(shipId)`는 방·정수 좌표·중심·점유·예약 정보를 제공한다. 렌더러에서 임의로 다른 격자를 만들어 게임과 불일치시키지 않는다.

## 3. 이동 명령

승조원 선택 후 자신의 현재 함선 위 타일을 누르면 `moveCrewToTile(crewId, tileX, tileY, shipId)`를 호출한다. 기존 방 단위 명령 `moveCrew`는 그 방의 도달 가능한 빈 타일로 연결해 기존 담당실 복귀와 AI 명령을 유지한다.

타일 명령은 실제 경로와 목적지 예약을 계산한다. 같은 아군 여러 명에게 같은 칸을 지정하더라도 정지 위치가 겹치지 않도록 처리한다. 다중 선택은 인접한 유효 목적지를 분배하거나 예약 충돌 이유를 표시한다. 구현이 선택하지 않은 경로를 성공한 것처럼 그리지 않는다.

이동 중 새 목적지를 선택하면 현재 위치에서 경로를 바꾸며 순간 이동시키지 않는다. 수동 이동은 명시적 공격 목표를 취소하여 후퇴를 가능하게 한다. 문 파괴에 필요한 대기는 이동 거리와 별도의 시간이다.

## 4. 명시적 공격과 자동 방어

`attackCrew(crewId, targetCrewId)`는 다음 조건을 검사한다.

| 조건 | 결과 |
|---|---|
| 공격자와 대상이 살아 있음 | 전사한 인원을 추격하거나 공격하지 않음 |
| 같은 물리 함선 | 본함에서 적선의 인원을 원격 공격할 수 없음 |
| 유효 진영이 서로 다름 | 정신 지배를 포함한 현재 진영으로 판정 |
| 직접 지휘 가능한 아군 | 적 소유 인원 또는 지배된 인원을 임의 조작하지 않음 |
| 실제 경로·인접 위치 존재 | 접근 가능한 공격 위치를 찾고 이동 |

타격은 실제 인접 조건을 만족한 뒤에만 발생한다. 같은 방에 있어도 멀리 떨어졌거나 대각선에 있으면 먼저 접근한다. 벽이나 닫힌 경계문 너머로 근접 피해를 주지 않는다. 대상이 움직이면 경로를 갱신하며, 죽거나 물리 함선·진영이 바뀌면 목표를 해제한다.

별도 공격 명령을 내리지 않은 인원도 선내 침입자와 인접하면 기존 자동 방어 정책을 사용한다. 적 승조원·강습대·정신 지배된 인원은 같은 이동·거리·피해 규칙을 사용한다.

## 5. 피해·쿨다운·피드백

종족별 최대 체력·이동 속도·근접 피해 배율, 실제 전투 숙련, 정신 지배 강화는 기존 상태를 재사용한다. 공격 시간과 타격 상태는 엔진이 기록한다. 렌더러가 장식용 애니메이션을 보여주었다는 이유로 피해나 경험치를 만들지 않는다.

UI는 적 목표의 이름·체력·현재 함선과 방, 접근 중 또는 근접 교전 상태와 다음 타격 시간을 표시한다. 유효 목표가 사라지면 대상 정보를 지운다. 아군 목록에는 종족을 표시한다. 타격은 짧은 공격 자세·타격선·체력 감소로 표현하며 일시정지 중에는 게임 시간에 묶인 전투 효과도 진행하지 않는다.

전사자는 점유·예약·공격 대상에서 제외한다. 함선 승무원 전멸·의료·화재·질식·텔레포트·승무원 경험치의 기존 결과는 유지한다.

## 6. 다른 시스템과의 상호작용

- **수리·진화:** 목적지 타일에 도착한 뒤 방의 손상과 화재를 처리한다. 적이 가까이 있으면 교전과 작업 우선순위를 적용한다.
- **의료:** 실제 의료실 안의 우호 인원을 치료한다. 의료실 해킹의 역효과도 유지한다.
- **텔레포트:** 설치된 송신실 안의 실제 인원을 보내고 도착 방의 유효한 타일을 배정한다. 귀환도 본함 수용 공간을 검사한다.
- **정신 지배:** 물리 위치와 원래 소유 배열은 유지하며 유효 진영과 행동만 바꾼다. 변경된 진영에 맞춰 목표를 다시 판단한다.
- **담당실 복귀:** 방 중심 겹침 대신 각 인원이 사용할 수 있는 타일을 선택한다.
- **함선 파괴·도주:** 적선에 남은 승조원 손실 규칙을 유지한다.

## 7. 저장과 이전 좌표

새 저장에는 타일 위치·경로·진행 중 이동·목적지 예약·공격 목표·대기 시간을 포함한다. 로더는 방 범위, 인접 관계, 문 연결, 물리 함선, 대상 참조를 검증하고 실패하면 현재 항해를 유지한다.

v6 이전의 연속 좌표와 방 중심 이동은 별도 호환 처리를 거친다. 로드 순간 기존 좌표·체력·능력·경로를 유지하고 재생 시 타일 중심으로 합류한다. 이 초기 정렬과 새로 발행한 사각 격자 이동 명령은 구분한다. 과거 저장의 위치를 바꾸지 않았다고 주장하면서 실제로는 새 항해를 만드는 방식은 사용하지 않는다.
