# FTL 역기획 + STARWARD v7 통합 산출물

## 바로 실행

1. ZIP을 모두 압축 해제합니다.
2. 최상위 `PLAY.html`을 Chrome, Edge, Firefox 등 최신 브라우저로 엽니다.
3. 함선과 난이도를 고릅니다. **시스템 설치**에서 빈 구획과 설치 비용을 확인할 수 있습니다.
4. **2D / 3D**, **현대 SF / 로우폴리 / 청사진**을 고르고 출항합니다.
5. 첫 전투는 일시정지입니다. 무기를 선택해 적 방을 조준하고 **Space / 전투 시작**을 누릅니다.
6. 수동 모드는 **발사/예약**으로 한 번 발사하고, 자동 모드는 충전마다 반복 발사합니다.

CSS와 JavaScript 5개를 하나의 HTML에 담았습니다. 게임 실행에 npm 설치나 인터넷 연결은 필요하지 않습니다. 웹 실행: https://starward-last-signal.taru00.chatgpt.site

## 이번 버전의 핵심

**빈 슬롯과 확장:** 새 함선은 여섯 핵심 시스템 방과 여섯 보조 구획을 사용합니다. 처음 네 마운트가 열려 있으며 드론·텔레포터·시작 능력 외에 빈 슬롯 하나가 있습니다. 나머지는40/60스크랩으로 확장합니다. 새 설비는 실제 방에 단계1·전력0으로 설치합니다. 설치 뒤 전력 연결이 필요합니다. 설치·확장·강화는 출항 준비·지도·상점·보상 화면에서 실행합니다.

**승조원 이동과 전투:** 승조원 선택 → 사각 타일을 눌러 이동합니다. 상하좌우·실제 문·점유와 예약을 사용합니다. 같은 함선의 적 승조원을 선택하면 접근 후 근접 공격하며, 다른 타일로 이동을 명령하면 퇴각합니다. 회복·수리·전송 집결도 실제 이동합니다.

**3D와 스타일:** 높이가 있는 함선·시설·승조원과 원근 카메라를 사용합니다. WebGL을 우선 사용하며 GPU가 없는 환경에서는 호환3D가 같은 조작을 제공합니다. 드래그로 회전, 휠로 확대·축소, 초기화 버튼으로 시점을 복구합니다. 2D/3D 전환과 그래픽 스타일 변경은 항해·체력·조준·이동·충전 상태를 유지합니다.

**기존 캠페인:** 8섹터 월드, 지역별20비콘, 반군 전선, 자체15이벤트와3종 연속 퀘스트, 최종 기함3단계, 텔레포터·드론·해킹·정신 지배·배터리·은폐, 장비·화물·상점·승조원 숙련이 이어집니다.

## 파일 구성

- `PLAY.html`: 최종 단일 HTML 실행판. 소스의 `dist/STARWARD_Offline.html`과 동일합니다.
- `ftl_reverse_design/`: 원작 FTL 시스템별 한국어 역기획 MD24개.
- `STARWARD_Source/dist/`: 실행 HTML, CSS, 데이터·엔진·캠페인·3D 렌더러·화면 JavaScript.
- `STARWARD_Source/docs/`: v3~v7 구현 문서16개. 새 규칙은v7 문서를 우선합니다.
- `STARWARD_Source/tests/`: 자동 규칙 검사, 공개 명령 완주 정책, 구버전 저장 fixture, 기계 판독 검증 결과.
- `STARWARD_Source/scripts/`: 오프라인 HTML과 소스 ZIP 재생성 도구.
- `STARWARD_Source/README.md`, `CHANGELOG.md`: 상세 조작·규칙·변경 이력.
- `BUILD_INFO.json`: 소스 커밋, 실행 파일 SHA-256, 검증 수치.

## 저장 호환

기존 v6 저장은8섹터 진행을, v1~v5 저장은 원래3섹터 진행을 유지합니다. 예전 도면과 장비를 다시 만들지 않습니다. 물리적으로 새로 추가된 빈 시스템 구획은 **새 출항**에서 사용하세요. 이전 연속 좌표는 가져오기 직후 유지하며 전투 재개 시 호환 이동으로 타일 중심에 정렬합니다.

웹과 로컬 파일의 저장 공간은 다를 수 있습니다. **저장 파일 관리 → JSON 내보내기/가져오기**로 항해를 옮기세요. 로더가 손상되거나 일관성 없는 상태를 거부하면 현재 항해는 유지합니다.

## 검사와 범위

최종 시험 수치·완주 결과·실제 브라우저에서 확인한 항목은 `tests/verification-v7.json`과 `docs/v7_validation.md`에 있습니다. 규칙 시험은 제한된 전술 상황을 준비할 수 있습니다. 별도 완주 정책은 자원·HP·좌표·승리 결과를 직접 주입하지 않고 공개 명령과 실제 전투 틱으로 진행합니다. 자동 정책의 성공은 일반 플레이어 승률을 뜻하지 않습니다.

STARWARD는 FTL의 핵심 구조를 참고한 자체 게임입니다. 원작의 전체 함선·종족·수백 사건·모든 장비·해금·수치를 동일하게 복제한 제품은 아닙니다. 슬롯 확장은 미리 배치된 마운트를 해제하며 자유로운 선체 건조 도구는 아닙니다. 실제 모바일 기기와 모든 브라우저를 검증한 것은 아닙니다.

## 개발용 실행과 재생성

```bash
cd STARWARD_Source
python3 -m http.server 8000 --directory dist
```

`http://localhost:8000`을 엽니다. Windows에서는 `python3` 대신 `py -3`를 사용할 수 있습니다.

```bash
node --test tests/*.test.cjs
node tests/playthrough.cjs
node scripts/build-offline.cjs
python3 scripts/package-source.py
```
