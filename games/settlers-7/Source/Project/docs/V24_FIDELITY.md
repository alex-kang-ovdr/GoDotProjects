# 원작 일치도와 플레이용 보완값

## 이번에 연결한 원작 참고 구조
본관/작업장, 3개 슬롯, 식량별 산출 배율, 귀족 작업장의 식량 필수 조건, 작업자와 창고 소속 운반자 분리, 모집 장소와 단계, 1.08 비용 변경, 성직자를 이용한 경쟁 연구, 상인별 왕복 거래 횟수, 매수·포교 원식 계수를 연결했다. 참고 문헌과 커뮤니티 후보의 근거 등급은 실행 프로필에 남아 있다.

## 미확인 항목을 채운 실행 선택
생산·건설·모집·교역·연구 시간, 운반 속도, 창고 총량 600, 버퍼 9, 원정 전투 HP·공격력·소모 한도, 기본 배치와 초기 재고, 6지역 지도, 기술별 모집 요구, 연구 재입찰 증가량, 거래 제안 9개, 정수 포교 올림, 6점/30초 승리는 원작 확정값이 아니다. 데이터 탭은 이를 별도로 표시한다.

운반량 3개를 선택했지만 v23에서 보존한 3/5 충돌을 해소했다는 뜻이 아니다. 작업자 운반량에도 같은 값으로 단순화했다. 창고 용량은 원작 건물 단계표의 재현이 아니라 안전한 실행 버퍼이며 승급 후에도 전체 물류 용량 재현은 미완료다.

블랙스미스·코킹 입력의 모호한 목재 표기는 실행 프로필에서 통나무로 선택했다. 정본의 null·후보 목록을 덮어쓰지 않는다. 생산량 후보가 적용되었어도 정확한 생산 주기까지 복원된 것은 아니다.

## 미구현
원작 12개 캠페인·전체 이벤트·24개 기술 전체·연구판 연결·원작 전체 교역판·전 승리 조건·장군·성직자 특수 효과 전부·지질학자·협동 멀티플레이·History Edition 판본 재현은 없다. 그래픽은 자체 Canvas 도형이며 원작 아트가 아니다. 지도는 연속 좌표지만 장거리 군사 이동은 간선 도로 기반 군대 단위다.

## 기존 산출물과의 관계
v23 원본 ZIP과 JSON을 그대로 포함한다. 이전에 누적된 웹 프로토타입을 수십 단계 패치한 것이 아니라, 복원 정본을 바탕으로 검증 가능한 v24 공통 엔진에 기능을 통합한 새 실행 분기다. 이전 실행판은 원본 ZIP 내부에 보존되어 있다.
