# v26 변경 기록

## 구현
- 생산 정책을 지역·자원 단위로 추가했다. 상한 목표에 도달하면 새로운 배치만 중단하고 하한에서 재개한다.
- 출발 창고·도착 창고·자원별 반복 보급과 실제 3개 단위 물류를 연결했다. 같은 목적지·자원은 갱신한다.
- 목적지 입고 예약을 포함하여 초과 주문을 막고 활성 동일 자원 규칙의 유향 순환을 거절한다.
- 보급 해제는 미픽업 첫 구간만 해제한다. 중계 화물과 이미 픽업한 자원은 계속 인계한다.
- 일괄 수송은 1~100개를 하나의 원자적 주문으로 예약한 뒤 여러 운반 작업으로 나눈다.
- 운영 탭에서 생산망·창고별 재고·실시간 생산시설 위치·보급 상태를 탐색한다.
- WASD/방향키, 가운데 버튼, 우클릭 취소, 두 손가락 이동·확대와 잘못된 건설 입력 방지를 추가했다.
- 이동 보간은 화면에만 적용한다. 저장과 전투/경제 틱은 변경하지 않는다.
- 지역/선택/관리자원별 입력값 유지 범위를 분리했다. 도움말이 기존 일시정지를 해제하던 동작을 수정했다.
- 새 게임 확인, 숨겨진 탭의 일시정지, v24·v25 저장 읽기와 v26 정책 보존을 추가했다.

## 변경하지 않은 것
원작 참고 정본 및 기존 경제/전투/승리 수치 파일. 기본 지도 크기, 2D 렌더러 종류, 기존 6개 지역, 연구 6종, 군대 집계 전투 구조.

## 저장 계약
v26은 operations.version=1을 가진다. 이전 버전 읽기는 재고를 재계산하거나 원장을 생성하지 않는다. 이전 형식에 임의로 붙인 operations 객체는 적용하지 않는다. 새 저장은 역방향 호환되지 않는다.
