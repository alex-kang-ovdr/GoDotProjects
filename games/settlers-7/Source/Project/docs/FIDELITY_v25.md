# 원작 일치도와 실행 완성도의 구분

이번 수정은 새 원작 수치 복원이 아닌 v24 코드의 실행 안정성 개선이다. reference_master_v23.json, 원작 복원 ZIP, playable_profile.json, game/data.js는 v24 입력과 바이트 동일하게 유지한다.

기존 `documented`·`community_candidate`·`playable_override` 근거 등급은 그대로다. 기록된 수치가 같아도 완전한 원작 동작 복원이 되었다는 뜻은 아니다. 특히 생산시간, 전투 집계, 연구비·시간, 포교 올림, 시장 거래율, 지도·점수 조건은 이전 실행용 정책이다.

v25 신규 규칙 중 도로 BFS, 생산 진단 순서, 최근60초 집계, 일괄 모집, 점령 후 소속 이전·훈련 취소·화물 회수·안전 귀환, 저장 백업은 프로젝트 설계다. 원작 UI나 포로·소유권 처리 규칙을 확인했다는 주장을 하지 않는다.

전체 캠페인·연구판·교역판·장군·3D·개별 병사 마이크로 제어는 범위 밖이다. 기존 2D 경제·전략 게임플레이의 오류와 조작 비용을 줄이는 데 집중했다.
