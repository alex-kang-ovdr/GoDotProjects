# v27 검증 범위와 재현

## 검사 계층

| 계층 | 수행 내용 | 증명하지 않는 범위 |
|---|---|---|
| 공통 엔진 | 명령·이동·전투·재고 수지·저장·승리 시나리오 | 브라우저 렌더링·실기기 조작 |
| UI 순수 템플릿 | 실제 엔진 사전 검사와 화면 문자열·초안 처리 연결 | DOM 이벤트·레이아웃·Canvas 표시 |
| 브라우저 | 배포 HTML에서 실제 입력·클릭·다운로드·가져오기 | 실행하지 못한 경우 어떤 화면 동작도 검증됐다고 집계하지 않음 |
| 빌드·출처 | 배포 HTML과 소스의 정확한 포함 관계, 변경 전후 해시, 원작 참고 데이터 보존 | 원작 규칙의 새로운 고증 |

최종 수치와 상태는 `reports/check_run.json`, `reports/release_summary.json`, `Implementation_Report.html`에서 확인합니다. `engine_tests`, `v25_engine_tests`, `v26_engine_tests`라는 이름은 과거 버전만 검사했다는 뜻이 아닙니다. 이 패키지의 v27 공통 엔진으로 다시 실행하는 회귀 검사입니다.

## 주요 신규 위험과 검사

1. 전 병종의 출발·이동·도착 인원 보존, 중간 지점에서 양쪽에 존재하지 않음.
2. 명시한 군사 편성만 출발, 기수 단독·병력 부족·총원 초과·성벽 조건 실패 시 상태 불변.
3. 출발 전 조회가 재고·인원을 바꾸지 않음. 오래된 조회 뒤 명령 재검사로 중복 출발 차단.
4. 여러 소유 지역을 통과하는 경로, 중립 지역 단절, 소유권 변경 뒤 안전한 귀환.
5. 교전 중 출발 거절, 모집 완료와 이동 증원의 실제 방어 합류, 기존 병사의 HP·탄약 보존.
6. 원정 취소 시 순간 이동 방지와 현재 위치 보존.
7. 이동·귀환·방어전 도중 저장 후 동일 진행 시 직렬화 결과 일치.
8. 과거 v24·v25·v26 운송 중 픽스처의 재고·예약·운반자·수지 원장 보존.
9. 잘못된 편성·전투 명단·저장 형식 거절.
10. 귀환 창고가 가득 찼을 때 화물·상인 보존, 대기 표시, 공간 확보 후 정상 완료.

## 현재 환경의 브라우저 제한

이번 실행 환경의 Chromium은 시작 단계에서 `socket() failed: Operation not permitted`로 종료되었습니다. v27의 브라우저 시나리오 20개는 작성했고 Python 문법을 확인했지만, 페이지를 열기 전 차단되었으므로 **실행된 브라우저 검사 수는 0개**입니다. 같은 실행 파일을 쓰는 이전 브라우저 suite도 실행 차단으로 기록합니다.

실제 화면·모바일 뷰포트·키보드 DOM 이벤트·브라우저 저장 지속성·파일 직접 열기는 이번 릴리스에서 검증 완료로 주장하지 않습니다. 과거 버전의 스크린샷이나 통과 기록을 현재 결과에 더하지 않습니다. 순수 템플릿 검사도 브라우저 검사와 별도 집계합니다.

브라우저 suite는 허용된 환경에서 Python Playwright와 Chromium으로 재현할 수 있습니다. 게임 파일 자체에는 이 도구가 필요하지 않습니다.

```bash
python tools/run_checks.py
# 브라우저가 실행 가능한 환경에서:
python tools/run_checks.py --browser
python tools/package_release.py
```

선택적으로 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`로 v27 브라우저 suite의 실행 파일 경로를 지정할 수 있습니다. 환경 정책을 우회하기 위한 설정은 제공하지 않습니다.

## 빌드와 결과의 연결

검사 시작 시 단일 HTML을 새로 빌드합니다. CSS·데이터·엔진·UI를 정확히 포함하는지 비교하고 외부 script·stylesheet 참조가 없는지 확인합니다. 검사 전후 런타임·테스트·픽스처·계약 파일의 SHA-256이 같아야 합니다.

패키징은 검사 대상 소스와 결과 JSON의 해시를 다시 비교합니다. 파일이 이후에 바뀌었거나 실패 결과가 있으면 패키징을 거절합니다. 브라우저 차단은 실패 시나리오를 통과로 바꾸지 않고 별도 미검증 상태로 노출합니다. ZIP은 CRC 및 파일별 SHA-256 검사를 거친 뒤 출력합니다.
