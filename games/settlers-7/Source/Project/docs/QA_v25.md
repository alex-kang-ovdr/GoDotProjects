# 검증 범위와 제한

정본 결과는 reports/engine_tests.json, v25_engine_tests.json, browser_tests.json, v25_browser_tests.json이다. 기존 테스트를 실행하지 않고 파일만 복사한 것이 아니라 최종 소스에서 다시 수행했다.

엔진 검사는 정상 비용 승리, 생산·물류 수지, 새 점령/귀환 경계 조건, v24 마이그레이션, 30분 경제와3개시드의 자동 경기, 의도적으로 잘못 만든 저장 파일을 포함한다. 구성된 희귀 상황은 일부 자원과 소유권을 직접 설정한 테스트이며 일반 플레이 영상으로 해석하면 안 된다.

브라우저는 /usr/bin/chromium headless + page.set_content로 단일 파일 전체를 로드했다. 실제 DOM 클릭·선택·입력·파일 업로드를 사용한다. 상태 준비나 긴 시간 진행 일부는 게임이 공유하는 엔진 API를 호출한다. 891×411과412×891은 화면 크기만 모사하며 모바일 OS·파일 앱·터치 하드웨어 검증이 아니다.

환경은 localhost 탐색을 ERR_BLOCKED_BY_ADMINISTRATOR로 거절했다. file:// 탐색, Chrome/Edge 사용자 설치본, 실제 출처에 저장한 localStorage의 재시작 지속성은 미검증이다. UI의 저장 실패 안내와 게임 유지, 공통 백업 함수의 메모리 어댑터 회전·용량 예외는 검사했다.

브라우저 페이지 오류는 검사 실행에서0개이며 실행판은 네트워크 요청을 만들지 않았다. 이 결과가 모든 하드웨어·모든 상태에서 오류0개를 보장하지는 않는다. 이전 검사에서 겪은 테스트 셀렉터/환경 탐색 문제를 수정한 뒤 최종 결과를 재생성했다.
