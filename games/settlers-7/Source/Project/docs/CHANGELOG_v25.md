# v24 → v25 변경 내역

## 기능이 아니라 잘못된 결과를 수정한 항목
1. `capture`: 소유자가 있는 지역이면 모두 수도로 간주하던 조기 종료 조건을 수정했다. 적 수도는 초기 소유자별 0/5번 지역이다. 일반 지역은 건물·창고·작업장·인력·예약을 함께 처리한다.
2. `stepExpeditions`: 방어군 손실 계산이 성직자·상인까지 삭제하던 문제를 수정했다. 전투 중에는 군사 병종만 갱신한다. 점령 완료 시 지역 인원 해산은 별도의 실행 정책이다.
3. 기수만 남은 방어군 때문에 점령이 끝나지 않던 문제를 수정했다.
4. 철수 시 이동 구간 진행률을 0으로 초기화해 이전 타일로 튀던 문제를 수정했다. 진행 중인 한 구간을 마친 뒤 새 경로로 이동한다.
5. 출발지가 점령당한 교역·원정의 복귀 대상이 없거나 적 소유가 된 경우 아군 지역을 다시 선택한다.
6. 완제품 출고가 가장 가까운 가득 찬 창고만 계속 선택하던 문제를 수정했다.
7. 모집 취소와 귀환 물자가 창고 공간·입고 예약을 무시하고 재고를 밀어 넣던 문제를 수정했다.
8. 주기적인 패널 재생성으로 재고 펼침·출정 인원·일부 선택값이 초기화되던 문제를 수정했다.
9. 도움말 후 ‘이어서 하기’의 콜백을 영구적으로 바꾸던 흐름을 정리했다.

## 플레이 편의
현황·진단 탭, 5단계 목표 안내, 건설 유효성 미리보기, 두 점 도로, 일괄 모집, 지역 생산 제어, 지도 확장, 저장 백업을 추가했다. 목표 안내는 튜토리얼 안내이며 원작 캠페인 이벤트가 아니다.

## 변경하지 않은 것
원작 참고 정본·밸런스 수치·생산 레시피·그래픽 종류·지도 크기. 기존 원작 미확인 항목을 새로 검증했다고 주장하지 않는다.
