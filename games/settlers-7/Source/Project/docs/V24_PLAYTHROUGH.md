# 검증된 플레이 시나리오와 점검 범위

테스트 스크립트의 `Real-cost new-game to victory without resource grants`와 브라우저 `Complete match reaches visible victory using normal costs`가 아래 경로를 실행한다. 결과의 통과 여부는 reports JSON에 기록한다.

AI를 끈 새 게임에서 수도 인접 들판을 상인으로 매수하고 철의 고개에는 초기 병력 6명을 파견한다. 수도에서 수련자 5명을 순차 모집한다. 성직자가 준비되면 공학과 위생 연구를 시작한다. 판자를 파는 상단을 세 차례 왕복시킨다. 경제는 이 동안 계속 생산하며, 영토·황제·연구·거래 점수로 승리 유지 조건에 도달한다. 이 경로는 개발자 자원 지급을 사용하지 않는다.

단위 테스트에는 통제를 위해 빈 시나리오에 자원을 넣는 fixture가 있다. 그 테스트를 추가 자원 없는 전체 플레이로 표현하지 않는다. AI 시험도 유한 시나리오 회귀이며 모든 플레이 전략을 보장하지 않는다.

브라우저 검사: 환영 화면, 건물 카드와 지도 클릭, 세 작업장 부착, 네 번째 슬롯 차단, 식량 변경, 생산 재고, 검사 도구, 근거 검색, 모집·취소, 연구, 교역, 매수, 중계 운송, JSON 다운로드와 파일 가져오기, 깨진 저장 거부, 일시정지, 카메라, 승리, 가로·세로 모바일 폭. 브라우저는 set_content로 실제 HTML 바이트를 읽는다. file:// 직접 실행과 실기기 성능 시험은 별도다.
