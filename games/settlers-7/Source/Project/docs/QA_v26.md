# v26 검증 방법

자동 검사 결과는 reports의 JSON에 테스트별로 수록한다. 엔진 60+49+33, 브라우저 34+26+31개이며 같은 배포 소스에서 실행한다. 과거 테스트의 버전 상수, 저장 키, 새 탭 수만 새 런타임 계약으로 조정했다. 참/거짓 검사를 제거해서 맞춘 것이 아니다.

신규 테스트는 재고 목표 히스테리시스, 이미 시작된 식량 배율 배치, 출고 지속, 수동 정지, 지역 범위, 입력 수요 억제, 예약 중복, 규칙 수정, 순환 차단, 배차/공간 부족, 첫/중간 구간 취소, 점령, 저장 이어하기, 잘못된 데이터, 반복 운송, 생산망 조회를 포함한다. 15분 4개 물류 경로와 저장 후 20초의 일치도 검사를 포함한다.

브라우저는 실제 DOM 클릭/입력/다운로드/파일 업로드와 Chromium CDP 터치 입력이다. 일부 희귀 상태는 공유 엔진으로 준비하며 별도 테스트용 경제·물류 엔진은 없다. 모바일 뷰포트 테스트는 물리 장치의 터치 반응·배터리·GPU 성능·파일 앱 실행 검증을 대신하지 않는다.

`file://` 탐색은 이 환경에서 실제 시도했고 `ERR_BLOCKED_BY_ADMINISTRATOR`로 실패했다. `reports/environment_limits.json`에 기록한다. 실제 브라우저 출처 기반 저장 지속성은 미검증이며 백업 함수는 기존의 명시적인 MemoryStorage 어댑터로 검사한다.

전체 원작과 동일한 수치/플레이 결과 검사, 모든 지도·모든 경로의 완전 탐색, 전체 입력 퍼징, 저사양 모바일의 프레임 성능 보장은 이번 완료 범위가 아니다.
