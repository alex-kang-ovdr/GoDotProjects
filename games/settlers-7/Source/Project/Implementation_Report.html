01 / GAMEPLAY확보한 영토가 다음 행동의 출발점이 됩니다.

두 번째 지역을 확보한 뒤 수도의 인원을 전방으로 옮길 수 있습니다. 병력은 정복과 방어에, 상인과 성직자는 기존 매수·포교 등 각자의 행동에 사용합니다. 목적지에 필요한 시설과 자원은 기존 조건대로 준비해야 합니다.

STEP 01

목적지와 편성 선택

원정 탭에서 아군 지역을 목적지로, 수도를 출발지로 선택합니다. 병종별 가용·선택·잔류 수량을 확인하고 보낼 인원을 정합니다.

STEP 02

도로를 따라 이동

병력·인원 이동 출발를 누르면 인원이 출발지에서 빠집니다. 부대 카드의 지도 보기로 실제 위치와 이동 경로를 확인합니다.

STEP 03

도착 후 증원·다음 원정

목적지에 도착한 인원만 주둔군에 합류합니다. 방어전이 진행 중이면 방어에 참여하고, 전투가 끝난 뒤 다음 인접 목표로 출정할 수 있습니다.

이 흐름은 기능 설명입니다. 실제 브라우저 실행 화면을 검증했다는 표현이나 과거 버전의 스크린샷을 사용하지 않았습니다.

02 / REPRODUCED DEFECTS인원이 두 곳에 존재하거나 사라지던 문제를 수정했습니다.

v26에서 재현

방어군 10명에서 5명 출정 → 다시 10명

교전 중 창병 10명 중 5명을 다른 곳으로 보낸 뒤 다음 전투 갱신에서 과거 방어 명단의 10명이 복원되었습니다. 떠난 5명까지 남아 중복되었습니다.

수정: 교전 중인 출발지의 출발 명령을 거절하고, 전투 갱신을 실제 주둔군과 동기화합니다. 거절한 명령은 인원·자원을 바꾸지 않습니다.

v26에서 재현

방어 중 합류한 대포 → 다음 갱신에서 소실

새 병력이 주둔군에 추가되어도 오래된 전투 명단이 주둔군을 덮어쓰면서 사라질 수 있었습니다.

수정: 모집 완료·이동 도착·귀환 인원을 살아 있는 방어 명단에 반영합니다. 기존 병사의 남은 HP와 탄약, 민간 인원은 보존합니다.

03 / IMPLEMENTED BEHAVIOR명령·화면·저장이 같은 규칙을 사용합니다.

변경실제 동작조건·경계
정확한 군사 편성창병·총병·기병·대포·기수의 수량을 직접 정합니다. 총인원 빠른 편성도 병종별 초안으로 확인합니다.총 1~35명. 기수 단독 공격은 거절합니다. 선택한 병력이 부족하면 전체 출발을 거절합니다.
아군 재배치전체 11종 인원이 소유 도로를 따라 이동합니다. 여러 아군 지역을 경유할 수 있습니다.출발과 목적지는 다른 아군 지역이어야 합니다. 도착하기 전에는 목적지 주둔 인원에 추가하지 않습니다.
출발 사전 검사군사·매수·포교·재배치의 가능 여부, 실패 이유, 필요 인원·물품, 경로, 이동 시간을 표시합니다.조회는 직렬화 상태를 바꾸지 않습니다. 실제 명령이 비용·인원·경로를 다시 검사합니다.
성벽 조건실제로 선택한 부대에 총병 또는 대포가 있는지 검사합니다.다른 지역이나 출발지에 남긴 원거리 병력으로 조건을 대신 충족하지 않습니다.
지도·상태 연결금색 점선은 예정 경로, 파란 선은 이동 경로입니다. 카드에서 현재 위치를 찾아가거나 귀환을 명령합니다.ETA는 이동 예상 시간입니다. 전투 시간·승률은 계산했다고 표시하지 않습니다.
소유권 변경·취소목적지·현재 경유지를 잃거나 소유 도로로 목적지에 도달할 수 없으면 아군 지역으로 귀환합니다. 우회 가능한 소유 도로가 있으면 이동을 이어갑니다. 취소 시 현재 위치와 진행도를 유지합니다.적 영토에 인원을 잘못 넣지 않습니다. 안전한 귀환지가 없으면 대기합니다.
귀환 화물창고가 가득 차면 귀환 물품 입고 대기로 표시하고 화물·인원을 유지합니다.입고 대기 중 ETA는 비워 둡니다. 공간이 생기면 실제 입고와 상인 귀환을 완료합니다.
입력 안정성출발지·목적지별 초안, 감소한 가용 인원 안내, 전체 모집 비용 표시를 연결했습니다.도움말 뒤의 Space 재개를 막고, 저장 복원 성공 후 오래된 배치 도구와 초안을 정리합니다.

v26의 생산 목표·반복 보급·일괄 물품 운송·생산망 탐색과 기존 건설·연구·교역·승리 판정은 유지했습니다. 새 재배치는 인원을 이동시키며, 물품 보급은 기존 창고 운송을 사용합니다.
