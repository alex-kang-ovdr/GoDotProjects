# 세틀러 7 v25 — 플레이 안정성·건설 UX·운영 진단 개선

## 실행
`Settlers7_Play_v25.html`을 브라우저로 엽니다. Windows에서는 `Start_Game.bat`도 사용할 수 있습니다. 단일 HTML에 게임 데이터·엔진·UI가 모두 포함되어 있고 외부 서버·CDN·패키지 설치가 필요하지 않습니다. 분리 소스의 진입점은 `game/index.html`입니다.

모바일 파일 앱은 HTML을 실행하지 않고 미리보기만 제공할 수 있습니다. 이 경우 PC 브라우저로 열거나 정적 웹서버에 폴더를 올려 사용하세요. 이 패키지는 공개 호스팅 URL을 제공하지 않습니다.

## 주요 개선
| 구분 | v25 동작 |
|---|---|
| 점령 | 일반 점령지를 빼앗았다는 이유만으로 즉시 승리하지 않습니다. 수도 점령과 점수 유지 승리는 별도로 판정합니다. |
| 소유권 | 점령지 건물·창고·작업장·소속 인력의 소유권을 함께 이전합니다. 관련 운송 예약을 정리하고 이미 픽업한 화물은 보존합니다. |
| 원정 귀환 | 출발지가 점령당하면 남아 있는 아군 지역으로 귀환합니다. 적 창고에 물자·병력을 반환하지 않습니다. |
| 물류 | 가장 가까운 창고가 가득 찼으면 연결된 다른 창고로 완제품을 배송합니다. 환불·귀환 화물이 용량을 넘지 않도록 합니다. |
| 건설 | 지도에 건설 가능·불가 미리보기와 이유를 표시합니다. 창고와 단절된 도로 옆 건설도 거절합니다. |
| 도로 | 시작점과 끝점을 클릭하면 건물·물·비소유 영토를 피해 연결합니다. 실패한 요청은 일부만 건설하지 않습니다. |
| 현황 | 최근 최대 60초의 생산량/분, 창고 순변화/분, 가용 재고·출고 예약·운반 중 수량을 표시합니다. |
| 진단 | 공급 부족·예약 경쟁·식량 정책·도로 단절·창고 포화·자원 고갈을 구별하고 지도 위치와 상위 생산 시설을 안내합니다. |
| 편의 | 다음 할 일 안내, 1·3·5명 일괄 모집, 지역 생산 정지/재개, 지도 넓게 보기를 추가했습니다. |
| UI 갱신 | 재고 펼침 상태와 출정 인원 등 입력값이 0.5초 주기 갱신으로 초기화되지 않도록 수정했습니다. |
| 저장 | v24 저장을 재고 변화 없이 읽고 v25 형식으로 저장합니다. 로컬 저장이 가능한 환경에서 현재 저장 + 이전 2개 백업을 보관합니다. |

## 조작
지도 드래그로 이동하고 휠 또는 +/−로 확대·축소합니다. Space는 일시정지, Esc는 건설·도로 계획 취소, B는 건설 탭입니다.

**처음 시작:** 현황 탭의 ‘다음 할 일’에서 주택·생산·영토·교역·연구를 확인하세요. 자원·인구·모집 대기열이 부족한 일괄 모집은 전부 거절하며 일부만 구매하지 않습니다.

**두 점 도로:** 건설 → 연결 도로 · 두 점 → 기존 소유 도로(또는 바로 옆) 클릭 → 끝점 클릭. 미리보기 후 확정합니다. 기본 간선 도로는 철거할 수 없습니다.

**재고 수치:** 가용 = 창고 재고 − 출고 예약입니다. 생산/분은 작업장에서 실제 생성한 수량이며 창고에 도착한 양과 다릅니다. 순변화/분은 창고 재고의 변화입니다. 작업장 버퍼·원정대 예치 물자는 이 수치에 혼합하지 않습니다. 시간 단위는 시뮬레이션 시간이며 실행 속도에 따라 현실 시간이 달라집니다.

## 저장·복원
v24와 v25 JSON 저장을 읽을 수 있습니다. v25 저장은 v24 실행판에서 읽을 수 없습니다. 저장 오류가 발생해도 진행 중인 게임을 먼저 덮어쓰지 않습니다.

브라우저 저장이 허용되는 환경에서 약 15초마다 자동 저장을 시도합니다. 동일한 상태는 백업을 회전하지 않습니다. 현황 탭에서 이전 자동 저장 2개를 불러올 수 있습니다. 브라우저가 저장 접근을 제한하면 **내보내기**로 JSON 파일을 보관하세요. 파일을 다른 경로로 옮기면 같은 브라우저라도 이전 저장소에 접근하지 못할 수 있으므로 JSON 사본을 권장합니다.

`profile`은 밸런스·경제 데이터 호환성을 나타내므로 기존 v24 프로필 ID를 유지합니다. 실제 저장 포맷과 런타임 버전은 25입니다. `data/runtime_v25.json`에 구분을 기록했습니다.

## 검증
- 기존 공통 엔진 회귀 검사: 60 / 60 통과
- v25 엔진·저장 회귀 검사: 49 / 49 통과
- 기존 브라우저 조작 회귀 검사: 34 / 34 통과
- v25 브라우저 조작 검사: 26 / 26 통과
- 합계: 엔진 109개 + 브라우저 60개, 실패 0개

정상 비용으로 승리하는 기존 시나리오, 30분 AI 비활성 경제 시뮬레이션, 3개 시드의 AI 경기 결과, 일반 지역 재점령, 화물·예약 보존, 잃은 출발지에서 귀환, 도로 미리보기, 입력 유지, v24 저장 읽기를 검사했습니다. 일부 상태·희귀 조건 검사는 의도적으로 구성한 테스트 상황이며 모든 게임 상태를 전수 검사했다는 의미는 아닙니다.

브라우저는 배포 HTML 내용을 **Chromium의 `page.set_content`로 로드**해 검사했습니다. 환경의 `ERR_BLOCKED_BY_ADMINISTRATOR` 제한으로 localhost 탐색이 차단되었고 file:// 직접 실행·실제 출처 기반 localStorage 지속 저장은 검증하지 못했습니다. 자동 저장 회전 로직은 실제 UI와 공유하는 함수에 명시적인 메모리 Storage 어댑터를 연결하여 별도 검사했습니다. 이를 실제 브라우저 저장 성공 검사로 세지 않습니다. 모바일 891×411 / 412×891은 뷰포트 검사이며 실기기 검사가 아닙니다.

## 원작과의 차이
v23 정본 JSON, 원본 복원 ZIP, v24 밸런스 JSON 및 data.js를 변경하지 않았습니다. 생산시간·전투 능력치·연구 비용·승리 조건 등 기존 실행용 보완값은 계속 원작 확정값이 아닙니다.

v25의 도로 계획·진단·백업·점령 후 경제 처리 역시 구현 정책입니다. 점령된 지역의 모집 대기열은 취소되고 이미 지불한 비용은 반환하지 않습니다. 가동 중인 생산 배치는 새 소유자에게 승계합니다. 지배권 상실로 취소된 연구는 남아 있는 아군 지역에 성직자를 되돌리며, 남은 지역이 없으면 반환하지 않습니다. 거주 성직자·상인 등 지역 인원은 점령 시 해산합니다. 이는 원작 포로·이주 규칙 복원이 아닙니다. 취소된 운송의 화물을 가진 운반자는 회수 경로에서만 적 영토 통과를 허용하는 단순화가 있습니다.

원작 전체 캠페인·연구판·장군·History Edition 고증, 개별 병사 조작과 3D 그래픽은 이번 범위에 포함하지 않습니다. 기존 2D 지도와 군대 단위 전투 구조를 개선한 버전입니다.

## 구성
- `game/`: 공통 엔진·UI·스타일·컴파일 데이터
- `reference/`: 변경하지 않은 v23 원작 참고 자료, 이전 README
- `data/`: 경제 실행 프로필·v25 런타임 정보
- `docs/`: 변경·구현·검증·원작 차이 설명; V24_ 문서는 과거 자료
- `tests/`: 실행 가능한 테스트, 실제 v24 운송 중 저장 예제
- `reports/`: 결과 JSON·화면·원본 보존 비교
- `SHA256_MANIFEST.json`: 파일별 SHA-256
