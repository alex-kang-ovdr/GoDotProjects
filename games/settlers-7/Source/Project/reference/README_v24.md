# 세틀러 7 v24 — 복원 데이터 적용 웹 실행판

## 바로 실행
`Settlers7_Play_v24.html`을 압축 해제한 뒤 브라우저로 엽니다. 이 파일 하나에 데이터·엔진·그림·UI가 모두 포함되어 있습니다. 별도 서버, 설치, 로그인, CDN, 네트워크 API가 필요하지 않습니다. 분리 소스로 실행하려면 `game/index.html`을 사용합니다.

모바일 파일 앱은 HTML을 실행하는 대신 미리보기만 보여줄 수 있습니다. 이때 PC 브라우저에서 열거나 정적 웹서버에 폴더를 올려 사용하세요. 이 패키지에는 공개 배포 URL이나 호스팅 서비스가 포함되어 있지 않습니다.

## 플레이
- 마우스/터치 드래그: 지도 이동. 휠/＋/−: 확대·축소. Space: 일시정지. Esc: 배치 취소.
- 건설: 본관 선택 → 소유 지역의 도로 옆 빈 타일 클릭 → 본관의 작업장 부착.
- 본관별 작업장 최대 3개. 식량 정책과 출고·원료 운송이 실제 생산에 영향을 줍니다.
- 생산: 지역별 창고 재고·작업장 입력/출력·현재 병목·우선순위를 확인합니다.
- 원정: 중립 지역 선택 → 인접 소유 지역에서 군사·상단 매수·성직자 포교로 확장합니다.
- 연구: 성직자를 먼저 모집하고 6개 구현 기술을 선점합니다. 연구 중에는 경쟁 입찰이 가능합니다.
- 무역: 상인이 1·3·5건의 교역을 수행하고 돌아옵니다. 지역 간 물자는 창고 소속 운반자가 중계합니다.
- 승리: 이번 실행용 시나리오는 6점을 30초 유지하거나 적 수도를 점령하면 끝납니다. 원작의 모든 VP 규칙을 구현한 것이 아닙니다.

## 데이터 반영 범위
자원 26종, 본관·서비스 건물 10종, 부속 작업장 28종과 독립 우물 생산, 유닛 11종, 실행 기술 6종, 실험 교역 9종을 사용합니다. 초기 수도는 작동하는 기본 경제망을 제공합니다. 두 왕국과 4개 중립 지역으로 구성한 6지역 지도입니다.

일반 작업장의 식량 없음/일반/고급은 산출량 1/2/3배로 적용됩니다. 귀족 주택 작업장은 일반 식량이 기본 조건이며 고급은 2배입니다. 식량은 생산시간을 줄이지 않습니다. 식량 배율 적용에 필요한 1회 소비 단위는 실행 프로필에 명시합니다.

모집은 복원 자료의 비용과 확인된 1.08 변경 항목을 반영합니다. 건물 승급과 모집 시설 조건을 검사합니다. 장군은 구현하지 않았습니다. 전투는 개별 유닛 조작 RTS가 아니라 지도 위 군대 이동과 시간 경과형 병종 집계 교전입니다.

## 원작 정본과 플레이 설정
`reference/reference_master_v23.json`과 `reference/Settlers7_ReverseDesign_v23.zip`은 입력 자료를 변경하지 않고 보관합니다. `data/playable_profile.json`과 `game/data.js`는 그 정본에서 만든 별도의 **혼합 실행 프로필**입니다.

확정하지 못한 원작 생산시간, HP·공격 주기·방어, 이름별 연구비·연구시간·연결, 포교 비용 반올림은 이번에도 원작 복원값으로 주장하지 않습니다. 게임이 작동하도록 별도 값을 지정하고 데이터 탭에서 근거를 볼 수 있습니다. 커뮤니티 생산 수량 후보, 모호한 통나무 매핑도 실행 선택으로 표시합니다.

6개 기술만 기능 구현했습니다. 24개 기술 전체, 원작 12개 캠페인·이벤트 스크립트·전체 교역판·모든 승리 점수·장군·지질학자·History Edition 판본은 구현하지 않았습니다. 원본 그래픽이나 프로그램을 추출·재배포하지 않습니다.

## 저장
상단 저장은 브라우저 로컬 저장소를 사용합니다. 접근 제한 시 안내가 나오며, **내보내기**로 JSON을 보관하고 **불러오기**로 복원할 수 있습니다. 자동 저장은 게임 시작 후 약 15초마다 시도합니다. 운송 중 화물·작업·예약·연구·원정·난수 상태를 저장합니다. v12 등 이전 프로토타입 저장을 마이그레이션하지 않습니다. v24 프로필만 지원합니다.

## 개발·검증 재실행
게임 실행에는 개발 도구가 필요하지 않습니다. 아래는 선택 사항입니다.

```bash
node tests/engine.test.js
python tools/compile_data.py
python tools/build_standalone.py
# Playwright와 Chromium이 있는 환경에서 선택 실행
python tests/browser_test.py
python tools/package_release.py
```

`game/engine.js`는 Node 테스트와 브라우저가 공유합니다. UI용 우회 경제 엔진이나 테스트 전용 전투 로직을 사용하지 않습니다. 브라우저 테스트의 초기 준비 일부는 공개 엔진 명령을 호출하며, 파일 입출력·건설·식량·원정·연구·교역의 지정 단계는 실제 DOM 조작을 사용합니다.
