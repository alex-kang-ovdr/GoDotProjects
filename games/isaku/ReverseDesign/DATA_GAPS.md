# 데이터 공백 및 검증 필요 목록 (DATA GAPS)

공개된 원작 공략과 위키 자료의 교차 검증으로 핵심 방 그래프·아이템·퍼즐 DAG·등장인물·엔딩 분기는 복원 완료되었으나, 아래 6개 항목은 원작 실행 바이너리/스크립트 직접 역공학 자료가 부재하여 `[재구성안]` 또는 `[검증 필요]`로 명시한다.

| Gap ID | 항목 | 현재 상태 | 누락/불확실 사유 | 권장 보완 방법 |
|---|---|---|---|---|
| `GAP-01` | 정확한 행동 틱(Turn/Clock) 내부 상수 및 방 이동 가중치 | `[재구성안]` | 공개 공략은 "지체/오답 시 납치" 조건을 서술하지만 PC-98 스크립트 내부의 정확한 카운터 임계값 숫자는 미공개 | 원작 스크립트 역공학 또는 실기 플레이 턴 카운트 측정으로 `windowTicks` 보정 |
| `GAP-02` | 비핵심 빈 교실 전체 목록 (예: 4F 2-1/2-2, 3F 2학년 일반 교실, 2F 1-3 교실 등) | `[검증 필요]` | 핵심 아이템·사건이 배치된 29개 방은 모두 복원했으나, 단순 조사·대기용 일반 교실 일부의 정확한 층 배치는 공략마다 생략·차이가 존재 | 원작 각 층 이동 메뉴 전수 스크린샷 대조 후 선택적 보조 방 추가 |
| `GAP-03` | `item_clue_memo_3_2` 및 `item_cipher_table`(난수표)의 원문 텍스트 | `[검증 필요]` | 비밀번호 `3878`과 난수표의 존재·위치는 `[확인]`되었으나, 게임 내 원문 문구와 난수표 매트릭스 숫자 전체는 미확보 | 원작 대사 스크립트 확인 또는 저작권 비침해 오리지널 추리 문구로 재작성 |
| `GAP-04` | 미유키 호감도 증감 선택지 전체 목록 및 정확한 가산치 | `[검증 필요]` | 해피 엔딩 분기 기준(`미유키 호감도 >= 3`)은 `[확인]`되었으나, 각 대화 분기별 `+1 / 0 / -1` 가중치 테이블 전체는 부분 확인 상태 | 3F 도서실·2F 1-1 교실·시계탑 등 핵심 선택지별 가산치 3~5개 지점을 정밀 검증 |
| `GAP-05` | 4F→3F 계단 문 열쇠(녹슨 철제 열쇠 파손 분기 vs 구리 열쇠)의 판본별 세부 순서 | `[해석]` | 일부 공략은 5F→4F에 녹슨 열쇠, 4F→3F에 구리 열쇠를 서술하고, 다른 요약은 4F→3F에서 녹슨 열쇠 파손 시 구리 열쇠 대체를 언급함 | 본 복원 데이터는 5F→4F(`녹슨 열쇠`) → 4F→3F(`구리 열쇠`)의 일관된 비순환 체인으로 정규화했으며, 실기 플레이로 세부 대사 확인 권장 |
| `GAP-06` | Windows 리뉴얼판 / 후속 리메이크판의 미세 UI 및 추가 회상 모드 사양 | `[검증 필요]` | PC-98 대비 풀보이스·High Color·『盗作』 동봉은 `[확인]`되었으나, 세이브 슬롯 상한 및 세부 편의 기능 차이는 미확정 | 현대 재구현 기준 20수동 슬롯 + 5자동 체크포인트로 상향 설계 |
