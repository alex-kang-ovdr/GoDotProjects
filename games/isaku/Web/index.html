4. 5종 엔딩 조건: 피해 0명 + 미유키 신뢰 3 이상(미유키 해피) / 2 이하(코토미 해피), 피해 발생 후 탈출(노멀), 아케미 배전반 화재·시계탑/진파치 실패(즉시 배드 엔딩).
