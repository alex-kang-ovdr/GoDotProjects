🌌 YU-NO A.D.M.S. 플레이 가이드

  1. 1일차 거점(node_day1_hub)에 보옥 세이브 필수!
    나중에 칸나 루트에서 얻은 아버지 서재의 열쇠를 들고 이 초기 시간대로 돌아와야 괘종시계(6→3)에서 보옥 6을 얻을 수 있습니다.
  2. 학원 정문(node_school_day1_gate)에도 보옥 세이브 배치!
    6개 히로인 루트가 갈라지는 허브입니다. 한 루트를 끝내거나 소용돌이(배드엔드)에 빠지면 A.D.M.S. 그래프에서 보옥 노드를 클릭해 점프하세요.
  3. 비대칭 역계승 (Global vs Local):
    보옥 점프를 해도 계승 아이템 14종(블루 카드, 은 메달, 초념석, 서재의 열쇠 등), 광점 보옥 6개, 루트 클리어 플래그는 그대로 들고 이동합니다!
  4. 추천 공략 순서:
    미츠키(보옥2·은메달) → 아유미(보옥3·블루카드) → 카오리(블루카드 계승→보옥4·초념석) → 미오(은메달+초념석 계승→보옥5) → 에리코 → 칸나(초념석 계승→서재 열쇠) → 1일차 점프 후 서재(보옥6) → 삼각산 수렴 → 데라 그란트 트루 엔딩!
