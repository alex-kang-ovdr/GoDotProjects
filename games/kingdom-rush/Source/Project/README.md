# Kingdom Rush · Frontier Defense v15

**브라우저에서 직접 플레이하는 JavaScript 타워 디펜스.** 사용자가 제공한 `KingdomRush_Reconstructed_v14.zip`의 복원 데이터에서 출발해, 실행 가능한 전투 엔진과 자체 지도·그래픽·조작 화면을 연결했습니다.

이 빌드는 원작 실행 파일을 포팅한 제품이나 공식 게임이 아닙니다. 참조 수치와 이 웹 게임에서 만든 규칙은 [데이터 안내](data/DATA_NOTES.md)에 구분했습니다.

## 바로 실행

`dist/index.html`을 Chrome, Edge, Firefox, Safari 등 Canvas 2D와 ES2020 이상을 지원하는 최신 브라우저에서 엽니다. 별도 설치, npm 패키지, 로그인, 외부 에셋, 서버가 필요하지 않습니다. 배포 ZIP의 `KingdomRush_Playable_v15.html`도 동일한 단일 파일입니다.

모바일 파일 앱은 HTML을 미리보기로만 표시할 수 있습니다. 이 경우 제공된 웹 플레이 주소를 브라우저에서 여세요. 별·강화·설정은 해당 브라우저에 저장되며, 파일로 실행한 경우 브라우저의 로컬 파일 저장 정책에 따라 현재 세션에서만 유지될 수 있습니다.

| 전문 능력 | 18개 구매·강화·자동 발동 능력 |

| 전투 규칙 | 물리 방어·마법 저항, 공중 표적, 범위·연쇄 피해, 독·속박·순간이동·변이 |

18개 능력의 기준 파라미터는 참조 데이터에서 보존했습니다. 정확한 발동 조건·표적 선정·타이밍·불명확한 예외는 자체 엔진 규칙입니다. 원작과 동일한 재현성을 검증했다는 의미가 아닙니다.

## 첫 전투

1. 길 옆의 `+` 건설 터를 선택합니다.
2. 오른쪽 패널에서 타워를 구매합니다. 첫 웨이브 전 판매는 100%, 전투 중 판매는 65%를 돌려받습니다.
3. **전투 시작**을 누릅니다. 다음 웨이브는 시간이 지나면 자동으로 들어옵니다.
4. 기존 타워를 선택해 강화합니다. 병영의 **집결 위치**로 병사들을 타워 사거리 안에 모읍니다.
5. 영웅과 지원군으로 적을 묶고, 불의 비로 위험한 무리를 제거합니다.

초반 추천: 남부 항구의 건설 터 02에 궁수, 04에 마법, 05에 병영을 배치합니다. 수입이 쌓이면 궁수탑을 명사수탑으로 강화하세요. 이 배치가 일반 난이도·왕국 강화 0·치트 없이 20생명/3별로 완주하는 엔진 회귀 검증을 포함했습니다.

## 조작

| 입력 | 동작 |
|---|---|
| 건설 터 클릭/터치 | 건설 선택 |
| 타워 클릭/터치 | 강화·전문화·능력·판매 |
| 적 클릭/터치 | 체력·방어·저항 정보 |
| 변이된 양 클릭 3회 | 양 처치 |
| `1` | 지원군 선택 → 길 위 클릭 |
| `2` | 불의 비 선택 → 전장 클릭 |
| `H` | 영웅 선택 → 이동 위치 클릭 |
| `N` | 첫 웨이브 시작 / 다음 웨이브 조기 호출 |
| `Space` 또는 `P` | 일시정지 / 재개 |
| `F` | 배속 순환 |
| `Esc` | 대상 선택 취소 → 선택 해제 → 일시정지; 메뉴에서는 닫기 |
| 우클릭 | 스킬/이동 대상 선택 취소 |

터치에서는 같은 동작을 화면 버튼으로 실행합니다. 전투 중 메뉴를 열거나 브라우저가 백그라운드로 이동하면 전투 시간이 멈춥니다.

## 진행과 난이도

모든 스테이지를 처음부터 선택할 수 있습니다. 캠페인에는 20생명, 영웅·강철에는 1생명이 주어집니다. 캠페인 최고 별은 최대 3개, 도전 모드는 각각 1개입니다. 각 전장/모드의 최고 기록만 합산하며 반복 클리어로 별을 무한 획득하지 않습니다. 총 별의 상한은 60개입니다.

왕국 강화는 궁수·병영·마법·포병·불의 비·지원군 6계열, 각 3단계이며 단계별 별 비용은 1·2·3개입니다. 다음 전투부터 적용됩니다. 이미 사용한 별은 무료로 회수해 재배분할 수 있습니다.

캐주얼은 적 체력 감소와 시작 골드 보너스를 제공하고, 베테랑은 적 체력을 높입니다. 이는 원작 플랫폼별 난이도 공식과 별개인 플레이용 난이도입니다. 중후반 전장은 단일 계열만 투자하면 방어·저항·공중 적에 막힐 수 있습니다. 미리 적 정보를 확인하고 화력을 섞으세요.

현재 전투의 실시간 중간 저장은 없습니다. 새로고침하면 해당 전투는 초기화됩니다. 최고 별과 강화·설정만 로컬 저장합니다. 온라인 계정 동기화·멀티플레이·상점·결제는 구현하지 않았습니다.

## 데이터의 근거

- 모든 260개 슬롯에 실행할 웨이브 편성을 지정했고, 선택한 후보의 적 수를 보존합니다.
- 103슬롯은 v14 출처 일치, 144슬롯은 단일 출처, 13슬롯은 충돌 후보를 기록한 상태입니다.
- 충돌 시 wikily 후보를 우선 선택했으며, 이는 원작의 정답을 확정했다는 뜻이 아닙니다.
- 일반 웨이브에 포함된 선택 개체 수의 합은 10,443입니다. 전투 중 소환체와 어둠의 탑 후속 보스는 별도입니다.
- 원본에서 비어 있던 지도 좌표·생성 시각·세계 좌표 사거리 등은 새로 작성했습니다.
- 초반 캠페인과 도전 모드에 골드 보조값을 적용했고, 영웅·타워 개방 조건과 일부 도전 제한을 플레이용으로 바꿨습니다.
- 원작 그림·음원·실행 코드를 배포물에 포함하지 않았습니다. 화면은 Canvas/SVG로 그리며 소리는 Web Audio로 합성합니다.

선택 기록, 원문 후보, 출처 URL, 해시, 자체 프로필 값은 `data/provenance.json`에 있습니다. 출처의 접근 날짜는 v14 기록이며, v15 제작 시 해당 외부 페이지를 다시 확인한 날짜가 아닙니다.

## 빌드와 검증

Python 3과 Node.js가 있는 환경에서 프로젝트 폴더를 열고 실행합니다. 런타임 패키지 설치는 필요 없습니다.

```bash
python3 tools/prepare_data.py
python3 tools/build.py
node tests/engine.test.js
```

데이터 변환을 다시 실행하지 않아도 `src/data.js`가 있으므로 빌드만 할 수 있습니다. `node --check src/app.js`와 같은 구문 검사도 지원합니다.

엔진은 1/60초 고정 스텝으로 갱신하며 배속은 스텝 수에만 영향을 줍니다. 고정된 시드와 동일한 명령열은 같은 결과를 냅니다. 게임 렌더링은 별도로 `requestAnimationFrame`을 사용합니다. 저사양 브라우저에서는 프레임이 크게 지연될 때 시간을 무한히 따라잡지 않고 화면 반응을 우선합니다.

검증 시나리오에는 구매 실패의 무변경 보장, 18능력 구매, 병력 소유권, 모드 제한, 피해 유형, 공중 표적, 스킬 재사용, 저지·부활, 소환·치유·폭발, 보스 2단계, 변이 클릭, 전체 260웨이브 편성 수, 결정적 재생, 무치트 승리와 패배가 포함됩니다. 전체 36모드의 무결점 난이도 밸런스나 실제 모바일 기기 성능을 보장하는 검증은 아닙니다.
