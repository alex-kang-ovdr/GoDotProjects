# v17 변경 기록

작성일: 2026-11-19 (Asia/Seoul)

## 목표와 결과

v16의 위치 표시 전용 시설을 전투에 연결하고, 시간 기반 전장 이벤트와 좁은 화면의 조작을 개선했다. 12개 전장, 36개 모드 조합, 260개 일반 웨이브, 34개 적 정의, 20개 타워 상태, 18개 능력, 30개 별 강화는 유지한다. 최초 일반 편성 10,443개체를 변경하지 않는다.

## 플레이 변화

| 영역 | v16 | v17 |
| --- | --- | --- |
| Silveroak B8 | 엘프 시설 위치·정보 | 수리, 유료 고용, 최대4명, 집결, 지상·대공, 회복, 영구 사망·재고용 |
| Stormcloud A1 | 태양광선 탑 위치·정보 | 마법사1~4명, 충전, 단일 표적 조준, 고정 피해, 고용 즉시 준비 |
| Forsaken 화산 | 사건 정의·시각 추정 연결로 | 첫 웨이브 기준400초/120초 반복, 별도 적 출처, 10초 예고, 남은 시간 표시 |
| 전장 보기 | 고정 전체 지도 | 1~3배 확대, 휠·핀치 처리, 드래그 이동, 전체 보기 복귀 |
| 전장 도감 | 지도·웨이브·타워·몬스터 | 전장 요소 탭, 시설 후보/실행값/근거와 미복원 목록, JSON 내보내기 |
| 결과 | 타워·전투 통계 | 시설 고용·선레이 발사·이벤트 적 수 추가 |
| 저장 | v16 저장 키 | v17 키; 같은 origin의 v16/v15 기록 읽기, 이전 키 보존 |

특수 시설은 복원 지도에만 배치한다. 수치의 출처 수준과 실행 보완값은 `data/special-components-v17.json`에서 분리한다. 자료에 없는 이동 속도는 원문 `null`을 유지하고 실행 속도만 별도 기록한다. 평균 피해, 거리 좌표 적용, 근접 우선 정책, 표적 선택 반경, 화산 서쪽 경로는 원작 실측 결과가 아니다.

## 구현 계약

- `world.facilities`와 시설 API가 골드·인원·쿨다운의 유효성을 검증한다. 잘못된 명령은 상태를 변경하지 않는다.
- 엘프 사망체는 자동 부활하지 않으며 고용 상한은 살아 있는 병력만 센다.
- 태양광선은 전장 전체의 적 하나에게만 피해를 적용한다. 주변 적에 범위 피해를 주지 않는다.
- 이벤트 시간은 첫 `callWave()`에서 시작한다. 준비·일시정지·승패 후에 추가 생성하지 않는다. 현재 마지막 적까지 처리하면 미래 반복을 기다리지 않고 승리한다.
- 이벤트 전용 경로는 필요할 때 한 번만 만들고 정규 경로와 일반 편성의 입구 분배를 바꾸지 않는다.
- 카메라는 화면 표현에만 적용한다. 게임의 위치·사거리·경로·충돌은1000×620 월드 좌표를 유지한다. 스킬·시설 조준·건설 선택은 화면에서 월드로 역변환한다.
- 드래그 또는 두 손가락 동작 뒤에는 클릭 명령을 보내지 않는다. 손을 떼는 동작이 타워 선택이나 스킬 발동으로 이어지지 않도록 분리한다.

## 검증과 남은 범위

41개 엔진 시나리오, 4개 카메라 시나리오가 통과했다. Silveroak의 시설을 사용하는 전체 캠페인 재생을 추가했으며, 기존34개 기대값은 변경하지 않았다. 브라우저에서는 시설 구매·집결·선레이 피해·충전과 확대·드래그를 확인했다. 360/390px 레이아웃 검사도 수행했다.

묘지 부활 영역, J.T. 반복 증원의 간격, Silveroak Iron의 두 번째 시설 위치, 모드별 기존 타워 추가 배치는 아직 복원하지 않았다. 모든 스테이지의 전체 난이도 균형과 모바일 실기기·Safari 성능을 검증한 것은 아니다.
