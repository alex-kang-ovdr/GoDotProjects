# v17 전장 렌더링

## 카메라 좌표

`ui.camera = { zoom, x, y }`에서 `x`, `y`는 화면 왼쪽 위에 보이는 월드 좌표다. 전장은 이전 버전과 동일하게 1000 × 620 좌표계를 사용한다. 렌더러는 다음 순서를 적용한다.

1. 장치 픽셀 좌표에서 전체 캔버스를 지운다.
2. 캔버스 크기에 맞는 월드 배율을 설정한다.
3. `scale(zoom, zoom)` 뒤에 `translate(-x, -y)`를 적용한다.
4. 지형, 사거리, 집결 깃발, 시설, 타워, 적, 아군, 발사체, 효과, 조준점, 전술 표식을 같은 변환으로 그린다.
5. 그리기가 끝나면 카메라 변환을 복구한다.

렌더러도 배율을 1–3배로 제한하고 카메라가 전장 바깥으로 이동하지 않게 좌표를 제한한다. UI 좌표 변환과 확대 중심 처리는 별도 카메라 모듈이 담당한다. 이전 미리보기 호출에는 카메라가 없어도 1배 화면이 유지된다.

## 특수 시설과 아군

- 실반 엘프 훈련소와 선레이 타워에 수리 전 잔해, 수리 후 건물을 각각 그린다.
- 시설 상단에는 수리 필요, 살아 있는 엘프 수, 마법사 고용 필요, 충전 시간, 발사 준비 상태를 표시한다.
- 선레이 타워의 고용된 마법사를 기단 주변에 표시하고 충전 진행 막대를 그린다.
- 선택한 엘프 훈련소에는 집결 깃발과 연결선을 표시한다. `facility_rally` 조작 중에는 `world.facilityRallyRange()` 값으로 이동 가능 범위를 표시한다.
- `kind: "elf"` 아군에는 녹색 두건과 활을 가진 독립적인 절차적 그림을 사용한다.
- 선레이 조준점은 단일 적을 가리킨다. 범위 피해를 의미하는 채워진 원을 사용하지 않는다.

## 효과 계약

선레이 발사 효과는 `kind: "sunray"`로 처리한다. `x`, `y`는 명중점, `originX`, `originY`는 발사점이다. 광선과 명중 섬광을 함께 그린다.

화산 추가 출현 효과는 `kind: "event_spawn"`으로 처리한다. `x`, `y`는 엔진에서 결정한 출현 지점이며 `radius`, `color`, `duration`을 사용한다. 새로운 출현 좌표나 시간을 렌더러가 만들어내지 않는다.

시설의 규칙·단가·피해·재사용 시간의 근거는 데이터 문서에 있다. 이 문서의 색상, 형태, 움직임, 위치 표시는 웹 구현의 독자적인 그림이며 원작 이미지나 애니메이션 복원을 주장하지 않는다.

## 확인

- `node --check src/render.js` 통과.
- DOM 없는 Canvas 모의 검사에서 기본 카메라, 2배 중앙 이동, 3배 경계 제한, 잘못된 숫자 입력의 4개 경우를 확인했다.
- 지형·아군·조준점·전술 표식이 같은 변환을 사용하고, 매 프레임 전체 픽셀 영역을 지우며, 변환 스택이 남지 않는 것을 확인했다.
- 두 시설의 수리 전후, 엘프 그림, 선레이 효과, 추가 출현 효과가 모의 컨텍스트에서 예외 없이 처리되는 것을 확인했다.
- 실제 화면의 배치와 입력 동작 검사는 통합 브라우저 QA에 포함한다.
