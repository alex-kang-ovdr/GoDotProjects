# v18 완성도 개선 기록

기준일: 2026-11-20 (Asia/Seoul). 기준 소스는 v17의 `b18cb18de3dc822712832e1c75dd3e6be52394a1`이다.

## 이번 버전의 목표

진행 중인 전투를 잃지 않고 다시 시작하며, 작은 화면에서도 적과 시설을 선택하고, 전투 결과를 다음 배치에 활용할 수 있도록 플레이 흐름을 보완했다. 전투 밸런스와 출처의 후보 수치를 그대로 두고 저장, 조작, 결과 집계와 가독성을 개선했다.

## 1. 전투 자동 저장과 이어하기

- 준비 또는 진행 중인 전투를 한 슬롯에 저장한다. 전투 시간 5초 간격, 성공한 명령, 메뉴 열기, 일시정지 전환, 백그라운드 진입, `pagehide`에서 저장을 시도한다.
- 골드·웨이브·타워뿐 아니라 난수 상태, 비행 중 공격, 아군과 적의 상태, 주문 충전, 시설과 화산 반복 일정까지 보존한다.
- 페이지를 다시 열면 복원한 전투를 일시정지하고 전장·시간·생명·골드 요약을 보여 준다. `전투 이어하기`를 누르면 진행한다. 종료한 동안의 실제 시간을 전투에 더하지 않는다.
- 준비 화면도 저장하며 새 전장 출전은 기존 한 슬롯을 교체한다. 승리·패배에서는 전투 스냅샷을 삭제하고 최고 기록은 별도 키에 보존한다.
- 저장소 실패를 전투 저장과 별/설정 기록으로 구분해 표시한다. 실패했는데 저장 완료라고 표시하지 않는다.
- 버전, 구성 데이터 체크섬, 크기, ID, 필드, 소유 관계를 확인한다. 손상 파일이나 호환되지 않는 전투를 임의로 실행하지 않는다.

상세 형식과 결정론 검증은 [CHECKPOINT_V18.md](CHECKPOINT_V18.md)에 기록한다. 이 형식은 웹 구현의 저장 형식이며 원작의 세이브 파일 형식이 아니다.

## 2. 백업 내보내기와 가져오기

설정의 `백업 내려받기`는 진행 기록과 현재 전투를 하나의 v18 JSON으로 내보낸다. 외부 서비스나 계정 동기화를 사용하지 않는다. `백업 가져오기`에서는 파일을 먼저 검사하고 가져올 전장과 기록을 보여 준다.

| 선택 | 동작 |
| --- | --- |
| 기록만 합치기 | 전장/모드 최고 별과 처치 기록을 합치고, 프로필별 상세 최고 기록을 비교해 유지한다. 현재 전투는 유지한다. |
| 기록과 전투 가져오기 | 기록을 합친 후 검증된 전투로 교체하고 일시정지 상태로 연다. |

현재 브라우저의 조작 설정과 별 배분은 두 선택 모두 유지한다. 전투 자체에는 저장 당시의 전투 옵션과 강화가 들어간다. 새 브라우저에서는 가져온 별을 왕국 강화 메뉴에서 배분할 수 있다. 입력 상한은 백업 8MB이며 내부 전투 스냅샷은 별도의 더 엄격한 상한을 적용한다.

진행 저장 키는 `kr_frontier_v18_progress`, 전투 키는 `kr_frontier_v18_battle`이다. 같은 출처에서 접근 가능한 v17/v16/v15 진행 기록을 순서대로 읽고 이전 키는 삭제하지 않는다. v17 이전에는 이번 중간 전투 저장 형식이 없으므로 이전 전투의 이관을 주장하지 않는다.

## 3. 선택과 화면 이동

- 몬스터의 지면 그림자 대신 몸체 중심을 기준으로 가장 가까운 적을 선택한다. 공중·보스·작은 몬스터의 중심 높이를 반영한다.
- 터치 입력에서는 확대 배율과 무관하게 최소 22 CSS 픽셀 반경을 허용한다. 여러 적이 겹치면 실제 중심 거리가 가까운 적이 우선한다. 죽었거나 화면 밖에 있는 적은 제외한다.
- 선레이 표적 미리보기와 실제 발사는 같은 선택 함수를 사용하고, 선택한 적의 ID로 엔진에 명령한다.
- 확대 중에는 전체 지도에 현재 카메라 범위, 경로, 타워, 적과 영웅을 표시한다. 지도 클릭·드래그로 이동하며, 지도에 키보드 포커스를 둔 뒤 방향키로 이동할 수 있다.
- 작은 전장에는 현재 스테이지 이름을 함께 표시한다. 선택한 몬스터에는 테두리를 그린다.

## 4. 전투 결과

피해 유형, 통과한 적, 실제 생명 손실, 누적 지출, 주문·시설 사용과 활약한 시설을 표시한다. 통과 개체 수와 명목 생명 비용, 실제로 차감된 생명을 분리했다. 판매된 타워도 이전 기여도를 유지하며 판매 후 적중한 투사체와 지속 피해를 해당 타워에 귀속한다.

실제 누수 기록에 따라 공중 대응, 방어/저항 대응 또는 저지 위치를 안내한다. 결과는 현재 전투가 끝났고 다른 메뉴가 없을 때 열린다. 다른 전장을 시작하면 이전 결과 대기를 취소한다. 완료 버튼에서 재도전·원정 지도·다음 전장으로 연결한다.

상세 API와 귀속 규칙은 [ENGINE_V18_NOTES.md](ENGINE_V18_NOTES.md)에 기록한다.

## 5. 화면 가독성

본문은 16px로 읽을 수 있게 정리하고 주요 버튼·타워 이름은 14px 이상, 보조 수치는 12–13px를 기본으로 사용한다. 900px 이하에서는 전장과 지휘 패널을 세로로 배치한다. 600px 이하에서는 전체 폭의 선택 패널과 접근하기 쉬운 웨이브 버튼을 사용한다. 저장 상태, 전투 시계, 포커스 표시, 대비·동작 줄이기 설정도 반영했다.

## 데이터와 검증 범위

v17과 v18의 `stages`, `enemies`, `towers`, `abilities`, `starUpgrades`, `specialComponents`, `stageEvents`를 구조적으로 비교해 모두 동일함을 확인했다. 12개 전장, 36개 모드 조합, 260개 웨이브, 최초 편성 10,443기를 유지한다. 데이터 버전·출력 이름·구현 메타데이터만 갱신했다. v17 특수 구성 출처 파일도 그대로 유지한다.

자동 검사 74개(엔진 44, 카메라 4, 선택 4, 체크포인트 15, 진행/백업 7)를 통과했다. 체크포인트 검사는 72개 준비 상태 조합과 두 규칙의 남부 항구 완주 비교, 시설·화산·투사체·난수·손상 입력을 포함한다. 브라우저의 실제 관찰과 한계는 [browser-qa-v18.md](../tests/browser-qa-v18.md)에 분리한다.

원작 빌드의 모든 수치·경로·타이밍을 실측한 판으로 승격시키지 않는다. 커뮤니티 후보, 시각 추정 경로, 웹 보완 규칙, 미확정 이벤트와 모드별 시설 차이는 기존 데이터 근거에 그대로 남아 있다. 모든 전장/난이도의 수동 완주와 실기기 성능 검증을 완료했다는 뜻도 아니다.
