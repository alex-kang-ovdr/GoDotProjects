# v15 플레이 데이터의 근거와 변경 범위

이 빌드는 사용자가 제공한 `KingdomRush_Reconstructed_v14.zip`의 실제 JSON을 읽어 만든 **별도의 플레이용 프로필**이다. 원본의 후보 수치를 실행 가능한 전투에 연결하지만, 특정 원작 플랫폼의 완전한 복제를 뜻하지 않는다. 원본 아카이브를 수정하지 않는다.

## 재사용한 사실 데이터

| 항목 | 수량 | 적용 내용 |
|---|---:|---|
| 캠페인 스테이지 | 12 | 식별자·순서·영문 이름·보스 연결 |
| 스테이지/모드 조합 | 36 | 캠페인·영웅·강철 |
| 웨이브 슬롯 | 260 | 176 캠페인 + 72 영웅 + 12 강철 |
| 적 정의 | 34 | 일반 적 31 + 보스 3; 보통 난이도 HP·방어·마법 저항·처치 골드 |
| 타워 상태 | 20 | 4개 기본 계열의 1~3단계와 8개 전문화 |
| 전문화 능력 | 18 | 각 능력의 원본 ID·단계별 추가 비용·`parameters` 객체 |
| 웨이브 출처 관측 | 384 | 후보 선택과 충돌 추적을 위해 보관 |

선택한 웨이브 재고에는 총 **10,443개체**가 있다. 이 수는 모드 36개의 최초 배치 수를 합한 것으로, 전투 중 생성되는 새끼 거미·해골·골렘 머리 등과 캠페인 종료 후 별도로 등장하는 베즈난은 포함하지 않는다.

타워의 `cost`는 해당 단계에서 추가로 지불하는 비용이다. 기초 타워부터의 누적 비용으로 다시 해석하지 않는다. 능력의 `values`는 v14 `levels[].parameters`를 그대로 옮긴 배열이며, 데이터 검증에서 모든 값의 동일성을 검사한다.

## 웨이브 후보 선택

v14는 103슬롯에서 출처가 일치하고, 144슬롯은 단일 출처이며, 13슬롯에 충돌이 남아 있다. 모두 원작 실행 파일에서 실측한 값은 아니다.

실행 시에는 하나의 수량이 필요하므로, **wikily 후보가 있으면 그 후보를 선택**한다. 충돌을 해결했다는 의미는 아니다. 선택한 관측 ID, 출처 ID, 개체 수, 선택하지 않은 충돌 후보를 `provenance.json`에 보관한다. 원본의 `targetBuildDecision`을 확정값으로 바꾸지 않는다.

충돌 슬롯은 다음과 같다.

- Silveroak Forest 강철 1웨이브
- Coldstep Mines 강철 1웨이브
- Stormcloud Temple 강철 1웨이브
- The Dark Tower 캠페인 3·4·6·8·10·11·12·13·14·15웨이브

## 이 웹 버전에서 만든 값

| 영역 | 웹 구현의 결정 |
|---|---|
| 지형 | 1000×620 좌표계, 숲·설원·황무지의 12개 자체 경로 |
| 건설 위치 | 스테이지마다 10~12개; 모든 건설점이 경로에서 38~160px 이내 |
| 이동속도 | 적 종류별 픽셀/초 값; 원문의 단위가 일관되지 않아 원문 숫자를 그대로 좌표계에 쓰지 않음 |
| 타워 사거리 | 종류별 130~230px의 자체 설정 |
| 출현 타이밍 | 엔진이 정한 간격과 그룹 시차; 원작 프레임 자료 없음 |
| 단계 개방 | 12스테이지와 모든 전문화를 처음부터 선택 가능 |
| 영웅 | 모든 모드에서 사용 가능한 자체 영웅; 원작 영웅 수치나 개방 규칙의 재현이 아님 |
| 미확인 공격 | 빠진 근접 공격력·간격에 보조값 적용, `fieldDecisions`에 기록 |
| 성기사/야만전사 간격 | 각각 1.47초 / 1.37초를 플레이용 값으로 선택 |
| 테슬라 기본 피해 | 후보 중 표시 피해 30~55를 채택; 별도 연쇄 처리에서 중복 배율을 피함 |
| 보스 동작 | 소환·동결·타워 봉인 등은 엔진의 자체 스크립트이며, 원작 프레임/조건과의 일치 미검증 |
| 효과·아트·소리 | 웹용 자체 그래픽 및 효과 |

원작 지도 그림이나 스프라이트, 원작 실행 코드, 음원은 이 참조 데이터에 포함하지 않는다.

## 모드 보조 규칙

캠페인 시작 골드는 v14 후보를 유지하며, 1~3스테이지만 최소 300으로 맞춘다. 나머지 캠페인은 원문 시작 골드 그대로다.

영웅 모드는 `max(원문 골드, 650 + 90 × 스테이지 순번)`, 강철 모드는 `max(ceil(원문 골드 × 1.25), 1100 + 125 × 스테이지 순번)`의 시작 골드를 쓴다. 원문 시작 골드가 없으면 위 식의 보조값을 적용한다. 각각의 `modes` 객체에 `sourceStartingGold`, `assistanceGold`가 남는다.

캠페인 생명은 20, 영웅·강철은 1이다. 강철 모드의 타워 계열 제한은 자료의 목록을 사용한다. 예외적으로 **왕국의 성채 강철**은 원본이 병영만 허용하지만, 확인되지 않은 사전 배치 방어 시설을 대신하기 위해 궁수·병영·마법 계열을 허용한다. 이 예외도 자체 프로필 규칙이다.

## 보스와 집계

- 저거너트는 성채 캠페인 17웨이브의 관측 개체에 포함된다.
- J.T.는 사원 캠페인 19웨이브의 관측 개체에 포함된다.
- 베즈난은 어둠의 탑 캠페인 15개 일반 웨이브 이후 별도 보스로 연결한다. v14의 2단계 HP 후보는 각각 6,666이다. `bossAfterWaves`는 이 후속 전투를 나타내며, 일반 웨이브 재고에 보스를 새로 더하지 않는다.

## 파일 구조와 재생성

- `reference_v14.json`: 재사용한 사실 데이터와 원본 출처 URL. 문서 전문이나 원본 아카이브를 포함하지 않는 축약 참조.
- `provenance.json`: 260슬롯의 선택 기록, 13개 충돌의 양쪽 후보, 자체 범위·속도·모드 보조 규칙.
- `data-validation.json`: 식별자·개체 수·능력 매개변수·경로·건설점 검증 결과.
- `../src/data.js`: 브라우저와 오프라인 단일 HTML이 사용하는 런타임 객체.
- `../tools/prepare_data.py`: 결정적인 데이터 변환 스크립트.

Python 3에서 다음 명령으로 다시 만들 수 있다. 외부 패키지는 필요 없다.

```bash
python tools/prepare_data.py
```

v14 원본 추출 폴더에서 참조를 새로 가져오려면 다음 명령을 사용한다.

```bash
python tools/prepare_data.py --source /path/to/KingdomRush_v14
```

출처 제목·URL·v14 기록상 접근 날짜는 `provenance.json`의 `sources` 배열에서 확인할 수 있다. 이 날짜는 v15에서 다시 열어 확인한 날짜가 아니다. 현재 웹 페이지가 이후 바뀌어도 이 빌드는 축약 참조의 해시로 사용 데이터를 식별한다.
