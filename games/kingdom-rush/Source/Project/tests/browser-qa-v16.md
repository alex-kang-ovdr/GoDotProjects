## 수정한 문제

작은 화면에서 웨이브 `0 / 7`이 여러 줄로 나뉘고 조작 버튼이8px 넘치던 문제를 발견했다. 자원과 조작을 두 행으로 나누고, 기존 고정 HUD 높이를 해제해 버튼이 전장 뒤로 가려지지 않게 수정했다. 수정 뒤360·390픽셀 화면과 도감에서 가로 넘침이 없음을 확인했다.

## 한계

브라우저 전투는 구매·진행을 확인하는 조작 검사다. 완주 수치는 별도의 고정 시드 엔진 회귀 결과이며 이 UI 세션의 결과로 표현하지 않는다. iframe 검증은 반응형 CSS 검증이고 실제 모바일 기기·모바일 Safari·저사양 장치의 성능 검증은 아니다. 모든36모드와 모든 타워 조합을 브라우저로 완주하지 않았다. 원작 실행 파일과 비교하는 정확도 검증도 아니다.
