## 범위

- 화산400/120초의 실제 발생, 반복 경로 재사용, 승리 종료, 시설 인원·영구 사망·대공·실패 원자성은 `tests/engine.test.js`에서 별도로 검증했다. 브라우저에서400초를 기다렸다는 뜻은 아니다.
- 전체 캠페인 완주는 고정 스텝 엔진 재생으로 검증했다. 수동 브라우저 플레이로 모든 전장을 완주하지 않았다.
- 화면의 필드 좌표 역변환·기준점 확대·경계 제한은 `tests/camera.test.js`4개 시나리오에서 확인했다.
- 두 손가락 핀치 입력 처리는 구현했지만 이번 Chrome UI 도구는 실제 다중 터치 제스처를 재현하지 않았다. 모바일 실기기·Safari·장시간 성능은 미검증이다.
- 브라우저의 확장 프로그램 자체 메타데이터 오류가 로그에 있었으며 게임 UI 예외와 구분했다.

테스트용 `qa-mobile.html`은 배포·다운로드 묶음에서 제거한다. 게임 캡처는 문서의 소스 자료나 원작 아트에 포함하지 않는다.
