# 03. 4부대 군단 전투, 병종 체계 및 미궁 탐색

## 1. 4부대 전열/후열 편성 및 승패 규칙 `[확인]`

『귀축왕 란스』의 군단 전투는 적·아군 각각 **최대 4부대(전열 2슬롯 + 후열 2슬롯)**가 맞붙는 턴제 전술전이다 `[확인]`.

```
[아군 편성 (최대 4부대)]           VS           [적군 편성 (최대 4부대)]
  후열 2슬롯     전열 2슬롯                       전열 2슬롯     후열 2슬롯
┌──────────┐  ┌──────────┐                     ┌──────────┐  ┌──────────┐
│ 슬롯 3   │  │ 슬롯 1   │  <=== 전투역 ===>   │ 슬롯 1   │  │ 슬롯 3   │
│ (원거리) │  │ (직접/벽)│                     │ (직접/벽)│  │ (원거리) │
├──────────┤  ├──────────┤                     ├──────────┤  ├──────────┤
│ 슬롯 4   │  │ 슬롯 2   │                     │ 슬롯 2   │  │ 슬롯 4   │
│ (마법/궁)│  │ (직접/벽)│                     │ (직접/벽)│  │ (마법/궁)│
└──────────┘  └──────────┘                     └──────────┘  └──────────┘
```

### 핵심 규칙 `[확인]`

1. **지휘관(Commander)과 병사(Troops)의 이중 구조**:
   - 모든 유닛은 **부대장(지휘관 HP)**과 **병수(Troops)**로 구성된다.
   - 병사는 부대장을 보호하는 방패(커버) 역할을 한다.
   - **병수가 0이 되어도 부대장은 단독으로 계속 싸울 수 있다.**
   - **부대장 HP가 0이 되는 순간 부대가 패배**하며, **아군 부대장 HP가 0이면 영구 사망·소실(Permadeath)**된다. 특히 란스(`chr_rance`)의 HP가 0이면 즉시 **`end_death`(전사 엔딩)**이다.
2. **전열 / 후열 공격 제한**:
   - **후열 2슬롯**에서는 오직 **원거리 공격 병과**(궁병 `cls_archers`, 마법사 `cls_mages`, 포병 `cls_artillery_tech`, 지원 `cls_clerics_support`)만 공격할 수 있다.
   - **전열 2슬롯**에 배치된 궁병·마법사는 원거리 공격 대신 **물리 직접 공격(Direct Attack)**을 선택할 수도 있다(높은 마법 내성 적이나 마인전 대응 시 필수 테크닉).

## 2. 최소 병수 우선 행동순과 전투역(`戦闘域`) `[확인]`

### 2.1 최소 병수 우선 행동순 (Smallest-Troop-First Turn Order)
- 각 행동 차례가 끝날 때마다, 전장에서 **현재 병수가 가장 적은 부대**에게 다음 행동권이 돌아온다 `[확인]`.
- 병수가 동률일 때는 **아군 슬롯 1 → 2 → 3 → 4 → 적군 슬롯 1 → 2 → 3 → 4** 순으로 우선한다 `[확인]`.
- **전술적 함의 `[해석]`**:
  - 병력을 과도하게 늘린 부대는 행동순이 맨 뒤로 밀려, `방어` 커맨드를 선택하기도 전에 적의 선제 공격을 다 맞고 큰 손실을 입는다.
  - 반대로 소수 정예 부대(또는 일부러 적정 병력만 유지한 란스·릭·마법사)는 **먼저 행동**해 `방어` 벽을 세우거나 `대기→Snipe`로 적 지휘관을 저격하는 주도권을 쥔다.

### 2.2 전투역 (Field Size / `戦闘域`)
- 1회 교전에서 전선에 동시 참여할 수 있는 **병력 수의 상한선**이다 `[확인]`.
- `현재 병수 <= 전투역`: 보유 병력 전원이 교전에 참가.
- `현재 병수 > 전투역`: `전투역` 수치만큼만 전선에 투입되고, 초과 병력은 후방 대기하다 전선 병력이 줄면 순차 보충된다.
- 따라서 좁은 지형·요새·미궁처럼 전투역이 좁은 전장에서는 물량보다 **지휘관 개인 스탯·병과 질·필살기**가 압도적으로 중요해진다.

## 3. 전투 커맨드 및 데미지 계산 구조 `[확인]` `[해석]`

### 3.1 4대 전투 커맨드 `[확인]`

| 커맨드 | 동작 및 효과 | 비고 |
|---|---|---|
| **공격 (직접 / 궁 / 마법)** | 대상 부대에 피해. 직접 공격만 적의 반격을 유발 | 궁·마법은 반격 없음 |
| **대기 (Wait)** | 해당 차례 공격권을 포기하는 대신 **다음 차례 이후 필살기 사용권 획득** | 방어 보정 없음 (무방비 노출 주의) |
| **방어 (Defend)** | 공격권을 포기하고, **같은 라운드에서 자신보다 늦게 행동하는 적의 공격 피해 대폭 경감** | 바레스·코르도바 등 고방어 탱커의 핵심 전술 |
| **필살기 (Special / Snipe)** | 사전 `대기`로 권한을 확보한 지휘관이 발동하는 고유 기술 | 저격형(`Snipe`)은 병사·전투역 무시 |

### 3.2 교전 데미지 구조 (원작 공략 문헌 검증 기반) `[확인]` `[검증 필요]`

교전은 **병 대 병**, **병 대 지휘관**, **지휘관 대 병/지휘관**의 3계층 판정으로 분해된다 `[확인]`.

1. **물리 공격 (직접 / 궁)**:
   - $\text{공격치} = \text{병 공격력} + \text{공격 지휘 보정} + \text{기합(みなぎり) 보정} + \text{장비/아이템 효과}$
   - $\text{방어치} = \text{부대장 방어력} + \text{아이템 효과}$
2. **마법 공격**:
   - $\text{공격치} = \text{마력(MAG)} + \text{공격 지휘 보정} + \text{기합 보정}$
   - $\text{방어치} = \text{대상 마력(MAG)}$
3. **손괴율 및 작전 보정**:
   - `공격치 - 방어치`에 `전투 LV`, `방어 커맨드 보정`, 그리고 **작전 지시도(10%, 50% 등)** 배율을 곱해 병력 손실과 지휘관 피격을 산출한다 `[확인]`. (정확한 내부 난수 테이블과 계수 상수는 `DATA_GAPS.md`에 기록 `[검증 필요]`.)
4. **저격형 필살기 (Snipe-Type: `Rance Attack`, `By La Way` 등)** `[확인]`:
   - 병사 피해 `0`, **전투역 무시**, **반격 미발생**, 적 지휘관 HP에 직격.
   - 피해량 공식: `0` ~ `floor(Strikes / 5)` 사이의 의사난수 롤 (일반적 상한 `6` 피해 → `Strikes >= 30`에서 최대 효율 도달) `[확인]`.
5. **닌자 전투 추격 (Ninja Support Proc)** `[확인]`:
   - 닌자가 배속된 지휘관이 공격 또는 필살기를 사용할 때, 닌자가 생존해 있으면 확률적으로 적 지휘관에게 **고정 1 피해** 추가 타격.
   - **마인(`cls_demons`)은 이 고정 1 피해에 완전 면역**이다.

## 5. 포획·투항 및 미궁 탐색(Dungeon Expedition) `[확인]`

### 5.1 포획과 영입 (Capture & Recruitment)
- 전투 승리 시 적 지휘관(네임드/일반)을 **포로로 포획**할 수 있다 `[확인]`.
- 포획된 인물은 이벤트 대화, 몸값 요구, 조건부 아군 등용(또는 이탈/처우에 따른 행복·불행 플래그 분기)으로 이어진다.

### 5.2 미궁 탐색 (Dungeon Expeditions vs Field Battles)
- 주간 **탐색(Expedition) 1회 슬롯**을 사용해 괴물 동굴(Monster Cave), 저주 해제 미궁(Uncurse Dungeon), 천적 미궁(Natural Foe Dungeon), 사사호 호저미궁(지하 66층), 성녀의 미궁, 루드라사움 유적(God Cave) 등에 부대를 파견한다 `[확인]`.
- **야전/공성전과의 차이점** `[확인]` `[해석]`:
  - 미궁 내부는 전투역 제약과 특수 몬스터 상성이 강하게 작용하므로, 대규모 병력보다 **지휘관 본인의 공격/방어/마력/필살기** 중심 소수 정예 편성이 유리하다.
  - 미궁 보상은 단순 장비/레벨업이 아니라 **마검 카오스, 신상(神像), 하니와 킹 영입, 창조신 페이즈 돌파** 등 전략 엔딩을 여는 필수 키 아이템을 제공한다.
