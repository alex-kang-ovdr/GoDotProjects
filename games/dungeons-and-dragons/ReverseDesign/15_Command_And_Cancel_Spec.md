# 커맨드·캔슬·전투 우선순위 상세 명세

## 입력 커맨드
- 방향 이력은 고정 틱 기준 최근 N틱으로 유지한다.
- 공격, 점프, 아이템 사용, 주문 선택을 별도의 명령으로 변환한다.
- 방향 조합의 유효 시간, 대시 인식, 연속 공격 입력 간격은 캐릭터별 테이블로 구성한다.
- 동시에 성립한 명령은 상태 허용 조건과 우선순위로 결정한다.

## 공격 상태
`Idle → Startup → Active → Recovery → Idle`이며 피격·다운·사망이 인터럽트할 수 있다.

| 상황 | 제안 처리 | 검증 상태 |
|---|---|---|
| 기본 공격 후 다음 공격 입력 | 허용 캔슬 창에서 연계 | 재구현 제안 |
| 공격 중 점프 입력 | 해당 기술의 점프 캔슬 허용 여부 확인 | 원작 검증 필요 |
| 피격과 타격이 동시 발생 | 틱 내 판정 순서 및 슈퍼아머 규칙 적용 | 재구현 제안 |
| 다운 중 공격 판정 | 다운 타격 가능 속성 검사 | 원작 검증 필요 |

## 공격 데이터 예시
```json
{"id":"fighter_slash_1","startupTicks":6,"activeTicks":3,"recoveryTicks":12,"cancelWindow":[7,12],"hit":{"damage":10,"rangeX":42,"laneTolerance":12},"note":"수치는 예시이며 원작 측정값 아님"}
```

## 검증
동일 동작을 10회 이상 녹화해 입력-발동, 유효 프레임, 캔슬 시점을 기록한다.
