# 주문·아이템 구현용 데이터 테이블

## 주문 분류
| 분류 | 동작 | 시스템 요구사항 |
|---|---|---|
| 투사체 | 방향성 비행체 | 생성 위치·충돌·소멸 |
| 광역 공격 | 일정 영역 적 타격 | 대상 필터·히트 수 제한 |
| 버프 | 능력치/상태 변화 | 지속시간·중첩 규칙 |
| 회복 | HP 회복 | 최대 HP 클램프 |
| 소환·특수 | 별도 효과 객체 | 수명·타깃·이벤트 |

## 주문 사용 처리
1. 클래스·주문 보유 조건 확인
2. 남은 사용 횟수 확인
3. 시전 상태 진입 및 입력 잠금
4. 발동 이벤트에서 효과 생성
5. 소모 시점 정책에 따라 횟수 차감
6. 종료/취소 시 상태 복구

## 아이템 데이터
```json
{"id":"healing_potion_example","type":"consumable","stackMax":9,"useEffect":{"kind":"heal","value":20},"note":"가상 데이터 예시"}
```

실제 주문 목록·사용 횟수·아이템 이름 및 가격은 클래스별 원작 자료 대조 후 별도 확정 테이블로 채워야 한다.
