# 자료와 코드의 구분

이 패키지는 사용자의 코스모티어 역기획·JavaScript 구현 작업을 위한 독립적인 데이터 정리본이다. Cosmoteer는 Walternate Realities의 게임이며 이 패키지는 공식 배포물이 아니다.

## 데이터 출처

공식 위키의 수치·명칭, 개발자의 공개 패치 공지를 근거로 직접 구조화했다. 긴 게임 설명문, 위키 문서 전문, 스크린샷, 이미지, 음원, 실행 파일, 원작 `.rules` 파일을 포함하지 않았다. 각 출처와 변경·정규화·미확정 여부는 JSON과 [출처 목록](docs/SOURCES.md)에 있다.

Cosmoteer Wiki는 CC BY-SA 4.0을 명시한다. 위키에서 유래한 편집 표현에 해당하는 범위에는 해당 조건을 따른다. 위키를 바탕으로 한 번역과 정리에서 수정·축약한 점을 위 문서에 표시했다.

- 공식 위키: https://cosmoteer.wiki.gg/
- CC BY-SA 4.0: https://creativecommons.org/licenses/by-sa/4.0/
- 개발자 공지: https://steamcommunity.com/app/799600/allnews/
- 원작 홈페이지: https://cosmoteer.net/

공개 사실 수치와 제작자가 가진 상표·게임 자산의 권리는 구분된다. 이 패키지에 없는 원작 자산의 재배포 권한을 부여하지 않는다.

## 자체 제작 부분

조회 화면, 데이터 정규화·검증 스크립트, 로더, 스키마, 한국어 설명은 이 작업을 위해 작성했다. STARFORGE 데이터는 사용자의 기존 프로젝트 v3 소스에서 추출했으며 자체 밸런스임을 별도 표시했다.
