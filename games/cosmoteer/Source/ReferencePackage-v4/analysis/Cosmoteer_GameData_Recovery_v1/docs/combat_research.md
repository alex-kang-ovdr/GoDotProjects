# 무장·방어·열 데이터 복구 조사

관측일: **2026-11-17**. 대상은 **Cosmoteer 현대 Steam판**이다. 최신 공식 공지의 기준은 0.30.5a이며, 이번 결과는 공개 자료를 구조화한 복구본이다. 원작 설치의 전체 규칙 파일이나 실제 실행을 검증한 버전 덤프는 아니다.

## 산출물과 범위

- `combat.json`: 57개 레코드. 일반 부품 34개, 오버클럭 모드 15개, 미사일·기뢰·파편 6개, 전역 규칙 2개.
- 40개 출처 메타데이터. 경제 분야와 공유하는 원자재 가격 출처 6개를 포함하며, 통합 시 같은 source ID는 한 번만 유지하면 된다.
- 주요 대상: 소형/대형 레이저, 디스럽터, 이온/프리즘, 표준/대형/갑판 캐논, 체인건/탄창, 레일건 3모듈, 발사기와 5탄종, PD/Flak, 실드 2종, 장갑 6형, 열 파이프 3형, 방열기·축열기·열교환기, 열 공명 랜스와 2펌프, 소화기.
- 채굴 레이저, 트랙터 빔, 원자로·추진·구조물 혼합 장갑은 다른 담당자의 범위다.

## 접근성과 신뢰 범위

Wiki.gg의 직접 열기는 403 응답이었다. 검색 색인에는 부품별 인포박스와 일부 최신 오버클럭 표가 노출되어 그 수치를 추출했다. 따라서 `wiki_snapshot`은 페이지에서 실제 관측한 숫자라는 뜻이며, 0.30.5a에서 검증한 숫자라는 뜻이 아니다. 위키 홈페이지도 커뮤니티가 작성·관리한다고 밝힌다.

공식 Steam 피드는 정식 패치와 RC를 함께 싣는다. 정식 0.30.5를 따로 확인했다. RC1의 화재 시작 강도 100%, 구조물 통과 피해 잔존 60%는 정식판 수치로 쓰지 않았다. 기존 역기획서의 출처 목록은 탐색에만 사용했고, 분석식·가정값·STARFORGE 프로토타입 수치는 원작 테이블에 넣지 않았다.

## 스키마 사용법

각 레코드는 별도 canonical `id`와, 실제 원문에서 확인된 경우에만 `game_id`를 가진다. 일반 부품은 `record_type=part`, OC는 `mode_override`와 `base_part_id`를 사용한다. 탄종은 건설 가능한 독립 부품과 분리했다. 한국어 이름은 연구자 번역이며 공식 현지화 문자열은 미검증이다.

`fields[field] = {value, unit, raw_label}` 형식이며, 각 필드에 `evidence`와 `field_status`가 있다. 주요 상태는 `wiki_snapshot`, `patch_confirmed`, `conflict`, `unverified`, `unresolved_version`이다. `observations`는 대체된 숫자·모순값·별도 계산을 보존한다. 모든 null은 **미확인**이며 0이나 일반판과 같다는 의미가 아니다. OC 필드가 null이면 일반판으로 자동 채우지 않는다.

전력은 원문의 Power Use/Capacity 수량을 유지했다. 와트나 MJ로 바꾸지 않았다. MJ 열량과 선체 타일의 heat 상태 임계값도 동일한 양으로 간주하지 않았다. `shots_per_second`는 원문 표기이며 반올림된 값의 역수로 정확한 발사 간격을 생성하지 않았다. `Value`와 `Blueprint Cost`는 구분했으며, 열 관리 연구처럼 공동 해금 묶음이 있을 가능성이 있어 Blueprint Cost의 단순 합산도 피해야 한다.

## 남은 공백

정량 자료가 부족한 방어 OC 모드의 실드 강도·면적·피해당 열량, PD 발전량, Flak 구름 수명·피해, 외부 구조형 열 파이프의 비용·HP·ID는 null이다. 열 공명 랜스의 기본 열량·저장량과 열교환기 반경·추가 폐열 비율도 확인하지 못했다.

전역 화재는 정식 패치의 시작 강도 20~40%를 확보했다. 발화 임계값, 선체 열 감소율, 화재 DPS·전파 확률, 그을림 임계값, 소화 거품 지속시간은 자료가 없어 null로 남겼다. 레일건 OC의 열 파이프 연결 요구도 장전기 문서와 발사기/가속기 문서가 충돌하므로 확정하지 않았다.

다음 검증은 사용자가 가진 **0.30.5a의 비이미지 규칙 파일** 또는 Alt 툴팁 캡처를 대상으로 하는 것이 가장 정확하다. 불확실한 필드와 충돌 행부터 확인하면 된다.
