# STARFORGE v3 데이터 출처 구분 감사

검토일: 2026-11-17  
프로토타입 기준 커밋: f90387acd3f7ca25a8285423f235352dd47d07e4  
프로토타입 데이터셋: starforge_v3

## 결론

이번에 추출한 **STARFORGE의 수치는 실제 구현값**이지만 **Cosmoteer 원작값은 아니다.** 기존 역기획서 22·23은 용어와 근거 관리 문서이며, 원작 부품 데이터베이스를 제공하지 않는다. 두 종류의 자료를 이름만으로 합쳐 원작 테이블의 빈칸을 채우면 안 된다.

## 기존 22·23 문서의 숫자 분류

| 위치 | 숫자·수식의 성격 | 복구 테이블 처리 |
| --- | --- | --- |
| 22 서두·§6 | 기준 빌드 0.30.5a, 작성일 2026-11-13, 문서 번호·연결 번호 | 출처·판본 메타데이터. 부품 성능값이 아니다. |
| 22 §6 | 패치 수치, 위키 수치, 충돌 수치, 가정 예시를 구분하는 원칙 | 개별 숫자의 출처를 다시 읽어야 한다. 이 표 자체는 원작값 확정의 근거가 아니다. |
| 22 §7 | R_supply ≈ n × q / T_trip | [제안] 정상상태 분석 모델. 원작 물류 엔진의 공식이나 실제 q·이동 시간을 복원한 것이 아니다. |
| 22 §7 | T_deplete ≈ B / (R_demand − R_supply), 분모가 0 이하이면 미사용 | [제안] 일정한 수요·공급을 가정한 분석식. 숫자 0은 수학적 적용 조건이다. |
| 22 §7 | D_total / T_test | 관측 피해율의 정의. 원작 무기 피해·연사·관통 공식이 아니다. |
| 22 §8 | RuleId, GameBuild, DefinitionId 등의 추출 양식 | [제안] 데이터 수집 스키마. 원작 내부 식별자나 클래스 선언이 아니다. |
| 23 §1 | HTTP 403, 직접 열기 실패, 검색 색인으로 확인한 범위 | 자료 접근 상태. 게임 수치가 아니며 완전한 원본 데이터 열람을 뜻하지 않는다. |
| 23 §2 | 0.30.5, 0.30.5a, Career 2.0 | 판본·계획의 구분. Career 2.0의 숫자는 현재 적용된 밸런스 계수가 아니다. |
| 23 §3 | 원자로 픽업, 방열기 내구도, 열 연결 등의 충돌 목록 | 미확정·버전 차이를 표시한 항목이다. 오래된 수치를 임의로 확정하면 안 된다. |
| 23 §4·§5 | 실측 우선순위, 상태 머신·점수식·틱 순서 | 재구현 제안과 검증 계획. 원작 코드에서 추출한 처리 순서가 아니다. |
| 23 §6 | SRC-01 등의 출처 번호, 문서 번호, URL 안의 숫자 | 탐색용 식별자. 원작 부품 ID나 게임 데이터 수치로 변환하지 않는다. |

22는 가격·사거리·승무원 상한의 전체 표를 임의로 채우지 않았다고 명시한다. 23 역시 게임 실행 및 설치 데이터·소스 대조를 수행하지 않았고, 장치별 수치가 완성된 데이터 파일을 제공하지 않았다고 명시한다. 따라서 이 두 문서만으로 원작 가격표·제조법·부품 HP를 복구할 수는 없다.

## STARFORGE에서만 확정되는 예

아래 값은 요청한 커밋의 dist/sim.js에서 확인되는 독립 구현값이다.

| 항목 | STARFORGE 값 | 원작과 혼동하면 안 되는 이유 |
| --- | --- | --- |
| 시작 크레딧 | 850 | 이 원정의 초기 예산이다. |
| 장갑 HP / 가격 | 230 / 58 C | 단일 격자 부품의 프로토타입 밸런스다. |
| 원자로 생산 / 가격 | 초당 10.5 전력 / 350 C | 원작 원자로 종류·전지 팩 크기·가격과 등가성이 없다. |
| 운반량 상한 | 전력 6, 탄약 8 | 이 작업 예약·버퍼 모델의 자원 단위다. |
| 승무원 기본 이동 | 초당 3.1 격자 | 내부 격자 한 칸은 월드 좌표 28이다. 원작 거리·속도로 환산하지 않는다. |
| 과열 진입 / 해제 | 100 이상 / 65 미만 | 이 구현의 열 상태 판정이다. 원작 열망 온도 기준이라고 표기하지 않는다. |
| 현장 수리 | 초당 8 HP, 자재 1당 4 HP | 공용 repairStock은 프로토타입의 추상 자원이다. |
| 자재 구매 | 최대 80 묶음, 단위당 2 C, 보유 상한 240 | 원작 제작 재료·수리 재료 레시피가 아니다. |
| 시뮬레이션 기본 틱 | 1/60초 | 브라우저 프로토타입의 고정 간격이다. 원작 틱 빈도가 아니다. |

정확한 파일·줄 범위는 starforge.json의 각 행에 저장했다. 부품 정의는 런타임 상수를 그대로 추출하며, 함선별 HP·질량·구성 수는 같은 코드로 초기화한 결과임을 별도 표시한다.

## 제조·원작 이름 매핑의 제한

- 이 구현에는 광물 → 금속 → 부품 같은 **산업 공장 레시피 테이블이 없다.** 전지 생산, 탄약 구매, 정비 자재 구매, 크레딧을 지불한 즉시 조립을 각각 구분해 추출했다.
- Storage Bay와 유사한 이름의 storage는 탄약 전용 한 칸 장치다. 원작 다품목 저장고와 크기·용량이 같다고 추정하지 않는다.
- Reactor, Laser, Cannon, Shield, Thruster, Radiator는 부품군·개념명 연결이다. 원작의 Small/Large 등 특정 부품 ID를 추정해 부여하지 않았다.
- KITE, ANVIL, WISP, patrol/siege/hunter, 세 갈래 3단계 개량은 STARFORGE 콘텐츠다. 원작 함선·의뢰·개량 행으로 등록하지 않는다.

원작 공개 데이터와 통합할 때는 dataset_id와 source_build를 분리하고, 이름 매핑은 외래 참조 후보로만 사용한다. 값의 출처가 공개 패치인지, 원작 데이터 파일인지, 실측인지, 이 프로토타입 코드인지 행 단위로 보존해야 한다.

## 추출 방식

scripts/export_starforge.cjs는 git show로 지정 커밋의 dist/sim.js와 dist/editor.js를 읽는다. 별도의 메모리 VM에서 상수와 초기 상태를 평가하며 저장소 파일은 수정하지 않는다. 결과에는 원본 파일 SHA-256, 행별 근거 범위, 추출 방식, 원작 수치 동등성 미확인 표기가 포함된다.
