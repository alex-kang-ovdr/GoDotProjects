# 복구 방식과 판본 관리

## 1. 복구 대상

대상은 Cosmoteer: Starship Architect & Commander의 현대 Steam판이다. 최초 요청의 나무위키 URL은 직접 열람이 되지 않아 숫자의 근거로 사용하지 않았다. 공식 홈페이지가 연결하는 위키와 개발자 Steam 정식 공지를 사용했다. 기준 확인일은 2026-11-17이며, 공지에서 확인한 참조 버전은 0.30.5와 0.30.5a다.

개별 위키 표의 정확한 게임 버전은 대부분 명시되어 있지 않다. 따라서 전체 데이터셋을 특정 설치 빌드에서 추출했다고 표기하지 않는다. JSON의 `exact_game_build`는 `null`이다. 최신 공지가 언급하지 않은 필드까지 일괄 최신 값으로 승격하지 않았다.

## 2. 원작 데이터의 채택 절차

1. 개별 부품·자원·규칙의 공개 표에서 실제로 읽은 값만 전사했다.
2. 영문 표제와 원래 단위를 보존하고, 검색·참조에 사용할 독립적인 안정 ID를 붙였다.
3. 같은 대상의 위키 인포박스, 본문, 제작표, 패치 이력이 다른지 대조했다.
4. 정식 개발자 패치가 직접 값을 바꾼 경우 그 값에 `patch_confirmed`를 붙였다. Release Candidate의 중간 수치는 정식값으로 사용하지 않았다.
5. 원문 사이의 충돌이 해소되지 않으면 `value: null`과 `conflict`를 기록했다. 복구한 원래 숫자는 `observations`와 `conflicts`에서 확인할 수 있다.
6. 재료 가격 합계, 자원 외래키, 단위, JSON 타입을 검사했다. 계산 합계가 다르다고 한쪽 숫자를 임의로 고치지 않았다.

위키 직접 열기는 여러 페이지에서 HTTP 403이었으며, 검색 색인에 노출된 실제 표·본문 범위로 조사했다. 출처의 `access_method`에 이 차이를 남겼다. 검색 수집일을 게임 업데이트 날짜로 바꾸지 않았다.

## 3. 단위와 ID

| 항목 | 처리 |
| --- | --- |
| 거리·부품 크기 | 위키의 m 표기를 사용. 내부 이동의 tiles/s와 별도 |
| 질량 | tonne. 자원 개당 질량은 근거가 없으면 null |
| 전력 | `game_power`, `game_power/s`, `game_power/battery`. W·J로 바꾸지 않음 |
| 열 | 원문에 MJ가 명시되면 MJ. 패치가 heat만 적으면 `game_heat`로 보존 |
| 지휘 점수 | 제공/소모의 부호 또는 `command_points_used` 키를 구분 |
| 관통 저항 | 원문이 음수 거리로 표시하면 부호를 보존. 손상량·양의 장갑 두께로 바꾸지 않음 |
| 생산식 | `item[]/ratio`는 재료 비율. 실제 생산 배치 크기·틱·주기는 별도 미확정 |
| `id` | 이 복구본이 정의한 안정 ID |
| `game_id_reported` | 위키 Technical ID의 표기. 실제 전체 rules ID와 동일하다고 보장하지 않음 |
| `engine_id` | 원본에서 확인하지 못했으므로 null |
| 한국어 이름 | 이 문서의 편집 번역. 공식 한국어 문자열 테이블을 추출한 것이 아님 |

정규화 중 필드명·단위 표기를 바꾼 경우 `source_field_name`, `source_unit`, `source_status`를 남긴다. 예를 들어 `range`를 `range_m`으로, `power/sec`를 `game_power/s`로 통일한다. 숫자를 다른 물리 규모로 변환하지 않는다.

## 4. 복구하지 못한 범위

전체 엔진 데이터베이스를 재현한 것은 아니다. 다음 항목은 원본 `.rules` 또는 동일 버전의 실행 관측이 필요하다.

- 부품 상속·오버라이드 관계, 전체 네임스페이스 ID, 엔진 컴포넌트 조합
- 문·승무원 작업 위치, 전력·열 포트 위치, 회전별 충돌·통행 폴리곤
- 전체 오버클럭 프로필과 연속 상태에 따른 보간식
- 일부 발사체 속도와 피해 의미, 공지에 목록이 없는 일괄 밸런스 변경의 적용 대상
- 원작 승무원 고용 공식, 자원 개당 질량, 정확한 제작 배치·제작 주기
- 함선 설계·함대 편성·미션 생성·세력 AI·지도 생성의 원작 데이터
- 공식 한국어 현지화 문자열, 이미지·음원·효과·셰이더

`UNRESOLVED.md`는 이번 조사에서 발견한 구체적인 누락·충돌 목록이다. 넓은 시스템 전체의 미복구와 한 필드의 미확정을 같은 의미로 보지 않는다.

## 5. STARFORGE 데이터의 복구

STARFORGE는 공개 문헌과 별개의 경로로 복구했다. 지정된 Git 커밋의 `dist/sim.js`, `dist/editor.js`를 읽고 상수·설계·계약·규칙을 추출했다. 원본 저장소를 변경하지 않았으며, 모든 행에 `value_origin: prototype_code`, 소스 파일, 줄 범위, 추출 방식이 있다.

부품 상수는 실제 런타임 결과와 비교했고, 개량 가격과 의뢰·함대 생성도 별도로 확인했다. 이 검증은 STARFORGE 구현의 정확성을 위한 것이며, Cosmoteer 원작과의 수치 일치를 증명하지 않는다.
