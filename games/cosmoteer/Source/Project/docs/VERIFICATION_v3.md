# STARFORGE v3 검증 기록

검증일: 2026-11-14. 시뮬레이션과 조립 로직은 Node.js v24.22.1, 사용자 화면은 Chrome에서 확인했습니다. v3는 기존 3구역 원정에 화재·현장 정비·기술 개량을 결합한 버전입니다.

## 자동 검증

```sh
npm test
# 또는
node --test tests/*.test.cjs
```

최종 실행: **55개 통과, 실패 0개**, 약 3.51초. 코어 27개, 조립 12개, v3 정비·성장·이관 16개입니다. 외부 테스트 라이브러리는 필요하지 않습니다.

### 완주 검사의 범위

테스트는 초기 함선에서 출발하며 추가 자금을 지급하거나 적 내구도를 강제로 줄이지 않습니다. 첫 구역 승리 후 실제 보상으로 각 1,940 C의 증설을 두 번 구매하고, 탄약을 별도로 결제합니다. 구역 사이 저장·불러오기를 거쳐 `complete`, 3승, 네 번째 보상 불가까지 확인합니다. 이 검사는 완료 가능한 한 진행 경로를 확인하며 모든 설계와 전술 조합의 승리를 보장하지는 않습니다.

기술의 효과 검사는 충분한 예산을 둔 명시적인 경계 표본을 사용합니다. 위의 자연 원정 완주 검사는 임의 예산을 사용하지 않습니다.

## 구현 범위와 한계

싱글플레이 3구역 원정의 조립·전투·물류·정비·회수·성장·저장 흐름을 검증했습니다. 거대한 성계 지도, 채굴·무역, 복수 함대 지휘, 멀티플레이는 이 버전의 범위에 없습니다. 정비 자재는 함선 공용 재고이며 승무원은 현장까지 이동하지만 자재를 상자에서 따로 운반하지는 않습니다. 실드는 전방위 모델을 유지합니다. 게임 상태 복원은 엄격하게 검사하지만 저장 파일은 클라이언트 게임 데이터이므로 서버 기반 변조 방지 기능을 제공하지 않습니다.
