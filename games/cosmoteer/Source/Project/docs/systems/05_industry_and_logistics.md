# 05. 황·탄약 생산과 승무원 물류

작성 기준: STARFORGE v4, 2026-11-18. 실행 정의는 [data.js](../../dist/data.js), 운용은 [sim.js](../../dist/sim.js)에 있습니다. 원작 관측값과 조정 근거는 [분석 데이터 어댑터](04_analysis_data_adapter.md)를 참조합니다.

## 1. 플레이 목적

탄약은 도크에서 즉시 보충하거나 함내 공장으로 생산합니다. 즉시 보충은 작업 인력과 시간이 필요 없고, 공장은 전투 중에도 탄약 공급을 이어갈 수 있습니다. 원료·전력·동선·완제품 공간 중 하나라도 부족하면 공장을 추가하는 것만으로 지속 화력이 늘지 않습니다.

생산형 청사진은 중포 2문, 레이저 1문, 탄약 공장 1개를 사용합니다. 기본 함선의 부품을 재사용하며 초기 자금 850 C에서 543 C로 적용할 수 있습니다. 저장고의 초기 황 6은 공장 투입 기준 탄약 120발에 해당하지만 운송·전력·출력 공간을 확보해야 실제 탄약이 됩니다.

## 2. 부품과 자원

| 부품 | 가격 C | 질량 | HP | 역할 |
| --- | ---: | ---: | ---: | --- |
| 소형 원자로 | 350 | 4.2 | 230 | 발전 10.5/s, 전력 저장 100, 운반 팩 6 |
| 중형 원자로 | 700 | 9.45 | 230 | 발전 31.5/s, 전력 저장 200, 운반 팩 12 |
| 대형 원자로 | 1,050 | 16.8 | 230 | 발전 94.5/s, 전력 저장 300, 운반 팩 18 |
| 탄약 공장 | 420 | 4.2 | 230 | 전력 24, 황 5, 완제품 탄약 60 |
| 보급 저장고 | 170 | 3 | 170 | 탄약 240, 황 20 |

위 값은 STARFORGE 실행 단위입니다. 원작 크기·가격·HP를 그대로 복제하지 않습니다. 모든 부품은 한 칸을 점유합니다. 공장과 저장고의 자원 버퍼는 각각 독립되어 있습니다. 황 공간이 남아 있다고 탄약 공간이 늘어나지는 않습니다.

## 3. 생산 상태

| 상태 | 조건 | 결과 |
| --- | --- | --- |
| producing | 작동 가능한 공장, 생산 허용, 원료/배치, 출력 공간, 전력 | 작업 시간 누적 |
| sulfur | 배치가 없고 황 1 미만 | 승무원 보급 대기 |
| power | 작업에 필요한 전력이 부족 | 진행 정지, 전력 보급 대기 |
| output_full | 완제품 20을 넣을 공간 부족 | 출력 이동 대기 |
| disabled | 플레이어가 개별 공장을 정지 | 원료·진행도 보존 |
| offline | 파괴 또는 조종실과 연결 상실 | 생산 불가 |

배치 시작에서 황 1을 차감하고 투입 상태를 켭니다. 전력을 공급받으며 작업 시간 10초가 누적되면 탄약 20을 넣고 배치를 종료합니다. 전력 소모는 작업 중 0.48/s이므로 완전한 한 배치는 총 4.8 에너지를 사용합니다. 생산 완료 전 중단·저장·재개는 황을 추가 차감하거나 탄약을 선지급하지 않습니다.

관측 자료의 생산율 2발/s와 황 0.05/발을 보존한 게임 배치입니다. 원작의 실제 내부 배치 크기와 주기는 미확인으로 남겨 두었습니다.

## 4. 실제 승무원 물류

1. 저장고에서 황을 픽업해 공장으로 운반합니다. 황의 1회 운반 상한은 4입니다.
2. 원자로에서 전지를 픽업해 소비 장치에 운반합니다. 원자로 등급에 따라 최대 6·12·18을 실을 수 있습니다.
3. 공장 또는 저장고에서 탄약을 픽업해 중포로 옮깁니다. 탄약의 1회 운반 상한은 8입니다.
4. 공장 완제품을 보급 저장고로 옮겨 공장 출력 공간을 확보할 수도 있습니다.
5. 대상의 빈 공간·공급원의 재고·다른 작업의 예약량을 고려하므로 같은 재고를 동시에 중복 예약하지 않습니다.

이동은 실제 통행 가능한 칸의 경로를 사용합니다. 기본 속도는 3.2칸/s이며 통로는 ×1, 일반 방실은 ×0.5입니다. 방실을 연속해서 통과하는 설계보다 통로를 확보한 설계의 왕복 시간이 짧습니다. 물류 개량, 혼잡, 실제 이동 경로는 최종 도착 시간에 추가로 영향을 줍니다.

소화·수리와 운송은 같은 승무원을 공유합니다. 생산 설비를 늘려도 인력이 부족하면 전력·탄약의 운송량은 늘지 않을 수 있습니다.

## 5. 도크 거래와 회수

황 가격은 2 C/개입니다. 구매 버튼은 5 또는 최대 20을 요청하며, 살아 있는 저장고의 실제 남는 공간으로 수량을 줄인 견적을 보여줍니다. 구매는 도크에서만 가능하고 크레딧 부족·유효하지 않은 수량은 상태 변화 없이 거부합니다.

전투 승리의 황 회수량은 2 + 구간 ×2입니다. 1·2·3구간에서 각각 4·6·8을 회수합니다. 수용량을 넘는 황은 1.2 C/개로 정산하고 합계를 내림합니다. 같은 승리의 황이나 크레딧을 다시 받을 수 없습니다.

탄약과 황은 별도의 실제 원장입니다. 수리비 결제나 청사진 재적용만으로 새 원료와 탄약이 생기지 않습니다. 철거할 때의 이전·매각은 [저장과 재고 보존](06_save_v4_and_inventory.md)에 설명합니다.

## 6. 표시와 조작

- **생산·기술·정비 보급 / U:** 공장별 상태·진행·비축, 황 구입, 기술 개량, 정비 자재를 확인합니다.
- **공장 선택:** 개별 생산 정지·재개가 가능합니다. 저장된 생산 허용 상태는 새로고침 후에도 유지합니다.
- **물류 오버레이:** 전지·탄약·황을 색상과 서로 다른 운반물 형상으로 구분하고 공급원 비축 및 경로를 표시합니다.
- **설계 분석:** 원자로별 실제 발전량, 팩 크기, 질량, 설치 수를 비교합니다.
- **함내 황 총량:** 저장·운반·생산에 투입한 황을 포함합니다. 버퍼의 빈 공간 계산과 혼동하지 않도록 저장량과 운반/투입량을 분리합니다.

## 7. 적용하지 않은 원작 요소

축전기 릴레이, 이동 보도, 다칸 부품 배치, 광물 채굴, 여러 종류의 공장, 전체 시장과 함대는 이번 버전의 범위에 포함하지 않습니다. 정비 자재는 v3의 공유 수리 자원 모델을 유지합니다. 실드는 전방위 모델이며 원작 방향성 실드와 같다고 표시하지 않습니다.
