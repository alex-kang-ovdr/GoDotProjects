# 변경 기록

## 분석 데이터 기반 생산·물류 — 2026-11-18 (v4)

### 실행 데이터와 부품

- 공개 자료 복구 테이블에서 출처·확인 상태를 보존한 실행 어댑터를 생성합니다. 원작 관측값, 명시적 게임 조정값, 적용하지 않은 값이 구분됩니다.
- 중형·대형 원자로와 탄약 공장을 추가해 14종 부품을 제공합니다. 등급별 전지 팩 6·12·18과 발전 10.5·31.5·94.5/s를 실제 보급에 사용합니다.
- 승무원 기본 이동 3.2칸/s, 통로 ×1·방실 ×0.5를 적용하여 통로 설계의 가치를 높입니다.
- 가격·HP·질량·전력 버퍼는 독립 게임 조정값이며 원작 한 부품의 다칸 점유는 이번 범위에 포함하지 않습니다.

### 실제 생산 흐름

- 황 구매→저장→승무원 운반→공장 투입→탄약 생산→무장 보급을 연결합니다.
- 공장은 황 1, 작업 10초, 전력 0.48/s로 탄약 20을 생산합니다. 원료 부족·전력 부족·출력 포화·설비 정지를 각각 구분합니다.
- 도크에서 황을 2 C/개로 구매하고, 남은 저장 공간만 원자적으로 정산합니다. 전투 중에는 구매할 수 없습니다.
- 회수 황은 승리당 2 + 구간 ×2입니다. 공간을 넘는 분량의 매각 정산과 중복 회수 차단을 포함합니다.
- FORGE 생산형 청사진, 생산 현황·구매 화면, 공장별 정지 버튼, 원자로 비교, 운반물·병목 아이콘을 추가합니다.

### 저장과 편집

- 저장 VERSION 4에 황 원장, 생산 진행·투입 상태, 새로운 운반 작업과 통계를 포함합니다.
- 배치 시작 시 황을 차감하고 완료 시 탄약을 지급합니다. 정지·저장 복원으로 중간 생산이 복제되지 않습니다.
- 기존 v1·v2·v3의 함선·재고·전투·기술을 이어받습니다. 원래 없던 황은 0으로 초기화합니다.
- 철거·청사진 교체 때 남는 재고를 우선 이전하고 초과분을 매각 정산합니다. 진행 중 배치는 투입한 원료의 가치로 처리하며 미완성 탄약을 생성하지 않습니다.
- 실제 출시 v3 커밋에서 동결한 저장 표본과 새 산업·데이터 회귀 검사를 추가했습니다. 최종 실행 결과는 docs/VERIFICATION.md에 기록합니다.


## 현장 정비·기술 개량 — 2026-11-14 (v3)

### 화재와 승무원 정비

- 피격·과열 점화, 화재 성장·지속 피해·상하좌우 확산을 추가했습니다. 모듈별 화재 강도와 손상 오버레이를 표시합니다.
- 승무원이 실제 경로로 현장 또는 인접 통로에 도착한 뒤 소화·수리합니다. 소화는 무자재, 수리는 자재 1당 4 HP를 회복하며 파괴 모듈은 도크에서 복구합니다.
- 균형·생존 우선·보급 집중 정책으로 정비와 물류의 인력을 배분합니다. G로 아군 모듈의 현장 우선 대상을 지정·해제합니다.
- 정비 자재는 초기 80, 상한 240입니다. 최대 80을 160 C에 보급하고, 상한 근처에서는 실제 남은 용량만 결제합니다.
- 화재 진압과 피해가 진행된 뒤 오래된 조립 Undo가 시간·HP·화재·통계를 되돌리는 회귀를 수정했습니다. 정상 조립 직후 Undo는 유지합니다.

### 원정 단위 기술

- 원자로 효율·함내 작업 동선·추진 제어 개량을 각각 최대 3단계로 구매합니다. 단계당 실제 발전 +10%, 승무원 이동 +8%, 추력 +10%를 적용합니다.
- U 또는 기술 창에서 도크 구매가 가능합니다. 가격·다음 단계 효과를 표시하고, 자금 부족·최대 단계·전투 중 구매를 거부합니다.
- 구매한 기술과 남은 정비 자재는 귀환·저장에 유지합니다. 새 원정에서는 기술 0과 초기 자재로 돌아가며 사용자 청사진 목록은 유지합니다.

### 저장과 검증

- VERSION 3에 fire·공유 자재·정비 정책·우선 대상·기술·서비스 경로·작업 진행을 저장합니다.
- 기존 v1·v2 원정을 지원합니다. v2 커밋 424bd7a에서 탄체가 있는 전투·회수 완료 승리·유료 증설을 완료한 도크 표본을 동결했습니다.
- 현장 작업의 경로·위치·무화물 조건과 수치 범위를 검증하며, 잘못된 입력을 현재 게임의 일부에만 적용하지 않습니다.

## 코어 확장 — 2026-11-14

### 조립

- 좌우 대칭 배치·철거·회전과 선택 부품 복제를 추가했습니다. 중앙 축의 부품은 한 번만 설치하고, 대칭 배치 중 한쪽이 실패하면 비용과 함선을 모두 유지합니다.
- 최근 24개 편집의 되돌리기·다시 적용을 추가했습니다. 부품뿐 아니라 편집에 따른 환불과 재고도 함께 복원합니다.
- 균형형·중포형·레이저형 기본 청사진과 사용자 청사진 저장을 추가했습니다. 적용 전 차액을 보여주며, 같은 종류의 부품을 재사용할 때 손상과 재고를 유지합니다.

### 전투와 작전

- 추진기의 방향·설치 위치와 함선 질량이 이동·선회에 영향을 줍니다. 작동하는 추진기가 없으면 자동 이동 명령만으로 가속하거나 선회하지 않습니다.
- 자기 함선의 부품이 사선을 가릴 때 무기가 발사하지 않도록 했습니다. 차폐·방향·보급·발열 등 발사 상태를 확인할 수 있습니다.
- 화면 하단 전술 막대에 균형·돌격·거리 유지·위치 고정 전술과 무장·원자로·조종실·실드 자동 표적 우선순위를 추가했습니다. 지정 해제 버튼으로 자동 표적 선택에 복귀할 수 있습니다.
- 각 구간 출격 전에 세 작전 중 하나를 선택합니다. 작전별 위험·보상과 적의 전투 양상이 달라집니다.

### 보급·복구·저장

- 도달할 수 없는 장치의 수요 때문에 도달 가능한 장치의 보급까지 멈추는 문제를 수정했습니다.
- 수리·귀환 때 승무원이 운반하던 탄약이 사라지는 문제를 수정했습니다. 구조 복구와 탄약 구매는 별도로 유지합니다.
- 탄약고가 가득 찬 상태에서 중포를 철거하고 청사진을 적용해도 반환할 곳 없는 운반 탄약을 보존합니다.
- 승무원실 철거 시 운반자를 우선 보존하며, 재고를 보관할 곳도 운반할 인원도 남지 않는 철거는 현재 상태를 바꾸지 않고 거부합니다.
- 도크에서 조종실을 철거했다 다시 설치하는 동안 승무원이 사라지는 문제를 수정했습니다.
- 모듈 파괴 뒤 승무원·운반 작업·경로를 재검토하며, 손상 직후의 저장 복원을 검증합니다.
- 저장 형식 v2에서 기존 v1 원정을 가져올 수 있습니다. 이전 배포판에서 고정한 도크·전투·회수 완료 승리 저장을 회귀 검사에 사용합니다.
- v2 전투 저장에 비행 중 탄체·최근 피격 기록·회수 잔해를 포함합니다. v1 파일에 원래 없던 탄체 정보는 복원할 수 없습니다.
- 앱의 JSON 내보내기에 사용자 청사진 목록을 함께 담습니다. 가져오기 실패 시 현재 원정과 목록을 유지합니다. v1 파일에 목록이 없으면 기존 목록을 유지합니다.
- 새 원정은 함선·자금·진행을 초기화하지만 사용자 청사진 목록은 유지합니다.

### 유지되는 범위

이 게임은 독자적인 단일 함선·세 구간 캠페인 프로토타입입니다. 원작의 함선 파일, 수치, 전체 Career, 함대·경제·멀티플레이를 지원하는 버전은 아닙니다. 전투 저장은 진행 복구를 위한 것으로, 순수 장식용 파편과 짧은 시각 효과는 복원하지 않습니다.

v2 출시 시 Node.js 검증은 38개 모두 통과했습니다. 실제 승리 보상으로 증설·탄약을 구매하고 구간 사이 저장을 복원하면서 세 구간을 완주하는 경로를 포함합니다. 현재 검증 범위와 실행 명령은 [README.md](README.md)의 테스트 항목을 참조합니다.
