# 원작 분석과 현재 구현 사이의 차이

현재 구현의 근거는 [v4 고정 커밋 추출](../data/starforge_v4.json)과 [동봉 소스](../reference_code/v4/SOURCE.json)다. 원작 관측은 [원작 v2](../data/cosmoteer_original.json)의 해당 레코드·필드에서 상태와 출처를 확인한다. 다음 단계 열은 제안이며 구현된 기능이 아니다.

| 시스템 | v4 실제 상태 | 원작 분석에 따른 차이 | 다음 단계 |
| --- | --- | --- | --- |
| 기하 | 14종 부품 모두 1셀 | 부품마다 공간 비용·문·작업 위치가 다름 | 다칸 정의·앵커·회전, 미확정 좌표와 자체 형상 구분 |
| 연결 | 조종실 중심 직교 구조, walkable 셀 | 구조·문·비벽체 직접 통행·열 포트가 서로 다름 | 세 그래프와 배치 금지 레이어 |
| 승무원 | 보급·수리·소화, 전역 정책 | 운용 인원과 공급 인원이 다른 작업 | 조작석 lease·역할별 작업 허용 |
| 경로 | 장소별 이동 속도, BFS 선택 | 보도 방향이 이동 시간과 경로 선택에 영향 | 시간 비용 경로·revision 캐시 |
| 전력 | 발전기3종, 전지팩6/12/18 자체값 | 원작 전지 크기와 저장·생산 단위의 구분 | 필드별 매핑·축전기 중계·순환 검사 |
| 실드 | 공용 원형 실드·HP 재생 | 발생기별 호·차폐·전지 피격 소모·완충 재가동 | 개별 상태·선분/호 교차·단위 검사 |
| 무장·피해 | 레이저/중포·부위 피해 | 관통량·저항·구조 감쇠의 적용 범위 필요 | 사건 순서·관통 원장·미확정 전체식 차단 |
| 냉각 | 함선 전체 방열량 비례 분배 | 선체 열과 배관 열망이 독립 | 열 포트·타일 상태·열교환 범위 |
| 폭발 | 원자로 고정폭발, 탄약 인접피해 | 저장 자원·완성탄·scorch/파괴 트리거 구분 | 재고 스냅샷·중복 소모 방지·큐 |
| 제작 | 탄약공장1종, 황→탄약 | 다양한 레시피와 목표재고, 일부 단위 상충 | 검증 레시피부터·출력 예약·부분관측 미채택 |
| 교역 | 황 구매·넘친 회수물 매각 | 유한 정거장 재고·수용 공간 | 견적 revision·부분체결·운반 정산 |
| 성장 | 3구역·3계약·개량3계열 | 명성·고용·진영·임무청구가 별도 | 지속 상태·보상 멱등성·회복 경로 |
| 저장 | VERSION4, 이전1/2/3 수용 | 새 공간·자원 체계는 의미 변경 | legacy 보존·도크 전환 초안·카탈로그 해시 |

가장 먼저 해결할 것은 공간과 자원 소유권이다. 문·조작석이 없는데 각도·수치만 옮기거나, 저장 원장을 나누지 않고 자원 종류를 늘리면 설계의 효과를 검증하기 어렵다. 요구사항의 선행 관계와 34개 수용 명세는 [구현 계획](../design/08_Implementation_and_Acceptance.md)에 연결되어 있다.
