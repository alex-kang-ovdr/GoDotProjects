## null·0·빈 배열

`null/unverified`는 미확인, `null/conflict`는 채택할 수 없는 충돌이다. `0`은 원문에 근거가 있는 실제 0이며 빈 배열은 해당 정의에서 목록이 없음을 뜻한다. 핵심 런타임 필드가 null이면 어댑터가 거부한다. 예를 들어 대형 실드 피격 전력값이 null이라고 해서 무료 방어막을 만들지 않는다.

원작 데이터의 `engine_id=null`과 연구자가 붙인 레코드 ID를 구분한다. 프로토타입 개념 연결은 내부 파일 ID를 증명하지 않는다. 한 레코드에서 여러 시대의 필드를 대조할 수 있으므로 새 필드의 `version_scope`가 있으면 그 범위를 우선 읽고, 없으면 레코드의 범위를 사용한다.
