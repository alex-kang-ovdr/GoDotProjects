무기 휠 — TAB을 누른 채 마우스를 움직이거나 1–5로 선택하고, TAB을 놓으면 확정합니다. 특수 능력은 사수·돌파자는 도보에서, 드라이버는 운전 중에 사용할 수 있습니다.

회복과 추격 — 8초 동안 피해를 받지 않으면 체력이 초당 4씩, 최대 50까지 회복됩니다. 방어구는 자동 회복되지 않습니다. 목격자 신고는 1.4초 뒤 접수되며, 경찰 시야를 끊으면 수색이 시작됩니다.

총구 앞이 막혀 있으면 벽에 명중합니다. 목표 차량을 차고 안에 정차하고 수배를 해제하면 인도가 완료됩니다. 선택 조건은 임무 패널에서 확인하세요.

모바일: 왼쪽 스틱 이동, 빈 화면 오른쪽 드래그 시점, 화면 버튼으로 사격·탑승·능력 사용. 상단 ⇄ 버튼으로 어깨 시점 전환. ‘무기 휠’ 버튼으로 열고 무기를 고른 뒤 다시 눌러 확정합니다.
