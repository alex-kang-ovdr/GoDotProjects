# HARBOR RUN — 3D TPS Playable v4

**GAMEPLAY DATA 04** — 기존 v3 실행 소스와 v7 역기획 데이터를 복원·대조하고, 전투·특수 능력·목격 신고·미션 조건을 실제 게임 루프에 연결한 버전입니다. 자체 WebGL2 렌더러, 절차적 로우폴리 캐릭터와 도시를 사용합니다. GTA V 내부 바이너리에서 추출한 데이터나 원작 에셋은 포함하지 않습니다.

## 실행

`index.html`을 WebGL2 지원 데스크톱 브라우저에서 여세요. 타이틀에 **GAMEPLAY DATA 04**가 표시됩니다. HTML 안에 코드·모델·합성 사운드가 포함되어 있으며 게임 실행에는 npm, CDN, 인터넷 접속이 필요하지 않습니다. 채팅의 파일 미리보기는 게임 실행용 브라우저와 다를 수 있습니다.

로컬 파일 실행이 지원되지 않는 환경에서는 Python 3이 설치된 PC에서 `START_WINDOWS.bat`, `START_MAC.command` 또는 `python serve.py`를 실행합니다. 기본 주소는 `http://127.0.0.1:8000/index.html`이며 같은 PC에만 바인딩됩니다. 환경의 보안 정책을 해제하지 마세요.

**검증 범위:** 현재 환경에서 로컬 Chromium 실행과 클라우드 브라우저의 로컬 파일 접근이 각각 정책에 의해 차단됐습니다. v4는 규칙 테스트와 실제 게임 소스를 실행하는 Node VM 통합 검사를 수행했습니다. 이번 버전의 실제 WebGL 화면, 포인터 잠금, 모바일 기기, 연속 무치트 완주를 검증했다고 주장하지 않습니다. 검사별 결과는 `reports/VALIDATION_SUMMARY.md`에 있습니다.

## 달라진 플레이

### 시작 시 접근 방식과 능력 선택

| 선택 | 실제 적용 |
|---|---|
| 우회 회수 | 서쪽 서비스 통로를 안내합니다. 선택 조건은 무사격 완료입니다. |
| 신속 회수 | 동쪽 진입로를 안내합니다. 선택 조건은 게임 시간 5분 이내 인도입니다. |
| 사수 / 집중 사격 | 도보에서 F. 게임 시간 0.35배, 사격·재장전 진행 2배를 적용합니다. |
| 드라이버 / 정밀 운전 | 운전석에서 F. 게임 시간 0.35배와 조향 보정 1.35배를 적용합니다. |
| 돌파자 / 돌파 | 도보에서 F. 플레이어 총격 피해 1.5배, 방어구를 사용하는 피격 피해 0.65배입니다. |

능력은 한 플레이어의 시작 선택입니다. 플레이 중 세 주인공 사이를 전환하는 기능은 없습니다. 에너지 100, 활성 실시간당 12.5 소모로 최대 8초 사용하고, 종료 후 3초가 지나면 실시간당 5씩 회복합니다. 최소 20이 있어야 다시 켤 수 있습니다. 일시정지·사망·허용되지 않는 승하차 상태에서 효과를 종료합니다.

### 무기 휠과 거리별 피해

Tab을 누르면 무기 휠이 열립니다. 마우스 방향 또는 1–5로 선택한 뒤 **Tab을 놓으면 장착**합니다. Esc로 취소합니다. 휠을 열면 게임은 0.15배 속도로 진행되고 사격·장전 시작·점프·탑승을 막습니다. 능력과 동시에 사용해도 시간 배율을 곱하지 않고 둘 중 작은 값을 씁니다. 능력 에너지는 계속 활성 실시간 기준으로 소모됩니다.

모바일에서는 ‘무기 휠’을 눌러 열고, 무기를 선택한 뒤 같은 버튼으로 확정합니다. ‘능력’ 버튼은 F에 대응합니다. 모바일 UI는 작성했으나 이번 환경에서 실제 기기로 검증하지 않았습니다.

| 무기 | 기본 피해 | RPM | 탄창 | 장전 | 감쇠 시작 → 종료 | 최소 피해 비율 |
|---|---:|---:|---:|---:|---:|---:|
| 권총 | 28 | 320 | 12 | 1.6초 | 15 → 50m | 50% |
| SMG | 15 | 780 | 30 | 2.0초 | 20 → 65m | 40% |
| 돌격소총 | 24 | 650 | 30 | 2.3초 | 45 → 120m | 55% |
| 산탄총 | 펠릿당 9 × 8 | 75 | 6 | 3.5초 | 5 → 25m | 20% |
| 지정사수총 | 90 | 45 | 8 | 2.8초 | 120 → 300m | 70% |

감쇠 시작점까지 기본 피해를 유지하고 시작~종료 구간에서 선형으로 감소합니다. 각 무기의 레이 길이를 넘어서 명중하지 않습니다. 산탄총은 펠릿마다 계산하므로 펠릿 수를 두 번 곱하지 않습니다. 헤드샷 배율은 2.4입니다. 방어구·명중 여부·거리·능력에 따라 최종 피해는 달라집니다.

이 표는 원작 실측치가 아니라 복원한 v7 설계값을 자체 실행기에 적용한 수치입니다. 산탄총·지정사수총 탄창은 v3 저장 호환을 위해 6·8발을 유지합니다. 연사 중 쿨다운의 남은 시간을 보존해 고정 60Hz에서도 설정 연사율이 과도하게 낮아지지 않게 했습니다.

### 회복과 목격 정보

마지막 피해 이후 게임 시간 8초가 지나면 체력을 초당 4씩, 최대 50까지 회복합니다. 방어구는 자동 회복하지 않습니다. 차고 인근 보급 지점은 기존처럼 체력·방어구·탄약을 채워 줍니다.

NPC는 시야각·거리·실제 월드 차폐를 통과해야 플레이어를 식별합니다. 비경계 시야는 110°/34m, 잠행 시 거리는 14m, 경계 시 360°/45m입니다. 총성을 들으면 당시 소리 위치를 조사하거나 도망가지만 소리만으로 범인을 확정하지 않습니다. 경찰 차량도 같은 관측 함수를 사용합니다.

목격 민간인·경비의 신고는 1.4 게임초 뒤, 경찰 신고는 다음 접수 단계에서 지연 없이 반영합니다. 신고에는 **목격 당시 위치**를 넣습니다. 시야를 잃어도 확보한 신고는 진행하며 접수 전 사망한 목격자만 제외됩니다. 여러 목격자가 같은 사건을 중복 접수하지 않습니다. 일반 교통차의 사고는 플레이어 범죄·킬·민간인 피해 통계에 합산하지 않습니다.

수배는 이 프로토타입에서 3단계이며 시야 이탈 후 수색 시간은 15 / 25 / 40 게임초입니다. 출동 상한은 작은 맵에 맞춰 2 / 3 / 4대입니다.

### 미션·보상·복원

흐름은 항만 접근 → 목표 차량 운전석 확보 → 신고·추격 해제 → 차고 인도입니다. 경로 표식은 안내용이므로 먼저 목표 차량을 확보해도 진행할 수 있습니다.

인도하려면 살아 있는 플레이어가 목표 차량의 확정 운전석에 있어야 하고, 차량이 차고 중심 ±7m 안에 있으며 속도 절댓값이 0.5m/s 이하여야 합니다. 수배와 미접수 신고가 모두 없어야 합니다. 최초 획득 후 3초 유예를 지나 이 조건을 1.25초 연속 유지하면 완료됩니다. 대기 중 신고·수배·움직임·하차가 생기면 대기 시간을 초기화합니다. 사망·차량 파괴는 완료보다 먼저 판정합니다.

보상은 기존과 같은 **750 CREDIT**, 실행별 1회입니다. 민간인 보호 / 차량 내구도 60% 이상 / 접근별 조건을 평가해 S~C 등급과 메달을 표시합니다. 메달은 추가 화폐를 지급하지 않습니다.

첫 차량 확보 때 체크포인트를 저장합니다. 기본 저장 버전 1에 `gameplayV4` 확장을 추가해 역할·에너지·미션 노드·신고 큐를 보존합니다. 불러오기는 전체를 검사한 뒤 반영하며 저장 당시 활성 능력은 꺼진 상태로 복원합니다. 저장된 신고는 새 실행 세대로 옮겨 오래된 작업이 재적용되지 않게 합니다.

v3 저장에는 새 미션 노드가 없으므로 현재 차량·수배 상태에서 안전하게 다시 판정합니다. 차량·탄약·위치·보상 원장은 유지합니다. 재획득 유예가 적용될 수 있으며 이전 버전에 없던 민간인 피해 기록은 소급 복원하지 못합니다. 로컬 파일의 브라우저별 저장 정책이 다를 수 있으므로 JSON 내보내기도 제공합니다.

## 기존 이동·점프

v3의 `motion.js`, `world.js`, `models.js`를 유지했습니다. 일반 이동의 방향 회전, 급반전 감속, 조준 옆걸음·후진, 발 접지와 착지 스프링, 공중 관성, 점프 버퍼, 낮은 턱 통과, 어깨 시점 전환을 계속 사용합니다. **동작 테스트 코스**에서 확인할 수 있습니다. T는 시작점 복귀입니다.

## 소스와 데이터

| 파일 | 역할 |
|---|---|
| `src/gameplay-data.js` / `gameplay.js` | 무기·시간·능력·회복·수배 수치와 공용 규칙 |
| `src/mission-data.js` / `mission.js` | 접근 분기, 진행 조건, 메달, 미션 저장 검증 |
| `src/perception.js` | 시각·청각 증거와 중복 방지 신고 큐 |
| `src/gameplay-integration.js` | 공용 규칙을 실제 입력·루프·HUD·저장에 연결 |
| `src/main.js` | 이동·전투·차량·NPC·카메라·기본 실행기 |
| `data/recovered_v7_*.json` | 이전 역기획 패키지에서 복원한 원본 설계 데이터 |
| `data/gameplay_v4.json`, `mission_v4.json`, `perception_v4.json` | 현재 소스에서 내보낸 수치와 출처 분류 |
| `data/recovery_map.json` | 복원 출처 → 적용 코드 → 차이·보류 범위 |
| `docs/PLAYABILITY_ANALYSIS_v4.md` | 문제 분석, 적용 결정, 남은 플레이 검증 |

수정 시 `src`가 기준입니다. `node tools/export_data.cjs`로 JSON 표를, `python build.py`로 단일 HTML을 다시 만듭니다. JSON 표만 바꿔도 HTML이 바뀌는 구조는 아닙니다.

```bash
node tools/export_data.cjs
python build.py
node tests/logic.test.cjs
node tests/motion.test.cjs
node tests/polish.test.cjs
node tests/gameplay_rules.test.cjs --report
node tests/mission_v4.test.cjs
node tests/perception.test.cjs
node tests/gameplay_v4_runtime.cjs
node tests/combat_v4_runtime.cjs
node tests/perception_v4_runtime.cjs
```

`runtime` 검사는 실제 게임 코드와 월드·모션 계산을 실행하지만 DOM, WebGL 출력, 오디오, RAF, 브라우저 저장소는 대체합니다. 브라우저 검사 `tests/gameplay_v4_browser.py`도 포함했으나 이번 실행에서는 브라우저 시작 전에 차단되어 게임 검사를 수행하지 못했습니다. 구버전 브라우저 검사들은 v3용 기대값을 포함하므로 v4 통과 증거로 사용하지 않습니다.

## 범위와 남은 확인

3인 주인공 전환, 5성 수배, 경찰 헬기, 원작 크기의 맵, 월드 스트리밍, 성장 시스템, 완전한 래그돌은 구현 범위에 포함되지 않습니다. 현재 미션은 자체 항만 차량 회수 임무입니다. 실제 화면 품질·터치 조작·지속 저장·사용자 GPU 성능·막힘 없는 전체 운전 경로와 난이도는 별도의 브라우저 플레이 확인이 필요합니다.

공식 동작 근거와 자체 튜닝 구분은 분석 문서의 출처 목록 및 `gameplay-data.js`의 `provenance`를 참고하세요.
