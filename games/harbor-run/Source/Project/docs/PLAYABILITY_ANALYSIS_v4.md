# Harbor Run v4 — 게임플레이 분석·복원 데이터 반영

작성 기준: 2026-11-18 / 대상: Harbor Run v3 실행 패키지 + GTA5 3D TPS ReverseDesign v7.

## 1. 복원 범위와 결과

제공된 최신 HTML과 실행 ZIP, v7 기획 ZIP을 복원해 대조했습니다. 이번 작업의 ‘복원’은 **이전 대화에서 만든 프로젝트 소스·설계 데이터의 복원**입니다. GTA V 실행 파일을 분석해 원작 내부 테이블을 추출하거나, 원작의 모든 행동을 실측했다는 의미가 아닙니다.

v3는 이미 차량 회수 미션, 보행·점프·엄폐·사격·운전·수배를 수행하는 독립 WebGL 프로토타입이었습니다. v7 기획에는 무기별 사거리 감쇠, 시간 도메인, 역할별 능력, 신고 정보 경계와 임무 진행 조건이 있었으나 실행기와 연결되지 않은 부분이 남아 있었습니다. v4는 그 차이를 코드로 연결했습니다.

원본 v7 데이터 두 개는 `data/recovered_v7_gameplay.json`, `data/recovered_v7_mission.json`으로 보존했습니다. 현재 실행 수치는 `src/gameplay-data.js`, `mission-data.js`, `perception.js`가 기준이며, `tools/export_data.cjs`로 JSON을 내보냅니다. 파일별 적용 위치와 미반영 범위는 `data/recovery_map.json`에 기록했습니다.

## 2. 플레이의 문제와 수정

| 체크포인트가 새 미션 런타임보다 먼저 저장될 수 있음 | 첫 획득 이벤트 이후 확정 체크포인트 | 재시작 후 확보 상태·좌석·신고 일치 |

## 3. 복원한 수치를 적용한 기준

### 그대로 적용한 핵심 값

v7에서 무기 5종의 기본 피해·RPM·장전 시간·사거리 감쇠 구간·최소 피해 비율을 가져왔습니다. 사수와 드라이버의 세계 시간 0.35, 사수의 행동 진행 2.0, 에너지 최대 100과 실시간당 12.5 소모도 반영했습니다. 무기 휠 0.15, 60Hz 시뮬레이션, 250ms 이상 프레임 정지 시 안전 일시정지 정책을 반영했습니다. 수배 1~3단계 수색 시간은 15/25/40초입니다.

### 실행기와 저장 호환을 위해 조정한 값

- v7 산탄총 8발·저격총 5발 제안은 그대로 쓰지 않고 v3의 6발·8발을 유지했습니다. 기본 저장 검증과 기존 탄창·예비탄을 깨뜨리지 않기 위한 결정입니다.
- v7 `sniper_01`은 현재 `marksman` ID로 연결했습니다. 원작 무기 분류를 복원했다는 의미가 아닙니다.
- 돌파 피격 배율은 v7의 0.7에서 v4 제안 0.65로 조정했습니다. 원작 공식 설명의 배율과 동일하다고 주장하지 않습니다.
- 경찰은 기존 3단계와 2/3/4대 출동 상한을 유지합니다. v7의 4~5단계와 6~8대 정책을 작은 현재 맵에 무조건 적용하지 않았습니다.
- 체력 회복 50/8초/초당4, 기본 시야 110°/34m, 잠행14m, 경계45m, 신고1.4초, 메달·차고 정차1.25초는 자체 프로토타입 규칙입니다.
- 캐릭터 이동·점프 수치와 애니메이션은 v3 수정본을 유지합니다. 큰 맵용 차량 최고속도와 월드 크기 제안을 덮어씌우지 않았습니다.

`gameplay-data.js`의 숫자별 `provenance`는 자체 설계값임을 표시합니다. 공식 자료는 동작 유형의 근거이고 수치 테이블의 측정 근거가 아닙니다.

## 4. 시간과 입력 처리

UI는 표시용 시간으로, 이동·물리·경찰 수색·미션 제한 시간은 게임 시간으로, 능력 자원은 일시정지를 제외한 활성 실시간으로 처리합니다. 따라서 집중 능력을 2초 쓰면 게임은 약 0.7초 진행하고 에너지는 25 감소합니다. 휠을 함께 쓰면 같은 2초에 게임은 약 0.3초 진행하지만 에너지 소모는 같습니다.

프레임이 250ms 이상 멈추면 일시정지하고 입력·능력을 해제합니다. 그보다 짧은 프레임은 UI 보간용 시간만 제한하고 활성 실시간은 모두 반영합니다. 100~250ms 프레임에서 에너지 소모까지 느려지는 결함을 별도 검사로 방지했습니다.

휠 선택 중 발사·장전 시작·점프·승하차를 차단하고, 닫을 때 발사 유지 입력을 비웁니다. 자동 발사 쿨다운은 사격 중 다음 발사 간격으로 잔여 시간을 이월하고, 유휴 상태에서는 누적 부채를 버립니다. 집중 능력의 행동 진행 2배에도 같은 규칙을 적용합니다.

## 5. 신고·추격의 정보 경계

시각 판정 성공일 때만 관측 위치를 반환합니다. 청각은 신원 확인 결과를 만들지 않습니다. 총성이 난 당시 좌표로 조사·도주 반응을 보일 수 있지만, 숨은 플레이어의 새 좌표를 계속 갱신하지 않습니다.

보고 큐는 사건 ID, 목격자 ID, 관측 위치·시각, 접수 예정 시각, 실행 세대(epoch)를 저장합니다. 같은 절도는 실행별 고정 ID로 묶고, 연속 총성은 짧은 구간에서 묶습니다. 신고가 접수되기 전에 목격자가 죽으면 그 후보를 취소하지만 다른 생존 목격자는 계속 신고할 수 있습니다. 접수 뒤의 사망은 이미 확보한 신고를 지우지 않습니다.

경찰의 마지막 목격 지점은 실제 관측 또는 접수된 증거로만 갱신합니다. 유효 관측자가 없으면 수색 시간이 줄어들며 플레이어의 현재 위치를 전달하지 않습니다. 일반 교통 차량의 NPC 충돌은 플레이어 행동 통계에 귀속하지 않습니다.

## 6. 미션과 저장

임무는 `briefing → recon → acquire → escape → deliver → complete`의 검증된 노드를 사용합니다. 경로 비컨은 선택 안내이며 반드시 밟아야 하는 관문이 아닙니다. 획득 후 차량에서 내리면 복귀 목표로 바뀌지만 획득 기록과 체크포인트를 중복 생성하지 않습니다.

완료 조건은 생존, 살아 있는 목표 차량, 확정 운전석, 차고 구역, 정차, 무수배, 신고 큐 비움, 획득 후 유예, 연속 인도 대기입니다. 같은 tick의 사망·차량 파괴는 성공보다 먼저 판정합니다. 보상 원장 키는 기존 실행 ID를 사용해 750을 한 번만 지급합니다.

저장 기본 버전은 1을 유지하고 v4 확장을 추가했습니다. 역할·에너지·임무 스냅샷·신고 큐를 임시 객체에서 먼저 검증합니다. 잘못된 발사 수, 카메라 수치, ID 순번, 좌석, 신고 미러, 미션 상태 등을 거부합니다. 수색 시간 0을 전체 시간으로 다시 채우지 않고, 카메라 0도 유효 값으로 복원합니다. 복원된 경찰 차량 ID의 최대 번호 다음부터 새 차량을 생성합니다.

v3 저장의 누락된 신규 상태는 보수적으로 다시 구성합니다. 과거 민간인 피해나 모든 미션 노드를 원본에 없던 정보로 만들어내지 않습니다. 이전 저장 변환 여부를 확장에 기록하고 결과 화면에도 집계 한계를 표시합니다. 브라우저 영구 저장 보존 여부는 이번 환경에서 검사하지 못했습니다.

## 7. 확인한 결과와 확인하지 못한 것

최신 검사 수와 실행 로그는 `reports/VALIDATION_SUMMARY.md` 및 개별 JSON 보고서가 기준입니다. 단위 검사는 규칙과 수학 조건을, Node VM 검사는 실제 `main.js`·어댑터·월드·모션·모델 총구 계산과 합성 입력 핸들러 연결을 확인합니다.

실제 전투 코드의 소총은 12 시뮬레이션초에 130발이며, 30/60/120Hz로 입력 시간을 나눠도 같은 결과였습니다. 집중 능력에서는 2 게임초에 44발로 연속 시간 기준 기대 43.33발의 한 tick 오차 범위 안에 있습니다. 산탄총은 명중 fixture에서 8×9=72 피해와 탄약 1발 소모를 확인했습니다. 이 값은 실제 GPU FPS나 사용자 화면 지연 측정치가 아닙니다.

임무 완료 검사는 테스트에서 차량과 목격자 상태를 배치해 조건을 검증합니다. 도심에서 항만까지 직접 운전하고 실제 추격을 피해 돌아오는 연속 완주가 아닙니다. 기존 v3에서도 연속 주행 난이도·정체 문제가 별도 과제로 남아 있었으므로 v4에서 해결됐다고 표시하지 않습니다.

이번 환경의 로컬 Chromium은 소켓 생성에서 차단됐고 확장 권한 요청도 정책으로 거부됐습니다. 연결 브라우저를 사용할 수 없어 허용된 클라우드 대체 경로를 확인했으나 로컬 파일 URL 역시 정책상 금지되었습니다. 제한을 우회하지 않았으며, 실제 WebGL 화면·포인터 잠금·모바일 기기·지속 저장은 **미검증**입니다. 이전 버전의 이미지나 통과 보고서를 v4 증거로 재사용하지 않았습니다.

## 8. 후속 플레이 확인 항목

다음 항목은 코드 검사를 더 늘리는 것보다 실제 브라우저에서 확인할 가치가 큽니다.

1. 두 접근 방식으로 차고 출발부터 인도까지 연속 주행하며 도로 정체·경비 피격·차량 손상과 실패 위치를 기록합니다.
2. 1366×768, 휴대폰 가로 화면에서 무기 휠·능력 게이지·목표 조건이 시야와 이동 버튼을 가리지 않는지 확인합니다.
3. 걷기·급반전·조준 후진·점프·착지에서 v3 동작 품질을 화면으로 비교합니다.
4. 일반 브라우저에서 Tab 유지/해제, Esc 취소, 창 전환, 포인터 잠금 해제 뒤 입력이 남지 않는지 확인합니다.
5. 같은 주소에서 브라우저를 닫고 다시 열어 v4 저장, v3 JSON 가져오기, 획득 체크포인트를 확인합니다.
