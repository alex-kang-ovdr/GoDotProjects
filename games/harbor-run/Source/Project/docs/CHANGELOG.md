# v3 — Motion & Control

v2의 모델 정면 좌표계와 진행 방향 일치 보정을 유지하고 아래를 추가했습니다.

- 급반전 시 입력 방향을 바라보며 감속. 정지·조준의 제자리 발 교체, 제한된 상체 조준 회전.
- 연속적인 상승/정점/하강 발 위치. 정확 적분 감쇠 스프링 착지. 연속 무기 지지 손 블렌딩.
- 28cm 이하 낮은 턱 통과와 선행 지지면/상승 공간 검사. 신발 롤의 밑창 여유 보정.
- 순수 표시 포즈 보간(시뮬레이션과 독립), 각도 래핑 및 순간이동 예외.
- V/⇄ 어깨 전환, 카메라 충돌 안전 검사, FOV와 흔들림 설정, 달리기 시 소폭 FOV 변화.
- Z/터치 걷기 토글. 잠행과 질주 동시 입력 시 잠행 우선.
- 접촉 이벤트 발소리, 착지음.
- 메뉴에서 바로 들어가는 모션 테스트 코스와 체크리스트. 테스트 전용 객체는 세션 종료 시 제거.
- 신규 순수 논리/리그 검사 10개, WebGL 검사 27개. 기존 161개 재실행.
