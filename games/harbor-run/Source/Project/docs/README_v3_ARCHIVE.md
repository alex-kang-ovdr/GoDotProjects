# HARBOR RUN — 3D TPS Playable v3

**MOTION & CONTROL 03** — v2 게임을 기반으로 이동·점프·카메라·접지 애니메이션을 개선한 실행 버전입니다. 기획 문서가 아니라 실제 WebGL2 싱글플레이 게임입니다. 자체 로우폴리 도시와 절차적 캐릭터를 사용하며 GTA V 에셋, 전체 맵, 원작 수치를 포함하지 않습니다.

## 실행

`index.html`을 WebGL2 지원 브라우저에서 여세요. 코드·모델·합성 사운드가 HTML 안에 들어 있습니다. 게임 실행에는 npm, CDN, 인터넷, 별도 에셋 다운로드가 필요하지 않습니다. 채팅 앱의 파일 미리보기 대신 일반 브라우저에서 실행하세요.

로컬 파일 접근이 제한되는 환경에서는, Python 3이 이미 설치되어 있을 때 `START_WINDOWS.bat` 또는 `python serve.py`로 실행합니다. 기본 주소는 `http://127.0.0.1:8000`입니다. 이 서버는 기본적으로 같은 PC에서만 접근합니다. 보안 정책을 해제할 필요는 없습니다. 서버를 종료하려면 Ctrl+C를 누릅니다.

기존 v2 HTML 대신 새 파일을 여세요. 타이틀에 **MOTION & CONTROL 03**이 표시됩니다.

## 먼저 확인할 곳

타이틀의 **동작 테스트 코스**를 선택하면 AI와 차량 간섭이 없는 해안 코스에 들어갑니다. 24cm 발판은 걸어서 통과하고, 52cm 장애물은 점프로 넘을 수 있습니다. 걷기·질주 거리, 점프 후 착지, 조준 옆걸음, 어깨 전환을 체크합니다. `T` 또는 상단 ↺ 버튼으로 시작점에 돌아옵니다. 테스트 모드에서는 수동 저장을 거절하여 기존 캠페인 저장을 덮어쓰지 않습니다.

**임무 시작**은 기존의 항만 차량 회수 미션입니다. **자유 플레이**는 차량·전투·경찰을 포함하는 원래 샌드박스입니다. 테스트 코스에서 타이틀로 나와 임무를 시작하면 코스 전용 충돌체가 제거됩니다.

## v3 변경점

| 영역 | 구현 |
|---|---|
| 방향 전환 | 일반 이동은 입력 방향으로 회전하며, 급반전 시 이동 목표 속도를 낮춰 뒷걸음 미끄러짐을 줄입니다. 회전 속도에 상한을 둡니다. 조준 중 후진·옆걸음은 그대로 유지합니다. |
| 제자리 회전 | 조준한 채 카메라를 돌리면 한 발을 지지하고 다른 발을 짧게 들어 옮깁니다. 상체는 제한된 범위에서 조준을 따라갑니다. |
| 보행·팔 | 실제 이동 거리에 맞춘 보행 위상과 발 앵커를 유지합니다. 질주로 바뀔 때 왼손이 총기 지지 자세에서 스윙으로 연속적으로 전환합니다. |
| 점프 | 공중 포즈가 수직 속도에 따라 연속적으로 바뀝니다. 착지는 감쇠 스프링으로 흡수합니다. 기존 공중 관성·천장 검사·점프 버퍼·코요테 타임도 회귀 검사했습니다. |
| 낮은 턱 | 높이 28cm 이하의 턱에서 상승한 캐릭터 공간과 앞쪽 지지면을 검사하고 통과합니다. 높은 장애물은 점프해야 합니다. 전용 원형 하부 지지 샘플을 적용합니다. |
| 카메라 | `V`/⇄로 어깨 전환, 시야각 설정, 흔들림 강도 설정을 제공합니다. 벽 충돌 시 즉시 당기고 복귀는 완화하며, 보간된 위치도 충돌 검사합니다. |
| 표시 보간 | 고정 60Hz 시뮬레이션 사이의 플레이어 포즈와 카메라 위치를 보간합니다. 게임 판정 상태는 바꾸지 않습니다. 고주사율 화면의 미세 끊김을 줄이기 위한 처리이며 FPS 보장은 아닙니다. |
| 접촉음 | 실제 발 디딤·착지 이벤트에 가벼운 합성 소리를 연결했습니다. 렌더 호출마다 소리가 나지 않습니다. |

## 조작

| 행동 | 입력 |
|---|---|
| 이동·시점 | WASD / 마우스 |
| 걷기·달리기 전환 | Z (기본은 달리기) |
| 질주·잠행·점프 | Shift / Ctrl / Space |
| 조준·사격·재장전 | 우클릭 / 좌클릭 / R |
| 어깨 시점 전환 | V / 화면 상단 ⇄ |
| 무기 변경 | 1–5 / 마우스 휠 |
| 엄폐·상호작용 | Q / E |
| 차량 운전 | W·S 가속·제동·후진, A·D 조향, Space 핸드브레이크 |
| 지도·도움말·일시정지 | M / H / Esc 또는 P |
| 개발자 패널 | F3 |
| 테스트 코스 시작점 | T / 화면 상단 ↺ |

모바일은 가로 화면을 기준으로 왼쪽 스틱 이동, 오른쪽 빈 화면 드래그로 시점, 화면의 사격·조준·점프·질주·걷기 버튼을 사용합니다. 걷기는 토글, 질주는 누르고 있는 동안 동작합니다. 상단 ⇄로 어깨를 바꿀 수 있습니다. 물리 기기가 아닌 터치 에뮬레이션에서 검사했습니다.

## 첫 미션

시작 지점의 청록색 차량에 E로 탑승하고 노란 표시를 따라 항만으로 이동합니다. 정차 후 내려 노란 회수 차량에 탑승합니다. 수배가 생기면 경찰 시야를 끊고 수색이 끝날 때까지 피하세요. 목표 차량을 녹색 차고 구역 안에 정차하면 750 credit을 받습니다. 목표 차량 운전·지정 구역·정차·수배 해제가 모두 필요합니다.

승하차 중 사격을 막고, 총구가 벽에 가려지면 벽 너머 적에게 피해를 주지 않습니다. 미션 체크포인트와 보상 중복 방지, JSON 저장 내보내기/가져오기를 유지했습니다. 저장 형식은 v1/v2와 동일한 버전 1이며 일반 미션 스냅샷 복원은 회귀 검사했습니다.

## 성능·설정

느리면 일시정지 → 그래픽 **낮음**을 선택하세요. 카메라 흔들림 기본값은 35%이며 0으로 끌 수 있습니다. 기본 시야각은 55–85도 범위에서 조절합니다. 조준 시야각은 별도 유지됩니다. 현재 새 카메라 선호 설정은 세션 동안만 유지됩니다.

## 소스·검증

- `src/motion.js`: 발 접지, 관절 IK, 공중 포즈, 착지 스프링, 시각 보간.
- `src/main.js`: 게임 루프, 입력, 캐릭터 모터, 카메라, 테스트 코스, 전투/미션 연동.
- `src/world.js`: 지면·장애물·낮은 턱 통과·카메라 레이 검사.
- `src/models.js`: 절차적 모델, 총구 위치, 합성 사운드.
- `src/engine.js`: 자체 WebGL2 인스턴싱 렌더러.
- `src/logic.js`, `src/data.js`: 게임 판정과 수치.
- `src/template.html`, `src/style.css`: 화면·설정·모바일 UI.

```bash

python tests/polish_browser.py
```

브라우저 실행 경로 기본값은 `/usr/bin/chromium`이고 `CHROMIUM_PATH` 환경변수로 바꿀 수 있습니다. 테스트의 ANGLE 옵션은 검사 컨테이너용이며 일반 게임 실행에서는 브라우저 기본 설정을 사용하세요.

**현재 빌드 자동 검사: 총 198/198 통과.** 자세한 결과와 범위는 `reports/VALIDATION_SUMMARY.md`를 참고하세요. 이 숫자는 기능 단위·수학 불변 조건·브라우저 픽스처 검사의 합이며 198개의 완전한 플레이 세션을 뜻하지 않습니다.

## 제한

모션캡처·스킨 메시가 아니라 절차적 로우폴리 리그입니다. 완전한 래그돌, 파쿠르, 움직이는 발판, 정교한 차량 위 착지는 포함하지 않습니다. 수평 면과 축 정렬 장애물 기반 모터이며 범용 삼각형 지형 컨트롤러가 아닙니다. 전체 도시를 한 번에 로드합니다. 교통·추격은 단순 모델입니다.

이번 v3에서는 미션 판정 회귀 검사는 수행했지만 무치트 연속 주행 완주는 다시 실행하지 않았습니다. v2의 자동주행에서 복귀 중 정체·피격 실패가 있었으며, 이번 모션 개선이 그 주행 AI/난이도 문제까지 해결했다는 뜻은 아닙니다. 실제 모바일 장치 성능, 사용자 GPU, 로컬 파일 실행 정책, 브라우저를 종료했다 켠 뒤 저장 유지도 별도 확인이 필요합니다.
