# 구현 범위와 설계 대응

## v7에서 실제 게임으로 옮긴 규칙

카메라 조준과 총구 충돌을 분리했습니다. 발사 요청 자체가 불가능한 상태면 탄약이 줄지 않지만 유효 발사가 벽에 막혔으면 탄약·총성·반동은 발생합니다. 재장전은 `Magazine`의 단일 커밋 시점에서 탄약을 이동하며 취소·반복 알림에 의해 탄약이 늘지 않습니다.

`Seat`는 유효 예약 토큰과 세대, 생존, 속도를 재확인하고 점유·운전권을 함께 확정합니다. 주행 중 하차는 거절합니다. NPC가 운전하는 차량의 탑승/탈취 표현은 간소화되어 있으며 원작의 사람 끌어내기 애니메이션 전체를 구현하지 않았습니다.

실제 경찰 시야는 공간 차폐 검사에서 생성합니다. 인지 간격 동안 플레이어의 새 좌표를 지식 모델에 전달하지 않도록 마지막 관측 좌표를 캐시합니다. 여러 경찰의 관측을 모아서 추격/수색을 판정하며 신고 이벤트 ID를 중복 처리하지 않습니다. 이 모델은 Rockstar 내부 AI를 복구한 결과가 아닙니다. 시야각·외형 식별·번호판 추적 등은 범위 밖입니다.

미션 완료는 생존·회수 차량 상태·운전석 점유·차고 구역·정차·수배 0의 동시 충족을 요구합니다. 보상 키는 안정적인 임무 실행 ID이고 재시도에 의한 중복 지급을 막습니다. JSON 저장 검증을 통과하기 전에는 현재 월드를 변경하지 않습니다.

## 렌더와 물리

자체 WebGL2 렌더러를 사용합니다. 배치 인스턴싱, 절차적 기본 메시, 그림자 맵, 지면·물·하늘 셰이더로 구성합니다. 충돌은 정적 AABB와 동적 원형/박스 근사입니다. 고정 1/60초 업데이트를 최대 6회 처리하고 렌더링은 requestAnimationFrame을 사용합니다. 긴 프레임에서 무제한 따라잡기를 하지 않습니다. 게임 종료/숨김/메뉴 상태는 입력을 해제합니다.

카메라 충돌은 단순 확장 박스 검사이며 원작 수준의 모든 near-plane 모서리 상황을 보장하지 않습니다. 야자수·가로등 등 일부 장식은 이동/카메라 충돌에서 제외했습니다. 원거리 시뮬레이션 LOD·정교한 차량 서스펜션·전 주민 스케줄은 구현하지 않았습니다.

## 데이터 수정

`src/data.js`의 무기 `cap`, `reserve`, `damage`, `rpm`, `reload`, `spread`, `range` 및 차량 파라미터를 수정한 후 `python build.py`를 실행합니다. 수치는 원작 실측값이 아닙니다. F3 패널의 치트/상태 변경은 QA용이며 임무 정상 진행에 필요하지 않습니다.

## 테스트 인터페이스

`window.HARBOR`와 `window.HARBOR_TEST`는 자동 검증용 인터페이스입니다. 브라우저 테스트에서 게임의 실제 step/render/input 및 공통 판정 함수를 호출합니다. 일부 통합 케이스는 상태 fixture로 특수 상황을 만들고, 별도 연속 주행 시나리오는 일반 차량/캐릭터 제어로 진행합니다. 테스트용 자율주행 제어기는 플레이 기능에 포함되지 않습니다.

## 후속 검증이 필요한 위험

실제 기기의 GPU 성능, 모바일 파일 열기, Pointer Lock 허가, localStorage origin별 지속성, JSON 파일 다운로드/재가져오기, 장시간 세션, 교통 정체·차량 엉킴, 복잡한 엄폐물/근접 카메라를 추가 검증해야 합니다. 브라우저 자동화 PASS는 인간 플레이테스트나 원작 재현도 인증이 아닙니다.
