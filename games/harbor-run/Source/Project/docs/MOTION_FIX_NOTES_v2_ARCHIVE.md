# 모션 구현 메모

## 축 규약

- 월드: Y up. 모델: local -Z forward, local +X right.
- 게임 yaw: forward=(sin(yaw), 0, -cos(yaw)).
- 모델 행렬: compose(position, [0, -yaw, 0]).
- world to local: x'=cos(yaw)*dx+sin(yaw)*dz, z'=-sin(yaw)*dx+cos(yaw)*dz.
- 일반 HM.compose는 변경하지 않습니다. 게임 yaw의 부호를 모델 경계에서만 변환합니다.

## 시뮬레이션 / 렌더링

HarborMotion.update(actor, dt, supportHeight)는 고정 물리 틱에서 한 번 호출합니다. 모델 렌더링은 HarborMotion.pose(actor)로 읽기만 합니다. 렌더 호출 횟수가 많아져도 위상이나 발 앵커가 추가로 움직이지 않습니다.

발 접지는 실제 수평 변위로 위상을 진행시키고, 지지 구간에는 월드 앵커를 유지합니다. 발판 높이는 world.supportHeight에서 조회합니다. 큰 순간이동은 리그를 초기화하여 이전 위치로 다리가 늘어나지 않게 합니다. 큰 방향 역전으로 다리 도달 범위를 벗어나는 경우에는 안전하게 앵커를 회복합니다.

## 점프 제안값 (원작 데이터 아님)

- 점프 초기 수직 속도: 6.0 m/s.
- 중력: 20 m/s².
- 이론적 정점: 0.9 m. 60Hz 반암시적 적분의 실제 검사값은 보고서 참조.
- 도약 준비: 약 0.06초, 물리 틱에 양자화.
- 입력 버퍼: 0.12초. 발판 이탈 허용: 0.085초.
- 공중 입력 가속 제한: 3.2 m/s². 입력이 없으면 수평 관성 유지.
- 재도약 제한: 0.16초. 접지 또는 유효한 발판 이탈 구간이 추가로 필요.

준비는 물리 위치를 내리는 대신 골반 포즈로 표현합니다. 발사된 이후 공중에서 걷기 위상은 정지합니다. 착지 자세는 실제 접지 전환에서 생성하고 약 0.24초 동안 흡수/복귀합니다.

## 중요한 QA 차이

기존 `Jump lands without sinking` 검사는 무조건 Y=0을 기대했습니다. v2에서는 시작 위치의 포장면이 Y=0.22이므로 시작 바닥 높이에 정확히 복귀하는 검사로 변경했습니다. 허용 오차를 넓히거나 실패를 삭제한 것이 아니라 기준 지면을 바로잡았습니다.

전체 자동주행 스크립트는 실제 경찰/교통을 포함하는 비결정적 시나리오입니다. v2의 1회 실행은 복귀 중 실패했으므로 미션 전체 통과라고 기록하지 않습니다.
