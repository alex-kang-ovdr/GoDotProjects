# Crownfall Arena 4.4 — 방진 강화와 실시간 개발자 테스트

2026-11-16 · 프로그램 버전 4.4.0 · 신규 전투 규칙 4

## 변경 결과

밀집보병은 방진 중 공격하지 않고 방어에 집중한다. 보호 대형의 기본 피해 감소율을 **35%에서 70%**로 높였고, **방패 돌격 중에만 공격**한다. 외부 좌측 패널에 카드별 밸런스를 실시간 조절하고 같은 전장의 두 진영을 직접 제어하는 개발자 테스트를 추가했다.

| 항목 | 새 경기 기본 동작 |
|---|---|
| 방진 피해 감소 | 70%. 보호 조건 충족 시 원래 피해 100 중 30을 받음 |
| 방진·집결·재집결 | 이동과 대형 유지, 공격 없음 |
| 방패 돌격 | 대형 방어를 해제하고 빠르게 이동하며 공격 |
| 돌격 비용·시간·대기 | 기본 엘릭서 1 · 5초 · 발동 시점부터 14초 |
| 기존 저장·리플레이 | 규칙 2/3을 유지. 기존 규칙 3의 35% 감소·방진 공격도 당시 규칙으로 재생 |

피해 감소는 단순 상태 이름이 아니라 실제 생존 인원·정렬·배치 완료·기절 여부를 확인한다. 기본 병력 수는 6명, 소환 비용 5, 방진 속도 24와 돌격 속도 68이다. 자세한 계약은 [PHALANX.md](PHALANX.md)를 참고한다.

## 개발자 테스트 사용법

1. 외부 좌측 **개발자 테스트 시작**을 누른다. 현재 개인 덱을 양 팀에 사용하고, 상대 AI는 꺼지며 양 팀 무한 엘릭서는 켜진다.
2. 양쪽 손패에서 카드를 선택해 배치하거나, **조절할 카드**를 고른 뒤 **아군 배치 / 적군 배치**로 덱 밖 카드도 직접 배치한다.
3. **아군·적군 버튼 또는 T**로 제어 진영을 바꾼다. 인게임 손패·다음 카드·엘릭서·조준·분대 스킬과 카드 상세가 함께 전환된다.
4. **양 팀 공통 / 아군만 / 적군만**을 선택하고 숫자·슬라이더를 조절한다. 적용 버튼 없이 즉시 반영된다.
5. 전장 초기화나 다시하기로 현재 수치·치트를 유지한 채 비교를 반복한다. 카드별·전체 기본값 복원은 편집 진영 선택을 따른다.

모바일 설정 서랍에서 손패 또는 직접 배치를 고르면 서랍을 닫고 전장으로 돌아간다. 직접 배치는 여러 번 필드를 눌러 반복할 수 있고 Esc·취소로 해제한다. 조작 진영을 바꾸어도 가로 전장의 적 왼쪽·아군 오른쪽 관계는 유지한다. 일반 대전은 계속 아군만 제어한다.

## 조절 항목과 실시간 적용

| 카드 종류 | 지원하는 수치 |
|---|---|
| 공통 | 소환 비용 |
| 병력·건물 | 최대 HP, 피해, 공격 간격, 사거리, 배치 시간, 투사체 속도, 광역 공격 반경 |
| 이동 병력 | 이동 속도 |
| 주문 | 피해, 타워 피해, 주문 반경, 지속 시간 |
| 방어 건물 | 수명 |
| 밀집보병 | 대형 피해 감소율, 돌격 속도, 능력 비용·지속 시간·재사용 대기 |

현재 병력의 수치를 바꿀 때 남은 HP 비율과 공격 대기 진행률을 유지한다. 배치 준비·건물 수명·분대 능력의 진행률도 해당 수치 변경에 맞춰 유지한다. 죽은 병사를 부활시키거나 기절을 해제하지 않는다. 이미 발사된 투사체, 예약된 주문과 생성된 지속 영역은 이전 수치로 처리하고, 새 공격·소환부터 변경값을 사용한다.

두 진영의 값이 다르면 공통 편집기에 ‘값 다름’을 표시한다. 공통 편집은 변경한 항목만 양 팀에 적용한다. 0 피해·0 비용도 표시할 수 있으며, 피해 감소율은 퍼센트 입력을 엔진의 비율로 변환한다. 전역 `CARDS`를 변경하지 않고 해당 Game의 진영별 정의를 사용한다.

## 치트와 반복 실험

- **아군·적군 무한 엘릭서:** 각각 켜고 끌 수 있다. 정상 비용을 소비 통계에 기록한 직후 자원을 10으로 보충하며, 손패와 스킬도 같은 자원을 사용한다.
- **스킬 재사용 대기 없음:** 재사용 대기만 제거한다. 이미 돌격 중인 분대는 중복 발동하지 않는다.
- **양 진영 어디든 배치:** 진영 제한을 해제한다. 벽·강·기존 몸체의 충돌과 가까운 합법 위치 탐색은 유지한다.
- **양 팀 병력 제거·타워 회복:** 실행 중 또는 일시정지 중 조작할 수 있다.
- 기존 대상 치트, 상대 AI 켜기·끄기, 1·2·4배속과 일시정지도 사용할 수 있다.

개발자 테스트는 일반 전적과 도전 진행에 반영하지 않는다. 테스트 안에서 전장을 초기화하면 수치·치트를 유지한다. 일반 모드로 이동한 뒤 새 테스트를 시작하면 기본값을 사용한다. 진행 중 테스트를 저장하고 이어가면 전장 상태와 함께 조절값·치트·선택 진영을 복원한다.

## 저장과 과거 기록

새 전투는 규칙 4를 사용하고 기존 snapshot·replay 포맷 2는 유지한다. 개발자 상태는 `config.developerMode:true` 및 최상위 `developer` 필드에만 저장한다. 개발자 전투를 일반 리플레이로 내보내거나 불러오는 것은 거절하고, 전체 스냅샷 이어하기를 사용한다.

개발자 명령에만 실제 소비한 `cost`를 기록하여 경기 중 비용 변경도 전투 분석에서 정확히 합산한다. 직접 소환은 `developer-spawn` 명령으로 기록하며 소환 분대와 연결한다. 덱 밖 밀집보병도 해당 소환 출처를 검증하여 스킬을 사용할 수 있다.

새 캠페인 context에는 규칙 4를 명시한다. 과거 context에 규칙 필드가 없으면 3으로 해석하여 기존 전투를 이어가며, 규칙 4의 시도를 규칙 3 전투에 연결하는 요청은 거절한다.

## 검증 결과

최종 소스에서 `node --test --test-reporter=tap tests/*.test.mjs`를 실행하여 **190개 통과, 실패 0, 건너뜀 0**을 확인했다.

| 범위 | 검증 내용 |
|---|---|
| 개발자 엔진 12개 | 경기·진영별 격리, 입력 원자 검증, HP·대기 비율, 과거 투사체·주문·독 수치, 직접 소환·분대 출처, 치트, 엄격한 복원·리플레이 차단 |
| 실제 앱 함수 5개 | 양 팀 HUD·손패·비용·상세 동기화, 반복 직접 배치, 정상 손패 전환, 현재 진영 분대 스킬, 일반 게임 제어 경계, 퍼센트 입력 |
| 개발자 AI 6개 | 팀별 비용·피해·반경, 현재 개체 DPS·사거리, 비돌격 밀집보병의 화력 0, 실제 근접 돌격 선택 |
| 개발자 렌더러 3개 | 양 팀 배치 영역·전방 영역·고스트 색, 2D/3D 좌표·미리보기·실제 소환, 자유 배치 표시, 시뮬레이션 불변 |
| 분대 20개 | 기존 대형 회귀와 새 70% 방어·돌격 이외 공격 금지, 새 규칙 저장·재생, 과거 규칙 3 밀집보병 snapshot 해시 두 개 |
| 캠페인 17개 | 기존 진행·메달·중복 방지 및 새 규칙 4와 구 규칙 3 context 복원 |
| 기존 전체 회귀 | 일반 전투·AI·18경기 완주·저장·리플레이·훈련·치트·2D/3D 렌더러·실패 복구 |
| 문법·DOM | 모든 JavaScript 구문, 고유 HTML ID와 app/devtools 바인딩, 필수 파일 확인 |

WebGL은 호출 기록기와 좌표·메시 검사로 검증했다. 앱 제어 검사는 실제 함수와 Game을 사용하며 전체 브라우저 화면 검사는 아니다. 이번 환경에서는 실제 모바일 브라우저의 터치·포커스·다운로드, GPU 픽셀 결과와 기기별 프레임 속도를 직접 확인하지 못했다.
