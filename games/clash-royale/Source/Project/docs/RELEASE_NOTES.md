# Crownfall Arena 4.5 — 복원 데이터와 신규 카드 구현

2026-11-17 · 프로그램 버전 4.5.0 · 신규 전투 규칙 5 · 저장/리플레이 형식 2 유지

## 구현 결과

연구 패키지 v4의 공개 근거를 실행 중인 카드 정의와 전투 행동에 연결했다. 기존 6개 카드의 확인된 수치와 미니언 거인의 3개 수치 필드를 적용하고, **미니언 거인·덩굴**을 실제로 소환·제어·공격·저장·재생할 수 있게 했다. 카드 풀은 21종, 추천 덱은 5종이다.

원작의 완전한 데이터베이스를 넣은 것은 아니다. 확인된 부분 필드, 자체 좌표·전투 정책, 미확인 수치를 구분한다. 연결 원장과 공식 출처는 [복원 근거 명세](RECONSTRUCTION_V4_5.md)에 있다.

## 빠른 확인

1. 외부 좌측 **카드 데이터**에서 `공개 근거 적용 · Lv.11 일부`를 선택한다.
2. **신규 카드 테스트**를 누른다. 미니언 거인·덩굴을 포함한 별도 덱으로 양 팀 무한 엘릭서 테스트가 시작된다. 개인 저장 덱은 바뀌지 않는다.
3. 선택된 미니언 거인을 아군 구역에 배치한다. 가로 화면에서 아군은 오른쪽, 적은 왼쪽이다.
4. `T` 또는 좌측 조작 진영 버튼으로 적을 배치한다. 개발자 편집기의 덩굴 배치 버튼으로 반대 진영 대상에게 주문을 사용한다.
5. 카드별 **최대 대상 수·기절 시간·접지 시간·피해·반경**을 실시간 조절한다. 선택 진영의 확인 수치를 되돌리려면 **이 카드 확인 수치 적용**을 누른다.
6. 일반 대전에서 사용하려면 덱 편집의 **덩굴 위의 거인** 추천 덱을 선택하고 새 대전을 시작한다.

## 새 카드 행동

### 미니언 거인

비행 상태로 강을 직접 건너고 건물만 원거리 공격한다. 밀치기에 면역이지만 피해·기절·동결·감속·접지는 적용된다. 2D의 큰 날개와 갑옷, 3D 입체 모델, 고유 카드 아이콘과 청록 마력탄·명중 효과를 추가했다.

### 덩굴

주문 범위 안 유효한 적을 현재 HP 내림차순, 중심 거리 오름차순, 안정적인 ID 순서로 정렬해 최대 3개를 선택한다. 타워와 건물도 선택 슬롯을 사용한다. 미리보기는 현재 후보를 보여 주고 **시전 지연이 끝나는 시점**에 실제 대상을 다시 확정한다.

선택 대상에게 피해와 기절을 적용하고 원래 비행 병력이면 접지 시간을 부여한다. 기본 2초 기절 동안 움직임을 멈추며 접지 중에는 지상 공격에 노출된다. `flying` 원본 분류와 위치는 보존하므로 강 위에서 강둑으로 순간 이동하지 않는다. 시간이 끝나면 비행 판정·렌더 고도가 돌아온다. 두 제어 시간을 다르게 조절한 경우 접지 상태 자체는 이동을 막지 않으며 기절 시간이 이동 정지를 결정한다.

현재 HP 기준·마지막 ID 동률 처리·접지 중 지상 공격 피격 정책·피해 틱 구조는 자체 구현 선택이다. 원작의 방패·특수 상태·정밀 경로 정책까지 복원한 것으로 취급하지 않는다.

2D·3D에서 실제 선정 대상만 덩굴로 연결한다. 접지된 비행 모델은 낮아지고 HP HUD와 3D 모델 선택 판정도 같은 높이를 사용한다. 우측 대상 상세에는 접지 잔여 시간과 밀치기 면역을 표시한다. 대상 상태 해제 치트는 접지도 해제한다.

## 프로필·개발 도구·레이아웃

- `reconstructed-v4-lv11`: 새 전투의 기본값. 확인된 부분 수치를 적용한다.
- `prototype-v4`: 기존 자체 수치를 사용한다. 신규 두 카드는 자체 보완 정의로 사용할 수 있다.
- 전투 수치의 우선순위는 **규칙별 기본값 → 선택 프로필 → 해당 진영의 개발자 조절값**이다.
- 외부 좌측 프로필 선택은 다음 새 전투에 적용한다. 현재 경기의 실제 프로필은 별도 표시한다.
- 카드 상세·개발자 편집기는 근거 적용, 수동 값 일치, 자체 보완, 적용 제외 사유를 구분한다.
- 개발자 **확인 수치 적용**은 허용된 필드만 선택 진영에 적용한다. 자체 HP·속도 등을 덮어쓰지 않는다.
- 덩굴의 최대 대상 수는 정수 1~8, 기절·접지 시간은 각각 0~10초로 조절할 수 있다. 기본 공개 대상 수는 3이다.
- 이미 예약한 주문·투사체에는 시전 당시 수치를 유지한다. 새 주문부터 변경값을 사용한다.

가로모드의 적 왼쪽·아군 오른쪽, 우측 세로 손패와 상단 다음 카드, 좌측 HUD·세로 엘릭서, 외부 PC 좌우 패널 구성을 유지했다. 새 데이터 설정이나 출처 설명을 중앙 전장에 추가하지 않았다.

## 저장과 재생

새 전투·캠페인·훈련은 규칙 5와 선택 프로필로 생성된다. 프로필은 저장 및 리플레이 초기 설정에 명시한다. 새 규칙 리플레이에서 프로필이 없거나 알 수 없는 값이면 거절한다. 새 캠페인 시도도 규칙과 프로필을 정체성에 포함하여 다른 설정의 전투 결과를 연결하지 않는다.

기존 규칙 2·3·4는 당시 자체 수치와 직렬화 모양을 유지한다. 규칙 4 개발자 저장에서는 신규 카드 선택을 비활성화하며 전체 기본값 초기화는 유효한 기존 카드만 처리한다. 구버전으로 전환할 때 사용 불가능한 신규 카드 상세를 남기지 않는다. 규칙 3 밀집보병의 이전 행동도 유지한다.

개발자 전투는 기존처럼 일반 리플레이로 내보내지 않으며 전체 스냅샷 저장·이어하기를 사용한다.

## 발견하고 수정한 문제

통합 검사에서 다음 문제를 수정했다.

- 첫 로딩에서 Game 생성 전 카드 근거를 조회하던 예외.
- 구버전 개발자 전투의 전체 초기화가 신규 카드에서 중단되던 문제.
- 구버전 저장·리플레이 전환 뒤 신규 카드 상세가 남던 문제.
- 고블린 둘이 타워 우회 지점으로 반대 방향에서 접근하며 20초 정지하던 교착. 규칙 5 일반 병력의 도착 반경을 몸체 반경까지 허용하고 과거 규칙과 분대 중심은 기존 판정을 유지했다.
- 기존 카드 피해를 직접 참조하던 일부 검증 fixture를 현재 프로필 조회 기준으로 정정했다. 실제 과거 결과는 별도의 원본 기록 fixture로 계속 대조한다.

규칙 5의 모든 병력·건물 배치는 전장 개체 512개 상한을 적용한다. 상한이나 배치 검증에 실패하면 자원·손패·명령을 바꾸지 않는다. 밀집보병의 방진 중 무공격·조건부 피해 70% 감소·유료 돌격 동작은 유지한다.

## 검증과 산출물

최종 자동 검사는 **251개 통과, 실패 0, 건너뜀 0**이다. 근거 생성, 새 카드 행동, 렌더러 기록, 실제 앱 함수, 구형 원본 기록과의 전체 비교, 18개 자동 대전 완주를 포함한다. 자세한 근거와 실기 미검증 범위는 [4.5 검증 기록](VALIDATION_V4_5.md)에 있다.

단일 오프라인 HTML에는 JavaScript 16개 모듈과 CSS 2개를 포함한다. 소스 ZIP에는 실행본·소스·시스템별 Markdown·검증 코드·근거 입력·재생성 스크립트를 담는다. `data/reconstruction`도 함께 제공하므로 ZIP에서 근거 모듈을 재생성·대조할 수 있다.
