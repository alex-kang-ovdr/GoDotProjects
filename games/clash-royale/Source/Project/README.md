## 바로 실행

가장 간단한 방법은 `dist/crownfall-offline.html`을 최신 브라우저에서 여는 것입니다. JavaScript, CSS, 그래픽이 모두 포함되어 있어 **파일 하나로 오프라인 실행**됩니다.

모듈 소스를 개발하려면 프로젝트 루트에서 다음 명령을 실행한 뒤 안내된 localhost 주소를 여세요.

```bash
python3 -m http.server 8080 --directory dist
```

`dist/index.html`은 ES module을 사용하므로 `file://`로 열기보다 위처럼 정적 서버로 제공해야 합니다. 단일 파일 버전에는 이 제한이 없습니다. Python은 개발용 정적 서버·근거 데이터 생성·ZIP 재생성에 쓰이며 게임 런타임은 JavaScript입니다.

## 4.5 복원 데이터와 신규 카드

좌측 **카드 데이터**에서 다음 전투의 프로필을 고릅니다. 기본값은 **공개 근거 적용 · Lv.11 일부**입니다. 폭탄병 피해 212, 화염구·화살비·감전 타워 피해 159·75·48, 창 고블린 공격 간격 1.6초, 독 안개 타워 총 피해 168을 적용합니다. 독 안개는 기존 8틱 모델에 맞춰 21/틱으로 계산합니다. 나머지 수치는 자체 밸런스입니다.

**신규 카드 테스트**를 누르면 미니언 거인·덩굴이 포함된 덱으로 양 팀 무한 엘릭서 개발자 전투를 시작합니다. 미니언 거인은 날아서 건물을 원거리 공격하고 밀치기에 면역입니다. 덩굴은 범위 안 높은 현재 HP 순서로 최대 세 대상을 기절시키고 공중 병력을 접지시킵니다. 확인된 행동 축과 자체 선택한 피해·HP·속도·지속 시간은 우측 카드 상세에서 구분합니다.

프로필 선택은 진행 중인 경기의 수치를 바꾸지 않습니다. 새 전투·캠페인·훈련에 적용되며 저장과 리플레이는 기록한 프로필로 복원합니다. 개발자 편집기의 **이 카드 확인 수치 적용**은 선택한 진영에 허용된 부분 필드만 즉시 적용합니다. **기본값**은 해당 경기 프로필의 기본값으로 돌아갑니다.

원작 전체 카드 데이터·레벨 성장·경제 시스템이 구현된 것은 아닙니다. 적용 근거와 미확인 항목은 [복원 연결 명세](docs/RECONSTRUCTION_V4_5.md)에 기록했습니다.

## 화면 구성

| 영역 | 제공하는 기능 |
|---|---|
| PC 외부 좌측 | 화면 방향, 2D/3D, 일시정지·음향·도움말·기록, 상대·난이도·덱·모드, 전역 치트 |
| 가운데 게임의 좌측 | 경기 시간·국면·점수, 세로 엘릭서와 생성 배율 |
| 가운데 전장 | 카드 배치, 병력·타워 전투, 필요한 순간의 배치·선택·스킬 표시 |
| 가운데 게임의 우측 | 맨 위 다음 카드, 그 아래 손패 4장의 단일 세로 열 |
| PC 외부 우측 | 선택한 타워·병력의 실제 상태, 대상 치트, 양측 통계, 카드 상세와 로그 |

폭 1,100px 이상이고 주 입력 장치가 정밀 포인터인 환경에서는 양쪽 PC 패널이 보입니다. 좁은 화면과 터치 중심 환경에서는 **게임 바깥 제목줄의 ‘설정’**으로 동일한 좌측 패널을 서랍 형태로 엽니다. 서랍 자체를 여는 동안 전투는 계속되며, 별도의 일시정지 버튼으로 멈출 수 있습니다. 덱·도움말 같은 모달을 열면 기존 일시정지 규칙이 적용됩니다.

기본 방향은 가로이며 이전에 세로로 저장한 선택은 유지합니다. 세로는 **상대 위 / 아군 아래**, 가로는 **상대 왼쪽 / 아군 오른쪽**입니다. 가로 손패는 4장을 한 열로 배치하고 다음 카드는 그 위에 둡니다. 엘릭서는 좌측에서 아래에서 위로 차오릅니다. 인게임 하단의 승리 조건·플레이 방법·상시 조작 설명은 제거했고, 설명이 필요하면 외부 도움말을 열 수 있습니다. 카드를 선택할 때만 카드 정보·취소가 나타나고, 밀집보병 분대가 있을 때만 전장 우측 하단의 스킬이 나타납니다.

### 2D / 3D

좌측 **렌더링 → 2D / 3D**로 진행 중인 전투의 표시를 바꿉니다. 2D는 Canvas, 3D는 WebGL의 실제 높이·깊이 판정·조명을 사용하는 로우폴리 전장입니다. 3D에서도 HP·타이머·텍스트는 정방향으로 표시합니다. 클릭·터치·드래그·방향키 조준은 현재 카메라에서 동일한 지면 좌표로 변환하며, 개체 선택은 실제 보이는 3D 모델 위치를 판정합니다.

표시 방식과 방향을 바꾸어도 480×640 논리 좌표, 전투 시간, 병력, AI, RNG와 명령 기록은 유지됩니다. WebGL 초기화나 그리기에 실패하거나 컨텍스트가 사라지면 같은 전투를 2D로 이어갑니다. 렌더링 선택은 브라우저 설정에 저장합니다. 기기별 실제 GPU 성능은 측정하지 않았습니다.

## 구현 범위

### 왕관의 길

6개 관문을 순서대로 진행합니다. 첫 관문은 처음부터 열려 있고, 승리하면 다음 관문이 열립니다. 잠긴 관문은 화면과 진행 모듈 모두에서 시작을 막습니다. 이미 완료한 단계는 자신의 덱으로 다시 도전해 최고 메달과 기록을 갱신할 수 있습니다.

| 단계 | 관문 | 상대 | 난이도 | 전장 |
|---|---|---|---|---|
| 1 | 숲길의 첫 왕관 | 브란 | 입문 | 숲 |
| 2 | 갈림길의 추격전 | 루나 | 입문 | 숲 |
| 3 | 황혼의 안개 | 세라 | 보통 | 황혼 |
| 4 | 성문 앞의 행진 | 브란 | 보통 | 황혼 |
| 5 | 빙원의 질주 | 루나 | 도전 | 설원 |
| 6 | 얼어붙은 성채 | 세라 | 도전 | 설원 |

승리하면 기본 1메달, **아군 타워 무손실 승리**에 1메달, **180초 안에 승리**에 1메달을 추가해 단계마다 최대 3메달을 받습니다. 실패·무승부·항복에는 메달을 주지 않습니다. 메달은 기록이며 카드 능력치나 시작 자원을 바꾸지 않습니다. 단계별 시도·승리·최고 메달·최단 승리 시간을 저장하고, 전체 최고 메달의 합은 18개입니다.

준비 화면에서 상대의 실제 8장 덱, 내 덱과 평균 비용, 공략 힌트를 확인합니다. 여기서 덱을 편집하면 같은 준비 화면으로 돌아옵니다. 출전 후 3초 카운트다운 동안 전투 시간과 엘릭서는 진행되지 않으며, ‘바로 시작’으로 생략할 수 있습니다. 단계는 고정 seed를 사용하지만 자신의 입력에 따라 결과가 달라집니다.

상대 난이도는 카드·자원 보정 없이 판단 속도와 선택을 바꿉니다. 단계 순서가 모든 덱 조합에서 승리하기 쉬운 순서라는 의미는 아닙니다. 입문 관문도 자신의 덱에 맞춘 수비와 역공이 필요합니다.

### 전투

- 논리 아레나 480×640, 두 레인, 중앙 강과 두 다리.
- 양측 프린세스 타워 2개와 킹 타워 1개. 킹은 피격 또는 아군 측면 타워 파괴 시 활성화됩니다.
- 지상 유닛의 다리 경유 및 고정 건물 우회, 공중 유닛의 직선 이동, 유닛 간 간단한 분리 처리.
- 무리의 각 개체가 벽·타워·현재 병력·강 경계와 겹치지 않도록 가까운 빈 공간을 탐색합니다. 최대 48 논리 픽셀 안에 모든 개체의 자리를 찾지 못하면 배치를 취소합니다. 전진 배치도 선택한 강변 안에서 형상을 유지합니다.
- 아군 건물이 다리 입구를 막으면 통과 가능한 다른 다리로 우회합니다. 이동·밀치기·몸체 분리에서도 지상 유닛의 반경을 포함해 강 경계를 지킵니다.
- 근접·원거리·공중·지상 광역·건물 우선 타기팅, 투사체 이동, 주문 예고·범위 피해·화염구 넉백.
- 배치 지연, 방어 건물의 수명, 타워 체력과 파괴 효과.
- 상대 프린세스 타워를 파괴한 레인에 전진 배치 구역 개방.
- 여전사와 얼음 정령은 자기 위치를 중심으로 광역 판정. 지상 전용 공격은 공중에 적용되지 않습니다.
- **감전:** 작은 범위 피해와 0.5초 기절. 기절 중 이동과 공격을 멈춥니다.
- **얼음 정령:** 한 번 자폭하여 지상·공중에 피해와 1.1초 동결을 적용합니다.
- **독 안개:** 8초 동안 매초 피해를 주고 영역 안에서 이동 속도를 20% 줄입니다. 최초 피해는 생성 후 1초, 총 8틱입니다. 밖으로 나간 대상에는 이후 틱을 적용하지 않습니다.
- 규칙 3 이상의 독은 **이동 속도만** 줄입니다. 공격 주기와 움직이지 않는 타워·건물의 공격 속도는 유지됩니다.
- 기절한 건물도 수명과 자연 체력 감소는 계속됩니다.

### 카드와 엘릭서

- 21종: 기사, 궁수, 거인, 고블린, 화염구, 화살비, 총사, 폭탄병, 미니언, 대포, 전투 여전사, 해골 병사, 돌격 기수, 창 고블린, 강철 검사, 감전, 독 안개, 얼음 정령, 밀집보병, 미니언 거인, 덩굴.
- 중복 없는 8장 덱, 4장 손패와 대기열. 사용한 카드를 대기열 뒤에 넣고 다음 카드를 같은 슬롯으로 가져옵니다.
- 시작 엘릭서 5, 최대 10. 기본 2.8초당 1 생성. 정규전 마지막 1분부터 2배, 연장전 마지막 1분부터 3배.
- 위치·비용 검증을 통과한 배치만 자원과 손패를 변경합니다.
- 브라우저 저장소에 덱·난이도·효과음 설정·승전 기록 저장. 저장소가 막혀도 게임 자체는 실행됩니다.
- 추천 덱 **거인의 행진 / 번개의 질주 / 안개의 성채 / 방패의 진군 / 덩굴 위의 거인**, 종류별 카드 필터, 평균 비용 및 타워 공략·대공·군집 대응 안내.

### 밀집보병과 방패 돌격

| 항목 | 구현 수치·동작 |
|---|---|
| 소환 | 엘릭서 5, 병사 6명, 3열 × 2행 |
| 개별 병사 | 체력 340, 공격력 65, 공격 간격 1.15초, 사거리 32 |
| 방어 대형 | 이동 속도 24, 보호 조건을 충족하면 받는 피해 70% 감소, 공격하지 않음 |
| 방패 돌격 | 엘릭서 1, 5초 동안 대형 해제·개별 추적과 공격, 이동 속도 68, 대형 방어 해제 |
| 재사용 대기 | 발동 시점부터 14초, 분대별로 독립 적용 |
| 돌격 종료 | 생존 병사 재집결 후 대형 유지; 분대 정렬과 보호 조건을 충족하면 방어 복구 |

현재 전투 규칙 5는 규칙 4의 밀집보병 동작을 유지하여 `forming/guard/regroup` 동안 공격하지 않으며 `charge`일 때만 공격합니다. 피해 감소는 살아 있는 병사가 셋 이상이고 실제 대형 조건을 만족할 때 적용합니다. 배치 중·기절·대형 이탈·돌격 상태에는 조건에 따라 보호가 해제됩니다. 사상자가 생기면 빈 대열을 정리하며, 지상 강 경계와 다리를 지킵니다. 상세 조건과 저장·리플레이 계약은 [PHALANX.md](docs/PHALANX.md)를 참고하세요.

바로 체험하려면 외부 좌측 **밀집보병 체험**을 누르세요. 방패의 진군 덱과 엘릭서 10으로 자유 연습을 시작하며, 시작 손패의 밀집보병을 자동 선택합니다. 아군 쪽에 배치한 뒤 전장 우측 하단 **방패 돌격** 또는 `E`로 발동합니다. 여러 분대가 있으면 병사를 직접 선택하거나 스킬 위 분대 선택창을 사용합니다. 체험 덱은 저장한 개인 덱을 덮어쓰지 않습니다.

### 승패

- 킹 타워 파괴: 즉시 승리, 3크라운.
- 정규전 180초 종료: 크라운이 많은 쪽 승리.
- 동률이면 최대 120초 연장: 다음 타워를 먼저 파괴하면 승리.
- 연장 종료까지 동률이면 남은 타워 중 최저 절대 체력을 비교. 더 낮은 쪽 패배, 같으면 무승부.
- 결과 화면: 크라운, 사용 카드 수, 실제 적용 피해량, 전투 시간.
- 일시정지에서 항복을 확인하면 상대 승리로 즉시 종료합니다. 시간을 추가 진행하거나 피해·크라운을 임의로 더하지 않으며, 종료 이유와 당시 점수를 기록합니다.

### AI

`easy / normal / hard`는 자원이나 카드 성능을 바꾸지 않습니다. 사고 주기·반응 지연·배치 오차·카드 선택만 달라집니다. AI는 자기 손패와 엘릭서 및 공개된 전장만 읽으며, 상대 손패·엘릭서를 읽지 않습니다. 플레이어와 같은 `canDeploy()` / `playCard()` 경로로 행동합니다. 밀집보병을 사용하는 덱에서는 공개 전장과 자기 자원으로 돌격 가치를 판단하고, 같은 비용·쿨다운 검증을 거쳐 스킬을 사용합니다.

방어 시 군집·비행·탱커를 구분하고, 공격 시 거인과 지원 병력을 조합합니다. 가치 있는 군집 또는 처치 가능한 타워에 주문을 사용합니다. 자유 연습에서는 AI 배치를 끄되 타워의 방어는 유지합니다.

| 상대 | 덱과 행동 |
|---|---|
| 철벽의 브란 | 거인·강철 검사·원거리 지원 병력으로 전열을 구성합니다. |
| 질주의 루나 | 돌격 기수와 저렴한 카드로 빠르게 순환하며 무거운 적 병력이 몰린 반대 레인을 압박합니다. |
| 안개의 세라 | 대포·광역 병력으로 수비하고 독 안개와 살아남은 병력으로 역공합니다. |

AI는 이미 수비 병력이 충분한 교전에 추가 엘릭서를 과하게 쓰지 않도록 평가하고, 보이는 방어 건물에 따라 공격 레인을 선택합니다. 독 안개의 총 피해를 즉시 피해로 간주하지 않으며, 독 안개가 남아 있어도 별도의 즉시 주문으로 확정 마무리가 가능하면 사용합니다.

3.0은 두 레인의 건물 공격수를 함께 끌어낼 중앙 대포 후보, 타워 주변의 대공 배치 대체 위치, 실제로 적을 공격할 수 있는 수비 전력만 계산하는 평가를 추가했습니다. 킹이 곧 파괴되는 상황에서는 제거·기절로 생존할 수 있는 주문을 우선하고, 상대 킹을 확정 파괴할 수 있으면 승리를 선택합니다. 이미 큰 아군 전력이 있는 레인에 추가 공격수를 보내기 전 반대 레인도 비교합니다.

### 자유 연습

PC에서는 외부 좌측 패널에서, 모바일에서는 외부 설정 서랍에서 **엘릭서 충전, AI 켜기·끄기, 1배·2배·4배 진행 속도**를 조절합니다. 자유 연습은 전적에 반영하지 않으며, 임의 자원 충전이 가능하므로 리플레이를 저장하지 않습니다. 연습 상태와 선택한 배속의 저장·이어하기는 지원합니다.

PC의 **치트 연습 시작**을 누르면 자유 연습으로 들어갑니다. 전역 치트는 내/양측 엘릭서 10, 모든 생존 타워 회복, 적 병력·배치 건물 제거를 제공합니다. 우측 대상 치트는 체력 회복, 피해량 적용, 제거, 3초 기절, 배치·공격 대기와 상태 이상 해제를 제공합니다. 일시정지한 전장에서도 대상 선택 도구를 켜서 개체를 고르고 조작할 수 있습니다.

피해·제거는 실제 남은 HP만 피해 통계에 반영하고, 타워가 파괴되면 정상 크라운·킹 활성화·승패 처리로 이어집니다. 이미 파괴된 대상의 부활이나 건물 수명 초기화는 하지 않습니다. 일반 대전·도전·훈련·리플레이에서는 치트가 비활성화되며, 엔진·도구 모듈에서도 다시 검사합니다.

### 개발자 테스트와 실시간 밸런스 조절

외부 좌측 **개발자 테스트 시작**을 누르면 두 진영 모두 현재 개인 덱으로 시작하고 상대 AI는 꺼집니다. 양 팀 무한 엘릭서는 기본으로 켜집니다. 일반 대전과 분리된 연습 전투이며 전적·도전 메달·대전 리플레이에는 포함하지 않습니다.

| 기능 | 사용법 |
|---|---|
| 양 팀 제어 | 아군·적군 버튼 또는 `T`로 전환. 외부 패널에서 양쪽 실제 손패를 동시에 보고 선택 |
| 모든 카드 직접 배치 | 조절할 카드 선택 → 아군/적군 배치 → 필드 클릭. 덱에 없어도 사용하며 손패는 순환하지 않음 |
| 반복 소환 | 직접 배치 선택을 유지하고 필드를 여러 번 클릭. `Esc` 또는 취소로 종료 |
| 카드별 수치 | 숫자·슬라이더를 바꾸는 즉시 반영. 양 팀 공통 / 아군만 / 적군만 선택 |
| 현재 병력 반영 | 체력 비율·공격 대기 진행률을 유지하며 HP·피해·사거리·속도 등을 갱신 |
| 무한 엘릭서 | 양 팀을 각각 켜고 끔. 카드·스킬 비용을 소비 통계에 기록한 뒤 자원을 10으로 보충 |
| 스킬 대기 해제 | 재사용 대기만 0. 이미 돌격 중인 분대에 중복 발동하지 않음 |
| 진영 제한 해제 | 양 진영에 배치 가능. 벽·강·개체 충돌과 합법적인 자리 탐색은 유지 |
| 기타 치트 | 양 팀 병력 제거·타워 회복, 기존 개별 대상 치트·AI 토글·배속·일시정지 |
| 반복 비교 | 전장 초기화·다시하기는 현재 조절 수치와 치트를 유지. 카드별/전체 기본값 복원 가능 |

조절 항목은 카드 종류에 따라 달라집니다. 비용, 체력, 피해, 공격 간격, 사거리, 이동 속도, 배치 시간, 투사체 속도, 광역 공격 반경, 주문 반경·타워 피해·지속 시간, 밀집보병 방어율·돌격 속도·스킬 비용·지속·대기를 지원합니다. 병력 수, 몸체 크기, 지상·공중 분류는 유지합니다.

이미 발사된 투사체와 예약된 주문은 발사·시전 당시의 수치로 처리합니다. 조절 후 생성되는 공격·소환에는 새 값이 적용됩니다. 양 팀 수치가 다르면 편집기에 ‘값 다름’을 표시하며, 공통 편집에서 바꾼 항목만 양 팀에 적용합니다.

진행 중 테스트의 조절값·치트·선택 진영은 저장·이어하기로 복원합니다. 일반 모드로 이동하면 테스트 수치를 사용하지 않으며, 그 뒤 새 테스트를 시작하면 기본값으로 시작합니다. 상세 API와 수치 범위는 [DEVELOPER_MODE.md](docs/DEVELOPER_MODE.md)를 참고하세요.

### 저장·이어하기

카드 배치 직후, 300틱(정상 속도에서 5초)마다, 일시정지·탭 전환·로비 복귀 시 전투를 저장합니다. 새로고침 후 로비의 **이전 전투 이어하기**를 누르면 병력·타워 체력, 손패·대기열, 엘릭서, 진행 중 투사체·시전·독 영역·상태 이상, 난수 상태와 AI 판단 타이머를 복원합니다. 도전 단계·시도 ID·전장 테마·남은 준비 카운트다운도 복원합니다. 저장소를 사용할 수 없는 환경에서는 새로고침을 넘어선 복원을 보장하지 않습니다.

저장 키는 설정·전적·도전 진행·최근 8경기 `crownfall.v1`, 진행 중 전투 `crownfall.match.v2`, 이전 버전 호환용 마지막 리플레이 `crownfall.replay.v2`입니다. 전술 훈련의 적 배치 순서와 달성 목표도 전투 저장에 포함됩니다. 전적·도전 결과·경기 목록은 프로필의 한 번의 쓰기로 함께 저장하지만 진행 중 전투 체크포인트는 별도 키입니다. 저장 데이터는 이 브라우저에만 남으며 서버로 전송하지 않습니다. 새 전투나 훈련을 시작하면 미완료 전투 저장을 교체하고, 종료 시 이어하기 저장을 제거합니다.

저장 형식 버전 `2`와 전투 규칙 버전은 별개입니다. 신규 전투는 `config.rulesVersion: 4`, 기존 버전 표기가 없는 전투는 `2`로 복원합니다. 기존 규칙 3의 밀집보병은 당시 35% 방어·방진 공격 규칙으로 재생합니다. 기존 리플레이는 당시의 배치·이동·독 감속 규칙으로 재생합니다. 규칙 2를 사용한 기존 저장의 전장 상태도 유지하며, 이후 AI 판단에는 개선된 AI 코드가 적용됩니다.

### 전술 훈련

| 과제 | 제한 시간 | 실제 성공 조건 |
|---|---:|---|
| 중앙으로 유인하기 | 35초 | 중앙 대포가 기수의 공격 대상이 된 후 기수를 처치하고, 아군 레인 A 타워 체력 75% 이상 유지 |
| 공중 무리 정리하기 | 25초 | 해당 화살비가 지정 미니언 세 기 모두에 실제 피해를 주어 처치하고, 아군 레인 A 타워 체력 75% 이상 유지 |
| 전열과 지원 연결하기 | 75초 | 살아 있는 거인 뒤에 궁수를 배치하고, 적 레인 A 타워에 925 이상 누적 피해 |

훈련은 고정 덱·seed·적 배치 스케줄을 사용합니다. 모든 적과 플레이어 배치는 정상 `playCard()`를 사용하고 비용·손패 회전·배치 제한을 지킵니다. 목표 위치와 체크리스트를 보여주며, 성공하면 다음 훈련으로, 실패하면 같은 조건으로 다시 도전합니다. 일반 대전 전적·최근 대전 리플레이에는 반영하지 않습니다.

화살비 과제는 다른 병력이나 화염구가 먼저 처치한 미니언을 성공으로 인정하지 않습니다. 적의 지정 배치 위치가 막히면 같은 레인의 합법적인 가까운 위치를 찾아보고, 불가능하면 0.25초 간격으로 최대 3초 재시도합니다. 계속 실패하면 안내와 함께 훈련을 종료합니다. 재시도 상태도 저장하여 복원 후 적을 중복 생성하지 않습니다.

### 전투 가독성과 분석

카드 미리보기는 실제 엔진의 `previewDeployment()` 결과를 사용합니다. 무리의 모든 생성 위치, 주문의 현재 피격 대상과 타워 피해를 보여주며, 독은 총 피해가 아닌 **1틱 피해**로 표시합니다. 시전 시점까지 적이 움직일 수 있으므로 현재 위치의 범위 확인이며 미래 적중을 보장하지 않습니다. 상대 영역·병력에는 점선도 사용해 색 외에 형태로 구분합니다.

엘릭서가 부족한 카드에는 현재 생성 속도 기준 예상 대기 시간을, 엘릭서 10에서는 상한 안내를 표시합니다. 결과 분석에는 실제 입력에서 구한 카드별 사용 횟수·소비량·좌우 레인과 주문 비중을 표시합니다. 분대 스킬의 횟수와 비용은 카드 수와 분리하며, 총 엘릭서 사용량에는 스킬 비용을 포함합니다. 카드 평균 비용은 스킬 비용을 제외해 계산합니다. 일반 대전의 미생성 엘릭서는 `시작 자원 + 시간별 자연 생성량 − 실제 사용량 − 종료 잔여량`으로 계산합니다. 임의 충전이 가능한 자유 연습에는 이 지표를 적용하지 않습니다.

도전 단계에 따라 숲·황혼·설원 지형을 표시합니다. 테마는 그림만 바꾸며 전투 좌표·비용·능력치는 동일합니다. 병력의 배치 준비 원형 표시, 체력이 25% 이하인 생존 타워의 경고, 겹친 피해 숫자의 간격 조정으로 전투 상태를 읽기 쉽게 했습니다. 동작 줄이기 설정에서는 장식 애니메이션을 줄이고 실제 상태 표시는 유지합니다.

### 리플레이

완료한 자유 대전과 도전 모드의 **최근 8경기**를 저장합니다. 승패·상대·단계·시간·점수·사용 덱을 보고 개별 기록을 선택해 **1배·2배·4배 재생, 일시정지, 시간 탐색, 처음부터 재생**할 수 있습니다. 리플레이를 보면서 전적이나 도전 해금·메달을 추가하지 않으며, 진행 중 전투에서 리플레이를 열면 그 전투를 저장한 뒤 전환합니다. 이전 버전의 마지막 리플레이도 첫 기록으로 가져옵니다.

초기 설정·seed와 승인된 배치 명령 `{ tick, team, handIndex, cardId, x, y }`를 기록합니다. 밀집보병 배치에는 `groupId`가 붙으며, 스킬은 `{type:"ability",tick,team,cardId,abilityId,groupId}`로 같은 명령열에 기록합니다. 분대의 생성 명령·진영·발동 시점·비용·대기 시간을 검증하며, 뷰어의 임의 스킬 입력은 차단합니다. 재생에서는 같은 tick에 해당하는 명령을 순서대로 적용한 다음 1/60초를 진행합니다. AI는 재실행하지 않습니다. 이 방식으로 종료 시각·크라운·타워 HP·유닛·투사체·효과·피해 통계까지 원본과 같은지 자동 검사합니다. 음수 tick, 순서가 뒤바뀐 명령, 잘못된 카드와 범위 밖 좌표 등 손상된 기록은 거절합니다.

새 기록은 종료 tick·승자뿐 아니라 종료 이유·크라운·6개 타워 HP·양측 누적 피해를 보관하고 재생 종료 시 비교합니다. 원본보다 일찍 끝나거나 결과가 다르면 정상 재생 완료로 처리하지 않습니다. JSON 내보내기·불러오기는 로컬 파일만 사용하며, 파일 형식·크기(최대 1MB)·입력·결과 데이터 범위를 검증합니다. 불러온 파일을 보는 것은 일반 전적이나 마지막으로 완료한 대전 기록을 변경하지 않습니다.

항복한 경기에는 선택 항목 `endAction`으로 종료 진영과 tick을 기록합니다. 마지막 tick의 배치 입력을 먼저 적용한 다음 항복을 처리하므로, 시작 직후 항복과 카드 사용 직후 같은 tick의 항복도 시간을 더 진행하지 않고 재현합니다. 파일에는 허용된 전장 테마·단계 메타데이터도 보존합니다. 예전 파일에 새 선택 항목이 없어도 읽을 수 있습니다.

### 시뮬레이션 사용 예

```js
import { Game, DEFAULT_DECK } from './dist/js/engine.js';
import { BattleAI } from './dist/js/ai.js';

const game = new Game({ deck: DEFAULT_DECK, seed: 123 });
const ai = new BattleAI(game, { difficulty: 'normal', seed: 456 });
game.start();

// 렌더 프레임과 독립적으로 1/60초 단위 호출
ai.update(1 / 60);
game.update(1 / 60);

// 플레이어 손패 첫 슬롯을 아군 레인에 배치
const result = game.playCard('player', 0, 120, 430);
console.log(result, game.state);
```

동일 seed와 동일 입력·고정 시간 스텝은 같은 시뮬레이션 결과를 냅니다. 화면에 표시되는 픽셀 크기는 달라져도 논리 아레나 좌표는 유지됩니다.

## 검증과 제한

자동 검증은 비용·손패 회전, 불법 배치의 상태 보존, 엘릭서 상한, 지상/공중 강 통과, 연장·킹 파괴·타이브레이커, AI의 숨은 정보 미조회, 주문 선택, 전체 경기 결정성을 포함합니다. 유닛 이동은 브라우저 프로토타입을 위한 휴리스틱이며 상용 게임의 모든 길찾기·밀기·동시 처리 규칙을 복제한 것은 아닙니다.

최신 자동 검사 범위와 결과는 [4.5 검증 기록](docs/VALIDATION_V4_5.md)에 정리했습니다. 복원 수치·신규 카드 행동·양 팀 개발 도구·프로필을 고정한 저장과 리플레이·과거 버전과의 전체 상태 일치를 검사합니다. 과거 4.4의 190개 검사 결과는 [당시 변경 기록](docs/RELEASE_NOTES_V4_4.md)에 보존합니다.

렌더러 검사는 현재 카메라의 좌표 왕복, 방향·DPR·레터박스, 실제 3D 높이와 메시·깊이 설정, 모델 표면 선택, 시뮬레이션 상태 불변과 실패 시 2D 복구를 다룹니다. WebGL 호출 기록기로 검사하므로 실제 GPU 픽셀 결과나 성능 검증은 아닙니다. 밀집보병의 방진·돌격·재집결·배치 대기는 독립 Canvas 2D 이미지에서도 확인했습니다.

정적 HTML 구조 검사에서는 설정을 외부에 두고, 방향 전환 대상 7개 노드를 8회 왕복한 뒤 부모와 형제 순서가 복원됨을 확인했습니다. JavaScript 문법·DOM ID·바인딩과 단일 HTML의 모듈 조합도 검사합니다. 브라우저 접근 제한으로 이번 버전의 실제 페이지 클릭·터치·포커스·다운로드 및 기기별 GPU 동작은 확인하지 못했습니다.

기존의 3상대 × 3난이도 × 2 seed 완주 회귀와 이전 6단계 × 추천 덱 3종의 18경기 표본은 난이도 균형이나 모든 군집 상황을 보장하지 않습니다. 경로는 이 규모의 로컬 아레나를 위한 휴리스틱이며, 실제 모바일 기기의 프레임 속도와 입력 지연을 측정한 성능 보장도 제공하지 않습니다.

현재 범위는 **싱글 플레이 코어 전투**입니다. 온라인 멀티플레이, 서버 권위 판정, 카드 성장·레벨, 상점·클랜·시즌·진화·챔피언·영웅은 포함하지 않습니다. 원작의 상표·카드 명칭은 기능을 설명하기 위한 참조이며, 원작의 이미지·소리·코드는 사용하지 않습니다.
