## 1. 이번 작업의 결과

이번 고도화는 기존 자료의 빈칸을 대상으로 공식 문서를 다시 조사하고, 2023년 공개 스냅샷에서 이전 변환 과정에 빠졌던 필드를 복원한 작업이다. 이미 알려진 내용을 다시 확인한 경우와 새로 구조화한 사실, 여전히 확인할 수 없는 값, 문서끼리 다른 주장을 하는 경우를 별도로 기록했다. 자료가 늘어난 정도를 게임의 재현 완성도로 환산하지 않는다.

실행 진입점은 [ROYALE_DATA_LAB.html](ROYALE_DATA_LAB.html)이다. 브라우저로 파일을 열면 카드별 원장, 원시 개체 관계, 행동 규칙, 경제·모드 조사 결과와 출처를 조회할 수 있다. 설치·서버·계정·외부 JavaScript 라이브러리를 요구하지 않는다. 출처 링크를 선택하면 해당 외부 페이지로 이동한다.

## 2. 추가 조사 내용을 분류하는 방법

새 경제·모드·카드 행동 조사 표에는 총 119행이 있다. 이 분류는 기존 패치 원장 및 역사 복원 표와 별개다.

| 조사 종류 | 경제 | 모드 | 카드 행동 | 합계 |
|---|---:|---:|---:|---:|
| `new_fact` 신규 구조화 | 38 | 31 | 24 | 93 |
| `rechecked_claim` 기존 주장 재확인 | 4 | 0 | 3 | 7 |
| `unresolved_gap` 미해결 결측 | 5 | 4 | 5 | 14 |
| `conflict` 상충 근거 | 0 | 5 | 0 | 5 |
| 합계 | 47 | 40 | 32 | 119 |

`new_fact`는 이번 구조화 표에서 추가한 항목을 뜻한다. 세계 최초 발견, 원작 내부 데이터 발견, 또는 다른 문서에 없던 정보라는 주장이 아니다. 신규 구조화 93행 중에는 공개 확률을 직접 더한 파생 검산 1행이 포함된다. 근거 수준은 별도의 `evidence_status`로 표시한다.

미해결 행은 값 전체가 `null`일 수도 있고, 알려진 맥락과 미확인 필드가 같이 있는 객체일 수도 있다. 예를 들어 Merge Tactics 일반 카드 25종이라는 맥락은 확인되어도 각 카드 비용을 모르면 `cost_map: null`을 유지한다. 이를 비용 0 또는 전부 같은 비용으로 바꾸지 않는다.

모든 추가 조사 행은 `original_client_observed: false`를 명시한다. 지원 문서를 본 날짜는 실제 계정에서 해당 규칙을 관측한 날짜와 다르다.

## 3. 공식 패치 복구

[40번 문서](40_official_patch_reconstruction_2026.md)에 5~8월 공식 기사에서 확보한 140행을 정리했다.

| 원문 적용 절 | 추가 행 |
|---|---:|
| 2026-05-04 | 18 |
| 2026-06-01 | 31 |
| 2026-07-06 | 17 |
| 2026-08-04 | 65 |
| 2026-08-26 | 9 |

각 행은 before/after, 카드 key, 기본·Hero·진화 형상, 본체·투사체·능력 등의 구성요소, 단위, 기준 레벨과 적용일을 갖는다. 기본형 변경이 모든 형상에 적용된다고 단정하지 않으며, 기사에 등장하지 않은 필드를 채우지 않는다.

가장 중요한 수정은 `reference_level: null`의 뜻을 나눈 것이다.

| `reference_level_status` | 처리 | v4 부분 필드 수 |
|---|---|---:|
| `specified` | 명시된 레벨이 선택 레벨과 같을 때 수치 표에 표시 | 69 |
| `not_applicable` | 시간·비율·거리 등 이 기록에서 레벨별 수치가 아닌 필드 | 82 |
| `not_stated` | 기사에 기준 레벨이 없음. 별도 미기재 목록으로 반환 | 40 |

Hero Tombstone의 7월 HP 4,044는 레벨 11로 명시되어 있다. 이후 8월의 4,224는 기사에 기준 레벨이 명시되지 않았다. 두 기록을 보존하고 이전 레벨 11 행에 `has_later_unspecified_level_change`를 표시한다. 이때 4,044를 현재 확정값이라고 부르거나 4,224를 자동으로 레벨 11에 대입하지 않는다. 근거와 기계 판독 감사는 [44번 문서](44_sources_and_level_reconciliation.md)를 따른다.

## 4. 역사 데이터 복원

[43번 문서](43_historical_behavior_recovery.md)는 원본 SHA-256 확인, 선별 기준, 113개 개체, 37개 추가 간선과 남은 10개 카드 루트 누락을 설명한다.

추가 간선은 얼음 마법사 투사체의 감속 buff, 통나무의 후속 투사체, 얼음·일렉트로 마법사와 전투 치유사의 배치 효과 등을 추적할 수 있게 한다. 모든 값은 2023-10-18 자료라는 표시를 유지한다. 2026 패치에 등장한 HP와 이 역사 자료의 이동 속도를 합쳐 현재 카드를 만드는 자동 병합은 하지 않는다.

별도의 선별 파일을 사용해 기존 역사 카탈로그 120행, 개체 정의 532행, 레벨 배열 4,956행의 의미와 바이트 생성 규칙을 바꾸지 않았다. 추가 정보를 기본 객체에 덮어쓰지 않고 출처가 같은 확장 행으로 연결한다.

## 5. 경제·모드·카드 행동에서 보완한 부분

### 경제

[41번 문서](41_economy_evidence_reconciliation.md)는 Mini Pass와 Pass Royale의 차이, 보상 선택과 사용 자격, Custom·Chain·Hoggy 상품의 조건, 타워 유닛의 성장·초과 전환, 앨범의 조각별 표시 확률을 보완했다. Royal Market의 고급 상품 해금 조건은 Crown Token **누적 소비 3,000**으로 기록한다. 보유 잔액 3,000과 혼합하지 않는다.

Epic 7레벨 골드, Arena 19–21 진화 조각 전환, 최대 카드 정확히 60개인 경계, 일일 골드 지급 승리 횟수, Wild Card 한도표는 추가 조사 후에도 미확인이다. 비용 계산기는 알려진 부분합을 전체 비용으로 표시하지 않는 기존 계약을 유지한다.

### 모드와 시즌

[42번 문서](42_modes_rotation_and_conflicts_research.md)는 2026년 11월 시즌과 2023년 동명에 가까운 테마의 경계를 분리하고, 퍼즐·Clan Voyage·Victory Run과 Merge Tactics의 특성·상호작용을 구조화했다. Ranked 진입 지원값 13,000과 날짜가 있는 11월 일정 14,000은 함께 기록하며 현재 단일 확정값으로 덮어쓰지 않는다.

Merge 일반 카드 25종의 정확한 비용을 확보하지 못했으므로 `null`을 유지한다. 라운드 수입, Clan 공격 속도, Rider 속도, 최대레벨 기부 보상도 상충 근거를 보존한다.

### 카드 행동

[45번 문서](45_card_behavior_and_version_boundaries.md)는 Minion Giant, Hero Ice Wizard, Vines, Baby Dragon Evolution, Spirit Empress, Skeleton Barrel Evolution의 공개 메타데이터·행동을 정리한다. 2025 출시 발표와 2026 지원·패치 자료를 날짜별로 분리했다. 신형 카드의 HP·사거리·첫 타격 시간 같은 전체 프로필은 공개 설명에 없으면 미확인으로 둔다.

## 6. 연구 도구에서 달라진 점

- **카드 사전:** 확장 패치 140행을 기존 이력과 함께 날짜순으로 탐색한다.
- **레벨 선택:** 기준 레벨 미기재 값은 선택한 레벨의 일반 수치 표에서 제외한다.
- **후속 변경 표시:** 나중에 레벨 미기재 패치가 있으면 이전 레벨 명시값에 경고를 붙인다.
- **행동 설명:** 발표 시점이 있는 카드 행동 자료를 숫자 레벨 표와 별도로 보여준다.
- **역사 그래프:** 기존 428개와 추가 37개 명시 참조를 합쳐 유한 그래프 끝까지 탐색한다.
- **규칙 탐색:** 새 6개 표를 검색·상태 필터·원본 보기·CSV 내보내기에 포함한다.
- **내보내기:** 일반 `records`, `unspecifiedLevelRecords`, `datedBehaviorFacts`를 나누어 정보의 의미를 보존한다.

이 도구에는 원작 계정 연결, 게임 데이터 자동 수집, 실제 전투 조작 또는 라이브 수치 동기화가 없다. 기존 Crownfall 게임의 가로 화면, 밀집보병, 개발자 치트와 렌더링 코드는 이번 연구 패키지에서 변경하지 않았다.

## 7. 파일과 재구축 순서

| 위치 | 역할 |
|---|---|
| `data/raw/` | 고정 역사 자료에서 선별한 사실 |
| `data/tables/` | 공통 스키마의 JSON과 같은 자료의 CSV |
| `data/sources/` | 출처·발행/조회 시점·범위·한계 |
| `data/analysis/` | 카드 범위, 출처 감사, 신규 조사 분류, 패치 연속성 |
| `lab/` | 오프라인 HTML을 구성하는 JavaScript·CSS·템플릿 |
| `scripts/` | 추출·정규화·조회·분석·검증·패키징 |
| `tests/` | 참조 코드·DOM 흐름·자료 경계 회귀 검사 |
| `reports/` | 실제 실행한 검사 결과와 남은 한계 |

```bash
python scripts/reconstruct_extensions.py
python scripts/rebuild.py
python scripts/reconcile_research.py
python scripts/analyze_quality.py
python scripts/validate.py
python scripts/build_lab.py
python scripts/verify_package.py
python scripts/package_release.py
```

생성 스크립트의 `--check`는 수록 결과가 현재 소스에서 재현되는지 확인한다. `verify_package.py`는 재현 확인, 정합성, Node 참조/DOM 흐름, Python 검사를 한 번에 실행한다. `package_release.py`는 검사 통과 후 파일별 SHA-256과 ZIP CRC·파일 바이트를 확인한다.

```bash
python scripts/query_data.py card tombstone --level 11
python scripts/query_data.py card ice-wizard --scope archive-2023 --level 11
python scripts/query_data.py compare phalanx
```

## 8. 완료한 범위와 남은 검증

이번 패키지에서 완료한 것은 추가 공개 근거의 수집·구조화, 누락된 역사 필드의 재추출, 근거 조건을 보존하는 조회, 재현 가능한 검사와 산출물 구성이다. 현재 원작 전체 DB, 비공개 서버 규칙, 모든 카드·레벨·형상의 완전 프로필을 복구했다고 주장하지 않는다.

실제 브라우저 화면·터치·GPU와 원작 클라이언트는 이번 검증에 포함하지 않았다. 최소 DOM 환경에서 실제 UI 이벤트 코드를 실행한 결과는 렌더링 검증과 구분한다. 44개 원작 관측 명세와 30개 참조 계약 시나리오 역시 서로 다른 범주로 집계한다. 자세한 실제 통과 수는 [릴리스 검증](reports/release_validation.md), 데이터 개수는 [정합성 보고서](reports/validation_report.md), 복원 범위는 [품질 보고서](reports/quality_report.md)에서 확인할 수 있다.

후속 구현은 결측을 먼저 숫자로 채우는 방식으로 진행하지 않는다. 레벨·형상·단위·적용 시점이 일치하는 근거를 확보한 항목부터 명시적으로 승인 가능한 설정으로 연결한다. 자료가 상충하는 항목은 두 주장을 남기고 필요한 관측 조건을 지정한다.
