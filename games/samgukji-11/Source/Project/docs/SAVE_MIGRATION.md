# v1 → v2 저장 변환

대상은 `RTK11_WEB_SAVE`, schema 1의 **RTK11_Web_v1** 프로토타입 저장 파일입니다.
원작 세이브 바이너리, 다른 샘플 구현의 저장 포맷은 지원하지 않습니다.

1. 헤더, 도시 42개, 부대 수와 좌표의 기본 구조를 검증합니다.
2. 입력 데이터를 복제합니다. 원본 파일과 v1 localStorage 키는 수정하지 않습니다.
3. 도시 위치를 `q2=2*q+(r%2)`, `r2=2*r`로 이동합니다.
4. 개발지는 새 지도에서 재생성합니다. 시설 종류·레벨·완료까지 남은 턴은 유지합니다.
5. 부대 좌표를 확장하고, 통행 불가·중복 위치일 때 가장 가까운 사용 가능한 헥스로 옮깁니다.
6. 화재 위치를 확장하고 schema 2 및 expanded-4x-v2 지도 식별자를 기록합니다.
7. 전체 무장 참조·도시 자원·부대 배치 검증을 통과한 결과만 불러옵니다.

군주, 턴, RNG, 도시 자원, 병력, 특기·능력치, 기교, 이벤트 완료 기록을 보존합니다.
개발지 인접 관계와 부대의 장애물 회피 위치는 달라질 수 있습니다. 따라서 변환 후 캠페인은
v1과 완전히 같은 이후 진행을 보장하지 않습니다. 원본 JSON을 반드시 보관하십시오.

새 자동 저장 키는 `rtk11-web-v2-3d-save`입니다. v2가 없을 때만 v1 키를 읽어 변환합니다.
브라우저 저장소가 차단된 경우 JSON 내보내기·불러오기를 사용하십시오.
