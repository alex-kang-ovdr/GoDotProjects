# v2 3D 렌더링 구조

## 모듈 경계

`Engine`은 DOM과 WebGL을 참조하지 않습니다. 렌더링이 없는 Node.js에서도 같은 턴·전투 결과를 계산합니다.
UI가 명령을 호출하면 엔진이 상태를 즉시 확정하고 `effects`에 시각화 기록을 추가합니다.
`Renderer3D.consume()`가 이 기록을 소비하지만 게임의 난수 시드·병력·위치를 다시 계산하지 않습니다.

```text
사용자 입력 → UI → Engine 명령·검증 → 확정된 게임 상태
                           └─ effects → Renderer3D
확정 상태 → 도시·시설·부대 화면      ├─ 경로 보행 / 무기 동작
                                   ├─ 화살·먼지·피해 숫자
                                   └─ WebGL2 인스턴스 버퍼
```

## 맵 확장

| 값 | v1 | v2 |
|---|---:|---:|
| 열 | 43 | 86 |
| 행 | 35 | 70 |
| 헥스 수 | 1,505 | 6,020 |
| 도시 수 | 42 | 42 |

odd-row offset 좌표에서 기존 지점은 `q2=2*q+(r%2)`, `r2=2*r`로 변환합니다.
이는 표시 중심 좌표의 2배와 일치합니다. 지형 생성에는 정규화한 q/2, r/2를 사용합니다.
도시 사이의 기존 헥스 직선 연결을 새 좌표에서 다시 계산해 도로와 여울을 확보합니다.
경로 검색 큐는 안정적 tie-break를 가진 최소 힙으로 변경했습니다. 이동 비용과 ZOC 규칙은 유지합니다.

## WebGL

외부 3D 라이브러리 없이 WebGL2 API를 사용합니다. 정점의 위치·법선·색상과 인스턴스별
모델 행렬·색을 버퍼에 저장하고 `drawArraysInstanced`로 출력합니다.
기본 형상은 상자·원기둥·원뿔·구·지붕·고리·깃발입니다. 아트 데이터 다운로드가 없습니다.

지형은 공유 위치에서 계산한 높이·법선·지표색을 이용한 헥스 팬 메시입니다.
수목과 도시 인스턴스는 공간 청크로 나누고 카메라 절두체 밖 청크를 제외합니다.
군대는 화면상 가까운 부대만 병사 모델을 생성하고, 원거리에는 간략 표식을 사용합니다.

그림자는 방향광 depth texture + 3×3 PCF입니다. 낮음 품질 및 전체 지도에 가까운 원거리 시점에서는 끕니다.
수면은 절차적 물결 색과 반사광을, 깃발은 정점 변형을 사용합니다.
고정된 색상 팔레트와 절차적 노이즈를 사용하며, PBR 스캔 재질·실사 텍스처·후처리 SSAO는 없습니다.

## 부대 모델과 애니메이션

보병은 상체·치마갑옷·머리·투구·팔·다리·무기의 조합, 기병은 말·안장·기수,
공성 병기는 차륜·목재 프레임·지붕·충목 또는 정란으로 구성합니다.
각 병사는 독립 엔진 개체가 아니라 동일한 규칙 부대를 표현하는 인스턴스입니다.

이동 효과에는 확정 경로 전체가 포함됩니다. 화면의 병사는 이 경로를 구간별 보간하므로
금지 지형을 직선으로 가로지르는 단순 시작/끝 보간을 피합니다.
전투 효과에는 공격자·대상 ID, 병과, 원래 좌표, 성공 여부, 전법 종류가 포함됩니다.
근접 전진, 무기 기울기, 원거리 포물선, 후퇴·넉백, 흙먼지, 피해 수치는 이 기록의 타임라인에 맞춥니다.

다음 턴을 누르면 AI의 논리 명령은 먼저 처리됩니다. 애니메이션은 이를 시각화하며 실시간 전투가 아닙니다.
병사별 충돌·공격 판정·사망 물리·물리 기반 군집 시뮬레이션을 수행하지 않습니다.

## 입력·화면

3D 피킹은 역투영한 카메라 광선과 지형 높이 함수의 교차를 구한 다음 offset hex로 반올림합니다.
화면상 병사 실루엣 근처 클릭에는 부대 선택 우선권을 줍니다.
이름·병력 바·피해 숫자는 별도의 투명 Canvas 2D 레이어에 표시하여 확대에 관계없이 읽을 수 있게 합니다.
기존 UI가 사용하던 focus/select/pan/zoom/toHex/toScreen/consume 인터페이스를 유지합니다.

## 자원과 제한

GPU 버퍼의 도시 인스턴스는 시설·소유권·손상 상태가 바뀔 때 재생성하고 이전 인스턴스 버퍼를 폐기합니다.
WebGL 컨텍스트가 생성되지 않으면 2D 렌더러로 전환하고 화면에 알립니다.
실행 도중 컨텍스트가 소실되면 상태 안내를 표시합니다. 자동 GPU 컨텍스트 복원은 구현하지 않았습니다.
