# 삼국지 11 웹 · 3D 전장 v2

기존 RTK11_Web_v1을 확장한 오프라인 JavaScript 턴제 전략 프로토타입입니다.
**43×35 → 86×70, 총 1,505 → 6,020 헥스(4배)**. 도시 수는 42개를 유지합니다.
WebGL2 입체 지형, 병사 대열, 기병, 공성 병기와 전투 연출을 구현했습니다.
원작 게임의 공식 포팅·완전 복원본이나 실사급 그래픽 데모가 아닙니다.

## 바로 실행

1. ZIP을 모두 압축 해제합니다.
2. **PLAY.html**을 WebGL2를 지원하는 브라우저에서 엽니다. Windows는 **START_GAME.bat**도 사용할 수 있습니다.
3. 캠페인을 시작하거나 **3D 전투 훈련**을 선택합니다.

`PLAY.html` 하나에 데이터, CSS, 엔진, 3D 렌더러, 2D 호환 렌더러가 포함됩니다.
인터넷·로그인·CDN·npm 설치 없이 동작하도록 구성했습니다. 단일 HTML 파일을 다른 폴더로 옮겨도 됩니다.
별도 실행 파일 다운로드: 패키지와 함께 제공한 `RTK11_3D_Play.html`은 `PLAY.html`과 같은 내용입니다.

기본 실행에서 Node.js는 필요하지 않습니다. 조직 정책으로 로컬 HTML 열기가 제한된 경우,
허용된 개발 환경에서 `node server.cjs` 또는 `START_LOCAL_SERVER.bat`으로 로컬 서버를 사용할 수 있습니다.
보안 정책을 해제하거나 우회하는 기능은 없습니다.

## 바로 3D 전투하기

시작 화면의 **3D 전투 훈련**은 아군 4부대, 적 3부대를 배치한 재구성 훈련 시나리오입니다.
선택된 조조 창병과 인접한 원소 극병을 대상으로 **공격 → 적 부대 클릭**을 수행할 수 있습니다.
왼쪽 부대 목록에서 노병·기병·충차도 선택할 수 있습니다.

**전투 시점**은 선택 부대를 가까이 보여 줍니다. **넓게 보기**는 좌우 정보 패널을 접어 전장을 넓힙니다.
훈련도 일반 엔진의 병력·공격·이동·턴·승패 규칙을 사용합니다. 원작의 역사적 전투 배치는 아닙니다.

## 조작

| 조작 | 기능 |
|---|---|
| 왼쪽 클릭 | 도시·부대 선택 / 현재 명령의 대상 지정 |
| 왼쪽 드래그 | 지도 이동 |

| 마우스 휠 / ＋·− | 확대·축소 |
| Q / E | 좌우 회전 |
| 전략 시점 / 전투 시점 | 높은 전략 시점 / 낮고 가까운 전투 시점 |
| V / 넓게 보기 | 좌우 패널 접기·복원 |
| 전체 | 지도 전체 / 수도 시점 |
| 미니맵 클릭 | 해당 지역으로 카메라 이동 |

작은 화면에서는 단일 손가락으로 지도 이동, 화면 버튼으로 회전·확대를 사용할 수 있습니다.
멀티터치 핀치·두 손가락 회전은 구현하지 않았습니다.

기병은 최대 20기이며, 공성 병기는 대표 병기와 호위병으로 표현합니다.
**화면에 보이는 병사는 수천 명 병력의 축약 표현이지, 각자 물리·경로 탐색을 수행하는 개별 AI가 아닙니다.**

## 기존 게임플레이

내정 건설·증축·철거, 징병·훈련·순찰·생산·수리, 부대 편성·출진·이동·전법·계략,
공성·도시 점령, 군량·보급·수송, 기교·정전·선택 이벤트, 적 AI·턴 진행·승패,
JSON 저장·불러오기를 유지했습니다. 기존 엔진 규칙 테스트를 다시 실행했습니다.

확장 지도에서는 도시 간 헥스 거리가 길어집니다. **이동력·사거리·1턴 10일 규칙은 유지**했으므로
진군에 더 많은 턴과 보급이 필요합니다. 이는 단순한 화면 확대와 다릅니다.

## 저장 파일

상단 **내보내기**로 JSON을 백업하고 **불러오기**로 복구합니다.
브라우저 저장소가 허용되면 명령 후 자동 저장합니다. 차단되면 JSON 저장을 사용하세요.

- 새 자동 저장 키: `rtk11-web-v2-3d-save`
- 이전 키 `rtk11-web-v1-save`는 덮어쓰지 않고 읽기만 합니다.
- 이 대화의 **RTK11_Web_v1** 형식(schema 1) JSON을 변환합니다.
- 원작 삼국지 11의 바이너리 세이브나 다른 프로토타입의 세이브를 읽는 기능은 아닙니다.
- 개발지는 재배치되어 인접 시설 보너스가 달라질 수 있습니다. 원본 JSON을 별도로 보관하세요.

## 성능·검증 범위

그래픽 하드웨어 가속을 사용할 수 있는 환경이 적합합니다. 느리면 **낮음** 품질을 선택하고,
전략 시점으로 돌아가거나 브라우저 창을 줄여 보십시오. 프레임 속도를 보장하지 않습니다.

검증 환경은 Linux Chromium + Xvfb + SwiftShader 소프트웨어 WebGL2입니다.
이 환경에서 실제 셰이더 컴파일, 3D 렌더링과 UI 조작을 검사했지만, 물리 GPU나
Windows/모바일 실기기 성능을 측정한 것은 아닙니다. 직접 `file://` 탐색은 작업 환경 정책으로
제한되어, 동일한 `PLAY.html` 번들을 브라우저에 직접 주입해 검사했습니다.
게임 규칙·서버 77개, 브라우저 UI 31개, 전투 렌더링 8개, 총 116개 검사가 통과했습니다.
정확한 실행 항목과 결과는 `docs/TEST_REPORT.md`에 기록했습니다.

## 소스 구성

```text
PLAY.html                   단일 HTML 실행본
index.html                  분리형 개발 실행본
css/style.css               반응형 UI
js/data.js                  JSON 데이터의 브라우저/CommonJS 번들
js/engine.js                DOM 없는 게임 규칙, 경로 탐색, 저장 변환
js/webgl.js                 행렬·절차 모델·인스턴싱·셰이더·그림자
js/renderer.js              지형·도시·병사·카메라·피킹·전투 연출
js/renderer2d.js            2D 호환 모드
data/game-data.json         수정 가능한 원본 게임 데이터
data/battle-training.json   훈련 시나리오 예제 저장
reference/                  기존 v5 자료와 v1 저장 예제
tests/                      규칙·서버·브라우저 검사
tools/build.mjs             의존성 없는 번들 빌드
```

개발 명령(Node.js 18 이상):

```sh
npm test
npm run build
npm start
```

`node tools/build.mjs`는 `data/game-data.json`에서 `js/data.js`를 다시 만들고
JS/CSS를 인라인으로 넣은 `PLAY.html`을 생성합니다. 외부 패키지를 설치하지 않습니다.

## 원작과의 차이

원작 그래픽·음원·모델·원문 대사를 사용하지 않았습니다. 모든 3D 메시와 연출은 이 프로토타입용
절차적 재구성입니다. 지도, 시나리오 초기 배치, 전투 공식과 AI도 원작의 완전 복원본이 아닙니다.
수군·항구·관문, 일기토·설전, 원작 전체 역사 이벤트·전체 특기, 병사별 물리 충돌·래그돌은 미구현입니다.
기존 공개 자료 기반 표본과 재구성 데이터의 구분은 `reference/`와 `docs/FIDELITY.md`를 참조하십시오.
