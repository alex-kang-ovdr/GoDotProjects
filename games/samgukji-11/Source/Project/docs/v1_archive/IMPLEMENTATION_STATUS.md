# 구현 상태 체크리스트

## 실제 연결된 플레이 흐름

```text
세력/난이도/승리조건 선택
  → 도시의 건설·징병·훈련·생산
  → 주장·부장·병과·병력·군량 편성
  → 헥스 이동·사거리 확인
  → 통상 공격 / 전법 / 교란 / 화계
  → 부대 격파 또는 성벽 파괴·도시 점령
  → 적 AI 행동·경제 갱신·보급·이벤트
  → 추가 확장·기교 연구·정전
  → 목표 도시 수 승리 / 세력 상실 패배
```

저장·JSON 내보내기·불러오기는 위 흐름에 연결되어 있습니다. 테스트는 고립된 규칙 검증과 브라우저 UI 명령 흐름 양쪽에서 수행합니다.

## 구현된 부분

- 새 42도시 헥스 월드, 육로 연결, 미니맵, 드래그·확대, 상태 라벨
- 도시별 자원, 행동력과 무장 행동 소모, 시설 건설·완공·강화·철거
- 생산과 출진의 실제 재고 차감, 부대별 군량, 보급과 입성
- 거리·지형 기반 이동과 사선 검사, 적 인접 이동 정지
- 7병과, 12전법의 구별된 효과, 교란·화재·반격·성벽·점령
- 규칙 기반 비플레이 세력 AI, 세력 연구, 단순 정전, 자동 수송
- 첫 군정 목표와 신규 선택 이벤트, 승패 화면
- 독립 엔진, 데이터 원본/생성본, 번들러, 로컬 서버, 단위/UI 테스트

## 의도적인 단순화

지도는 원작 좌표가 아닙니다. 무장 능력 산정은 최대값 결합이며 주장/부장 상성 규칙이 없습니다. 시설 강화는 동일 시설 병합이 아닙니다. 수송은 지도 부대 없이 시간으로 처리합니다. 외교 정전은 확정 성공합니다. 도시 점령 시 포로·등용 판정 대신 일부 무장 후퇴와 수비관 귀속을 적용합니다. 관시·범위 전법은 단순 헥스 기하를 사용하고 난사 아군 피해를 생략했습니다.

## 아직 없는 부분

관문·항구·함선과 수전, 잔도·낙석·군사시설·불함정, 원작 전체 특기·기교, 일기토·설전, 임무/인사/포상/등용/혈연, 군단 위임, 원작 역사 이벤트와 결전제패, 인물 사망/승계, 멀티플레이, 플랫폼 로그인·분석 지표 SDK, 사운드·원작 아트, 화면 녹화·리플레이 플레이어, 데이터 편집 UI는 포함하지 않습니다.

## 테스트의 한계

자동 검사 통과는 원작 수치와의 일치 또는 전략 AI의 완성도를 뜻하지 않습니다. 장기 밸런스 테스트와 실제 사용자 플레이 검토가 필요합니다. 고정 시드의 재현성을 검사하지만 원작 난수열은 재현하지 않았습니다.
