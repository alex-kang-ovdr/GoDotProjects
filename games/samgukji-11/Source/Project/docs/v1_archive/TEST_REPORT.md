Python Playwright와 Chromium headless를 사용했습니다. DOM 버튼 클릭, 폼 입력, 실제 Canvas 좌표 클릭, 다운로드와 파일 업로드로 조작했습니다. 게임 상태를 읽어 결과를 확인했으며 정상 조작 흐름에서 게임 상태 값을 직접 바꿔 명령 결과를 조작하지 않았습니다. 카메라/선택을 위한 공개 UI 테스트 핸들은 사용합니다.

주요 흐름:

```text

 → 초기 전위대 선택 → Canvas에서 이동

 → JSON 다운로드 → 한 턴 진행
 → 저장 JSON 업로드 → 이전 턴 복구
```

## 중요한 실행 환경 제한

작업 환경에 설치된 Chromium은 관리 정책으로 `file://`와 `http://127.0.0.1` 페이지 탐색을 차단했습니다. 정책을 바꾸거나 해제하지 않았습니다.

따라서 브라우저 검사는 **실제 번들과 같은 전체 HTML/CSS/JS를 `page.set_content`로 렌더링**하여 수행했습니다. 로컬 파일 더블클릭 및 브라우저 HTTP 탐색 자체를 이 환경에서 통과했다고 주장하지 않습니다. 로컬 HTTP 서버는 Node HTTP 클라이언트로 응답과 경로 보안을 따로 검사했습니다.

자동 저장은 환경의 저장소 권한에 따라 실패할 수 있도록 처리했고 JSON 파일 내보내기/불러오기 흐름을 확인했습니다. 영구 브라우저 저장·파일 URL 저장소의 실제 브라우저별 정책까지 검증한 것은 아닙니다. 중요한 진행은 JSON으로 보관하세요.
