# 삼국지 11 웹 v3 — 동일 게임 2D / 3D 전환

**같은 캠페인·같은 부대·같은 게임 상태를 2D 지도 또는 3D 전장으로 표시합니다.**
모드를 바꾸어도 게임을 새로 시작하거나 턴을 진행하지 않습니다.

## 실행

ZIP을 모두 풀고 **PLAY.html**을 Chrome 또는 Edge에서 엽니다.
Windows에서는 **START_GAME.bat**으로 같은 파일을 열 수 있습니다.
이 배포물과 함께 제공되는 `RTK11_2D3D_Play.html`도 동일한 단일 파일 실행본입니다.
인터넷, CDN, 로그인, npm 설치 없이 동작하도록 코드·데이터·CSS가 모두 포함되어 있습니다.

작업 환경이나 조직 정책으로 로컬 HTML 실행이 제한되면 허용된 환경에서
`node server.cjs` 또는 `START_LOCAL_SERVER.bat`을 실행합니다. 기본 서버는 localhost 전용입니다.
IIS에는 압축 해제한 폴더를 정적 콘텐츠로 배치하고 `index.html` 또는 `PLAY.html`을 엽니다.
Windows·IIS에 대한 실제 배포 검증은 수행하지 않았습니다.

## 전환 방법

- 시작 화면에서 **2D 지도 / 3D 전장**을 선택한 뒤 캠페인 또는 **전투 훈련**을 시작합니다.
- 플레이 중 지도 위의 **2D 지도 / 3D 전장** 버튼을 누릅니다.
- 키보드 **B**로 현재 모드를 전환합니다. 대화창·입력란에서는 작동하지 않습니다.

모바일 화면에도 두 버튼이 표시됩니다. 3D가 지원되지 않거나 실행 중 GPU 연결이 끊기면
**2D로 계속 진행**하며 사용할 수 없는 3D 버튼은 비활성화됩니다.

## 전환 시 유지되는 항목

| 항목 | 동작 |
|---|---|
| 캠페인 | 세력, 턴, 날짜, 금·군량·병력, 도시·시설·연구·이벤트 유지 |
| 전투 | 부대 위치, 병력, 기력, 행동 여부, 상태 이상 유지 |
| 선택·명령 | 선택한 도시·부대, 이동/공격/전법 모드, 선택 전법, 격자 유지 |
| 카메라 | 지도의 중심 좌표 유지, 확대율은 두 투영 사이에서 환산 |
| 3D 시점 | 돌아왔을 때 기존 회전각·기울기 유지 |
| 연출 | 진행 중인 이동·전투 효과의 원래 타임스탬프를 넘겨 중복 실행 방지 |
| 저장 | 동일한 JSON 저장 데이터를 두 모드에서 공통 사용 |

2D는 북쪽 고정 평면 지도이며, 3D는 원근·회전·지형 고도가 있습니다.
따라서 화면 배치까지 픽셀 단위로 동일하지는 않습니다.
확대율은 각 모드의 허용 범위로 제한되므로 극단적인 확대·축소에서는 시야 크기가 달라질 수 있습니다.

## 유지된 게임

86×70 = **6,020헥스**, **42개 도시**, 내정·병장 생산·출진·이동·공성·점령,
전법·계략·보급·기교·정전·선택 이벤트·적 AI·승패·저장을 유지했습니다.
이번 버전은 화면 전환 추가이며 **게임 규칙 엔진 `js/engine.js`는 v2와 동일합니다.**
원작의 완전 복원판은 아니며 기존 재구성 수치·지도·AI의 한계도 동일합니다.

## 2D와 3D

| 2D 지도 | 3D 전장 |
|---|---|
| Canvas 2D 지형·도시·병과 표식 | WebGL2 지형·도시·병사·병기 모델 |
| 북쪽 고정, 드래그·확대·미니맵 | 드래그·확대·회전·기울기·미니맵 |
| 공격선·화살·피격 표시·피해 숫자 | 병사 동작·화살·먼지·화재·피해 숫자 |
| 3D 회전·품질 설정 비활성화 | 낮음/보통/높음 품질 선택 |

전략 시점/전투 시점 버튼은 2D에서도 각각 넓은 시야/근접 확대에 사용합니다.
V 키 또는 넓게 보기로 정보 패널을 접습니다.

## 성능과 모드 기억

보이지 않는 렌더러의 animation frame 루프는 멈춥니다.
다시 전환할 때 재사용하도록 기존 지형과 GPU 자원은 메모리에 보관합니다.
즉 **2D 전환만으로 이미 할당된 모든 GPU 메모리를 해제하는 방식은 아닙니다.**
처음부터 2D를 선택한 선호 설정이 읽히면 3D 렌더러는 3D 선택 시까지 만들지 않습니다.

선호 모드와 3D 품질은 `rtk11-view-preferences-v3`에 따로 저장합니다.
브라우저 저장소가 허용된 경우에만 재실행 시 복구됩니다.
게임 상태 저장은 기존 `rtk11-web-v2-3d-save` 키와 schema 2를 유지하므로
v2 브라우저 저장을 이어받을 수 있습니다. 파일 위치/브라우저에 따라 저장소 접근이 달라질 수 있으므로
**이전 실행본에서 JSON 내보내기 → 새 실행본에서 불러오기**를 권장합니다.
이 대화의 RTK11 웹 v1 JSON도 기존 좌표 변환 기능으로 불러올 수 있습니다.
원작 삼국지 11 바이너리 세이브는 지원하지 않습니다.

## 변경 소스

```text
js/view-manager.js       동일 게임의 렌더러 선택·재사용·오류 복구·선호 모드
js/view-math.js          투영과 무관한 카메라 중심·화면 크기 환산
js/renderer2d.js         2D 전투 효과, 전체 지도, 활성/정지 생명주기
js/renderer.js           3D 렌더러 활성/정지·GPU 오류 알림
js/webgl.js              GPU 자원 추적·해제
js/ui.js                 모드 버튼·B 단축키·입력 상태 유지
index.html / css/        시작 화면·전장·모바일의 모드 전환 UI
```

`npm test`는 엔진·서버·카메라 계산 테스트를 실행합니다.
`npm run build`는 수정된 소스를 `PLAY.html`로 묶습니다.
브라우저 검사는 개발 환경에 Playwright와 Chromium을 별도 설치한 뒤
Linux에서는 `xvfb-run -a python tests/browser_dualmode.py`로 실행합니다.
일반 게임 실행에는 이 테스트 도구가 필요하지 않습니다.

검사 결과와 제한은 `docs/TEST_REPORT.md`, 기술 구조는 `docs/DUAL_VIEW.md`를 참조하십시오.
