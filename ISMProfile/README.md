# ISMProfile — Unreal InstancedMeshProfile → Godot port

Same deterministic voxel terrain, cube/atlas, ortho camera and AB/BA benchmark protocol as the Unreal sample,
run in Godot (MultiMesh vs one node per block) and compared against Unreal (ISM vs one Actor per block).

Results and analysis: [report/README.md](report/README.md). Reproduction commands are in section 6 of the report.
