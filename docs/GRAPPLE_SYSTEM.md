# 물리 갈고리 체인

`G`를 누르면 마우스로 조준한 다른 우주선에 갈고리를 발사한다. 사거리 안의 대상에 명중하면 `RigidBody2D` 링크와 `PinJoint2D` 제약으로 구성된 체인이 연결된다. 플레이어가 실제 추력으로 이동하면 연결된 우주선도 체인 물리에 따라 끌려간다. 같은 키를 다시 누르면 수동 해제하며, 최대 사거리와 여유 길이를 넘으면 자동으로 끊어진다.

체인 링크는 `collision_layer = 0`, `collision_mask = 0`으로 생성되므로 함선↔체인 링크의 충돌·일반 상호작용을 만들지 않는다. 연결 대상에 남는 물리 효과는 PinJoint 제약의 견인뿐이다. 반면 연결된 두 우주선은 기존 2D 물리 충돌을 그대로 유지한다.

갈고리 체인은 별도 HP를 가진다. 비행 중 갈고리 머리 또는 연결된 체인 선분을 레이저·총알·미사일로 맞히면 피해를 받고, HP가 0이 되면 `GRAPPLE DESTROYED`로 연결이 해제된다. 체인 피격 판정도 선분의 제곱 거리 비교를 사용한다.

사거리 판정은 `ShipBody.is_within_surface_range`를 사용한다. 제곱 거리 비교에 양쪽 조립체 바운드 스피어를 더하므로, 큰 우주선도 외곽 기준으로 정확히 인식된다. `PinJoint2D` 체인을 유지하면서 끝점 사이에는 신장량·상대 속도 기반 축방향 장력 보정을 적용한다. 이 보정은 고출력 메인 추진기에서도 긴 링크의 제약 오차를 줄인다. 링크 길이, 최대 링크 수, 감쇠, 장력 강성·댐핑·상한, 사거리, 끊김 여유는 [balance.gd](../Godot/scripts/balance.gd)의 `GRAPPLE` SSOT에서 조정한다.
