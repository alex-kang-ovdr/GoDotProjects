# 모듈 확인 치트 / 텍스처 디자인 모드

2026-09-23 구현. 기본은 **무텍스처 모듈 치트**다. 왼쪽 위 HUD의 다섯 번째 버튼 `디자인 보기`를 누르면 기존 albedo+RGB mask 디자인으로 전환하고, `모듈 치트 보기`로 돌아온다.

- 치트: 파트 타입별 단색 BoxMesh, 셀 외곽, 짧은 한글 역할명과 HP 막대. 이름은 코어/장갑/주추진/역추진/RCS/레이저/미사일/자동어뢰/미사일고/탄약고/방어막 등 전체 파트 종류에 대응한다.
- 텍스트는 함선·카메라 회전과 상쇄되어 화면에서 수평을 유지한다. 다칸 파트는 파트 중심에 이름을 한 번만 표시한다.
- 커서를 모듈에 올리면 하단 카드에 전체 표시명, 데이터 ID, Hull 현재/최대, 질량, 추진력, Power가 나온다. 플레이어·NPC·중립 부품을 구별하며 부품을 들고 있을 때는 `배치 중` 상세 정보를 유지한다. 이름 표시는 번역·시각 메타데이터이며 물리 튜닝이 아니다.
- 중립 부품도 치트 모드에서는 `SALV` 대신 역할명을 표시한다. 다칸 부품의 끝 셀에서도 상세 정보를 확인할 수 있다. 중립 부품은 기존 2D 표현을 유지하며 디자인 모드에서는 종전 회수 표식으로 돌아간다.
- 디자인: 기존 고유 텍스처·RGB 마스크 재질. 치트용 이름·HP 막대와 검사 카드를 숨긴다.
- 두 모드 모두 같은 3D 메시·직교 투영·2D 충돌체를 사용한다. 변경 시 재질만 교환하여 HP·탄약·질량·위치·CoM·파트 수를 변경하지 않는다.
- 기존 플레이어·NPC와 새로 생성하는 NPC에 적용된다. 세션 중 선택은 재시작에도 유지되며 앱을 새로 실행하면 치트가 기본이다. 영구 저장 옵션은 아직 없다.
- `visual_tuning.gd`의 `use_textured_design`과 `MODULE_DEBUG_LABELS`에서 표현 정책을 관리한다. CSV의 전체 `display_name`은 그대로 유지한다.

- 2026-09-23 공용 프레임워크 9개 suite 전부 통과. `core-gameplay`는 기본 무텍스처, 디자인 전환, 기존/새 NPC 적용, 치트 복귀, 22개 종류의 명시적 이름 매핑, 질량·코어 HP·파트 수 불변을 확인했다.
