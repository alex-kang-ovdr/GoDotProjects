# 표적 지정 · 자동 조준 · 자동 항법

## 입력 규칙

- **적 함선 좌클릭/터치**: 적의 회전된 외곽 박스 안을 클릭하면 적 함선만 `TARGET LOCK`으로 지정한다. 적 함선의 파트는 중립 회수품이 아니므로 들거나 장착할 수 없다.
- **중립 부품 좌클릭/터치**: 실제 부품 중심에서 72px 이내를 눌렀을 때만 회수한다. 회수 범위가 넓은 상태에서 적을 잘못 집는 문제를 피한다.
- **빈 공간 좌클릭/터치 또는 우클릭**: 해당 월드 좌표를 자동 항법 목적지로 지정한다. 자동 항법은 함선이 목적지를 향해 회전한 후 메인 추진기를 가하며, 54px 안에 들어오면 정지한다.
- **적 함선 우클릭**: 적을 먼저 표적으로 지정한 뒤 유도 미사일을 발사한다. 우클릭 드래그는 기존처럼 카메라 수평 회전만 수행한다.
- **수동 추력**: `W/S/A/D` 입력이 있는 동안 자동 항법을 해제한다.

## 조준과 무기 HUD

표적이 살아 있는 동안 `Space`, `F`, 그리고 우측 하단의 무기 카드는 표적 함선 중심을 조준한다. 표적이 없으면 마우스 좌표를 사용한다. 자동 미니 어뢰는 사거리 내 적대 NPC 중 선택 표적을 우선한다.

우측 하단 HUD는 색 블록과 `GUNS`, `MISSILE`, `GRAPPLE` 상태를 표시하며 클릭/터치도 가능하다. 주무기 준비·냉각, 미사일 발사대·재고·재사용 시간, 갈고리 체력/준비 상태를 보여 준다.

## 2026-09-23 실제 구현 보정

- 자동 어뢰는 적대 NPC만 공격한다. 평화 NPC는 표적 선택만으로 공격하지 않는다.
- 유도탄은 살아 있는 표적 좌표를 갱신하며 미니 어뢰는 2초 유도 후 급가속한다.
- HUD 주무기 카드는 누르고 있으면 연사한다. 미사일 발사대 유무·탄약 소비·쿨다운을 표시한다. 대화·정지·편집 중 입력은 차단한다.
- 회수는 함선 외곽 기준 420px 이내다. 잘못된 배치에서는 계속 들고 있으며 Q/우클릭/화면 회전 버튼, ESC/취소 버튼을 제공한다. Shift 재배치로 끊긴 하위 연결도 중립으로 분리한다.
- 항법은 올바른 회전 부호·각속도 피드백·전방 정렬 후 가속·제동 거리 계산을 적용한다. 54px 진입 후 순간 정지가 아니라 실제 제동으로 잔여 속도를 줄인다.

## 조정 위치 (현재)

자동 항법 수치는 공용 밸런스 SSOT인 [`balance.gd`](../Godot/scripts/balance.gd)의 `Balance.NAVIGATION`에만 둔다.

- `arrival_radius`: 목적지 도착 판정 반경
- `slow_radius`: 접근 저속 구간 반경
- `turn_gain`: RCS 회전 보정 계수
- `cruise_throttle`, `approach_throttle`: 실제 메인 추진기 입력값

테스트는 `target-navigation` 자동화 스위트가 적 선택, 표적 조준 좌표, 자동 항법 활성화 및 실제 추력 발생을 검사한다.
