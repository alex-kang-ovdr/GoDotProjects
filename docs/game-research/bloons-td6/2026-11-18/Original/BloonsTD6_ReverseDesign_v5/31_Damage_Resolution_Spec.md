# 피해 처리 상세 규격

## 단일 타격 파이프라인
1. 타격 시점 대상이 살아 있는지 확인.
2. 탐지(Camo) 조건 검사: 타게팅 단계와 충돌 단계 모두 구분.
3. 타격 태그/면역 매트릭스 검사. 면역이면 피해·상태이상·관통 소비 정책을 별도로 적용.
4. 피해량 계산: 기본값, 타입별 보너스, MOAB 보너스, 취약 디버프, 난이도 보정.
5. 내구도 소진 후 자식 생성. 오버킬 피해 전달 여부는 공격 효과마다 별도 정의.
6. 소환된 자식의 진행 거리, 방향, 속성 상속, 분할 횟수 처리.
7. Pop 보상은 최종 파괴한 레이어와 모드 규칙을 기준으로 회계 이벤트 발행.

## 충돌 중복 방지
`projectileId,targetId,hitEpoch` 키를 사용. 같은 투사체의 재타격 가능 여부는 `rehitCooldownTicks`로 설정. 자식 생성은 커맨드 버퍼로 모아 프레임 종료 시 반영해 순회 중 컬렉션 변경을 피한다.

## 결정론
고정 60Hz 논리 틱(프로토타입 가정), 정수 틱으로 스폰·쿨다운·상태이상 처리. 렌더 프레임과 분리. 난수는 seed 고정. 부동소수 비교에는 정렬된 ID 타이브레이커 사용.

## 테스트
- 단일 Red 풍선 1피해로 제거
- Yellow 계층에 2피해 적용 시 자식 레이어 검증
- 면역 풍선에 비호환 타입 적용 시 피해 0
- 관통 3인 투사체가 네 번째 대상에 영향 없음
- 동일 프레임 이중 타격에서 자식 중복 생성 없음
- Camo 탐지 버프 제거 직후 신규 타겟 선정 불가
