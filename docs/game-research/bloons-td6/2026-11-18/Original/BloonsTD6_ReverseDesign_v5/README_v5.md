# Bloons TD 6 역기획서 v5.0

기존 v4 문서 전체와 신규 상세 명세 39~46, 타워 공격 유형 CSV, 23종×15단계=345개 업그레이드 검증 슬롯 CSV, 라운드 1~100 검증 템플릿 JSON을 포함한다.

**중요:** `upgrade_slots_v5.csv`의 빈 효과/가격과 `rounds_1_100_verification_template_v5.json`의 빈 그룹은 원작 데이터를 복원했다는 의미가 아니다. 원작 수치의 검증 전 데이터는 `unverified`로 표시한다. 공격 유형 분류는 구현을 위한 개념적 분류이며 복합 공격은 추가 컴포넌트로 정의해야 한다.

## 읽는 순서
39 공격 계약 → 40 분할 → 41 업그레이드 → 42 라운드 → 43 영웅 → 44 실험 → 45 개발 도구 → 46 수용 기준.

## 검증 정책
실제 원작 관찰과 구현 가정은 별도 출처 필드로 구분한다. 원작 에셋은 포함하지 않는다.
