# 경제와 난이도 모델

## 회계 이벤트
`PopIncome`, `RoundBonus`, `FarmIncome`, `AbilityIncome`, `TowerPurchase`, `UpgradePurchase`, `TowerSale`, `LifeLoss`. 현금 변경은 단일 원장을 통과하며 모든 이벤트에 tick/sourceId/amount를 기록.

## 투자 회수
순투자액 = 구매비용 + 업그레이드비용 - 즉시수익. 회수 시점은 누적 추가수익이 순투자액을 초과하는 최초 라운드. 방어 타워를 경제 타워로 바꾸는 기회비용은 시뮬레이션으로 측정.

## 난이도 파라미터
초기 현금, 초기 목숨, 타워 가격 배율, 라운드 종료 보너스, 판매 환급률, 수익 감소 규칙, 지식 사용 허용, 업그레이드 제한을 모드 설정으로 분리. CHIMPS는 구매·수익·판매·지식 등의 별도 제한을 데이터 규칙으로 표현.

## 검증
같은 타워 구성에서 난이도별 총 구매비용이 규칙에 맞게 변경되는지, 음수 현금이 발생하지 않는지, 중복 팝 수익이 없는지 자동 검사.
