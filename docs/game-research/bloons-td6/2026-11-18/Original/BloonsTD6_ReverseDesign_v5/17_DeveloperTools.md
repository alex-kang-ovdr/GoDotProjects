# 밸런스 에디터·치트·계측

> Bloons TD 6 역기획 v2.0 | 공개 동작 분석 + 구현용 모델. 수치 예시는 원작 확정 데이터가 아닙니다.

## 에디터 화면
타워 목록 → 스탯/업그레이드/피해 타입 편집 → 즉시 재계산 → 샌드박스 테스트 → JSON export/import.

## 테스트 컨트롤
라운드 스킵, 풍선 종류/수/속도 지정, 게임 배속, 무적, 무한 현금, 타워 강제 배치, 시뮬레이션 스텝 실행, 전투 로그.

## 관측
선택 타워의 shots, hits, effectiveDamage, pops, pierceWaste, immunityMiss, cashEarned를 분리. 10초 이동 평균 DPS와 라운드 누적값 제공.

## 자동 회귀
타워 데이터 변경마다 기본 10개 시나리오를 재실행하고 승리 라운드/현금/유출 수/CPU 시간을 비교한다.
