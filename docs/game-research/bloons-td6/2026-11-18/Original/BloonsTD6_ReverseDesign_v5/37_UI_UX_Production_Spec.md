# UI/UX 제작 명세

## 가로 모드 기본 배치
좌측 70~75% 게임 보드, 우측 타워 구매 패널. 상단 라운드/현금/목숨/속도, 하단 선택 타워 업그레이드. 작은 화면에서는 우측 패널을 접을 수 있다.

## 입력 상태 머신
Idle → TowerPreview → PlacementValid/Invalid → Confirmed → Idle. 기존 타워 선택 시 SelectedTower → Upgrade/Sell/Targeting. 터치 드래그 취소는 화면 바깥 이동이나 취소 버튼으로 처리.

## 피드백
배치 가능=녹색 외곽선, 불가=빨간 외곽선(색상 외 아이콘 병행). 공격 사거리 원, 버프 범위 원, 경로 장애 표시, 업그레이드 선행조건 및 가격, 타워별 팝 카운터.

## 접근성
UI 크기 80~150%, 색각 보정 팔레트, 투사체 이펙트 밀도 감소, 카메라 흔들림 끄기, 키보드 단축키, 입력 취소/되돌리기.
