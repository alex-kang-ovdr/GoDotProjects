# 46. 제작 완료 기준 및 릴리스 게이트

## P0 코어 플레이
- 맵 로드 → 타워 배치 → 라운드 시작 → 자동 공격 → 풍선 파괴/누출 → 승패
- 업그레이드 구매 제한과 가격 검증
- 면역·탐지·관통·분할·수익 이벤트 검증
- 저장/불러오기 후 동일 시드 재현

## P1 콘텐츠
- 각 타워의 공격 컴포넌트 정의 및 경로별 업그레이드
- 영웅 XP·스킬 및 타워 버프 상호작용
- 주요 풍선 속성, 다중 경로, 장애물, 물 배치
- 1~100라운드 스폰 데이터: `verified` 비율 표시

## P2 완성도
- 모바일 터치·데스크톱 마우스/키보드 UX
- 효과음, 피격 피드백, 선택·배치 유효성 피드백
- 부하 상황 성능 계측, 시뮬레이션/렌더 분리

## 게이트
`schema_valid=true`, `deterministic_tests_pass=true`, `no_blocker=true`, `accuracy_report_generated=true` 조건 충족 시 후보 빌드 승인. 원작 재현 정확도는 **콘텐츠별 검증 비율**로 보고하며, 완료되지 않은 항목을 숨기지 않는다.
