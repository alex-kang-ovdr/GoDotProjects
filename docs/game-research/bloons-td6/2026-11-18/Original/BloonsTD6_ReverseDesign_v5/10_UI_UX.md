# 가로모드 UI/UX

> Bloons TD 6 역기획 v2.0 | 공개 동작 분석 + 구현용 모델. 수치 예시는 원작 확정 데이터가 아닙니다.

## 화면
상단 HUD: 라운드, 라이프, 현금, 게임 속도, 일시정지. 우측: 타워 카탈로그와 가격. 타워 선택 시 업그레이드 패널, 판매, 타게팅. 좌측 또는 하단: 능력 슬롯과 알림.

## 배치 UX
카탈로그 선택 → 맵 위 드래그/클릭 → 반투명 범위 표시 → 적법성 실시간 판정 → 확정 시 비용 차감. 터치는 길게 누르기/드래그, 마우스는 클릭 배치 지원.

## 피드백
구매 불가(자원 부족), 지형 불가, 경로 잠금, 탐지 불가, 면역, 라운드 종료, 새 스킬 해금을 서로 다른 시각 신호로 표현.

## 접근성
색상만으로 풍선 유형을 구분하지 않고 아이콘/윤곽 제공. 애니메이션 감속 옵션, UI 스케일, 키보드 단축키, 일시정지 중 상세 툴팁 지원.

## 테스트
16:9, 16:10, 모바일 가로, 720p, 터치 오조작, UI 패널에 가려진 배치 영역.
