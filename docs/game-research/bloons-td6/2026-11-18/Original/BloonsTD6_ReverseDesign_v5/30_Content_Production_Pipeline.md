# 콘텐츠 제작 파이프라인 v4

## 데이터 레이어
- `source`: 관찰/공식 설명/검증 필요/프로토타입 가정 중 하나. 공개 설명과 역추정 수치를 구분한다.
- `id`: 세이브 호환성을 위해 영구 고정. 표시 이름과 분리한다.
- `version`: 게임 버전과 데이터 스키마 버전을 별도 저장한다.
- `modifiers`: 타워 기본 공격을 대체하지 않고 델타를 순차 적용한다.

## 제작 흐름
1. 기획자가 CSV에서 항목 생성, 중복 ID 검사.
2. JSON Schema에 따라 필수 필드와 타입 검증.
3. 업그레이드 간 선행조건 및 배타 경로 검증.
4. 샌드박스 시뮬레이터에서 풍선 1개, 100개, MOAB 혼합 조합 검증.
5. 골든 리플레이와 비교하고 diff 리포트 생성.
6. 데이터 버전 증가 후 릴리스. 기존 저장 게임은 ID 기반 마이그레이션.

## 원작 정확도 분류
A=공식 또는 게임 내 직접 확인, B=반복 관찰, C=커뮤니티 자료, D=구현 가정. D는 절대 원작 확정값으로 표기하지 않는다.
