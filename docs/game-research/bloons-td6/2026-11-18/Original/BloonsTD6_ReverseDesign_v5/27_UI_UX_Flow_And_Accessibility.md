# UI/UX 화면 및 상태 전이

## 화면 흐름
Home → MapSelect → ModeSelect → Loadout/Hero → Gameplay → Pause/Settings → Victory/Defeat → Result. 전투 중 TowerSelect → PlacementPreview → PlacedTowerPanel → Upgrade/Targeting/Sell.

## 가로 화면
좌측 상단 Lives/Cash/Round, 우측 타워 팔레트, 선택 타워 상세는 우측 또는 하단 확장 패널. 중요한 경로와 적은 패널에 가리지 않도록 safe area 사용. 모바일은 드래그 배치·길게 누르기 상세·취소 영역을 지원.

## 피드백
배치 가능/불가 색상, 업그레이드 가격·조건, 면역으로 공격 실패 시 시각적 피드백, 활성 스킬 준비 상태, 경로별 위험 신호, 라운드 시작/자동 시작.

## 접근성
색각 이상 대비, 색상 외 모양으로 풍선 구분, 폰트 확대, 화면 흔들림/광과민 이펙트 감소, 음향 개별 조절.
