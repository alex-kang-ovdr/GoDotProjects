# 구현 로드맵

> Bloons TD 6 역기획 v2.0 | 공개 동작 분석 + 구현용 모델. 수치 예시는 원작 확정 데이터가 아닙니다.

## Phase 1 — 전투 MVP
1맵, 5종 기본 풍선, 3타워, 배치, 타게팅, 투사체, 팝, 수익, 20라운드. 완료 조건: 외부 서버 없이 브라우저에서 20라운드 승패 가능.

## Phase 2 — 전략 시스템
면역, camo, regrow, ceramic, MOAB, 3경로 업그레이드, 4타게팅, 농장/판매, 모드. 완료 조건: 속성 대응 조합이 필수.

## Phase 3 — 콘텐츠 확장
전체 타워 카탈로그, 영웅, 다중 경로, 80+ 라운드 데이터, 맵 편집, 세이브, 능력. 완료 조건: 데이터 파일로 새 타워/웨이브 추가 가능.

## Phase 4 — 완성도
이펙트, 사운드, 최적화, 터치 UX, 개발자 밸런스 편집기, 자동 회귀 테스트, 모바일 성능 측정.

## 리스크
원작 버전별 수치 변화, 비공개 구현, 자식 풍선 중복 수익, 대규모 투사체 성능, 능력 중첩. 데이터와 코드 분리로 대응.
