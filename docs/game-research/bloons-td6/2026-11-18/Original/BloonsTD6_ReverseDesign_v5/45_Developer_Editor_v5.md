# 45. 개발자 실시간 에디터

## 패널
- Tower Inspector: 공격 주기, 사거리, 피해, 관통, 공격 유형, 업그레이드 단계
- Bloon Inspector: HP, 속도, 면역 태그, 경로 진행률, 자식 생성 규칙
- Round Timeline: 스폰 그룹 생성/복제/이동, 타입 변경, 웨이브 재생
- Economy: 현금, 생명, 수익 배율, 판매 환급률, 농장 생산
- Scenario Runner: 시드·맵·모드·라운드 선택, 일괄 실행
- Combat Debug: 히트박스, 타게팅 선, 피격 이벤트, DPS 히스토리

## 치트
무한 현금, 무적, 즉시 스킬 쿨다운, 스폰 일시정지, 특정 풍선 소환, 타워별 공격 비활성화, 배속 0.25~8배. **개발 전용**이며 사용자 게임 저장에 기록하지 않는다.

## 데이터 수정
- 변경 전후 diff 표시, undo/redo, JSON 스키마 검증
- 원작 검증 데이터는 읽기 전용 기본값; 실험값은 overlay에 기록
- `sourceStatus`를 `verified`에서 `assumed`로 자동 하향하지 않고 별도 override로 표시
- 플레이 도중 값 변경 시 기존 투사체 적용 여부를 명시

## UX
일반 게임 UI와 개발 UI를 분리한다. 디버그 패널은 접을 수 있고, 가로 화면에서 플레이 영역을 가리지 않는 도킹을 지원한다.
