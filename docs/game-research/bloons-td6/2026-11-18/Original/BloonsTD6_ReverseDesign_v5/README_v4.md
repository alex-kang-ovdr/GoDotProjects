# Bloons TD 6 Reverse Design v4

기존 v3 문서와 v4 신규 9개 상세 명세, 프로토타입 예시 JSON 2개, 피해 상호작용 CSV 1개를 포함합니다.

## 중요
- `sample_*_v4.json`의 수치는 **원작 수치가 아닌 프로토타입 가정값**입니다.
- 원작의 최신 버전 전체 타워/업그레이드/라운드 수치를 검증 완료한 데이터베이스가 아닙니다.
- `38_Verification_Backlog.md`에 정확도 검증 작업을 분리했습니다.
- 원작 고유 그래픽·사운드·텍스트는 포함하지 않습니다.

## 권장 구현 순서
피해 처리 → 업그레이드 상태 머신 → 라운드 스폰 → 경제 원장 → 맵 배치 → 시뮬레이터 → UI.
