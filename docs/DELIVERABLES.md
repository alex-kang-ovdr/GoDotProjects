# 산출물 및 기능 검증 현황

## 목적

이 문서는 `Captain Salvage` 워크트리에 필요한 실행물·설계물·조사 자료·검증 자료가 빠지지 않았는지 확인하는 인수인계 목록이다. 각 항목의 상태는 코드·정적 검사로 확인된 것과 실제 플레이로 아직 확인하지 못한 것을 구분한다.

## 실행 산출물

- [index.html](../index.html) — 게임 진입점, HUD, 조작 안내, 출항·재시작 UI. **코드 확인됨**.
- [styles.css](../styles.css) — 반응형 레이아웃과 HUD 시각 스타일. **정적 확인됨**, 실제 브라우저 시각 QA는 **미검증**.
- [game.js](../game.js) — 물리, 전투, 회수·재장착, 스폰, 보스, 정거장, 배경 렌더링. `node --check`와 Canvas 모의 런타임 경로는 **통과**. 실제 전투 완주·성능은 **미검증**.

## 설계·인수인계 산출물

- [GDD](GDD.md) — 핵심 루프, 부품 규칙, 충돌·파괴, 난이도, 성능 상한, 수락 시나리오.
- [월드 항로 설계](WORLD_ROUTE.md) — 7구역·3정거장·2중간 보스·최종 보스·30분 목표의 좌표와 튜닝 변수.
- [마일스톤 계획](MILESTONES.md) — 초기 10개 마일스톤의 이력과 장거리 항로 확장 범위.
- [절차 우주 배경 구현 계획](PROCEDURAL_SPACE_BACKGROUND_PLAN.md) — 외부 텍스처 없이 만드는 2D 별·은하수·성운의 PBG-1~PBG-6 구현·테스트·커밋 기준.
- [수동 테스트 계획](TEST_PLAN.md) — 충돌, 파괴, 회수, 재장착, 정거장, 보스 게이트, 배경, 30분 세션의 검증 절차.

모든 설계 문서는 한글로 작성돼 있으며, 구현 완료와 플레이테스트 완료를 같은 의미로 쓰지 않는다.

## 기능별 구현·검증 상태

### 비행과 함선 조립

- 관성 이동, 회전, 모듈 질량, 추진·열·사격은 구현됐다.
- 검증: JavaScript 문법과 Canvas 모의 런타임 초기화·출항·추진·사격 경로 통과.
- 미검증: 실제 키보드 체감, 브라우저별 입력, 밸런스.

### 충돌·파괴·피드백

- 함선 모듈 간, 부유 부품과 모듈·부유 부품 간의 2D 겹침 해소와 반발이 구현됐다.
- 큰 충격은 모듈 피해, 균열, 파편, 스파크를 생성한다.
- 미검증: 고속 충돌의 피해량 공정성, 파편 수가 많은 장면의 프레임 시간.

### 회수와 재장착

- 중립·적 유래 회수 부품 클릭 장착, `Shift` + 클릭 장착 부품 이동·재장착, 코어 이동 방지가 구현됐다.
- 미검증: 처음 플레이어가 소켓 강조와 420px 회수 범위를 이해하는지.

### 장거리 월드와 진행

- 성장 연동 일반 적, 7구역, 3개 정거장, 순차 중간 보스 2개, 최종 보스 게이트가 구현됐다.
- 약 30분은 월드 거리와 전투·정비 시간을 합친 **목표값**이며, 완료 시간 데이터는 없다.
- 미검증: 28–32분 평균 도달·완주 시간, 난이도 상승의 공정성, 보스전 재미.

### 배경

- CC0 패럴랙스 성운·별과 결정적 셀-해시 별 레이어가 구현됐다.
- 텍스처 없는 독자 2D 생성기는 계획만 작성됐으며 PBG-1부터 순차 구현해야 한다.
- 미검증: 최소 사양 기기 프레임 시간, 전투 가독성, 절차 성운 캐시 품질.

## 공통 검증 명령

- `node --check game.js`
- `git diff --check`

기능 구현 마일스톤에는 이 명령만으로 충분하지 않다. 해당 기능의 단위·모의 런타임·수동 시나리오를 [수동 테스트 계획](TEST_PLAN.md) 또는 해당 계획 문서에 추가하고, 결과를 진행 보고에 기록한다.

## 커밋 규칙

1. 하나의 커밋에는 하나의 기능 또는 문서 기능만 넣는다.
2. 구현 범위, 수락 기준, 실행한 테스트, 남은 미검증 항목을 진행 보고에 먼저 밝힌다.
3. 수락 기준을 통과하면 한글 커밋 메시지로 로컬 브랜치에 커밋한다.
4. 미통과·차단 상태에서는 커밋하지 않고 원인과 다음 검증을 기록한다.
5. 원격 저장소 푸시·PR 생성은 사용자가 별도로 요청한 경우에만 한다.

## 현재 누락·차단 상태

- **누락 없음**: 현재 웹 실행물, 설계, 테스트 계획, 조사 기록, 사용 중인 배경 자산의 출처 기록은 워크트리에 존재한다.
- **미검증 항목**: 실제 브라우저 시각 QA, 실제 30분 세션, 대표 플레이어 테스트, 최소 사양 성능 프로파일링.
- **외부 차단**: 자동화 환경은 로컬 `file://` 브라우저 탭을 재로드·검사하는 것을 보안 정책상 허용하지 않았다. 정적·모의 런타임 검증으로 대체했으며, 실제 브라우저 확인은 수동 테스트 계획에 남긴다.
