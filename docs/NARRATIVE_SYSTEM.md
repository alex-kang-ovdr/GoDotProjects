# 퀘스트·튜토리얼·이벤트·대화 UI

## 구현 범위

`Godot/scripts/narrative_data.gd`가 텍스트, 아이콘 코드, 선택지, 이벤트 거리와 튜토리얼 임계값의 단일 원본이다. 물리 밸런스(`physics_tuning.gd`)와 시각 수치(`visual_tuning.gd`)는 이 파일에 두지 않는다.

`DialogueOverlay`는 CanvasLayer 위의 비차단 대화 큐다. 대화가 표시된 상태에서도 Godot 2D 물리, 적 AI, 투사체, 추력 입력은 계속 실행된다. 선택지는 `1`, `2` 또는 클릭으로 선택하며, 선택지가 없는 안내는 `Enter` 또는 대화 패널 클릭으로 넘긴다.

## 현재 흐름

1. 출항 시 CONTROL TOWER가 `비행 절차 시작`과 `안내 건너뛰기`를 제시한다.
2. 절차 시작은 실제 속도 12 이상을 요구하고, 만족 시 전방에 튜토리얼 중립 부품을 생성한다.
3. 해당 부품을 좌클릭 회수하면 빈 연결 소켓 릴리스 안내로 전환한다.
4. 해당 부품을 유효 소켓에 장착하면 무게중심·RCS 안내와 함께 완료된다.
5. 첫 적대 함선 탐지/격파와 각 정거장 최초 접근, 정거장 정비·업그레이드가 대화 큐 이벤트를 추가한다. 보스 스폰 경로는 `boss_name`을 전달하면 중간/최종 보스 조우 대화를 같은 큐에 추가한다.

정거장 접근 이벤트는 620px, 실제 서비스는 220px 이내의 `E` 입력이다. 같은 정거장 접근 이벤트는 한 세션에 한 번만 추가된다.

## 검증 경계

`narrative` 자동 스위트는 데이터, 선택 액션, 대화 큐 전환을 검증한다. 실제 마우스 클릭 위치, 한글 폰트 가독성, 전투 중 대화 가독성은 RHI 수동 실행에서 확인해야 한다.
