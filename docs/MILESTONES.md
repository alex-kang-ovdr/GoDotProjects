# 10-Milestone Delivery Plan

각 마일스톤은 실행 가능한 상태와 하나의 검증 질문을 남긴다.

## 현재 상태 (2026-09-15)

1–10은 브랜치의 순차 커밋으로 구현됐다. 다만 “완료”는 코드·문서 전달 상태를 뜻하며, 재미·밸런스·최소 사양 성능의 플레이테스트 완료를 뜻하지 않는다. 세부 출처와 구현 차이는 [GDD](GDD.md) 및 [References](../References/CAPTAIN_FOREVER_RESEARCH.md)에 기록한다.

1. **Flight deck** — 무의존성 HTML Canvas 셸, 반응형 HUD, 출항·재시작 진입점을 만든다.
2. **Flight model** — 코어, 방향, 관성, 키보드 추진을 구현해 함선을 조종 가능하게 만든다.
3. **Ship assembly** — 격자형 모듈 데이터와 부품별 렌더링을 추가해 구성의 차이를 보이게 한다.
4. **Fire control** — 0.28초 쿨다운 레이저, 열 냉각, 원형 투사체 피격 판정, 모듈 체력을 추가했다. 첫 모듈 레이캐스트는 범위 밖이다.
5. **Hostile rigs** — 거리 유지·조준 AI와 웨이브별 추가 무기를 구현했다. AI는 플레이어와 완전히 동일한 조종 규칙이나 웨이브별 조준 정확도 변화는 사용하지 않는다.
6. **Break and drift** — 개별 모듈 파괴, 적 코어 사망 시 살아 있는 비코어 모듈의 잔해 분리, 화면 효과를 구현했다. 구조 연결 연쇄 파괴는 범위 밖이다.
7. **Salvage rig** — 클릭 회수, 연결점 탐색, 자동 스냅, 함선 능력치 재계산을 구현한다.
8. **Sector run** — 5웨이브 난이도 곡선, 휴식 시간, 승패 상태를 추가한다.
9. **Readable combat** — HUD·색 외 텍스트 라벨·회수 포인터·모션 감소·객체 상한을 구현했다. 저사양 프로파일링은 아직 없다.
10. **Release candidate** — 수동 테스트 체크리스트와 실행 문서를 작성했다. 밸런스 패스·브라우저 시각 QA·호스팅 배포는 아직 검증 또는 수행되지 않았다.
