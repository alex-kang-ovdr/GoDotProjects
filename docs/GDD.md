# Captain Salvage — Game Design Document

## 제품 정의

`Captain Salvage`는 브라우저에서 실행되는 탑다운 2D 모듈형 우주 전투 프로토타입이다. 플레이어는 취약한 지휘 코어를 조종하고, 적의 코어만 정밀하게 파괴하여 보존된 잔해를 자신의 함선에 덧붙인다. 이 문서는 조사에서 얻은 설계 원칙을 오리지널 규칙과 시각 언어로 재구성한 것이다. 원작의 코드, 이름, 아트, 음향, 레벨은 사용하지 않는다.

## 조사 기반과 해석

Captain Forever의 알려진 설계는 명령 모듈이 파괴되면 패배하며, 적 명령 모듈을 파괴한 뒤 남은 모듈을 노획하는 구조다. 모듈을 전투 중에도 부착할 수 있어 전투와 제작이 분리되지 않는다. [공식 위키](https://captainforever.wiki.gg/wiki/Captain_Forever)와 [PC Gamer의 분석](https://www.pcgamer.com/captain-forever-remix-review-early-access/)은 코어 보호·기동성·화력 사이의 긴장과 “강한 화력은 좋은 노획품도 부술 수 있다”는 역설을 핵심으로 설명한다. [Jay Is Games의 리뷰](https://games.jayisgames.com/review/captain-forever.php)는 불균형한 추진 배치가 조종을 망칠 수 있음을 지적한다.

본 프로토타입은 이 세 가지를 검증한다.

- 코어를 살리기 위해 장갑을 붙일수록 무거워지는 선택이 재미있는가.
- 적 코어를 노려야 부품을 보존한다는 목표가 정밀 사격을 유도하는가.
- 회수 클릭과 자동 스냅 부착이 전투의 흐름을 깨지 않는가.

## 플레이어 판타지와 세션

플레이어는 잔해 지대의 즉석 함장 겸 정비사다. 한 세션은 8–12분, 키보드와 마우스를 사용한다. 감정 곡선은 “작고 취약함 → 교전 중 즉흥적 해체 → 기묘하지만 강한 함선 완성 → 큰 적 앞에서 다시 위태로움”이다.

## 핵심 루프

1. 추진기로 접근하고 회전하며 적의 사격선을 피한다.
2. 외곽 모듈을 피하거나 제거해 적 지휘 코어의 노출을 만든다.
3. 코어를 파괴해 연결된 온전한 모듈을 잔해로 분리한다.
4. 가까운 잔해를 클릭해 빈 연결점에 자동 부착한다.
5. 화력·기동·내구의 새 균형으로 다음 위협을 고른다.

## 조작과 상태

- `W/S`: 전진/후진 추진, `A/D`: 회전, `Space`: 모든 레이저 발사, 클릭: 잔해 회수, `R`: 새 항해.
- 지휘 코어는 항상 존재해야 하며 체력이 0이면 즉시 패배한다.
- 부품은 코어 또는 연결된 부품에 인접한 격자에만 붙는다. 최대 부품 수는 18개다.
- 추진기는 배치 방향에 따라 선형 가속과 회전 토크를 만든다. 불균형한 함선은 조작하기 어렵지만, 자동 안정 보정으로 완전히 조종 불능이 되지는 않는다.
- 레이저는 사격선 위 첫 모듈에 피해를 준다. 부서진 일반 모듈은 사라지고, 적 코어가 먼저 파괴되면 살아 있는 연결 모듈은 회수 가능 잔해가 된다.

## 콘텐츠와 튜닝 값

- `armor`: 18 HP, 질량 1.8, 방어용.
- `thruster`: 14 HP, 질량 1.1, 힘 180. 한 개 이상이 있어야 기동이 좋다.
- `laser`: 12 HP, 질량 1.2, 0.34초마다 7 피해.
- `battery`: 16 HP, 질량 1.4, 보조 에너지로 연속 사격의 열을 낮춘다.
- 첫 실행은 최대 5웨이브, 웨이브마다 1–3척의 적이다. 무기와 체력은 플레이테스트 전 후보 값이다.

## AI와 난이도

적은 거리 260–430px을 유지하고 플레이어 코어를 조준한다. 웨이브가 오를수록 적 수와 모듈 수를 먼저 높이고, 조준 정확도는 마지막에만 높인다. 플레이어가 재조립 중일 때의 전멸 방지를 위해 다음 적 투입 전 5초의 숨 고르기 시간을 제공한다.

## 피드백·접근성·성능

- 코어는 분홍색, 아군 부품은 청록색, 적은 주황색, 회수 가능 잔해는 황색으로 표시한다.
- 화면 흔들림과 광량은 설정 없이도 최소화하고, 색만으로 상태를 전달하지 않는다.
- `aria-live` HUD와 키보드 중심 조작을 제공한다. 클릭 회수에는 큰 히트 영역을 둔다.
- 1280×720 기준 목표는 모듈 80개, 탄환 120개, 잔해 30개 이하와 60fps다. 상한 도달 시 오래된 탄환·효과부터 제거한다.

## 검증 기준

- 정상: 시작 → 이동 → 적 격파 → 부품 회수 → 다음 웨이브의 흐름이 가능하다.
- 실패: 플레이어 코어 파괴 시 입력과 적 생성이 멈추고 재시작이 가능하다.
- 엣지: 빈 연결점이 없거나 잔해가 멀면 회수되지 않는다. 코어에는 잔해를 부착할 수 없다.
- 관찰: 첫 플레이에서 코어의 중요성, 회수 클릭, 추진기 배치 효과를 설명 없이 이해하는지 기록한다.

## 범위 밖

멀티플레이, 영구 메타 진행, 스토리 캠페인, 절차 생성 은하, 사운드 자산과 원작의 고유 표현은 이번 웹 프로토타입 범위 밖이다.
