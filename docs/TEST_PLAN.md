# Release-Candidate Manual Test Plan

## 준비

최신 Chromium, Edge 또는 Firefox에서 `index.html`을 연다. 데스크톱 입력 검증은 1280×720에서, 반응형 레이아웃 검증은 390px 폭에서 수행한다. 브라우저 확대율은 100%로 둔다.

## 핵심 경로

1. **출항과 관성**: 출항 후 `W`를 1초 누르고 떼고, `A` 또는 `D`로 방향을 바꾼다. 함선이 방향 전환 직후에도 관성으로 이동하고 경계 밖으로 나가지 않아야 한다.
2. **전투**: `Space`를 길게 눌러 적 모듈과 코어에 피격 표시가 나는지 확인한다. HUD `HEAT`가 올라가고 사격을 쉬면 내려가야 한다.
3. **노획**: 적 코어를 파괴한다. 황금색 모듈이 떠오르는지, 가까운 부품을 클릭하면 플레이어 함선의 인접 빈 격자에 붙는지, `SALVAGE`와 `MASS`가 갱신되는지 확인한다.
4. **회복 불가 경로**: 멀리 있는 잔해를 클릭한다. 부착되지 않고 “가까이/연결점” 안내가 표시되어야 한다. 18개 모듈이면 추가 부착이 일어나지 않아야 한다.
5. **웨이브와 종료**: 적을 전부 제거한 뒤 5초간 회수한 다음 다음 구역이 시작되는지 확인한다. 5구역 종료 시 승리 오버레이, 플레이어 코어 0 시 패배 오버레이와 재출항 버튼이 보여야 한다.
6. **접근성·반응형**: `prefers-reduced-motion` 환경에서 전환 애니메이션이 최소화되는지, HUD의 핵심 수치가 색 없이 읽히는지, 좁은 화면에서 캔버스와 HUD가 겹치지 않는지 확인한다. 390px 검증은 레이아웃만 대상이며, 터치·게임패드 플레이는 현재 지원하지 않는다.

## 자동 확인

- `node --check game.js`가 성공해야 한다.
- 코드에 외부 런타임·네트워크 요청·빌드 단계가 없는지 정적 검토한다. 이 확인만으로 실제 브라우저 성능을 증명할 수는 없다.

## 미검증 항목

재미·난이도·저사양 60fps는 실제 대표 플레이어 및 최소 사양 기기에서 아직 검증되지 않았다. GDD의 수치는 첫 플레이테스트에서 한 변수씩 바꿔 측정할 후보값이다.
