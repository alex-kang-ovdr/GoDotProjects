# 코어 게임플레이 리뷰·피드백 루프

날짜: 2026-09-23. 브랜치: `captain-forever`. 비교 출처는 [벤치마크 아카이브](../References/CORE_GAMEPLAY_BENCHMARK_2026-09-23.md). 게임 디자인의 ‘확인된 사실 / 해석 / 테스트 결과’ 구분을 적용했다.

## 루프 1 — 결함 재현 → 구현 → 회귀

기준본에서 신규 테스트가 재현한 여섯 실패:

1. 다칸 파트의 질량이 앵커 한 셀에 몰림 → 실제 점유 셀 중심 가중 평균.
2. 다른 함선에서 회수한 파트의 UID 중복 → 장착 시 충돌 재발급.
3. 메시 재구축이 카메라·조명까지 삭제 → 메시/카메라/조명 수명 분리, 함선마다 독립 3D 월드.
4. `apply_force`에 CoM을 중복 차감 → Godot 원점 기준 위치 계약으로 수정.
5. 자동 항법 RCS 부호 반대 → 방향 교정, 각속도 감쇠 피드백·정렬 후 추진·접근 제동.
6. 자동 미니어뢰가 평화 NPC에 선제 공격 → 적대 상태만 자동 교전.

여섯 실패가 수정 후 모두 통과했다. 기존 `physics` 테스트도 잘못된 CoM 계약을 기대하고 있었으므로 공식 엔진 계약에 맞게 수정하고, 별도로 실제 비대칭 비행 검증을 추가했다. 성공시키기 위해 실제 비행 검사를 삭제하지 않았다.

## 루프 2 — 연결된 게임 흐름

- 대화·편집·P/ESC 일시정지 중 월드 물리, 발사, 임무 시계 정지. HUD 뒤 입력 차단.
- R 재시작 확인 대화, 사망 시 지속 안내·새 항해 버튼. 최종 보스 붕괴 완료 뒤 승리 화면.
- 잘못된 장착은 계속 들기, Q/우클릭/버튼 회전, ESC/버튼 취소. 무제한 원거리 회수 차단.
- Shift 재배치로 끊긴 파트도 중립으로 분리. 장착·재배치·손실마다 물리와 메시 갱신.
- 탄약고 반복 병합 후 계속 들기. 삭제 예정 중립 파트 재선택 차단.
- 질량·CoM·셀별 관성모멘트, 실제 점유 셀의 박스 충돌체 사용. 다칸 중립 파트도 크기·회전을 유지.
- 투사체 이동과 충돌을 같은 고정 스텝에서 처리. 궤적과 실제 파트 박스를 교차 판정해 빈 공간 피해·고속 관통 누락 방지.
- 유도탄 표적 추적, 미니어뢰 2초 후 가속, 정거장 피해·냉각·유도·사거리 보너스와 보급 적용.
- 기존 자유 항로의 정거장 3개·중간 보스 2개·최종 보스 진행을 연결. 신규 시나리오 그래프 구현과 별개다.

## 루프 3 — 물리 계측과 표시 확인

60Hz `flight-metrics`의 비대칭 장갑 추가 함선 결과:

- 2초 전진: 257.746px/s, 회전 편차 0rad.
- 2초 중립 제동: 5.141px/s에서 4.616px/s로 개선. `NEUTRAL_BRAKE_SPEED`를 180에서 120으로 변경한 결과이며 RCS 최대 힘은 변경하지 않았다.
- 90도 다른 방향의 500px 목적지: 8초 뒤 도착 잔차 48.443px, 속력 0.0133px/s, 자동 항법 종료. 도착 반경은 54px이고 순간이동/속도 강제 0이 아니다.

웹 시각 확인에서 시스템 한글 폰트 의존으로 글자가 네모로 나타났다. OFL 1.1 나눔고딕 원본 약 2.05MB와 라이선스를 포함해 해결했다. 방어막 라벨/박스 겹침, 알림/무기 카드 겹침도 조정했다. 배경이 부모의 장착 후보·항법 표식을 덮는 렌더 순서를 고치고, 긴 항해에서 배경 별이 사라지지 않도록 카메라 기준 반복 시차 배경을 적용했다.

## 입력·시스템 점검 범위

- WASD: 추력/역추력/RCS, 수동 입력이 자동 항법 해제. 기초 물리 테스트와 비행 계측 통과.
- Space/주무기 카드 유지: 반복 발사. F/우클릭 표적: 미사일. G: 그래플 연결/해제. 무기 없음·탄약·쿨다운 상태 안내.
- 클릭/드래그/터치: 표적 선택, 회수·배치, 빈 공간 자동 항법. 터치가 합성한 마우스 이벤트는 월드에서 중복 처리하지 않는다.
- Shift 재배치, Q 회전, ESC 회수 취소. 터치 회전·취소 버튼 제공. 터치의 장착 파트 재배치 진입은 후속 UX 과제다.
- 휠/+/- 줌: 약 0.333–1.5. 우클릭 드래그 수평 시점 회전. 직교 투영 유지.
- P/ESC 정지, H 도움말, E 정거장, N 현재 자유 항로 관문, R 새 항해. `--edit-mode` 편집·테스트 파일럿 전환.
- NPC 상태: 기존 66ms 로밍·선제공격·반격·대화 테스트 유지. 평화 NPC 자동 공격을 제거하고 멀어진 일반 NPC를 정리한다.
- 충돌/분해: 셀 박스 충돌, 연결 분리, 붕괴 중 무충돌 유예·관성·기존 운동량 유지. 한글 폰트 및 직교 메시 카메라 수명 검증 추가.

## 검증 방법

공용 프레임워크의 9개 suite: runtime, physics, narrative, npc-ai, grapple, target-navigation, developer-mode, core-gameplay, flight-metrics. `Run-CaptainSalvage-Tests.bat`의 8·9번으로 새 테스트를 실행한다. 7과 E의 기존 계약은 유지한다.

PC/Web release export를 사용하며 실제 화면에서 한글·대화·일시정지·회수 표시를 확인한다. 헤드리스 통과만으로 렌더링·터치 UX 합격을 대신하지 않는다. 로그는 `Saved/AutomationTestResults`에 보관하며 빌드와 로그는 Git 제외다.

이번 실행 증거: PC release에서 초기 함선·한글 HUD·입장 대화를 확인했다. 웹 release에서는 한글 표시 → 안내 건너뛰기 → P 정지 → 중립 BEAM-3 회수 → Q 회전 → 유효 앵커 클릭 장착 → 3D 메시·질량·방어막 용량 변경 → P 정지를 직접 확인했다. 장착 뒤 질량은 17.5에서 22.3, 방어막 가능 층은 1에서 0으로 바뀌어 질량 제한과 일치했다. Android 터치 입력 실기기 확인은 이 기록에 포함하지 않는다.

## 미완료·후속 우선순위

사용자 후속 요구로 [모듈 확인 치트](MODULE_INSPECTION_MODE.md)를 추가했다. 기본 무텍스처+한글 역할명, HUD 디자인 토글, 화면 수평 텍스트와 전체 이름·스펙 검사 카드를 제공한다. 중립·배치 중 부품도 식별한다. 런타임 수치 불변, 기존/새 NPC 적용, 22종 매핑, 회전 상쇄, 상세 카드 검사를 추가해 통과했다. 최종 PC/Web export와 9개 suite를 재실행했고, PC 한글 모듈 렌더링 및 웹 양방향 토글·중립 부품 상세 카드까지 확인했다.

1. [시나리오 그래프·FTL·4종 목표](SCENARIO_FTL_GDD.md): 이번에는 설계 확정, 런타임 미구현. 기존 자유 항로 6단계 테스트는 이를 대체하지 않는다.
2. CSV `weapon_type`·파트별 무기 스펙과 모든 발사 경로의 완전한 데이터 구동, 개별 무기 쿨다운·사거리 피드백. 현재 일부 무기 규칙은 `Balance.WEAPONS`와 kind 기반이다.
3. 장기 잔해/투사체 상한과 적 강도 산정. 현재 회수 횟수 기준에는 재회수로 강도가 상승하는 편향이 있다.
4. 그래플의 고속 탄환 궤적 교차·아군 사격 정책, 파트별 자세 제어의 극단적 비대칭 사례, 이동하는 표적과 투사체의 상대 스윕 검증.
5. 삼각기둥 전용 3D 메시, 부위 표적 UI, 터치 재배치/핀치 줌/작은 화면. 현재 삼각 파트 물리·3D는 셀 박스 근사다.
6. 중·대형 운석의 충격량 피해, 개별 행성계 환경·재료 보상, 사운드 피드백.
7. 25–35분 시나리오 실플레이, Android 실기기, 저사양 프레임·메모리 측정, 멀티플레이 권한/정지/FTL 동기화.

이번 변경은 코어 결함 수정과 회귀 기준 강화다. 전체 게임 100% 완성, 웹 기준본 100% 호환, 실제 30분 완주, 최소 기기 성능을 검증했다고 주장하지 않는다.
