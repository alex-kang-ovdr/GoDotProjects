# 파트 색상 등급 · 디자인 테마 분류

`Godot/data/part_tuning.csv`가 파트의 플레이어 표시명, 색상 등급, 디자인 테마를 함께 관리하는 단일 원본(SSOT)이다. 수치 밸런스는 변경하지 않으며, 이 분류는 장착 UI, 전리품 표시, 개발자 편집 모드 검색·필터, 3D 복셀 재질 선택에 공통으로 쓰인다.

## 식별 규칙

`themed_name`은 `<테마 코드>-<등급 코드>-<영문 파트 이름>` 형식으로 쓴다. 코드 식별자는 저장·네트워크·다국어 표시명이 아닌, 데이터와 아트 에셋을 연결하는 안정적인 키다.

| 테마 | CSV 값 | 코드 | 디자인 방향 |
| --- | --- | --- | --- |
| 테란·인간 | `terran_human` | `TH` | 산업용 금속, 노출된 볼트·패널, 실용적 추진·탄도 장비 |
| 저그·생물 | `zerg_biological` | `ZG` | 갑각, 유기적 분절, 비대칭 실루엣 |
| 프로토스·하이테크 | `protoss_hitec` | `PR` | 매끈한 에너지 도관, 발광 패널, 정밀 고기술 장비 |

| 등급 | CSV 값 | 코드 | 색상 | 사용 의도 |
| --- | --- | --- | --- | --- |
| 일반 | `common` | `CMN` | `gray` | 표준 제작품 |
| 고급 | `uncommon` | `UNC` | `green` | 역할이 뚜렷한 개선형 |
| 희귀 | `rare` | `RAR` | `blue` | 전문 장비·고효율 구조 |
| 영웅 | `epic` | `EPC` | `purple` | 희소한 고성능 장비 |
| 전설 | `legendary` | `LEG` | `gold` | 빌드의 중심이 되는 고유 장비 |

예: `PR-EPC-SHIELD-GENERATOR`는 프로토스·하이테크 테마의 영웅(보라) 방어막 생성기다.

## 현재 분류와 표현 범위

초기 함선의 범용 구조·추진·탄도 부품은 테란·인간, 에너지·유도·방어막 계열은 프로토스·하이테크, 웨지 계열은 저그·생물 테마의 기준 샘플로 분류했다. 현재 4×4 공용 복셀 아틀라스에는 테마별 전용 텍스처가 아직 모두 존재하지 않으므로, 3D 렌더는 CSV 테마에 맞춰 재질 틴트·금속도·발광을 달리 표현한다. 전용 아틀라스를 추가할 때에는 `design_theme`을 바꾸지 않고 해당 테마의 텍스처 슬롯만 확장한다.

색상 등급은 외곽선·발광의 색상과 개발자 모드 미리보기에 적용한다. 색상 자체가 공격력·내구도·드롭 확률을 자동으로 변경하지 않는다. 수치 변경은 기존 `hull`, `mass`, `power`, 추진력, 무기 필드에서 명시적으로 조정한다.

## 새 파트 추가 체크

1. `MODULES`에 구조, 점유 격자, 구동기 정의를 추가한다.
2. CSV에 `grade`, `grade_color`, `design_theme`, `theme_code`, `themed_name`을 모두 채운다.
3. 테마 코드와 등급 코드는 표의 고정값만 쓴다.
4. 복셀 텍스처 타일 또는 향후 테마 전용 타일을 `VisualTuning`에 등록한다.
5. 개발자 모드에서 테마·등급 필터와 미리보기를 확인하고 PC·Web 자동화 테스트를 통과시킨다.
