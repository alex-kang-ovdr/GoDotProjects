# PC · Android · 웹 배포 타겟

## 목표와 경계

`Captain Salvage`는 하나의 무의존성 HTML Canvas 빌드를 세 곳에 배포한다. PC는 현대 데스크톱 브라우저, Android는 현대 Chrome의 가로 화면, 웹은 HTTPS 정적 호스팅이다. 같은 코드와 저장 데이터를 쓰는 PWA가 이번 배포 단위의 결과물이다.

네이티브 Windows 실행 파일, 서명된 Android APK/AAB, Google Play 등록, 결제·로그인·클라우드 저장은 이 단위에 포함하지 않는다. 이들은 별도 서명 키, 스토어 계정, 개인정보·등급·자산 심사가 필요하다. PWA가 실기기 검증을 통과한 뒤에만 래퍼 또는 스토어 패키징을 검토한다.

## 조작과 화면 규칙

- PC: 키보드 `W/A/S/D`, `Space`, `E`, `R`, 마우스 클릭·휠, `+`/`-`를 기본 입력으로 유지한다. 우클릭 드래그는 수평 시점을 회전하고, 짧은 우클릭은 미사일 표적을 지정한다. 권장 화면은 1280×720 이상이며, 16:9 캔버스를 브라우저가 비율대로 축소한다.
- Android: 가로 화면을 권장한다. 화면 좌측에는 전진·후진·회전, 우측에는 사격·미사일·정거장·이동 모드·줌 버튼을 표시한다. 버튼을 누르는 동안만 동일한 가상 키 입력이 유지되어 PC와 물리·전투 규칙을 공유한다.
- Android 부품 재장착: `MOVE`를 누른 뒤 장착 모듈을 탭해 들어 올리고, 강조된 빈 소켓을 다시 탭한다. 일반 탭은 필드 부품 회수 또는 운반 중인 부품 배치다.
- 카메라는 세 타겟 모두 0.7×~1.5× 기울임 없는 직교 Top-View를 유지한다. PC는 우클릭 드래그로 수평 방향만 회전하고, Android는 핀치·회전을 아직 사용하지 않으며 화면 버튼으로만 줌을 바꾼다.

## 웹 배포 계약

- `index.html`을 HTTPS 정적 호스트의 배포 루트에 둔다. 상대 경로를 사용하므로 하위 경로 배포도 가능하다.
- `manifest.webmanifest`, SVG 아이콘, `sw.js`는 설치형 PWA와 오프라인 앱 셸을 제공한다. 서비스 워커는 HTTPS 또는 `localhost`에서만 등록한다. `file://` 직접 열기에서는 게임은 실행되지만 설치·오프라인 캐시는 활성화되지 않는다.
- 배포 시 응답 MIME 형식은 HTML, CSS, JavaScript, JSON/manifest, SVG 및 PNG가 정상 제공되어야 하며, 서비스 워커 파일은 페이지와 같은 오리진·스코프에 있어야 한다.
- 캐시 이름을 바꾸면 다음 배포에서 이전 앱 셸을 정리한다. 게임 코드나 핵심 자산을 변경할 때마다 `sw.js`의 `CACHE_NAME` 버전을 올린다.

## 성능 가설과 폴백

Android의 저사양 적합성은 아직 증명되지 않았다. 현재 고정 1280×720 Canvas, 적 5, 보스 1, 투사체 160, 부유 부품 60, 운석 48, 파티클 220 예산을 동일하게 적용한다. 최소 타겟에서 프레임이 무너지면 게임 규칙을 바꾸지 않고 파티클, 운석 수, 부유 부품 상호 충돌, 절차 별 밀도, 일반 적 상한 순으로 낮춘다.

PC/Android 모두에서 대표 전투·운석·보스 구간의 1% low FPS, 평균 FPS, 긴 프레임 수, 배터리·발열 체감을 기록해야 한다. 수집 전에는 60fps, 오프라인 설치, 터치 조작성 어느 것도 완료됐다고 주장하지 않는다.

## 수락과 수동 검증

1. PC Chromium 또는 Edge에서 키보드·마우스 조작, 직교 줌, 우클릭 표적 미사일/드래그 회전 구분, 회수·재장착·정거장 사용이 유지된다.
2. Android Chrome 가로 화면에서 가상 버튼을 누르는 동안만 비행·사격·미사일 발사가 지속되고 손을 떼면 즉시 멈춘다. `MOVE` 재장착, 줌 버튼, 일반 탭 회수가 함께 동작한다.
3. HTTPS 배포에서 Manifest가 인식되고 첫 온라인 실행 뒤 같은 버전의 앱 셸이 오프라인에서도 열린다. 배포 직후와 캐시 갱신 뒤를 각각 확인한다.
4. 실제 Android 최소 타겟 기기에서 10분 전투·운석 지대·보스 구간을 기록한다. 성능 기준은 측정 후 확정한다.

이 문서의 PWA 구성·정적 파일 존재는 자동 확인할 수 있지만, 실제 설치·오프라인·터치·성능은 기기와 HTTPS 호스트가 있어야 검증할 수 있다.
