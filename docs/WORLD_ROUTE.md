# 항로 모드와 구현 상태

갱신: 2026-09-23. 최신 시나리오 요구는 [SCENARIO_FTL_GDD](SCENARIO_FTL_GDD.md)가 우선한다.

## 시나리오 — 신규 설계

월드맵에서 연결된 행성계를 선택해 FTL 한 번마다 한 행성계로 이동한다. 갈림길은 있지만 최종 목표로 이어진다. 섬멸·탈출·보호·아이템 획득 임무, AI 패턴·캐릭터·대화를 행성계별로 구성한다. 전투 카메라를 자동 횡스크롤시키는 방식은 아니다.

아직 설계 단계다. 그래프 월드맵과 임무 컨트롤러는 다음 구현 대상이며, 거대한 공간의 비행 거리로 30분을 만드는 이전 가설을 시나리오에 적용하지 않는다.

## 자유 항로 프로토타입 — 현재 실행 코드

좌표 SSOT는 `balance.gd`의 `WORLD`. 시작 `(0, 0)`에서 아래 여섯 관문을 순서대로 검증한다. N/다음 관문 버튼은 현재 관문으로 자동 항법한다. 시나리오 FTL 버튼이 아니다.

1. KEPLER `(24000, 9000)` — E 정비. 코어 최대 HP +30, 수리·탄약 보충.
2. RIFT BREAKER `(49000, 22000)` — 1800px 진입 시 tier 4 보스 생성, 격파 후 진행.
3. LYRA `(77000, 37000)` — 피해 +2, 유도 회전속도 +1rad/s, 미사일 수명/미니어뢰 비행거리 1.25배. 수리·보급.
4. CROWN EATER `(104000, 49000)` — tier 7 중간 보스.
5. PERSEUS `(130000, 64000)` — 냉각 +12/s, 유효 방어막 +1층, 복구 대기 -1초. 수리·보급.
6. VOID WARDEN `(157000, 73000)` — tier 10 최종 보스. 붕괴 뒤 완료 대화·재시작.

업그레이드는 정거장별 한 번만 지급한다. 재방문은 수리·보급이다. 현재 코드에서는 정거장 서비스가 다음 관문을 열기 때문에 ‘정거장을 건너뛰어도 진행 가능’하다는 이전 문구를 제거했다.

일반 NPC는 3척 미만일 때 8초 간격, 주변 620px에서 생성한다. 레벨은 회수 횟수로 상승한다. 5000px 밖 비보스·비선택 NPC를 정리해 조우가 영구 중단되는 것을 막는다. 장비 가치 기반 난이도와 장기 오브젝트 수 제한은 후속 과제다.

운석은 시작 부근 12개 정적 충돌체다. 이전 문서의 ‘6개 벨트 지연 생성’, ‘중·대형 운석 충격량 피해’, ‘보스 보상 파트 3개’는 현재 코드에 없어 구현 완료 목록에서 제외했다. 향후 시나리오 행성계 환경으로 재설계한다.

## 검증과 제한

- `core-gameplay`: 관문으로 위치를 이동시켜 정비→보스 생성→격파→완료 상태를 검증한다. 30분 완주가 아니다.
- `flight-metrics`: 비대칭 질량 2초 가속·2초 제동·90도 자동 항법을 실제 Godot 물리 프레임으로 계측한다.
- 시나리오 25–35분은 방문 노드 수·임무 체류 시간의 미검증 목표다.
- 장시간 소크, Android 실기기, 멀티플레이 임무 동기화는 미검증이다.
