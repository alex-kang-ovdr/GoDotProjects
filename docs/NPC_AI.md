# NPC 우주선 AI

## 의도와 상태

일반 NPC는 대부분 `roaming` 상태로 스폰 지점 반경 460px을 순찰한다. 전투를 자동으로 강제하지 않아 회수·탐색 루프가 유지되며, 플레이어의 공격이 명확한 적대 전환점이 된다.

- `roamer`: 로밍하다가 플레이어 투사체에 피격되면 공격한다.
- `aggressive`: 로밍하다가 760px 레이더 범위 진입 또는 피격 시 공격한다.
- `contact_quest`: 560px 대화 범위 진입 시 회수 의뢰 대화를 요청한다.
- `contact_warning`: 560px 대화 범위 진입 시 사격 통제 구역 경고를 요청한다.

공격 NPC는 620px 무기 사거리에서만 발사한다. 경고 NPC는 사용자가 명령을 확인한 뒤 5초 동안 사거리 밖으로 나가도록 요구하며, 머무르면 공격으로 전환한다. 어느 상태든 플레이어의 실제 투사체가 명중하면 즉시 공격 상태가 우선한다.

퀘스트 NPC의 의뢰 수락은 표식 `BLOCK` 중립 부품을 생성한다. 이를 회수해 유효 소켓에 장착하면 완료 대화가 표시된다. 대화는 비차단이라 물리·AI·투사체는 계속 실행된다.

## 조정과 검증

프로필 비율, 레이더/무기/대화 거리, 로밍 반경, 이탈 유예는 [balance.gd](../Godot/scripts/balance.gd)의 `NPC_AI`만 수정한다. 현재 비율은 로밍 70%, 레이더 선제 공격 20%, 대화형 10%다. 이는 구현용 초기값이며 플레이테스트로 밸런스 검증된 값은 아니다.

`npc-ai` 자동 스위트는 상태 전환을, `physics`는 우회전 RCS의 실제 각속도 부호를 검증한다. 다수 NPC의 경로 품질·대화 빈도·난이도는 패키지 빌드 플레이테스트가 필요하다.
