# Reference Archive

이 폴더는 `Captain Salvage`의 기획 판단에 사용한 웹 조사 기록을 보관한다. 외부 페이지의 전문, 이미지, 영상, 코드 및 상표 자산은 저장하지 않는다. 각 기록에는 원문 URL, 열람일, 출처 성격, 프로젝트에 적용한 해석을 남긴다.

## 보관 원칙

- 원작의 사실은 1차 출처 또는 공식 라이선스 제품 설명으로 우선 확인한다.
- 비평과 커뮤니티 위키는 플레이 감각과 세부 규칙을 보강하는 2차 출처로만 사용한다.
- `Captain Salvage`의 수치와 규칙은 원작의 사본이 아닌 독자적인 프로토타입 제안이다.
- 인용은 짧은 식별용 표현만 사용하고, 재현 가능한 근거는 원문 링크로 제공한다.
