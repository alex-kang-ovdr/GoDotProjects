# CC0 Space Texture Set

- `bg_1_1_cc0.png` — Sauer2, [Starfield background](https://opengameart.org/content/starfield-background), CC0. 수평 타일 가능 별밭.
- `space001_cc0.png`부터 `space005_cc0.png` — Soluna Software, [Space backgrounds with stars and nubular](https://opengameart.org/content/space-backgrounds-with-stars-and-nubular), CC0. 1600×1600 별·성운 배경.
