# RimWorld 레퍼런스 노트

- 조사일: 2026-11-27
- 기준 자료: 변방의 기록 4.0 웹 플레이어블의 기존 역기획 및 독자 구현 문서
- 출처: [RimWorld 공식 사이트](https://rimworldgame.com/)
- 확인 버전/플랫폼: 참고 대상은 RimWorld; 이 노트에서 원작 버전/플랫폼 비교 검증은 하지 않음.

## 확인된 사실과 프로젝트 해석

**프로젝트 자료에서 확인한 사실:** `docs/web-v4`의 원본 설명은 RimWorld 역기획에서 정착지 생존·자율 작업·공간/분업 관리라는 관계를 참고했다고 밝힌다. 변방의 기록은 그와 별개인 수치·시간·규칙으로 구성했고, 원작 코드·이미지·음악을 사용하지 않았다고 명시한다. 본 Godot 이관에서도 Node 시뮬레이션 규칙과 네이티브 UI를 분리하는 것이 작업 범위다.

**해석/적용:** 이 장르의 화면은 타일 맵의 공간 정보와 주민별 작업·상태를 함께 읽게 해야 한다. UI 재설계 시 맵 조작을 중심으로 두되 작업 우선순위, 일정, 재고, 위기 경보를 빠르게 확인할 수 있는 계층을 마련한다. 이는 프로젝트 적용 제안이며 원작의 UI 세부를 이 문서가 검증했다는 뜻은 아니다.

## 적용 및 검증 상태

- 적용 대상: `FrontierColonyGodot` 네이티브 UI 설계.
- 상태: 아직 구현 전. 상세 기존 게임 규칙은 [웹 v4 기준 README](../../FrontierColonyGodot/docs/web-v4/README.md) 및 핸드오프에 기록.
- 에셋: 수집·추출·재배포하지 않음. 참고용 분석과 프로젝트에 직접 사용할 수 있는 자산을 구분함.
