# 코어 게임플레이 벤치마크

열람일: 2026-09-23. 공식 설명·매뉴얼을 읽은 조사이며, 세 게임의 이번 실플레이 비교 결과는 아니다. 원본 게임 에셋과 전문은 복제하지 않는다.

## 1. Cosmoteer — 설계의 결과가 전투에 보이게

출처: [공식 홈페이지](https://cosmoteer.net/), 개발사 Walternate Realities.

확인 사실: 무기·엔진 등 모듈 배치가 성능에 영향을 준다. 물리 기반 교전에서 모듈별 파괴와 선체 분리가 가능하며 무기·방어막·동력 계통을 노릴 수 있다. 계약, 전리품, 업그레이드와 함선 설계를 결합한다.

프로젝트 해석: 조립 결과와 질량·무게중심·추력·충돌·시각 표시가 반드시 일치해야 한다. 외곽 바운드 안의 빈 공간을 맞췄다고 코어에 피해를 전가하면 부위 전투의 의미가 사라진다. 승무원 운송 시뮬레이션은 현재 경량 게임의 필수 범위로 가져오지 않는다.

검증 항목: 다칸 질량중심, 고유 파트 ID, 연결 분리, 빈 셀 피격, 고속 탄환 최초 충돌, 재조립 직후 메시 갱신.

## 2. Captain Forever — 회수·재조립·전투의 짧은 순환

출처: [공식 비행 매뉴얼](https://www.captainforever.com/helpcf.php), Farbs.

확인 사실: WASD 추진·회전, 클릭/드래그 모듈 이동과 릴리스 장착, 연결 상위 모듈을 떼면 하위도 분리되는 규칙, 발사 버튼 유지 시 연사, 휠 줌과 P 정지 기능을 설명한다. 전투 선택·후퇴·고급 부품 회수도 안내한다.

프로젝트 해석: 클릭 한 번으로 회수하고 다음 클릭 또는 드래그 릴리스로 장착하는 접근성을 유지한다. 실패한 장착은 파트를 없애지 않고 계속 들게 한다. Q/우클릭 회전과 ESC 취소를 제공한다. 평화 NPC를 자동 무기가 먼저 공격하지 않게 하여 전투 선택권을 보장한다. 원작의 Q/E 횡추진·R/F 줌 키는 현재 프로젝트와 다르므로 동일 조작이라고 주장하지 않는다.

검증 항목: 회수 거리, 유효 후보, 연속 병합, 취소, 분리 연결성, 터치·마우스 중복 입력, 수동 입력의 자동 항법 해제.

## 3. FTL — 판단을 위한 정지, 사건과 선택의 항해

출처: [개발사·배급사 Subset Games의 공식 Steam 제품 설명](https://store.steampowered.com/app/212680/FTL_Faster_Than_Light/). 공식 웹 페이지는 열람 시 접근 오류가 있어 이 1차 제품 설명으로 대체했다.

확인 사실: 전력·무기·승무원 명령, 전투 중 일시정지, 텍스트 사건과 선택지, 무작위 은하와 실패 위험을 설명한다.

프로젝트 해석: 대화가 뜬 뒤에도 뒤에서 공격받는 불공정을 제거한다. 임무·선택·정비·다음 목적지 정보를 분명하게 제시한다. 2026-09-23 사용자 확정 요구인 ‘월드맵 갈림길에서 FTL 경로를 선택하고 한 번에 한 행성계 이동’은 아래 별도 GDD의 독자 설계다. 이 자료만으로 FTL의 세부 점프 수치나 맵 생성 규칙까지 검증했다고 보지 않는다.

검증 항목: 대화/일시정지 상태 입력 차단, 시계 정지, 분기 후 목적지 도달 보장, 임무 실패 안내, 보상 중복 방지.

## 기술 근거

[Godot RigidBody2D 공식 문서](https://docs.godotengine.org/en/stable/classes/class_rigidbody2d.html): `apply_force`의 위치는 바디 원점에 대한 글로벌 방향 오프셋이다. 호출 전에 CoM을 차감하면 엔진의 토크 계산과 중복된다. 질량은 파트 합, CoM은 셀 중심 가중 평균, 관성은 각 셀의 자체 관성과 평행축 항으로 계산한다.

## 적용 범위

- 이번 코드 변경: 조작·조립·물리·전투·HUD·기존 자유 항로의 결함 수정.
- 신규 시나리오 모드: [월드맵·FTL 시나리오 GDD](../Docs/SCENARIO_FTL_GDD.md)에 확정 요구와 구현 게이트를 분리해 기록.
- 성능·재미·30분 완주 평가는 짧은 회귀 테스트만으로 통과 처리하지 않는다.
