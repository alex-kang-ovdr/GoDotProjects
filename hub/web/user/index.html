기록과 이용 지표

게임을 시작하면 게스트 세션을 만들고 진행을 서버에 저장합니다. Google 로그인을 이용할 수 있다면 게스트 기록을 계정에 연결할 수 있습니다.

게임 카드가 화면에 보인 시간, 클릭, 게임 로딩과 결과, 실제 플레이 시간을 수집해 게임 품질과 재방문을 확인합니다. 다른 탭으로 이동하거나 일시 정지한 시간은 플레이 시간에서 제외합니다.

서버 연결이 끊기면 진행을 현재 탭에 임시 저장합니다. 임시 기록은 해당 계정에서만 볼 수 있고 로그아웃하면 정리됩니다. 로컬에서 시작한 진행은 저장 기록 화면에서 직접 서버에 연결할 수 있습니다.
