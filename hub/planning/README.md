# 포함 기획서의 기준

이 폴더의 PDF와 HTML은 28장으로 작성한 기존 제품 기획 기준선이다. 제품 목표와 0.1 당시의 구현·검증 현황을 포함하므로 현재 0.2의 남은 작업 목록으로 해석하지 않는다.

현재 구현은 상위 `README.md`, `docs/POC_COMPLETION.md`, `docs/POC_API_CONTRACT.md`, `docs/POC_GAMES.md`를 기준으로 한다. 이번 소스의 검증 증거는 `reports/acceptance.html`과 `docs/VALIDATION_STATUS.md`에 있다.

0.2에서 추가한 주요 기능은 저장 충돌 복구·보관 슬롯/백업 복원·슬롯 정리, 실제/QA 지표 분리, KST 기간/게임별 관리자 필터, SQLite 데이터 복원, 통합 수용 검사다. 원 기획 PDF는 이 구현 작업에서 재작성하지 않았다.
