PLAYHUB · WINDOWS 배포

PlayHub를 시작하세요

Node 24 런타임, SQLite, 플랫폼 코드와 게임이 포함된 단일 실행 파일입니다. 처음 실행할 때 기존 Rebex Tiny Web Server를 연결합니다.

1. 설치하고 실행하기

  1. ZIP을 Windows 10 또는 11 x64 PC에 풉니다.
  2. 이미 보유한 RebexTinyWebServer.exe를 PlayHub.exe 옆에 두거나, 실행 시 파일 선택 창에서 선택합니다. Rebex 실행 파일은 ZIP에 포함되지 않습니다. 공식 제품 페이지와 공식 EULA를 확인하세요. EULA는 다른 앱의 런타임 구성 요소로 재배포할 때 Rebex의 명시적 허가를 요구합니다.
  3. Run_PlayHub.cmd 또는 PlayHub.exe를 실행하고 콘솔에 PlayHub 0.3 is running.이 표시될 때까지 기다립니다.
  4. 최초 관리자 비밀번호를 콘솔에서 확인해 안전한 곳에 보관하세요. 분실하면 종료 후 PlayHub.exe --reset-admin-password를 명시적으로 실행해 새 비밀번호를 발급합니다.

PlayHub 실행에는 Windows PowerShell 5.1이 필요합니다. 기존 Rebex 실행 파일에는 .NET Framework 4.6 이상이 필요합니다. Node.js, npm, SQL 데이터베이스, IIS를 별도로 설치할 필요는 없습니다.

2. 주소와 포트

서비스기본 포트접속
사용자 사이트8080LAN 가능
관리자 사이트8081이 PC에서만
사용자 API8090LAN 가능
관리자 API8091이 PC에서만

포트는 구성에 저장된 값으로 고정되며 사용자 지정값도 유지됩니다. 충돌 시 포트와 PID가 표시됩니다. PlayHub로 확인된 프로세스만 Y로 종료한 뒤 같은 포트로 재시도할 수 있습니다. N 또는 Enter는 실행을 중단합니다. 다른 프로그램은 자동 종료하지 않고 대체 포트도 선택하지 않습니다. 다른 프로그램이 점유했다면 직접 종료하거나 설정을 변경한 뒤 재실행하세요.

콘솔에서 U는 사용자 사이트, A는 관리자 사이트, Q는 종료입니다. 관리자 서비스는 loopback 전용입니다. 다른 PC에서 사용자 사이트를 열려면 해당 PC의 LAN 주소와 사용자 포트를 사용하고 필요한 LAN 방화벽 허용을 직접 설정하세요. 외부 공개, 공유기 포트 포워딩, 방화벽 변경은 자동 실행하지 않습니다.

PlayForge 연결

PlayHub 상단의 PlayForge 링크는 같은 주소의 /PlayForge/를 새 탭으로 엽니다. 서버에 PlayForge ZIP을 풀고 그 폴더의 웹 진입점이 이 URL에서 제공되도록 정적 경로나 리버스 프록시를 설정하세요. 작업 폴더 GamePlayHub/PlayForge/에 압축을 푼 뒤 서버 URL 연결도 구성해야 합니다.

3. 데이터와 커뮤니티

사용자 데이터는 %LOCALAPPDATA%\PlayHub 아래에 저장됩니다. 같은 PC에서 재실행하거나 ZIP을 업데이트해도 유지됩니다. 다른 PC 또는 새 Windows 계정에는 이전 사용자의 저장 데이터나 로그인 정보가 자동으로 전달되지 않습니다.

게임 21종과 한국어, 영어, 일본어, 중국어 간체, 프랑스어, 스페인어, 브라질 포르투갈어, 힌디어 UI를 제공합니다. 게임 상세 화면에서 댓글과 개선 제안을 작성하고, 공감하거나 신고할 수 있습니다. 관리자는 제안 상태를 접수, 반영 예정, 반영 완료, 보류로 관리합니다. 작성자가 입력한 내용은 자동 번역하지 않습니다.

4. 데이터와 로그를 별도로 옮기기

ZIP에 포함된 Export_PlayHub_Data.cmd, Import_PlayHub_Data.cmd, Export_PlayHub_Logs.cmd, Import_PlayHub_Logs.cmd를 실행하면 파일 선택 창에서 원본·대상 위치를 고릅니다. 도구는 tools/Transfer_PlayHub.ps1를 사용합니다.

  • 데이터 내보내기: 먼저 PlayHub를 정상 종료하세요. 도구가 서버를 중지하지만 프로세스를 강제 종료하지는 않습니다. 데이터 ZIP에는 private/config, private/data(계정·저장·찜·커뮤니티·SQLite 분석/감사 데이터)와 사용자 지정 게임 변경 내용이 담깁니다.
  • 데이터 가져오기: 기존 데이터를 바꾸려면 확인 질문에 Y로 응답해야 합니다. 현재 데이터는 날짜가 붙은 백업으로 보존하고 새 PC의 dataDir을 설정합니다. 브라우저 쿠키는 이전되지 않으므로 등록 계정은 다시 로그인하세요. 게스트 기록에 계속 접근하려면 이동 전에 계정을 연결해 기록을 병합하세요.
  • 데이터 ZIP 보호: ZIP은 암호화되지 않으며 관리자 비밀번호 해시와 OAuth 설정이 들어 있습니다. 공개 공유를 피하고 신뢰할 수 있는 대상에만 안전하게 전달하세요.
  • 로그 내보내기: 보고서, 로그, 임시 파일, 캐시, 생성된 사이트와 앱 캐시를 담습니다. 데이터베이스, 비공개 설정, Rebex 실행 파일과 인증서는 제외하지만 IP 주소나 이용자 입력 문구가 포함될 수 있으니 공유 전에 확인하세요.
  • 로그 가져오기: ZIP은 비어 있는 새 폴더에만 풀며 활성 인스턴스의 파일을 바꾸지 않습니다.

5. 검증 상태와 ZIP 구성

PlayHub Portable은 Windows 로컬/LAN 사용을 위한 PoC이며 인터넷 공개용 프로덕션 서버로 제공하지 않습니다.

이전 애플리케이션의 Windows EXE 패키지 검사·자체 검사와 HTTP 검증은 54개 통과, 3개 건너뜀입니다. 이전 소스 브라우저에서는 21개 게임과 커뮤니티 UI 검증이 통과했습니다.
배포 대상 PC 확인 필요
최종 ZIP의 Rebex 설치·LAN 접속 및 새 데이터/로그 이전 명령은 아직 실행 검증하지 않았습니다.

ZIP에는 PlayHub.exe, licenses/Node-LICENSE.txt, licenses/PORTABLE-NOTICES.txt, 이 안내 파일, SHA256SUMS.txt, PACKAGE_MANIFEST.json이 포함됩니다. Run_PlayHub.cmd가 포함됩니다. 소스 폴더와 검증 보고서는 배포 ZIP에 넣지 않습니다. 동봉된 SHA-256 목록으로 파일을 확인할 수 있습니다.

PlayHub 배포 안내 · Rebex 바이너리는 사용자가 보유한 라이선스 사본을 사용합니다.
