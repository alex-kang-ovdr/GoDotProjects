게임 카드의 실제 화면 노출, 클릭, 실행 준비, 활성 플레이 시간과 완료 결과를 수집해 게임 품질과 재방문을 확인합니다. 숨긴 탭과 일시정지 시간은 활성 플레이에서 제외하며, 10초·60초 기준은 서버에서 판정합니다.
