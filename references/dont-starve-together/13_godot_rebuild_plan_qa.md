## 1. 목적과 범위 경계 (`[재구성 설계]`)

이 문서는 앞선 01~12번 문서에서 검증한 DST의 규칙·수식·아키텍처를 **PlayForge / Godot 4.7.2 (데스크톱 + Web/WASM + 저사양 PC)** 환경에서 재구축할 때 필요한 기술 매핑, 성능 예산, 단계별 Vertical Slice 로드맵, 그리고 QA 수용 기준을 정의한다.

> **명시적 제외 범위**:
> - Klei 원본 C++ 바이너리·Lua 코드·KTEX/KAnim/FMOD 원본 자산의 직접 재배포는 포함하지 않는다(저작권 분리).
> - 초기 마일스톤(M0~M3)에서는 스킨 상점·Steam 인벤토리·18인 전 캐릭터 스킬트리 전체·고대 금고/콜라보 이벤트를 제외하고 **핵심 협동 생존 루프 + 계절 + 요리/농사 + 보스전 + 멀티플레이 동기화**에 집중한다.

## 2. DST → Godot 4.7.2 아키텍처 매핑

| DST 원본 개념 | Godot 4.7.2 재구성 매핑 | 설계 근거 |
|---|---|---|
| `EntityScript` + `components/` | `Node3D` (XZ 평면 좌표) + Composition 기반 컴포넌트 스크립트(`HealthComp`, `HungerComp`, `SanityComp`, `CombatComp`, `PerishableComp` 등) | 얕은 상속 계층 + 컴포넌트 합성으로 창발적 상호작용(불/젖음/온도/부패) 유지 |
| `tuning.lua` / `preparedfoods.lua` / `recipes.lua` | 데이터 주도 `Resource` / JSON 테이블 (`data/tuning.json`, `data/recipes.json`, `data/foods.json`, `data/crops.json`) | 코드 수정 없이 밸런스 수치·레시피·작물 속성 튜닝 가능 |
| `StateGraph` (`SG*.lua`) | 명시적 상태 머신 + `AnimationPlayer`/타이머 기반 프레임 타임라인(`attack_windup`, `hit_frame`, `recovery`, `hit_stun`) | 카이팅·공격 취소·슈퍼아머 프레임 정확성 보장 |
| `Brain` + `BehaviourTree` | 경량 우선순위 BT(`Priority`/`Sequence`/`While`/`Condition` 리소스) — 0.25~0.5초 주기 틱 | 매 프레임 평가 대신 가변 틱으로 수백 개체 AI 비용 절감 |
| `FollowCamera` (2.5D 빌보드) | `Camera3D` (`fov=35°`, `heading=45°`, `pitch=30~60°`, `dist=15~50`) + `Sprite3D` (Y-Billboard 또는 고정 카메라 정렬) | 원작과 동일한 팝업북 원근감과 45° 회전 시점 재현 |
| `Ground` 타일 + `Ocean` | 청크 기반 `MeshInstance3D` / 커스텀 타일 블렌딩 셰이더 (`16×16` 타일 청크) | 78종 타일 경계와 미니맵 텍스처를 저비용 드로우콜로 렌더링 |
| `combine_colour_cubes.ksh` + `lighting.ksh` | 2D 라이트맵 텍스처 + `WorldEnvironment` 3D LUT 보간 셰이더 (낮/황혼/밤/계절/광기/계몽) | 시간대와 정신력 상태를 즉각 인지시키는 핵심 시각 신호 |
| `ismastersim` + `Replica` + `Classified` + `RPC` | Godot `MultiplayerAPI` / WebSocket 서버 권위 시뮬레이션 (`PlayForge` 릴레이 또는 Godot DS) + 19종 핵심 상태만 델타 복제 + 소유자 전용 `Classified` 채널 | 6인 협동 플레이 시 대역폭 절감 및 치트 방지 |
| `Master` / `Caves` 2-Shard | 1차: 단일 프로세스 다중 `SubViewport`/월드 인스턴스 분리 → 확장: 2-프로세스 샤드 마이그레이션 | 초기 개발/웹 실행 단순화와 향후 확장성 양립 |

## 3. 저사양 PC 및 Web(WASM) 성능 예산 (`[재구성 설계]`)

`game-designer` 스킬 원칙에 따라 성능을 후반 최적화가 아닌 **초기 설계 제약**으로 못 박는다.

| 비용 항목 | 목표 예산 (웹/저사양 PC 60 FPS 또는 30 FPS 고정 시뮬) | 폴백(Fallback) 정책 |
|---|---|---|
| **시뮬레이션 틱** | 고정 `30 Hz` (`dt = 1/30s`, 원작 `FRAMES` 일치), 렌더 `60 FPS` 보간 | 부하 시 AI/부패/온도 틱을 2~4프레임 분산(Staggered Tick) |
| **활성 엔티티 수** | 플레이어 반경 `48m` 내 활성(`EntityWake`), 외곽은 `EntitySleep` 후 접근 시 `LongUpdate` 일괄 정산 | 6인 분산 시 플레이어당 활성 반경 동적 축소(`36m`) |
| **드로우콜 / 스프라이트** | 화면 내 250 드로우콜 이하, 바닥/나무/풀/벽은 아틀라스 배칭 또는 `MultiMeshInstance3D` | 원거리 그림자·풀 흔들림 셰이더 비활성 |
| **조명·포스트프로세스** | 라이트맵 1/4 해상도 렌더 + 단일 풀스크린 ColourCube/Distort 패스 | 저사양 프로필: Bloom·Distortion·열기 아지랑이 Off, 2단계 명암 LUT만 유지 |
| **오디오 보이스** | 동시 재생 24보이스 상한, 동일 효과음 80ms 쓰로틀링 | 비/파도/바람 루프 1채널 통합 |
| **메모리 (Web WASM)** | 초기 로드 ≤ 120 MB, 런타임 힙 ≤ 512 MB | 타일/스프라이트 지연 스트리밍 |

> **[미검증]** 위 수치는 초기 설계 예산이며, 실제 저사양 기기·브라우저 프로파일링 전까지 "검증된 성능"으로 표기하지 않는다.

## 4. 단계별 구현 로드맵 (Vertical Slice M0 ~ M5)

| 단계 | 목표 마일스톤 | 포함 시스템 | 검증 게이트 (완료 조건) |
|---|---|---|---|
| **M0** | **2.5D 코어 루프 & 시계** | `FollowCamera(35°/45°)`, 16세그 하루(`480s`), 체력·허기·정신력, 이동·채집(도끼/곡괭이), 모닥불·찰리 어둠 | 3일 생존, 밤 어둠 피격·광원 회피 자동 시뮬 테스트 통과 |
| **M1** | **제작·요리·부패·전투** | 인벤토리(15+4슬롯), 프로토타이퍼(과학/연금술), 요리 냄비 우선순위(`cooking.lua`), 부패 배율, `Combat` + DST 방어구(`max` 흡수 + `0.7×` 내구도) | 미트볼/피에로기 판정, 다중 방어구 내구도 분배 단위 테스트 100% 통과 |
| **M2** | **사계절·환경·농사·거인** | 4계절(20/15/20/15), 기온/체온/습기 히스테리시스, 14작물 3영양분·7스트레스 농사, 하운드 습격 + 외눈사슴(4,000 HP) | 70일 가속 시뮬에서 사계절 전환·거대작물(`stress<=1`)·거인 처치 통과 |
| **M3** | **멀티플레이어 협동(2~6인)** | 서버 권위 시뮬, 19종 `Replica` + `Classified`, 이동 예측 토글, 유령화(`playerghost`)·고백 심장 부활·최대체력 페널티(`-25%`)·120초 전원 사망 리셋 | 2클라이언트 헤드리스 연동에서 동시 채집/전투/사망/부활 정합성 통과 |
| **M4** | **캐릭터 비대칭·바다·동굴** | 대표 6~8인 고유 기믹(윌슨/윌로우/볼프강/웬디/위그프리드/WX-78/워톡스/웜우드), 보트(`0.7^k` 돛 체감) & 달섬(`LUNACY`), 동굴·유적·악몽 주기 | 달 계몽 85% 진입/82.5% 해제, 보트 누수·수리, 샤드 이동 테스트 통과 |
| **M5** | **엔드게임·평면 전투·스킬트리** | `PlanarEntity` 비선형 감쇄 `(sqrt(4d+64)-8)*4`, 평면 피해/방어, 진영 상성, 균열 스포너, 15포인트 스킬트리 | 물리 100 → `54.16` 감쇄 검증, 진영 세트 보너스 및 균열 3단계 성장 검증 |

## 5. 핵심 경계 조건 QA 수용 기준표 (`[재구성 설계]`)

> 아래 항목은 구현 시 자동화 회귀 테스트로 검증할 **계획 및 수용 기준**이다(아직 구현/실행된 테스트가 아님).

| ID | 경계 시나리오 | 기대 동작 (코드 검증 근거) |
|---|---|---|
| `QA-01` | 투구(80%) + 갑옷(80%) 동시 착용 상태로 물리 피해 100 피격 | 체력 피해 **20** (96% 중첩 금지), 투구/갑옷 내구도 각 **40**씩 균등 차감 (`inventory.lua:415–453`) |
| `QA-02` | `planarentity` 적에게 물리 100 + 평면 30 공격 | 물리 `54.16` + 평면 `30` = 총 **84.16** 적용 (`planarentity.lua:902`) |
| `QA-03` | 방어구 80% 착용 플레이어가 평면 30 단독 공격 피격 | 일반 흡수 무시 → 체력 **30** 직격; `PlanarDefense=10` 장비 2부위 착용 시 `30 - 20 = 10` 적용 (`inventory.lua:438–460`) |
| `QA-04` | 정신력 광기/계몽 경계 진동 | Insanity `15%` 진입 후 `16%`에서도 광기 유지, `17.5%` 이상에서 복귀; Lunacy `85%` 진입, `82.5%` 이하에서 해제 (`sanity.lua:391–403`) |
| `QA-05` | 습기 경계 진동 및 건조 | `35`에서 젖음 진입, `20`에서 유지, `15` 이하에서 건조; 강우 중에는 `GetDryingRate() == 0` (`moisture.lua:289`) |
| `QA-06` | 고백 심장 4회 연속 부활 | 매회 `-25%` 누적되나 최대 체력 페널티는 **75% 상한**(`MAXIMUM_HEALTH_PENALTY = 0.75`)에서 클램프 (`health.lua:464`) |
| `QA-07` | 냄비 동률 우선순위 & `wetgoop` 폴백 | 최고 `priority` 후보군만 선별 후 `weight` 가중 추첨; 조건 불일치 시 `wetgoop` 반환 (`cooking.lua:238–288`) |
| `QA-08` | 작물 체크포인트 스트레스 누적 1점 vs 2점 | 1점은 `NONE`(거대 작물), 2점은 `LOW`(일반 작물 + 씨앗 2) (`farmplantstress.lua:72–78`) |
