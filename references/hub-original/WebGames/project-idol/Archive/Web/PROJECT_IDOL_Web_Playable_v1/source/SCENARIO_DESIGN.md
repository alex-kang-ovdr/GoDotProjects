# 시나리오 구조 및 분기 설계

## 6단계 활동기
1. Trainee (1~12개월): 스카우트, 평가, 멘탈 관리
2. Predebut (13~24개월): 데뷔조 구성, 첫 팬덤, 티저
3. Rookie (25~36개월): 데뷔, 소규모 공연, 낮은 음원 성과
4. Growth (37~48개월): 컴백, 팬덤 충성도, 음원 카탈로그 축적
5. Breakout (49~60개월): 우연한 숏폼 바이럴, 과거 곡 재발견, 역주행
6. Veteran (61~72개월): 대형 공연, 계약, 솔로/그룹 갈림길

## 엔딩 평가 순서
1. 강제 실패/활동 종료 조건
2. 주연 개인 아크 완결 여부
3. 그룹 결속/팬덤/음악성/대중성 조건
4. 동일 조건 충족 시 우선순위와 플레이어 선택 플래그로 결정
5. 그룹 엔딩 + 캐릭터별 후일담을 별도로 합성

## 역주행 모델
발매곡은 release_month, quality, catalog_value, discoverability, genre, fan_conversion을 보존.
매달 노출량 = 현재 프로모션 + 팬 콘텐츠 + 숏폼 확산 + 외부 방송 노출.
과거곡의 역주행은 품질과 노출량의 결합으로 확률적으로 발생하며, 밈 성공을 필수조건으로 두지 않음.
