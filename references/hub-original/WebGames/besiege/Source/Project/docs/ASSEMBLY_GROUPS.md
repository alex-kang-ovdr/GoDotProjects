# IRONWOOD 4.0 — 그룹 조립 UX와 변형 규칙

기준 구현: [editor.js](../dist/editor.js)의 `planGroupTransform()`, [main.js](../dist/main.js)의 선택·편집 이력, [scene.js](../dist/scene.js)의 선택 윤곽.

## 1. 선택과 시각 피드백

선택 도구에서 부품을 클릭하면 단일 선택입니다. Shift/Ctrl/Meta 클릭 또는 **여러 부품 선택** 버튼을 켠 상태의 클릭은 선택 집합에 부품을 추가하거나 뺍니다. 빈 곳의 추가 선택 클릭은 기존 묶음을 보존합니다. 모바일에서도 별도 키 없이 토글 버튼으로 여러 부품을 선택합니다.

금색 윤곽은 기준 부품, 청록 윤곽은 나머지 선택 부품입니다. 마지막으로 추가한 부품을 기준으로 삼으며 그 부품을 선택 해제하면 남은 마지막 부품이 기준이 됩니다. 기준 부품의 정수 셀을 묶음 회전의 중심으로 사용합니다.

두 개 이상을 선택하면 개별 출력·고각·행정 설정을 숨기고 묶음 편집 도구를 표시합니다. 개별 속성 변경은 한 부품을 선택하여 수행합니다. 코어가 묶음에 들어 있으면 전체 변형을 거부하고 버튼을 비활성화합니다. 일부만 변경하는 동작은 없습니다.

## 2. 변형의 정확한 의미

| 명령 | 규칙 | 성공 후 선택 |
| --- | --- | --- |
| 6방향 이동 | 모든 선택 부품에 정수 delta를 더함, 기본 한 셀 | 이동한 원래 ID |
| 방향으로 복사 | 해당 축의 묶음 너비만큼 이동한 복사본 생성 | 새 ID의 복사본 |
| 90° 회전 | 기준 부품 주위에서 Y축 +90°, rot도 1 증가 | 원래 ID |
| X=0 반사 | 월드 X=0 기준 x→−x, rot→−rot, 좌우 구동 교환 | 원래 ID |
| 묶음 삭제 | 선택 전체 제거 | 없음 |

회전 중심을 `(px,pz)`라고 할 때, 상대 좌표 `(dx,dz)`는 `(dz,-dx)`가 됩니다. y는 바뀌지 않습니다. 4회 회전하면 원래 위치와 방향으로 돌아갑니다. 피벗은 정수 셀이라 반 셀 위치가 생기지 않습니다.

복사 오프셋은 `선택 축 최대 좌표−최소 좌표+1`입니다. 이 방식으로 묶음 내부 모양과 설정을 유지하며 원본 바로 옆에 새 묶음을 둘 수 있습니다. 기존 설계의 다른 부품과 겹치면 복사 전체를 거부합니다. 사용자는 방향을 바꾸거나 공간을 마련한 뒤 다시 실행합니다.

회전과 반사는 해당 설계의 연결 그래프를 다시 계산합니다. 바퀴의 실제 차축 방향이 함께 돌아가므로 이전 지지가 없어질 수 있습니다. 분리된 초안은 편집·저장이 가능하지만 출격하려면 코어까지 실제로 연결되어야 합니다.

## 3. 원자적 처리

`planGroupTransform(parts, selectedIds, options)`는 원본을 변경하지 않습니다. 입력 ID를 검증하고, 이동할 선택 부품을 점유 검사에서 일괄 제외한 뒤, 전체 후보를 만들어 스키마·범위·겹침·100부품 한도를 검사합니다. 복사는 원본 점유를 유지하며 새 ID를 생성합니다.

모든 후보가 유효할 때만 새 배열을 반환합니다. 하나라도 실패하면 `ok:false`이고 현재 설계와 선택을 보존합니다. 빈 선택, 존재하지 않는 ID, 코어 포함, 비정수 위치, 범위 이탈, 점유 충돌, 잘못된 ID 생성기를 처리합니다. 일부 부품만 남거나 복사되지 않는 부분 성공은 없습니다.

반환에는 `ok`, `parts`, `selectedIds`, `addedIds`, `removedIds`, `changed`, `error`, `warnings`가 포함됩니다. 이동량 0 같은 무변화 명령은 `changed:false`를 반환하여 실행 취소 이력을 소비하지 않습니다. 유효한 변경 한 번은 실행 취소 한 단계입니다. 이력은 최대 70개의 독립 설계 스냅샷입니다.

## 4. 단일 부품 도구와의 관계

기존 G 이동, C 복사, R 회전, M 대칭 배치를 유지합니다. 단일 부품 이동은 새 위치를 클릭하기 전까지 원본 데이터를 바꾸지 않고, Esc로 취소합니다. 여러 부품일 때 G/C는 묶음 방향 도구를 안내하고 R/Delete는 묶음 전체에 적용됩니다.

부품 배치 도구를 선택하면 다중 선택 모드를 해제합니다. 출격할 때 배치 도구와 선택을 정리합니다. 시험 중에는 편집이 없으며, 부품 클릭은 일시정지 점검으로 전환됩니다.

## 5. 실패에서 재설계로

시험을 종료하고 돌아오면 실제로 손상·분리되었거나 높은 하중이 기록된 원본 부품을 보고서에서 찾을 수 있습니다. 보고서 강조는 선택 윤곽과 별도의 주황색 윤곽입니다. 현재 설계·작전의 서명이 이전 시험과 다르면 강조를 해제합니다. 동일 ID가 다른 설계에서 재사용되어 엉뚱한 부품을 가리키는 것을 방지합니다.
