# 이벤트 데이터 및 실행 엔진 명세 (v3)

## 데이터 출처 구분
- `CONFIRMED`: 원작 매뉴얼 또는 재현 실험으로 확인한 사항
- `SECONDARY`: 공략 자료 기반, 아직 독립 검증되지 않음
- `UNVERIFIED`: 역사적 후보, 원작 이벤트 존재도 미확인
- `DESIGN_ONLY`: 프로토타입 실행을 위해 새로 만든 규칙

`event_conditions_prototype.csv`의 날짜 조건은 역사적 연도만 참고한 **설계 예시**이며 원작 트리거가 아닙니다. `event_effects_prototype.csv`는 실제 원작 효과가 아니라 대사 표시/중복 방지 데모입니다.

## 원작 대사 및 이벤트 복원 절차
1. PK 버전, 언어, 시나리오, 설정 및 이벤트 활성 여부 기록
2. 이벤트 발생 직전 세이브와 스크린샷 확보
3. 발생 전후 무장 소속·충성·관계·도시·금·군량·병력 비교
4. 동일 조건 3회 이상 재실행하고 분기 조건 단일 변수 변경
5. 대사 텍스트는 사용자가 제공한 게임 데이터/캡처와 직접 대조해 별도 출처 기록
6. 결과가 일치할 때만 `CONFIRMED` 승격

## 처리 순서 (재구현 제안)
- 정기 시간 경과 처리
- 이벤트 후보 조회 및 조건 평가
- 중복 발생 방지 확인
- 선택지 및 대사 표시
- 효과를 트랜잭션으로 적용
- 발동 기록과 세이브 직렬화
