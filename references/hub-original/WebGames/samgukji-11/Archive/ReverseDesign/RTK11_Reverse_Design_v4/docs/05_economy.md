# 자원·경제·수송

> **원작 일치도 표기:** `확인`=원작 UI/공식 자료로 검증, `참고`=공략 자료 기반, `가설`=재구현 제안, `미확정`=실측 필요. 이 문서는 비공식 역기획이며 코에이테크모의 내부 명세가 아닙니다.

## 주요 자원
금, 군량, 병력, 병장(창·극·노·군마 등), 기교 포인트, 행동력은 서로 다른 자원이다. 자원 소유 범위(도시/부대/세력)를 혼합하지 않는다.
## 수입과 지출
시장·농장 등 시설 수익과 병력 유지·출진·명령 비용을 이벤트 기반으로 기록한다. 수입 지급 주기와 반올림 규칙은 실측 전 미확정.
## 수송
출발 거점의 보유량과 수송 부대 적재량을 분리한다. 출발 시 차감, 도착 시 가산, 수송 도중 괴멸 시 손실을 테스트한다.
## 검증
조폐/곡창 인접 보너스, 시설 레벨 변화, 거래, 부대 군량 고갈, 자원 상한 및 초과 처리.

## 구현 인터페이스 공통 요구
- 모든 명령은 실행 가능 여부·소모 자원·상태 변경·이벤트 로그를 반환한다.
- 시나리오와 규칙 데이터를 로직에서 분리한다.
- 재현 실험에는 버전, 난이도, 시나리오, 날짜, 입력 상태, 결과 스크린샷을 첨부한다.
