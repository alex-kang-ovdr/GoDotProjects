`provenance: "v5_secondary_sample"`은 **기존 v5의 출처 있는 표본을 이어받았다**는 뜻이지 본 작업에서 원작 게임을 직접 실행하여 다시 검증했다는 뜻이 아닙니다. 표본의 원본 CSV와 출처 등록부를 `reference/`에 보존했습니다.

## 실제 개발에 사용할 때

원작 수치를 추후 추가할 경우 이 구현의 프리셋을 조용히 덮어쓰지 말고 원작 버전·언어·플랫폼·시나리오·출처·검증 상태를 별도 레코드로 보존해야 합니다. 현재 저장에는 재구성 수치가 복사되어 있으므로 데이터만 교체해도 기존 저장이 원작 상태로 바뀌지 않습니다.

코어 엔진과 데이터·UI는 분리되어 있습니다. 다음 우선순위는 PC PK 정확한 무장·도시·시나리오 테이블 편입, 원작 지도 좌표 교체, 시설 합병과 관문/항구, 원작 특기 우선순위, 실측 피해 수식 순입니다. 이 문서는 이후 작업이 이미 수행됐다는 의미가 아닙니다.
