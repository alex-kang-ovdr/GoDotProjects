## 핵심 로직

벡터 기저·선분/구체·선분/상자·회전 상자 충돌, 동일 Seed 재현, 모든 바닥 칸의 연결, A* 경로, 스폰 위치, 이동·회피 벽 관통 방지, 한 공격의 대상 중복 타격 방지, 준비 동작 무피해, 근거리 검 날 타격, 상하 조준, 벽 우선 접촉, 전방 방패와 후방 피격을 검사했습니다.

타이밍 방어·일반 방어·가드 붕괴·도끼 방패 제한, 몬스터 단일 타격·회피, 수색 중단·중복 동전 지급 방지, 가방 부족 시 원본 보존, 원격 루팅 거부, 장비 교체 원자성, 회수 가능한 버리기, 물약 완료 시 소비·중단, 화살 유한 장전, 투사체 이동·벽 차폐, 화염구 단일 대상 중복 피해 방지, 보스 단일 공격·페이즈·충격파, 정지·사망·시체 단일 생성·탈출 멱등성·재시작도 포함합니다.

## 브라우저 검증 방법

Chromium **144.0.7559.96**, Playwright, Xvfb, SwiftShader 소프트웨어 WebGL을 사용했습니다. 1440×900 화면에서 UI와 스크린샷을 확인하고 1024×700 화면의 가방 가로 넘침을 검사했습니다.

실행 환경의 탐색 정책이 파일 URL과 localhost 접속을 차단하여, 완성된 `index.html` 내용을 `page.set_content`로 about:blank 페이지에 주입했습니다. 정책 우회나 변경은 하지 않았습니다. 실제 렌더러·DOM·입력 이벤트를 사용했고, 재현이 필요한 전투·정산 구간은 고정 시간 간격 수동 전진을 사용했습니다. UI 통합 테스트에서는 반복적인 소프트웨어 렌더링 비용을 줄이기 위해 자동 렌더링을 끄고 필요한 프레임을 명시적으로 그렸습니다. 실제 게임에서는 자동 렌더링이 기본값입니다.

## 브라우저에서 확인한 행동

첫 프레임·시작·전체 시스템 초기화, 실제 W 키 이동, E 키 수색, 루팅 패널 열기, 네 아이템 일괄 획득, 장착과 이전 장비 반환, 포인터 드래그, R 회전, 내려놓기, 인벤토리 중 시뮬레이션 진행, F1 정지·재개, 적 공격 예고 프레임 렌더링, 탈출 결과 UI·보상, 중복 정산 차단, 재시작을 검사했습니다.

별도 입력 테스트에서는 연습장 버튼, 사용자 클릭에 따른 실제 마우스 잠금, 단일 좌클릭의 단일 공격, 우클릭 방어·해제, 2/3 키의 활·화염구 전환 및 자원 소모, R 장전 및 예비 화살 차감을 확인했습니다.

## 저장 검증의 경계

이 환경의 about:blank 문서에서는 영구 localStorage를 사용할 수 없어 **저장 불가 안내와 현재 탭 보관 골드, 중복 정산 방지** 경로를 검증했습니다. 실제 파일 출처에서 브라우저를 닫고 다시 열었을 때의 localStorage 지속성은 검증하지 않았습니다. 저장 코드는 예외 처리를 포함하며 실제 환경의 저장 정책에 따릅니다.

## 이 결과가 보장하지 않는 것

전체 15분 매치를 사람이 반복 플레이한 결과나 게임의 재미·밸런스 인증은 아닙니다. 모든 GPU·브라우저·난이도에서의 성능, 온라인 동기화, 고속 회전에 대한 완전한 연속 메시 물리 판정, 영구 저장 정책의 일관성을 보증하지 않습니다. 충돌 테스트는 정의된 근사 판정 모델의 회귀 검증입니다.
