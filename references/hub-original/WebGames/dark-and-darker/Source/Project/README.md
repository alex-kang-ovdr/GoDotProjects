# Crypt of the Fallen v13

**1인칭 3D 던전 탐험 / 전투 / 루팅 / 탈출 — 오프라인 싱글플레이 웹 프로토타입**

Dark and Darker의 탐험·전투·탈출 구조에서 영감을 받은 독립 프로토타입입니다. 원작 공식 제품이나 정확한 시즌 규칙 재현물이 아닙니다. 원작 소스코드·캐릭터 에셋·음원은 포함하지 않습니다.

## 실행

압축을 풀고 **`index.html`을 데스크톱 Chrome 또는 Edge에서 여세요.** 웹 서버, 계정, 패키지 설치, CDN 접속은 필요하지 않습니다. 실행에 필요한 코드와 스타일이 HTML에 모두 들어 있습니다. `src/`, `tests/`, `docs/` 폴더는 개발·검증용이므로 게임 실행에 필요하지 않습니다.

첫 화면에서 난이도와 던전 Seed를 고른 후 `던전 입장`을 누릅니다. `연습장`에서는 일반 검사·수호자·궁수를 상대로 전투를 시험할 수 있습니다. 연습장은 골드가 정산되지 않습니다.

처음에는 입구의 보급품 상자를 바라보고 **E를 길게 눌러** 단검·도끼·갑옷·물약을 확인하세요. 전리품을 확보하고 푸른 포탈에서 E를 길게 누르면 탈출합니다. 보스 처치는 탈출의 필수 조건이 아닙니다.

브라우저에서 마우스 잠금이 거부되면 방향키로 시점을 움직일 수 있습니다. WebGL을 사용할 수 없으면 화면에 오류 안내가 표시됩니다. 모바일 터치 조작은 구현하지 않았습니다.

## 조작

| 입력 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 / 방향키 | 상하좌우 시점 |
| 좌클릭 / 우클릭 유지 | 공격 / 방패 방어 |
| 1 / 2 / 3 | 장착 근접 무기 / 활 / 화염구 |
| Shift / Space / Q | 달리기 / 점프 / 회피 |
| E 길게 | 상자·시체 수색 / 탈출 |
| H | 물약 사용. 사용 동작이 완료되면 회복·소비 |
| R | 활 장전. 가방에서는 선택 아이템 회전 |
| I / M | 인벤토리 / 미니맵 |
| F1 / Esc | 일시정지. Esc는 마우스 잠금 해제에도 사용 |
| T 또는 Y 또는 F2 / V | 개발자 진단 / 충돌 판정 시각화 |

가방에서 드래그로 이동하고, 아이템을 선택하여 장착·회전·내려놓기 버튼을 사용합니다. 더블클릭으로 장비를 장착하거나 소모품을 퀵 슬롯 자원으로 옮길 수 있습니다. **가방을 열어도 던전은 멈추지 않습니다.** 안전하게 설정을 바꿀 때는 F1을 사용하세요.

## v13 주요 변경

### 실행·상태 처리 통합

v12의 누적 함수 덮어쓰기를 걷어내고 전투·AI·인벤토리를 하나의 게임 상태로 통합했습니다. 던전 생성 전 첫 프레임 오류와 오래된 시작 함수 바인딩을 수정했습니다. 보스 공격과 렌더링도 중복된 구버전 루프 대신 단일 경로로 처리합니다.

### 근접 전투와 방패

장검·단검·도끼의 준비/타격/후딜과 스태미나 비용을 분리했습니다. 화면에 보이는 무기의 궤적과 충돌 검사가 같은 위치 계산을 사용합니다. 검 끝점 하나만 검사하지 않고 날을 따라 여러 지점을 샘플링하며, 타격 활성 구간을 짧은 시간 단위로 나눕니다. 벽·방패·신체 후보 중 먼저 닿는 접촉을 처리합니다.

방패는 방향 조건만 보는 것이 아니라 회전 가능한 3차원 상자(OBB)로 판정합니다. 머리·몸통·다리는 구형 피격 영역을 사용합니다. 방어를 시작한 뒤 0.23초 이내 적중하면 타이밍 방어가 성립하고 반격 기회가 생깁니다. 스태미나가 부족하면 가드가 무너집니다. **양손 도끼는 방패를 사용할 수 없습니다.**

이는 기하학적 근사 판정이며 삼각형 메시 전체를 연속 충돌 검사하는 물리 엔진은 아닙니다. 수치와 타이밍은 이 프로토타입의 독립 설정입니다.

### 몬스터와 보스

검사·궁수·철갑 수호자·군주를 구분했습니다. 팔·다리·갈비뼈·턱·무기를 나누어 이동, 공격 준비, 타격, 피격, 사망 자세를 절차적으로 표시합니다. 궁수는 거리를 벌리고 화살을 발사하며 수호자는 정면 방패로 공격을 막습니다.

군주는 하나의 공격 상태 머신에서 내려찍기·휩쓸기를 수행하고 체력 50% 미만이면 광역 충격파를 추가합니다. 바닥 예고를 보고 범위 밖으로 빠져나가거나 충격파를 점프로 피할 수 있습니다. A* 경로 탐색과 마지막으로 확인한 플레이어 위치 추적을 사용합니다.

### 가방과 장비

6×4, 총 24칸을 **실제 아이템 데이터**로 관리합니다. 기존 12개 개수 제한과 별도 UI 좌표 체계를 제거했습니다. 아이템 회전, 경계·겹침 검사, 드래그 배치, 장비 교체를 지원합니다. 가방이 꽉 차면 아이템은 상자에 남으며 숨겨지거나 자동 소멸하지 않습니다. 교체할 기존 장비가 들어갈 공간이 없으면 교체 전체를 취소합니다. 내려놓은 아이템은 현장 가방에서 다시 회수할 수 있습니다.

### 탐험·표현·설정

Seed 기반 던전, 탐색한 지역만 보이는 미니맵, 보스 체력 표시, 피해 수치, 수색 진행률, 전리품 패널을 통합했습니다. 절차적 석재·바닥·목재·금속 재질과 횃불 색 조명을 사용합니다. F1에서 시야각, 마우스 감도, 렌더 해상도, 효과음, 머리 흔들림을 조절합니다. 외부 음원 없이 Web Audio로 효과음을 만듭니다.

## 전리품·저장 규칙

탈출하면 소지 골드와 **가방 및 장착 장비의 가치가 골드로 합산**됩니다. 이번 버전은 영구 아이템 보관함이나 상인 거래 대신 자동 정산 모델을 사용합니다. 매번 기본 장비로 출전하며 사망하면 해당 출전의 전리품을 잃습니다. 이미 정산된 보관 골드는 유지됩니다.

보관 골드·출전·탈출 횟수는 `localStorage`의 `crypt_v13_save`에 기록합니다. 이전 `crypt_v3_gold`가 같은 브라우저 저장 영역에서 보이면 최초 실행 시 가져옵니다. 파일 위치, 브라우저, 보안 설정에 따라 저장 영역이 다를 수 있어 이전 저장의 자동 이전을 보장하지 않습니다. 저장이 차단된 경우 안내 메시지를 표시하고 현재 탭에서만 보관 골드를 유지합니다. 진행 중 던전 자체의 중간 저장은 없습니다.

연습장과 개발자 치트를 사용한 출전에는 골드를 지급하지 않습니다. 결과 정산은 같은 출전에 한 번만 적용합니다. 로컬 싱글플레이 저장이므로 사용자가 데이터를 수정하는 것을 막는 보안 시스템은 아닙니다.

## 검증

- Node 핵심 로직/시뮬레이션 **55/55 통과**.
- Chromium WebGL·UI 통합 **21/21 통과**.
- 실제 마우스·키보드 입력 **10/10 통과**.
- 던전 300개 Seed 연결성, 별도 100개 Seed의 스폰 위치 검사 포함.
- 테스트 중 JavaScript 예외 및 외부 런타임 리소스 요청 0건.

상세 범위와 제한은 `tests/TEST_REPORT.md`에 있습니다. 자동화 환경에서 HTML을 브라우저에 주입하여 WebGL을 실행했습니다. 보안 정책으로 파일 URL 직접 탐색은 테스트하지 못했습니다. 실제 PC의 장시간 수동 플레이, 전체 난이도 밸런스, 다양한 GPU 성능을 인증한 것은 아닙니다.

## 소스 수정 및 재빌드

```text
src/core.js       기하 계산, Seed 던전, 아이템·격자 가방, 공격 프로파일
src/game.js       고정 시간 간격 시뮬레이션, 전투·AI·루팅·탈출
src/renderer.js   WebGL 렌더러와 정적 던전 메시
src/scene.js      절차적 캐릭터·무기·이펙트 메시
src/app.js        입력·UI·효과음·저장·프레임 루프
src/style.css     화면 구성
src/template.html 빌드 템플릿
```

```sh
python build.py
node tests/test_core.cjs
```

게임 실행에는 Python과 Node가 필요하지 않습니다. 위 명령은 개발용입니다. 브라우저 테스트는 별도로 Python Playwright, Chromium, Linux에서는 Xvfb 등 표시 환경을 요구합니다. 테스트 스크립트는 기본적으로 `/usr/bin/chromium`, `DISPLAY=:99`를 사용합니다.

## 구현 범위 밖

온라인 PvP·협동 서버, 실제 스켈레탈 에셋, 삼각형 메시 전체 CCD, 정교한 동적 그림자, 영구 아이템 보관함·상인·퀘스트, 모바일 터치 조작은 포함하지 않습니다. 캐릭터는 생성형 저폴리 메시와 절차적 관절 움직임으로 구성됩니다. 조명은 실시간 차폐 그림자가 없어 벽 너머 광원이 간접적으로 영향을 줄 수 있습니다.
