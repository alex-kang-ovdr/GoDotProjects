# 변경 내역

## 4.0.0 — 2026-11-14

### 기밀문과 실제 방

- 기밀문에 자동·열림·잠금 모드를 추가했습니다. 자동문은 실제 대원 접근에 맞춰 열리며 닫힌 문은 산소·이산화탄소·지면 물의 교환을 막습니다. 열 전도와 전선·배관 연결은 유지합니다.
- 잠금은 실제 길찾기를 차단하고 기존 경로를 다시 판단하게 합니다. 점유한 문을 잠그는 명령을 거부해 통과 중인 대원을 가두지 않습니다.
- 자연 지형·완공한 벽·출입문을 기준으로 연결 공간을 분석합니다. 내부 6~64칸과 문이 있는 밀폐 구역에서 침실·식당·온실을 판정하고 실제 경계·면적·가구·미달 이유를 제공합니다. 열린 문도 구조적 출입 경계로 유지됩니다.
- 침실은 실제 침상 기력 회복 +25%와 초당 스트레스 추가 회복 0.2, 식당은 실제 식사당 추가 스트레스 회복 3, 온실은 기존 급수·온도·산소·비침수 조건을 만족하는 실제 성장 +20%를 적용합니다. 존재만으로 이용 누계가 늘어나지 않습니다.
- 금지 시설은 완공되어 남아 있다면 비활성화해도 방을 무효화합니다. 필요한 침상·식탁·농장은 활성 상태여야 합니다. 천장 파괴·가구 철거·복구로 구조와 효과를 다시 판정합니다.
- 구역 탭과 `R` 오버레이, 선택 구역 강조·실제 문 상태·방 색상·미달 이유와 방 사용 집계를 연결했습니다.

### 휴대 산소와 실제 작업 기술

- 연구 45에 해금되는 산소 충전소를 추가했습니다. 광석 20·금속 12로 건설하고 8W로 주변 실제 산소를 초당 최대 0.08 압축합니다. 공급 셀에 최소 0.35를 남기고 자체 탱크 용량은 18입니다.
- 대원은 실제 충전소까지 이동해 재고에서 초당 최대 1.5를 용량 6의 휴대통으로 옮깁니다. 저장 산소를 이송할 때는 전력이 필요하지 않으며 중단·저장·재개에도 양을 보존합니다.
- 마스크 자동 모드는 현재 공기로 호흡할 수 없을 때만 초당 0.055를 실제 소비합니다. 사용 안 함은 보충·소비를 멈추고 잔량을 보존합니다. 통이 비면 일반 호흡 감소와 긴급 피난으로 돌아갑니다. 마지막 틱보다 적은 잔량도 비율만큼 정확히 소비·호흡합니다.
- 산소 압축·이송·소비·보호받은 호흡 시간과 저장/휴대 합계를 구분합니다. 충전소 철거는 실제 산소를 주변에 반환할 수 있을 때만 허용하며, 사망한 대원의 남은 산소도 저장 상태에 보존합니다.
- 채굴·건설·해체·발전·연구·수확·조리와 성공한 운반/산소 이송의 실제 작업에만 XP를 기록합니다. 이동·대기·수면·식사·무전력 대기는 XP가 아닙니다. 60 XP마다 1포인트, 최대 6레벨을 얻습니다.
- 굴착·공학·생활을 각각 최대 3등급까지 수동 배분합니다. 굴착은 등급당 채굴 +20%, 공학은 건설·해체 +15%와 연구 +10%, 생활은 조리·수확 +15%입니다. 배분 전 속도는 그대로이고 기존 스트레스 효율에 곱합니다. 생산 수량은 늘리지 않습니다.
- 대원 패널에 휴대통·사용 모드·현재 휴대 호흡·경험·레벨·포인트·기술 배분을 추가했습니다.

### 안전한 확장과 검증된 정상 경로

- 기존 16개 목표를 보존하고 침실+식당 2종, 수동 배분 3등급, 실제 휴대 호흡 합계 30초, 안전한 확장 연속 180초를 추가해 5단계 20목표로 확장했습니다.
- 현재 정착 조건에 더해 각 방과 충전소의 실제 접근, 기술·휴대 호흡 누계, 완공·활성·전력 연결·비침수 충전소를 검사합니다. 저장고가 가득 찬 정상 압축 대기는 허용하며 중단 시 현재 시간을 초기화하고 이유를 표시합니다.
- 실제 심부 채굴·수거로 추가 시설 재료를 조달하고, 기존 바닥에서 작업할 수 있는 낮은 침실 8칸·식당 10칸을 완성하는 경로를 추가했습니다. 사다리로 채굴한 바닥의 귀환 경로를 보존합니다.
- 초기 한 대의 확산기와 문 열기만으로 먼 방에 산소가 부족한 문제를 실제 계측했습니다. 조건을 낮추지 않고 세 추가 구리 광맥을 채굴·운반해 침실과 식당에 실제 확산기를 설치하고 문을 열어 환기하는 정상 운영으로 해결했습니다.
- 공개 명령만으로 새 기지를 시작해 게임 시간 **2,188.5초에 20개 목표**를 완료했습니다. 실제 운반 389개, 휴대 호흡 617.9초, 기술 3등급, 침실 휴식 199.7초, 유효 식당 식사 15회이며 세 대원 모두 건강 100이었습니다.
- 추가 **10주기** 동안 최저 건강 100, 하층 농장 각 9회 수확, 조리 51→75끼, 식탁 식사 36→60회, 계획 수면 32→57회, 침실 휴식 199.7→534.7초를 확인했습니다. 최저 식품은 약 96.65끼입니다. 현재 정착·확장 타이머는 이후에도 갱신되며 마지막 값은 각각 140.8초였습니다.
- 최종 예제 저장과 정확한 수치를 `examples/self-sustaining-colony.json`, `examples/validation-report.json`에 갱신했습니다. 생성 스크립트는 새 기지부터 공개 명령으로 재실행하고 정확한 저장 왕복과 추가 10주기를 확인합니다.

## 3.0.0 — 2026-11-14

### 실제 운반과 보관

- 광석·금속·조류·석탄의 채굴 결과를 바닥의 자원 더미로 바꿨습니다. 대원이 최대 12개를 수거하고 코어 또는 보관함까지 실제로 이동한 뒤 공용 재고에 입고합니다.
- 코어의 기본 고체 용량 600과 자원 보관함당 추가 용량 240, 가까운 도달 가능한 활성 거점 선택, 더미별 우선순위 1~5를 추가했습니다. 용량·접근 문제는 더미의 대기 이유로 표시합니다.
- 역할·교대·긴급 호흡·경로 단절·사망에서 운반 화물을 현재 위치에 내려놓고 예약을 해제합니다. 다른 대원이 회수할 수 있으며 고체가 사라지거나 중복되지 않습니다.
- 보관함을 해체한 뒤 현재 재고와 환불을 보존할 수 없으면 해체를 거부합니다. 수거 뒤의 비축은 공용이며 건설·생산 설비별 최종 투입 배송은 이번 범위에 포함하지 않습니다.

### 조리·냉장·식탁·교대

- 조리대·식탁·냉장고를 추가했습니다. 조리대는 연구 10에 해금되며 실제 작업 대원·10W·원식량 2끼·청수 0.3L·기본 작업 6초로 조리식 3끼를 만듭니다.
- 조리식 목표 비축량 0~60끼, 기본 12끼를 지원합니다. 급수·전력·작업자가 끊기면 부분 진행을 보존하며, 저장·불러오기와 복구가 중복 생산을 만들지 않습니다.
- 원식량과 조리식에 실제 부패를 적용합니다. 연구 30에 해금되는 냉장고는 실제 6W 공급 중에만 공용 식품의 부패 속도를 80% 낮춥니다.
- 대원이 식탁까지 직접 이동해 먹습니다. 조리식을 우선 소비해 포만 30을 회복하며 조리식·식탁 식사는 스트레스를 줄입니다. 식탁이 바쁘면 자리를 기다리되 긴급한 굶주림은 즉시 식사로 처리합니다.
- 운반·조리 역할과 자율·주간·중간·야간 교대를 추가했습니다. 세 교대는 40초씩 어긋나며 여가에는 실제 식탁, 수면에는 실제 침상을 사용합니다.
- 수면 구간에 침상에서 6초 이상 쉬면 교대 주기당 한 번 계획 수면을 기록합니다. 높은 스트레스는 채굴·건설·해체·연구·조리의 실제 효율을 최저 48%까지 낮춥니다.

### 목표·정보·실행

- 기존 12개 목표를 유지하고 실제 운반 80개·조리 12끼·식탁 식사 6회·정착 240초를 더해 총 16개 목표로 확장했습니다. 운반 목표는 금속 12를 보급합니다.

- 물류 탭과 `H` 물류 오버레이, 실제 더미·화물·운반 인력·용량·대기 이유, 조리 목표 입력, 조리/냉장 상태·부패 수치, 대원 교대표·수면 이력과 새 생산 누계를 UI에 연결했습니다.

## 2.0.0 — 2026-11-14

### 생활과 물 순환

- 청수관과 오수관을 서로 독립된 연결 레이어로 추가했습니다. 전선·두 배관은 같은 칸에 공존하며 설비 앵커 칸에서 입출력합니다.
- 코어의 초기 청수 저장, 청수·오수 각각 80L 탱크, 관 셀별 1L 버퍼를 추가했습니다. 전역 물 재고는 실제 저장 슬롯의 합계입니다.
- 네트워크를 나누거나 합칠 때 물을 복제하지 않습니다. 관·탱크를 철거할 때 같은 망으로 물을 옮기며 저장 여유가 없으면 거부합니다. 청수관·오수관 선택 철거 도구를 추가했습니다.
- 수세식 화장실, 세면대, 급수 탱크, 오수 정화기, 물 전해장치, 수소 발전기, 순환 냉각기를 추가했습니다.
- 대원에게 용변 욕구·위생과 실제 화장실·세면 이용 작업을 추가했습니다. 연결·재고·배출 여유·접근 경로가 있어야 이용합니다.
- 물 수집기가 연결된 청수망에 취수하도록 바꾸고 오른쪽 웅덩이에 표시된 지하수 유입구를 추가했습니다. 농장과 연구도 실제 청수 연결을 요구합니다.
- 정화기는 오수와 광석을 소비해 청수 95%를 회수합니다. 전해장치는 청수·전력으로 산소·수소를 만들고, 수소 발전기는 실제 수소를 소비합니다. 수소는 공용 재고로 단순화했습니다.
- 냉각기는 전력과 청수를 소비하고 같은 양의 오수를 내보내며 주변 온도를 낮춥니다.

### 자동 제어·진행·정보

- 설비별 배터리·산소·온도 자동 제어와 히스테리시스를 추가했습니다. 수동 정지가 우선하며 자동 제어의 직전 상태도 저장합니다.
- 연구 상한을 50에서 100으로 늘렸습니다. 연구 15에 정화기, 35에 전해·수소 발전, 60에 냉각기를 해금합니다.
- 기존 초기 목표 6개를 보존하고 위생 이용·취수·정화·수소 발전·연구 100·180초 자립 유지 목표를 더해 총 12개를 3단계로 구성했습니다.
- 최종 자립은 누적 생산뿐 아니라 현재 연결된 생활·취수·정화·전해·발전 설비와 건강·식량·물·산소·위생 조건을 요구합니다. 미달 이유를 표시하고 연속 유지 시간을 초기화합니다.
- 실제 생산·생활 이용 누계와 최대 90개 추세 표본, 배관 가동·저장 상태, 막힌 작업의 이유를 공개 상태에 추가했습니다.
- UI에 배관 분류와 오버레이, 생활 현황, 생산 추세, 작업 목록, 단계별 목표, 자동 제어를 추가했습니다. `V`는 배관 보기, `L`은 청수관, `Q`는 오수관 도구입니다.

### 수지와 수정

- 농장 생장 주기를 75초에서 120초로, 한 번의 수확량을 식량 5에서 1.5로 조정했습니다. 대원 소비와 비교했을 때 시작 농장만으로 세 명을 장기간 유지할 수 없게 했습니다.
- 포만 감소를 초당 0.20, 한 끼 회복량을 24로 조정했습니다. 식량 잔여 주기 표시는 대원 1명당 주기 1끼 기준으로 맞췄습니다.
- 연구를 가동 중 초당 0.24, 청수 소비를 초당 0.008L로 조정했습니다. 초기 목표의 보급도 줄여 이후 생산 설비의 필요성을 유지했습니다.
- 소비 설비가 없는 회로에서도 빈 배터리 충전을 위해 수동 발전 대원이 일하도록 수정했습니다.
- 도달할 수 없는 작업이 설명 없이 대기하던 문제를 수정했습니다.
- 완성 농장 해체의 물 환불이 합계 재계산에서 사라지던 문제를 수정했습니다. 환불량을 실제 청수 저장에도 반영합니다.

### 저장과 검증

- 저장 형식을 v2로 확장했습니다. 정상 v1 진행·승리 저장을 변환하며 지형·설비·자원·작업 진행·완료한 초기 목표를 보존합니다. 기존 승리는 새 자립 목표로 이어집니다.
- 손상된 신규 필드, 잘못된 자동 제어, 음수·비유한값, 물 재고와 슬롯 합계 불일치를 거부합니다. 실패한 불러오기는 현재 게임이나 입력 객체를 부분 수정하지 않습니다.
- 실제 v1 엔진에서 생성한 진행 중 저장과 승리 저장을 fixture로 보존했습니다.
- Node 통합·회귀 테스트를 **29개**로 확장해 모두 통과했습니다. 공개 명령만으로 정상 승리, 자립 유지 도중 배관 단절·복원, 승리 후 추가 10주기 운영을 확인합니다.
- README에 실제 검증한 좌표·시설 순서·배관 경로·해금·수지·단순화와 테스트 명령을 정리했습니다.
- 정상 공개 명령 진행으로 승리한 관찰용 기지 `examples/self-sustaining-colony.json`을 추가했습니다. 조작법의 세이브 가져오기로 물 순환과 고급 시설을 확인할 수 있습니다.
- 추천 경로와 예제 기지에 취수 구역 방수벽을 포함했습니다. 대원을 기지 쪽에 둔 채 건설하고, 저장고가 가득 찬 뒤에도 지하수 넘침으로 하층 농장이 멈추지 않도록 했습니다. 추가 10주기 동안 세 농장의 비침수·반복 수확을 회귀 검증합니다.
