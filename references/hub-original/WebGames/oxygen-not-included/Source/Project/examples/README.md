# 완성된 기지 관찰 예제

`self-sustaining-colony.json`은 **v4 엔진에서 새 기지를 시작해 실제 공개 명령만 사용하고 20개 목표를 완료한 저장**입니다. 월드 시드는73, 게임 시간2,188.5초이며19주기째에 저장했습니다. 재고·연구·대원 상태·경험·산소·지형을 직접 주입하지 않았습니다.

## 가져오기

1. 게임의 **조작법 → 세이브 가져오기**에서 `self-sustaining-colony.json`을 선택합니다. 현재 기지를 보관하려면 먼저 내보내기를 사용하세요.
2. 일시정지 상태에서 목표 **20/20**, 정착 **240초**, 확장 **180초**, 대원 세 명의 교대·휴대 산소·배분한 기술을 확인합니다.
3. `V` 배관 보기, `H` 물류 보기, `R` 구역 보기를 전환합니다. 기밀문으로 나뉜 침실8칸·식당10칸과 각 방의 실제 산소 공급을 살펴보세요.
4. 시간 진행을 재개하면 실제 식사·조리·수확·교대·방 휴식이 계속됩니다. 충전소는 탱크가 가득 차 있어 정상 대기할 수 있습니다.

## 주요 위치

| 좌표 | 관찰할 대상 |
|---|---|
| `(24,11)` | 코어, 청수 저장과 고체 수거 거점 |
| `(25,11)` / `(29,11)` | 화장실·세면대의 실제 이용 |
| `(31,11)` / `(32,11)` | 청수·오수 탱크와 정화기 |
| `(33,11)` / `(34,11)` | 물 전해·수소 발전. 산소나 전력이 충분하면 자동 대기 |
| `(36,11)` / `(37,11)` | 실제 방수벽과 취수기. 대원이 기지 쪽에 돌아온 다음 벽을 건설한 상태 |
| `(18,16)` | 보관함, 코어와 합계 고체 용량840 |
| `(20,16)` | 유효한 식당 안의 실제 식사·여가 장소 |
| `(25,16)` / `(26,16)` | 조리대·냉장고, 기존 전선과 청수망 사용 |
| `(28,16)` / `(29,16)` / `(30,16)` | 장기 운영 중 반복 수확하는 하층 농장 |
| 내부 `x=15~18,y=10~11` | 침상3개·산소 확산기1개가 있는 침실 |
| 내부 `x=17~21,y=15~16` | 식탁·보관함·산소 확산기가 있는 식당 |
| `(14,11)` / `(19,11)` | 침실 출입문. 현재 환기를 위한 열림 모드 |
| `(16,16)` / `(22,16)` | 식당 출입문. 현재 환기를 위한 열림 모드 |
| `(18,11)` / `(19,16)` | 두 방의 지역 산소 확산기. 실제 전력과 조류 소비 |
| `(21,11)` | 산소 충전소. 주변 산소를 압축하고 대원이 실제로 방문해 보충 |
| 사다리 `(23,21~22)` / `(17,22~23)` | 실제 심부 채굴·운반·귀환 통로 |
| `(23,22)`, `(20,22)`, `(17,23)` | 방·충전소 재료를 조달한 구리 자리 |
| `(14,21)`, `(10,23)`, `(9,23)` | 지역 산소 설비 재료를 추가로 조달한 구리 자리 |

문이 열려도 완공된 출입문은 구조적 방 경계로 유지됩니다. 실제 기체·물은 열린 문을 통과합니다. 초기 한 대의 상층 확산기와 문 열기만으로는 먼 생활 구역에 산소가 충분히 도달하지 않아, 추가 광맥을 실제로 수거한 뒤 방 안에 확산기를 보강했습니다. 방을 나누는 일과 생활 환경을 공급하는 일은 함께 필요합니다.

조리대의 목표는12끼이며 한 배치가3끼여서 저장 시 조리식은 약13.3끼입니다. 나루는 운반/주간/굴착1, 모아는 조리/중간/생활1, 솔은 운영/야간/공학1을 사용합니다. 각 대원은 작업으로 레벨6까지 성장했고 미배분 포인트5개씩이 남아 있습니다. 역할은 선호도이며 필수 생활 행동과 다른 필요한 일을 계속 수행합니다.

저장 시 실제 휴대 호흡은 합계617.9초, 산소 압축61.9655, 충전소→휴대통 이송43.9655, 실제 휴대 소비33.9845입니다. 충전소에는18, 대원 통에는 합계9.981이 남아 있습니다. 이송된 산소는 남은 휴대량과 실제 소비의 합계이며 중복 생산하지 않습니다.

입고한 고체는 공용 비축입니다. 예제의 채굴품은 이미 모두 수거했으므로 물류 화면에 바닥 더미가 없을 수 있습니다. 새 블록을 채굴하면 더미→화물→거점 입고를 다시 관찰할 수 있습니다. 마지막 확산기 두 대에 금속을 사용해 공유 금속은0이므로 더 건설하려면 새로운 광맥을 탐사해야 합니다.

## 실제 추가10주기 기록

같은 저장을1,200초 더 운영해 게임 시간3,388.5초에 확인했습니다.

| 항목 | 첫 승리 | 추가10주기 뒤 |
|---|---:|---:|
| 완료 목표 / 살아 있는 대원 | 20 / 3 | 20 / 3 |
| 대원 건강 | 전원100 | 전원100 |
| 전체 식품 | 약96.8끼 | 약130.3끼 |
| 실제 수확 누계 | 91.5끼 | 145.5끼 |
| 조리 누계 | 51끼 | 75끼 |
| 식탁 식사 | 36회 | 60회 |
| 계획 수면 | 32회 | 57회 |
| 유효한 침실 휴식 | 199.7초 | 534.7초 |
| 유효한 식당 식사 | 15회 | 39회 |

전체 기간 최저 건강은100, 최저 식품은 약96.65끼였습니다. 하층 농장 세 곳은 각각9회씩 수확했으며 최대 지면 물은0.1333 미만으로 농장 중단 임계0.5보다 낮았습니다. 추가10주기 동안 휴대 산소 소비는 증가하지 않았습니다.

완료 목표와 승리 이력은 유지되지만 현재 생활 조건은 계속 바뀝니다. 마지막 정착·확장 유지 시간은 각각140.8초이며,10주기 내내 모든 연속 조건을 유지했다는 뜻은 아닙니다. 정확한 재고·생산·대원 상태·현재 미달 이유·농장 기록은 [validation-report.json](validation-report.json)에 있습니다.

## 재생성

프로젝트 루트에서 다음 명령을 실행합니다.

```sh
node examples/generate-example.mjs
```

`tests/scenarios.mjs`의 새 기지→실제 채굴·운반·건설·교대·문 제어·기술 배분 경로를 실행합니다. 첫 승리 저장을 정확히 왕복하고 이후10주기 생존·농업·조리·식사·수면·실제 방 사용을 검증한 뒤 두 JSON을 갱신합니다. 실제 v1·v2·v3 엔진에서 보존한 `tests/fixtures/`의 여섯 원본 저장은 수정하지 않습니다.

전체 회귀는 `npm test`로 실행합니다. 상세 건설 순서·비용·수지는 프로젝트 [README](../README.md), 새 방과 장비 안내는 [방·장비·안전한 확장](../docs/rooms-and-expansion.md)에 있습니다.
