# Campaign Edition 4.0

## 캠페인의 마지막 길

- 무전기 복구·구호팀 교신·대피 물자 봉인의 3단계 선택 목표를 추가했습니다.
- 단계마다 날짜·선행 조건·실제 비용과 작업 시간을 사용합니다. 일반 작업과 동일하게 예약·중단·환급되며 중복 보상은 차단합니다.
- 교신 다음 아침에 식재료 2·약품 1·붕대 1·연료 2를 한 번 지급합니다. 보급은 난방·습격 이후 정산하고 재고 변화에 포함합니다.
- 12일 생존 조건을 유지하면서 준비 상태가 마지막 대피와 개인 후일담에 남습니다.
- 구호 화면에서 담당자를 고르고 실제 시간, 진행 중·예약됨·완료 상태를 확인할 수 있습니다.
- 현재 건강·질병·허기·난방·피로·문 상태·식사를 바탕으로 필요한 행동을 최대 4개 안내합니다.

## 싸움을 피할 수 있는 현장 행동

- 부품 1개를 던지는 소음 유인과 T·탭 조준을 추가했습니다. 조준 중 시간 정지, 취소 시 미소비, 성공 후 시간 재개를 적용합니다.
- 같은 층의 현재 보이는 범위 안에서만 던질 수 있고, 문·거리·동작·가방·재사용 조건을 검사합니다.
- NPC는 소리의 착지점으로 걸어가 조사합니다. 플레이어를 이미 보는 경우와 공격 중 행동을 우선하며, 기존 적대 상태는 유지합니다.
- 은신 중 투척, 재사용 8초, 유한한 소리 표시·조사 시간, 저장 후 계속하기를 지원합니다.
- 소음 유인 사용 횟수를 아침 보고와 캠페인 통계에 남깁니다.

## 탐색 정보와 표현

- 탐험한 구간, 발견한 사물과 현재 보이는 사람을 사용하는 미니맵을 추가했습니다.
- 귀환선은 실제로 확인한 계단·구간에 한정하며 첫 닫힌 문 앞에서 끊어집니다.
- 유인 조준 궤적·착지 소리, 복구한 무전기·교신 상태·대피 꾸러미를 Canvas에 표시합니다.
- 미니맵 전체를 클릭 판정에서 제외하여 지도 위 클릭이 이동·투척으로 새지 않게 했습니다.
- 지도 표시와 화면 움직임 줄이기 설정을 제공합니다.

## 저장·검증·문서

- 구호 단계의 날짜·보급 이중 지급·작업 비용·동시 작업을 검증합니다. 이전 저장에는 새 필드를 기본값으로 보완합니다.
- 유인 필드와 현장 결과의 허용 범위를 맞추고, 유인 중 저장·복원과 캠페인 정산을 함께 검사합니다.
- 자동 테스트 158개, 단일 HTML UI 검사 통과. 실제 API로 기본 완주 6회와 구호 준비 완주 4회를 수행했습니다.
- 브라우저에서 무전기 복구→야간 투척→물자 회수→정상 귀환→다음 날 진행을 확인했습니다. 세부 범위와 남은 확인 사항은 [VALIDATION.md](VALIDATION.md)에 적었습니다.
- 시스템별 한국어 명세를 5개로 확장하고, 단일 실행 HTML과 전체 소스 ZIP을 갱신했습니다.

# Core Edition 3.0

## 전투의 위험을 읽고 대응하기

- NPC는 0.55초의 공격 예고 후 거리·시야·문·회피 상태를 다시 검사해 피해를 적용합니다.
- 플레이어에게 스태미나를 추가했습니다. 공격 22, 회피 28을 사용하며 조건을 만족하면 초당 14를 회복합니다.
- Q 회피는 0.26초의 유한 이동, 0.18초의 회피 판정, 2.4초의 재사용 대기를 갖습니다. 닫힌 문·계단·세계 경계를 지킵니다.
- 보이는 적의 예고 원호, 회피 자세·잔상, 스태미나와 재사용 상태를 Canvas와 UI에 연결했습니다.

## 주민과의 비폭력 선택

- 진료소·정비소·아파트의 주민에게 R 또는 대화 카드로 말을 걸 수 있습니다.
- 무료 통행 요청과 물자를 건네는 도움·교환을 구분합니다. 출입 허락만으로 사유 물자를 가져갈 수는 없습니다.
- 도움 또는 교환 중 한 번을 완료하면 보상과 지정 보관함 이용 권한을 얻습니다. 재방문·저장 복원으로 보상을 반복 획득하지 못합니다.
- 가방의 비용과 보상 후 최종 칸을 검증한 다음 물자·권한을 함께 반영합니다.
- 주민을 공격하면 허락이 철회되고 적대 관계가 다음 방문에도 남습니다. 도움 기록은 캠페인 통계와 후일담에 연결됩니다.
- 출발 화면에서 물·식사·약품·부품도 챙길 수 있습니다.

## 은신처 유지와 캠페인

- 문 내구도는 실제 습격 때만 줄며 막아낸 습격에도 마모가 남습니다. 문 보강의 방어 효과가 내구도에 비례합니다.
- 은신처 수리: 목재 2·부품 1, 기본 70분, 내구도 최대 35 회복. 윤의 건설 시간 특성과 예약·취소를 지원합니다.
- 새 게임에 표준·봉쇄 난이도와 선택적인 생존기 번호를 추가했습니다. 진행 중 난이도는 고정됩니다.
- 봉쇄는 출발 물자가 줄고 허기·습격 확률·강도·마모가 증가합니다. 실제 수치와 차이를 시작 화면에 표시합니다.
- 개인별 후일담은 생존·부상·질병·사기·공동체의 선택에 따라 달라집니다.

## 결과와 조작

- 밤 보고서에 출발 직전 대비 재고 순증감, 세 인물의 건강·포만·기력·사기·질병 변화가 추가됐습니다.
- 밤 예측에 문 내구도와 습격 발생 시 손상 범위를 표시합니다.
- 야간 패널을 앞으로 배치하고, 작은 화면의 방향·조사·회피·공격 버튼을 화면 하단에 고정했습니다.
- 여러 터치 포인터를 따로 추적해 한 손가락을 떼어도 다른 손가락의 이동 입력이 사라지지 않습니다. 이동을 누르는 동안에도 야간 HUD를 갱신합니다.
- 일시정지한 상태에서 Canvas 주민 대화를 열어도 대화 종료 후 정지 상태를 유지합니다.
- 결말 화면에서 난이도를 고르는 새 생존기 설정을 열고 취소·재시작할 수 있습니다.
- 키보드에 Q 회피, R 주민 대화, B 응급처치를 추가했습니다.

## 저장과 배포

- 구 저장은 표준 난이도·내구도 100·안정된 전투 상태·빈 대화 이력으로 이행합니다.
- 저장소 쓰기가 실패해도 자동 저장은 5초 간격을 지키며 매 프레임 재시도하지 않습니다.
- 같은 생존기 번호라도 난이도가 다르면 아침 기록을 섞지 않습니다. 명시적 새 게임은 같은 번호로 재도전해도 백업과 아침 기록을 새로 만듭니다.
- 전체 소스, 단일 HTML, 시스템별 구현 명세를 함께 갱신합니다. 검증의 실제 범위와 결과는 `VALIDATION.md`에 기록합니다.

# Core Edition 2.0

## 낮의 계획과 동료 관리

- 작업 중인 인물에게 최대 3개의 다음 작업을 예약할 수 있습니다.
- 예약 가능 여부는 선행 작업의 완료, 시설 개선, 재료 생산과 남은 시간을 고려합니다. 예약 자체는 물자를 선점하지 않으며 실제 시작 시에만 차감합니다.
- 다른 인물이 재료를 써서 시작 조건이 사라지면 해당 예약을 건너뛰고 기록을 남깁니다.
- 미라를 포함한 생존자가 다른 동료에게 약품이나 붕대로 치료할 수 있습니다. 의료 보너스는 시전자를 기준으로 적용합니다.
- 건강·포만·기력·사기의 숫자를 표시하고, 현재 가장 급한 식사·치료·휴식과 시설 목표를 안내합니다.

## 밤을 준비하는 판단

- 계획 화면에 실제 방어 공식과 같은 값으로 경계 인원, 방어력, 예상 습격 강도와 확률을 표시합니다.
- 들고 나가는 장비를 뺀 은신처 재고로 계산합니다. 반출 물자로 지난밤 방어·난방을 소급 충족시키지 않습니다.
- 난방 연료와 침대 부족, 피로한 경비와 강한 습격 가능성을 경고합니다.
- 지도 선택에 방문 횟수, 조사한 상자, 확인한 잔여 물자, 발견한 잠금 상태를 표시합니다. 미확인 물자의 수량은 숨깁니다.

## 직접 조작 수색

- 문 열기·닫기·잠금 해제와 실제 길·시야 차단을 추가했습니다. 닫힌 문 너머로 이동·공격·물품 획득을 할 수 없습니다.
- 발견 전 구역은 어둡고, 방문한 구역과 발견한 물품은 기억합니다. NPC는 현재 시야에 들어온 경우에만 표시합니다.
- NPC는 추적 중 닫힌 비잠금 문을 잠시 뒤 열 수 있으며, 잠긴 문은 통과하지 못합니다.
- 상자의 물품을 가방에 들어가는 만큼 한 번에 담을 수 있습니다. 남은 물품은 현장에 그대로 남습니다.
- 안전한 곳에서 3초 응급처치로 체력 30을 회복할 수 있습니다. 완료 시 붕대 1개를 소비하고 12초 재사용 대기시간이 생깁니다. 이동·피격으로 중단되면 소비하지 않습니다.
- 발각·경고·은신 상태, 체력, 가방 점유와 남은 시간을 화면에서 확인할 수 있습니다.

## 물물교환

- 상인과 교환할 품목과 수량을 직접 선택합니다.
- 제공 가치와 요구 가치를 비교하며, 가격과 재고는 화면에 표시합니다.
- 상인은 유한 재고를 갖고, 직접 교환과 기존 꾸러미가 그 재고를 공유합니다.
- 구매·판매 가격 차이와 꾸러미 가격을 검증해 되팔기만으로 재고를 무한 증식시키는 허점을 막습니다.

## 저장과 실행

- 자동 저장 직전 정상 기록을 백업합니다. 기본 기록이 손상되면 백업과 아침 기록에서 복구합니다.
- 설정에서 현재 생존기의 하루 시작 시점으로 돌아갈 수 있습니다. 복구 전 기록 내보내기도 가능합니다.
- 기존 v1 생존 기록에 없는 새 필드를 보완합니다. 기존 진행 중 수색에는 새 문을 열린 상태로 넣어 경로를 보존합니다.
- CSS·아이콘·모든 JavaScript를 내장한 `last-light.html`을 제공합니다. 정적 서버 없이 브라우저에서 실행할 수 있습니다.
- 새 게임 첫 화면에 최소한의 진행 안내를 제공하고, 게임 중에는 실제 상태에 맞춰 준비 목표를 갱신합니다.

## 검증 범위

엔진·수색·저장·화면 연결에 대한 자동 테스트와 실제 Canvas 출력 검증을 수행합니다. UI 연결 테스트는 DOM 인터페이스를 모사하므로 실제 브라우저의 배치·접근성·터치 품질 검증을 대체하지 않습니다. 배포된 사이트는 기존 본인 전용 접근 설정을 유지합니다.
