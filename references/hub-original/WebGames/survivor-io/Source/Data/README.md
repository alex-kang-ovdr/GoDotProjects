# 탕탕특공대 상세 데이터 시트 (역기획/구현용)

## 중요: 데이터 신뢰도
- **원작 요소/수치 가정**: 이름·게임플레이 유형은 원작에서 알려진 요소를 바탕으로 정리했지만 수치는 실측이 아닙니다.
- **구현용 가정/가상 분포**: 개발 가능한 예제 사양입니다. 원작 공식 수치가 아닙니다.
- **미확인**: 현재 시점의 원작 버전, 국가별 상점, 이벤트, 공식 확률 공시를 확인해야 합니다.
- 과금 가격, 확률, 드랍 가중치, HP, 공격 계수, 쿨다운은 절대로 원작의 실제 수치로 인용하지 마세요.

## 파일 구성
엑셀 통합 시트와 시스템별 CSV, Markdown을 제공합니다. CSV는 UTF-8 BOM이며 ID를 기준으로 조인할 수 있습니다.

## 구현 권장
- WeaponDefinition, SkillDefinition, SkillLevelDefinition, EnemyArchetype, SpawnWave, EffectDefinition, LootTable, StoreProduct로 분리
- 원작 관찰 데이터와 개발 가정값을 별도 컬럼 및 버전으로 유지
- 과금 상품과 뽑기 확률은 서버 원장/스토어 API 및 지역별 공식 공시로 교체
- 스킬 진화 조건은 문자열 이름 대신 별도 EvolutionRecipe 테이블로 정규화
- 몬스터 스폰 및 VFX는 모바일 디바이스별 동시 객체 수 제한과 풀링 필수
