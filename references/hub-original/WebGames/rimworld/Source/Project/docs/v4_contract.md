# v4 구현 계약 — 제작·장비·교역

이 문서는 `변방의 기록`의 독자적인 브라우저 프로토타입 규칙이다. 원작의 수치나 동작을 그대로 복제한 명세가 아니다.

## 범위와 공통 자료

- 이전 v3의 생존·의료·소방·일정·연구·전력·구조선 목표를 유지한다. 신규 연구, 모집, 품질, 내구도, 탄약은 이번 범위에 넣지 않는다.
- 게임 저장 버전 4. v1·v2·v3 실제 저장을 가져온다. 새 게임의 은화는 60, 이전 저장에서 새 자원은 0이다. 기존 RNG·지도·진행 작업을 보존한다.
- 자원은 기존 5종 + `silver`, `rifle`, `armor`, `tool`. 공유 상수는 `dist/economy-data.js`의 `EXTRA_RESOURCE_LABELS`, `RECIPES`, `EQUIPMENT`, `TRADE_PRICES`이며 엔진에서 재수출한다.
- 새 업무 `craft`를 추가한다. 기본 제작 기술은 서윤 10, 도현 7, 미나 6이며 기본 우선순위는 모두 3이다. 이전 저장에도 같은 기본값을 넣는다.
- 작업대 `workbench`: 목재 20, 강철 8, 작업량 10, 내구도 120, 무전력·연구 불필요. 새 게임에 미리 배치하지 않는다.

## 제작

`state.industry = { bills: { [recipeId]: {mode:'count'|'maintain',target:0..99,paused:boolean} }, crafted: {tool:0,armor:0,rifle:0} }`.

기본은 `count / target:0 / paused:false`. 명령은 `bill {recipeId,mode,target,paused}`. 매개변수를 모두 검증한 뒤 수정하며, 변경한 레시피의 진행 작업은 안전하게 중단한다. 값이 완전히 같으면 작업을 중단하지 않는다.

- `count`는 앞으로 완성할 남은 개수다. 완료할 때 1 감소한다. 이미 진행 중인 작업 수를 고려해 초과 시작하지 않는다.
- `maintain`은 식별 가능한 총 보유량(창고 + 바닥 + 일반 운반 + 장착 장비)과 진행 중 제작 수를 합산한 목표다. 배송·장착 대기 중인 물품을 다시 만들지 않는다.
- 주문만으로 재료나 제품이 생기거나 차감되지 않는다. 주민이 접근 가능한 창고에서 재료를 실제 수령하고 작업대로 운반한다. 한 자원씩 운반하고, 작업에 전달된 자재는 제작 작업에 기록한다. 모든 재료가 준비되면 제작 기술에 따라 진행한다.
- 작업대는 한 번에 한 작업만 예약한다. 여러 작업대와 제작자의 경쟁에서도 중복 완성과 음수 재고가 없어야 한다.
- 완성품은 작업대 바닥에 놓인다. 운반 후 창고 재고가 된다. 입력 자재는 완료 시 소비하고, 완료한 작업의 정리 과정에서 다시 반환하지 않는다.
- 징집·일정·긴급상황·주문 변경·작업대 파괴·사망으로 중단하면 이미 수령한 운반물은 주민 위치, 전달한 재료는 작업대 위치에 한 번만 반환한다. 아직 수령하지 않은 창고 재료는 건드리지 않는다. 제작 진행도는 중단 시 사라진다.

## 장비

`colonist.equipment = {weapon:null|'rifle',armor:null|'armor',tool:null|'tool'}`. 기본 권총은 기존 전투 규칙을 유지하는 기본 능력이며 판매 가능한 물품이 아니다.

- `equip {id,item}`: 살아 있고 일어선 비징집 주민이 창고에 있는 장비를 가지러 가는 실제 강제 작업이다. 수령 후 1.5초 장착한다. 두 사람이 마지막 한 개를 요청해도 한 명만 받을 수 있다. 유효하지 않은 요청은 기존 작업을 중단하지 않는다.
- `unequip {id,slot}`: 같은 자격의 주민이 장비를 벗어 자기 위치 바닥에 내려놓는다. 장착 중 작업도 안전하게 중단한다. 같은 장비 반복 명령으로 능력치가 누적되지 않는다.
- 사망 시 장비를 바닥에 한 번 내려놓고 슬롯을 비운다. 이미 쓰러진 상태에서는 소유권을 유지한다.
- 소총: 사거리 9칸, 피해 ×1.35, 명중률 +0.04, 징집 사격 간격 1.2초. 민간인 자동 방어의 기존 반경과 피해 계수는 유지한다.
- 조끼: 총탄 피해와 총상 출혈 증가량 ×0.65. 화재·배고픔·온도에는 적용하지 않는다.
- 도구: 건설·수리·농사·채집·채광·제작의 실제 작업 진행량 ×1.25. 이동·조리·연구·의료·생활 회복에는 적용하지 않는다.

## 교역

`initializeTrade(game,{migration=false})`, `updateTrade(game,dt)`, `executeTrade(game,payload)`, `validateTrade(data,bad)`를 새 모듈에서 제공한다. `state.trade`에는 `nextVisitAt`, `visits`, `visitor`(없으면 null), `stats:{bought,sold,earned,spent}`를 둔다. 방문자 최소 필드는 `id`, `name`, `x`, `y`, `phase:'arriving'|'trading'|'leaving'`, `path`, `destination`, `arrivedAt`, `leavesAt`, `stock`, `silver`다. 세부 이동 필드는 구현 문서에 기록한다.

- 첫 방문 예정은 새 게임 80초, 이전 저장은 현재 시각 +80초. 안전한 지도 동쪽 가장자리에서 기지 외곽의 접근 가능한 만남 지점으로 이동한다. 도착 후 100초 머무르고 퇴장한다. 다음 방문은 퇴장 완료 시각 +220초다.
- 상인은 비전투 방문자다. 활성 습격 때 새 방문을 연기하고, 방문 중 습격이나 만남 지점 화재가 발생하면 안전을 위해 떠난다. 교역도 즉시 닫힌다. 영구 폐쇄 지형이면 재탐색을 제한하고 정상적으로 방문을 종료한다.
- 방문 생성·재고·이동은 저장 가능한 상태와 씨앗/방문 횟수로 결정한다. **기존 엔진 RNG를 소비하지 않아** 상인으로 기존 전투·환경 난수 흐름을 바꾸지 않는다.
- 기본 재고: 목재 30, 강철 24, 식재료 16, 식사 10, 약품 6, 도구 2, 조끼 2, 소총 2, 상인 은화 180. 가격은 공유 상수다. 식품은 구매만 가능하다. 음식을 되팔아 신선도가 회복되는 경로가 없다.
- `trade {traderId,side:'buy'|'sell',type,count}`. 수량은 1..100 정수. 현재 방문자의 정확한 ID, 거래 단계, 안전한 배송 위치, 살아 있는 비징집 주민의 왕복 가능한 접근, 재고·은화를 모두 확인하고 한 번에 교환한다. 오류는 어떤 자원도 변경하지 않는다.
- 구매는 창고 은화를 차감하고 상인의 해당 재고를 줄인다. 물품은 **상인 위치 바닥에 배송**하며, 운반 전에는 창고 재고로 쓰지 못한다. 신선한 구매 식품도 배송 뒤 기존 부패 규칙을 따른다.
- 판매는 **창고 수량만** 판매할 수 있다. 바닥·운반·장착·건축 선지급·제작 자재는 판매하지 않는다. 판매 대금은 **상인 위치 바닥의 은화**로 지급하고, 운반 후에 구매에 쓸 수 있다. 상인 은화도 실제로 감소하며 매입한 물품은 재고에 들어간다. 상인에게 지불한 구매 은화는 상인 잔고에 더한다.
- 은화는 1회 최대 100개 운반, 다른 물품은 기존 12개 운반. 방문이 끝나도 배송된 물품과 대금은 플레이어 소유로 남는다.
- UI가 읽는 방문/가격/경로 상태는 난수나 상태를 변경하지 않는다. 시간은 시뮬레이션 시각 기준이다.

## 검증과 파일 책임

1. 기존 61개 회귀와 기본 공개 명령 완주 유지.
2. 재료 경쟁·주문 초과 생산·모든 취소/파괴 시 소유권 보존.
3. 실제 장착 수령·소총/조끼/도구의 계산 효과·사망 반환.
4. 거래 양방향 재고/화폐 보존, 입력 오류/종료/부족 시 무변경.
5. 중간 제작·장착·상인 이동/거래의 정확한 저장 및 미래 재현.
6. 원본 fixture v1·v2·v3 SHA 보존. v3: `b5e4aca65d24333ec7147799c73082e31de38ea23c8a5deec82f30781e906e2c`.
7. 실제 app.js를 실행하는 Node DOM 대역과 Canvas 대역 검증. 실제 브라우저 시각 검증은 접근 제한이 해소되기 전까지 미확인으로 명시.

모듈 경계는 엔진·제작, 교역·환경·렌더링, UI·입력, 공유 상수, 수용 테스트로 분리한다. 변경한 JavaScript와 CSS의 캐시 버전은 모두 4.0.0으로 맞춘다.
