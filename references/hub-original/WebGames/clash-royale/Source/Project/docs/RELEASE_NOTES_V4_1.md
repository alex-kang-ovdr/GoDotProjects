# Crownfall Arena 4.1 — PC 도구와 모바일 화면

2026-11-16 · 화면 구성과 입력·연습 도구 개선

## 변경 결과

PC의 좌측은 설정·전역 치트, 중앙은 모바일 게임 화면, 우측은 대상 상세·실시간 통계·대상 치트로 구성했습니다. 좌측에서 세로·가로 모드를 선택할 수 있고, 가운데 게임 상단에도 방향 전환 버튼을 넣었습니다. 좁은 화면과 터치 중심 환경에서는 두 PC 패널을 함께 숨깁니다.

| 영역 | 기능 |
|---|---|
| 좌측 설정 | 화면 방향, 다음 대전 난이도, 캠페인·자유 대전·훈련·연습, 덱 편집 |
| 좌측 전역 치트 | 자유 연습 시작, AI 배치 켜기·끄기, 1·2·4배속, 내/양쪽 엘릭서 10, 모든 생존 타워 회복, 적 병력·건물 제거 |

| 우측 대상 상세 | 실제 HP, 공격 피해·간격·대기, 사거리·이동 속도, 배치 대기, 월드 위치, 상태 이상·공격 대상 |
| 우측 대상 치트 | 회복, 지정 피해, 제거, 3초 기절, 배치·공격 대기와 상태 이상 해제 |

## 세로·가로와 입력

세로 화면은 기존처럼 아군이 아래쪽에 있습니다. 가로 화면은 월드 `(x,y)`를 `(640-y,x)`로 투영해 아군이 왼쪽, 상대가 오른쪽에 놓입니다. 가로 손패는 전장의 오른쪽에 배치합니다. 전투 상태와 저장·리플레이의 논리 좌표는 변경하지 않습니다.

지형·다리는 방향에 맞춰 회전하고, 타워·유닛·HP·피해 숫자·주문 표시·독 타이머는 정방향으로 유지합니다. 클릭·터치·드래그는 캔버스의 실제 위치·여백·크기를 반영해 역변환합니다. 방향키도 화면 방향에 맞춰 이동하며, 전환 중이던 카드 드래그는 취소하여 다른 위치에 잘못 배치하지 않게 합니다.

대상 고정 선택과 hover를 분리했습니다. 마우스를 우측 도구로 옮겨도 선택이 유지됩니다. 대상 선택 도구 또는 Shift 클릭은 카드 배치와 구분됩니다. 사망·새 경기·저장 복원·리플레이 탐색 및 재시작 시 이전 개체 참조를 유지하지 않습니다. 일시정지 중 대상 선택 도구를 켜면 전투는 멈춘 채 덮개만 숨겨 다른 개체를 고를 수 있습니다.

숫자 입력·선택 상자·편집 요소 또는 Ctrl/Meta/Alt 조합에서는 전투 단축키를 실행하지 않습니다. 방향 설정은 브라우저 프로필에 저장합니다.

## 치트의 경계

치트는 자유 연습 전용입니다. 일반 대전·캠페인·훈련·리플레이·종료된 전투에서는 UI가 비활성화되고, 모듈에서도 다시 검사합니다. 연습 결과는 일반 전적·도전 메달·최근 경기 리플레이에 추가하지 않습니다.

치트가 실제 피해를 가하면 제거한 HP만 정상 피해 통계에 포함하고, 타워 사망·크라운·킹 활성화·승패는 기존 엔진 경로를 따릅니다. 자원 충전·회복은 사용 카드나 피해 통계를 만들지 않습니다. 회복은 이미 파괴된 대상을 부활시키거나 건물 수명을 새로 주지 않습니다. 일시정지는 유지하며 시간·tick을 임의 진행하지 않습니다. 연습 상태와 4배속도 기존 snapshot으로 저장·복원합니다.

브라우저 접근 정책 제한으로 이번 버전의 전체 페이지 클릭과 실제 모바일 터치·오디오·파일 저장은 검증하지 못했습니다. 독립 Canvas 출력은 웹페이지 전체 화면 캡처가 아니며, 실제 기기 FPS나 DOM 배치의 사용성을 입증하는 자료도 아닙니다. CSS는 소스 검토를 수행했으며 별도의 CSS 파서가 설치되어 있지 않아 파서 검사는 수행하지 않았습니다.

## 코드와 문서

- `dist/workspace.css`: PC 패널과 모바일 세로·가로 화면의 반응형 구성.
- `dist/js/app.js`: 방향 저장·전환, 입력·대상 선택, 도구 연결, 통계, 4배속 복원.
- `dist/js/renderer.js`: 화면 투영·역변환, 정방향 표시, 고정 대상 강조.
- `dist/js/debug.js`: 치트 검증·처리와 분리된 대상 조회.
- `dist/js/engine.js`: 연습 효과를 정상 피해·사망·종료에 연결하는 공개 API.
- [LAYOUT_AND_TOOLS.md](LAYOUT_AND_TOOLS.md): 화면과 도구의 전체 사용·개발 계약.
- [CORE_GAMEPLAY.md](CORE_GAMEPLAY.md): 유지되는 전투 규칙과 새 연습 API.
- [4.0 변경 기록](RELEASE_NOTES_V4.md), [3.0 변경 기록](RELEASE_NOTES_V3.md): 이전 버전 이력.

새 화면과 모듈은 단일 실행 HTML과 소스 ZIP에도 포함됩니다. 기존 게임 주소와 접근 범위를 유지합니다.
