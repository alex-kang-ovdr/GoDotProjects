# Breach Command · V2

**적의 공격 예고를 읽고, 메크의 위치와 장비로 전장을 바꾸며 도시를 지키는 브라우저 전술 게임**입니다. 세 편대 중 하나로 출격해 중간 작전의 위험과 보상을 선택하고, 다섯 번의 전투를 거쳐 최종 균열을 봉쇄합니다.

V2는 **3개 편대, 8개 작전 정의, 한 캠페인당 5전투·21턴**으로 구성됩니다. 파일럿 성장, 보조 장비, 분기 작전, 환경 위험, 포드 회수, 저장 파일 이동을 포함합니다. 전장과 유닛은 프로젝트의 SVG 코드로 그리며, 효과음은 브라우저에서 합성합니다. 외부 이미지·음원, 서버 API, npm 패키지 없이 실행합니다.

이 문서는 이 저장소의 구현을 설명합니다. Into the Breach의 전술 구조를 참고한 독립적인 웹 게임이며, 원작 전체의 콘텐츠·수치·캠페인·Advanced Edition 규칙을 복제한 제품은 아닙니다. 상세 데이터와 판정 순서는 [CORE_GAMEPLAY.md](docs/CORE_GAMEPLAY.md)에 정리했습니다.

## 빠르게 실행하기

`dist/index.html`을 브라우저로 열면 플레이할 수 있습니다. 개발 중에는 프로젝트 루트에서 정적 서버를 실행하면 같은 주소에서 저장을 이어 쓰기 편합니다.

```sh
python3 -m http.server 4173 --directory dist
```

브라우저에서 `http://localhost:4173`을 엽니다. 별도의 설치나 번들러 개발 서버는 필요하지 않습니다.

### 단일 오프라인 HTML

Node.js가 있는 환경에서 다음 명령을 실행합니다.

```sh
node scripts/build-offline.mjs
```

생성물은 `dist/breach-command-offline.html`입니다. 파일 하나를 복사해 인터넷 없이 플레이할 수 있습니다. 웹 버전의 저장 관리 화면에서도 오프라인 HTML과 전체 소스를 다운로드할 수 있습니다. 단일 HTML에서는 자기 자신과 소스 ZIP을 받는 링크를 숨깁니다.

빌드 스크립트는 CSS와 `campaign.js → engine.js → art.js → app.js`를 HTML 본문 끝에 포함합니다. 파일을 바꾸지 않고 입력·참조·단일 파일 구성을 검사하려면 다음 명령을 사용합니다.

```sh
node scripts/build-offline.mjs --check
```

소스의 동작을 수정한 뒤에는 오프라인 HTML을 다시 빌드해야 다운로드 버전에도 반영됩니다.

## 플레이 흐름

1. **새 작전**에서 편대·난이도·선택적 시드를 고릅니다. 보존한 베테랑이 있으면 첫 번째 메크에 배치할 수 있습니다.
2. 배치 화면에서 메크를 선택하고 하단의 유효한 칸으로 옮깁니다. 기본 배치로 바로 시작해도 됩니다.
3. 적의 공격 방향·순서, 출현 표식, 환경 예고를 확인합니다. **작전 브리핑**에서 필수 목표와 보조 목표를 읽습니다.
4. 메크를 이동한 뒤 주무기·보조 장비·수리 중 하나를 사용합니다. 무기를 먼저 쓰면 해당 메크의 이동도 끝납니다.
5. 목표에 마우스를 올리거나 터치하면 행동 결과와 이후 턴 종료 피해를 미리 확인할 수 있습니다.
6. 턴을 종료하면 **화염 → 환경 위험 → 적의 순서별 공격**을 처리합니다. 마지막 턴이면 작전을 완료하고, 그 외에는 증원과 다음 공격 예고를 처리합니다.
7. 정비 화면에서 보상을 확인하고 코어로 강화하거나 장비를 교체합니다. 다음 작전 카드를 고른 뒤 출격합니다.
8. 최종전에서는 열핵 폭탄을 5턴 동안 지킵니다. 종료 후 생존 파일럿 한 명을 선택해 다음 캠페인에 경험을 넘길 수 있습니다.

적을 모두 없애는 것은 공통 승리 조건이 아닙니다. 전력망 0, 메크 전멸, 최종전 폭탄 파괴 중 하나가 발생하면 실패합니다. **보조 목표 실패만으로 캠페인이 끝나지는 않습니다.**

### 여덟 작전

| 순서 | 작전 | 보조 목표와 선택의 차이 |
| --- | --- | --- |
| 1 | 해안 방어선 | 전력 손실 1 이하로 기본 전술 익히기 |
| 2 | 숲의 송전소 | 표시된 송전소 보호 |
| 2 | 침수 지대 회수 | 매 턴 2칸 침수, 추가 적, 회수 포드, 위험 보너스 |
| 3 | 사막 봉쇄선 | 유닛으로 출현 표식을 총 2회 차단 |
| 3 | 공습 유도 작전 | 매 턴 2칸에 피해 2 공습, 추가 적, 적 5기 제거 |
| 4 | 빙하 대피소 | 표시된 대피소 보호, 얼음 지형 활용 |
| 4 | 폭풍 속 회수 | 매 턴 3칸에 피해 1 폭풍, 알파 적, 회수 포드 |
| 5 | 최후의 균열 | 폭탄 방어. 지휘 개체 제거는 별도 보조 목표 |

중간 세 단계에서 각각 두 작전 중 하나를 선택하므로 경로 조합은 8가지입니다. 같은 단계의 두 작전은 기반 지도를 공유하며 목표·위험·추가 적·포드·일부 지형이 달라집니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 메크 클릭 / `1`·`2`·`3` | 메크 선택 |
| `M` | 이동 모드 |
| `A` | 주무기 모드 |
| `Q` | 보조 장비 모드 |
| 유효한 칸 클릭 | 이동 또는 선택한 무기 사용 |
| `R` | 수리. 기본 HP 1 회복, 화염·빙결·산성 해제 |
| `U` | 행동을 확정하기 전 마지막 이동 취소 |
| `Z` | 현재 턴의 시작 상태로 복구. 임무당 1회 |
| `Space` | 턴 종료. 적 행동 재생 중에는 결과로 건너뛰기 |
| `H` | 도움말 |
| 방향키 / `Enter` | 전장에 포커스가 있을 때 칸 이동 / 칸 선택 |
| `Enter` | 배치 단계에서 문서 본문에 포커스가 있으면 출격 |
| `Esc` | 대화상자 닫기 또는 목표 선택 해제 |
| `Tab` / `Shift+Tab` | 조작 요소와 대화상자 내부 포커스 이동 |

버튼이나 링크에 포커스가 있을 때 `Space`는 해당 요소의 기본 동작을 사용합니다. 터치 공격은 목표를 한 번 눌러 예측을 확인한 뒤 **공격 확정**이나 같은 목표를 다시 눌러 실행합니다. 저장 관리에서 마우스 공격에도 같은 확정 단계를 켤 수 있습니다.

작은 화면에서는 **전장 확대**를 켜고 가로로 스크롤해 칸을 자세히 볼 수 있습니다. **빠른 재생**이나 **결과 보기**는 연출만 줄이며 판정 결과를 바꾸지 않습니다. 운영체제의 동작 줄이기 설정도 연출에 반영합니다.

## 성장·보상·베테랑

### 코어와 정비

작전 성공 보상은 다음 항목의 합입니다.

```text
기본 2 + 전력 무손실 1 + 해당 작전의 위험 보너스
       + 성공한 보조 목표 보상 + 회수한 포드 수
```

포드 목표는 목표 자체의 코어 보상을 0으로 두고 **회수 포드당 코어 1개**를 별도로 지급합니다. 회수 즉시 보유 코어가 늘지는 않으며, 해당 작전을 완료해야 정산됩니다. 현재 작전 데이터에서 무손실·보조 목표까지 달성한 최대 보상은 일반 경로 4개, 위험 경로 5개입니다.

| 소비 | 비용 | 효과와 제한 |
| --- | --- | --- |
| 화력 강화 | 코어 2 | 주무기 피해 +1. 메크당 최대 2회 |
| 기동 강화 | 코어 1 | 이동력 +1. 메크당 최대 2회 |
| 내구 강화 | 코어 1 | 최대 HP +2. 메크당 최대 2회 |
| 보조 장비 교체 | 코어 2 | 충격파·보호막·산성 중 다른 장비로 교체 |

보조 장비는 별도의 추가 행동이 아닙니다. **주무기·보조 장비·수리는 같은 행동 한 번을 공유**합니다. 장비마다 작전당 1회 사용할 수 있고, 다음 작전에 들어가면 다시 충전됩니다. 기존 장비의 환불이나 예비 장비 보관함은 없습니다.

남은 코어는 다음 작전으로 이월합니다. 정비 진입 시 전력망은 표준에서 최대 1, 안정에서 최대 2만큼 회복하며 상한은 7입니다. 최종 승리 후에는 전력을 회복하지 않습니다. 다음 작전에서는 전투 불능 메크까지 전부 복구합니다.

### 파일럿

| 파일럿 | XP 2 / 계급 1 | XP 4 / 계급 2 |
| --- | --- | --- |
| 하린 `vanguard` | 임무 시작 보호막 | 최대 HP +1 |
| 태오 `engineer` | 수리량 1에서 2로 증가 | 최대 HP +1 |
| 서윤 `scout` | 이동력 +1 | 최대 HP +1 |

완료한 임무마다 세 파일럿이 XP 1을 얻고, 승급 효과는 다음 임무부터 적용됩니다. XP가 4를 넘을 수 있지만 계급은 2가 최대입니다. 이 구현에서는 전투 불능 메크의 파일럿도 보존되며, 다음 임무에서 메크와 함께 돌아옵니다.

캠페인 종료 화면에서는 **현재 생존한 메크의 파일럿 한 명**을 베테랑으로 보존할 수 있습니다. 보존 XP 상한은 4이며 다음 캠페인에서 첫 번째 메크에 배치할 수 있습니다. 코어·강화·장비·메크는 새 캠페인으로 이어지지 않습니다.

## 전술 규칙의 핵심

- 건물에 실제로 들어간 피해만큼 전력망이 감소합니다. 확률적 전력 방어는 없으며 시작 전력과 상한은 모두 7입니다.
- 밀치기는 공격 방향과 충돌 대상을 바꿉니다. 막힌 방향이나 전장 바깥으로 밀면 충돌 피해 1을 받습니다.
- 보호막과 빙결은 다음 피해 한 번을 막습니다. 둘 다 있으면 빙결을 먼저 소비합니다.
- 산성 유닛의 일반 피해는 2배로 계산한 뒤 장갑을 차감합니다. 충돌·화염·출현 차단의 고정 피해에는 이 증폭이 적용되지 않습니다.
- 연막과 빙결로 취소된 적의 공격은 그 턴에 연막 밖으로 나가거나 해동해도 복구되지 않습니다.
- 속박 거미는 예고한 인접 메크의 자발적 이동을 막습니다. 거미를 밀거나 공격을 취소시키면 속박을 해제할 수 있습니다.
- 불안정 벡은 제거될 때 상하좌우로 피해 1을 주며 연쇄 폭발할 수 있습니다.
- 지상 적은 물에 들어가면 제거됩니다. 지상 메크는 물에서 살아남지만 공격할 수 없습니다. 구덩이는 비행하지 않는 메크도 파괴합니다.
- 이동은 표시된 경로의 칸마다 지형 효과를 적용합니다. 도착 지점만 보지 말고 화염·산성·포드를 통과하는 경로도 확인하세요.
- 환경 위험은 적 공격보다 먼저 발동합니다. 적을 예고 칸으로 밀어내면 공격 전에 제거할 수 있습니다.

## 저장과 진행 이동

현재 작전, 턴 초기화 기준, 마지막 이동 취소 상태, 베테랑, 종료 기록을 브라우저에 자동 저장합니다. 같은 브라우저의 같은 주소에서 다시 열면 이어서 진행합니다. 설정도 별도로 저장합니다.

**저장 관리 → 진행 내보내기**는 현재 진행과 되돌리기 상태, 프로필을 JSON 파일로 만듭니다. 다른 브라우저나 오프라인 HTML에서는 **진행 불러오기**로 이 파일을 선택합니다. 가져오기는 파일 크기와 JSON·게임 상태를 검사한 뒤 현재 진행을 교체합니다. 잘못된 파일은 거부하며, 플레이 설정은 현재 브라우저의 값을 유지합니다.

이전 V1 저장도 읽습니다. 진행 중인 전장·턴·RNG·피해·강화는 유지하고 새 필드를 추가합니다. 기존 전투에 갑자기 새 환경 위험이나 보조 목표를 삽입하지 않으며, 이미 받은 보상을 다시 지급하지 않습니다. 다음 임무부터 V2 작전 선택을 사용합니다.

자동 저장은 브라우저 프로필과 주소 단위이며 기기 사이에 자동 동기화되지 않습니다. 브라우저 데이터를 지우기 전이나 실행 주소를 바꿀 때는 JSON을 내보내세요. `file://`로 연 오프라인 HTML의 저장 범위는 브라우저 설정에 영향을 받습니다. 저장을 사용할 수 없어도 열린 페이지에서 플레이는 계속할 수 있습니다.

## 점수와 기록

종료 점수는 다음과 같습니다.

```text
완료 임무 × 1,000 + 남은 전력 × 100 + 처치 × 25
                  + 회수 포드 × 150 + 남은 코어 × 20
```

표준·안정 난이도는 같은 공식을 사용합니다. 결과는 로컬에 최대 30개를 보관하며, **같은 시드·편대·난이도 조합은 한 번 기록**합니다. 경로와 베테랑 선택은 이 중복 판정 키에 포함되지 않습니다.

## 소스 구조와 공개 API

| 파일 | 역할 |
| --- | --- |
| [dist/campaign.js](dist/campaign.js) | 작전·파일럿·장비 데이터, 목표 평가, 보상 견적, 결정적 환경 예고 |
| [dist/engine.js](dist/engine.js) | 입력 상태를 보존하는 규칙 전이, 경로, AI, 전투, 성장, 검증과 이전 |

| [dist/index.html](dist/index.html) | 앱·대화상자·알림·파일 입력과 리소스 진입점 |
| [dist/style.css](dist/style.css) | 레이아웃, 반응형 화면, 확대와 시각 상태 |

| `tests/*.test.cjs` | 규칙·데이터·진행·저장 회귀 테스트 |
| `tests/playthrough-v2.cjs` | 공개 API만 사용해 선택 경로를 진행하는 재현 가능한 정책 실행 |

브라우저 로드 순서는 **`campaign → engine → art → app`**입니다. `campaign.js`와 `engine.js`는 CommonJS로도 사용할 수 있습니다. 상태를 바꾸는 엔진 API는 `{ state, events, error }`를 반환하며 입력 상태는 변경하지 않습니다. `createRun()`은 새 상태 자체를 반환합니다.

```js
const E = require('./dist/engine.js');
let state = E.createRun({ squad: 'gravity', difficulty: 'normal', seed: 20261114 });
state = E.beginBattle(state).state;
const forecasts = E.forecast(state); // 입력과 RNG를 소비하지 않는 턴 종료 예측
const objectives = E.getObjectives(state);
const result = E.endTurn(state, { trace: true }); // 최종 상태와 재생 프레임
if (!result.error) state = result.state;
```

장비 사용은 `command(state, { type: 'attack', slot: 'secondary', unitId, x, y })`, 장비 교체는 `equipSecondary(state, unitId, gearId)`, 작전 선택은 `nextMission(state, operationId)`를 사용합니다. 전체 API는 상세 문서의 표를 참고하세요.

## 검증 명령

프로젝트 루트에서 실행합니다.

```sh
node --test tests/*.test.cjs
node scripts/build-offline.mjs --check
```

테스트는 결정성·입력 보존, 경로와 지형 효과, 주무기·보조 장비, 속박·폭발·환경, 보조 목표와 정산, 분기 진행, 파일럿 성장, 저장 검증과 V1 이전을 다룹니다. 브라우저 조작·반응형 화면·파일 다운로드는 엔진 테스트와 별도로 확인합니다.

경로를 따라 실제 합법 명령을 실행하는 보조 검증도 제공됩니다.

```sh
node tests/playthrough-v2.cjs --squads=rift,control,gravity --routes=safe,risk --difficulty=normal --seed=20261114
```

이 스크립트는 제한된 탐색 정책의 결과를 보고합니다. 특정 실행의 승패는 편대·경로·시드와 정책에 따라 달라지며, 전체 밸런스의 보증으로 취급하지 않습니다.

이번 버전의 실제 검증 결과와 제한은 [QA_V2.md](docs/QA_V2.md)에 기록했습니다.
