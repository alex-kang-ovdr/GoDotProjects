# XXIII → XXIV 변경 기록

## 재현한 기존 오류

XXIII HTML을 Chromium에 넣어 실행했을 때 `Cannot read properties of undefined` 오류로 초기 콘텐츠 적용이 중단되었습니다. `applyContent`에서 만든 던전 인자에 `map`이 없는데 관문 검사에서 읽고 있었습니다. 이전 검증 버튼의 함수는 IIFE 외부에서 내부 `dungeon`을 참조했고, 2D 화면에도 WebGL 함수 `box3` 호출이 남아 있었습니다.

기존 WebGL 캔버스의 CSS 기준은 게임 화면이 아니라 버튼과 설명을 포함하는 section이었습니다. 확인한 뷰포트에서 원래 캔버스 높이는 약 545px인데 WebGL 레이어 높이는 1322px였습니다. XXIV에서는 같은 `.stage` 안에서 세 캔버스가 같은 영역을 사용합니다.

## 구조 변경

단일 파일에 덧붙였던 AI 래퍼를 제거하고, 상태·이동·전투·표시를 책임별 소스로 나누었습니다. 배포물은 여전히 하나의 HTML입니다. 렌더 호출과 60Hz 시뮬레이션을 분리했습니다. 프레임 지연 누적은 0.1초, 한 프레임의 보충 스텝은 6회로 제한합니다. 탭 전환과 포커스 이탈은 일시정지합니다.

## 행동 변경

후퇴 조향 뒤 일반 추격을 다시 적용하던 구조 대신 단일 전술 목표를 경로 탐색에 전달합니다. 분대의 최초 인원수는 사망한 개체 목록으로 다시 계산하지 않습니다. 시야, 관문, 몸체 반경, 발사체 충돌을 같은 맵 질의 계층에 연결했습니다.

원거리 직업도 기본 공격을 위해 근접해야 했던 구조를 바꿨습니다. 적 공격에 준비 상태를 추가했고, 적이 기절하면 준비 공격을 취소합니다. 보스 2개 체력 임계점에는 제한된 수의 소환 분대를 연결했습니다.

## UI 변경

클래스별 핫바, 상태 표시, 탭형 가방/스킬/기록, 옵션 비교 툴팁, 3D 피해 숫자, 원형 경고, 저장 JSON 이동, 모바일 화면 정렬을 추가했습니다. 기존 패시브 영역은 별도의 클릭 핸들러를 가지므로 버튼을 눌러 성장할 수 있습니다. 도움말/새 탐험 대화상자가 열려 있을 때 게임은 멈춥니다.

## 세이브 정책

기존 슬롯을 덮어쓰지 않는 v24 슬롯을 사용합니다. 세계 지형을 다시 생성하여 덮어쓰지 않고 저장된 맵과 진행 상태를 복원합니다. 버전 검증과 일부 구버전 보완 로직을 제공하되, 모든 실제 구버전 파일 호환을 주장하지 않습니다.

## 유지한 범위 / 변경하지 않은 범위

3직업, 5층, 경험치와 장비 성장, 물약, 분해·강화·각인, 단순 룬 조합, 상점, 사망과 부활을 유지했습니다. 기존 생성기의 기본 크기는 25×17 타일입니다. 방 개수와 배치는 Seed에 따라 달라집니다. 원작의 전체 기획 문서를 게임에 모두 반영한 상태가 아닙니다.
