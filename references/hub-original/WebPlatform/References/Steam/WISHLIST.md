# Steam 위시리스트 참고

- 조사/갱신일: 2026-11-16
- 플랫폼: Steam 웹 도움말·Steamworks 문서. 클라이언트 빌드는 특정하지 않음.
- 출처: https://help.steampowered.com/en/faqs/view/0CAD-3B4D-B874-A065
- 출처: https://partner.steamgames.com/doc/marketing/wishlist

## 확인한 사실

Steam은 관심 게임을 위시리스트에 추가·해제하고 별도 목록으로 관리하는 흐름을 제공합니다. 개발자 문서는 위시리스트를 게임에 대한 관심과 연결해 설명합니다. 이 분석에는 Steam 화면이나 이미지 자산을 복제하지 않았습니다.

## 해석과 PlayHub 적용

게임 카드·상세의 하트 버튼과 헤더의 전용 목록을 연결했습니다. 카드 이동과 찜 동작을 별도 버튼으로 구분하고, 중복 요청에도 결과가 변하지 않도록 서버에서 처리합니다. 게스트도 목록을 유지하고, 계정 연결 시 중복 없이 합칩니다. 가격·할인·발매 알림 기능은 현재 무료 웹게임 플랫폼 범위에 포함하지 않았습니다.

장점은 관심 게임을 다시 찾는 경로가 짧다는 점입니다. 관리할 게임이 비공개가 된 경우를 고려해야 하므로 목록 항목에 이용 가능 여부를 전달하고 해제는 허용합니다.

## 구현·검증

`wishlist_items` 저장과 사용자 격리, CSRF, 추가·제거 멱등성, 비활성 게임 처리, 게스트 병합은 HTTP 테스트로 확인합니다. 실제 브라우저에서도 찜 버튼 클릭이 SQLite에 저장되는 것을 확인했습니다. 관리자 화면은 선택 기간의 실제 추가·해제 이벤트를 집계합니다.

## 자료 사용 범위

위 URL의 문서는 기능 분석을 위한 참고입니다. Steam 로고·스크린샷·상업용 이미지를 수집하거나 재배포하지 않았으며 별도의 자산 사용 권한을 주장하지 않습니다.
