반영한 보안 변경

Windows 래퍼는 백업 생성 전에 Administrators/SYSTEM 전용 보호 DACL을 설정하고 icacls 종료 코드를 검사합니다. 기존 snapshot도 제한된 상위 ACL을 상속하도록 처리합니다. 이 동작의 실제 Windows 검증은 별도입니다.

POSIX CLI는 snapshot을 처음부터 0600으로 배타적으로 생성하며 metadata도 0600으로 기록합니다. 기존 snapshot 또는 metadata를 덮어쓰지 않습니다. Linux에서 실제 CLI로 파일 권한과 보존을 확인했습니다.

임시 DB, WAL/SHM, config, snapshot과 sidecar는 정리했습니다. 이 보고서에는 행 수와 검사 결과만 남깁니다.
