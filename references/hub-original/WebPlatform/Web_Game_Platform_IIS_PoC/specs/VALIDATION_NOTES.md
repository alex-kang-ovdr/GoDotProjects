# 계약과 문서 검증 기록

작성일 2026년 11월 16일. 아래는 v1 문서·계약 예제 검증 기록입니다. v2에서 추가한 실행형 PoC 검증은 27장과 실행 패키지의 docs/VALIDATION_STATUS.md·reports를 따릅니다.

## 수행한 검증

- 중앙 카탈로그·게임 manifest·분석 이벤트 JSON Schema의 자체 구조 확인.
- catalog와 manifest 예제의 입력 검증, 8개 ID와 경로의 대응 확인.
- 잘못된 스키마 버전·미허용 필드·경로 이탈·외부 URL·P0 Worker와 외부 통신·저장 설정·instructions 길이 등 잘못된 입력의 거부 확인.
- OpenAPI YAML 파싱, 참조, 경로 매개변수, 인증·CSRF·guest·collector·공개 launch descriptor와 저장 조건부 요청의 정합성 확인.
- D1·D7·D30의 정확일 계산, KST 자정 경계, 지연 수집 24시간, 성숙 분모, 중복 행, 게임/플랫폼 scope, 기간 이전 최초 활동의 의미를 가상 데이터로 확인.
- 원문 문서와 목록·인증·이벤트·단계별 범위의 교차 검토.
- 공식 레퍼런스 목록의 58개 URL을 공식 웹 자료에서 확인.

## 검증 범위의 한계

SQL은 SQLite의 동등 집계와 사전 기대값으로 의미를 검증했습니다. PostgreSQL 엔진에서 실제 실행한 결과가 아니므로 적용 시 입력 테이블·인덱스·시간대·쿼리 계획을 확인해야 합니다. OpenAPI는 구조·참조·정책을 검사했으며 실제 API 서버와 전체 표준 검증기를 실행한 결과는 아닙니다.

JSON Schema만으로 실제 파일의 존재, 카탈로그 ID와 폴더 ID의 관계, 심볼릭 링크 경로, MIME, 압축 해제량, 브라우저 실행이나 사용자 권한을 검증할 수 없습니다. CI 교차 검사와 서버 검증, 실기기 시험은 17장의 개발 완료 조건에 포함되어 있습니다.

기획서 HTML은 자체 포함 문서이며 플랫폼 애플리케이션이 아닙니다. v1에는 실행 코드를 포함하지 않았습니다. v2는 별도 Web_Game_Platform_IIS_PoC 패키지에 게임·로그인·저장·지표 수집·정적 SEO 코드를 제공합니다. 실제 Windows/IIS·브라우저·Google 인증은 대상 환경 검증으로 남깁니다.
