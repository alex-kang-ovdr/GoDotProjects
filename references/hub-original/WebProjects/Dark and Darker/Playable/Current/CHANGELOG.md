# v13 변경 기록

## 수정

- 던전 미생성 상태의 첫 렌더링 오류 제거.
- 시작 버튼이 기본 함수만 실행하던 연결을 완성된 초기화 경로로 교체.
- 과거 버전별 update/render/damage 중첩을 제거하고 단일 상태로 통합.
- 보스 공격 중복 처리, 모델 중복 렌더링 제거.
- 화면 가방 배치와 아이템 소유 상태의 불일치 제거.
- 재시작 시 전투·보스·전리품·상호작용 상태 초기화.
- 중복 결과 호출의 보관 골드 재지급 방지.
- 활의 무한 화살 보충 대신 유한 예비 화살을 소비하는 장전 적용.
- 가방·정지 화면에서 게임 공격 입력을 차단하고 마우스 잠금 상태 정리.

## 추가·개선

- 장검·단검·도끼 고유 공격 시간, 3타 콤보 입력 예약, 공격 활성 구간 판정.
- 검 날 다중 지점의 시간 분할 궤적, 신체 구체·방패 OBB·벽 AABB 충돌.
- 타이밍 방어, 반격 강화, 스태미나 부족 가드 붕괴, 양손 도끼 방패 제한.
- 네 적 유형, 관절형 저폴리 몸체, 이동·공격·피격·사망 절차적 자세.
- 군주 2단계, 내려찍기·휩쓸기·충격파 통합.
- 드래그·회전·장착·교체 취소·회수 가능한 버리기, 실제 24칸 가방.
- 돌·목재·금속 절차 재질, 횃불 색 광원, 안개, 개편된 HUD·설정·결과 UI.
- Seed 재현 가능한 던전과 별도 연습장.
- 자동 회귀 테스트, 검증 결과 JSON, 실제 WebGL 스크린샷.

## 정책 변경

- 원작의 세부 스킬·수치가 아니라 독립 프로토타입 규칙 사용.
- 탈출 후 아이템 지속 보관 대신 가치의 골드 자동 정산. 매 출전 기본 장비.
- 연습 및 치트 출전 골드 보상 없음.
- 동작 검증을 위한 `cryptDebug` 인터페이스 포함. 운영 보안 또는 멀티플레이 서버 권한 모델 아님.
