# RTK11 역기획 v3 — 데이터 재구축

v2 전체를 보존하고 검증 가능한 데이터 모델을 추가했습니다.

## 추가 파일
- `event_audit_matrix.csv`: 역사 이벤트 후보 25개 원작 검증 현황
- `event_conditions_prototype.csv`: 조건 75개 (설계 예시)
- `event_effects_prototype.csv`: 효과 50개 (설계 예시)
- `dialogue_v3_original_writing.csv`: 새로 작성한 대사 100줄
- `numeric_rules_audited.csv`: 주요 수치 23개 (확인 수준 표시)
- `normalized_schema.csv`: 10개 논리 테이블
- `EVENT_ENGINE_SPEC.md`, `DATA_DICTIONARY.md`, `TEST_CASES.md`

**중요:** 이벤트 후보는 실제 원작 구현을 검증한 목록이 아니며, 대사는 원작 대사가 아닙니다. 수치 신뢰도 medium은 실측 완료를 의미하지 않습니다.
