# 시나리오·초기 배치

> **원작 일치도 표기:** `확인`=원작 UI/공식 자료로 검증, `참고`=공략 자료 기반, `가설`=재구현 제안, `미확정`=실측 필요. 이 문서는 비공식 역기획이며 코에이테크모의 내부 명세가 아닙니다.

## 초기 데이터
시나리오 ID, 연월, 세력/군주, 도시·관문·항구 소유, 무장 소속·충성·상태, 도시 자원, 외교, 기교, 이벤트 플래그.
## 로딩 순서(제안)
정적 지도→무장 마스터→시나리오 델타→세력/도시 소유→관계→이벤트 상태→일관성 검사.
## 데이터 품질
모든 도시 소유 세력 ID 유효, 무장 중복 배치 불가, 죽은 무장의 활동 상태 금지, 출진 부대 좌표 중복 금지.
## 주의
전체 시나리오 시작 수치는 원본 게임/공식 데이터와 대조하기 전까지 빈 데이터 시트로 유지한다.

## 구현 인터페이스 공통 요구
- 모든 명령은 실행 가능 여부·소모 자원·상태 변경·이벤트 로그를 반환한다.
- 시나리오와 규칙 데이터를 로직에서 분리한다.
- 재현 실험에는 버전, 난이도, 시나리오, 날짜, 입력 상태, 결과 스크린샷을 첨부한다.
