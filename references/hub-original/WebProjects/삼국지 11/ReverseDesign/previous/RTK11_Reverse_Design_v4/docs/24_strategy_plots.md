# 전략 계략

> **원작 일치도 표기:** `확인`=원작 UI/공식 자료로 검증, `참고`=공략 자료 기반, `가설`=재구현 제안, `미확정`=실측 필요. 이 문서는 비공식 역기획이며 코에이테크모의 내부 명세가 아닙니다.

## 범위
도시/세력 대상으로 수행하는 이간, 유언, 유인, 이호경식 등 전략 계략을 전술 계략과 구분한다.
## 명령 데이터
`StrategyPlot {id,targetType,requiredOfficer,actionCost,goldCost,successRules,effects}`.
## 검증
대상 소속, 충성, 치안, 군주 관계, 성공/실패 후 정보 공개, 효과 지속 시간.

## 구현 인터페이스 공통 요구
- 모든 명령은 실행 가능 여부·소모 자원·상태 변경·이벤트 로그를 반환한다.
- 시나리오와 규칙 데이터를 로직에서 분리한다.
- 재현 실험에는 버전, 난이도, 시나리오, 날짜, 입력 상태, 결과 스크린샷을 첨부한다.
