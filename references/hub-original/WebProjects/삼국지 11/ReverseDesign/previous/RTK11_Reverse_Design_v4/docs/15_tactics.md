# 병과별 전법

> **원작 일치도 표기:** `확인`=원작 UI/공식 자료로 검증, `참고`=공략 자료 기반, `가설`=재구현 제안, `미확정`=실측 필요. 이 문서는 비공식 역기획이며 코에이테크모의 내부 명세가 아닙니다.

## 전법 목록(통용 일본어 표기 병기)
창병: 돌출(突出), 나선첨(螺旋突), 이단첨(二段突).
극병: 웅수(熊手), 횡치(横薙), 선풍(旋風).
노병: 화시(火矢), 관시(貫矢), 난사(乱射).
기병: 돌격(突撃), 돌파(突破), 돌진(突進).
## 기력 소모(검증 대기)
창병 15/20/25, 극병 15/20/25, 노병 10/15/25, 기병 15/20/25. 수치는 버전별 게임 UI에서 교차 검증한다.
## 전법 데이터
`Tactic {id,troopType,minAptitude,energyCost,range,allowedTerrain,hitRules,damageRules,displacement,statusEffect}`.
## 판정 순서
사거리/지형/적성/기력→성공→피해·위치 변화·상태이상→후속 충돌. 실제 내부 판정 순서 미확정.
## 테스트
대상 뒤 장애물, 밀치기 연쇄, 혼란 발동, 다수 대상, 화재 발생, 공격 실패 시 기력.

## 구현 인터페이스 공통 요구
- 모든 명령은 실행 가능 여부·소모 자원·상태 변경·이벤트 로그를 반환한다.
- 시나리오와 규칙 데이터를 로직에서 분리한다.
- 재현 실험에는 버전, 난이도, 시나리오, 날짜, 입력 상태, 결과 스크린샷을 첨부한다.
