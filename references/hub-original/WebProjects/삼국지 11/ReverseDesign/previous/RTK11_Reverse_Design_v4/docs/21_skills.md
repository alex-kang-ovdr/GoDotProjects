# 무장 특기

> **원작 일치도 표기:** `확인`=원작 UI/공식 자료로 검증, `참고`=공략 자료 기반, `가설`=재구현 제안, `미확정`=실측 필요. 이 문서는 비공식 역기획이며 코에이테크모의 내부 명세가 아닙니다.

## 설계 원칙
특기는 단순 능력치 보너스가 아니라 전투/계략/내정/이동/등용/연구 등 여러 명령의 규칙을 바꾸는 후크다.
## 대표 특기
신산, 허실, 귀모, 연환, 심모, 반계, 비장 등을 별도 데이터 ID로 관리한다. 무장-특기 매핑과 효과 세부는 원작 데이터 대조 후 확정한다.
## 적용 지점
`BeforeValidation`, `SuccessCheck`, `DamageModifier`, `AfterSuccess`, `OnDefense`, `OnTurnBoundary`.
## 테스트
동일 특기 중복 부장, 서로 상충하는 특기, 지력 동률, 간파와 연환, 공격·반격·지원 연계.

## 구현 인터페이스 공통 요구
- 모든 명령은 실행 가능 여부·소모 자원·상태 변경·이벤트 로그를 반환한다.
- 시나리오와 규칙 데이터를 로직에서 분리한다.
- 재현 실험에는 버전, 난이도, 시나리오, 날짜, 입력 상태, 결과 스크린샷을 첨부한다.
