# 이벤트·퀘스트·대사 설계

삼국지 11의 역사 이벤트는 일반 RPG 퀘스트 체계와 다르다. 따라서 `quest` 테이블을 원작의 정식 기능으로 단정하지 않는다.

## 이벤트 생명주기
후보 수집 → 원작 존재 여부 검증 → 발동 조건 역추적 → 실행 효과 검증 → 재발동/충돌 규칙 검증 → 데이터 확정.

## 조건 카테고리
- 시간: 연도·월·상순/중순/하순
- 세력: 존재, 군주, 관계, 동맹
- 도시: 소유, 점령, 인접 세력
- 무장: 생존, 소속, 신분, 친애/혈연
- 이벤트 상태: 기발동 플래그, 연쇄 선행 이벤트
- 플레이어 선택: 선택지별 결과

## 실행 효과
소유권 이전, 무장 소속 변경, 충성 변화, 외교 변화, 자원 변화, 대사/연출, 후속 플래그. 실제 지원 여부는 사건별 검증 필요.

## 대사 테이블
화자 ID, 장면 ID, 선택지 ID, 지역화 키, 조건, 문장, 출처/저작권 상태를 분리한다. v4의 16줄은 모두 신규 시연용 문장이다.

## 테스트
1. 필수 조건 하나만 거짓이면 발동 금지.
2. 중복 발동 금지.
3. 리소스 음수 방지.
4. 후속 이벤트는 선행 플래그를 요구.
5. 세력 멸망, 무장 사망, 도시 소유 변경 시 경계 처리.
