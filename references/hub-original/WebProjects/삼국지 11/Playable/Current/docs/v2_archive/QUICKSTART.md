# 3D 전장 빠른 시작

ZIP을 전부 해제한 후 `PLAY.html`을 여십시오. 서버·설치·로그인 없이 실행하도록 번들했습니다.

**3D 전투 훈련 → 공격 → 선택 부대 오른쪽 적 클릭**으로 전투를 확인할 수 있습니다.
`전투 시점`으로 확대하고 `넓게 보기(V)`로 패널을 접을 수 있습니다.

왼쪽 드래그는 이동, 오른쪽 또는 Shift+드래그는 회전·기울기, 휠은 확대입니다.
화면의 회전·확대 버튼은 터치 환경에서도 사용할 수 있습니다.

캠페인은 조조·유비·손책 중 선택합니다. 지도는 86×70, 도시 수는 42개입니다.
이동력이 두 배로 늘지는 않았으므로, 긴 진군에는 군량을 더 적재하거나 보급을 계획해야 합니다.

느릴 때는 품질을 **낮음**으로 변경하십시오. 2D 호환 모드로 표시되면 WebGL2를 초기화하지 못한 환경입니다.
코드에서 브라우저 보안 정책이나 GPU 설정을 강제로 바꾸지 않습니다.

상단 내보내기로 JSON을 백업하십시오. v1 JSON은 불러올 때 지도 좌표를 변환합니다.
원본 파일을 보관하십시오. 개발지 재배치로 시설 인접 보너스는 달라질 수 있습니다.
