# Into the Breach 산출물 통합 패키지 · V2

패키징: 2026-11-16 (한국 시간 기준)
구현 버전: Breach Command V2 · 2026-11-14 배포본

## 바로 실행

1. ZIP 전체를 압축 해제합니다.
2. 이 폴더의 **PLAY.html**을 브라우저로 엽니다.
3. 「작전 시작」 또는 「새 작전」에서 플레이합니다.

PLAY.html은 CSS와 JavaScript를 모두 포함한 단일 파일입니다. 별도 설치, npm 패키지, 서버 연결 없이 실행하도록 구성했습니다.

## 폴더 구성

| 위치 | 내용 |
| --- | --- |
| PLAY.html | 단일 파일 실행판 |
| game/dist/ | HTML·CSS·JavaScript 원본과 오프라인 실행판 |
| game/README.md | 실행·조작·규칙·구조 안내 |
| game/docs/CORE_GAMEPLAY.md | 시스템별 규칙·데이터·API·예외 명세 |
| game/docs/QA_V2.md | 테스트·완주 기록과 검증 한계 |
| game/scripts/ | 오프라인 HTML 빌드 스크립트 |
| game/tests/ | 자동 테스트, 캠페인 플레이 검증, 이전 버전 저장 표본 |
| reverse_design/ | 시스템별 상세 역기획 Markdown 22개 |
| MANIFEST.json | 파일 목록과 SHA-256 체크섬, 소스 버전 |

역기획 문서는 원작을 분석한 문서입니다. 웹 게임은 해당 전술 구조를 참고한 독립 구현이며 원작의 모든 콘텐츠를 재현하지 않습니다.

## 게임 구성과 저장

- 편대 3종, 작전 정의 8종, 캠페인당 5전투·21턴
- 이동·공격·수리, 보조 장비, 적 공격 예고, 지형·환경 위험
- 보조 목표·포드·코어 강화, 파일럿 성장과 베테랑 승계
- 자동 저장과 JSON 내보내기·불러오기, V1 저장 호환

다른 브라우저나 실행 위치로 진행을 옮길 때는 게임의 저장 관리에서 JSON을 내보내고 불러옵니다.

## 개발과 검증

소스의 기본 진입점은 game/dist/index.html입니다. Node.js가 있으면 game 폴더에서 실행합니다.

```sh
node --test tests/*.test.cjs
node scripts/build-offline.mjs
```

2026-11-14 검증 기록은 자동 테스트 70개 통과와 표준 난이도·시드 20261114에서 6개 캠페인 자동 완주입니다. 당시 실제 브라우저 화면·모바일 터치 검증은 미리보기 연결 문제로 보류되었습니다. 자세한 범위는 game/docs/QA_V2.md에 기록했습니다. 이번 패키징에서는 파일 일치와 압축 무결성을 확인했으며 게임 기능을 변경하지 않았습니다.
