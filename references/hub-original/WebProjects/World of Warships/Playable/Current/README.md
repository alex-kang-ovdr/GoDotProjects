# IRON TIDE V3 — 싱글플레이 해전

월드 오브 워십 역기획을 바탕으로 선정한 수상함 전투를 JavaScript와 Canvas 2D로 재구성한 독립 프로토타입입니다. **기초 훈련 → 작전·함종·장비 선택 → AI 함대와 전투 → 전투 평가·경험치 → 다음 출격 또는 3연전 원정**의 흐름을 제공합니다. 원작의 게임 데이터·아트·서버 코드를 사용하지 않습니다.

## 실행

- 배포된 웹 주소에서 바로 플레이합니다.
- 내려받은 소스에서는 **`dist/index.html`을 브라우저로 열면** 됩니다. 로컬 실행에 웹 서버·패키지 설치·빌드가 필요하지 않습니다.
- 런타임 외부 의존성과 원격 이미지·폰트 요청이 없습니다. 음향은 Web Audio로 합성하고, 그림은 Canvas와 SVG로 그립니다.
- 게임에는 계정 서버나 온라인 대전이 없습니다. 기록과 진행 중 전투는 해당 브라우저에 저장합니다.

## V3에서 완성한 흐름

- 실제 이동·명중·점령으로 통과하는 **5단계 기초 훈련**. 정지 표적은 일반 함체·장갑·HP를 사용하며 반격하지 않습니다. 단계마다 장면을 새로 시작합니다.
- **군도 원정**: 북쪽 군도 → 해협의 보루 → 외해 교전을 순서대로 승리합니다. 패배·무승부는 같은 단계를 재도전하며, 진행은 해당 브라우저에 남습니다.
- 표적을 명시적으로 선택하고 접촉 상실 시 마지막 위치를 유지합니다. **L 선행 조준**은 현재 관측 속도의 예상 지점을 한 번 설정합니다.
- 카메라와 조준 좌표의 변환을 일치시켰으며, V2 전투 저장을 V3로 복원합니다. V3에서는 무장·확산·조준점·조준경·선택 표적도 함께 저장합니다.
- 좌초 탈출·경계 선회·공격 가능한 AI 표적 선택·거점 명령 유지와 실제 포탑 정렬을 개선했습니다.

## 기초 훈련

항구의 **기초 훈련 시작**을 누르면 고정 순양함으로 훈련합니다. 항구에서 선택한 함종·장비는 유지됩니다.

| 단계 | 실제 통과 조건 | 핵심 조작 |
|---|---|---|
| 첫 항해 | 표시된 해역까지 직접 이동 | W 증속, A/D 조타 |
| 고폭탄 사격 | 플레이어 주포 HE로 정지 표적에 피해 | 1, 조준, 발사 |
| 철갑탄과 측면 | 플레이어 주포 AP로 측면 표적에 피해 | 2, 포탑 정렬, 발사 |
| 측면 어뢰 발사 | 오른쪽 표적에 어뢰를 실제 명중 | 3, 측면 발사각, 발사 |
| 거점 확보 | 플레이어가 거점 A를 실제 점령 | 이동 후 S 감속·정지 |

목표 달성 후 전투를 멈추고 다음 단계로 이동하거나 현재 단계를 반복할 수 있습니다. 다른 무장으로 표적을 먼저 격침하면 다시 도전할 수 있습니다. 부포나 화재·침수만으로 주포·어뢰 훈련을 통과하지 않습니다. 훈련 진도는 완료한 단계를 기억합니다. 이전 단계를 반복하다 나가거나 수료 후 다시 연습해도 이미 달성한 진도가 내려가지 않습니다.  다시 열면 미완료 단계의 새 장면에서 시작합니다. 훈련은 전적·XP·원정에 포함되지 않으며, 저장해 둔 일반 전투를 덮어쓰지 않습니다.

## 군도 원정

항구의 **원정 시작하기**는 현재 선택한 난이도로 새 원정을 시작합니다. 시작한 원정의 난이도는 끝까지 고정됩니다. 함종과 장비는 각 출격 전에 바꿀 수 있습니다. 자유 작전 선택은 원정 단계에 영향을 주지 않습니다.

승리할 때만 다음 해역으로 진행합니다. 패배·무승부에서는 같은 해역에 재출격하며, 결과 화면이 다음 행동을 설명합니다. 항구 복귀 후에는 원정 카드에서 이어할 수 있습니다. 진행 중 전투를 이어 하는 버튼은 현재 전투 중간부터, 원정 카드의 버튼은 현재 단계의 새 전투부터 시작합니다.

세 해역을 모두 승리하면 완주 횟수와 이번 원정의 시도 횟수·누적 피해·XP를 확인합니다. 완료 후 새 원정을 시작할 수 있습니다. 일반 전투와 동일한 XP 계산을 사용하며 원정 자체의 전투 능력 보너스는 없습니다. 원정 진행과 경력 기록은 같은 저장 객체에서 갱신되어 중복 결과가 단계를 두 번 넘기지 않습니다.

## 작전 선택

모든 작전은 플레이어와 AI 아군 2척 대 적 AI 3척입니다. **플레이어 기함 격침은 즉시 패배**, 적 함대 전멸은 즉시 승리입니다.

| 작전 | 규칙 | 제한 시간 | 전술 특징 |
|---|---|---|---|
| 북쪽 군도 | A·B·C 거점, 250점에서 시작해 800점 선취 | 8분 | 세 항로에 전력을 나누고 섬 뒤로 우회 |
| 해협의 보루 | 중앙 B 거점, 180점에서 시작해 640점 선취 | 7분 | 단일 목표를 둘러싼 엄폐·집중사격·지원 |
| 외해 교전 | 거점 없음, 적 함대 격파 | 5분 | 넓은 사격각과 제한된 엄폐; 시간 종료 시 팀 잔존 HP 비율 비교 |

거점 안에 양 팀 함선이 함께 있으면 점령이 경합됩니다. 북쪽 군도와 해협의 보루에서는 제한 시간에 팀 점수를 비교합니다. 외해 교전의 시간 종료 판정은 각 팀의 **남은 총 HP / 시작 총 최대 HP**를 비교합니다.

## 함종과 장비

| 함종 | 역할 | 특수 능력 |
|---|---|---|
| 구축함 해오름 | 빠른 기동, 어뢰 공격, 근거리 교란 | 연막 |
| 순양함 청해 | 균형 잡힌 주포·어뢰, 근거리 지원 | 음파 탐지 |
| 전함 백야 | 높은 내구도, 장거리 대구경 포격 | 음파 탐지; 어뢰 미탑재 |

장비는 처음부터 모두 사용할 수 있으며 **플레이어 함선에만** 적용합니다. 단순한 상위 장비 대신 성능 교환을 제공합니다.

| 장비 | 이점 | 비용 |
|---|---|---|
| 표준 장비 | 기본 성능 유지 | 없음 |
| 포술 특화 | 주포 재장전 12% 단축 | 최대 속도 6% 감소 |
| 생존 특화 | 최대 HP 10% 증가 | 주포 재장전 8% 증가 |
| 기동 특화 | 최대 속도 10%, 선회 성능 15% 증가 | 최대 HP 8% 감소 |

난이도는 입문·표준·베테랑으로 선택합니다. 기본 출격 속도는 전진 2단이며, W로 증속하거나 S로 정지·후진할 수 있습니다.

## 조작

| 입력 | 동작 |
|---|---|
| W / S | 기관 출력 한 단계 증가 / 감소 |
| A / D | 좌현 / 우현 조타 |
| 마우스 이동 | 조준 위치; 표적 선택은 바꾸지 않음 |
| 적 함체·이름표 클릭 / 터치 | 현재 보이는 표적을 선택; 마우스 클릭은 사격도 수행 |
| 왼쪽 클릭 유지 / Space | 선택 무장 발사; 준비되면 반복 사격 |
| 마우스 휠 | 전투 시점 확대·축소 |
| 1 / 2 / 3 | 고폭탄 HE / 철갑탄 AP / 어뢰 |
| Q | 피해 복구반: 화재·침수와 일반 모듈 손상 해제 |
| R | 수리반: 실제 회복 가능한 피해만 점진적으로 회복 |
| E | 함종 능력: 연막 또는 음파 탐지 |
| Tab / 표적 선택 버튼 | 현재 보이는 적 표적 순환 |
| L / 선행 조준 버튼 | 선택한 표적의 현재 속도로 예측한 위치를 한 번 조준 |
| M | 전술 지도 전환 |
| V | 쌍안경 조준 시점 전환 |
| C | 어뢰의 좁은 / 넓은 확산 전환 |
| F | 선택한 적에 아군 집중 공격 지시 |
| G | 거점 점령 지시 순환; 외해 교전에서는 기함 집결 |
| P / Esc | 일시정지·재개 |

전술 지도에서 거점을 누르면 아군에게 그 거점의 점령을 지시합니다. 집중 공격 지시는 현재 탐지된 적에게만 내릴 수 있습니다. 지시는 25초 동안 유지되며 새로운 지시로 교체됩니다. 점령 지시를 받은 AI는 거점 안에서 감속해 실제 점령을 유지하며, 가까운 위협·충돌 회피 상황에는 기동합니다.

모바일에서는 화면 버튼으로 조함합니다. 바다를 누르거나 끌어 조준한 뒤 **FIRE**를 누르세요. 화면의 무장·복구·쌍안경·확산·지시 버튼도 터치로 동작합니다. 다른 탭이나 창으로 이동하면 전투가 자동으로 일시정지합니다.

## 전투 판정

### 사격 준비와 탄종

조준점과 HUD가 사거리, 섬에 가린 사선, 포탑 정렬, 사용할 수 있는 포문, 재장전, 예상 비행 시간을 보여 줍니다. 사거리 밖이나 차단된 사선에는 발사하지 않습니다. 포탑 발사 허용 오차는 약 1.43도(0.025라디안)이며 정렬 중에는 예상 남은 시간을 표시합니다. 한 번 누른 발사 입력은 짧은 정렬 대기만 허용하고, 긴 재장전 뒤 발사하려면 버튼을 계속 누르거나 다시 누릅니다.

선체 측면을 적에게 향하면 더 많은 주포를 쓸 수 있지만, 적의 AP 공격에 유리한 각도를 내줄 수 있습니다.

HE는 직접 피해와 화재를, AP는 입사각·장갑과 명중 위치에 따른 관통·과관통·도탄·집중방호구역 피해를 제공합니다. 탄착까지 시간이 걸리므로 움직이는 표적의 예상 위치를 조준해야 합니다. CA·BB의 부포는 탐지된 근거리 적을 자동 공격합니다.

어뢰는 측면 발사각을 갖습니다. 구축함은 선수 기준 좌우 **30–150도**, 순양함은 **45–135도** 범위에서 발사합니다. 좁은 확산은 집중 명중, 넓은 확산은 회피 경로 차단에 유리합니다. 어뢰는 이동 구간 전체를 검사해 빠른 이동 중에도 함체 충돌을 놓치지 않도록 처리합니다.

선행 조준점은 관측한 속도·방향이 계속된다는 가정으로 계산합니다. L을 누른 뒤 적이 선회하면 다시 조준해야 하며, 자동 추적·자동 발사를 수행하지 않습니다. 어뢰를 선택하면 어뢰 속도를 사용합니다. 선택 표적이 시야에서 사라지면 다른 적으로 자동 전환하지 않고 마지막 관측 위치를 유지합니다.

직접 명중 결과는 새로운 플레이어 명중 이벤트로만 표시합니다. 피해가 0인 도탄·비관통도 이유를 표시하며, 화재·침수·부포의 지속 피해는 별도 작은 누적 안내로 표시합니다. 이전 AP 명중 결과가 이후 화재 피해에 재사용되지 않습니다.

### 피해·수리·모듈

함체는 선수·중앙·선미 구획을 갖습니다. 동일 구획의 내구도가 소진된 뒤에는 해당 구획에 들어오는 직접 피해가 줄지만, 완전히 면역이 되지는 않습니다.

수리반은 잃은 HP 전체를 무조건 회복하지 않습니다. 피해 종류별 회복 가능량을 별도로 누적하고, 한 번 사용할 때 최대 HP의 18%까지 그 장부에서 회복합니다. 이 프로토타입의 회복 비율은 다음과 같습니다.

| 피해 종류 | 회복 가능한 비율 |
|---|---:|
| HE·부포 | 55% |
| 일반 AP | 50% |
| 집중방호구역·충돌 | 10% |
| 어뢰 | 35% |
| 화재·침수 | 100% |

기관·조타·주포에는 정상·손상·치명적 손상 상태가 있습니다. 모듈은 자동 복구되며 영구 파괴되지 않습니다. 주포 손상 중에는 장전 진행이 일시 정지됩니다. 피해 복구반은 일반 손상을 즉시 복구하지만, 치명적 손상은 남은 복구 시간을 기다려야 합니다.

이 숫자와 판정은 **브라우저 전투를 위한 독자적 간소화 규칙**이며 월드 오브 워십의 실제 함선 제원·내부 계산과 동일하다는 뜻이 아닙니다.

### 탐지와 정보

섬·탐지 거리·발포 노출·연막·소나가 시야에 영향을 줍니다. 탐지하지 못한 적의 실제 위치를 함선·표적 표시나 포구 화염으로 노출하지 않습니다. 미니맵의 마지막 접촉 위치는 현재 위치와 구분합니다. 어뢰 접근 경고는 플레이어 팀이 탐지한 적 어뢰를 바탕으로 표시합니다.

## 자동 저장과 이어 하기

- 전투 중 약 3초마다, 일시정지·항구 복귀·페이지 종료 때 진행 상태를 저장합니다.
- 페이지를 다시 열면 항구의 **진행 중 작전 계속하기**로 돌아갈 수 있습니다.
- 함선 상태, 재장전·소모품·손상 타이머, 발사체, 점수와 난수 상태가 저장 대상입니다.
- 재개 시에는 눌린 입력 상태를 초기화하고, 탄종·확산·조준 좌표·조준경·표적 선택은 보존합니다. V2 UI 저장이 없으면 저장된 함선 조준점을 사용하며 기본 HE/좁은 확산으로 시작합니다.
- V2 엔진 저장은 유효성을 검사한 뒤 V3 상태로 옮깁니다. 이미 발사한 발사체·난수·소모품·전투 ID를 유지합니다.
- 훈련 진도는 별도 저장하며 진행 중 자유·원정 전투를 보존합니다.
- 새 출격은 진행 중 전투 저장을 대체합니다. 전투가 끝나면 활성 전투 저장을 정리합니다.
- 저장은 해당 브라우저의 로컬 저장소에 있습니다. 브라우저 데이터 삭제, 다른 기기·다른 접속 주소, 저장소 제한은 별개로 취급합니다. 저장이 거부되면 자동 저장 안내에 실패를 표시합니다.

## 전투 평가와 함장 경력

전투 종료 시 피해량·격침·명중률·거점 점령, 무장별 피해, 달성 항목을 표시합니다. 별 평가는 최대 3개입니다.

1. 승리하면 별 1개.
2. 자신의 기본 함종 HP 절반 이상 피해를 주면 별 1개.
3. 남은 HP가 35% 이상이거나 거점을 하나 이상 점령하면 별 1개.

승리가 아닌 결과는 최대 별 1개로 제한합니다. 경험치는 피해·승리·거점·격침과 난이도로 계산하며 한 전투 보상에 상한을 둡니다. 계급은 소위 → 중위 → 대위 → 소령 → 중령 → 대령 순서입니다. 계급은 전투 능력치를 올리지 않습니다.

최근 전투 20개를 화면에서 조회할 수 있습니다. 동일 전투의 결과가 재처리되어도 경험치·승리 수를 중복 지급하지 않도록 별도 전투 ID 장부를 유지합니다. 보상 화면에는 실제로 증가한 XP를 표시하며 기록 저장 실패도 안내합니다. 작전별 최고 별 평가, 최고 피해, 승리 횟수와 최단 승리 시간도 분리해 기록합니다. V3는 난이도별 최고 별 평가와 함종별 출격·승리·최고 피해를 표시하며, 전투 기록에 장비와 난이도를 함께 남깁니다. V2에서 난이도를 알 수 없는 종합 기록은 임의로 특정 난이도 기록으로 배분하지 않습니다.

## 코드 구조

| 파일 | 책임 |
|---|---|
| `dist/operations.js` | 불변 작전·장비 데이터, 계급·보상·경력 정규화와 중복 지급 방지 |
| `dist/sim.js` | 이동·충돌·피해·탐지·AI·명령·승패·저장 상태 검증 |

| `dist/interaction.js` | UI 저장 검증, 함체·이름표 선택, 새 직접 명중 이벤트 요약 |
| `dist/render.js` | 바다·지형·함선·무장·구획·효과·조준점 렌더링 |
| `dist/game.js` | 입력·게임 루프·카메라·HUD·저장·결과·음향 |
| `dist/index.html` | 항구·전투·도움말·결과·전적 화면 |
| `dist/style.css` | 데스크톱·모바일 레이아웃과 시각 스타일 |
| `tests/simulation.test.cjs` | 코어 전투·저장/복원 검증 |
| `tests/operations.test.cjs` | 작전 배치·경로·장비·경력·원정·멱등성 검증 |
| `tests/training.test.cjs` | 실제 이동·발사체·점령을 통한 훈련 통과와 오판 방지 |
| `tests/interaction.test.cjs` | 저장된 조준·무장, 카메라 좌표, 터치 선택, 직접·지속 피해 분리 |

## 검증 실행

Node가 있는 개발 환경에서 다음 명령을 실행합니다.

```bash
node tests/simulation.test.cjs
node tests/operations.test.cjs
node tests/training.test.cjs
node tests/interaction.test.cjs
```

작전·경력 테스트는 초기 배치 안전성, 전함 크기의 여유 공간을 고려한 거점 접근 경로, 장비의 성능 교환, 계급 경계, 유한한 보상, 입력 데이터 정규화, 기록 20개 제한, 과거 전투의 중복 지급 방지, 저장소 오류 처리를 검증합니다. 전투 테스트는 이동·탐지·무장·피해·수리·모듈·작전 종료와 저장/복원을 검증합니다. 추가 회귀 검증은 실제 AI 좌초 탈출·경계 탈출·점령 완료, 가려진 최근접 표적 대신 교전 가능한 표적 선택, 정렬 전 발사 차단, V2 저장 이행과 V3 결정론적 재개, 원정 승리 조건, 다섯 훈련의 실제 완료를 다룹니다. 상세한 실행 결과는 `CHANGELOG.md`에 기록합니다.

## 범위

완성된 범위는 수상함의 싱글플레이 전투와 브라우저 로컬 경력 흐름입니다. 항공모함·잠수함, 온라인 동기화, 실제 함선 데이터 전체, 다층 3D 장갑과 정밀 신관, 서버 계정·상점·연구 트리는 포함하지 않습니다. 함선의 움직임·거리·사격 주기는 짧은 브라우저 세션에 맞춰 조정했습니다.
