# 전투 및 무기

## 1. 시스템 목적과 역할
무기는 자동 타격형·투사체형·범위형·지속장판형·회전형 등으로 분류한다. 공통 파라미터: 기본 피해, 쿨다운, 발사 수, 관통, 속도, 지속시간, 범위, 치명타, 넉백. 무기별로 최근접 적 추적 또는 고정 방향/주기 패턴을 적용한다.

## 2. 규칙과 구현 관점
대표 무기 예시: 쿠나이, 수호자, 축구공, 드릴, 번개, 화염병. 실제 진화 조합과 밸런스 값은 게임 버전 기준 별도 검증. 피해 계산 예시(추정): final = base × 공격력계수 × 스킬계수 × 치명타계수 × 방어보정.

## 3. 주요 상태/데이터
- 설정값은 코드에서 분리해 JSON 또는 데이터 테이블로 관리한다.
- 전투 중 상태 변화와 UI 표시 이벤트를 분리한다.
- 스테이지 시작, 일시정지, 사망, 클리어, 재시작 시 경계 조건을 처리한다.

## 4. 예외 및 QA 항목
- 프레임 드랍 및 일시정지/재개 시 시간 계산 오류가 없어야 한다.
- 중복 보상, 중복 이벤트, 객체 풀 재사용 후 잔존 상태를 검증한다.
- 실제 게임과의 일치 여부는 플레이 영상/버전별 실측으로 확인한다.

## 5. 역기획 검증 상태
- **대표 메커니즘**: 장르와 게임 플레이 관찰에 근거한 개념 분석.
- **구현 제안**: 원작 내부 코드가 아닌 재구성 설계.
- **미확정**: 세부 수치, 드랍 확률, 패치별 콘텐츠.
