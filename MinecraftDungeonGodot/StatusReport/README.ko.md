# Voxel Frontier 개발 현황 보고서

`dist/index.html`은 외부 호스팅 없이 내려받아 브라우저에서 열 수 있는 정적 개발 현황 보고서입니다.

보고서는 M05 스테이션 완료 기록, M06 S01 생존 샌드박스·F4 디버그 워크벤치, 최신 자동 검증, 성능 미달 항목, Minecraft급 절차 생성 다양성 게이트를 포함합니다. 외부 배포 설정이나 추적 코드는 포함하지 않습니다.

`milestones/index.html`은 M01–M06의 독립 웹 문서 목록입니다. 각 문서에는 해당 마일스톤의 실제 게임 플레이 스크린샷, 현재 상태, 검증 증거, 제한, 다음 게이트가 포함됩니다. `milestones/assets/`에는 보고서가 참조하는 로컬 PNG 증거를 보관합니다. ZIP에는 종합 보고서, 각 마일스톤 문서·스크린샷, 생존·채집·건축 분석 문서를 포함합니다.
