# 깊은 생성과 접근성 자체 검토 — 2026-09-08

이번 검토는 구현 에이전트의 코드·실행 증거 자체 검토이며 독립 리뷰어나 별도 에이전트 검토를 가장하지 않는다. Unreal 원본 코드는 수정하지 않았다.

## 발견 → 수정 → 재검증

- 초기 6시드 탐색 감사에서 오래된 높이맵, 건물로 다시 채워진 동굴 메타데이터, 구조물 중첩, 보호 경로 누락을 발견했다. shaping 높이와 최종 동작 높이를 분리하고 마지막 셀 재계산, feature 메타데이터 정리, 구조물 간격, 보호 계단/방을 추가했다.
- 강화한 128시드 검사에서 -56/-17의 출입구를 샘이 막았고 -40에서 건물 접근로가 보호 동굴을 채웠다. 샘의 건물 근접 배제를 추가하고 접근로 길이를 포함해 보호 영역 후보를 제외했다.
- 그 수정 후 17시드에서 작은 해안 코어의 샘 공간이 사라졌다. 보장 코어 최소 반경을 2→4로 확대했다. 샘 존재 조건을 완화하지 않았으며 수정 후 128시드 전체가 통과했다.
- 깊이 변경 뒤 게임플레이·저장 테스트의 고정 y 좌표가 지하로 들어가는 문제를 수정했다. 테스트용 배치는 최종 최대 높이+6을 사용한다. PackedInt32Array에 없는 `max()` 호출은 Array 변환으로 고쳤고 실패한 테스트 프로세스만 종료한 뒤 전체 검증을 반복했다.
- 동굴 하행 성공만으로 접근성을 판정하지 않도록 실제 W/Space 입력 왕복을 추가했다. 시드 1337/-7/42 모두 지하 방 도착과 지상 복귀·착지를 통과했다.

## 구현 경계

생성 버전 3은 평균 약 30블록 깊이의 지층과 Godot 내장 [FastNoiseLite](https://docs.godotengine.org/en/stable/classes/class_fastnoiselite.html)의 3D simplex/FBM 밀도 공동을 사용한다. 이전 세대 저장은 명시적으로 거부한다. 포맷 버전 자체는 2를 유지한다.

온도·습도·대륙성·침식·기이도 수평 표본에 깊이를 추가했지만 생물군 선택 함수는 아직 앞의 4개 축을 사용한다. 기이도는 지형 높이에 사용하고 깊이는 조회 계약으로 제공한다. 이를 Unreal의 모든 6축 생성 계약과 같다고 보지 않는다. 광맥은 moss/cobble 표식이며 도구·드롭 시스템은 후속 범위다.
