# 청크 렌더러 전환 자체 검토

2026-09-08. 구현 세션의 자체 코드 검토와 실행 검사이며 독립 리뷰어 검토는 아니다.

## 변경과 검증

GridMap 런타임을 16³ 청크 ArrayMesh/정적 삼각형 충돌로 전환했다. 시드 생성 기본값과 희소 편집 형식을 보존하며 최종 셀을 청크별로 인덱싱한다. 면 노출 상태는 편집 셀과 6축 이웃만 갱신하고 영향받은 청크의 메시·충돌을 교체한다. 같은 저장 반복 복원은 재생성이 없으며, 청크의 마지막 블록 삭제 시 이전 충돌도 제거한다.

동일 재질·시각·충돌 조건의 인접 면을 직사각형으로 병합한다. UV는 블록 수만큼 반복하므로 픽셀 밀도를 유지한다. 물은 충돌이 없고 잎은 투명하지만 고체인 레지스트리 규칙을 각각 적용한다. 청크 경계에서 양쪽 면이 중복되지 않으며 이웃 블록을 제거하면 필요한 면이 드러난다.

메시 검사 502개는 3³ 고체 쉘(54개 단위 면→6사각형), 6축 삼각형 방향, 음수 경계, 투명/충돌 정책, 사라진 청크 충돌, 변경하지 않은 청크 revision 보존을 포함한다. 96회 결정적 혼합 재질 편집 후 캐시와 전체 재계산을 대조하고, 병합 메시와 충돌을 단위 면으로 환산해 별도의 블록 이웃 계산과 정확히 비교한다.

## 측정 루프

첫 노출면 구현은 경계 편집 CPU P95 36.519ms로 실패했다. Greedy 병합만 추가하면 20.552ms였다. 국소 면 캐시를 추가한 후 최종 전체 검증에서는 6.690ms로 내려갔다. 캐시를 저장·복원 경로에도 연결했고 기존 단위 48개·저장 74개·128시드·렌더 입력 검사를 유지했다.

전체 근거: `Saved/Verification/20260908-200932-300`, `Verify.ps1 -RenderComparison`, 종료 코드 0. 각 backend는 같은 시드1337/크기185/셀168,156/기본 해시924137349를 생성하고 같은 카메라·64회 편집 시퀀스를 사용한다. 144개 청크, 노출 면101,560개가 최종 20,649개 사각형으로 병합됐다. 185전경은 전체 지형을 포함하며 기본 1인칭 HUD도 직접 확인했다.

- 새 청크: 준비 2.928865초, 갱신 CPU P95 6.690ms, 다음 렌더 프레임 표식 P95 8.088ms, 최대 작업 집합238.49MiB.
- 기존 GridMap: 준비 5.945577초, 편집 제출 CPU P95 0.014ms, 다음 렌더 프레임 표식 P95 16.875ms, 최대 작업 집합331.99MiB.
- 엔진 내부 static allocator 관측값은 각각122,484,232bytes/200,197,956bytes다. 이 수치는 OS 물리 메모리와 별개다.

GridMap의 제출 호출은 실제 재생성을 지연하므로 청크 동기 갱신 시간과 직접 같은 작업이라고 비교하지 않는다. `ready_ms`는 생성·렌더 구성 뒤 물리/프로세스 프레임과 frame_post_draw를 기다린 시점이다. `edit_to_frame_p95_ms`는 편집부터 다음 frame_post_draw까지의 CPU 관측 시간이며 GPU 실행 완료나 물리 스텝 완료 지연을 의미하지 않는다. 현재 64회 경계 시나리오에서만 목표16.7ms를 검증했으며 모든 지형·장기 세션에 일반화하지 않는다.

OS 메모리는 실제 `Godot_v4.7.2-stable_win64.exe`를 직접 실행하고 100ms마다 `PeakWorkingSet64`를 관찰했다. 이전 `20260908-200823-226`의 프로세스 메모리는 작은 콘솔 실행기를 관측한 잘못된 값(6.4MiB)이므로 폐기한다. 파일은 실패 계측 근거로 남기고 유효 비교에는 최종 폴더만 사용한다.

## 남은 검증

Unreal은 더 깊은 지형과 다른 생성 기능을 제공한다. 이 결과는 Godot GridMap 대비 최적화이며 Unreal 우위 달성 근거가 아니다. 6축 기후, 보호 연결 동굴, 구조물/feature 최종 일관성, 조작 패널과 챌린지 기능 동등성, 깊은 지형 성능을 계속 개발한다. 청크 스트리밍·비동기 메시 생성은 아직 구현하지 않았다.

구현에 사용한 엔진 API와 삼각형 방향 규칙은 [Godot ArrayMesh 공식 문서](https://docs.godotengine.org/en/stable/tutorials/3d/procedural_geometry/arraymesh.html)와 [ConcavePolygonShape3D 공식 문서](https://docs.godotengine.org/en/stable/classes/class_concavepolygonshape3d.html)를 확인했다.
