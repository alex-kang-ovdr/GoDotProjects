# 절차적 월드 생성 조사·기획·개발 루프 (2026-09-09)

## 조사 결론

Minecraft Bedrock의 공식 월드 생성 개요는 기반 지형 → 생물군 → 구조물 → 피처(나무·식생·샘·광석) → 하늘 → 최종 스폰이라는 레이어 순서를 설명한다. 기반 지형은 시드와 매끄러운 기울기 노이즈를 쓰고, 생물군은 높이·온도·습도·침식·weirdness 같은 신호와 지하 요소를 결합한다. Minecraft의 1.18 공식 소개는 산악 생물군이 지형과 기온에 맞고, 무성/드립스톤 동굴처럼 지하 생물군이 자연스럽게 형성되는 방향을 제시한다.

현재 Godot은 6개 기후장, 표면/지하, 광맥·샘, 보호 동굴망·6개 랜드마크와 결정성/접근성 검사를 이미 갖는다. 그러나 생물군과 거대 지형의 이유 있는 결합, 자연 동굴의 생물군별 정체성, 구조물/피처의 예약·충돌 계약, 스트리밍 경계는 Minecraft 수준이라고 판정할 근거가 아직 부족하다.

참고: [Minecraft World Generation Overview](https://learn.microsoft.com/en-us/minecraft/creator/documents/world-generation?view=minecraft-bedrock-stable), [Minecraft 1.18 world generation 소개](https://www.minecraft.net/en-us/article/new-world-generation-java-available-testing).

## 다양성 품질 목표

사용자가 제시한 Minecraft 세계 문서 수준을 **범주적 다양성 목표**로 채택한다. 현재 6개 생물군을 단순 색상 변형으로 늘리는 것이 아니라, 아래 다섯 층이 조합돼 서로 다른 탐험 결정을 만들어야 한다.

1. 지상: 해안/해양, 평원/초원, 숲, 건조 지대, 설원, 고지/산악을 각기 다른 고도·경사·표면·식생 규칙으로 생성한다.
2. 지하: 일반 동굴, 수직 협곡, 습윤/식생 동굴, 광물 지대, 위험·보상 지하 구조를 고도와 지상 생물군 조건에 따라 구분한다.
3. 피처: 나무 형태·밀도, 식생, 샘, 광맥, 암석/지질물, 지표 장식은 생물군 태그와 분포 규칙으로 배치한다.
4. 구조물: 단일 건물, 소규모 군집, 조립식 다방 구조를 지역 예약·간격·입구·보상 계약으로 생성한다.
5. 환경/차원: Overworld 외 환경은 별도 월드 프로필(지형, 하늘/안개, 자원, 구조물, 위험)을 가진다. Nether/End를 이름만 복제하지 않고 Godot 게임의 독립 규칙·콘텐츠가 준비되는 M06 이후에 구현한다.

Minecraft Bedrock의 공식 개요도 기반 지형, 생물군, 구조물, 피처를 별도 패스로 다루며, 생물군이 기후·표면·환경 규칙을 선택하고 피처가 광석·식생 등을 배치한다고 설명한다. 따라서 이 프로젝트도 이 순서를 데이터 계약으로 고정한다. 현재 구현은 1의 일부와 2의 기반만 충족했으며, 3–5는 미완료다.

## 반복 단위와 완료 조건

각 하위 마일스톤은 (1) 고정 시드/128시드 조사와 결함 목록, (2) 순수 데이터 패스와 불변식, (3) 실제 충돌·카메라 캡처, (4) 41/185/255 크기 성능, (5) 실패 로그·PNG·해시 기록 순으로 닫는다. 골든 해시를 바꾸는 패스는 생성 버전/저장 호환성을 먼저 결정한다. 하나의 멋진 화면이나 단일 시드 성능으로 완료 처리하지 않는다.

### M03.2 — 거대 지형과 생물군 일관성

고도·기후·침식성 신호를 분리하고 산/해안/평원 전이 폭, 생물군 최소 면적, 스폰 주변 안전 경사를 계약으로 만든다. 128시드에서 생물군 비율·경계 길이·경사 분포를 기록하고 6개 고정 카메라 시트와 실제 보행 경로로 확인한다. 기존 6축 데이터가 있어도 이 계약이 통과하기 전에는 완료가 아니다.

### M03.3 — 지하 생물군과 탐험성

치즈/스파게티/협곡을 단순 빈 공간이 아니라 고도·습도·지표 생물군 조건을 가진 지하 구역으로 분류한다. 각 구역은 입구, 충분한 머리 공간/지지 바닥, 조명·광석·샘의 피처 조건을 갖고 자연 공동과 보호 동굴망을 별도로 검사한다. 128시드의 빈 공간 부피만이 아니라 실제 CharacterBody3D 왕복, 막힘/우회, 광석 수확 후 저장까지 검증한다.

### M03.4 — 구조물과 피처 예약

구조물은 지역 좌표 기반 예약으로 배치하고, 지형 적합성·서로의 거리·입구·보상/피처 충돌을 데이터 계약으로 만든다. 나무·광석·샘 같은 피처는 구조물 이후에 배치하되 보호 영역을 훼손하지 않는다. 시드 재실행/지역 순서 교체에도 같은 결과여야 하며, 구조물 하나가 랜드마크 접근성 보정에 의존하지 않도록 독립 검사한다.

### M03.5 — 다양성 매트릭스 게이트

위 다섯 층의 조합을 128시드로 표로 기록한다. 각 시드는 최소한 지상 생물군 4종, 지하 유형 2종, 피처 4종, 구조물/군집 1종을 충족해야 하며, 185/255 크기에서는 분포·거리·접근성·경계 이음새를 따로 검사한다. 한 시드에서 모든 유형을 강제하는 대신 전체 시드 집합의 커버리지와 희귀 유형의 재현 시드를 공개한다. PNG 카메라 시트와 실제 이동/채굴/저장 회귀가 없는 유형은 '생성 가능'으로 세지 않는다.

### M10 선행 — 스트리밍 경계

청크/지역별 순수 생성과 캐시 키를 정의하고, 경계 양쪽 생성 순서를 바꿔도 높이·동굴·구조물·피처가 이어지는지 검사한다. 로드/퇴출의 메모리 상한, 이동 중 P95, 저장 편집/고갈 광맥/스테이션 지속성을 함께 측정한다. 255 전체 맵의 좋은 결과는 스트리밍 구현의 증거가 아니다.

## 현재 판정과 다음 작업

M05 스테이션 루프는 완료 기록했지만 절차 생성의 경쟁 우위는 아직 미달이다. 다음 구현 루프는 M03.2의 생물군-지형 일관성 계측표와 시드별 카메라 시트를 먼저 추가하고, 그 결과로 한 가지 지형 규칙만 변경한 뒤 전체 결정성·저장·실제 렌더 회귀를 다시 실행한다. M03.5 다양성 매트릭스가 통과하기 전에는 이 목표를 달성했다고 선언하지 않는다.
