# Unreal ↔ Godot 비교 스코어카드

갱신일: 2026-09-09. 이 문서는 “더 나은 수준”을 검증 가능한 조건으로 바꾼다. 콘텐츠 범위가 다르면 속도 수치를 승리로 판정하지 않는다. 아래 기록은 시간순이며 최신 판정은 마지막 절이다.

## 완료 판정 규칙

아래는 초기 M01–M03 비교 게이트이며 모두 충족해야 이 범위의 우위를 검토할 수 있다. 경쟁 프로젝트 전체보다 낫다는 최종 판정에는 현재 Unreal 기능 범위와의 추가 동등성도 필요하다.

1. 기능: Unreal M01–M03의 블록 계약, 저장 무결성, 6축 기후·6생물군, 자연 동굴 3종, 협곡, 샘, 자원, 생물군별 구조물, 채굴·배치·HUD를 빠짐없이 제공한다.
2. 정확성: 같은 시드·설정 해시, 128시드 속성 검사, 음수·경계 청크, 손상·미래 버전 저장 거부, 실제 입력/충돌 스모크를 통과한다.
3. 시각: 1280 × 720 이상 실제 엔진 캡처에서 지형·블록·HUD가 잘리지 않고 구분된다.
4. 성능: 같은 185 × 185 시드 1337, 같은 생성 기능과 측정 범위에서 생성 시간과 최대 메모리를 비교한다. Godot은 생성 시간 또는 메모리 중 하나를 20% 이상 개선하고 다른 항목은 10% 넘게 악화시키지 않는다.
5. 편집 응답성: 단일 블록 편집은 해당 청크와 필요한 경계 이웃만 dirty 처리하며 P95 렌더 갱신이 16.7 ms 이하이다.
6. 근거: 전체 검증 명령, 로그, JSON 지표, PNG, 알려진 한계, 코드 리뷰 결과를 보존한다.

2026-09-09 재조회: Unreal의 `Docs/HANDOFF.ko.md`와 `Docs/Milestones/M04_COMPLETION.ko.md`–`M06_COMPLETION.ko.md`는 M06 완료/M07 진행을 보고한다. Godot은 시간 기반 채굴·물리 드롭·24가지 방향·균열·36슬롯/커서에 4장비·개별 도구 아이템·14레시피와 저장 v6를 추가했다. 월드 상자/화로·광석 획득·제련과 생존·시간·날씨는 여전히 큰 기능 격차다. 이는 해당 로컬 문서 확인이며 이번 Godot 작업에서 Unreal 하네스를 재실행한 결과는 아니다. M01–M03 게이트만 통과해 전체 사용자 목표를 완료 처리하지 않는다.

계측 해석(09일 보강): 현재 자동 지연 표본은 편집 시작→엔진 viewport 갱신 신호까지이며 실제 GPU 완료·OS presentation·입력→광자 측정은 아니다. 첫 관측 viewport 픽셀 변화는 별도 검사한다. 16.7ms 목표는 유지하고 실제 표시 응답성/엔진 간 비교에는 같은 정의의 추가 근거가 필요하다. 과거 절의 “화면 반영”을 물리 화면 표시 보장으로 확대 해석하지 않는다.
