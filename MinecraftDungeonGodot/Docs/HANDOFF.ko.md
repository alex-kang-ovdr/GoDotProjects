`PlaneMask.revision`은 실제 값이 바뀔 때만 증가한다. `PlaneGeometry`는 identity/revision별 immutable geometry를 보존하며 변경된 평면만 기준 병합기로 다시 구성한다. ordered packed 배열을 합친 뒤 청크 전체 메시/충돌을 업로드한다. 청크 제거·전체 rebuild·clear에서 캐시를 정리하고 비동기 publication에서 함께 인계한다. 기준 `build()`와 benchmark의 `--geometry=reference`를 유지한다. 1,005개 정확성/수명 검사가 추가됐으며 cache 상주량/초기 구성 비용은 늘었다.

Overworld 41–255, Dungeon 11–255 홀수, 방 시도 1–512다. 모드 초안 변경은 크기를 185/41로 바꾸고 방 시도는 Overworld에서 비활성이다. `request_generation()`은 작업 스레드에서 독립 layout·검사·청크 인덱스를 만든다. 메인은 숨긴 렌더러에 약 4ms 목표로 청크를 나눠 구성한 뒤 publication 한다. 기존 순수 데이터는 전용 정리 스레드에서 참조를 내리고, 이전 청크 노드는 숨긴 뒤 메인에서 약 2ms 배치로 제거한다. 노드 제거 후 물리 2틱과 정리 스레드 join까지 SETTLING/조작·저장 잠금을 유지한다. 중첩 공유 스냅샷은 수정하지 않으며 Node/GPU/물리 객체를 작업 스레드로 넘기지 않는다. 스레드 시작 실패는 보고된 동기 fallback, 월드 종료는 소유 스레드 join으로 처리한다. 예산은 엄격한 프레임 상한이 아니다. COMPUTING→MESHING→SETTLING 동안 패널을 닫아도 잠금을 유지하고 생성 작업 오류는 기존 월드·플레이어를 보존한다. 검사 미실행은 READY, 검사한 생성만 PASS다. 초기 CLI 생성은 동기식이다.

`generation_trace_enabled`는 기본 false이며 진단 도구에서만 켠다. 생성/검사/인덱싱 작업 시간, 프레임 전후 상태와 메인 실행 시간, 개별 청크 단계, 데이터/노드 정리와 수신자 호출을 기록한다. `generation_profile.gd`의 3회 왕복과 `controls_smoke.gd`의 헤드리스/렌더 trace가 증거다. 현재 trace 파일명은 `headless-`/`render-generation-trace-*`로 분리한다. 최신 전체 실행의 초기 무접두사 헤드리스 파일도 보존했고 추가 헤드리스 40개 검사로 접두사 경로를 검증했다.

Dungeon은 독립 시드 방 배치, 비중첩 직사각형 방·3칸 통로·입구/출구를 생성한다. 최종 지지 바닥·2칸 여유·전체 연결·벽·경계·방·경로를 검사한다. 시드 1337/41/34시도는 1,498셀·해시 1360838879, 실제 W 입력으로 63칸 경로 왕복을 확인했다. 두 모드는 같은 편집·렌더·저장 경로를 쓴다. 직사각형 하위 던전 API는 없다.

## 이번 생성 변경과 저장 경계

Overworld 생성 버전은 6이다. 버전 4에서 도입한 temperature/humidity/continentalness/erosion/weirdness/depth 독립 수평 기후장과 역할은 유지한다. Weirdness는 고지 판정과 높이, Depth는 높이에 기여한다. 모든 축이 생물군 또는 높이를 실제 바꾸는지 단독 교란 검사로 확인한다. Unreal도 모든 축을 생물군 분기에 직접 쓰지는 않는다. `climate_at()`의 여섯 번째 값은 독립 Depth이며 상대 깊이 조회는 `density_depth_at()`이다. 고지 표면은 돌, 설원은 눈이다.

연속 밀도 cheese 공동·곡선 spaghetti 터널·협곡·광맥 표식·해안 샘·비중첩 5×5 랜드마크를 생성한다. 기존 8블록 보호 계단/전실은 유지하고 `CaveNetwork`가 Y=4 중앙 방·4개 말단 방·내리막 접근로를 추가한다. 중심 열 높이를 먼저 계획하고 바닥/공기 충돌 시 무변경으로 거부한다. 나무 수관과 건물/문 앞 후보도 보호 천장을 피하며 후속 경로 보정에서 바닥·공기를 보존한다. 5개 방 보행 연결·바닥 재질·보호 공기 전체 6방향 연결을 최종 셀 검사에 추가했다. 작은 월드의 6생물군 코어는 높이 shaping 뒤에 강제하므로 높은 해안 코어 등 생물군/고도 일관성은 아직 개선 대상이다.

`VoxelTraversal`은 최종 셀에서 스폰→모든 문 연결을 검사한다. 고체 지지/2칸 몸 공간/4방향/단차 최대 1블록과 낮은 쪽 점프 여유 1칸이 필요하다. `LandmarkRoutes`는 막힌 문 앞에서 기존 연결 영역까지 비용 기반 탐색으로 조약돌 연결로를 보정한다. 동굴 공기/바닥·건물/문 앞·샘/열린 상부·기존 성공 경로와 연결 지점→스폰 경로를 보존한다. 점프 공간과 자체 X/Z 재방문을 검사하고 안전한 곳만 넓힌다. 모든 구간이 3칸 너비 또는 지표면인 것은 아니며 지하 절개/협곡 위 바닥이 가능하다. 생성 metadata가 아닌 최종 셀 그래프와 독립 고체 표면 DFS, 실제 W/Space 왕복으로 검증한다. 자연 동굴 전체 연결은 별도 미완료 항목이다.

높이맵은 열당 inclusive Y, 빈 열은 -1이다. `terrain_heights`는 초기 shaping, `surface_heights`는 최종 비공기(물 포함), `ocean_floor_heights`는 최종 물 제외 고체(지붕/나뭇잎 포함), `heights`는 최종 충돌 높이다. 현재 물만 비고체라 고체 바닥과 충돌 값은 같지만 별도 배열로 계산한다. 이들은 생성 스냅샷이며 실시간 편집 높이맵은 아니다. Unreal Surface/OceanFloor의 장식 전 지면 의미와 다르므로 API 동등성으로 표시하지 않는다.
