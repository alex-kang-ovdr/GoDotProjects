# 웅크리기·천장 여유·가장자리 보호 자체 검토

Unreal 이동 계약의 몸 높이 1.8/1.5m, 반경 0.3m, 웅크린 속도 1.295m/s를 Godot CharacterBody3D에 독립 구현했다. 눈높이는 발 기준 1.62/1.27m다. Unreal 소스는 읽기 전용으로 참고했으며 변경하거나 복사하지 않았다. 이 기록은 구현 에이전트의 자체 검토다.

## 구현

Shift가 실제 CapsuleShape3D 높이와 중심, 카메라 높이를 바꾼다. 몸 중심만 낮추고 발 위치는 유지한다. 웅크리기가 Ctrl 달리기보다 우선한다. Shift를 놓아도 서 있는 캡슐 공간이 막혔으면 웅크린 상태를 유지하고, 이동해서 여유가 생기면 다시 선다.

천장 검사는 자기 RID를 제외한 [PhysicsShapeQueryParameters3D](https://docs.godotengine.org/en/4.7/classes/class_physicsshapequeryparameters3d.html)와 [intersect_shape](https://docs.godotengine.org/en/4.7/classes/class_physicsdirectspacestate3d.html#class-physicsdirectspacestate3d-method-intersect-shape)를 사용한다. 바닥 접촉을 천장 충돌로 오인하지 않도록 검사체 바닥만 2cm 올리되 최종 서 있는 높이는 유지했다.

가장자리 보호는 지상 웅크리기에서 다음 수평 위치 아래 지지 면을 검사한다. x/z를 개별 검사한 뒤 합성 위치도 다시 검사하여 대각 빈 공간을 놓치지 않는다. 지지 법선은 캐릭터의 floor_max_angle과 비교한다. 점프 상승 중에는 보호를 적용하지 않으며 발밑 바닥이 제거되면 정상 중력으로 떨어진다. 일반 보행까지 강제로 제한하지 않는다.

체크포인트에 boolean `crouched`를 추가했다. 포맷 2/생성 버전 3을 유지하고 누락 자세는 standing으로 읽는다. 복원은 자세뿐 아니라 실제 충돌체와 카메라도 갱신한다. R 안전 복귀와 새 월드 생성은 자세를 다시 세운다. 저장 뒤 제어가 재개되면 Shift/천장 상태에 따라 평상시 자세 전환 규칙이 다시 적용된다.

## 실제 검증

전체 명령 `pwsh -NoProfile -File MinecraftDungeonGodot/Verify.ps1`: `Saved/Verification/20260908-210603-071`, 종료 코드 0.

- 웅크리기 헤드리스 24개, 렌더 입력/PNG 포함 25개 단언 통과
- 실제 1.55m 여유의 낮은 통로에서 standing 진입 거부, crouch 진입, 천장 아래 uncrouch 거부, 출구에서 standing 복원
- 발 높이 유지·실제 캡슐·눈높이, Ctrl+Shift 동시 입력의 속도 우선순위
- 30/60/120Hz의 대각 가장자리에서 실제 지지·접촉 유지. 마지막 x/z는 각각 약 3.99855/2.99855, 3.99942/2.99942, 3.99985/2.99985
- Shift 해제 후 보행 추락, 의도적 웅크린 점프, 발밑 복셀 채굴 후 중력 낙하
- 자세 체크포인트·잘못된 boolean 거부·레거시 기본값·R 자세 복구
- 쓰기 PID 80768 종료 후 읽기 PID 87004에서 편집 1,000개와 웅크린 자세/몸 높이/눈높이·진행도·인벤토리·위치·시점 복원
- 기존 단위 48·저장 74·메시 502·최적화 534·Builder 53/72, 128시드 행렬(19.859초), 동굴 3시드 왕복 통과

`crouch.png`를 직접 확인하여 낮은 천장 아래 카메라와 CROUCH 표시를 확인했다. 이 통로는 테스트용 물리 지붕이며 생성 월드의 신규 던전 콘텐츠라고 주장하지 않는다. `runtime.png`에서 Shift 안내와 기존 HUD 배치를 확인했다. 지형 생성 세 시드 측정은 2.778–3.166초이며 셀 해시는 유지됐다.

## 한계와 후속

1m 통로를 통과하는 포복 기능이 아니며 1.5m 몸보다 낮은 곳은 통과할 수 없다. 지지 검사는 캐릭터 중심 아래의 현재 정적 지형을 기준으로 하며 움직이는 발판·경사 조합 전체를 검증하지 않았다. 악의적으로 변조한 위치까지 지형과 충돌 없이 복원한다는 보장은 기존 저장 검증 범위 밖이다. 픽셀 단위 가장자리 동작이 Minecraft/Unreal과 완전히 같다는 주장은 하지 않는다.

생성 설정 패널·모드 전환/던전·Alt+2, 기후/높이맵 동등성과 시각 개선이 남아 있다. 이번 루프는 렌더 성능 비교를 다시 수행하지 않았고 기존 편집 프레임 P95 16.948ms 미달을 해소했다고 판정하지 않는다.
