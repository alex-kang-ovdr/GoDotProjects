# 초기 준비 병목 개선 — 2026-09-08

구현 에이전트의 자체 코드·실행 검토다. 월드 콘텐츠를 줄이지 않고 초기 준비 경로를 개선했다. 생성 버전 3, 포맷 버전 2와 월드 해시 계약은 유지한다.

## 계측과 변경

`profile-before/chunks.json`에서 생성 6.411초 중 정렬·해시 4.014초, 초기 메시 준비 중 마스크 판정 8.534초를 확인했다. ArrayMesh/충돌 업로드 자체는 0.297초였다. 이 결과에 따라 GPU 또는 충돌 품질을 낮추지 않고 다음을 변경했다.

- 일반 좌표를 48비트 정수 키로 정렬한다. 각 축에 32768 바이어스를 더하고 x/y/z 순서를 보존해 엔진의 정수 배열 정렬을 사용한다. 원래 FNV 순서·연산을 유지하며 범위를 벗어나는 전체 Vector3i 좌표는 기존 비교 정렬로 처리한다.
- 청크의 유효 셀과 인접 6면만 임시 18³ 정수 배열에 적재한다. 재질 쌍별 시각·충돌 판정표를 사용해 셀마다 6회 반복하던 사전 조회와 정의 조회를 줄인다. 대각 이웃은 면 판정에 필요하지 않으므로 읽지 않는다.
- 청크 좌표의 나눗셈/내림을 부호 보존 비트 시프트로 바꿨다. 음수 경계와 int32 양 끝값을 기존 수식과 대조했다.
- 국소 편집의 면 캐시 경로는 유지한다. 느린 마스크 구현도 회귀 기준으로 보존한다.
- 밀도별 마이크로벤치마크에서 1셀의 임시 배열 준비는 약 422µs였지만 직접 판정은 15.5µs였다. 64셀까지 직접 경로, 그보다 크면 배열 경로를 사용한다. 4,096셀의 적응형 경로는 4.174ms, 직접 경로는 28.397ms였다. 임계값은 이 기기의 20회 평균 탐색에서 정했으며 보편적 최적값이라고 주장하지 않는다.

## 보존해야 하는 결과

시드 1337, 185 × 185의 1,061,164셀, 해시 1321744834, 청크 429개, 단위 노출면 247,158개, greedy 87,449쿼드는 변경 전후 같다. 41맵 해시 32651302도 고정 회귀로 검사한다.

`tools/optimization_equivalence.gd`의 534개 단언은 빈 월드, 무작위 128개 셀 집합, 좌표 양 끝값, 삽입 순서, 부호 있는 청크 나눗셈, 여러 재질·공기·경계·편집·복원 뒤의 전체 마스크를 기준 구현과 대조한다. 적응형 경로와 강제 배열 경로를 각각 검사하여 작은 청크에서 새 경로가 검사를 우회하지 않게 했다. 기존 메시의 독립 면/충돌 검사 502개도 유지한다.

## 관측 해석

최초 최적화 탐색 실행 `profile-after`는 준비 7.229초를 기록했다. 경계면 전용 조회까지 적용한 중간 전체 검증 `20260908-203915-239`는 6.340초다. 적응형 경로까지 적용한 최종 전체 검증 `20260908-204250-004`는 6.696초로, 이전 깊은 지형의 15.977초보다 약 58.1% 짧다. 최종 생성 3.042초, 마스크 1.342초, 메시 구성 1.086초, 업로드 0.273초다. 청크 인덱싱과 기타 준비는 이 세부 단계 합 밖에 있으므로 이를 전체 시간으로 오인하지 않는다.

직접 콘솔 실행 탐색 두 번의 편집→프레임 P95는 16.947/16.875ms로 목표를 약간 넘겼다. 중간 전체 하네스는 10.247ms였지만 최종은 VSync 기본값 1에서 16.948ms로 다시 목표를 넘었다(CPU P95 6.880ms). 원시 64개 샘플을 JSON에 보존하며 좋은 실행만 골라 통과로 판정하지 않는다. 약 16.7ms 간격으로 모이는 샘플은 표시 타이밍 영향과 일치하지만 포커스/VSync가 원인이라는 확정 진단은 아니다. 응답성 게이트는 재검증·안정화 대상으로 남긴다.

## 최종 실행과 화면

`pwsh -NoProfile -File MinecraftDungeonGodot/Verify.ps1 -RenderComparison`은 `Saved/Verification/20260908-204250-004`에서 종료 코드 0으로 끝났다. 이는 하네스 실행·정확성 검사 성공이며 위의 성능 게이트 미달을 무효화하지 않는다. 단위 48, 저장 74, 메시 502, 최적화 동등성 534, 128시드 행렬(21.842초), 극단 시드/대형맵 감사, 동굴 왕복·렌더 입력과 PNG 생성이 통과했다.

최종 실제 엔진 프로세스의 최대 작업 집합은 청크 520.47MiB, GridMap 1,130.05MiB였다. 생성/카메라/64편집이 같은 Godot 내부 비교이며 GridMap 준비 시간은 49.582초, 편집→프레임 P95는 29.268ms다.

지상/동굴 PNG를 직접 확인했다. 최종 185 전경 PNG의 SHA-256은 `a871ef009da65c626bdd0791487d1176f13d9f17f20c6fcef1afc9225e92769f`로 최적화 전 `20260908-202733-752/chunks.png`와 동일하다. 화면을 단순화하거나 동굴/충돌을 빼서 얻은 개선이 아니다. 설원 과노출과 동굴 안내 부족은 그대로 남아 있다.

Unreal의 같은 크기 월드와 콘텐츠 수·구현 기능·계측 범위는 아직 완전히 일치하지 않는다. 초기 속도 개선이 엔진 간 최종 우위 달성을 뜻하지 않는다. 조작 패널·Builder challenge·기후 판정·높이맵 동등성·시각 품질 작업을 계속한다.
