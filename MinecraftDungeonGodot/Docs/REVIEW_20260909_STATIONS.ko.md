# M05 스테이션·광석·제련 완료 기록 (2026-09-09)

## 완수 범위

월드 셀에 결합되는 상자와 화로를 독립 GDScript 상태로 구현했다. 상자는 27칸, 화로는 원료/연료/결과 3칸이며, 고정 20Hz에서 철 원석 1개를 200틱에 철괴 1개로 바꾼다. 석탄 1개는 1,600틱 연소한다. 결과가 가득 차면 점화하지 않고, 이미 타는 화로는 결과가 가득 차도 연료 시간만 소비한다. 빈 화로는 회수할 수 있고, 내용물이 있는 스테이션은 채굴/저수준 셀 교체로 사라지지 않는다.

상자·화로는 각각 판자·벽돌 블록 외형을 사용하지만 상태는 별도로 저장한다. `X`로 조준 스테이션을 열고 `B`로 가방을 오가며, 마우스·키보드로 이동한다. 셀 결합 상태는 최대 128개다. 생성기의 실제 광맥 표식과 맞추어 조약돌 광맥은 석탄, 이끼 광맥은 철 원석을 낸다. 채굴된 광맥은 `depleted_ore`로 저장해 같은 재질을 다시 설치해도 원석을 재생성하지 않는다.

저장 포맷은 7이다. v7은 스테이션/고갈 광맥/20Hz 잔여 시간을 모두 검증한 뒤 원자적으로 복원한다. v2–v6은 스테이션이 없는 상태로 읽으며, v6에 새 재료 드롭이 있으면 모호한 복원을 피하기 위해 거부한다. 생성 버전 6과 기존 기본 월드 해시는 바꾸지 않았다.

## 검증 결과

최종 전체 근거는 `Saved/Verification/20260909-093733-788`, `Verify.ps1 -RenderComparison -BenchmarkScreen 0`이다. 상위 종료 코드는 0이고 61단계가 완료됐다. 헤드리스 스테이션 2,565개와 실제 렌더 스테이션 2,584개 단언, 제작 2,683/2,695개 단언이 모두 통과했다. 오버월드/던전의 별도 OS 프로세스 재시작은 각각 1,002개 편집과 스테이션 상태를 복원했다. 생성 골든(예: seed 1337, 41: `2029358965`; 255: `546771480`)도 유지됐다.

처음에는 스테이션 장식 노드의 메타데이터 처리와 마우스 입력 경로가 실패했고, 이후 실제 씬 루트 입력·저장 원자성·작은 창 패널 검사를 추가해 수정했다. 별도 전체 실행에서 제작의 고정 시간 대기와 Builder의 드롭 보간 동등 비교가 흔들렸으나, 게임 규칙을 완화하지 않고 실제 명령 상태/진행 시작을 측정하도록 테스트를 안정화했다. 실패 로그는 기존 증거 폴더에 보존한다.

## 남은 한계

제작은 목록형 UI이며 수동 드래그 제작 격자는 아니다. 오프라인 제련 시간 경과, 아이콘/사운드, 다중 플레이 권위, 생존 수치·시간·날씨는 아직 없다. 255맵 실제 교체 P95는 17.344ms로 16.7ms 목표를 넘었으므로 성능 우위도 주장하지 않는다.

## 공유 참고

Unreal M05의 셀 결합 상자/화로, 20Hz·200/1600틱 계약을 기능 참고로 삼았지만 Godot은 1개 저장 제한 대신 최대 128개 스테이션을 독립 저장한다. 블록 외형과 상태, 생성 광맥과 재설치 블록, 월드 저장과 UI의 소유권을 각각 분리하는 방법을 양 프로젝트의 공통 피드백으로 기록한다.
