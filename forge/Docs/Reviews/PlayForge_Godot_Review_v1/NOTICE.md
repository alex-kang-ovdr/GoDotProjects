# 문서 패키지 안내

이 패키지는 PlayForge의 Godot 채택을 위한 독립 검토·설계 자료입니다. Godot Foundation, Epic Games, Havok 또는 관련 공급자의 공식 승인·보증 문서가 아닙니다.

Godot/서드파티 원본 코드·바이너리·SDK·폰트는 포함하지 않습니다. API명과 제품명은 비교·설계 설명용입니다. 라이선스 판단은 참고자료에 근거한 기술 검토이며 실제 계약·법률 검토를 대체하지 않습니다.

동봉 Python 도구는 문서·JSON·파일 해시의 정합성을 검사할 뿐, Godot를 빌드·실행하거나 공급자 권한을 확인하지 않습니다.

실제 런타임·미들웨어·GPU·협업 서버·네트워크·보안·성능·Unity MCP 비교는 수행하지 않았습니다.
