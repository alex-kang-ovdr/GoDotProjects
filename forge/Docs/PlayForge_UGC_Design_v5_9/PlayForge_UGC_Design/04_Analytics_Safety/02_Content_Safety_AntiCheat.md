# 콘텐츠 안전성·음성·안티치트

> PlayForge Cloud | 설계 기준 2026-11-17 | 제안 설계 (구현 완료 아님)

## 안전성 경계

UGC GDScript는 샌드박스 실행. OS/파일/임의 네트워크 차단, CPU·메모리·Spawn·RPC Rate Limit. 공유 에셋은 업로드 시 파일 포맷·스크립트·권리·악성 콘텐츠 검사.

## 콘텐츠 검토

자동 검사 → 위험 점수 → 필요 시 운영자 검토 → 게시/반려/제한 → 이의제기. 콘텐츠 신고, 사용자 차단, 게시 중단, 삭제 요청, 감사 로그를 제공한다.

## 음성

EOS Voice 기반 팀/파티/전체 채널, PTT, 개인 음량, Mute, Block, Report. 채널 참가 권한은 매치/팀과 연계. 음성 장애가 게임플레이를 중단하지 않도록 한다.

## 안티치트

서버 Authority가 Movement/Physics/Combat/Inventory/RPC/PlayerData를 검증. EAC는 지원 PC 플랫폼에 선택적으로 사용하며 모바일·웹까지 동일 보호를 보장하지 않는다. Listen Host는 신뢰할 수 없는 Authority이므로 경쟁전은 Dedicated 권장.

## 개인정보·미성년

최소 수집, 보존 기간·접근 통제, 지역별 규정 검토, 음성/채팅 권한, 미성년 계정 안전 설정, 신고·제재 이의제기 절차. 자동 제재는 오탐 검토와 복구 경로를 둔다.

## 검증

권한 우회·과도한 RPC·GDScript 무한 루프·악성 공유 파일·가짜 이벤트·신고 스팸·세션 토큰 재사용·EAC 비지원 플랫폼 경로 테스트.
