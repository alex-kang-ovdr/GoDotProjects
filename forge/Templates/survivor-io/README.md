# 탕탕특공대 (Survivor.io) — Godot 4.7 포팅 템플릿

`games/survivor-io` 웹 프로토타입의 핵심 루프, 무기·진화, 영웅 특수기, 11종 적 AI 및 3개 챕터 보스 패턴을 Godot 4.7.2 네이티브 2D(GDScript)로 포팅한 PlayForge 템플릿입니다.

## 주요 구현 기능

- **조작**: PC(`WASD` / 방향키 이동, `Space`/`Shift` 대시, `E` 영웅 특수기, `1/2/3` 레벨업 선택, `P`/`Esc` 일시정지) 및 모바일 터치 가상 조이스틱 + 하단 액션 버튼
- **3종 영웅 & 액티브 스킬**:
  - `선봉대원` — `충격파` (반경 180 피해 + 탄막 제거 + 0.8초 무적)
  - `공병` — `자동 포탑` (10초간 반경 420 자동 사격)
  - `구조대원` — `회복장` (6초간 초당 최대 체력 5% 회복)
- **9종 무기 + 진화(합체 포함) & 8종 패시브**:
  - `쿠나이 → 유령 수리검`, `수호자 → 절대 수호자`, `로켓 → 심판의 미사일`, `번개 → 천둥의 사슬`, `화염병 → 지옥 화염`, `드릴 → 귀환 화살`, `A형 드론 + B형 드론 → 파괴자 드론`
- **11종 적 & 3개 챕터 보스 패턴**:
  - 공간 해시 그리드(`64px`) 기반 다수 적 분리 및 탄환 판정
  - 챕터별 예고 텔레그래프 보스 패턴(`돌진/충격파`, `포격/소환`, `레이저/빙결탄막`) + 2페이즈 강화
- **영구 성장 저장**: `user://survivor_io_save.cfg`에 골드·최고 처치·클리어·영구 강화(공격력/체력/방어력) 저장
