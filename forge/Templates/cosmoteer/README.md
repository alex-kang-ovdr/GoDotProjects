# Cosmoteer 함선 실험실

함선을 직접 조립하고 승무원 보급과 추진기를 운용하는 Godot 함선 실험실이다. 자유 교전에서 기동을 익히거나, 서로 다른 목표를 가진 임무를 완료하면서 다음 출격을 연다. Windows용 Cosmoteer 스냅샷에서 추출한 기존 부품 카탈로그, 전력 보급 사격장과 데이터 탐색기도 열 수 있다.

## 실행과 조작

PlayForge 웹 고도 템플릿(`forge/Templates/cosmoteer`, 템플릿 ID `cosmoteer`)으로 통합되어 있다. PlayForge 서버에서 `cosmoteer` 템플릿으로 프로젝트를 생성해 웹 에디터/웹 런타임으로 열거나, Windows에서 [Run.cmd](Run.cmd) 또는 Godot 4.7.2에서 [project.godot](project.godot)을 열고 **F5**를 누른다. 통합 회귀 테스트는 저장소 루트에서 `node --test forge/Tests/cosmoteer-godot.test.cjs`로 실행한다. 실행에는 프로젝트에 포함된 JSON과 번들 한글 폰트(`assets/fonts/cosmoteer-ui.txt`)를 사용한다.

- **조선소 · 전투**는 출격 가능한 기본 함선으로 열린다. 오른쪽 목록에서 부품을 골라 빈칸을 클릭하고 **R**로 다음 부품을 회전한다. 우클릭은 철거, **되돌리기**는 마지막 편집을 복원한다. **비우기**로 처음부터 만들 수 있다. **설계 저장**과 **불러오기**는 Godot 사용자 데이터의 `user://ship_design.json` 한 슬롯을 사용한다.
- 기본 선택인 **자유 교전**에서 **전투 출격**을 누르면 즉시 기동전을 시작한다. **W/S**로 전진·후진, **A/D**로 좌현·우현 횡이동, **Q/E**로 좌회전·우회전한다. 화면의 조종 버튼을 길게 눌러도 된다. 키를 놓으면 남은 속도가 항력으로 줄어든다.
- **특수 추진 실험선**에는 전방으로 힘을 내는 부스트 추진기와 로켓 노즐·연장기·측면 배터리가 있다. **전투 출격 → B → W** 순서로 부스트를 켜고 전진한다. 화면의 **부스트 켜기/끄기** 버튼도 사용할 수 있다. 로켓은 담당 승무원 2명이 도착하면 조종 입력에 반응한다.
- **O** 또는 화면의 **오버클럭** 버튼으로 엔진룸과 변을 맞댄 추진기의 출력을 올린다. 특수 추진 실험선에서는 부스트 추진기와 로켓 노즐이 모두 연결되어 있다. 전투 화면에서 추진기를 선택하면 현재 추력·전력 소모·발열과 누적 열을 확인할 수 있다.
- 비행 화면에서 적 부품을 클릭하거나 **집중 사격**으로 표적을 지정한다. 소형 레이저는 사거리와 사각, 전력·포수 조건이 맞을 때 자동 발사한다. **함선 내부**에서 승무원과 손상된 부품을 확인하고 **비행 화면**으로 돌아올 수 있다. 자유 교전에서는 적 함교를 모두 파괴하면 승리한다. 조선소로 돌아오면 격납고의 출격 전 설계를 다시 편집할 수 있다.
- **실험 조종석**에서 실행을 누르면 운반원이 반응로와 레이저 사이의 6칸을 왕복한다. 보급 통로를 닫으면 운반이 멈추고, 무기는 이미 받은 전력을 사용한다. 포수 배치와 사격 허가를 각각 바꾸거나 표적 거리를 최대 사거리 260m 밖으로 옮겨 결과를 비교할 수 있다.
- **한 단계**는 0.25초 진행 후 멈춘다. 처음부터 버튼은 통로·포수·사격 허가와 표적 거리를 기본값으로 복원한다. 데이터 탭을 보는 동안 실험 시간은 멈춘다.
- **추출 데이터**에서 함선 부품과 자원의 ID를 검색하면 수치와 원본 행을 확인할 수 있다. **규칙 파일**은 파일을 기준으로 양방향 참조를 보여준다. **DLL 메서드**는 선택한 메서드의 IL 오프셋과 호출 대상을 보여준다.

## 임무와 개장

조선소에서 임무를 선택해 목표를 확인하고 출격한다. 임무 승리는 다음 임무를 열며, 재도전하면 최단 완료 시간의 발사·명중 기록을 보관한다. 임무 기록은 교전 종료 시 `user://lab_operations.json`에 저장된다. 한 슬롯짜리 함선 설계와 별도로 보관되므로 같은 임무에 여러 설계로 도전할 수 있다.

| 임무 | 교전 조건 | 완료 조건 |
|---|---|---|
| 항로 교전 | 120m, 거리를 조절하는 정찰선 | 적 함교를 제압한다. |
| 정밀 무장 해제 | 145m, 추가 추진기를 장착한 추격선 | 적 함교를 유지하면서 적 무장을 모두 제거한다. |
| 대피 시간 확보 | 135m, 두 무기를 갖춘 장거리 교전 함선 | 32초 동안 아군 함교를 지킨다. |

임무 목표, 초기 거리, 상대 함선·기동 방식, 잠금 조건은 실험실의 [임무 데이터](data/operations.json)에서 읽는다. 전투가 끝나면 목표의 성공·실패 원인과 시간, 발사·명중 수를 확인할 수 있다. 조선소에서 선체 구조와 전력 보급 경로, 추진기 구성을 편집해 다시 출격한다.

## 조립과 교전 규칙

| 설계 선택 | 교전에서 확인할 수 있는 결과 |
|---|---|
| 소형 선실 2개, 소형 함교·반응로·레이저 각 1개, 연결 통로 | 선실당 2명이 출발한다. 출격하려면 조종사·포수·운반원과 실제 보급 경로가 필요하다. 민트색 선은 편집 중 가장 짧은 반응로–레이저 통로를 표시한다. |
| 통로의 길이와 분기 | 승무원은 상하좌우로 연결된 통로 칸을 걷는다. 통로가 끊어지면 저장된 전력과 운반 중인 배터리만 남는다. 우회로가 있으면 살아 있는 칸을 따라 새 경로를 찾는다. |
| 추가 레이저와 선실 | 배치 가능한 포수와 운반 인력이 갖춰진 무기마다 별도 저장고와 발사 주기가 작동한다. |
| 추진기 장착 위치와 회전 | 노즐의 분사 반대 방향으로 힘이 작용한다. 무게중심에서 벗어난 노즐은 회전력도 만든다. 노즐 위치가 다른 설계는 같은 입력에도 가속과 선회가 달라진다. |
| 입사 방향의 장갑 | 발사체가 교전 공간을 이동하며 회전·이동한 적함의 부품과 충돌한다. 장갑이 탄도 위에 있으면 먼저 피해를 받는다. 옆으로 돌아가면 같은 표적에 접근하는 탄도가 달라진다. |

격자는 16×10이다. 출격하려면 배치한 모든 부품이 변을 통해 하나의 선체로 연결되어야 한다. **전체 부품**에는 추출 카탈로그 96종과 실험실 엔진룸이 있다. 전투용 목록은 통로, 소형 선실·함교·반응로·레이저, 1×1 장갑, 일반 추진기 6종, 특수 추진 부품 4종과 실험실 엔진룸을 제공한다. 기존 저장 설계도 그대로 불러온다. 추진기가 없는 설계는 정지 포대로 출격한다.

자유 교전은 120m 간격에서 출발한다. 적도 추진기로 거리를 조절하고 선수를 돌린다. 추진기를 단 함선은 즉시 조종할 수 있도록 조종사가 함교에 배치된다. 연결된 반응로의 비축 전력을 함교와 추진기로 미리 옮기며 전투 중 보충은 운반원이 맡는다. 자유 교전에서 양측 함교 동시 파괴, 양측 무장 상실 또는 120초간 명중 없음은 무승부다.

### 추진기와 레이저

| 추진기 | 노즐당 기본 추력 | 최대 출력 도달 시간 | 작동 노즐당 최대 전력 소모 |
|---|---:|---:|---:|
| 소형, 2방향 소형, 3방향 소형 | 400 | 즉시 | 30/초 |
| 중형 | 1,300 | 1초 | 100/초 |
| 대형 | 3,600 | 2초 | 200/초 |
| 초대형 | 8,000 | 4초 | 400/초 |

연두색 경로는 편집 중 전력 보급로를 보여준다. 추진기 선택 시 **힘 방향** 화살표로 회전 후의 가속 방향을 확인할 수 있다. 소형 계열은 6초마다 전력 30을 자체 충전한다.

**부스트**는 일반 모드에서 최대 추력 3,600, 전력 소모 200/초다. 전력이 5,001에 도달하면 작동 준비가 되고 방전될 때까지 준비 상태가 유지된다. B로 켜면 최대 추력이 9,600으로 오른다. 분사 시 최대 450/초에 더해 켜 둔 동안 0.1초마다 10이 빠지고 보급이 중단된다. 소모 후 직접 끄면 잔량이 방전된다. 전력이 바닥나면 자동으로 꺼지며 운반원이 다시 채운다.

**로켓**은 노즐과 연장기를 같은 회전각으로 일렬로 맞추고 측면의 금색 접점에 배터리를 붙인다. 실험선에서 연장기를 선택해 **R**을 한 번 누른 뒤 기존 연장기 바로 오른쪽 빈자리에 놓으면 3단이 된다. 모든 단에 전력이 공급되고 승무원 2명이 조작하는 조건의 최대치는 다음과 같다.

| 로켓 조합 | 최대 추력 | 최대 전력 소모 | 정지 출력에서 최대까지 |
|---|---:|---:|---:|
| 노즐 단독 | 10,000 | 300/초 | 4초 |
| 노즐 + 연장기 1개 | 20,000 | 600/초 | 약 5.66초 |
| 노즐 + 연장기 2개 | 30,000 | 900/초 | 약 6.93초 |

노즐과 연장기는 각각 전력 2,000을 저장한다. 측면 배터리 하나는 물리 저장 용량을 4,000 늘린다. 실험선에서 측면 배터리만 철거하면 최대 추력과 소모율은 그대로이고 연결 저장 용량은 8,000에서 4,000으로 줄어든다. 조선소 아래 수치는 전부 보급된 설계의 최대치다. 전투 화면 아래에서 현재 인원, 전력, 발생 추력과 소모율을 확인할 수 있다.

### 엔진룸과 열

2×2 실험실 엔진룸과 변을 맞댄 추진기는 함교가 가동 중일 때 오버클럭할 수 있다. 오버클럭 중 추력은 30%, 분사에 드는 전력은 45% 증가한다. B로 켜는 부스트 유지비는 초당 100이다. 엔진룸을 여러 개 붙여도 배율은 한 번 적용된다. 함교가 정지하거나 접한 엔진룸이 모두 파괴되면 해당 추진기의 추가 출력이 사라진다.

| 전력과 승무원이 충분한 최대 분사 상태 | 일반 추력 → 오버클럭 | 전력/초 → 오버클럭 | 발열/초 → 오버클럭 |
|---|---:|---:|---:|
| 부스트 추진기 · 일반 모드 | 3,600 → 4,680 | 200 → 290 | 5 → 33.25 |
| 부스트 추진기 · 부스트 모드 | 9,600 → 12,480 | 550 → 752.5 | 13.75 → 40 |
| 로켓 노즐 + 연장기 1개 | 20,000 → 26,000 | 600 → 870 | 14.0 → 40.0 |

추진기는 초당 열 16을 방출한다. 열이 100에 도달하면 분사를 차단하고 35까지 식으면 사용할 수 있다. 오버클럭 명령을 켜 둔 경우 냉각 후 다시 적용된다. 엔진룸 부품과 이 출력·열 규칙은 실험실에서 직접 설계했다. 표는 최대 분사 조건이며 실제 계기는 입력, 전력 잔량, 로켓 승무원과 연결된 단계 수를 반영한다.

소형 레이저는 유효 사거리 260m, 포탑 회전 범위 200°, 회전 속도 90°/초, 발사 허용 오차 1°를 사용한다. 비행 계기에 사거리 밖·포탑 사각·조준 중·사격 가능 상태를 표시한다. 60Hz 물리에서 부품의 밀도와 물리 직사각형 면적으로 질량을 추정하고 살아 있는 부품으로 무게중심·관성을 계산한다. 노즐 출력 배분과 적의 조종은 자체 구현이다.
