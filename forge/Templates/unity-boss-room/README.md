# Unity Boss Room 3D Co-op — Godot 4.7.2 Template

Unity 공식 멀티플레이어 3D 코옵 RPG 샘플(Boss Room)을 Godot 4.7.2로 결정론적 자동 포팅한 템플릿입니다.

- 클래스 전환: `1` Tank / `2` Archer / `3` Mage / `4` Rogue (나머지 3명은 협동 AI)
- 조작: `WASD` 이동, `Space` 기본 공격, `Q` 주력 스킬(Tank 방패 막기 → 보스 돌진 스턴 / Mage 광역 힐 / Archer 파워샷 / Rogue 대시), `E` 특수 스킬, `R` 아군 부활
