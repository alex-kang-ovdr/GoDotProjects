# v14 → Godot G1/G2 포팅 명세

G1의 초기 포팅 규칙을 아래에 기록하고, G2의 후속 개선은 [`G2_CHANGES.md`](G2_CHANGES.md)에 별도로 설명합니다. G2에서도 원본 JSON 수치·근거 필드는 유지하며, 보스 준비·회복·스폰 중첩 방지와 UI·그래픽 개선은 새 설계 결정으로 구분합니다.

## 기준과 출처

입력은 사용자가 제공한 `SurvivorArena_v14.zip`입니다. 원본 ZIP은 4,262,519바이트이며 SHA-256은 `2f192d4522f678f961522fe20f4190ca1b779bcb6ab6702ef03b31b2363f7eb4`입니다. 원본을 수정하지 않고 별도 Godot 프로젝트를 생성했습니다.

입력의 `src/reference.js`가 `data.js`와 `gameplay.js` 일부를 덮어쓰는 구조를 실제 최종 동작 기준으로 삼았습니다. 예전 `data.js`의 잘못된 쿠나이+공격력 같은 조합을 그대로 옮기지 않고, 참조 모드가 `reference_subset.json`에서 구성한 최종 조합을 사용합니다.

## 그대로 유지한 전투 규칙

1. 기본 HP **160**, 기본 이동 속도 **190** 논리 단위/초, 기본 흡수 반경 **65**.
2. 장착 주무기 1개가 액티브 슬롯을 사용합니다. 액티브·보조는 각각 **6칸**이며 일반 성장 상한은 **5레벨**입니다.
3. 17개 공격 정의의 5레벨 피해량 배열과 기본 쿨다운은 v14 JSON에서 읽습니다. 17개에는 주무기 5개, 전투 스킬 11개, 합체 결과인 파괴자가 포함됩니다.
4. 보조 12종의 누적 보너스 60개 레벨 값을 읽습니다. 회복은 5초 단위, 피해 감소·XP·자석·골드는 별도 효과입니다.
5. 무기 5레벨 + 대응 보조 1레벨 이상에서 진화 후보가 됩니다. 조건 만족만으로 즉시 진화하지 않습니다.
6. A/B 드론은 각각 5레벨을 요구하며 파괴자로 합체하면 액티브 1칸이 반환됩니다. 합체 후 A/B 신규 카드가 다시 나오지 않습니다.
7. 일반 수호자도 적 탄환을 막습니다. 기본형은 가동/대기 시간이 있고 진화형은 지속 회전합니다.
8. 리볼버 기본 탄창 6발, 진화 10발, 재장전 기본 1.65초에 쿨다운 보조를 적용합니다.
9. 쿠나이·리볼버는 자동 조준, 방망이·카타나·샷건은 이동 방향 기준입니다. 드릴·공·부메랑·드론에는 각자의 관통·반사·복귀·방사 행동을 구현했습니다.
10. 5분/15분 보스 스케줄과 최종 보스 처치 승리 조건, 중간 보스·엘리트 보급, 임무 크레딧을 유지합니다.

## 포팅 과정에서 달라진 부분

| 항목 | G1 결정 | 이유/영향 |
|---|---|---|
| 월드 좌표 | 논리 40단위 = Godot 1단위 | 기존 공격·이동 값을 유지하고 렌더만 변환 |
| 적 외곽 생성 | 플레이어 중심 반폭 X700/Y560의 고정 직사각형 | 화면 크기에 따라 생성 규칙이 달라지지 않음. 웹판의 화면 외곽 생성과 위치는 다름 |
| 난수 | 인스턴스별 Godot RandomNumberGenerator | 상태를 저장할 수 있음. JS Math.random과 같은 전투 시퀀스는 보장하지 않음 |
| 보급 진화 후보 | 한 번에 최대 3개 | 키 1/2/3과 카드 UI를 통일. 자격 조합 자체는 동일 |
| 일시 효과 | 최대 120개, 떠오르는 글자 풀 | 효과 폭주를 제한. 피해 판정 수치와 분리 |
| 그래픽 | 절차적 블록 3D·네이티브 조명·그림자 | 웹 WebGL 코드를 직접 호출하지 않음 |
| 저장 | 별도 JSON 스키마 | 브라우저 저장 자동 변환 미지원 |
| 커스텀 모드 | v14 기본 참조 모드만 포함 | 입력 ZIP의 `custom/index.html`에 보존된 v13은 별도 포팅하지 않음 |

네이티브 전투가 JS와 매 프레임 같은 적 위치/처치 순서까지 재생되는 비트 단위 포팅은 아닙니다. 데이터와 주요 규칙을 이식하고 Godot에서 동일한 장르의 완결된 한 판을 실행하도록 재구성했습니다.

## 원작 데이터의 범위

`reference_subset.json`의 `evidence_status`, `source_ids`, `source_urls`, `client_verified`를 유지했습니다. `runtime_balance.json`은 계속 **DESIGN**이고 `client_verified=false`입니다. G1에서 원작 미확인 값을 공식값으로 바꾸지 않았습니다.

G2에서도 이 근거 구분을 유지합니다. G1 저장 호환을 위한 실제 다중 보스 스냅숏과 생성 출처는 `tests/fixtures/`에 있습니다. G2의 신규 전투 메타데이터가 없는 G1 저장에 진입 연출이나 추가 보상을 새로 지급하지 않습니다.
