# Survivor Arena — Godot Edition G2

기존 **SurvivorArena v14의 공개 참조 플레이 모드**를 **Godot 4.6.3 · GDScript · 네이티브 3D**로 포팅하고, G1의 전투 흐름과 사용성을 개선한 **G2** 프로젝트입니다. 블록형 캐릭터, 자동 공격, 경험치 수집, 6+6 빌드, 진화, 보스전, 저장 후 이어하기를 포함합니다.

## G2에서 달라진 점

- **보스전 흐름:** 전장 정리 → 1.6초 준비 → 독립 교전 → 2초 회복. 일반 웨이브와 다음 보스가 중첩되는 상황을 제어합니다.
- **실제 수치 비교:** 성장 카드에 현재 빌드의 전후 피해·간격·투사체 수·회복량과 진화 진행도를 표시합니다.
- **3D 표현:** 주무기 반동, 총구 섬광, 탄환 잔상, 처치 파편, 진화 무기, 보스 표시, 도시·사막·설원의 서로 다른 장식물을 추가했습니다.
- **설정과 레이더:** 음량·효과음·그래픽 품질·화면 흔들림·피해 숫자·전술 레이더를 조절하고 저장합니다.
- **전투 기록:** 최근 12개 결과와 전장별 최고 기록, 패배의 마지막 피해 원인을 확인합니다.
- **기존 진행 보존:** G1 프로필·전투 저장을 읽고, 마지막 전장·무기 선택을 복원합니다. GUI 위의 터치로 조이스틱이 시작되는 문제도 수정했습니다.

자세한 변경과 설계 판단은 [`docs/G2_CHANGES.md`](docs/G2_CHANGES.md), 실제 검증 결과와 플랫폼별 확인 범위는 [`docs/BUILD_AND_TEST.md`](docs/BUILD_AND_TEST.md)에 있습니다.

## 바로 실행

### Godot 프로젝트

1. ZIP을 풀고 Godot **4.6.3 Standard**를 실행합니다. .NET 버전은 필요하지 않습니다.
2. **Import**에서 `SurvivorArena_Godot_G2/project.godot`를 선택합니다.
3. 첫 에셋 임포트가 끝나면 **F5**로 실행합니다.
4. 도시 / 쿠나이 / 5분 / 일반으로 시작하면 조작과 성장 흐름을 확인하기 좋습니다.

외부 플러그인, npm, CDN, 서버 연결 없이 프로젝트를 실행합니다. 프로젝트 내 이미지·모델·효과음은 절차적으로 구성했고 한글 폰트도 포함했습니다. 배포별 실행 파일과 검증 상태는 `docs/BUILD_AND_TEST.md`를 확인하세요.

CLI 실행:

```bash
godot --path /path/to/SurvivorArena_Godot_G2
```

### 내보낸 빌드

| 빌드 | 실행 방법 |
|---|---|
| Windows | Windows ZIP을 풀고 `SurvivorArena.exe` 실행 |
| Linux x86_64 | Linux ZIP을 풀고 `chmod +x SurvivorArena.x86_64` 후 실행 |
| Web | Web ZIP을 풀고 해당 폴더에서 `python -m http.server 8060`, 브라우저에서 `http://localhost:8060` 접속 |

Web 빌드는 Godot의 JavaScript 부트스트랩과 WebAssembly 실행 엔진을 사용합니다. `index.html`, `.js`, `.wasm`, `.pck`를 같은 폴더에 두고 HTTP로 제공하세요. 기존 v14 단일 HTML과 실행 방식이 다릅니다. HTTPS 배포 또는 localhost에서 WebGL 2.0을 지원하는 브라우저를 사용합니다.

## 플레이 흐름

로비에서 무기·전장·시간·난이도를 선택하고 출전합니다. 이동만 조작하면 장착 무기가 자동으로 공격합니다. 적이 떨어뜨린 경험치를 모으면 전투가 정지되고 세 장의 성장 카드 중 하나를 선택합니다. 액티브 6칸과 보조 6칸 안에서 조합을 구성하고 최종 보스를 처치하면 승리합니다.

| 구분 | 구현 내용 |
|---|---|
| 주무기 5종 | 쿠나이, 야구 방망이, 카타나, 샷건, 리볼버 |
| 전투 스킬 11종 | 수호자, 로켓, 번개, 화염병, 드릴, A형/B형 드론, 축구공, 벽돌, 부메랑, 방어막 |
| 합체 결과 | 파괴자 드론 |
| 보조 12종 | 공격력, 이동 속도, 쿨다운, 최대 체력, 자석, 회복, 범위, 지속시간, 탄속, 경험치, 골드, 피해 감소 |
| 진화 15조합 | 무기+보조 14조합, A/B 드론 합체 1조합 |
| 전장 3종 | 도시, 사막, 빙결 시험장 |
| 적 | 일반, 러너, 탱커, 원거리, 엘리트, 분열체, 저격수, 미니, 보스 |
| 보스 패턴 | 돌진·충격파, 포격·소환, 레이저·빙결 탄막 |
| 보급 | 경험치, 회복, 보급 상자, 자석, 폭탄 |
| 부품 시험 | 드론 유도, 번개 타격 수 +2, RPG 기본 간격 −0.5초 |
| 저장 | 전투 체크포인트, 카드 후보, 난수 상태, 탄창/재장전, 정산 기록 |

**5분 모드:** 02:30 중간 보스, 05:00 최종 보스. **15분 모드:** 05:00·10:00 중간 보스, 15:00 최종 보스. 최종 시간이 지나도 보스를 처치하기 전까지 전투가 계속됩니다.

G2에서는 이전 보스가 살아 있으면 다음 보스 등장을 대기시킵니다. 처치 및 회복 시간이 끝난 뒤 미처리 순서대로 등장합니다. 보스 등장 때 정리되는 일반 적은 처치나 보상으로 계산하지 않습니다.

방망이·카타나·샷건은 **마지막 이동 방향**으로 공격합니다. 적을 향해 방향을 바꾸어 운용하세요. 쿠나이·리볼버는 가까운 적을 자동 조준합니다. 리볼버는 기본 6발을 쏘면 재장전합니다.

## 조작

| 입력 | 동작 |
|---|---|
| W / ↑ | 화면 위로 이동 |
| S / ↓ | 화면 아래로 이동 |
| A·D / ←·→ | 좌우 이동 |
| 화면 드래그 | 터치 또는 마우스 가상 조이스틱 |
| 1 / 2 / 3 | 카드 선택 |
| R | 레벨업 카드 다시 뽑기, 전투당 3회 |
| P / Esc | 일시정지 / 계속하기 |
| B | 빌드와 무기별 피해량 보기 / 닫기 |
| M | 효과음 켜기 / 끄기 |
| N | 전술 레이더 켜기 / 끄기 |
| F11 | 전체 화면 전환 |

창의 포커스를 잃으면 자동으로 일시정지합니다. 이동 입력은 대각선 길이를 정규화해 대각선으로 더 빠르게 이동하지 않습니다. 선택 화면, 일시정지, 빌드 화면에서는 전투 시간이 흐르지 않습니다.

로비 또는 일시정지의 **설정**에서 음량과 화면 효과를 조절합니다. 설정 창에서 Esc를 누르면 원래 화면으로 돌아가며, 일시정지를 임의로 해제하지 않습니다. 모바일의 긴 카드·도감·기록 화면은 세로로 스크롤합니다.

## 저장과 이어하기

15초 간격 및 성장 선택·일시정지 시 체크포인트를 저장합니다. **저장 후 로비 → 저장한 전투 계속하기**로 돌아오면 진행 중인 카드 선택까지 이어집니다. 창 종료 요청에서도 체크포인트를 저장합니다.

네이티브 저장은 Godot `user://` 아래 `SurvivorArenaGodot` 전용 디렉터리를 사용합니다. `run.json`과 `profile.json`을 JSON으로 기록하고 각각 이전 `.bak` 파일을 보존합니다. 본문 SHA-256을 확인하고 기본 저장이 손상되었으면 이전 백업을 읽습니다. 결과의 전투 ID를 기록해 같은 완료 전투의 보상이 중복 정산되는 것을 막습니다.

**같은 기기의 G1 네이티브 저장은 G2에서 이어받습니다.** 기존 프로필의 통계·크레딧·설정·정산 ID를 유지하며 새 옵션에만 기본값을 넣습니다. 과거 개별 전투 기록은 G1에 없었으므로 만들어 내지 않습니다. G1에서 여러 중간 보스가 함께 저장된 경우도 기존 교전을 보존하고, 모든 기존 보스 처치 후 새 일정으로 넘어갑니다.

최근 전투는 12개를 최신순으로 보관합니다. 전장별 최단 클리어는 승리한 전투만 대상으로 합니다. 설정 변경은 즉시 적용하고 짧은 지연 후 파일에 저장하며, 종료·로비 전환 시에는 대기 중인 변경을 먼저 확정합니다.

기존 브라우저 `localStorage` 저장과 다른 기기·브라우저의 저장은 자동으로 옮기지 않습니다. 보상 크레딧은 전투 기록이며 영구 능력치 상점으로 연결하지 않았습니다.

## 데이터와 적용 범위

`data/runtime_balance.json`과 `data/reference_subset.json`은 제공된 v14 파일에서 **바이트 단위로 동일하게** 가져왔습니다. 입력 ZIP 및 데이터 해시는 `data/PORT_PROVENANCE.json`에 기록했습니다.

무기 피해량·쿨다운·적 능력치·웨이브·드랍·보스는 기존 v14의 **구현용 설계값**입니다. 보조 60개 레벨 값과 15개 진화 조건은 v14가 선별한 공개 커뮤니티 참조 자료에 기반합니다. 이번 작업은 원작 클라이언트 데이터를 추출하거나 원작 전체 시스템을 복구한 것이 아닙니다.

포팅 범위는 v14의 기본 참조 플레이 모드입니다. v13 커스텀 특성·대시·영웅 액티브·거점, 원작의 SS 장비 성장·펫·탈것·상점·결제·서버·멀티플레이는 이 버전의 실행 범위에 포함되지 않습니다. 건물·나무·차량은 장식이며 충돌·엄폐가 없습니다. G2의 보스 교전 준비·회복 규칙은 새로 작성한 설계입니다. 포팅 과정의 세부 차이는 `docs/PORTING.md`에 명시했습니다.

## 프로젝트 구조

| 경로 | 역할 |
|---|---|
| `project.godot` / `scenes/main.tscn` | 프로젝트 설정과 진입 씬 |
| `scripts/main.gd` | 입력, 상태 연결, 저장, 오디오, 화면 크기 처리 |
| `scripts/arena_sim.gd` | 노드에 의존하지 않는 60Hz 전투 시뮬레이션 |
| `scripts/catalog.gd` | JSON을 무기·보조·진화 정의로 연결 |
| `scripts/arena_world.gd` | Node3D·Camera3D·MultiMesh 기반 렌더링 |
| `scripts/arena_hud.gd` | 한국어 로비·HUD·카드·빌드·결과 UI |
| `scripts/arena_radar.gd` / `scripts/skill_icon.gd` | 전술 레이더·절차적 스킬 아이콘 |
| `scripts/save_store.gd` | JSON 검증, 임시 파일/백업, 중복 정산 방지 |
| `scripts/touch_stick.gd` | 터치와 마우스 이동 입력 |
| `scripts/arena_audio.gd` / `assets/audio` | 원본 절차적 효과음과 재생 풀 |
| `data` | v14 원본 수치·참조 근거·포팅 출처 |
| `tests` | 실행 가능한 회귀 검사, 실제 결과 JSON, 렌더 캡처 |
| `tools` / `export_presets.cfg` | 테스트, PCK 및 Windows/Linux/Web 내보내기 |

런타임에 절차적 씬을 구성하므로 에디터에서 메인 씬을 열었을 때는 진입 노드가 중심으로 보입니다. **F5 실행 후 Remote 씬 트리**에서 생성된 월드·카메라·UI를 확인할 수 있습니다.

## 수정·검사·내보내기

무기 피해와 기본 쿨다운은 `data/runtime_balance.json`, 적 수치·웨이브·공격 판정은 `scripts/arena_sim.gd`, 모델·팔레트·카메라는 `scripts/arena_world.gd`, 레이아웃은 `scripts/arena_hud.gd`에서 변경합니다. 참조 근거 파일은 구현용 밸런스와 분리해 유지하세요.

```bash
python tools/run_tests.py --godot /path/to/godot
python tools/run_tests.py --godot /path/to/godot --balance
python tools/export_game.py windows --godot /path/to/godot
python tools/export_game.py linux --godot /path/to/godot
python tools/export_game.py web --godot /path/to/godot
python tools/serve_web.py
```

실행 파일 내보내기에는 사용 중인 Godot 버전과 일치하는 Export Templates가 필요합니다. 이 프로젝트는 **Compatibility 렌더러와 단일 스레드 Web 프리셋**을 사용합니다. 내보내기 시 `data/*.json`이 포함되도록 프리셋을 설정했습니다.
