# 변경 기록

## v11 — Godot 포팅판 / 2026-11-20

### 추가

- Godot 4.6.3 Standard 프로젝트, 네이티브 GDScript 시뮬레이션, Control UI, Compatibility 2D 렌더러
- 10영웅 40스킬과 주요 패시브, 공통 점멸·회복·와드, 5대5 AI·전투·성장·상점·승패
- 1/1.5/2배 맵 시작 전 선택, 0.5/0.75/1/1.5배 속도, 연습·일반 모드
- 지형 시야·관측 기억·고정 공격 원점 표시, 네이티브 저장·불러오기
- 현재 시야 마스크로 스킬 효과의 픽셀을 제한하는 SubViewport 합성
- 영웅·아이템 도감, 한글 폰트, 독립 실행용 PCK와 Windows/Linux 내보내기
- Godot 실제 엔진 자동 검증, 지속 시뮬레이션 결과, 재현 도구, 포팅 설계·시스템 문서

### 이식 과정 보완

- 시야 검사 전 거리 제거, 물리 스텝 내부 시야 캐시, 미니언·포탑 대상 탐색 주기 분리
- 시야 셀 지형 사전 계산, 시야원별 장애물 후보 축소, 미니맵 안개 텍스처 공유
- 시야 밖 원형·광선 효과가 흐린 탐색 영역을 통해 노출되지 않도록 합성 마스크 적용
- 숨겨진 중립 공격의 원점도 임시 힌트 제공. 원작 v10과의 의도적 차이로 기록
- 저장 상태의 비유한 값·타입·중복 ID·참조·버전 검증, 실패 시 현재 경기 유지
- 럭스 반환 보호막, 레오나 방어 연장, 아리 매혹·어시스트, 소라카 잘못된 W의 무변경 검증
- 사거리 직전의 공격 이동 정지 현상 수정, D/F·와드 원래 v10 규칙 이식
- 경기 교체 시 렌더러 참조 해제, 초상화 레이아웃, 재시전·충전 표시 개선

### 보존

- 원본 웹 v10 작업 트리·배포·기존 다운로드 파일은 변경하지 않음
- 공식 16.22.1의 기존 데이터 값을 JSON으로 추출, 35개 PNG는 바이트 동일하게 재사용
- 원작 분석·복원 문서와 원본 웹 v10 ZIP을 참고 자료로 동봉

### 구현 경계

- 일반 기본 공격은 선딜레이 완료 시 피해 적용; 스킬 투사체는 실제 비행·선분 충돌
- 전역 A*·건물 몸체 충돌·유닛 밀침 대신 원형 벽 충돌·미끄러짐·지역 우회 사용
- 기존 브라우저 JSON 저장 자동 가져오기, 레거시 3영웅 프로필, 학습·전적 UI, 완전한 모바일 UX·온라인 멀티플레이는 제외
- Windows 실행본은 Linux에서 교차 내보내기 검증. 실제 Windows OS에서 실행 검증하지 않음
