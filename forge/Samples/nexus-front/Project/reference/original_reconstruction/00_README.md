# League of Legends 원작 분석 데이터 재구축·복원 기획

**2026-11-17 KST · PC판 · 소환사의 협곡 중심 · 공개 패치 26.22 · Data Dragon 16.22.1**

이 패키지는 기존 시스템별 역기획서 25개를 보존하고, 실제 공식 정적 데이터를 CSV/JSON으로 재구축한 뒤, 변경된 규칙·복원 공백·구현 순서·검증 조건을 연결한 후속 분석 자료다. **원작 공개 데이터의 복원과 실행 가능한 원작 게임의 완성은 구분한다.** 기존 JavaScript 게임 Nexus Front v7의 실행 코드는 이번 작업에서 변경하지 않았다.

### 피해 공식의 복원 상태

공개 QWER 692개 모두 미해결 툴팁 식별자가 있다. 전체 토큰 3,308개 중 3,274개가 미해결이다. 모든 스킬에 공통인 append 토큰 692개를 제외해도 **682개 스킬에 2,582개 미해결 참조**가 남는다. 따라서 이번 결과를 “전 챔피언의 피해 공식과 동작 복원 완료”로 표현하지 않는다.

`effect` 배열 6,920개 중 5,880개는 원소가 모두 0이며 모든 QWER의 `vars`가 빈 배열이다. 이 0을 실제 무피해 스킬의 근거로 사용하지 않는다. 원본 0·누락·null·미해결은 각각 보존한다. 예를 들어 Ahri Q는 쿨다운·비용·정적 사거리를 확보했지만 `totaldamage`는 그 JSON만으로 해결되지 않는다.

공식 패치의 명시적 계산값은 별도 규칙 장부로 보완한다. 제3자 클라이언트 추출 자료에서 계산 노드를 확인하려는 추가 시도는 이번 환경에서 접근하지 못했으며, [조사 기록](supplementary/communitydragon/README.md)에 미확보로 남겼다.

## 6. 사용자 기능 요구의 위치

현재 웹 게임의 맵 선택은 **시작 전 1 / 1.5 / 2배**, 진행 속도는 **0.5 / 0.75 / 1 / 1.5배**다. 이 기능과 고저차 시야 요구는 독자 프로젝트 규칙으로 추적한다.

고정 건물은 팀별 마지막 관측 스냅샷을 표시하고, 시야 밖 피해·파괴·상태 변화는 재관측 전까지 갱신하지 않는 계약을 구체화했다. 고지대 공격은 공격 원점을 일시 공개하며, 원점 공개와 적 식별·타깃 가능·주변 지형 공개를 별도 정책으로 분리했다. 이 설계가 현재 웹에 구현되어 있다고 설명하지 않는다. 코드 확인 결과 현재 웹은 구조물 실제 상태를 공개하며 벽·높이 LOS와 건물 기억이 없다.

## 7. 실행과 검증

압축 해제한 이 폴더에서 Python 3로 실행한다. 정적 데이터 재생성은 표준 라이브러리만 사용하며 API 키가 필요 없다.

```sh
# 동봉한 선택 필드 projection을 사용해 CSV/JSON 재생성·검증
python scripts/rebuild_data.py

# 기획용 차이·수용 사례 테이블 재생성: 게임 테스트를 실행하는 명령은 아님
python scripts/build_planning_tables.py

# 문서 링크·보존본·메타데이터·패키지 해시 검증
python scripts/validate_package.py
```

공식 고정 버전을 다시 수집하려는 경우에만 다음 명령을 사용한다.

```sh
python scripts/rebuild_data.py --download --version 16.22.1 --previous 16.21.1 --workers 8
```

재다운로드는 원본 응답 해시·수집 시각을 바꿀 수 있다. 기존 보고서의 해시와 새 수집본을 혼합하지 않는다. 데이터 또는 문서를 수정하면 `PACKAGE_MANIFEST.json`도 새 배포본에 맞춰 생성해야 하며, 이전 패키지의 검증 결과를 그대로 적용하지 않는다.

## 8. 폴더 구성

| 경로 | 내용 |
|---|---|
| `baseline_2026-11-13/` | 기존 25개 MD의 무수정 보존본 |
| `docs/systems/` | 시스템별 새 분석 7개 |
| `docs/08…12`, `docs/98…` | 데이터·실행·로드맵·QA·실제 예시·출처 장부 |
| `data/` | CSV/JSON 22종, 사전·범위·검증 결과 |
| `raw/` | 긴 설명을 제외한 공식 JSON 선택 필드 projection, 원천 매니페스트 |
| `analysis/` | 구현 차이, 미실행 수용 사례, 코드 감사, 패키지 검사 |
| `supplementary/` | 제3자 자료 미확보 조사 기록 |
| `scripts/` | 재수집·정규화·검증·기획 테이블 재생성 |

`raw/`의 파일은 원본 응답 전체가 아니다. 원본 응답 SHA-256과 배포 projection SHA-256은 [source_manifest.json](raw/source_manifest.json)에 각각 기록한다. 긴 챔피언 이야기·툴팁 원문·게임 아트·사운드·서버 코드 등은 포함하지 않는다.

## 9. 남은 복원 과제

가장 중요한 공백은 스킬 피해식·효과 순서·재시전·충돌 반경·투사체·취소·숨겨진 예외, 룬·아이템 설명 전용 효과, 정밀한 지형·시야·경험치·보상 경계다. 다음 구현에서는 버전이 고정된 소수 콘텐츠의 입력부터 결과까지 검증한 뒤 확대하는 것이 적합하다.

이번 조사에서 사용자가 처음 제시한 나무위키 본문은 열지 못했다. 확인한 근거는 Riot의 공식 정적 데이터·패치·지원·개발 문서와 현재 프로젝트 코드다. 내부 구현, 실제 클라이언트 플레이 테스트, 전 챔피언 동작 일치 또는 새 게임 배포를 완료했다고 주장하지 않는다.
