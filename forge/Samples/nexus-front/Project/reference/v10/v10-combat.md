# v10 영웅 전투 구현 및 복원 범위

기준: 2026-11-18. 정적 원본 데이터는 Riot Data Dragon **16.22.1**에 고정한다. 실행 엔진은 **v10**, 새 영웅은 **다리우스·이즈리얼·레오나·소라카**이며 기존 아리·애쉬·가렌·럭스·리 신·진을 합쳐 **10명, Q/W/E/R 40개**를 선택해 플레이할 수 있다.

이 문서는 실제 구현 계약이다. 원본 스킬 코드의 추출물이나 원작 서버와 수치·판정이 완전히 같다는 의미의 복원 문서가 아니다. 공식 원본에서 확보한 이름·기본/성장 능력치·스킬 랭크별 마나/재사용 대기시간/사거리 배열과, 실행을 위해 작성한 피해식·충돌 반경·지속시간·AI 판단 기준을 구분한다. 원본 스냅샷과 출처/해시는 [v10-champion-data.md](v10-champion-data.md), 런타임 수치는 `dist/restored-gameplay.js`의 `TUNING` 및 각 스킬 처리 함수에 있다.

## 1. 근거와 데이터 사용

공식 행동 설명 근거:

- [다리우스 공식 영웅 페이지](https://www.leagueoflegends.com/ko-kr/champions/darius/)
- [이즈리얼 공식 영웅 페이지](https://www.leagueoflegends.com/ko-kr/champions/ezreal/)
- [레오나 공식 영웅 페이지](https://www.leagueoflegends.com/ko-kr/champions/leona/)
- [소라카 공식 영웅 페이지](https://www.leagueoflegends.com/ko-kr/champions/soraka/)
- [Riot Data Dragon 설명](https://developer.riotgames.com/docs/lol#data-dragon)

공식 페이지는 스킬의 주요 행동 형태를 대조하는 근거이며, 페이지에 없는 수치까지 증명하지 않는다. Data Dragon의 미해결 템플릿 토큰은 원본 필드에 남겨 두며 임의로 공식 수치로 채우지 않는다. 실행부의 `mechanicsEvidence`는 `authored_reconstruction_not_original_formula`, 정적 정의의 `behaviorEvidence`/`geometryEvidence`는 `project_reconstruction`이다.

사거리는 기존 프로젝트 단위 환산을 유지한다. 자기 중심 스킬의 원본 `1` 같은 sentinel은 보존하고, 실제 영역은 별도 값으로 표현한다. 예를 들어 다리우스 Q는 원본 랭크 배열을 변경하지 않고 `runtimeRangeOverride=230`과 별도 반경 230을 사용한다. 전역 스킬의 원본 `25000` 역시 원본 필드에 보존한다.

Q 피해는 `50/80/110/140/170 + (1+0.1×Q랭크)×총 공격력`이다. 출혈의 1중첩당 초당 피해는 `(12 + 1.2×레벨 + 0.3×추가 공격력)/5`로 작성했다. 이 공식과 관통·회복·녹서스의 힘 수치는 실험용 밸런스 값이다.

녹서스의 힘은 `restored.buffUntil`과 순수 함수 `noxianBonus()`로 계산한다. `hero.damage`에 값을 누적하지 않으므로 아이템 재계산, 저장/재개, 표시 반복, 버프 만료로 공격력이 중복 가산되지 않는다. 기본 공격 피해 미리보기에도 동일한 계산을 사용한다.

원작의 랭크별 궁극기 재사용 창과 최종 랭크 처리 차이를 그대로 재현하지는 않았다. 이번 실행본은 모든 랭크에서 **R 직접 처치 시 즉시 재사용 가능**한 정책이다. W 처치 시 자원 반환 같은 세부 예외도 포함하지 않는다.

W 소유권은 `(sourceId, targetId)` 쌍으로 관리한다. 다른 이즈리얼의 공격이 표식을 소비하지 않는다. W 표식을 붙인 투사체와 실제 후속 피해의 원점을 각각 저장하며, E 탄환은 **착지점**을 공격 원점으로 유지한다. 시전자가 다시 이동해도 저장된 공격 원점을 추적 갱신하지 않는다.

원작의 R 준비 모션·시전 시간, Q의 모든 아이템 적중 효과, 미니언/관통 피해의 전체 예외까지 포함한 시뮬레이션은 아니다. 현재 R은 즉시 투사체를 생성한다. W 마나 반환의 추가 수치 60과 피해식은 재구성 값이다.

## 4. 레오나

| 구분 | 실제 실행 동작 | 재구성 수치와 제한 |
|---|---|---|

| R 흑점 폭발 | 지점에 지연 폭발을 만들며 중심은 기절, 바깥 영역은 강한 둔화를 적용한다. | 지점 사거리 600, 지연 0.65초, 전체 반경 150, 중심 반경 65. 기절/둔화 1.5초, 둔화 배율 0.2. |

W 피해는 `45/80/115/150/185+0.4×주문력`, E는 `50/90/130/170/210+0.4×주문력`, R은 `100/175/250+0.8×주문력`이다. 모두 재구성 밸런스 값이다.

Q 기절은 피격자의 공격 준비·귀환·채널링을 끊는다. E 도착 전 레오나가 사망하거나 기절/속박/매혹되면 접근 이동을 하지 않는다. 이미 발사한 투사체의 피해와 마지막 적의 속박은 별도 판정이다. 속박 자체는 기본 공격을 금지하는 상태로 취급하지 않는다.

햇빛 소비는 일반 피해 처리의 후속 훅에서 실행한다. 먼저 소비할 표식을 만료시킨 다음 추가 피해를 적용하므로 서로 다른 레오나의 표식이 재귀적으로 무한 발동하지 않는다. 기본 공격 미리보기는 추가 피해의 **원 소유자**를 이용해 난이도·팀 버프·저항을 계산한다. 자기 표식은 자기 미리보기의 추가 피해에 포함하지 않는다.

원작의 W 고정 피해 감소를 포함한 모든 세부 방어 공식이나 천공의 검의 원작 이동 판정 전체를 복원한 것은 아니다. E 접근은 프로젝트의 지형 충돌을 고려한 지상 돌진을 사용한다.

피해·회복식:

| 스킬 | 실행 공식 |
|---|---|
| Q 피해 | `85/120/155/190/225+0.35×주문력` 마법 |
| Q 자기 재생 | 총 `50/65/80/95/110+0.3×주문력`, 2.5초 동안 0.5초 간격 5회 |
| W 회복 | `90/130/170/210/250+0.65×주문력` |
| E 최초/종료 피해 | 각각 `70/95/120/145/170+0.4×주문력` 마법 |
| R 회복 | `150/250/350+0.5×주문력`, 저체력 증폭 별도 |

W는 대상 검증이 가장 먼저 수행된다. 자기 자신·적·사망한 아군·미니언·빈 땅을 지정하면 HP/마나/재사용 대기시간/시전 횟수/기본 공격 준비/귀환 상태가 바뀌지 않는다. 비용 지불로 소라카가 죽는 경우도 차단한다. `getSkillInfo('w').healthCost`는 현재 가호 상태가 반영된 실제 체력 비용이다.

W에 좌표가 없는 터치 탭/자동 조준 호출은 범위 안 다른 **부상 아군** 중 체력 비율이 가장 낮은 영웅을 선택한다. 범위 내 아군이 모두 최대 체력이면 자원과 행동 상태를 변경하지 않고 실패한다. 적 포커스가 있어도 아군 선택 정책을 바꾸지 않는다. 좌표가 주어진 경우에는 해당 위치 주변의 아군만 선택하며, 명시적으로 지정한 최대 체력 아군에게 시전하는 기존 정책은 유지한다. 명시적으로 지정한 위치가 비어 있으면 멀리 있는 다른 아군에게 대신 시전하지 않는다.

소라카 AI에는 적 표적 없이 동작하는 지원 판단이 있다. 저체력 아군에게 W를 사용하고, 여러 아군이 다쳤거나 극도로 위험한 아군이 있을 때 R을 판단한다. 자기 HP가 부족한 상황에서 W를 계속 사용하지 않도록 최소 체력 비율 조건을 둔다. 전체 아이템·회복량 감소·회복 증폭 조합을 모두 구현한 체계는 아니다.

## 6. 공통 전투 계약

### 시전과 제어

모든 Q/W/E/R은 `getSkillInfo` → 사용 가능 확인 → 지정 대상 유효성 검사 → 비용 지불 → 공격 준비 취소 → 실제 스킬 실행 순서다. 예외인 Q/W 강화 기본 공격의 소비는 시전 순간이 아니라 공격이 실제로 발사되거나 근접 타격을 실행한 순간이다.

새 스킬은 기존 침묵·기절·매혹·속박 상태와 연결된다. 속박은 이즈리얼 E와 레오나 E 시전을 제한한다. 소라카 E의 침묵은 진 R 같은 채널링을 중단한다. 사망 시 개인 강화 공격·방어·녹서스의 힘·소라카 가호 표시를 초기화하고, 사망한 시전자 몸에 붙는 다리우스 Q/레오나 W는 폭발하지 않는다. 이미 발사한 투사체, 설치 영역, 다른 아군에게 전달한 회복은 해당 효과의 수명과 대상 상태를 따른다.

### 피해 미리보기

`previewBasicAttack()`은 난수·탄약·마나·표식·강화 공격·출혈을 소비하지 않는다. 실제 기본 공격과 동일한 `attackPayload()` 및 저항 계산을 사용한다. 새로 추가한 요소는 다음과 같다.

- 다리우스 W의 강화 물리 피해와 녹서스의 힘 추가 공격력.
- 레오나 Q의 별도 마법 피해 및 다른 레오나가 남긴 아군 발동 햇빛.
- 이즈리얼 W 표식의 기본 공격 폭발 피해.
- 레오나 W의 임시 방어력/마법 저항력과 다리우스 E 방어구 관통.

시간이 지난 뒤 발생할 출혈 틱은 즉시 기본 공격 예상 피해에 포함하지 않는다. 공개 `getBasicAttackPreview()`는 기존과 같이 현재 보이는 적에 대해서만 결과를 반환한다. 결과를 반복 조회해 게임 상태나 RNG가 달라지지 않는 것을 검사한다.

### 시야와 공격 원점

기존 v9의 벽·고저차·수풀 시야, 고정 건물 관측 스냅샷, 미관측 건물 변경 동결, 공격 원점 임시 공개 규칙을 유지한다. 새 피해도 `game.damage()`를 통과해 동일한 시야 기록 훅을 사용한다.

직선 투사체는 발사 위치를 유지한다. 이즈리얼 E 탄환은 착지 위치를 유지한다. 소라카 E 설치 영역은 설치 지점을 사용한다. 소라카 Q와 레오나 R 같은 지연 지점 효과는 시전 원점을 저장한다. 다리우스 Q와 레오나 W처럼 시전자 몸을 따라가는 공격은 실제 폭발 위치를 그 타격 원점으로 확정하고, 이후 출혈/표식은 그 값을 보존한다. 공격 원점 단서는 영웅의 현재 위치를 추적하는 시야 권한이 아니다.

## 7. 상태와 저장 형식

새 출력은 `engineVersion: 10`이다. v4~v9 입력을 계속 수용한다. 기존 v9 문서/ZIP/정적 데이터 파일을 새 구현으로 덮어쓴 역사로 취급하지 않는다.

| 위치 | 추가/확장 내용 |
|---|---|
| `state.rosterVersion` | 9 또는 10. v4~v9 입력은 9로 마이그레이션해 기존 고정 로스터 유지. 신규 LoL 경기는 10. |
| `hero.restored.defenseBonus` | 레오나 W가 저항 계산에 제공하는 임시 값. 구 저장 기본값 0. |
| `hero.restored.rejuvenationUntil` | 소라카 자신의 가호 만료 시각. 구 저장 기본값 0. |
| `hero.restored.stacks` | 기존 애쉬는 상한 4 유지. 이즈리얼만 상한 5. |
| `hero.restored.buffUntil` | 기존 사용을 유지하며 다리우스 녹서스의 힘 만료 시각으로도 사용. |
| 신규 투사체 | `ezreal_q`, `ezreal_w`, `ezreal_r`, `leona_e`. |

새 효과는 공통 `id/sourceId/team/kind/x/y/originX/originY/at/until/radius` 필드를 사용한다.

| 효과 종류 | 고유 데이터 |
|---|---|
| `darius_bleed` | `targetId, stacks, nextAt, damage` |
| `darius_q` | `innerRadius, fireAt, damage` |
| `ezreal_mark` | `targetId, damage, refund` |
| `ezreal_bolt` | `targetId, fireAt, damage` |
| `leona_sunlight` | `targetId, damage` |
| `leona_guard` | `fireAt, damage` |
| `leona_flare` | `innerRadius, fireAt, damage` |
| `soraka_star` | `fireAt, damage` |
| `soraka_zone` | `damage, rootDuration, hits[]` |
| `rejuvenation` | `targetId, nextAt, heal` |

레오나 E 투사체의 `lastHeroId`는 `null` 또는 실제로 맞은 적 영웅 ID여야 하며 `hitIds`에도 포함되어야 한다. 이즈리얼 W 투사체에는 제한 범위를 검증하는 `refund` 값이 있다. 새 효과는 종류별 허용 필드, 소유 영웅, 시전자/대상 팀 관계, 대상 종류, 숫자 범위, 중복 ID 및 중복 hits를 검증한다. v10 효과 수 상한은 256이며 구 v9 이하 검증의 128 상한은 유지한다.

구 저장의 v9 고정 로스터는 v10으로 다시 저장한 뒤 불러와도 유지한다. 이를 위해 원래 로스터 선택 버전을 함께 저장하고 초기 세계의 영웅 ID/팀/역할/라인/영웅 종류와 일치시킨다. 새 영웅의 기본값을 채우기 전에 구버전 검증기를 적용하며, 원본 체크포인트 객체를 수정하지 않는다. v8 리 신 표식/공격 원점 마이그레이션 역시 유지한다.

## 8. 라인 배치와 AI

신규 경기의 플레이어는 정적 데이터의 `preferredRole`에 배치한다. support는 bot 라인, jungle은 mid 라인 좌표 체계를 사용한다. 역할 ID는 각 팀에서 중복되지 않는다.

| 역할 | AI 선택 풀 |
|---|---|
| mid | 아리, 럭스 |
| top | 가렌, 다리우스 |
| jungle | 리 신 |
| bot | 애쉬, 진, 이즈리얼 |
| support | 럭스, 레오나, 소라카 |

선택은 경기 seed의 RNG로 결정되며 같은 seed/플레이어/맵 설정으로 같은 로스터를 만든다. 기존 레거시 3영웅 규칙의 팀 구성은 유지한다. AI는 새 스킬의 거리·상태·피해에 맞추어 판단한다. 다리우스는 R의 예상 고정 피해로 처치 가능성을 판단하고, 이즈리얼은 위협 시 E로 후퇴하며 W 후 Q를 사용하고, 레오나는 원거리 R/E와 근접 W/Q를 조합한다. 소라카 지원 판단은 적 탐색보다 먼저 실행된다.

## 9. 검증 범위와 결과

역학 검사 파일: `tests/v10-combat.test.cjs`, **26개 통과**. 첫 실행에서 발견한 2개 실패는 테스트의 중복 위치에 놓인 앞선 영웅/아직 생성 전인 에픽 몬스터, 처치 경험치로 인한 테스트 대상 체력 재계산 문제였다. 실제 전투 조건을 구성하도록 테스트 fixture를 수정한 뒤 전부 통과했다. 후속 검사는 소라카 W 자동 조준 시 부상 아군이 없으면 자원과 행동 상태를 보존하고, 최대 체력 아군의 수동 지정은 계속 허용하는지 확인한다.

주요 검사:

- Q 안쪽/바깥 피해, 출혈·회복 대상, 다리우스 E 전방 제한/관통/공격 취소, R 중첩·처치 초기화.
- 녹서스의 힘 발동·5중첩 확산·만료 및 기본 능력치 비변경.
- 이즈리얼 Q 첫 충돌과 적중 시에만 재사용 대기시간 감소, W 미니언 통과/건물·에픽 표식/마나 반환 차이.
- 실제 맵 벽을 넘는 E와 안전 착지, 착지 원점 유지, 관통 R과 공격 속도 5중첩 만료.
- 레오나 Q 기절·공격 준비 취소, 햇빛의 자기 소비 금지/아군 소비와 순수 피해 예측.
- 레오나 W 저항 증가·지연 폭발·적중 연장·만료, E 마지막 영웅 접근/시전자 속박 시 이동 취소, R 중심과 외곽 차이.
- 소라카 Q 영웅 적중 회복, W 잘못된 대상의 완전 무소모/자동 아군 선택/가호 전달, E 침묵과 종료 속박, R 전역 생존 아군 회복.
- 소라카 적 없는 지원 판단·방향성 이동 속도와 새 개인 버프의 사망 초기화.

별도 QA 파일 `tests/v10-data-persistence.test.cjs`의 **35개**는 실제 v9 소스로 만든 체크포인트, 신규 16스킬 시전 직후 저장과 4초 후 전체 상태 동일성, 새 효과 10종과 투사체 4종의 손상 거부, 역할/맵 크기/속도 유지 등을 확인한다. 전체 회귀 및 배포 검증의 최종 합계는 프로젝트의 v10 검증 보고서를 따른다.

이 수치들은 전투 시뮬레이션의 정확한 완전 복원률을 뜻하지 않는다. 검증한 것은 명시한 재구성 규칙의 실행, 잘못된 입력의 무소모, 소유권 분리, 저장 결정성, 기존 시야·맵·속도·전투 기능과의 연결이다.
