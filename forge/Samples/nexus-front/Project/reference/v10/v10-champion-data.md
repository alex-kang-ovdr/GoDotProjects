# v10 영웅 데이터와 스킬 복원 명세

기준일: 2026-11-18 · 정적 데이터: Data Dragon **16.22.1** · 패치 표기: **26.22**

## 1. 이번 버전의 범위

v9의 6명에 다리우스·이즈리얼·레오나·소라카를 추가해, 선택 가능한 영웅을 **10명**, Q/W/E/R 전투 정의를 **40개**로 확장했다. 기존 도감 173명·692개 QWER·863개 아이템과 구매 가능한 25개 아이템은 유지한다. 패시브는 10명의 개별 전투 규칙으로 연결하며 40개 QWER 수에 포함하지 않는다.

이번 작업은 기존 정적 분석 자료에서 플레이 가능한 정의를 확장하는 작업이다. 전체 173명을 플레이 가능하게 만들거나 원작 엔진을 복제한 것으로 표현하지 않는다. 수치의 출처와 실제 게임에서 선택한 판정 규칙을 분리한다.

| 구분 | v9 | v10 |
|---|---:|---:|
| 선택 가능한 영웅 | 6 | 10 |
| 선택 영웅 QWER | 24 | 40 |
| 전체 챔피언 도감 | 173 | 173 |
| 전체 QWER 도감 | 692 | 692 |
| 전체 아이템 도감 | 863 | 863 |
| 구매 가능한 아이템 | 25 | 25 |
| 챔피언 초상화 / 아이템 아이콘 | 6 / 25 | 10 / 25 |

## 2. 증거 수준과 원본 보존

| 항목 | 근거 | 구현 시 취급 |
|---|---|---|
| 이름·기본 능력치·성장 필드 | 기존 고정 스냅샷 및 공식 CDN JSON 재대조 | 원본 수치 보존 |
| 스킬 이름·최대 랭크·랭크별 쿨다운·마나·정적 사거리 | 공식 16.22.1 챔피언별 JSON | 원본 배열 보존 |
| 출혈·표식·치유·돌진 등 동작의 큰 구조 | 공식 챔피언 페이지 및 16.22.1 설명·툴팁 검토 | 의미를 요약해 전투 규칙 설계에 사용 |
| 정확한 피해식·계수·시전 시간·투사체 속도·충돌 폭·재사용 창 | 정적 자료의 토큰을 완전히 해석하지 못함 | `project_reconstruction`으로 명시 |
| 기본 전장 역할 | 웹 게임의 팀 구성 정책 | `preferredRole`로 분리 |

`data/restored-input.json`은 v9 기준 커밋 `865c0ef389e582c09207f3a3f56b55ac8a0926b2`의 바이트를 그대로 유지했다. 이미 173명 전체의 사실 필드가 들어 있으므로 신규 4명을 추가하기 위해 원본 분석 배열을 다시 만들 필요가 없었다. 데이터 생성기는 이 스냅샷에서 런타임에 사용할 10명을 선택한다.

기존 분석 패키지의 `raw`에는 원문 설명을 제외한 사본이 있다. 따라서 그 사본의 파일 해시를 원본 응답 해시와 혼동하지 않는다. 이번에는 신규 4명의 **공식 CDN 응답을 별도로 수신해** 각 응답의 SHA-256이 기존 스킬 `sourceHash`와 일치하고, 20개 능력치 및 16개 스킬의 랭크 배열이 일치함을 확인했다. 원문 설명 전문은 산출물에 추가하지 않았다.

원본 `attackdamageperlevel` 등 값이 0인 필드는 그대로 보존한다. 이 값을 원작의 실제 성장량이 없다는 증거로 해석하지 않는다. 미해결 토큰은 `unresolvedTokens`와 별도 행동 근거 파일에 남긴다.

주요 파일: [고정 입력](../data/restored-input.json), [생성기](../scripts/import-restored-data.py), [브라우저 데이터](../dist/restored-data.js), [행동 근거](../data/restored-mechanics-v10.json), [에셋 명세](../data/restored-assets.json).

## 5. 행동 복원의 구현 계약

공식 설명에서 확인한 동작 구조를 아래와 같이 연결한다. 수치가 명시되지 않은 피해·회복량, 지속 시간, 피격 판정은 구현용 수치로 남기며 원작과 동일하다고 표시하지 않는다. 세부 근거 포인터와 미해결 토큰은 [행동 근거 JSON](../data/restored-mechanics-v10.json)에 있다.

| 영웅 | 전투 흐름 | 경계 조건 |
|---|---|---|
| 다리우스 | 출혈 누적 → E 포획 → W 강화 평타 → Q 도끼날 → R 마무리 | Q 안쪽과 바깥쪽을 구분. R의 적 챔피언 대상·처치를 검사하고 재구성 규칙으로 쿨다운을 즉시 초기화 |
| 이즈리얼 | Q 적중으로 쿨다운 단축 → W 표식 → 평타 또는 스킬로 폭발 → E 재배치 | W는 미니언을 표식 대상으로 삼지 않음. 평타 폭발과 스킬 폭발의 마나 환급을 구분 |
| 레오나 | E 마지막 적 챔피언에게 진입 → Q 기절 → W 방어·폭발 → 아군이 햇빛 소모 | 햇빛은 다른 아군 챔피언이 소모. R 중심 기절과 바깥 둔화를 구분 |
| 소라카 | Q로 재생 확보 → W 아군 치유 → E 침묵·지연 속박 → R 전체 치유 | W는 살아 있는 다른 아군 챔피언만 허용. 적·자신·건물·미니언 대상 거절 |

다리우스 E의 지속 방어구 관통, Q의 대형 몬스터 회복, 이즈리얼 W의 에픽 몬스터 표식, 소라카 W의 재생 전달은 공식 의미에 포함된다. 해당 동작을 v10 전투 코드에 연결하며 수치·판정·원작과의 차이는 [v10 전투 계약](v10-combat.md)과 회귀 검사에서 구분한다. 다리우스 R은 원작의 랭크별 일시 재사용 창을 생략하고 처치 시 즉시 쿨다운을 초기화한다.

소라카 R의 체력 40% 미만 치유 강화는 고정 버전 툴팁에서 확인된다. 강화 비율과 최종 회복식은 미해결 토큰을 포함하므로 복원된 정적 사실과 별도로 관리한다.

## 6. 조준·범위·기하 메타데이터

`target`은 입력 방식이다. `ground`라도 다리우스 R처럼 클릭 지점의 적 챔피언을 찾는 경우가 있으므로 단순 지역 피해로 해석하지 않는다. 새 `ally`는 아군 선택용이며 소라카 W에만 적용한다. `geometry`는 이 웹 게임의 판정·표시를 설명하는 재구성 메타데이터다.

| 스킬 | target | 월드 사거리 | radius | geometry / 추가 조건 |
|---|---|---:|---:|---|
| 다리우스 Q | `self` | 230 | 230 | `{"shape":"annulus","innerRadius":126.5}` |
| 다리우스 W | `self` | 150 | 75 | `{"shape":"next_attack"}` |
| 다리우스 E | `direction` | 267.5 | 45 | `{"shape":"cone","halfAngleRadians":0.65}` |
| 다리우스 R | `ground` | 230 | 40 | `{"shape":"unit","team":"enemy","championOnly":true}` |
| 이즈리얼 Q | `direction` | 575 | 20 | `{"shape":"projectile"}` |
| 이즈리얼 W | `direction` | 575 | 20 | `{"shape":"projectile"}` |
| 이즈리얼 E | `dash` | 237.5 | 70 | `{"shape":"blink","boltSearchRadius":350}` |
| 이즈리얼 R | `direction` | 4800 | 65 | `{"shape":"line"}` |
| 레오나 Q | `self` | 50 | 75 | `{"shape":"next_attack"}` |
| 레오나 W | `self` | 225 | 225 | `{"shape":"circle"}` |
| 레오나 E | `direction` | 437.5 | 22 | `{"shape":"line"}` |
| 레오나 R | `ground` | 600 | 150 | `{"shape":"circle","centerRadius":65}` |
| 소라카 Q | `ground` | 405 | 110 | `{"shape":"circle"}` |
| 소라카 W | `ally` | 275 | 60 | `{"shape":"unit","team":"ally","championOnly":true,"selfAllowed":false}` |
| 소라카 E | `ground` | 462.5 | 130 | `{"shape":"circle"}` |
| 소라카 R | `self` | 12500 | 70 | `{"shape":"global","team":"ally","championOnly":true}` |

`radius`는 입력 표시나 효과의 기준값으로 사용하며 모든 스킬에서 피격 반경을 뜻하지 않는다. 강화 평타와 아군 지정 스킬의 실제 적격성은 전투 코드가 검사한다. 다리우스 Q의 `rangeByRank=1`은 자신의 주변에 사용하는 표시값이므로 피해 반경으로 사용하지 않는다. 실제 바깥 반경 230과 안쪽 반경 126.5는 재구성값이다. `runtimeRangeOverride=230`은 자기 주변 효과의 미리보기를 위한 값이며 원본 배열을 바꾸지 않는다.

이즈리얼 R의 원본 사거리 배열 25,000은 보존하고 런타임만 `runtimeRangeOverride=4800`으로 둔다. 2배 맵의 3,200×3,200 대각선 길이보다 길어 지원하는 맵을 가로지를 수 있다. 실제 투사체 이동 거리는 현재 맵의 대각선 길이를 사용하며 4,800은 조준 메타데이터의 최대값이다. 이즈리얼 R의 원작 준비 시간은 생략해 즉시 발사한다. 원본 엔진의 투사체 소멸 거리나 시야 규칙을 검증했다는 의미는 아니다. 소라카 R은 `geometry.shape=global`이며 사거리 원으로 아군을 걸러내지 않는다.

## 9. 생성과 검증

재생성에는 네트워크가 필요 없다. 저장된 고정 입력과 생성기만 사용한다. 신규 PNG는 저장소에 함께 포함된다.

```bash
python3 scripts/import-restored-data.py
```

이번 데이터 단계에서 확인한 항목은 다음과 같다.

- 동일 입력으로 연속 생성한 `dist/restored-data.js`가 바이트 단위로 동일함.
- 신규 4명의 20개 능력치와 16개 QWER의 이름·쿨다운·비용·사거리 배열이 고정 원본 및 공식 응답과 일치함.
- 신규 4개 공식 응답 SHA-256이 기존 스킬 `sourceHash`와 일치함.
- `data/restored-input.json`이 v9 기준과 바이트 단위로 동일함.
- 기존 31개 에셋 레코드가 같고 전체 35개 파일의 크기·SHA-256이 에셋 명세와 일치함.
- 생성 결과가 173명·692개 QWER·863개 아이템·플레이 10명·구매 25개를 유지함.

정적 검증은 전투 동작 검증을 대신하지 않는다. 최종 게임 검증 보고서에서 신규 패시브·QWER, 조준 취소, 자원 실패, 사망·부활, 체크포인트, 세 맵 크기 및 게임 속도별 결과를 함께 확인한다.

## 10. 변경 파일과 보존 범위

- `scripts/import-restored-data.py`: 신규 4명 선택, 설명·타깃·기하·역할 정의 및 10명 검증.
- `dist/restored-data.js`: 생성기로 다시 만든 브라우저 데이터.
- `data/restored-mechanics-v10.json`: 신규 4명의 공식 동작 의미와 출처 포인터·해시·미해결 토큰.
- `data/restored-assets.json`: 기존 31개 항목 보존 후 신규 4개 항목 및 갱신일 추가.
- `dist/assets/champions/{Darius,Ezreal,Leona,Soraka}.png`: 공식 초상화 4개.
- `docs/v10-champion-data.md`: 이 문서.

기존 분석 패키지, 기존 v9 ZIP, 기존 25개 아이템 정의, 고정 입력 데이터는 수정하지 않았다. 전투 엔진·UI·검증 보고서의 변경 이력은 각 v10 문서에서 다룬다.
