# Nexus Front — Godot v11

**기존 JavaScript 웹 v10을 Godot 4.6.3의 네이티브 GDScript 게임으로 옮긴 버전입니다.** `project.godot`를 가져오고 **F5**를 누르면 영웅 선택부터 실제 전투까지 실행됩니다. 게임 실행에는 웹 브라우저·WebView·JavaScript·Node.js·네트워크 연결이 필요하지 않습니다.

- 버전: **v11 / Godot 포팅판**
- 작성 기준일: **2026-11-20 (Asia/Seoul)**
- 원본: Nexus Front 웹 v10, Git `d53d9e1df6525719f0d791010235090119451d45`
- 확인한 엔진: **Godot 4.6.3 stable / Standard**. .NET 버전과 C# 런타임은 필요하지 않습니다.
- 렌더러: **Compatibility / OpenGL**, 절차형 2D 전장과 기존 초상화
- 플레이: 싱글 플레이어 1명 + AI 9명, 5 대 5, 세 공격로, 넥서스 파괴 승리

## 실행

### 프로젝트를 편집하며 실행

1. Godot **4.6.3 Standard**를 설치합니다. 공식 배포: <https://godotengine.org/download/archive/4.6.3-stable/>
2. 압축을 풀고 Godot 프로젝트 관리자에서 **Import**를 선택합니다.
3. 이 폴더의 **project.godot**를 엽니다. 첫 실행 시 폰트·이미지를 가져옵니다.
4. **F5**를 누릅니다. 영웅, 맵 크기, 속도, 모드를 선택하고 **전장 진입**을 누릅니다.

명령줄에서도 실행할 수 있습니다.

```bash
godot --path /path/to/Nexus_Front_Godot_v11
```

### PCK 게임 데이터 실행

소스 패키지의 `exports/Nexus_Front_Godot_v11.pck`는 실행에 필요한 리소스를 묶은 게임 데이터입니다. **PCK 자체는 독립 실행 파일이 아니며**, Godot 4.6.3 실행기가 필요합니다.

```bash
godot --main-pack exports/Nexus_Front_Godot_v11.pck
```

별도 Windows/Linux 패키지를 받은 경우에는 해당 폴더의 실행 파일을 사용합니다. `.pck` 파일은 실행 파일 옆에 함께 두어야 합니다. 지원 환경과 검증 범위는 [내보내기 문서](docs/EXPORT.md)를 참조하세요.

## 게임 설정

| 설정 | 지원 값 | 동작 |
|---|---|---|
| 맵 크기 | **1× / 1.5× / 2×** | 시작 전에만 선택. 월드 1,600 / 2,400 / 3,200. 지형·공격로·건물·캠프 좌표를 함께 확대 |
| 게임 속도 | **0.5× / 0.75× / 1× / 1.5×** | 경기 중 변경 가능. 2× 속도는 제공하지 않음 |
| 연습 | 플레이어 6레벨 / 2,500G | Q3/W1/E1/R1로 주요 스킬을 즉시 체험 |
| 일반 | 1레벨 / 600G | 미니언·적 처치로 성장하고 스킬을 학습 |

게임 시간에 따라 재사용 대기·시야·웨이브·재생·부활이 함께 진행됩니다. 설정한 배속은 다음 실행에도 유지됩니다. 일시 정지 시 월드 시뮬레이션을 멈추며, 상점·도감·메뉴를 닫으면 직전 정지 상태로 돌아갑니다.

## 저장

진행 중인 전투는 `user://nexus_front_v11.nfs`에 저장합니다. 설정은 `user://nexus_front_settings.cfg`에 저장합니다. 60게임초마다 자동 저장하며 저장 버튼으로 즉시 저장할 수 있습니다. 완료된 전투는 진행 중 체크포인트에 덮어쓰지 않습니다.

웹 v10의 브라우저 JSON 저장과 Godot v11의 `.nfs`는 **서로 다른 형식**입니다. 이 배포는 브라우저 저장 파일의 자동 가져오기를 제공하지 않습니다. `.nfs`는 객체 역직렬화를 허용하지 않는 Variant 데이터이며, 타입·범위·참조·버전 검증에 실패하면 현재 경기를 바꾸지 않습니다.

## 데이터·원본 보존

`data/restored_data.json`은 기존 `dist/restored-data.js`의 데이터를 값 변경 없이 JSON으로 추출한 것입니다. 35개 기존 PNG는 바이트 단위로 그대로 복사했습니다. 원작 정적 수치와 프로젝트가 재구성한 피해 공식·판정·AI는 별도 근거로 구분됩니다. **173개 도감 영웅 전체가 플레이 가능한 것은 아닙니다.**

원본과 내보낸 데이터의 SHA-256, 영웅·스킬·아이템 수, 초상화별 SHA-256은 `data/provenance.json`에 있습니다. 기존 v10 소스 ZIP과 분석 문서는 `reference/`에 보존했습니다. 참고 자료는 역사적 분석이며, 현재 Godot의 구현 범위는 이 README와 `docs/`가 기준입니다.

## 검증 실행

```bash
godot --headless --path . --script tools/run_tests.gd
# Python이 있는 개발 환경에서는 로그의 GDScript 오류까지 실패로 처리:
python3 tools/test.py
```

집계 결과는 `docs/validation_results.json`, 실제 실행 로그는 `docs/validation.log`, 전체 검증 범위는 [QA.md](docs/QA.md)를 확인하세요.

## 구현 경계

이 배포는 **네이티브 싱글 플레이어 코어 게임 포팅**입니다. 원작 서버 구현·리플레이 시스템·온라인 멀티플레이·계정·매치메이킹·상용 수준 캐릭터 애니메이션을 포함하지 않습니다. 웹의 레거시 3영웅 별도 프로필, 학습 코치·과제·전적 UI, 브라우저 공유 기능은 Godot UI로 이식하지 않았습니다. 카메라와 전장은 2D이며 새 3D 모델을 생성하지 않았습니다.

이 프로젝트는 Riot Games의 공식 게임이 아닌 팬 제작 분석·구현 프로젝트입니다. 원작 명칭·초상화·정적 자료의 권리는 각 권리자에게 있습니다. 데이터 출처와 폰트 라이선스는 [DATA.md](docs/DATA.md), `assets/FONT_LICENSE.txt`에 기록되어 있습니다.
