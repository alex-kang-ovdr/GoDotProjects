# 영웅·스킬 포팅 명세 — Godot v11

## 기준과 범위

기준 소스는 Nexus Front 웹 v10, 커밋 `d53d9e1df6525719f0d791010235090119451d45`입니다. Godot 런타임에서 JavaScript를 호출하지 않으며, `scripts/ability_system.gd`가 GDScript로 전투 상태를 직접 갱신합니다. 플레이 가능한 영웅 10종, Q/W/E/R 40개와 각 영웅의 주요 패시브를 구현했습니다.

`data/restored_data.json`의 `playableHeroes[].skills`에 들어 있는 Data Dragon **16.22.1**의 스킬 이름, 최대 랭크, 랭크별 소모 자원·재사용 시간·사거리 배열을 사용합니다. 이 문서의 피해 계산, 충돌 반경, 재시전 상태와 AI 판단은 v10의 **프로젝트 재구성 규칙**을 옮긴 것입니다. 라이브 리그 오브 레전드 서버 코드나 모든 판정의 동일성을 의미하지 않습니다.

데이터의 공식 출처 URL·JSON 포인터·SHA-256은 각 항목의 `source`, `sourcePointer`, `sourceHash`에 보존되어 있습니다. 전체 카탈로그에 포함된 173개 챔피언 모두가 플레이 가능한 것은 아닙니다.

## 공통 시전 순서

1. 생존, 스킬 습득, 행동 불가·침묵, 이동 스킬의 속박, 재사용·충전·재시전 준비 상태를 검사합니다.
2. 필요한 자원과 지정 대상의 팀·생존·사거리·가시성을 확인합니다.
3. 검증을 통과한 경우에만 자원, 재사용 시간, 캐스팅 횟수, 귀환·기본 공격 상태를 변경합니다.
4. 투사체·지연 영역·상태 효과를 생성하거나 즉시 효과를 적용합니다.
5. 피해는 `SimWorld.damage()`를 통과합니다. 방어, 보호막, 기여자, 사망, 공격 출처 힌트가 공통 경로에서 처리됩니다.

이 순서로 **소라카 W의 잘못된 시도는 체력·마나·재사용·시전 횟수를 전혀 바꾸지 않습니다.** 좌표 없는 자동 W는 사거리 안의 부상 아군 중 체력 비율이 낮은 대상을 선택합니다. 수동 지정을 사용하면 살아 있는 다른 아군 영웅만 허용하며, 자신이나 적은 허용하지 않습니다.

## 판정과 수치

- 게임 월드 단위는 원본 정적 사거리의 `0.5`배입니다. 맵 크기를 1.5배·2배로 바꾸어도 영웅의 공격·스킬 사거리가 함께 커지지 않습니다.
- 다리우스 Q의 원본 정적 사거리 `1`은 자기 시전용 센티널입니다. 이를 실제 범위로 사용하지 않고, 데이터에 명시한 재구성 반경 **230**, 안쪽 반경 **126.5**를 사용합니다.
- 이즈리얼 R, 애쉬 전역 스킬, 진 R은 데이터에 명시된 `runtimeRangeOverride`를 사용합니다. 이즈리얼·애쉬의 실제 투사체 이동 한도는 현재 맵 대각선 길이입니다.
- 투사체는 이전 좌표부터 다음 좌표까지 선분과 원의 거리를 검사합니다. 빠른 투사체가 한 프레임 사이에 대상을 건너뛰는 문제를 줄입니다. 대상별 충돌 목록으로 중복 적중을 막고, 아리 Q·럭스 W의 반환 구간에서는 목록을 새로 시작합니다.
- 지정 대상 스킬은 현재 가시성을 요구합니다. 직선 투사체·범위 공격은 보이지 않는 곳에도 시전할 수 있으며, 실제 충돌은 월드 상태를 기준으로 처리합니다.
- 다리우스 Q와 레오나 W는 캐릭터를 따라가는 효과입니다. 실제 발동 지점이 공격 출처가 되고, 설치한 영역은 설치 지점이 출처가 됩니다. 지속 피해·표식이 이동하는 대상의 위치를 공격 출처로 잘못 노출하지 않습니다.
- 시전자와 대상의 조합으로 출혈·햇빛·정수 표식을 소유합니다. 같은 영웅이 양 팀에 존재해도 표식을 덮어쓰지 않습니다.
- 레오나의 햇빛은 적격 표식을 먼저 모두 소비한 후 추가 피해를 발생시킵니다. 중첩 피해 호출이 다시 표식을 발동하는 재귀를 막습니다.
- 일반 공격의 치명타 RNG, 진 탄약 소비, 강화 공격 소비는 `basic_attack()`에서 한 번 처리됩니다. UI 설명을 읽는 `describe()`는 전투 상태를 바꾸지 않습니다.

## AI와 상태 보존

AI는 해당 영웅에 맞는 시전 우선순위를 사용합니다. 가렌·다리우스는 근거리와 처형 조건, 레오나는 접근·기절, 이즈리얼은 표식 연결과 탈출, 소라카는 적이 없어도 부상 아군 회복을 선택합니다. 진의 커튼 콜은 시전 방향 부채꼴 안에서만 재시전하며 이동·중단·군중 제어로 취소할 수 있습니다.

Godot 저장에는 영웅별 `state`, 투사체 위치·방향·이미 적중한 ID, 영역·표식의 시전자·대상·남은 시각, 재시전 슬롯, 효과 ID 시퀀스가 포함됩니다. `export_state()` / `import_state()`는 네이티브 데이터를 사용하고, 역직렬화 시 유한한 숫자·좌표, 허용 타입, 상한, 필수 필드, 시전자 ID, 중복 ID를 검사합니다. 웹 v10의 JSON 저장과 Godot v11 저장은 서로 다른 형식입니다.

## 구현 경계

이 파일은 원작의 서버 틱·애니메이션 취소·미세한 판정·모든 아이템 온힛 상호작용까지 복제하지 않습니다. 피해·계수는 v10에서 구분해 둔 재구성 튜닝을 유지합니다. 이즈리얼 R의 별도 충전 시간과 원작 특수 예외 전체, 복잡한 엔진 오브젝트·네트워크 예측은 구현 범위가 아닙니다. 이동 스킬은 공통 지형 검사를 사용하는 2D 위치 이동입니다.

## 검증

`tests/test_abilities.gd`는 실제 Godot 4.6.3 헤드리스 실행에서 **160개 검사 통과**를 확인했습니다. 포함 항목은 40개 스킬 진입과 공식 랭크별 재사용 시간, 소라카 W 무효 입력 무변경, 재생 비용 감소·전달, 다리우스 안쪽/바깥쪽 Q·5출혈·R 초기화, 이즈리얼 표식·자원 환급·적중 쿨다운 감소, 레오나 아군 전용 햇빛·방어 연장, 아리 반환 구슬·매혹 이동·처치 관여, 럭스 2대상 Q와 반환 보호막, 리 신 Q2, 진 탄약·재장전·채널링, 잘못된 저장 상태 거부입니다.
