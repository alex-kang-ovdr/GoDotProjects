# 월드 시뮬레이션 · Godot v11

## 기준과 책임

이 프로젝트는 Nexus Front 웹 v10 커밋 `d53d9e1df6525719f0d791010235090119451d45`를 Godot 4.6.3의 GDScript로 이식한 단일 플레이 게임이다. 게임 규칙은 [`scripts/sim_world.gd`](../scripts/sim_world.gd), 영웅의 QWER와 패시브는 [`scripts/ability_system.gd`](../scripts/ability_system.gd), 시야와 고정 오브젝트 관측 기록은 [`scripts/vision_system.gd`](../scripts/vision_system.gd)가 담당한다. JavaScript 실행기나 웹뷰가 게임 로직을 실행하지 않는다.

영웅 기본 능력치와 아이템·스킬의 등급별 정적 배열은 기존 `16.22.1` 복원 데이터에서 가져왔다. 피해 공식, 전장 크기, 시간 압축, AI, 미니언·구조물 수치 및 D/F 수치는 Nexus Front의 재구성 규칙이다. 공식 라이브 서비스의 서버 구현이나 대전 균형과 동등하다는 의미가 아니다.

## 실행 흐름

`SimWorld.new()` → `setup(options)`로 한 경기를 구성한다. `step(dt)`가 게임 시간과 전투를 진행하고, `winner`가 0 또는 1이면 시뮬레이션을 종료한다. UI는 물리 프레임에 게임 속도 배수를 곱한 시간을 전달한다. 쿨다운, 출혈, 재시전, 귀환, 부활, 와드 수명과 시야 힌트는 모두 같은 게임 시간을 따른다. 큰 프레임 입력은 최대 0.1초로 제한하며 일시 정지 중에는 `step`을 호출하지 않는다.

맵 배수는 시작 옵션 `map_scale`의 1 / 1.5 / 2이다. 한 변은 각각 1600 / 2400 / 3200 프로젝트 단위이며, 라인 좌표·기지·벽·수풀·언덕·정글 캠프 위치와 지형 반경을 비례 이동한다. 영웅 자체의 사거리·이동 속도는 맵 배수로 늘리지 않는다. 따라서 큰 맵에서는 이동과 합류에 더 많은 시간이 걸린다.

### 시작 모드

| 모드 | 플레이어 시작 | 피해 조정 |
|---|---|---|
| 일반 전투 | 1레벨, 600G, Q 1랭크 | 일반 피해 |
| 훈련 | 6레벨, 2500G, Q3 / W1 / E1 / R1 | 플레이어가 받는 피해 ×0.7 |

AI 영웅은 두 모드 모두 정상적인 1레벨 성장으로 시작한다. 훈련은 모든 버튼을 빠르게 확인하기 위한 시작 옵션이며 무적 모드는 아니다.

## 전장과 승리 조건

양 팀은 미드·탑·정글·바텀·서포터 역할을 한 명씩 갖는다. 선택한 영웅의 기본 역할에 플레이어가 배치되고 나머지 역할은 시드가 고정된 무작위 선택으로 채운다. 양 팀의 영웅 합계는 10명이다.

세 라인에는 팀마다 외곽 포탑과 안쪽 포탑, 억제기가 있다. 기지에는 수호 포탑 두 개와 넥서스가 있다. 총 16개 포탑, 6개 억제기, 2개 넥서스가 생성된다.

파괴 순서는 라인 외곽 포탑 → 같은 라인 안쪽 포탑 → 같은 라인 억제기 → 기지 수호 포탑 두 개 → 넥서스다. 선행 조건이 충족되지 않은 구조물은 `protected` 상태이며 피해가 적용되지 않는다. 억제기가 파괴된 라인에는 상대편 강화 미니언이 추가된다. 전투 시작 6분 전까지 아군 미니언이 430 거리 안에 없는 구조물 공격은 피해가 20%로 줄어든다. 넥서스 파괴가 실제 승패를 확정한다.

첫 웨이브는 시작 시 생성하고 이후 18초마다 세 라인 양 팀에 근접 3 + 원거리 2를 추가한다. 세 번째 웨이브마다 공성 미니언이 추가되며 270초 이후에는 매 웨이브 공성 미니언이 나온다. 살아 있는 라인별 미니언이 충분히 많으면 생성을 생략하고, 오래된 미니언은 정리하여 개체 수가 끝없이 증가하지 않도록 한다.

## 전투·성장·AI

기본 공격은 준비 동작과 회복 시간을 나누어 처리한다. 발사 전 이동, 제어 효과 또는 주문 입력으로 준비 동작을 취소할 수 있다. 피해는 준비 동작 종료 시 하나의 공통 경로로 적용되며, 물리 방어력·마법 저항력·고정 피해, 보호막, 피해 감소, 다리우스 방어구 관통, 패시브 발동, 처치 및 보상이 이 경로를 사용한다. 일반 기본 공격의 비행 시간은 별도로 시뮬레이션하지 않고 종료 시점에 명중 판정한다. 영웅 스킬 투사체는 이동·충돌·다중 적중·왕복을 별도로 시뮬레이션한다.

처치자에게 골드와 CS를 주고, 가까운 아군 영웅에게 경험치를 준다. 영웅 처치는 킬·데스·어시스트와 팀 점수에 반영하며 참여 기록은 제한된 시간 동안만 인정한다. 레벨은 최대 18이다. 일반 스킬 랭크는 5, 궁극기는 3이며 궁극기 랭크는 6 / 11 / 16레벨 조건을 따른다. 능력치 성장은 웹 v10의 `(레벨−1) × (0.7025 + 0.0175 × (레벨−1))` 곡선과 원본의 레벨당 값을 사용한다. 원본에 들어 있는 0을 임의의 수치로 바꾸지 않는다.

봇은 3레벨까지 Q/W/E를 각각 배우고 이후 주력 스킬과 궁극기를 강화한다. 적 탐색은 보이는 적과 현재 공격 가능한 구조물에 한정된다. 서포터 소라카는 적이 없어도 다친 아군을 치료한다. 정글 역할은 보이는 중립 캠프를 선택한다. 낮은 체력 또는 마나 고갈 시 후퇴·귀환하고, 기지에서 역할별 아이템을 구매한다. 포탑은 평소 미니언을 우선하지만 사거리 안에서 아군 영웅을 공격한 적 영웅에게 공격 대상을 바꾼다. 영웅을 연속 공격하면 포탑 피해가 증가한다.

이동은 원형 벽에 대한 연속 충돌 검사와 미끄러짐, 짧은 우회 경유점을 사용한다. 전역 A* 경로망, 유닛 간 물리 밀침 또는 건물 몸체의 물리 충돌은 이 버전에 포함되지 않는다. 공격 판정용 건물 반경과 지형에 대한 스킬/이동 충돌은 각각 적용된다. 지형을 변경할 때 이 차이를 고려해야 한다.

## 공용 주문과 시야 와드

| 입력 | 동작 | 제약 |
|---|---|---|
| D 점멸 | 최대 300 거리, 벽을 넘고 유효한 지점에 착지 | 32초, 기절·속박·매혹 중 불가, 자원 소모 없음 |
| F 회복 | 자신 `220 + 최대 체력 × 0.08`; 240 안의 아군 영웅 `150 + 시전자 레벨 × 10`; 자신의 이동 속도 +25% 1.6초 | 28초, 기절·매혹 중에도 사용, 자원 소모 없음 |
| 와드 | 체력 60, 시야 480, 수명 50초, 설치 사거리 최대 450 | 22초, 소유자당 최대 2개, 세 번째 설치 시 가장 오래된 와드 제거 |

점멸은 도착 후보가 벽 내부이면 조준선 위에서 가까운 유효 지점을 찾는다. 유효한 이동이 없으면 쿨다운과 자원을 소비하지 않는다. F는 체력이 가득 차 있어도 이동 속도 효과를 위해 쓸 수 있다. 성공한 D/F는 귀환과 기본 공격 준비 동작을 취소한다. 봇도 체력이 38% 아래로 내려가면 F를 사용할 수 있다.

## 정글·귀환·부활·상점

일반 캠프는 처음부터, 드래곤은 45초, 심연 거인은 120초에 등장한다. 중립 몬스터는 공격받으면 반격하고 활동 반경 밖으로 유인되면 원위치로 돌아가 회복한다. 재등장은 일반 캠프 38초, 드래곤 85초, 심연 거인 150초다. 드래곤은 팀의 피해를 중첩당 6.5%, 최대 4중첩 강화한다. 심연 거인은 70초 동안 아군 영웅 가까이 있는 미니언의 피해를 40%, 이동 속도를 10% 높인다.

귀환은 4초이며 이동·피해·제어 효과로 취소된다. 사망한 영웅은 레벨과 경기 시간에 따른 7~22초 후 아군 기지에서 체력·자원을 회복하고 부활한다. 기지에서는 체력·자원이 빠르게 회복된다.

상점은 아군 기지 180 거리 안 또는 사망 상태에서 이용한다. 복원된 구매 가능 아이템 25개와 인벤토리 6칸을 지원한다. 조합에 필요한 같은 부품이 두 개이면 실제 보유한 수량만큼만 할인하며, 한 부품을 두 번 사용하지 않는다. 하위 부품만 보유했을 때도 레시피를 재귀 탐색하여 할인한다. 조합은 부품을 제거한 뒤 최종 아이템을 넣으므로 가득 찬 인벤토리에서도 공간이 생기면 구매할 수 있다. 신발과 고유 아이템 그룹의 중복 구매를 제한하고 판매 금액은 복원 데이터의 값을 사용한다.

## 시야와 저장

벽·고지대·수풀·공격 위치의 일시적 힌트·마지막으로 관측한 건물 상태는 [FOG.md](FOG.md)를 따른다. 고정 건물의 관측 기록은 렌더러가 실제 적 구조물의 숨은 현재 상태를 직접 읽어서 갱신하지 않도록 별도 저장한다.

네이티브 체크포인트는 v11의 `.nfs` 형식이다. Godot의 객체 복원을 허용하지 않는 Variant 직렬화로 Vector2, Color, 바이트 배열을 보존한다. 영웅의 재시전·중첩·잔여 쿨다운·공용 주문, 움직이는 투사체·설치 효과와 다음 ID, 와드, RNG, 맵 배수, 웨이브 일정, 시야 탐색과 건물 기억을 저장한다. 새로운 `SimWorld`에서도 `load_game(path)`를 바로 호출할 수 있다.

파일 크기 8MiB 제한, 필수 필드·타입·수치 범위·유한 좌표·영웅 상태·투사체/효과·시야 스키마 검증을 수행한다. 임시 월드에서 검증한 뒤 적용하므로 손상된 저장을 불러오려다 진행 중인 경기가 바뀌지 않는다. 저장은 임시 파일을 작성한 뒤 이름을 바꾸어 반영한다. **웹 v10의 JSON 체크포인트와 `.nfs`는 서로 다른 형식**이다. 브라우저의 이전 저장을 자동 변환하지 않는다.

## 성능 구조와 검증

다수 유닛은 씬 트리 노드 하나씩으로 구성하지 않고 시뮬레이션 Dictionary와 통합 2D 렌더링으로 처리한다. 상태와 화면을 분리하므로 헤드리스 검증에서도 같은 규칙이 실행된다.

대상을 찾을 때 거리와 팀을 먼저 검사하고 필요한 후보에만 시야의 정확한 검사를 한다. 한 물리 스텝 안의 동일 대상/팀 시야 결과를 재사용하며 대상 위치·생존·강제 노출 정보가 바뀌면 다시 계산한다. 캐시는 스텝 경계에서 버려지고 UI나 저장에서 재사용되지 않는다. 시야 제공자 이동의 영향은 최대 다음 물리 스텝에 반영된다. 미니언과 포탑은 대상이 비었다고 매 프레임 전체 목록을 다시 탐색하지 않으며 각각 0.25초, 0.2초 주기로 새 대상을 찾는다. 라인 경유점은 0.4초, 지형 우회점은 0.18초까지 재사용하고 목표가 이동하거나 가까워지면 즉시 갱신한다. 구조물 보호 상태는 생성·파괴·불러오기 시점에 갱신한다.

[tests/test_world.gd](../tests/test_world.gd)는 맵 배수, 공식 기본 능력치, 기본 공격 취소, 피해·방어·보호막, XP/궁극기 조건, 레시피 수량과 6칸 조합, 전체 승리 경로, 귀환·부활, D/F·와드, 저장 지속성과 손상 입력 거부를 검증한다. 영웅 스킬과 시야는 별도 테스트 묶음에서 검증한다. 최종 실행 결과와 성능 측정 조건은 프로젝트 검증 보고서에 기록한다. 실제 화면 렌더링 성능은 GPU·해상도·운영체제에 따라 달라지므로 헤드리스 수치를 화면 FPS로 해석하지 않는다.
